## V2.0 EXP（feat/v2.0-exp，实验中）

> **这是起闯战争史上最大规模的系统重构。** 它不是数值微调，而是把"靠龟缩活到最后"的旧范式
> 整体拆掉，换成"在限定的世界时钟里争取综合评分"的新范式。
>
> **全程实验开关门控。** 每个里程碑都挂在 `engine/experiments.py` 的独立开关后（`k_initiative`、
> `hp20`、`m3_*`、`m4_economy`、`world_clock`、`scoring`、`m7_talents` 等）。**所有开关关闭时，
> 游戏与 V1.95 逐字节一致**——golden 回放（M0e）对 v1~m6 全程零污染验证保证了这一点。
>
> **数值尚未定稿。** 所有平衡数值集中在 `data/balance.json`，标注 `[待风洞]`，由 `stats_runner`
> 风洞校准。因此本条目**只记录机制变化，不引用具体调参数字**（它们会随风洞漂移）。
> 量纲性事实（生命值 1.0→20 量纲、硬克制废除等）属结构决定，照实记录。

### 设计宪法（一切改动的上位规则）

V2.0 的每一处改动都受 `docs/design/v2exp/v2.0_exp_design_draft_v0.2.md` §0「设计宪法」约束，核心五条：

1. **认知负担三层模型**：L1 一眼层（状态全明牌、零计算）／ L2 口算层（常规战斗判断 ≤2 次算术）／
   L3 委托层（机器代算，但每个"惊讶"都能用一句话+算式日志解释）。
2. **移植七律**：乘法变加法（常驻 ×2/−50% 转平直加减）；真伤分级（仅留给叙事级效果，其余降格为
   "穿甲=防御按 50% 计"）；外甲=装备（有耐久、会碎、可修）／内甲=身体改造（永久属性、不碎）；
   **零产出禁令**——承诺出去的主动行动永不结算为零（被闪→擦伤，被抗→残控，钩空→闪避失效）。
3. **稀缺三级制**：时间稀缺（限量营业）／份数稀缺（全图 ×N 抢完即止、死亡掉落回流）／
   神器稀缺（全图 ×1，唯一性即身份）。普及型效果必须数值化，独特机制只配神器席位。
4. **两货币纪律**：全局可计数货币最多两种——**信用点**（经济通货）与**喝彩**（荣誉/元货币）。
   旧"凭证"退役，"通行证"降级为普通钥匙物品。
5. **控制设计准则**：位置操纵（推/拉/逐，反制丰富）优先于行动剥夺（眩晕/震荡，体验最差、必须稀缺）。

### 玩法范式转移

- **从"活到最后"到"综合评分"**：终分 =（剧情分 + 喝彩分 + 战果分）× 存活系数 + 往世分。
  **活到最后只是一个加分项**，不再是唯一目标——主动战斗、达成天赋叙事、赢得观众喝彩都直接计分。
- **死亡不再出局**：阵亡者进入**往世层**化作星辰，仍能用星光对牌局施加有限影响，并继续积累往世分。
- **世界会主动收束**：白昼世界时钟（黎明→白昼→黄昏→终焉）随轮次推进不断加压，
  系统性消解了旧版"无毒圈、可无限龟缩"导致的节奏拖沓。

### 关于神代天赋7的设计转译

团队选择将列车大战和色彩反转两个剧情片段加入神代天赋7的转译基础，原因：

**第一层**：团队中无人之前玩过 BA。大叔厨在补剧情时，其他成员通过总结视频和百科了解剧情梗概。我们选择无视社区的节奏——团队经历过崩三兔女郎、原神4.8散兵风波、星铁3.0阿格莱雅审判等事件，知道社区风波的夸张程度。

**第二层**：经分析，V1.3 剧情的问题主要集中在商战段落，而星野的暴走和反转化本身没有设计问题：
- 星野是二周目阿拜多斯最痛苦的人之一，早期剧情是经典的一失足成千古恨
- 梦死后，星野的转变是在后辈面前扮演一个像梦一样温柔可靠的前辈
- 但这终究是皮套——梦屡屡被骗的经历让她依然保持极度务实，不依赖任何人
- V1.3 中星野选择单走符合人设
- V1.2 结束后星野对 sensei 有信任但无依赖——始终没有敞开心扉

二游剧情可能存在编排问题，但没有这些剧情，星野就不是我们认识的星野了。

### 关于神代天赋的意义

神代天赋是角色导向的设计：团队中有人提名角色 → 提取角色特征 → 翻译进游戏机制 → 其他人辅助完成翻译和严谨化 → 设计文案 → 写规则说明 → 丢给 code agent → 大量测试纠错 → 更新 AI 使用逻辑 → 天梯平衡 → 上传。

我们想让玩家在游戏中真正成为自己喜欢的角色的样子。
