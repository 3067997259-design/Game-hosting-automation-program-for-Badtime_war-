# 0. 设计宪法（一切改动的上位规则）

## 0.1 认知负担三层模型

| 层 | 定义 | 纪律 |
|---|------|------|
| **L1 一眼层** | 状态感知：血条/耐久条/buff 图标/位置 | 做满做足，全部明牌显示，零计算 |
| **L2 口算层** | 行动规划：攻防估算、TTK 推演 | **两步心算法则**：任何常规战斗判断 ≤2 次算术运算 |
| **L3 委托层** | 精确结算：流水线、锚定求解、安定値 | 机器代算，但**每个惊讶必须能用一句话解释**（算式日志） |

## 0.2 复杂度自背原则

天赋可以给**持有者**增加 L2/L3 负担（那是他买的专家体验），但它暴露给**对手**的一切必须 L1 化
（一个图标、一个数字、一行状态）。每个天赋标注认知评级 🧠×1~3，写进选择界面。

## 0.3 移植六律

1. **乘法变加法**：常驻 ×2/-50% 转平直加减；乘法只允许出现在单次主动技上。
2. **真伤分级制**：真伤仅保留给叙事级效果（诗的「。」、Terror 主炮、元亨利贞穿透判定）。
   其余旧真伤降格为"穿甲"（防御按 50% 计）或高额属性伤害。
3. **0.5 额外生命 ≈ 新体系 2~3 点**；小盾/光环 → 可再生护体值池；自动回血 → 每轮再生率。
4. **外甲=装备**（防御力+耐久，会碎可修），**内甲=身体改造**（永久属性，不会碎）。
   "外层不破不能打内层"规则自动消失。
5. **审计补偿机制**：旧约束（行动饥荒/量化/眩晕回血）催生的补丁（善见天、各类保底），
   新体系下逐个判断退役或转职。
6. **换算不是 ×10**：旧 1.0 HP ≈ 新 20，但 TTK 故意拉长（裸杀 1 刀 → 3~5 刀），因为伤口持久化。

## 0.4 两条经验法则

- **基于关系的绝对效果**（爱愿）可保留绝对性；**基于属性的绝对效果**（克制全免）必须转数值。
- **AI 钩子代码行数 = 认知负担计量表**：新机制立项时预估钩子规模，超 300 行触发认知预算审查。

# 1. 行动系统：同时承诺制

> 替换 D4 赢家通吃。设计动机：6 人局玩家 ~63% 轮次无事可做（实测 2/4/6 人局
> 平均轮长 27/63/87）；同时承诺同时解决等待问题和隐藏信息缺失问题。

## 1.1 新轮次结构

```
R0  轮次开始结算（钟相变化、DoT、天赋钩子——沿用现有时序框架）
R1  承诺阶段：所有存活玩家同时、秘密提交本轮行动
R2  先攻判定：D6 + 先攻修正，决定结算顺序（替代旧 D4+D6 双骰）
R3  结算阶段：按先攻顺序逐个公开并执行承诺
R4  轮末结算（沿用）
```

## 1.2 冲突结算规则（严格先攻制）

- 按先攻顺序逐个执行。**攻击目标已移走 → 挥空**（消耗本轮行动，蓄力不消耗）。
- 抢同一限量条目 → 先攻者得，后者行动落空（可设兜底：自动转为该地点免费行动）`[待风洞]`。
- `[待拍板]` 备选模型：**分相位结算**（所有移动→所有交互→所有攻击），更可预测，
  但"移动必躲攻击"会让闪避过强。v0.1 默认严格先攻制。

## 1.3 旧机制处置

| 旧机制 | 处置 |
|---|------|
| D4 争夺行动权 | 退役。D4 骰子退役，先攻统一用 D6+修正 |
| 未行动保底加成 | 退役（无等待即无需保底） |
| 额外行动回合 | 转为「追加承诺」：本轮结算完毕后立即公开执行一个行动 |
| forfeit | 保留为「观望」承诺（合法但无补偿） |
| 所有天赋 D4/D6 加成 | 统一折算为先攻修正 |
| 起床 | 保留：首轮承诺必须为起床 |

# 2. 数值模型

## 2.1 核心公式

```
HP = 20（全整数体系，量化规则废除）
单次伤害 = max(裸伤 − 对应属性防御力总和, ⌈裸伤 × 25%⌉)    ← 保底规则
外甲每吸收 1 点伤害消耗 1 点耐久；耐久归零即碎（可修复）
```

口诀（L2 教学）："怎么打都至少掉四分之一。"

## 2.2 武器表 `[待风洞]`

| 武器 | 裸伤 | 属性 | 备注 |
|---|---|---|---|
| 拳击 | 2 | 普 | |
| 小刀 / 警棍 | 4 | 普 | |
| 磨刀小刀 | 7 | 普 | |
| 魔法弹幕 | 5 | 魔 | |
| 远程魔法弹幕 | 5 | 魔 | 需锁定 |
| 地震 | AOE 3 | 魔 | |
| 地动山摇 | AOE 3 | 魔 | +震荡（至多 2 单体目标） |
| 电磁步枪 | AOE 4 | 科 | +震荡，需蓄力 |
| 高斯步枪 | 6 / 蓄力 10 | 科 | |
| 导弹 | 8 | 科 | 远程，三步流程不变 |

TTK 预算（验收标准）：裸装 3~5 刀；半装 5~7；满配龟壳 8~10 且每刀有可见进展。

## 2.3 外甲表（装备：防御+耐久）`[待风洞]`

| 外甲 | 主防 | 副防 | 耐久 | 修复 |
|---|---|---|---|---|
| 盾牌 | 普 -2 | — | 8 | 不可修，重新拿取 |
| 陶瓷护甲 | 普 -3 | 科 -1 | 12 | 不可修；保留免疫电流震荡 tag |
| 魔法护盾 | 魔 -3 | 普 -1 | 12 | 重吟唱 1 行动 +6 耐久 |
| AT 力场 | 科 -3 | 魔 -1 | 12 | 重展开 1 行动 +6 耐久 |

- 外甲最多 3 件，同名限 1。修复改为**增量制**（+6/次）——废除旧的"1 行动满血复活"修复平价。
- 三属性循环保留为**定价表**（主防/副防分布），硬克制（攻击无效）废除。

## 2.4 内甲表（手术：永久身体改造）

| 手术 | 效果 | 限制 |
|---|---|---|
| 额外心脏 | 生命上限 +4 | 终身 1 次；手术清空凭证（保留） |
| 晶化皮肤 | 普 -1 / 科 -1（永久，不可破坏） | 同上 |
| 不老泉 | 每轮再生 1 HP（不超上限） | 同上 |

## 2.5 状态重做

- **眩晕苏醒不再回血**（废除 `hp=min(1.0,max_hp)` 刷新）。眩晕改为来源性状态
  （地动山摇/电磁/天赋），效果：下一轮只能承诺「苏醒」。
- **重伤**（HP ≤5）：先攻 -2，受 AOE 伤害 +1。`[待风洞]`
- **治疗**：医院新增条目「治疗」：1 行动 + 1 凭证 → +6 HP。`[待风洞]`
- **病毒重做**：废除二元即死。释放后第 3 个轮末起，未免疫者每轮末 -3 HP（面具/封闭免疫，
  可靠治疗对冲）。从处决器变成压力钟。`[待风洞]`

## 2.6 警察换算

- 警察单位 HP 10，警棍 4，盾牌（普 -2，耐久 8）。
- 警察保护：过滤裸伤 ≤6 的单体攻击。`[待风洞]`
- 威信/状态机/队长系统不变。**集结改为自动**（举报后下轮自动完成），省出的回合还给举报者。

# 3. 世界时钟：白昼（三幕剧压力曲线）

> 主题来源：第零章「黎明一旦升起便要坠毁于白昼」。
> 阶段长度按人数缩放：基准段长 = 6 + 初始人数。`[待风洞]`

| 阶段 | 轮次（6人局示例） | 规则变化 |
|---|---|---|
| **黎明** | 1~12 | 基础规则。发育与结盟 |
| **白昼** | 13~24 | 地点限量营业（每地点每条目每轮 1 次，先攻争夺）；每人首次攻击记「嫌疑」不记罪；**击杀掉落启用**（死者装备掉落原地，1 行动拾取） |
| **黄昏** | 25~36 | 全体造成伤害 +1；治疗费用 ×2；商店免费；眩晕来源效果 +1 轮 |
| **终焉** | 37+ | 每轮末全体 -2 真伤（叙事级豁免无效）；喝彩事件分值 ×2 |

`[待拍板]` 黄昏是否让警察系统停摆（秩序崩塌）——对好市民/警长玩法冲击大，需单独风洞。

# 4. 胜利系统：综合评分制

> 活到最后只是加分项。终分公开揭晓于终局（中盘只见组件不见总分）。

## 4.1 总公式

```
终分 = (剧情分 + 喝彩净值 + 战果分) × 存活系数 + 往世分
存活系数：终局存活 ×1.5；中途死亡 ×max(0.5, 存活轮数/总轮数)
往世分：死后以星身份挣得，固定 ×0.5 折算
```

## 4.2 喝彩（两用资源：可消耗 / 余额计入终分）

获取事件（每类每局限 1 次，仅收录可机检事件）`[待风洞]`：

| 事件 | 分值 |
|---|---|
| 首杀 | +2 |
| 重伤（HP≤5）状态下完成反杀 | +3 |
| 打破满配（3 外甲）目标的最后一件外甲 | +2 |
| 用仅剩最后一次的限定天赋完成击杀 | +2 |
| 锚定监控期内反杀 G5 | +3 |
| 在终焉阶段完成击杀 | +2 |

消耗用途：重掷先攻骰（1 点）/ 单次伤害 +2（1 点）/ 偷看一名玩家本轮承诺（2 点）/
抵消一次犯罪记录（2 点）。`[待风洞]`

反合谋三闸：每类一次；对抗性事件要求目标"非自愿"（本局对你造成过伤害）；
合谋 bot 风洞实测，刷得动就改规则。

## 4.3 完结条（剧情分大额块，试点 3 个）

| 天赋 | 完结条 | 剧情分 |
|---|---|---|
| G2 | 完成一次完整谢幕 | +15 |
| G4 | 救世主状态毕业（状态结束时存活，此后再存活 5 轮） | +12 |
| G5 | 完成 2 次成功锚定 | +15 |

达成率验收目标：10~20%。试点验证后逐步为全部神代补完结条。

## 4.4 可见性规则

喝彩余额公开；完结条进度半公开（"G5 已完成 1/2 次锚定"）；精确总分终局揭晓。

# 5. 往世层（死者成为星）

- 出局玩家坠入往世层，每轮获 1 点星光（上限 3）。
- 星光行动（每轮 1 次，对同一玩家每 2 轮限 1 次）：
  - **拨弄命运**：某玩家本轮先攻 ±1（1 点）
  - **预兆**：在某地点投下预兆，下轮第一个交互者 ±2 HP（2 点）`[待风洞]`
  - **加冕**：某玩家下一个喝彩事件分值 ×2（2 点）
- 星光行动产生往世分（×0.5 折算计入本人终分）。
- 星不能直接造成伤害或击杀。被锚定击杀者**不能成为星**（继承现有规则，恐怖加倍）。

# 6. 经济与地点

- **凭证**保留"资格开关 + 手术清空"结构；新增消耗口：治疗 1 凭证。
  `[待拍板]` 是否进一步货币化（商店购买也消耗）——v0.1 暂不动。

- **击杀掉落**随白昼阶段启用。

## 7.5 G5 涟漪（咬合型，数值基本不动）

四个咬合点：

1. **破坏性行动重定义**（硬克制消失）：「获得使路径上任一武器单次伤害落到保底线的防御配置」。
   配合加权预算制：移动 0.5 / 持久反制配置 1.5 / 控制 G5 1.5 / 隐身（无探测）1.0；
   变数 = 2.0 + 0.5×命定 `[待风洞]`。可行性求解器（≤5 理想回合）**不动**。
2. **善见天退役转职**（行动饥荒已愈）：新·善见天 = 锚定期间每轮结算前**提前看到目标的秘密承诺**。
   对价：目标每轮可虚报一次承诺（提交两个，结算时二选一）。
3. **追忆新水源**：每轮基础 +1；所在地点每发生一次喝彩级事件额外 +1（打捞名场面的记忆）。
4. **诗的换算**：爱与记忆之诗 n 段 ×5 点（科/普/魔依次，第 4 段起为真伤）；
   诗的「。」原样保留（真伤天花板）；爱愿保留绝对性（关系型豁免条款）。

## 11.5 献诗十四首

九成为事件型（次数 +1、立刻行动、重置触发），零修改。数值型三首：
追光之诗易伤 `0.5→2`（每次追加 `+0.5→+1`）；群星之诗弹射 `2×0.5 → 2×2`；
负世之诗火种数不变（事件型）。

## 11.6 BasicAI 战力公式重导出

旧常数（`hp*10 + weapons*15 + ...`）全部失效。新模型评估更简单且连续：

```
有效HP ≈ HP + Σ耐久 × 平均吸收率 + 防御力 × 预期受击数
威胁度 ≈ max(裸伤 − 我的对应防御, 保底) × 攻击可达性
```

红利：硬克制消失 = 评分函数的 `-50 被克制` 悬崖消失，目标/武器选择变为光滑函数。
承诺预测 v0 用"假设对手重复上轮 / 贪心"启发式；StageAI 的 `assess()` 框架直接复用
（它已经会玩全员行动制）。

## 11.7 RL 管线

1. 同时承诺制 → 环境从轮流决策变为并行决策（PettingZoo parallel 形态，更标准）；
   平均轮长 25 → episode 缩短约 70%，训练提速。
2. 伤害量纲 ×5：reward.py 事件常数整体重标定；HP/伤害观测特征 ÷20 归一化。
3. BC 数据全部作废，M6 后重采。
4. **结论：RL 冻结至 M6，解冻时一次性重设计，不做增量缝补。**
