## 第零章

人子的乐园终将跌入愁苦人世，黎明一旦升起便要坠毁于白昼，凡是金的，怎可能光华长留？
众星属于所有人，便从不属于任何人。若你爱所有人，便不爱所有人。
故⬛⬛ 将飞上高空，变作天上的太阳。万众在⬛⬛ 的光芒中热烈生长，而新世界的一切歧途将无所遁形。

## 一、游戏概述

《起床战争》是一款“带主持人（DM）的多人乱斗生存桌游”，或者把建议场合算上，“朋友局桌面剧场的乱斗生存，为了活下来尽情演出”——用桌游式的回合/行动权框架去承载TRPG式的裁定、叙事大招与舞台装置技能，让玩家在“发育—个人对抗—势力对抗—尽情演出”的循环里，靠策略、社交或天赋系统赋予你的能力把局面推向高潮。
本游戏依照实际游玩人数（只考虑人类，AI玩家的先天倾向不会受人数影响改变）和玩家情况，对目前所有扩展的启用情况做出如下建议：
1）2人起玩，一个人打纯人机局也是可以的。但纯人类的局中，2人局建议不允许有人上任警察或当警长，可以引入天赋
2）3人及以上，建议开始允许加入警察和上任警长。3人以上时，强烈建议使用电子裁决系统
如果这一桌有初次参与的玩家，强烈建议不使用神代天赋5
无论人数，引入天赋则强烈建议使用电子裁决系统。
请注意，这个游戏的核心机制一部分是靠天赋撑起来的，所以为了更好的游玩体验，强烈建议在对游戏机制有初步了解后就引入天赋
玩家人数：2人以上，3–6人最佳。
游戏目标：成为最后存活的玩家（或最后存活的小队，但双排模式暂时没有做）。
核心机制：
每个全局轮次通过 D4 争夺行动权；轮次内可能有多个胜者依次行动。
玩家通过移动、获取物品、学习法术、手术强化、攻击对手等方式发展。
引入「警察系统」提供法律与秩序、可争取的中立势力。
天赋系统提供强力差异化能力（强烈建议：要么全员选，要么全员不选）。

## 二、组件与信息公开


### 2.1 地图与地点

本游戏地点为「菜单式地点」，默认包括：
家（每位玩家独有）/商店/魔法所/医院/军事基地/警察局，以及扩展可能新增地点。
连通规则：所有地点视为直接连通；一次「移动」可从当前地点到任意另一地点。

### 2.2 信息公开原则

以下信息默认公开透明：
·玩家当前位置、状态、装备与护甲层、是否被锁定/是否面对面等标记
·注意：隐身不影响其他人知道隐身者的位置等信息，只影响能否进行锁定和找到。
·天赋是否已发动、发动声明、剩余次数（若可公开记录）
·其他没有特殊声明的内容
你们可以尽情交谈、合纵连横、口头立约（嘴上约定不等于规则强制），甚至是打嘴炮或者是虚张声势，py交易，或者赌上一瓶冰红茶，看谁能从幻想乡里走出来，或者能否摆脱锚定

## 三、游戏准备


### 3.1 初始状态

每位玩家初始拥有（未特殊声明时）：
生命值（HP）：1
攻击力：0.5（拳击，普通属性伤害）
护甲：无
物品：无
购买凭证：无

### 3.2 家中资源

每位玩家家中无限量存放：
·小刀（近战武器，普通伤害1）
·盾牌（特殊外层护盾，普通护盾1，优先于所有其他护盾消耗）
·购买凭证（山姆会员）：可无限次获取（见第七章）
「盾牌不像其他护盾一样有额外加成，但至少能给一个社恐走出家门的勇气。」

### 3.3 游戏开始

所有玩家处于「睡眠」状态。睡眠玩家不存在于地图上，无法被攻击、无法被锁定/找到，也不占用任何地点。这主要是为了避免虐泉。
