「祂沿着巨树，攀登到了存在的尽头。而存在者恒存在，不存在者不存在。」
「祂聆听到了婴儿的啼哭，那是人类发出的第一声，也是最后一声呐喊」
「祂因而放声大笑，那笑声逆转了宇宙的终末。」
「祂说，要有笑声，于是就有了笑声」
（满足条件后自动触发，最多发动1次）
笑点：特殊道具，无其他作用。在每个全局轮次中，如果你没有获得行动回合，或者在自己的行动回合中选择forfeit，就获得1个「笑点」。获得6个「笑点」后，此能力自动触发。
能力发动后，你在下一个轮次开始时D4点数必为4，D6点数必为6，且行动回合转化为「插入式笑话」
「插入式笑话」：特殊行动回合，在这个行动中，行动者可以进行任意一个本游戏中目前在场的玩家可执行的行动。在判定行动能否执行时，会采取被借用的玩家的状态进行验证。行动造成的后果：获得的物品、击杀数和击杀奖励（若存在）会归于该天赋持有者，而犯罪记录、威信损失、凭证损失归于被借用的玩家（这个的灵感一部分来自欢愉技）
E.g.玩家A（已进入「插入式笑话」，在自己家中，没有持有的物品），玩家B（警长），玩家C（唯一一个手里有凭证且正在商店的玩家，没有犯罪记录）
此时玩家A可以执行：
拿自己家里的小刀等物品
在商店购买陶瓷护甲等物品（来自C），物品归自己
指挥警察攻击C（来自B），威信损失归于B
