人子的乐园终将跌入愁苦人世，黎明一旦升起便要坠毁于白昼，凡是金的，怎可能光华长留？
众星属于所有人，便从不属于任何人。若你爱所有人，便不爱所有人。

## 间章I
之前让几个chatbot帮我读游玩手册的时候，AI大人几乎没有例外地指出：很多元叙事内容被夹杂在了严肃的规则文本里，这虽然是AfterRain的风格，但是非常不利于其他人阅读。就当是为了你不知道有没有的读者，对手册使用信源统一和格式整理吧！（此处自行脑补一个炎拳脸）
所以我想起了间章。正式章节用大型数字编序号，间章用罗马数字编号并随意插在章节之间，这是我写自己的第一本小说的时候在用的格式。可惜，一个从决定动笔的时候就言之无物的作品，最后也只能是写四百字撕掉四百字，最终忍无可忍把撕烂了的本子丢进垃圾桶。唉，那个没有AI的年代，要是写得烂就一点办法都没有。直到我最后彻底放弃整个工作时，GPT也才出到3.5吧，大概一直到4o它才正式开始擅长（情感）写作，只可惜后来又不侧重训练这方面了。
骗你的，现在只靠AI也写不出太多真正动人的东西来，如果没有真正属于自己的体会的话。不过我希望自己一辈子也写不出来这种东西：
“母亲走的时候才五十出头，是累病的。如今她的坟就在村边，一个不起眼的小土包。每次回村，我总要去那儿站站，跟她说说话。我在城里干了大半辈子苦力，扛水泥、扎钢筋、爬脚手架，手上肩上全是老茧，累是真累。可想想母亲当年端那口大铁锅的劲儿，想想她冻得发抖还咬牙撑到天亮的样子，我这力气就又上来了。……坟头上的草青了又黄，黄了又青，就像我的念想一样，一年年总也断不了。我已经当了爸爸，也已经当了爷爷，但我已经三十多年没叫过妈妈了。我想着，等哪天我扛不动水泥了，就回村里挨着那堆土躺下，没准那时候我再叫妈妈，她就能听见了。”
话题扯远了。不过就我读的这点孱弱的文本量，我能在1.96的develop_diary里诌出那个19世纪就被浪漫文学写烂了的开头已经是不容易了。还不如让我整点之乎者也出来，起码小时候真的背过四书。
为什么提到这些呢？因为我必须要从与设计草案不同的角度想想为什么要做这次大型改动。从我第一次在cherrystudio上伪装成一个捡到这份手册的路人问opus4.6“你觉得这份手册作为一个极度罕见的桌游类型写的怎么样？”（我怕它刻意讨好我，听说假扮自己的仇人去问效果会更好）到现在，大概很快就五个月了。直到整个V2.0能稳定落地，或许需要从那天开始需要半年。一般的商业游戏如果半年封测，这个时候大概该公测了。有必要多说点什么。
具体改动太多，建议去看changelog。如果你是从旧版一路玩过来的，那你大概会发现：V2.0-exp 看起来已经不像最开始那个体育课自由活动时间里走出来的游戏了，甚至和星野刚登场时那个已经有一半完全无法靠着纸笔和骰子运行的游戏也大不相同。它的数值模型已经大幅改变（新模参考了Minecraft，这倒是真成了“起床战争”，乐），有信用点，有世界时钟，有综合评分，有死后往世层，甚至还有一堆看起来不像桌游规则、比较像作者瑰夏喝多了或者一口气买了两家的subscribe Plan，嫌token不够烧突然上头了想加的东西。
比如我还想加个神代天赋什么的。然后就有足够数量的神代，可以划分成组然后作为扩展独立引入。不过这是后话。
是的。我确实把它改复杂了。虽然这个游戏没怎么尊重过至繁归于至简的原则，但毕竟原来底层还是干净凝练的。然而，调整BasicAI和RL的经历让我发现了很多老的设计中的实际问题：行动权饥荒本来以为是“不确定性”的核心，然而事实上“无所事事”带来的坐牢感反而更强，这个游戏还连个前端或者游戏桌布那种堪称前端的东西都没有（尤其是推荐的6人，如果没有朋友一边玩一边聊天的话。在体育课上的时候，我们一般是三人乱斗或者二对二，那时候连保底都没有，问题也没这么大），护甲克制直接收益归零（说实在的，这是RL的灾难，奖励信号太尖锐了），警察保护要不然是叹息之墙，要不然人家随便针对就是死（V1.94 orchestra架构引入后，通过逐个枚举植入了一整套反制警察的逻辑。在这之前political胜率最高，生效后暴跌。这个开发思路是很脆弱和不可持续的），残局则经常变成几个人围着地图站梅花桩或者无效攻击——这游戏没毒圈啊，站梅花桩拼毒有个P用。
当然，通过手动设计逻辑，BasicAI仍然可以直接产出精彩的对局（比如我亲眼见证星野扎针丢闪冲刺架盾，然后下一轮10cost连开七枪硬生生打死满甲队长）
可它们全都是预制好的，星野能打出这样的操作是因为我编码了这样的逻辑和预制的战术宏。如果某一环错了，比如没丢出闪/烟，那么后面七枪的伤害将会被完全过滤掉。我在考虑，我抛弃了规范性、复杂度和可解释/理解性三条底层逻辑，到底有没有创造真正的博弈深度？或者说，到底有没有创造戏剧张力？一个三阶魔方，历史上或许没有两个人的随机打乱是一样的，但对于一个只会层先法的萌新，每次去玩魔方需要做的都是那几个公式而已。如果每次星野撞到队长都是上药装子弹然后10cost开五枪是一眼可见的最优解，那这个游戏真的有意思吗？
以及最终极的一个问题：
我给玩家设计的胜利目的，到底和他们想做的是否相同？对这个游戏来说，“活到最后”究竟是不是最合适的胜利方法？
AfterRain回顾了他快二十年的人生，发现自己做了半年的游戏，然而一分钟游戏设计课也没上过，连“设计者希望玩家的游玩目标和他们自己的目标应该尽量重合”这句话都是后来才听说的。实在不行大二报个选修去吧。
所以 V2.0 的目标很简单，但很简单不太可能：让底层世界更像一个能承载演出的舞台，而不是每次都靠天赋把桌子掀了重摆。
我第一次用Devin Deepwiki给整个项目做百科时，它对神代天赋给出了一个我很喜欢的定义：“管理复杂资源，且可以剧烈地改变游戏现实的类boss不对称技能或复杂子游戏系统”。
但剧烈地改变游戏现实，需要建立在有“游戏现实”这个概念的基础上，不然就退化为无意义的战力PK。
我希望普通攻击也有意义，希望死亡不是干坐，希望活到最后不是唯一答案，希望那些神代天赋可以更好地服务于终极意义——
但不是全都靠单开一片空间，然后把思考压力转嫁给全桌来任性。
当然，这好像有点太正经了，不像是AfterRain写得出来的东西
但如果你愿意为了一个角色的弧光多读两页规则，多忍受一点机制怪，耐心等待自己的高光时刻，
那欢迎来到 V2.0。
白昼或许已经升起。但还请不要太相信它。

## 一、游戏概述
起闯战争是一局 2–6 人的**回合制大逃杀**。你扮演一名被卷入"起闯战争"的参战者，在一张六地点
的地图上移动、发育、结盟、厮杀，并争夺最高的**综合评分**。
它的外壳仍然是多人乱斗：出门，拿东西，打人，报警，被警察打，继续打人。很朴素，很健康，但 V2.0 以后，这个游戏不再只问“谁最后还站着”。它会问你有没有打出足够精彩的场面，有没有完成属于天赋的结局，有没有在死后继续干涉命运，有没有让这一局在结束以后还值得被桌边的人复述两句。
这可能就是当年那些在操场边上的凉棚底下抢凳子坐的小孩最喜欢的东西？
### 1.1 我活到最后≠我能赢，不等式秒了
V2.0 的胜负由**综合评分**裁定——
```
终分 = （剧情分 + 喝彩净值 + 战果分） × 存活系数 + 往世分
```
- **活到最后只是加分项**（计入"存活系数"），不再是唯一目标。一味龟缩苟活，终分会很难看。
- 评分四源：**剧情分**（达成"完结条"等叙事里程碑）、**喝彩**（打出名场面，见第十二章）、
  **战果分**（击杀与有效伤害）、**往世分**（死后在往世层的作为）。
- **中盘只见组件、不见总分**；精确终分在**终局统一揭晓**。
- **双轨获胜**：终分第一与"最后存活者"并列记录——你可以是赢家，也可以是活到最后的那个，二者未必是同一人。
### 1.2 死亡不等于出局
被击杀者**坠入往世层、化作群星中的一抹微光**：不能再直接造成伤害，但仍能用"星光"拨动生者的命运、
并继续为自己积累**往世分**（见第十二章）。
### 1.3 残局与终结
为避免残局陷入"谁都不动"的僵局，游戏设有**残局终结机制**（白昼世界时钟的"终焉"阶段等，见第十一章）
持续施压，推动对局走向结束。

## 二、组件与信息公开
### 2.1 地图与地点
地图由六个地点构成：**家（home）/ 商店 / 魔法所 / 医院 / 军事基地 / 警察局**。
任意地点之间移动均为一次行动（无邻接限制）。各地点的供应见第六章。
### 2.2 信息公开原则
起闯战争是**高信息公开**的博弈：玩家的位置、装备、生命值（HP）、状态标记等对所有人可见（隐身/探测另有规则，见第九章）。
唯一的私密信息是少数"匿名"来源（如匿名冷箭的归因，见第九章）。**公开是博弈的前提**——
你能看见别人在攒什么、走向哪里，别人也能看见你。
### 2.3 玩家状态条（L1 清单）
每名玩家随时可查看以下状态：
- **生命值**：上限 ⟦bal:hp20.player_max_hp⟧（整数血量模型，见第八章）。
- **外甲耐久条**：每件外甲的剩余耐久（见第八章）。
- **钱包**：信用点余额（经济，见第七章）。
- **箭矢**：n / ⟦bal:bow.max_arrows⟧（弓的弹药）+ 升级模块双槽（见第六章）。
- **状态图标**：眩晕/震荡/石化、灼烧层数、隐身/探测、各天赋专属标记等。

## 三、游戏准备
### 3.1 初始状态
每名玩家以 ⟦bal:hp20.player_max_hp⟧ 点生命值开局，位于自己的**家**，初始处于"未起床"状态。
### 3.2 起始包（家中资源）
每人开局获得：
- **弓** + ⟦bal:bow.initial_arrows⟧ 支箭（人手一份的跨地点武器，见第六章）；
- 在家可拾取**小刀 / 盾牌**的资格。
> 注：家**不再产出任何经济资源**（信用点只能在外面挣，见第七章。为什么这么设计呢？因为AfterRain设计这里的时候突然发现他在心智不成熟的时候就骨质疏松了，幸好他的手头一直很紧）。
### 3.3 游戏开始
游戏从第一个全局轮次开始。每名玩家的**首个行动回合必须用于"起床"**；起床后方可进行其它行动。

## 四、时序与流程
### 4.1 全局轮次（Round）的标准结构
游戏以"全局轮次"推进，每轮依次结算：
1. **轮次开始结算**：持续效果计时、天赋的"轮次开始"效果、病毒倒计时（若挂在轮首）、
   白昼世界时钟阶段推进（见第十一章）。
2. **先攻判定与行动权分配**（见 4.3）。
3. **警察状态机推进**（见第十章）。
4. **行动回合**：取得行动权者按先攻顺序依次行动（见 4.2）。
5. **轮次结束结算**：警察执法、病毒与死亡判定、持续效果计时、检查胜负与残局终结，进入下一轮。
### 4.2 行动回合（Action Turn）的标准结构
每个行动回合分三步：
1. **回合开始**：触发"回合开始"类天赋效果。
2. **指令输入**：执行一个行动类型（见第五章）。
3. **回合结束**：触发"回合结束"类效果。
某些效果会插入**额外行动回合**（如部分天赋）；额外回合在当前回合之后按规则插入。
### 4.3 K 常量行动制（取代旧"行动权争夺"）
V2.0 废除了旧版"D4 掷骰争夺行动权"与"未行动保底加成"，改为更清爽的 **K 常量行动制**：
- 每个全局轮次，**固定有 K 名玩家获得行动权**：
  ```
  K = max(1, 当前存活人数 − ⟦bal:action_system.k_sitout_count⟧)
  ```
  默认 `k_sitout_count = ⟦bal:action_system.k_sitout_count⟧`，即**每轮只有先攻垫底的 1 人轮空**，其余全部行动。
- **先攻**由 d⟦bal:action_system.initiative_die⟧ + 各类修正决定；行动权按先攻从高到低分配，行动也按此顺序进行。
- **轮空在人数越少时越频繁**：这样可以在决战时为了戏剧性保留足够的不确定，同时加速前期的发育阶段。世界时钟的存在确保了
- **放弃行动（forfeit）**仍是合法选择（主动跳过，无补偿）。
### 4.4 交战与借机攻击
- **交战状态**：两名玩家处于同一地点，且本轮或上一轮之间彼此发生过伤害，即视为"交战中"。
- **借机攻击**：交战中若一方**主动移动**离开该地点，每名与其同地点的交战对手获得 **1 次免费攻击结算**
  （走正常命中/闪避，见第九章；移动者本次不享受移动带来的闪避加成）。每名追击者每轮限 1 次。
- **豁免**：**被动位移**（被击退、被钩索拉拽等）不触发借机攻击。

## 五、行动类型
每个行动回合，玩家执行**一个**行动。可选类型如下。
### 5.1 起床
仅"未起床"者可用，也是其首个行动回合的**强制选择**。起床后该状态永久解除。
### 5.2 移动
移动到任意其它地点（无邻接限制，一次一地）。注意：处于交战中主动移动会触发对手的**借机攻击**（见 4.4）；
被动位移（被击退/被拉拽）不算主动移动。
### 5.3 交互
在当前地点办理该地点提供的事务，统称"交互"：获取物品 / 学习法术 / 进行手术 / 办理通行证 /
补给箭矢 / 修理护甲 / 治疗 / 打工等（各地点供应见第六章，费用见第七章）。部分项目需多个回合完成（进度保留）。
### 5.4 锁定（远程命中前置）
对一名玩家建立"锁定"标记。**锁定不再是远程攻击的硬前置**——弓未锁定也能射，只是命中更低
（见第九章）；锁定 = 拉满该目标的远程命中。
### 5.5 找到（近战前置）
与同地点的一名玩家建立"面对面（交战）"关系，是近战攻击的前置。
### 5.6 攻击
用一件武器攻击一名合法目标（近战需面对面，通用远程需可见）。命中与伤害结算见第八、九章。
### 5.7 射箭（弓）
弓的专属攻击动词，是**唯一的常规跨地点武器**：
- 跨地点合法；**不需锁定**（锁定只加命中）。
- 消耗 1 支箭（无限模块豁免）；射出的箭落在**目标所在地点**的箭堆，可由"找到"行动免费拾回（风险换弹药）。
- 伤害/属性/附带效果由已装的升级模块决定（见 6.2）。
> 例：你在商店、敌人在魔法所。你 `射箭` 跨地点命中（未锁定，吃命中惩罚）；这支箭落在魔法所，
> 谁先到谁能 `找到` 捡走。
### 5.8 钩索
军事基地的神器（全图唯一），科技属性，**双模式共享 ⟦bal:hook.cooldown_rounds⟧ 轮冷却**：
- **拉取**：将任意地点的一名玩家拽到你所在地点，附 ⟦bal:hook.damage⟧ 点科技伤害（走命中/闪避）。
  被闪避（擦钩）= 不位移，但目标本轮全部闪避加成失效。
- **位移**：把自己钩向任意地点。**不触发借机攻击**（机械把你拽走，对手刀砍空气）。
### 5.9 特殊操作
天赋/装备的专属操作，统称"特殊操作"，例如：**蓄力**（给需蓄力的武器充能）、重新展开魔法护盾/AT 力场、
磨刀、释放病毒（在医院）、取消架盾等。具体由你持有的物品/天赋决定。
### 5.10 放弃行动
主动跳过本回合，无补偿（合法选择）。

## 八、护甲与伤害（HP20 数值模型）
V2.0 改用**整数血量模型**：生命值上限 ⟦bal:hp20.player_max_hp⟧，所有伤害为整数。
护甲不再简单地提供护甲值和属性免疫，而是**提供有耐久的减法式防御**。
### 8.1 核心伤害公式
```
单次伤害 = max( 裸伤 − 目标对该攻击属性的防御总和 ,  ⌈裸伤 × 25%⌉ )
```
即"减法防御 + 保底线"：再厚的甲，**怎么打都至少掉 ⌈裸伤的四分之一⌉**（保底比例
⟦bal:hp20.min_damage_ratio⟧）。"几乎可确保不存在打不穿的龟壳"。
> 例：裸伤 4 的武器打"对该属性防御 3"的目标 → max(4−3, ⌈4×0.25⌉) = max(1, 1) = **1 伤害**；
> 打无防御目标 → max(4, 1) = **4 伤害**。
### 8.2 外甲：防御表 + 耐久
每件外甲有一张**防御表**（属性 → 防御值，主防高/副防低）和**耐久**：
- 攻击被外甲减伤时，**吸收量（= 裸伤 − 实伤）按 1:1 消耗耐久**；耐久归零即破碎（防御归零）。
- 多件外甲同时防御：吸收量**按各甲对该属性的防御贡献比例**分摊到各自耐久，余数给贡献最高者。
| 外甲 | 防御表 | 耐久 |
|---|---|---|
| 盾牌 | 普 −⟦bal:armor.盾牌.defense.普通⟧ | ⟦bal:armor.盾牌.durability⟧ |
| 陶瓷护甲 | 普 −⟦bal:armor.陶瓷护甲.defense.普通⟧ / 科 −⟦bal:armor.陶瓷护甲.defense.科技⟧ | ⟦bal:armor.陶瓷护甲.durability⟧ |
| 魔法护盾 | 魔 −⟦bal:armor.魔法护盾.defense.魔法⟧ / 普 −⟦bal:armor.魔法护盾.defense.普通⟧ | ⟦bal:armor.魔法护盾.durability⟧ |
| AT 力场 | 科 −⟦bal:armor.AT力场.defense.科技⟧ / 魔 −⟦bal:armor.AT力场.defense.魔法⟧ | ⟦bal:armor.AT力场.durability⟧ |
### 8.3 内甲：永久属性防御
内甲（通过医院**手术**获得，如晶化皮肤）是**永久的属性防御**，**没有耐久、不会破**，
直接计入"该属性防御总和"。
### 8.4 属性与防御表
V2.0 **取消了"属性被克制 = 整次攻击无效"的硬克制**。属性差异改由**防御表**表达：
同一件甲对不同攻击属性给出不同防御值（主防、副防、或未列即 0）。被"克制"的武器照样有效，只是面对更高防御、伤害更低。
> 例：陶瓷护甲对普通 −⟦bal:armor.陶瓷护甲.defense.普通⟧、对科技仅 −⟦bal:armor.陶瓷护甲.defense.科技⟧。
> 拿科技弓打它，比普通武器更划算——但都不会"无效"。
### 8.5 选层与溢出
- 外甲未全破时攻击**自动导向外层**，不能越过外甲直击内层。
- 最后一件内层防御被打穿后，**溢出伤害转移到生命值**。
### 8.6 穿甲与真伤
- **穿甲**（如穿甲箭模块）：目标防御**按系数折算**后再代入公式（防御打折，更易破）。
- **真伤**（部分天赋/诗）：无视属性防御直击（仍可被特定绝对效果阻挡）。

## 九、命中与战斗状态
### 9.1 命中 / 闪避 / 擦伤
V2.0 默认**确定命中**（命中率 ⟦bal:accuracy.base⟧）——初始情况下对砍必中，避免带来额外认知
**概率只在有人为投资时才出现**：
| 闪避来源 | 命中 |
|---|---|
| 目标本轮主动移动 | −⟦bal:accuracy.move_evasion⟧ |
| 目标隐身（攻击属性∈其隐身集且你无对应探测，见 9.4） | −⟦bal:accuracy.stealth_evasion⟧ |
| 跨地点远程**未锁定** | −⟦bal:accuracy.unlocked_ranged_penalty⟧ |
闪避总和封顶 ⟦bal:accuracy.evasion_cap⟧（命中下限不低于 100−封顶）。**被闪避 ≠ 落空 = 擦伤**：
按保底线结算少量伤害，且不触发武器附带效果（震荡/灼烧等）。
> 例：你射一个本轮移动过、且你未锁定的远程目标 → 命中 100 − ⟦bal:accuracy.move_evasion⟧
> − ⟦bal:accuracy.unlocked_ranged_penalty⟧。掷未过则擦伤保底。
### 9.2 生命、重伤、死亡
- 生命值降至 0 即死亡（坠入往世层，见第十二章）。
- **重伤**：生命值处于 0 与 ⟦bal:hp20.severe_injury_threshold⟧ 之间时，承受额外不利
  （受 AOE 伤害 +⟦bal:hp20.severe_injury_aoe_bonus⟧、先攻 ⟦bal:hp20.severe_injury_initiative_penalty⟧）。
### 9.3 眩晕 / 震荡 / 石化
- **眩晕**：失去本全局轮次内下个行动回合。
- **震荡**（电流武器）：眩晕的电流变体；陶瓷护甲（未破）免疫电流震荡。
- **石化**：下回合二选一结算；细节见相关天赋。
- 负面状态有**抗性两层制**（韧性脉冲等）削弱其堆叠，见设计草案。
### 9.4 隐身 · 探测 · 可见 · 锁定 · 面对面
- **可见 / 锁定 / 面对面**：远程命中加成靠锁定；近战靠面对面（见第五章）。
- **隐身与探测按属性分轨**（各分普通/魔法/科技三系）：
| 隐身（降命中） | 探测（反隐 + 火控） |
|---|---|
| 隐身衣（普通）/ 隐身术（魔法）/ 隐形涂层（科技） | 热成像仪（普通）/ 探测魔法（魔法）/ 雷达（科技） |
  当攻击属性落在目标的隐身集、且攻击者**无对应属性探测**时，该次攻击吃隐身闪避（9.1）。
- **匿名冷箭**：跨地点冷箭信息不足时不可被举报（归因规则，见第十章）。
### 9.5 灼烧（DoT）（以后可能不只这一类DoT伤害）
灼烧每层每轮直扣 ⟦bal:burn.damage_per_stack⟧ 点生命值，上限 ⟦bal:burn.max_stacks⟧ 层；
作为持续伤害**不受属性防御/抗性管辖**。火矢模块、燃烧类天赋共用此层。
### 9.6 病毒
在医院"释放病毒"后，潜伏 ⟦bal:virus.incubation_rounds⟧ 轮，此后每个轮末对未免疫者
扣 ⟦bal:virus.damage_per_round⟧ 点生命值（防毒面具免疫）。去除病毒的“全或无”设计效应，避免过于极端的收益。
## 十、警察系统
警察是一股**可夺取的中立秩序**：玩家可以举报违法者、上任队长、指挥警察单位。
### 10.1 警察保护（强制擦伤）
受警察保护者，**受警察保护的目标，被非 AOE 单体攻击时，攻击强制按保底伤害结算。**
### 10.2 警察单位与执法
警察单位：生命值 ⟦bal:police.hp⟧，警棍伤害 ⟦bal:police.baton_damage⟧。满足条件时在轮末执法攻击违法者。
### 10.3 状态机
警察按 `闲置 → 举报 → 集结 → 出动` 推进：有人举报违法者后进入举报，逐步集结、出动执法。
### 10.4 威信与队长
- **队长**由竞选产生，可指挥警察单位。
- **威信**：攻击无辜者 −1、队长犯罪 −1；威信归零则解除队长身份，原队长成为唯一违法者。
### 10.5 犯罪名单与匿名
违法行为（伤害无辜、进入他人之家、释放病毒等）会被记入犯罪名单。**匿名冷箭**信息不足时不可被举报（见 9.4）。
### 10.6 分级坠落（随白昼）
警察随世界时钟**分级坠落**（见第十一章）：**黄昏**取消警察保护、但保留执法与状态机；
**终焉**警察系统全部停摆。秩序随白昼渐崩。

## 十二、评分 · 喝彩 · 往世层
### 12.1 终分总公式
```
终分 = （剧情分 + 喝彩净值 + 战果分） × 存活系数 + 往世分
```
- **存活系数**：终局存活 ×⟦bal:scoring.survival_alive⟧；中途死亡 ×max(⟦bal:scoring.survival_floor⟧, 存活轮数 / 总轮数)。
- **战果分**：每击杀 +⟦bal:scoring.kill_score⟧；每累计 ⟦bal:scoring.damage_per_point⟧ 点有效伤害 +1（上限 +⟦bal:scoring.damage_cap⟧）。
- 中盘只见组件、不见总分；精确终分**终局揭晓**。
### 12.2 喝彩（两用资源）
打出"名场面"可获喝彩点（**每类每局限 1 次**，反合谋）：
| 事件 | 喝彩 |
|---|---|
| 首杀 | +⟦bal:applause.first_kill⟧ |
| 重伤（HP≤⟦bal:hp20.severe_injury_threshold⟧）状态下反杀 | +⟦bal:applause.severe_revenge⟧ |
| 打破满配（3 外甲）目标的最后一件外甲 | +⟦bal:applause.break_full_armor⟧ |
| 用最后一支箭完成击杀 | +⟦bal:applause.last_arrow_kill⟧ |

## 十三、天赋
共 14 个：原初 7（T1–T7）+ 神代 7（G1–G7）。
如果你是来查阅天赋的具体数值的，去看talents.md就够了。如果你想知道为什么一个天赋会长成这个鬼样子，那每个设计前的那几句废话是你不得不品的一环。我的思路和记忆一样混乱，但我会尽力写的清楚一些。
天赋没有被简单设计为可以用收益矩阵量化的东西（这也给我带来了不少麻烦）。原初天赋的目的是把回忆里那些比较爽的口胡打磨成好用的大红按钮；神代天赋则更麻烦，它们承担的是角色弧光、舞台、命运、告别，以及一些本来不应该由桌游规则承担的东西。
这当然会让规则变复杂，变得像仪式和演出。没办法，有些东西是“伤害+2”承受不住的。
所有数值经 bal 占位引 balance（语法见 render_docs.py）。
### 13.1 原初天赋
#### 1.「一刀缭断」（原初）
一句话概括：你将发动一次很不讲道理的近战攻击。一次？你再看看你后面呢？
本游戏的元老之一，和这个游戏的雏形一起产生。
- 使用次数 2 / 行动回合开始发动 / 消耗回合 / 目标：同地点已面对面的一名玩家。
- **效果**：选一件近战武器立刻攻击该目标；本次**裸伤 ×⟦bal:talents.t1.melee_multiplier⟧、且目标防御减半**。
- 单次主动技的"乘算豁免"；仅对本次攻击生效。
#### 2.「剪刀手传奇一突牢玩家」（原初）
「海的那边是什么样？我不知道，小时候没上过学，字都不识几个」
「但如果你又是一楼锁小美，然后十枪空十一枪；又是进点不给屏障还往心夏枪口底下冲，甚至点个小绘精灵都不知道给盾」
「我下把就排在你对面把你打成筛子……靠，没文化骂人都吃亏」
这是一个把好几个老原初天赋（特别是元老）揉碎以后重新捏出来的进攻型天赋。更像一个人被生活揍了很多拳以后终于学会先动手。新玩家想体验追着人打的快乐，可以从这里开始。同时也可以试着规划一下若干被动效果的资源管理，进而过渡到神代天赋的使用。
- 起床后获得以下**各自独立**的子效果（成本/时机各异）：
  1. **我到鹅城只为了三件事** ：伤害玩家但未杀死 → 不视为犯罪；
  2. **这一次可以，那下一次呢？**触发特定犯罪类型 → 获 1 个额外行动回合（每种犯罪限 1 次）；
  3. **警觉（元老级天赋）**：首次"找到他人"与首次"被他人找到"各给 1 个额外行动回合（全局共 1 次）；
  4. **攻击回盾**：你每第 2 次击中对手护甲的攻击，将为你的对应护甲恢复相当于被击中护甲最大耐久度 ⟦bal:talents.t2.shield_recovery_durability⟧的耐久度；如果你已有同名护盾，则同名护盾的最大耐久度恢复该值；如果没有，则立刻获得耐久度等于该值的该种类护盾。
  5. **按住shift以潜行**：击杀数为 0 时，攻击他人不解除自身隐身。
#### 3.「天星」（原初）
一句话概括：天理尝蛆。
元老级别的天赋中最年轻的一个。早期反制警察的对策卡，零帧起手的能力和石化伤控二选一在那个攻击成本高的年代算是猛攻哥最严厉的父亲之一。它的作用是让上头直接冲的人突然意识到：哦，这个游戏还是可以有人对着一个地点直接砸大招的。
- 使用次数 2 / 行动回合开始发动 / 消耗回合 / 目标：你所在地点除你外的所有单位。
- **效果**：各造成 `⟦bal:talents.t3.aoe_base⟧ + 命中单位数`（上限 ⟦bal:talents.t3.aoe_cap⟧）伤害，
  穿甲（防御按 ⟦bal:talents.t3.armor_pierce⟧ 计），并施加**石化**。

#### 5.「combo」（原初）
「锁屏可打」
「已退出锁屏可打大队」
「好耶！感谢奥托普雷先生帮我又拿下一首 FC」
元老级天赋，只比天星要早。这个天赋的设计一开始很朴素：连续行动三轮给奖励，然后就成了很强的天赋。乐，这说明大部分几千字的天赋其强度（至少是与BasicAI杂交之后的强度）不超过或者不如一个每次二十几概率连续行动三次之后补偿1额外回合的朴素内容强势——不知道该说是数值平衡做得好还是策略写的垃圾，哈哈。
然后就彻底重做成了现在这个复杂的样子。神代天赋开演唱会，原初天赋打个铺面很合理吧？
- 无次数上限 / 自动 / 无成本 / 目标自己。**音游谱面**：
  每隔 ⟦bal:talents.t5.chart_cadence_rounds⟧ 轮发一张**有序谱面**（1–3 个音符 = 动作大类 @ 拍点轮，提前公开）。

  奖励"手感火热"：临时攻击 +⟦bal:talents.t5.fever_atk_fc⟧（FC）/ +⟦bal:talents.t5.fever_atk_clear⟧（Clear）、
  小回血 +⟦bal:talents.t5.heal_fc⟧ / +⟦bal:talents.t5.heal_clear⟧、**FC 额外一次追加行动**。
#### 6.「朝阳好市民」（原初，随风洞最可能机制加强）

这个天赋的强度不完全来自数值，而来自它把“秩序”变成了玩家可以操作的武器。别人打架，你报警；别人出门，你记罪；别人以为自己在玩大逃杀，你告诉他这里还有基层治理。很可怕，很现实。
- 常驻 / 自动 / 目标自己。
- **效果**：举报热线（"举报"无需前往警察局）；本局违法名单**额外增加**（进入他人之家 / 进入军事基地 / 释放病毒）；
  竞选队长所需回合 −1。
- 边界：随白昼**黄昏**起警察保护下线、**终焉**警察停摆（见第十一章），但黄昏阶段远程举报与犯罪名单仍有效。
#### 7.「死者苏生」（原初）
一句话概括：以自己或对手墓地的一只怪兽为对象可以发动。什么？你说这是游戏王？这名字不就是从游戏王搬过来的？
V2.0 已经有了往世层，所以复活不再承担“让死者别干坐”的唯一职责。它现在更像是一张提前埋下去的保险。我们也在想是否能允许它直接复活坠入往世层的玩家——诶，有个好东西叫献予彼岸之诗。
- 全局 1 次 / 需先在魔法所连续学习 2 回合 / 习得后消耗 1 回合"挂载" / 目标：任一玩家（含自己）。
- **效果**：被挂载者死亡时——保留全部物品、在自己家中重生、破损护盾（魔法护盾/AT力场）恢复展开、
  下个行动回合免起床；复活生命值 ⟦bal:talents.t7.revive_hp⟧。结算完成后本天赋永久失效。
- 边界：全场最多 1 名挂载目标；免死优先于复活结算（若被免死则不触发）。
### 13.2 神代天赋（即将分类进入各扩展）（高复杂度预警）
#### 神代 1.「火萤Ⅳ型-完全燃烧」
「我曾安眠，赤染之萤。自破碎的天空坠落，沉睡在静默的星河。」
「我梦见一片焦土，一株破土而出的新蕊，它迎着朝阳绽放，向我低语呢喃……」
「我会看见，飞萤之火自无梦的长夜亮起，绽放在终竟的明天。」
第二批神代天赋。复刻自游戏《崩坏·星穹铁道》的角色流萤。
这个天赋的原型其实和流萤没什么关系——那时候没有崩铁。我记得好像是有节课下课了，班里的传奇DM（整个游戏的灵感其实是他的，这哥们带D&D团水平也是一绝）问我来不来一盘快攻。我问他怎么个快攻法，他说他开个斑纹——伤害翻倍，伤害减半，但是只能活十个还是十五个轮次，如果结束的时候我没被杀，就是我赢了。
那一局的结果我倒是记得清楚：下一节课上课铃响的时候我靠着放他风筝最后赢了他。
这段记忆留到了六年后。我在思考如何用规则刻画萤萤的弧光时，这段记忆被我打捞了上来。
流萤的故事，从不会做梦的量产铁骑，效忠于不存在的格拉默女皇直至国家、战友与蝗灾一同覆灭，一直到她加入星核猎手，希望从今往后能摆脱失熵症，成为流萤，成为一个平凡的，可以用自己的身体做自己想做任何事的女孩子，已经很长了。将来还会更长。把这么长一个故事复刻成一个技能，那太不聚焦了。所以，我提取了关键词“燃烧”。截止到目前，她的一生都是在燃烧。只不过，过去她在为不存在的女皇而战，而如今，她将为生而战，为了一切自己所爱的继续燃烧。至于作为自机角色的流萤，由于这个游戏现在没有韧性条的概念，自然也没有根据削减韧性出伤的超击破概念，能借鉴的就少些。将来如果做机制升级，倒是有可能加上来。
不同于G7的Terror（BA的剧情表明一个被色彩反转的角色不可能还原），Vol1.3里星野的反转没有完全，才被老师救了回来。失熵症有没有救？肯定是有的，病因都给出来了。只不过截止到崩铁4.3剧情仍然没有提到该怎么办。所以，我还没有设计一个可以解除失熵症的机制。
不过这一天迟早会来的。我相信她一定会为自己夺得胜利。
也祝愿你能陪她跨越注定的结局。就像她在燃烧殆尽后坠入原始忆质时留给主角的最后一句话：“去为他们，为我，夺回开拓的权力。”
（呜呜呜我的萤宝啊，自己都疼出眼泪了还要颤抖着安慰主角不要害怕。你等着，我吹两轮风洞之后再找个理由给你加强。我玩崩铁氪不起6+5在这里还改不了数值吗）
- **源式萤火中枢**：造成伤害 +⟦bal:talents.g1.attack_bonus⟧、受到伤害 −⟦bal:talents.g1.defense_reduction⟧、濒死不眩晕并在下回合回复。
- **失熵症**（燃烧自己的代价）：从游戏开始到一定轮次（具体公式待风洞测试）之后，每 ⟦bal:talents.g1.entropy_interval_rounds⟧ 轮结算一次，这个debufff优先摧毁外甲、否则毁 ⟦bal:talents.g1.entropy_armor_loss⟧ 点内层（目前无甲跳过、不致死，不过以后可能加入无护甲则扣血的机制，因为“活到最后”不是唯一的胜利方法了）；中后期才开始。
- **DHGDR-超新星过载**：debuff第一次开始生效时，以及每次完成击杀时，获得一次DHGDR-超新星过载的使用次数。此技能的次数不能叠加。有使用次数时，你的move指令可以指定你现在所在的地点，并在你move至任意一个地点时自动发动。此次move不能被除G3幻想乡之外的任何方式阻挡，到达指定地点后对所在地点全体造成 ⟦bal:talents.g1.supernova_damage⟧ 点无视克制伤害（此伤害享受源式萤火中枢的伤害加成）。（穿甲 ⟦bal:talents.g1.supernova_pierce⟧）+ ⟦bal:talents.g1.supernova_burn⟧ 层灼烧（此伤害享受源式萤火中枢的伤害加成）。。
- **炽愿**：超新星每命中/击杀一个单位都可以积1层，每层可抵 1 次失熵 debuff 或充当额外生命值（⟦bal:talents.g1.ardent_temp_hp⟧）。
- **坠落在燃烧的天空**：每 ⟦bal:talents.g1.initiative_interval_rounds⟧ 轮 +⟦bal:talents.g1.initiative_bonus⟧。若上一个全局轮次中有击杀，这个全局轮次投掷时无视冷却生效，但生效后会正常刷新冷却轮次。

「它漠视九重天下的人子：不歌颂他们的伟大，也不嗤笑他们的挣扎。」
有些问题不能靠站队解决，不能靠警察保护解决，甚至不能靠桌面上那套已经写好的公共规则解决。
所以幻想乡把人拉出去。离开白昼，离开秩序，离开警察，离开那些花里胡哨的护身符，回到最原始也最不讲理的决斗里。
它很像一个小孩在桌上画了一条线，然后说：你过来，我们在这里重新算。
使用次数：2 次。
启动时机：在自己的行动回合开始时（T0）。
成本：消耗一个行动回合。
目标：与你处于同一地点的至多 1 名其他玩家；若同地点没有可选目标，也可以独自展开。
效果：你与目标被拉入「遗世独立的幻想乡」。V2.0 口径下，它不是让全桌真的多等若干个外部轮次，而是在发动这一刻立刻、连续、同步结算完整个结界流程。外部流程不会插入行动，也不会在结界中途推进警察、白昼、病毒、持续时间等全局结算。对桌面体验来说，就是“把这一小段拿出来，马上算完，再把人放回去”。
结界开场
结界展开时，发动者立刻获得 1 个结界内额外行动回合。
结界会移除结界内玩家的隐身，并强制双方相互可见、视为面对面。
若只拉入自己，则你独自完成这段结界流程；若拉入目标，则你们两人进入后续猜拳决斗。
结界内轮次
结界最多持续 ⟦bal:talents.g3.max_barrier_rounds⟧ 个结界轮次。
每个结界轮次中，结界内双方猜拳；平局重猜，胜者成为该轮唯一行动者。
行动者可以正常执行战斗相关行动，但不能与地点交互：不能拿取物品、学习法术、手术、购物、举报、释放地点菜单项目，也不能移动离开结界逻辑。换句话说，幻想乡不是让你去逛街的，是让你把眼前这个问题算清楚的。
结界内不能通过 lock 指令锁定结界外玩家，也不能把结界外单位拖进本次结算。
压制与特权
发动者在结界内免疫控制效果；眩晕、震荡、石化等会被结界处理掉。
被拉入幻想乡的目标受到天赋压制：主动天赋不能发动，被动天赋也不生效。这个压制是当前版本最强、也最粗暴的部分，很多看似“为什么不能触发”的交互，本质上都来自这里。
六爻一类“解除锁定/发现/反制”的效果在结界内不生效；警察保护也无法把手伸进幻想乡。
解除条件
结界内仅剩 1 名玩家存活；或结界已结算满 ⟦bal:talents.g3.max_barrier_rounds⟧ 个结界轮次。
解除后，存活玩家回到原地点，面对面关系解除，外部流程从结界发动后的时点继续。
涟漪增强
献予「永恒」之诗会使被拉入幻想乡的目标第一次行动只能选择 forfeit。当前代码中“次数增加”部分仍存在字段口径差异，手册暂不把它写作稳定收益；若后续接线完成，再补进本段。
#### 神代 4.「愿负世，照拂黎明」
「他们说我生来就是救世主，是将要担负世界的人，可……我的愿望究竟是什么？」
「直到生命尽头，我才知道，原来我只想……■■■■■」
「这个世界未竟的道路，就由我来担负着她走下去吧。」
愿负世一直不是“不够强”的问题。旧版本里它像一口只会在濒死时点燃的炉子：你越是被围攻、被援助、被命运推到桌角，越会把所有火种压进最后一次站起身。V2.0 并没有把这个主题拿走，只是把“能站多久、能打多痛、站完以后还留下什么”拆成了裁决系统能看懂的结构。否则救世主不是背负世界，是把整张桌子一起拖进数值地狱。（是的，我们已经被拖过一次了。）
使用次数：唯一触发。触发并完成结算后，本天赋永久失效。
启动时机：满足「致命攻击」条件时自动触发；若获得献予「负世」之诗，可在自己的行动回合开始时主动启动。
成本：消耗全部「火种」。
资源：「火种」（上限 ⟦bal:talents.g4.ember_pool_cap⟧；若程序状态栏仍显示旧上限，视作迁移未收口，以本信源项为准）。
目标：自己。
火种积累（常驻）
你获得「火种」的方式：
每次你被其他玩家攻击（无论是否造成伤害），获得 1 点火种。
每次其他玩家对你使用正面效果的天赋技能（治疗、加成、强化等），获得 1 点火种。
若上述攻击或援助来自「限定使用次数」的天赋技能，则额外获得 1 点火种。
进入「救世主」状态后不再继续获得火种。火不是无限续杯，不然这就不是负世，是电能大哥二号。
绝境触发（自动）
当你受到一次致命攻击，也即该次伤害在正常结算后会使你的心血归零时：
你立刻消耗所有火种，免疫此次死亡，并将心血至少设为 ⟦bal:talents.g4.revive_hp⟧；
随后进入「救世主」状态。此次攻击不再继续向下结算死亡，但攻击本身仍然算发生过。
「救世主」状态
你每消耗 1 点火种，获得以下收益：
1. 获得 ⟦bal:talents.g4.temp_hp_per_ember⟧ 点「余烬生命」。余烬生命是独立第二血条，位于内层护甲之后、本体心血之前；不参与治疗与再生，消耗后就是真的少了。
2. 获得 ⟦bal:talents.g4.attack_per_ember⟧ 点临时攻击力，加成所有近战攻击；总加成最高为 +⟦bal:talents.g4.attack_cap⟧。
3. 范围攻击获得额外伤害：消耗火种 ≤⟦bal:talents.g4.aoe_high_threshold⟧ 时为 +⟦bal:talents.g4.aoe_bonus_low⟧，超过时为 +⟦bal:talents.g4.aoe_bonus_high⟧。
4. 持续时间为 ⟦bal:talents.g4.duration_base⟧ + ceil(消耗火种 / 3) 轮，最高不超过 ⟦bal:talents.g4.duration_cap⟧ 轮。
状态期间规则：
禁用所有远程攻击。
每个 R4 轮次结束时，救世主持续轮次 -1。
若持续轮次归零，状态结束。
若在救世主状态中再次受到致命伤害，不会再触发第二次救世主；当前状态会被迫结束，然后照常进入死亡判定。救世主可以替世界挡一次坠落，但不能把坠落本身改写成不存在。
状态结束与毕业
状态结束时，临时攻击力、范围攻击加成、余烬生命全部清空，本天赋永久失效。
V2.0 不再沿用旧版「剩余临时生命转永久生命值」的写法；长期收益改由完结条承担。
若救世主状态结束时你仍存活，并在此后继续存活 ⟦bal:finale.g4_survive_rounds⟧ 轮，达成「救世主毕业」，获得 +⟦bal:finale.g4_graduation⟧ 剧情分。
#### 神代 5.「往世的涟漪」
这个天赋一直很难写。不是因为它的数值最难，虽然锚定命运确实已经足够让人想关电脑了；真正的问题是，
它很容易被写成一个普通的“攒资源，然后放大招”机制。
但她不是在做交易。
她是在记忆里打捞，在命运上下注，在别人还没走到那个结局以前先说：我见过这条路。于是系统要替她证明，
这不是一句漂亮话，而是一条真的会收束的路径。
「爱与记忆」之诗：以追忆为弓，命运为箭，于过去打捞命运，在当下激起涟漪。
- **资源「追忆」**：每轮 +⟦bal:talents.g5.reminiscence_per_round⟧，所在地点每发生一次喝彩额外 +⟦bal:talents.g5.reminiscence_applause_bonus⟧。
  满后 T0 二选一：
- **方式一·锚定命运**（不消耗回合）：对一个事件（击杀/破甲/获取/到达）锚定。系统算出**命数**（达成所需理想轮数）
  与**变数**（容错预算）；随后监控 ⟦bal:anchor.window⟧ 轮，目标的**开拓**（提高路径关键属性防御/闪避、脱离、致残你、治疗、
  抢夺路径上的有限物品等）累计超过变数则失败，否则事件由命运实现。监控期目标对你的闪避/隐身失效（善见天）。
- **方式二·献诗**（消耗回合）：对某天赋持有者吟唱对应诗篇予以强化；非自我目标会被施加**爱愿**（一段时间内无法伤害你）。
  「爱与记忆之诗」对场上单位逐段造成伤害（每段 ⟦bal:talents.g5.poem_destiny_stage_damage⟧，第 4 段起真伤）。
- **完结条**：完成 2 次成功锚定 → +⟦bal:finale.g5_double_anchor⟧。
#### 神代 6.「要有笑声！」
（它真的从废案区回来了。这个事实本身就像一条插入式笑话。）
（而且它没有看上去那么超模。事实上，它可能是几个神代里最容易把收益摊在桌面上数清楚的那个。你可以说这不够像欢愉，但你不能说这不够方便平衡组加班。）
「祂沿着巨树，攀登到了存在的尽头。而存在者恒存在，不存在者不存在。」
「祂聆听到了婴儿的啼哭，那是人类发出的第一声，也是最后一声呐喊」
「祂因而放声大笑，那笑声逆转了宇宙的终末。」
「祂说，要有笑声，于是就有了笑声」
这个天赋的核心逻辑很朴素：只要世界上出现了一个不该空出来的停顿，就会有人把它剪成包袱。别人没行动，空气尴尬；有人选择 forfeit，空气更尴尬；而当尴尬攒到足够多的时候，欢愉就从规则的缝里探出头来，说：这段我来演。
笑点：特殊道具，无其他作用。
每个全局轮次结束时，如果你本轮没有执行行动回合，或者你在自己的行动回合中选择 forfeit，获得 1 个「笑点」。
基础触发阈值为 6。笑点达到阈值时，清空当前笑点并获得 1 次「插入式笑话」充能。
当前电子裁决程序仍会在充能后的下一轮给予 D4、D6 强制满点，用来把这次笑话尽量投递进你的行动回合；设计稿中提到的“G6 本体 D4 投递退役”若后续真正接线，删掉这一句即可。
「插入式笑话」
这是一个特殊行动回合。进入该回合后，你可以执行当前场上其他单位可枚举出的任意一个合法行动；判定行动能否执行时，采用被借用单位的状态进行验证。
行动造成的收益归属：获得的物品、击杀数和击杀奖励（若存在）归于 G6 天赋持有者。
行动造成的责任归属：犯罪记录、威信损失、凭证损失等代价归于被借用的单位。
这不是“你变成了那个人”，而是“那个人的可执行行动被剪进了你的节目里”。这句话听起来像在逃避责任，主要是因为它确实在逃避责任。
E.g. 玩家A已进入「插入式笑话」，人在自己家中，手里没有物品；玩家B是警队队长；玩家C是唯一一个拥有购物凭证且正在商店的玩家，没有犯罪记录。
此时玩家A可以执行：
拿自己家里的小刀等物品。
借用玩家C的商店购买行动，购买陶瓷护甲等物品，物品归玩家A。
借用玩家B的队长指令，指挥警察攻击玩家C；若因此产生威信损失，威信损失归玩家B。
涟漪增强
献予「欢愉」之诗会立刻使目标获得 1 次「插入式笑话」充能。
在 M7 口径下，旧说明里的“后续 forfeit 需求减少”改写为直接获得 ⟦bal:talents.g5.poem_joy_laugh_bonus⟧ 点笑点；它不再负责额外设置 D4、D6。换句话说，昔涟把笑话直接塞进了你的手里，至于世界什么时候安静下来，那是世界自己的问题。
#### 神代 7.「大叔我啊，剪短发了」（星野）
「我闻那 sensei 曾言：阿拜多斯的小鸟游星野，在百万军中取百万军之首，如探囊取物耳。今日相逢，卿等不可轻敌啊！」
「虽然不知道发生了什么事情，但……唔啊，如果你们几个没有事的话，大叔我就要回去睡觉了……」
「不要打哑谜，请说清楚你的来意，委员长小姐姐。」
星野这个天赋，基本可以视为一次“我想还原一下，结果发现要还原的东西越来越多”的工程事故。
盾要有，光环要有，荷鲁斯之眼要有，Terror 要有，掩体推进和持盾架点的感觉也要有。少一个都不太对，多一个又确实像在给桌游塞小型 DLC。怎么办？做都做了。
她不是来适配这个游戏的。是这个游戏在努力适配她。
如果你想玩一个“按一次按钮，获得一个强力效果”的天赋，星野不是给你的。她更像一台需要驾驶的战术载具：你要知道什么时候举盾，什么时候架盾，什么时候把位置钉死，什么时候把 cost 烧成一串宏，什么时候承认大叔真的要变成另一个东西了。
被动效果一：战斗续行（光环系统）
你持有 ⟦bal:talents.g7.halo_count⟧ 层「光环」。每层光环点亮时，提供 ⟦bal:talents.g7.halo_value⟧ 点可再生护体值。
光环被消耗后会黯淡并进入恢复队列；同一时间最多只有 1 层光环处于恢复中。当前实现的冷却公式仍按存活人数自动计算。
游戏开始时，光环会依次恢复。三层光环首次全部点亮时，你获得一次性的「战斗续行」免死：受到致命伤害时自动免疫此次死亡，并将心血设为 ⟦bal:talents.g7.revive_hp⟧。触发后永久失效；Terror 形态下不生效。
被动效果二：最强的矛与盾（融合装备）
你第一次同时持有盾牌和 AT 力场时，两者自动融合为特殊无属性护盾「铁之荷鲁斯」。
铁之荷鲁斯初始耐久为 ⟦bal:talents.g7.iron_horus_durability⟧。它不是普通护甲，而是星野整套战术系统的地基：架盾、持盾、被动保护、Terror 折算都会读取它。
铁之荷鲁斯受损后，可以通过 `special 修复 <盾牌/AT力场>` 消耗一件盾牌或 AT 力场修复 ⟦bal:talents.g7.iron_horus_repair⟧ 点耐久，最高不超过上限。
当前程序中仍保留“未处于架盾/持盾时自动修复”的冷却框架，但修复量已被调为 0；不要把它当成可依赖的续航来源。
你第一次同时持有电磁步枪和高斯步枪时，两者自动融合为特殊武器「荷鲁斯之眼」。它初始不携带子弹，弹匣上限为 8 发。
你同时完成盾与枪的融合后，自动习得战术指令，并获得 2 次自由配发机会：每次可选择 1 个战术道具、1 种药物，或 2 发某属性子弹。
被动效果三：战斗潮流（cost 系统）
你拥有特殊体力条 cost，基础上限为 5。每个 R0 回满。
如果你上一全局轮次使用过战术指令宏，则下一轮回满后 cost -1；肾上腺素可以覆盖这次代价。它叫“失却汇流成泉”，翻译一下就是：大叔可以很强，但不能每轮都用同一套宏把桌子碾过去。
百变星野（初始形态）
你入场时选择一种形态。起床时的额外收益只在起床时结算；之后可在家中通过 `special 更衣 <形态>` 花费 1 回合换形态，但不会重新获得起床收益。
通用起床收益：获得一次消费资格（当前程序仍以凭证字段实现）。
水着-shielder：起床获得盾牌；架盾每个 R4 不扣 cost，免费维持。
临战-Archer：起床后获得 1 个额外行动回合；战术「射击」每连续执行 2 次，额外执行 1 次射击，额外射击的弹丸不飞散，并有破甲概率。
临战-shielder：起床时恢复 1 层光环；持盾状态下若一个战术宏中先冲刺、再 find 成功，可自动冲击并震荡目标，随后进入架盾。
战术指令宏
持有铁之荷鲁斯与荷鲁斯之眼后，你可以在回合中使用 `special Hoshino` 进入战术指令宏。系统会逐条读取战术动作，直到你输入 `terminal` 结束。
宏内动作按顺序执行并逐步扣 cost；如果某一步 cost 不足，宏会在该步骤中断，已经执行的动作不会回退。
可用动作包括：架盾、射击、重新装填、持盾、投掷、服药、冲刺、取消、find、lock、转向、排弹。
战术动作一：架盾（cost 2）
将铁之荷鲁斯插入地面，划分「正面」与「背面」。
架盾时，当前地点内已经存在的其他单位被划为正面；之后进入该地点的单位默认划为背面。你通过 find 找到的目标会被额外归入正面；断开面对面关系后，再次主动 find 你之前归入背面。
架盾期间，来自正面的裸伤若 ≤⟦bal:talents.g7.shield_block_threshold⟧，被完全格挡；若超过该阈值，则铁之荷鲁斯扣除 ⟦bal:talents.g7.shield_overflow_durability_cost⟧ 耐久并无效化本次剩余伤害。
架盾期间，处于你正面的敌人若想正常 move 离开，需要额外多花 1 回合。可豁免的方式包括超新星过载、最后一曲、强制位移、插入式笑话等。
架盾期间你无法正常 move。每个 R4 最后检查一次维持 cost：水着-shielder 免费，其他形态扣 1 cost；cost 不足、铁之荷鲁斯归零、或你陷入控制效果时，架盾结束。
战术动作二：射击（cost 2）
消耗 1 发子弹，使用荷鲁斯之眼射击。每发子弹包含 3 颗弹丸，每颗弹丸造成 ⟦bal:talents.g7.eye_pellet_damage⟧ 点对应属性伤害。
普通射击：3 颗弹丸全部命中你选定的目标。
持盾射击：2 颗弹丸必中选定目标，第 3 颗有概率飞散。
架盾射击：若正面只有 1 个目标，则 1 颗必中，另外 2 颗各自可能飞散；若正面有多个目标，则选中目标至少吃 1 颗，剩余 2 颗在正面单位中随机分配。
临战-Archer 的额外射击不消耗 cost 和子弹。若触发破甲，在 M7 口径下不再追加旧版真伤，而是使目标最外层可破护甲额外失去 ⟦bal:talents.g7.armor_pierce_durability_cost⟧ 耐久。
战术动作三：重新装填（cost 0）
摧毁自己 1 件有属性的物品或护甲，为荷鲁斯之眼填充 4 发对应属性子弹。普通/科技/魔法属性按被摧毁物品判定；超出弹匣上限的部分丢弃。
战术动作四：持盾（cost 1）
将铁之荷鲁斯展开为可移动的举盾状态。
持盾时，铁之荷鲁斯提供 ⟦bal:talents.g7.hold_defense⟧ 点减法防御，随后用自身耐久吸收剩余伤害；若被击破，会吸收本次溢出并结束持盾。
持盾期间不能 interact。持盾不会因为 R4 cost 不足自动结束，但会因铁之荷鲁斯归零、控制效果、或 `special 取消盾牌` 主动取消而结束。
持盾状态下执行射击，会进入持盾射击模式。
战术动作五：投掷（cost 1）
向指定地点投掷一个战术道具。战术道具从军事基地获取，一个行动通常只能获取 1 样，最多同时持有 2 样。
破片手雷：造成小额普通伤害并施加「脆弱」，使后续破甲概率提高。
震撼弹：对目标地点除自己外单位施加震荡；可作用于警察单位。
闪光弹：造成致盲，目标在持续期间无法查看行动与状态；警察单位被致盲期间不自动攻击、不执行队长命令、不提供保护。
烟雾弹：展开烟雾。你进入烟雾时获得隐身；其他单位在烟雾中不能 find/lock，已有 find/lock 会被解除；警察在烟雾中不自动攻击、不提供保护。
燃烧瓶：叠加灼烧，逻辑同火萤的燃烧体系。
若你处于架盾状态，道具只对执行结束时仍处于你正面的单位生效。
战术动作六：服药（cost 0）
使用自身携带的一种药物。药物从医院获取；习得战术指令后，当前实现不检查消费资格。
EPO：立刻使 cost +1。
海豚巧克力：恢复 1 层光环。
肾上腺素：全局仅能使用 1 次，通过宏外 `special 肾上腺素` 注射，不消耗行动回合；下一个 R0 生效，使 cost 回满至 10，所有光环立刻恢复，并获得 D4 +3。
其他战术动作
冲刺：cost 1，持盾状态下移动到指定地点；每个宏最多 1 次。
取消：cost 0，取消架盾或持盾；也可通过宏外 `special 取消盾牌` 执行。
find/lock：各 cost 1，按常规 find/lock 结算；在架盾状态下，find 成功会把目标纳入正面。
转向：cost 0，架盾状态下翻转正面/背面，并切换“阻止离开/阻止进入”的守点口径。
排弹：cost 0，重排弹匣顺序；每个宏最多 1 次。
铁之荷鲁斯的被动保护
不处于架盾/持盾时，铁之荷鲁斯仍会作为特殊防线介入伤害：先提供 ⟦bal:talents.g7.passive_defense⟧ 点减法防御，再用自身耐久吸收伤害，但会保留 ⟦bal:talents.g7.passive_break_reserve⟧ 耐久作为将破保留线；溢出的部分优先由光环护体值吸收，再继续进入常规护甲与心血结算。
这也是星野最像“重装单位”的地方：你以为只是打她，其实是在先拆盾，再拆光环，再拆人。
色彩反转
场上每有 1 名玩家因任何原因出局，你获得 2 点「色彩」；若该玩家由你击杀，则额外获得 2 点色彩。
色彩达到 6 时，你可以在自己的回合开始时选择是否进入「自我怀疑」。
色彩达到 10 时，若你的本体心血受到伤害但没有死亡，你不陷入眩晕，所有穿戴过且已破碎的护甲恢复，然后强制进入「自我怀疑」。
自我怀疑状态下，你的下一次行动回合会被跳过；该回合结束时，你反转为 Terror。
Terror 状态
Terror 形态下，cost 显示为 Null，玩家名被覆盖为「星野-Terror」。
你失去所有战术指令、战术道具、药物、铁之荷鲁斯与光环，只允许执行 attack 和 move。
进入 Terror 时，你失去反转发生时的所有护甲与光环，并将它们折算为额外生命值：每件护甲 +⟦bal:talents.g7.terror_armor_per_piece⟧；铁之荷鲁斯按剩余耐久 / ⟦bal:talents.g7.terror_horus_divisor⟧ 折算；每层光环 +⟦bal:talents.g7.terror_halo_per_layer⟧。若总额低于 ⟦bal:talents.g7.terror_hp_floor⟧，补正到该保底值。
Terror 攻击：只能使用荷鲁斯之眼的异常主炮，对地图上除自己外所有单位造成 ⟦bal:talents.g7.terror_attack_damage⟧ 点无视属性克制伤害；伤害结算后扣除 ⟦bal:talents.g7.terror_attack_cost⟧ 点 Terror 额外生命值。若这一击已经全歼场上其他玩家，则不再扣除代价。
Terror 移动：移动完成后扣除 ⟦bal:talents.g7.terror_move_cost⟧ 点 Terror 额外生命值；不足以支付也可以移动，但归零后判定死亡。
Terror 攻击正常违法，但无法被举报；警察不会主动靠近或攻击 Terror，也会拒绝相关队长指令。
Terror 形态下，挂载在你身上的复活不会生效。你的心血归零时，立刻无视任何条件死亡。
献予「守夜人」之诗
若你接受往世的涟漪献予「守夜人」之诗，「色彩」将永久变为 null。若你已处于 Terror，会解除 Terror，并把剩余额外生命值转化为永久额外生命值；随后按诗篇规则扣除一部分永久额外生命值，以恢复铁之荷鲁斯并取回战术系统。
这不是简单的加强，更像一次“有人终于把你从沙漠里拽回来”的改写。要不要接受，请自己想清楚。
## 新手指南
本章写给第一次坐到桌边的人。不要试图一口气背完整本手册。认真说，这种行为对精神状态不是很好。
你只需要先知道：起床，出门，挣钱，拿装备，找人打架，别让警察把你当成年度工作 KPI，最后尽量打出一点值得被记住的场面。
剩下的东西可以边玩边学。反正电子裁决程序会替你记住绝大多数你不想记住的东西。
### 核心速览
- **行动不靠抢**：每轮你几乎都能行动（K 行动制，见 4.3），不再投 D4 拼运气。
- **钱要出门挣**：家里**不产任何资源**，去商店/医院**打工**赚信用点（七章）。
- **起床第一**：第一个行动回合必须"起床"。
- **怎么打都有效**：HP20 减法防御 + 保底——再厚的甲也至少掉 ¼，没有"打不动"的龟壳；
  属性"硬克制"已废除，只剩伤害高低之分（八章）。
- **死亡不出局**：被杀会**坠入往世层、化作星**，仍能用星光影响战局（十二章）。
- **赢法不止一种**：终局看**综合评分**，"活到最后"只是加分项——战果/喝彩/完结条同样能赢（一章）。
### 推荐流程（骨架）
1. **起床**（首个行动回合）。
2. **出门发育**：去商店/医院打工攒信用点 → 买陶瓷护甲/磨刀石，或给弓买升级模块（六章）。
   家不再是经济来源，记住你的床，但别赖床。
3. **武装**：弓人手一份（起始 ⟦bal:bow.initial_arrows⟧ 箭），是唯一常规跨地点武器；近战需先"找到"。
4. **交战**：同地点"找到"后近战，或"射箭"跨地点（锁定拉满命中）。磨对手的甲就是在烧他的钱——磨甲也是一种打法（七章）。
5. **用天赋**：天赋是你的演出主轴、关键时刻的底牌。
### 天赋选择建议
如果你是新玩家，优先从原初天赋开始。它们的规则也不算短，但至少大多数时候你知道自己在干什么：
想打人选一刀/剪刀手，想要一点玄学和工具箱选六爻，想体验节奏奖励选 combo，想玩秩序和举报选好市民，
想把复活点成桌面笑话选死者苏生。
如果你想第一次就碰神代天赋，可以，但请先确认这一桌不靠这一局建立友谊。
G1 火萤适合想主动进攻、愿意接受后期代价的人；G2 注视适合愿意读舞台规则、并且真的想演一场的人；
G3 神话之外适合想把别人拖进小黑屋重算的人；G4 愿负世适合喜欢绝境反打和背负感的人；
G5 往世的涟漪适合愿意和命运解应用题的人；G6 要有笑声适合想把节奏断点变成笑话的人；
G7 星野适合愿意驾驶一个机制套件的人。
以及，第一次玩不建议点 G5。不是它不美，是它真的会让主持人和 AI 一起沉默。
### 常见问题
**Q：我被打到很残怎么办？**
A：生命值降到重伤线（≤⟦bal:hp20.severe_injury_threshold⟧）会承受额外不利（九章）；归零则坠入往世层成星。残血时搏命还是补甲/治疗，自己权衡。
**Q：警察打我，能反杀吗？**
A：能，但袭警本身算犯罪；且 V2.0 警察保护是"每轮免疫小于阈值的单体伤害"，要打穿得靠大单体或 AOE（十章）。
**Q：怎么赚钱？旧版的"购物凭证"呢？**
A：凭证经济已废除，改用**信用点**：出门打工、击杀夺财。家不产钱，被动收入被一票否决（七章）。
**Q：天赋能用几次？可以不选吗？**
A：次数见各天赋说明（十三章）。可以不选（白板，规则允许），但建议一桌"要么都选、要么都不选"以免体验落差。
**Q：我死得早，要干等到游戏结束吗？**
A：**不用**。V2.0 死者坠入往世层化作星，每轮获星光、用星光行动（拨弄命运/预兆/加冕）继续左右战局，还能挣往世分计入自己终分（十二章）。
**Q：这个游戏会不会拖很久？**
A：V2.0 针对老版"龟缩/拖沓"做了系统性改造——经济战（修甲烧钱、手术财产税）、HP20 保底（必掉 ¼）、
白昼世界时钟（黄昏加伤、终焉每轮真伤的"毒圈"）、综合评分制（"活到最后只是加分项"）合力压缩对局长度，
平均轮数较 v1 **显著缩短**（具体随风洞复核）。
**Q：鼓励玩家交流吗？**
A：鼓励。本游戏近乎完美信息博弈，结盟、劝说、口头约定都随意——边聊边玩。
**Q：无天赋局是什么定位？**
A：仅建议作**初学者入门**。无天赋本体仍有机制残缺（戏剧张力主要靠天赋承载），但老版"极度奖励防御、
没有毒圈、终结能力低下"那套老毛病，已被 V2.0 的经济 / 世界时钟 / 综合评分制大幅缓解。
**Q：为什么要做神代天赋？主持难不难？**
A：因为我们想让你成为你喜欢的角色。
这句话听起来很中二，但确实就是答案。神代天赋不是为了把游戏做得更好平衡而诞生的，甚至很多时候正相反：
它们会主动制造复杂度、例外、专属资源、专属结局，逼着底层系统让路。正常项目组可能会把这些东西砍掉，
写成“造成伤害 +2，受到伤害 -1”，然后大家都轻松。
但那样就没意思了。
这个游戏的天赋模式追求的是某个时刻：全桌的目光突然聚焦到你的表演上。可能是火萤 IV 型一穿五，
可能是六爻放逐救世主，可能是舞台终于谢幕，可能是一个死者在往世层把最后一点星光押给还活着的人。
胜者当然重要，但真正会被记住的往往是这些场面。
主持难不难？难。没有电子裁决程序会非常难。启用神代天赋前，请确认大家都知道自己要玩的不是简洁竞技桌游，
而是一台会在关键时刻为了角色弧光放弃一部分可理解性的演出机器。
