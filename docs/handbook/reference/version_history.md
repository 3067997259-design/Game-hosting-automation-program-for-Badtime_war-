## 附录 C · 版本历史
### V2.0-exp 相对 v1 的关键变化（changelog 摘要）
- **HP20 整数数值模型**：减法防御 + ⌈25%⌉ 保底 + 护甲耐久 + 防御表；**硬克制废除**。
- **K 行动制**：取代 D4 争夺行动权。
- **远程重置**：弓（人手一份 / 可跨地点 / 升级模块）+ 钩索（神器 / 强制位移）；导弹退役。
- **信用点经济**：取代购物凭证；禁被动收入、修甲经济战、手术财产税。
- **白昼世界时钟**：黎明 / 白昼 / 黄昏 / 终焉四幕压力曲线（自带"毒圈"）。
- **综合评分制 + 往世层**：终分 =（剧情 + 喝彩 + 战果）× 存活 + 往世；死者成星。
- **天赋全面 hp20 化**：14 天赋数值重整（T5 谱面、G5 锚定、G6 笑点等）。
- 完整逐条记录见 `docs/history/changelog.md`。
