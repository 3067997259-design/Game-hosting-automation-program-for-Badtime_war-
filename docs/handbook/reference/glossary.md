## 附录 A · 术语表（V2.0）
| 术语 | 含义 |
|---|---|
| 全局轮次（Round） | R0→R4 的整套流程 |
| 行动回合（Action Turn） | 获得行动权后执行一次行动的时刻 |
| K 行动制 | 每轮可行动人数 = max(1, 存活 − ⟦bal:action_system.k_sitout_count⟧)（取代旧"D4 争行动权"） |
| 生命值（HP） | 整数生命值，上限 ⟦bal:hp20.player_max_hp⟧ |
| 重伤 | 生命值处于 0 与 ⟦bal:hp20.severe_injury_threshold⟧ 之间的不利状态 |
| 防御表 | 护甲对各攻击属性的减伤值（主防/副防）；硬克制已由它取代 |
| 耐久 | 外甲的损耗条，吸收伤害 1:1 消耗，归零即碎 |
| 擦伤 | 被闪避的攻击，按保底线结算、不触发附带效果 |
| 信用点 | V2.0 统一通货（取代购物凭证） |
| 嫌疑 | 白昼阶段首次攻击记"嫌疑"、不记罪 |
| 喝彩 | 名场面奖励，两用资源（计入终分 / 可消耗） |
| 完结条 | 达成叙事里程碑的大额剧情分 |
| 往世层 / 星 | 死者坠入的层；化作星，用星光继续影响战局 |
| 星光 / 往世分 | 星的资源 / 星挣得并折算入终分的分数 |
| 命数 / 变数 / 开拓 | G5 锚定：理想达成轮数 / 容错预算 / 被锚者的反抗手段 |
| 谱面 / FC | T5：有序拍点 / 全连（全 Perfect） |
| 分级坠落 | 警察随白昼分阶段失效（黄昏保护下线、终焉停摆） |
| 位移三件套 | 推（弓·冲击）/ 拉（钩索）/ 逐（六爻） |
