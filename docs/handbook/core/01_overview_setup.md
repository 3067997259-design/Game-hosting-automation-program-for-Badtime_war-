## 一、游戏概述
起闯战争是一局 2–6 人的**基于回合制的类大逃杀MUD**。你扮演⬛⬛⬛⬛⬛⬛⬛⬛，在一张六地点的地图上移动、发育、结盟、厮杀，并争夺最高的**综合评分**，最终赢得比赛，⬛⬛⬛⬛。
它的游戏本质是多人乱斗，并在此基础上希望和奖励你打出足够精彩的场面，有没有完成属于天赋的结局，有没有在离场继续干涉命运，有没有创造让这一局在结束以后还值得被桌边的朋友复述的场面。
这可能就是当年那些在操场边上的凉棚底下抢凳子坐的小孩最喜欢的东西？
### 1.1 我活到最后≠我能赢，不等式秒了
V2.0 的胜负由**综合评分**裁定——
```
终分 = （剧情分 + 喝彩净值 + 战果分） × 存活系数 + 往世分
```
- **活到最后只是加分项**（计入"存活系数"），不再是唯一目标。一味龟缩苟活，终分会很难看。
- 评分四源：**剧情分**（达成"完结条"等叙事里程碑）、**喝彩**（打出名场面，见第十二章）、
  **战果分**（击杀与有效伤害）、**往世分**（死后在往世层的作为）。
- **中盘只见组件、不见总分**；精确终分在**终局统一揭晓**。
- **双轨获胜**：终分第一与"最后存活者"并列记录——你可以是赢家，也可以是活到最后的那个，二者未必是同一人。
### 1.2 死亡不等于出局
被击杀者**坠入往世层、化作群星中的一抹微光**：不能再直接造成伤害，但仍能用"星光"拨动生者的命运、
并继续为自己积累**往世分**（见第十二章）。
### 1.3 残局与终结
为避免残局陷入"谁都不动"的僵局，游戏设有**残局终结机制**（白昼世界时钟的"终焉"阶段等，见第十一章）
持续施压，推动对局走向结束。

## 二、组件与信息公开
### 2.1 地图与地点
地图由六个地点构成：**家（home）/ 商店 / 魔法所 / 医院 / 军事基地 / 警察局**。
任意地点之间移动均为一次行动（无邻接限制）。各地点的供应见第六章。
### 2.2 信息公开原则
起闯战争是**高信息公开**的博弈：玩家的位置、装备、生命值（HP）、状态标记等对所有人可见（隐身/探测另有规则，见第九章）。
唯一的私密信息是少数"匿名"来源（如匿名冷箭的归因，见第九章）。**公开是博弈的前提**——
你能看见别人在攒什么、走向哪里，别人也能看见你。
### 2.3 玩家状态条（L1 清单）
每名玩家随时可查看以下状态：
- **生命值**：上限 ⟦bal:hp20.player_max_hp⟧（整数血量模型，见第八章）。
- **外甲耐久条**：每件外甲的剩余耐久（见第八章）。
- **钱包**：信用点余额（经济，见第七章）。
- **箭矢**：n / ⟦bal:bow.max_arrows⟧（弓的弹药）+ 升级模块双槽（见第六章）。
- **状态图标**：眩晕/震荡/石化、灼烧层数、隐身/探测、各天赋专属标记等。

## 三、游戏准备
### 3.1 初始状态
每名玩家以 ⟦bal:hp20.player_max_hp⟧ 点生命值开局，位于自己的**家**，初始处于"未起床"状态。
### 3.2 起始包（家中资源）
每人开局获得：
- **弓** + ⟦bal:bow.initial_arrows⟧ 支箭（人手一份的跨地点武器，见第六章）；
- 在家可拾取**小刀 / 盾牌**的资格。
> 注：家**不再产出任何经济资源**（信用点只能在外面挣，见第七章。为什么这么设计呢？因为AfterRain设计这里的时候突然发现他在心智不成熟的时候就骨质疏松了，幸好他的手头因为买订阅计划和云服务器的原因一直很紧）。
### 3.3 游戏开始
游戏从第一个全局轮次开始。每名玩家的**首个行动回合必须用于"起床"**；起床后方可进行其它行动。
