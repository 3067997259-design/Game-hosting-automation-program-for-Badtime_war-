## 四、时序与流程
### 4.1 全局轮次（Round）的标准结构
游戏以"全局轮次"推进，每轮依次结算：
1. **轮次开始结算**：持续效果计时、天赋的"轮次开始"效果、病毒倒计时（若挂在轮首）、
   白昼世界时钟阶段推进（见第十一章）。
2. **先攻判定与行动权分配**（见 4.3）。
3. **警察状态机推进**（见第十章）。
4. **行动回合**：取得行动权者按先攻顺序依次行动（见 4.2）。
5. **轮次结束结算**：警察执法、病毒与死亡判定、持续效果计时、检查胜负与残局终结，进入下一轮。
### 4.2 行动回合（Action Turn）的标准结构
每个行动回合分三步：
1. **回合开始**：触发"回合开始"类天赋效果。
2. **指令输入**：执行一个行动类型（见第五章）。
3. **回合结束**：触发"回合结束"类效果。
某些效果会插入**额外行动回合**（如部分天赋）；额外回合在当前回合之后按规则插入。
### 4.3 K 常量行动制（取代旧"行动权争夺"）
V2.0 废除了旧版"D4 掷骰争夺行动权"与"未行动保底加成"，改为更清爽的 **K 常量行动制**：
- 每个全局轮次，**固定有 K 名玩家获得行动权**：
  ```
  K = max(1, 当前存活人数 − ⟦bal:action_system.k_sitout_count⟧)
  ```
  默认 `k_sitout_count = ⟦bal:action_system.k_sitout_count⟧`，即**每轮只有先攻垫底的 1 人轮空**，其余全部行动。
- **先攻**由 d⟦bal:action_system.initiative_die⟧ + 各类修正决定；行动权按先攻从高到低分配，行动也按此顺序进行。
- **轮空在人数越少时越频繁**：这样可以在决战时为了戏剧性保留足够的不确定，同时加速前期的发育阶段。世界时钟的存在确保了
- **放弃行动（forfeit）**仍是合法选择（主动跳过，无补偿）。
### 4.4 交战与借机攻击
- **交战状态**：两名玩家处于同一地点，且本轮或上一轮之间彼此发生过伤害，即视为"交战中"。
- **借机攻击**：交战中若一方**主动移动**离开该地点，每名与其同地点的交战对手获得 **1 次免费攻击结算**
  （走正常命中/闪避，见第九章；移动者本次不享受移动带来的闪避加成）。每名追击者每轮限 1 次。
- **豁免**：**被动位移**（被击退、被钩索拉拽等）不触发借机攻击。

## 五、行动类型
每个行动回合，玩家执行**一个**行动。可选类型如下。
### 5.1 起床
仅"未起床"者可用，也是其首个行动回合的**强制选择**。起床后该状态永久解除。
### 5.2 移动
移动到任意其它地点（无邻接限制，一次一地）。注意：处于交战中主动移动会触发对手的**借机攻击**（见 4.4）；
被动位移（被击退/被拉拽）不算主动移动。
### 5.3 交互
在当前地点办理该地点提供的事务，统称"交互"：获取物品 / 学习法术 / 进行手术 / 办理通行证 /
补给箭矢 / 修理护甲 / 治疗 / 打工等（各地点供应见第六章，费用见第七章）。部分项目需多个回合完成（进度保留）。
### 5.4 锁定（远程命中前置）
对一名玩家建立"锁定"标记。**锁定不再是远程攻击的硬前置**——弓未锁定也能射，只是命中更低
（见第九章）；锁定 = 拉满该目标的远程命中。
### 5.5 找到（近战前置）
与同地点的一名玩家建立"面对面（交战）"关系，是近战攻击的前置。
### 5.6 攻击
用一件武器攻击一名合法目标（近战需面对面，通用远程需可见）。命中与伤害结算见第八、九章。
### 5.7 射箭（弓）
弓的专属攻击动词，是**唯一的常规跨地点武器**：
- 跨地点合法；**不需锁定**（锁定只加命中）。
- 消耗 1 支箭（无限模块豁免）；射出的箭落在**目标所在地点**的箭堆，可由"找到"行动免费拾回（风险换弹药）。
- 伤害/属性/附带效果由已装的升级模块决定（见 6.2）。
> 例：你在商店、敌人在魔法所。你 `射箭` 跨地点命中（未锁定，吃命中惩罚）；这支箭落在魔法所，
> 谁先到谁能 `找到` 捡走。
### 5.8 钩索
军事基地的神器（全图唯一），科技属性，**双模式共享 ⟦bal:hook.cooldown_rounds⟧ 轮冷却**：
- **拉取**：将任意地点的一名玩家拽到你所在地点，附 ⟦bal:hook.damage⟧ 点科技伤害（走命中/闪避）。
  被闪避（擦钩）= 不位移，但目标本轮全部闪避加成失效。
- **位移**：把自己钩向任意地点。**不触发借机攻击**（机械把你拽走，对手刀砍空气）。
### 5.9 特殊操作
天赋/装备的专属操作，统称"特殊操作"，例如：**蓄力**（给需蓄力的武器充能）、重新展开魔法护盾/AT 力场、
磨刀、释放病毒（在医院）、取消架盾等。具体由你持有的物品/天赋决定。
### 5.10 放弃行动
主动跳过本回合，无补偿（合法选择）。
