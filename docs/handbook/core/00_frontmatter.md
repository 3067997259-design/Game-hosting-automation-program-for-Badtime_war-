# 起闯战争：完全游玩手册 V2.0-exp
> 本手册是**人类玩家的规则说明书**。本游戏已确认完全脱离桌面可演算范围，必须依托电子裁决程序运行；
> 本文件只记录游戏规则、天赋说明、Q&A等基本内容，不含程序内部裁决/AI 实现。设计理由与实测记录见：
> `v2.0_exp_design_draft`。

## 第零章
人子的乐园终将跌入愁苦人世，黎明一旦升起便要坠毁于白昼，凡是金的，怎可能光华长留？
众星属于所有人，便从不属于任何人。若你爱所有人，便不爱所有人。
故⬛⬛将飞上高空，变作天上的太阳。万众在⬛⬛的光芒中热烈生长，而新世界的一切歧途将无所遁形。
## 间章I
之前让几个chatbot帮我读游玩手册的时候，AI大人几乎没有例外地指出：很多元叙事内容被夹杂在了严肃的规则文本里，这虽然是AfterRain的风格，但是非常不利于其他人阅读。就当是为了你不知道有没有的读者，对手册使用信源统一和格式整理吧！（此处自行脑补一个炎拳脸）
所以我想起了间章。正式章节用大型数字编序号，间章用罗马数字编号并随意插在章节之间，这是我写自己的第一本小说的时候在用的格式。可惜，一个从决定动笔的时候就言之无物的作品，最后也只能是写四百字撕掉四百字，最终忍无可忍把撕烂了的本子丢进垃圾桶。唉，那个没有AI的年代，要是写得烂就一点办法都没有。直到我最后彻底放弃整个工作时，GPT也才出到3.5吧，大概一直到4o它才正式开始擅长（情感）写作，只可惜后来又不侧重训练这方面了。
骗你的，现在只靠AI也写不出太多真正动人的东西来，如果没有真正属于自己的体会的话。不过我希望自己一辈子也写不出来这种东西（这是农民工安大爷于2025年7月9日在太原火车站劳务市场参与短视频创作挑战时撰写的作文，这里借来一小段）：
“母亲走的时候才五十出头，是累病的。如今她的坟就在村边，一个不起眼的小土包。每次回村，我总要去那儿站站，跟她说说话。我在城里干了大半辈子苦力，扛水泥、扎钢筋、爬脚手架，手上肩上全是老茧，累是真累。可想想母亲当年端那口大铁锅的劲儿，想想她冻得发抖还咬牙撑到天亮的样子，我这力气就又上来了。……坟头上的草青了又黄，黄了又青，就像我的念想一样，一年年总也断不了。我已经当了爸爸，也已经当了爷爷，但我已经三十多年没叫过妈妈了。我想着，等哪天我扛不动水泥了，就回村里挨着那堆土躺下，没准那时候我再叫妈妈，她就能听见了。”
这才叫文学。话题扯远了。不过就我读的这点孱弱的文本量，我能在V1.96的develop_diary里诌出那个19世纪就被浪漫文学写烂了的开头已经是不容易了。还不如让我整点之乎者也出来，起码小时候真的背过四书。
为什么提到这些呢？因为我必须要从与设计草案不同的角度想想为什么要做这次大型改动。从我第一次在cherrystudio上伪装成一个捡到这份手册的路人问opus4.6“你觉得这份手册作为一个极度罕见的桌游类型写的怎么样？”（我怕它刻意讨好我，听说假扮自己的仇人去问效果会更好）到现在，大概很快就五个月了。直到整个V2.0能稳定落地，或许需要从那天开始需要半年。一般的商业游戏如果半年封测，这个时候大概该公测了。有必要多说点什么。
具体改动太多，建议去看changelog。如果你是从旧版一路玩过来的，那你大概会发现：V2.0-exp 看起来已经不像最开始那个体育课自由活动时间里走出来的游戏了，甚至和星野刚登场时那个已经有一半完全无法靠着纸笔和骰子运行的游戏也大不相同。它的数值模型已经大幅改变（新模参考了Minecraft，这倒是真成了“起床战争”，乐），有信用点，有世界时钟，有综合评分，有死后往世层，甚至还有一堆看起来不像桌游规则、比较像作者瑰夏喝多了或者一口气买了两家的subscribe Plan，嫌token不够烧突然上头了想加的东西。我原来只是怀疑我做的是什么游戏，现在开始一起怀疑我做的是不是游戏了——我可能只是把设计表达欲、文字表达欲和技术表达欲融合在了一起，然后对照九大艺术发现做的东西只能勉强归为游戏而已。
比如我还想加个神代天赋什么的。然后就有足够数量的神代，可以划分成组然后作为扩展独立引入。不过这是后话（真的是后话，预告一行写在Q&A里了）。
是的。我确实把它改复杂了。虽然这个游戏没怎么尊重过至繁归于至简的原则，但毕竟原来底层还是干净凝练的。然而，调整BasicAI和RL的经历让我发现了很多老的设计中的实际问题：行动权饥荒本来以为是“不确定性”的核心，然而事实上“无所事事”带来的坐牢感反而更强，这个游戏还连个前端或者游戏桌布那种堪称前端的东西都没有（尤其是推荐的6人，如果没有朋友一边玩一边聊天的话。在体育课上的时候，我们一般是三人乱斗或者二对二，那时候连D4保底都没有，问题也没这么大），护甲克制直接收益归零（说实在的，这是RL的灾难，奖励信号太尖锐了），警察保护要不然是叹息之墙，要不然人家随便针对就是死（V1.94 orchestra架构引入后，通过逐个枚举植入了一整套反制警察的逻辑。在这之前political胜率最高，生效后暴跌。这个开发思路是很脆弱和不可持续的），残局则经常变成几个人围着地图站梅花桩或者无效攻击——这游戏没毒圈啊，站梅花桩拼毒有个P用。
当然，通过手动设计逻辑，BasicAI仍然可以直接产出精彩的对局（比如我亲眼见证星野扎针=肾上腺素丢闪冲刺架盾，然后下一轮10cost连开七枪硬生生打死满甲队长）
可它们全都是预制好的，星野能打出这样的操作是因为我编码了这样的逻辑和预制的战术宏。如果某一环错了，比如没丢出闪/烟，那么后面七枪的伤害将会被警察保护完全过滤掉。我抛弃了规范性、复杂度和可解释/理解性三条底层逻辑，到底有没有创造真正的博弈深度？或者说，到底有没有创造戏剧张力？一个三阶魔方，历史上或许没有两个人的随机打乱是一样的，但对于一个只会层先法的萌新，每次去玩魔方需要做的都是那几个公式而已。如果每次星野撞到队长都是上药装子弹然后10cost开五枪是一眼可见的最优解，那这个游戏真的有意思吗？
以及最终极的一个问题：
我给玩家设计的胜利目的，到底和他们想做的是否相同？对这个游戏来说，“活到最后”究竟是不是最合适的胜利方法？
AfterRain回顾了他快二十年的人生，发现自己做了半年的游戏，然而一分钟游戏设计课也没上过，连“设计者希望玩家的游玩目标和他们自己的目标应该尽量重合”这句话都是后来才听说的。实在不行大二报个选修去吧。
所以 V2.0 的目标很简单，但很简单不太可能：让底层世界更像一个能承载演出的舞台，而不是每次都靠天赋把桌子掀了重摆。
我第一次用Devin Deepwiki给整个项目做百科时，它对神代天赋给出了一个我很喜欢的定义：“管理复杂资源，且可以剧烈地改变游戏现实的类boss不对称技能或复杂子游戏系统”。
但剧烈地改变游戏现实，需要建立在有“游戏现实”这个概念的基础上，不然就退化为无意义的战力PK。
我希望普通攻击也有意义，希望死亡不是干坐，希望活到最后不是唯一答案，希望那些神代天赋可以更好地服务于终极意义——
但不是全都靠单开一片空间，然后把思考压力转嫁给全桌来任性。
当然，这好像有点太正经了，不像是AfterRain写得出来的东西
但如果你愿意为了一个角色的弧光多读两页规则，多忍受一点机制怪，耐心等待自己的高光时刻，
那欢迎来到 V2.0。
白昼或许已经升起。但还请不要太相信它。
