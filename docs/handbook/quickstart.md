## 新手指南
本章写给第一次坐到桌边的人。不要试图一口气背完整本手册。认真说，这种行为对精神状态不是很好。
你只需要先知道：起床，出门，挣钱，拿装备，找人打架，别让警察把你当成年度工作 KPI，最后尽量打出一点值得被记住的场面。
剩下的东西可以边玩边学。反正电子裁决程序会替你记住绝大多数你不想记住的东西。
### 核心速览
- **行动不靠抢**：每轮你几乎都能行动（K 行动制，见 4.3），不再投 D4 拼运气。
- **钱要出门挣**：家里**不产任何资源**，去商店/医院**打工**赚信用点（七章）。
- **起床第一**：第一个行动回合必须"起床"。
- **怎么打都有效**：HP20 减法防御 + 保底——再厚的甲也至少掉 ¼，没有"打不动"的龟壳；
  属性"硬克制"已废除，只剩伤害高低之分（八章）。
- **死亡不出局**：被杀会**坠入往世层、化作星**，仍能用星光影响战局（十二章）。
- **赢法不止一种**：终局看**综合评分**，"活到最后"只是加分项——战果/喝彩/完结条同样能赢（一章）。
### 推荐流程（骨架）
1. **起床**（首个行动回合）。
2. **出门发育**：去商店/医院打工攒信用点 → 买陶瓷护甲/磨刀石，或给弓买升级模块（六章）。
   家不再是经济来源，记住你的床，但别赖床。
3. **武装**：弓人手一份（起始 ⟦bal:bow.initial_arrows⟧ 箭），是唯一常规跨地点武器；近战需先"找到"。
4. **交战**：同地点"找到"后近战，或"射箭"跨地点（锁定拉满命中）。磨对手的甲就是在烧他的钱——磨甲也是一种打法（七章）。
5. **用天赋**：天赋是你的演出主轴、关键时刻的底牌。
### 天赋选择建议
如果你是新玩家，优先从原初天赋开始。它们的规则也不算短，但至少大多数时候你知道自己在干什么：
想打人选一刀/剪刀手，想要一点玄学和工具箱选六爻，想体验节奏奖励选 combo，想玩秩序和举报选好市民，
想把复活点成桌面笑话选死者苏生。
如果你想第一次就碰神代天赋，可以，但请先确认这一桌不靠这一局建立友谊。
G1 火萤适合想主动进攻、愿意接受后期代价的人；G2 注视适合愿意读舞台规则、并且真的想演一场的人；
G3 神话之外适合想把别人拖进小黑屋重算的人；G4 愿负世适合喜欢绝境反打和背负感的人；
G5 往世的涟漪适合愿意和命运解应用题的人；G6 要有笑声适合想把节奏断点变成笑话的人；
G7 星野适合愿意真的指挥学生作战的人。
以及，原来第一次玩不建议点 G5，不过现在这个游戏只需要让DM当吟游诗人了之后反而不是很忌讳这一点了。
### 常见问题
**Q：我被打到很残怎么办？**
A：生命值降到重伤线（≤⟦bal:hp20.severe_injury_threshold⟧）会承受额外不利（九章）；归零则坠入往世层成星。残血时搏命还是补甲/治疗，自己权衡。
**Q：警察打我，能反杀吗？**
A：能，但袭警本身算犯罪；且 V2.0 警察保护是"每轮免疫小于阈值的单体伤害"，要打穿得靠大单体或 AOE（十章）。
**Q：怎么赚钱？旧版的"购物凭证"（已退役）呢？**
A：凭证经济已废除，改用**信用点**：出门打工、击杀夺财。家不产钱，被动收入被一票否决（七章）。
**Q：天赋能用几次？可以不选吗？**
A：次数见各天赋说明（十三章）。可以不选（白板，规则允许），但建议一桌"要么都选、要么都不选"以免体验落差。
**Q：我死得早，要干等到游戏结束吗？**
A：**不用**。V2.0 死者坠入往世层化作星，每轮获星光、用星光行动（拨弄命运/预兆/加冕）继续左右战局，还能挣往世分计入自己终分（十二章）。
**Q：这个游戏会不会拖很久？**
A：V2.0 针对老版"龟缩/拖沓"做了系统性改造——经济战（修甲烧钱、手术财产税）、HP20 保底（必掉 初始伤害的¼）、
白昼世界时钟（黄昏加伤、终焉每轮真伤的"毒圈"）、综合评分制（"活到最后只是加分项"）合力压缩对局长度，
平均轮数较 v1 **显著缩短**（具体随风洞复核）。
**Q：鼓励玩家交流吗？**
A：鼓励。本游戏近乎完美信息博弈，结盟、劝说、口头约定都随意——边聊边玩。
**Q：无天赋局是什么定位？**
A：仅建议作**初学者入门**。无天赋本体仍有机制残缺（戏剧张力主要靠天赋承载），但老版"极度奖励防御、没有毒圈、终结能力低下"那套老毛病，已被 V2.0 的经济 / 世界时钟 / 综合评分制大幅缓解。
**Q：为什么要做神代天赋？主持难不难？**
A：因为我们想让你成为你喜欢的角色。
这句话听起来很中二，但确实就是答案。神代天赋不是为了把游戏做得更好平衡而诞生的，甚至很多时候正相反：
它们会主动制造复杂度、例外、专属资源、专属结局，逼着底层系统让路。正常项目组可能会把这些东西砍掉，
写成“造成伤害 +2，受到伤害 -1”，然后大家都轻松。
但那样就没意思了。
这个游戏的天赋模式追求的是某个时刻：全桌的目光突然聚焦到你的表演上。可能是火萤 IV 型一穿五，
可能是六爻放逐救世主，可能是舞台终于谢幕，可能是一个死者在往世层把最后一点星光还给活着的人。
胜者当然重要，但真正会被记住的往往是这些场面。
游戏自己难不难？很难说不。启用神代天赋前，请确认大家都知道自己要玩的不是简洁竞技桌游，而是一台会在关键时刻为了角色弧光放弃一部分可理解性的演出机器。
**Q：你顶着这么多技术债还要在2.0上线前再塞一个神代进来？**
A：恭喜你答对了，阿拜多斯双子星我们已经有了星野，为什么不顺手再做一个色彩白字呢？她能挖掘的也很多。
