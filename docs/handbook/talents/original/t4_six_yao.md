#### 4.「六爻」（原初）
一句话概括：什么都会一点，但什么都得看命。
元老级别天赋，比警觉、一刀缭断和死者苏生年轻，比天星和朝阳好市民老的多
让人很难评价的天赋。脸白的时候像全能工具箱，脸黑的时候像你花了一个行动回合证明玄学不可信，即使已经在某个版本中（好像是V1.93 Hotfix）增强了几乎所有子效果。
不过，这个游戏确实需要一点“我也不知道要发生什么”的若干个存在。
- 充能：每 ⟦bal:talents.t4.charge_interval_rounds⟧ 轮 +1（最多储 2）/ 行动回合开始发动 / 消耗回合 / 目标：另一名玩家。
- **效果**：与目标猜拳，按六种组合结算（夺甲 / 获武器 / 获甲 / 全体蓄力 / 2 个连续额外行动 / 清除锁定探测并隐身）。
- **待修 / 待风洞**：「飞龙在天」当前裁决程序复制外层护甲时仍生成 1.0 耐久，疑似新 HP20 体系迁移残留；正式口径以风洞后裁决程序为准。
