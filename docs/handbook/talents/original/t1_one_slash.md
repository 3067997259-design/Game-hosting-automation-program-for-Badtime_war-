#### 1.「一刀缭断」（原初）
一句话概括：你将发动一次很不讲道理的近战攻击。一次？你再看看你后面呢？
本游戏的元老之一，和这个游戏的雏形一起产生。
- 使用次数 2 / 行动回合开始发动 / 消耗回合 / 目标：同地点已面对面的一名玩家。
- **效果**：选一件近战武器立刻攻击该目标；本次**裸伤 ×⟦bal:talents.t1.melee_multiplier⟧、且目标防御减半**。
- 单次主动技的"乘算豁免"；仅对本次攻击生效。
