#### 6.「朝阳好市民」（原初，随风洞最可能机制加强）
一句话概括：你不会真的想得罪一个组织比 FBI 还庞大，且背后不知道多少关系的老大爷/老大娘群体吧？
这个天赋的强度不完全来自数值，而来自它把“秩序”变成了玩家可以操作的武器。别人打架，你报警；别人出门，你记罪；别人以为自己在玩大逃杀，你告诉他这里还有基层治理。很可怕，很现实。
- 常驻 / 自动 / 目标自己。
- **效果**：举报热线（"举报"无需前往警察局）；本局违法名单**额外增加**（进入他人之家 / 进入军事基地 / 释放病毒）；
  竞选队长所需回合 −1。
- 边界：随白昼**黄昏**起警察保护下线、**终焉**警察停摆（见第十一章），但黄昏阶段远程举报与犯罪名单仍有效。
