#### 神代 5.「往世的涟漪」（警告：认知复杂度极高）
全游戏第一个神代天赋，也是口头游戏被重整为规则书时的第一个由我独立设计的天赋。它倒逼整个世界的规则被严谨化，也是我做RL训练的源动力之一。
致敬游戏崩坏-星穹铁道的角色，昔涟。
关于涟宝，其实能说的很多很多，你想做角色鉴赏，她美得发光（真是发光。昔涟一身粉衣服还有渐变粉头发，不白的发光很容易显黑，这不是抹两层腻子能解决的了）；你想做剧情赏析，你会看到哀丽秘榭（直译过来是爱莉希雅的坟墓的意思，md崩三还在追我）姐弟（不是真姐弟啦）如何踏上拯救翁法罗斯的道路，看到负火的囚徒如何在三千万次的永劫轮回中一遍遍为了几乎不存在的天外变量——和希望一遍遍杀死至爱的人，看到小昔涟如何用三千万次如我所书的记忆存档和水晶花的寓言将一颗种子培养为以爱为因，以告别明天、永远走向过去为代价最终改写和锚定了几乎是注定的毁灭结局，让翁法罗斯走向明天的大昔涟——德谬歌。
记得过完3.7剧情我愣了半天。大昔涟和小昔涟原来真的是轮回里的两个世代吗，还有《昔涟》里那句我的明天叫做昨天是人想得出来的东西吗？翁法罗斯一年都在讲“明天见”的故事，然后你给我来个“我的明天叫做昨天”？给你大坝解释一下这是几个意思？包饺子不好吗？
还有网上那些骂昔涟什么不买两千块钱弓皮记忆里就没你的，什么除了爱爱爱一点没有的黑潮造物，过剧情不带脑子还是不带眼睛？我看昔涟就TM多余救你们。你几个趁早进无限轮回里当快乐囚徒去吧，把昔涟放出来。
冷静下来了，对不起，这份手册里不会再有这种攻击性内容了。
所以，在G5的设计里，我提取了“追忆”“爱”“锚定”作为关键词，把时间线本身作为了G5操纵的对象。那时候没有方式二。又有一阵，我想做出记忆里的双排战模式（因为basicAI逻辑太难写而暂且放弃，再次捡起来是G2重置的时候了），再加上锚定是个上下限无法稳定统计的设计，加入了一套独立的强化系统（几乎是直接把作为自机角色的昔涟塞进来了）。
然后我就拿着我回忆里的零散规则和G5的初稿去迫害deepseek V3.2了。它看完“先是大惊，然后不敢相信”（只是玩了个新三国的梗，它至少装得很冷静），然后把五十几条会导致崩溃的边界模糊条件拍到了我的脸上，最后（并不）谨慎地建议我把锚定整个砍掉。我也有点火气上来了，于是把整个规则书重新手写一遍，明确了几十条边界闭合补丁（在这份手册里已经看不到它们的痕迹了，上一个版本可以），然后把锚定的规矩也重新闭合了一次，它这才恭喜我可以撑地了（又是一个新三梗而已）终于设计出一个堪称独特的东西。嗯，无论如何，我还是感谢它的，没有它找茬的话大概不会有这份手册，也不会有后面的整个程序了。还有它的后辈Deepseek V4，在后续的开发工作里也是汗马功劳，真便宜啊。
时至今日，它还是我最得意的设计之一。玩起来的感觉和难度绝对会让人感觉在与命运抗争。
来体验一下昔涟的感觉吧？
- **资源「追忆」**：从三千三百万次轮回的守望中打捞和精心呵护的，存在于过往未来的无数可能性所凝结成的璀璨水晶花碎片。无其他特殊作用。
上限 24。每个 R0 阶段，G5持有者获得 ⟦bal:talents.g5.reminiscence_per_round⟧ 层；特殊情况下：若上一轮G5持有者所在的地点发生喝彩级别的事件，则这一次额外获得 ⟦bal:talents.g5.reminiscence_applause_bonus⟧ 层。首次发动需要追忆达到 24，但只消耗 12；首次之后发动门槛降为 12，上限仍为 24（也就是说，如果一次释放需要消耗24以上追忆，这一局就无法使用了，此处提前点名爱与记忆之诗）。
- T0 阶段，满足释放门槛时，可以在两个释放方式中二选一：**方式一·锚定命运**不消耗行动回合；**方式二·献诗**消耗行动回合。
若已经处于锚定监控期，不能再开下一次锚定；若已经进入 G2×G5 duet，则在结束前不能再发动普通锚定/献诗。
**方式一 · 汝将收梢于花开之时，一如终结诞下起始**
- 选择一个锚定事件：你击杀某玩家、你破坏某件护甲、你获取某个物品/权能、你到达某地点。操作者（短句主语）必须是 G5 自己；不能锚定“我攻击他三次”这种多段愿望，也不能锚定纯概率事件。
- 系统会用锚定评估器计算**命数**：在不受干扰的理想路径里，达成事件所需的最少轮数。可行上限与监控窗口同为 K = ⟦bal:anchor.window⟧。若命数超过 K，则锚定不成立，追忆返还；若成立，系统快照备份 G5 当前状态，并根据「三相的因果门径」公布路径中的一个随机步骤。
- **变数**是目标能挣扎的预算，当前设计公式为 `clamp(⟦bal:anchor.variance_base⟧ + (K - 命数), 0, K - 1)`。命数越短，命运越清晰；命数越贴近 K，目标越容易挣脱。
- **开拓** 被锚定者的反抗：提高锚定路径关键属性的防御、进入能阻断路径的隐身、脱离关键位置、治疗到让路径失效、拿走路径上的有限物品、致残或杀死 G5，都会增加开拓计数。
- **三相的因果门径**：确认锚定有效，监控轮次开始前，系统随机公布锚定路径的一个环节。
- **一如初见的重逢**：倘若被锚定的玩家进行的破坏性行动不止一次，且进行完所有破坏性行动后除了位置，最终状态没有改变（不管出于什么原因，包括捡来的甲被打爆）（其余所有信息都保持相同，包括但不限于装备，金钱，天赋触发情况），则最终统计时开拓计数额外扣除两次。
- **一页永恒的善见天**：监控轮次内，被锚定玩家的隐形和闪避值对发动者无效。
- **诗的「。」，誓约的「∞」**：锚定击杀和护甲破坏的判定成立和结算实现无视所有的、无论来源的防御、免伤、保护、死亡豁免、复活效果。被成功锚定击杀的玩家的HP将在结算时立刻归0且强制判定死亡、不进入往世层，其他可能引入出局玩家额外返场方式的扩展效果也不得生效。
- 监控期结束时，若开拓计数不超过变数，锚定成功，事件自动实现。击杀/破甲类成功后，事件保留发生，但 G5 自身状态回溯到锚定前备份；失败时，G5 可选择回到过去或留在当下。若 G5 在锚定期间死亡，锚定立即失败，不能靠回到过去复活。
补充：锚定一旦成立，实现事件所需的「最少轮数」（命定）及其对应的行动路径即被固化，仅作为判定开拓的基准。发动者无需、也不必在游戏中实际执行这些行动步骤。
- 获取/到达类属于简单锚定：一经提出和判定可行则立刻成功实现，不进入锚定轮次环节。两次成功锚定会点亮完结条：+⟦bal:finale.g5_double_anchor⟧。
