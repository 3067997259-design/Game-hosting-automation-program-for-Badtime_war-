# 0. 设计宪法（一切改动的上位规则）

## 0.1 认知负担三层模型

| 层 | 定义 | 纪律 |
|---|------|------|
| **L1 一眼层** | 状态感知：血条/耐久条/buff 图标/位置 | 做满做足，全部明牌显示，零计算 |
| **L2 口算层** | 行动规划：攻防估算、TTK 推演 | **两步心算法则**：任何常规战斗判断 ≤2 次算术运算 |
| **L3 委托层** | 精确结算：流水线、锚定求解、命中率、安定値 | 机器代算，但**每个惊讶必须能用一句话解释**（算式日志） |

## 0.2 复杂度自背原则

天赋可以给**持有者**增加 L2/L3 负担（那是他买的专家体验），但它暴露给**对手**的一切必须 L1 化
（一个图标、一个数字、一行状态）。每个天赋标注认知评级 🧠×1~3，写进选择界面。

## 0.3 移植七律（v0.2 由六律扩为七律）

1. **乘法变加法**：常驻 ×2/-50% 转平直加减；乘法只允许出现在单次主动技上。
2. **真伤分级制**：真伤仅保留给叙事级效果（诗的「。」、Terror 主炮、元亨利贞穿透判定）。
   其余旧真伤降格为"穿甲"（防御按 50% 计）或高额属性伤害。
3. **0.5 额外生命 ≈ 新体系 2~3 点**；小盾/光环 → 可再生护体值池；自动回血 → 每轮再生率。
4. **外甲=装备**（防御力+耐久，会碎可修），**内甲=身体改造**（永久属性，不会碎）。
   "外层不破不能打内层"规则自动消失。
5. **审计补偿机制**：旧约束（行动饥荒/量化/眩晕回血）催生的补丁（善见天、各类保底），
   新体系下逐个判断退役或转职。
6. **换算不是 ×10**：旧 1.0 HP ≈ 新 20，但 TTK 故意拉长（裸杀 1 刀 → 3~5 刀），因为伤口持久化。
7. **零产出禁令**（v0.2 新增）：承诺出去的主动行动永不结算为零。攻击被闪避 → 擦伤
   （保底伤害，§2.7）；控制被抵抗 → 降级残控（§2.5.1）；钩锁被闪 → 目标本轮闪避加成失效
   （§2.9）。任何能把一次主动行动变成 0 的新规则都必须重新设计为"降级"。
   唯一豁免是叙事级效果——爱愿走关系型豁免条款（见 0.4）。

## 0.4 两条经验法则

- **基于关系的绝对效果**（爱愿）可保留绝对性；**基于属性的绝对效果**（克制全免）必须转数值。
- **AI 钩子代码行数 = 认知负担计量表**：新机制立项时预估钩子规模，超 300 行触发认知预算审查。

## 0.5 稀缺三级制（v0.2 新增）

| 级 | 机制 | 实例 |
|---|------|------|
| **时间稀缺** | 白昼限量营业（每地点每条目每轮 1 次） | 全部地点商品 |
| **份数稀缺** | 全图 ×N 份，抢完即止，死亡掉落回流 | 弓模块 ×2、隐身/探测件 ×2（拍板采用） |
| **神器稀缺** | 全图 ×1，唯一性即身份 | 电磁步枪（唯一震荡）、钩锁（唯一拉拽）、无限模块（唯一无限弹药） |

通则：**神器级允许独特机制，普及级必须走数值化路径。** 想给一个效果做"全场唯一的某某"，
先确认它配得上神器席位；反之，普及型效果不许携带二元独特机制。

## 0.6 两货币纪律（v0.2 新增）

全局可计数货币最多两种：**信用点**（经济通货，占位名）与
**喝彩**（荣誉/元货币，可消耗可计分）。凭证作为货币概念退役；通行证降级为普通钥匙物品。
新系统想引入第三种货币 → 违宪，先砍掉一种旧的。
定名流程（拍板）：代码标识符用 `credit`，用户文本走 prompts.json 以「信用点」占位——
正式定名后改 prompts.json 一处全局生效，不阻塞开发。

## 0.7 控制设计准则（v0.2 新增）

**位置操纵优先于行动剥夺。** 行动剥夺类控制（眩晕/震荡：被控者整轮坐牢）体验最差，
必须稀缺——神器或天赋专属；位置操纵类控制（击退/拉拽/放逐：行动权还在，世界变了）
反制丰富，允许普及。

位移三件套（§2.9）：**推**（弓·冲击）/ **拉**（钩锁）/ **逐**（六爻）。
新增位移效果须先认领家族空位或进扩展素材库。

# 1. 行动系统：K 常量顺序行动制

> v0.1 的"同时秘密承诺制"**废案**。三个理由：① RL 需要信念建模——MaskablePPO 在
> 同时行动+隐藏信息下自博弈不收敛，需走 CFR/ReBeL 路线，工程量另算一个项目；
> ② 热座模式无法做秘密提交；③ 其核心博弈价值（移动/攻击猜心）已被 §2.7 命中/闪避体系吸收。
> 替代方案保留了它的两个真正目标：**全员参与**（K=N）与**隐藏信息**（行动隐匿，§1.2）。

## 1.1 新轮次结构

```
R0  轮次开始结算（钟相变化、DoT、天赋钩子——沿用现有时序框架）
R1  先攻判定：全员掷 D6 + 先攻修正，排名前 K 名获得本轮行动权
R2  警察状态机推进（沿用）
R3  行动阶段：获权者按先攻顺序逐个公开行动（沿用现有 T0→T1→T2 回合结构）
R4  轮末结算（沿用）
```

- **K（行动配额）**：balance.json 常量。K=1 即旧模型的行动饥荒，K=存活人数即全员行动。
  **默认 K = 存活人数 − 1**（拍板）：每轮点数最低者坐牢——保留先攻骰的生死感，
  并为 G6 笑点提供稳定来源；K 是台面上的风洞旋钮，扫 K=1..N 全曲线（§9）。
  所有数值（TTK/治疗/再生）按 K=N−1 的行动密度校准。
- **同点 tiebreak**：同点者之间补掷 D6；再同，先攻修正高者优先。
- **工程红利**：K 模型是现有 R0–R4/T0–T2 引擎的参数化（只改 action_queue 的装填规则与排序），
  不是重写；承诺制则需要新建提交-结算两段式管线。

## 1.2 行动隐匿（隐藏信息的唯一通道）

- 处于隐身状态的玩家，其行动对**缺少对应属性探测**的玩家不可见
  （**复用 `engine/filtered_state.py` 的代理模式而非实例**——该模块的本职是
  G7 闪光弹致盲系统的快照冻结视图；行动隐匿需要的是活数据+行踪裁剪，
  M3 据此新建 `VisibilityProxy`，原致盲系统不动。v0.2 初稿"复用网络层
  filterstate"的措辞有误，联机层并无视图过滤，per-player 联机路由挂账 2.x）。
- 可见性是二元判定：观察者持有与你**任一**隐身件对应属性的探测 → 你的行动对其可见。
  （闪避加成按属性逐条算，可见性一刀切——认知负担分层。）
- BasicAI / RL 必须消费过滤后视图（GameQuery 层做可见性裁剪），**禁止 AI 开图**。
- 日志/回放存全量，显示时过滤。

## 1.3 交战与借机攻击

- **交战状态**：双方同地点，且本轮或上一轮之间发生过伤害（复用现有 in_combat 追踪）。
- **借机攻击**：交战中主动移动离开地点 → 每名同地点交战对手获得 1 次免费攻击结算
  （走 §2.7 命中/闪避；移动者本次不享受任何移动类闪避加成）。每名追击者每轮限 1 次。
- 豁免：**被动位移**（被击退/被拉拽）不触发借机攻击；钩锁·拉己模式明确不触发（§2.9）。

## 1.4 旧机制处置

| 旧机制 | 处置 |
|---|------|
| D4 争夺行动权 | 退役，D4 骰子退役 |
| 未行动保底加成 | 退役（补偿逻辑不再需要）；「未行动」作为**事件**保留，归 G6 笑点经济（K=N−1 下每轮稳定产生一次，§7.6） |
| 额外行动回合 | 保留现有 R3 插入逻辑（顺序制天然兼容） |
| forfeit | 保留为合法跳过（无补偿） |
| 所有天赋 D4/D6 加成 | 统一折算为先攻修正 |
| 起床 | 保留：首轮行动必须为起床 |
| v0.1 承诺制全家（秘密承诺/挥空/偷看承诺/追加承诺/分相位结算备选） | 废案 |

# 2. 数值模型

## 2.1 核心公式

```
HP = 20（全整数体系，量化规则废除）
命中结算 = 见 §2.7（默认命中，概率只来自投资；闪避成功 = 擦伤）
单次伤害 = max(裸伤 − 对应属性防御力总和, ⌈裸伤 × 25%⌉)    ← 保底规则
擦伤伤害 = ⌈裸伤 × 25%⌉（直接按保底结算，不触发武器附带效果 [待风洞]）
外甲每吸收 1 点伤害消耗 1 点耐久（吸收量 = 裸伤 − 实伤）；耐久归零即碎（可修复）
多件外甲共同吸收时（拍板）：按各甲对该次攻击属性的防御贡献比例分摊吸收量，
余数给贡献最高者——L3 代算，算式日志展示明细
```

口诀（L2 教学）："怎么打都至少掉四分之一。"

## 2.5 状态重做

- **眩晕苏醒不再回血**（废除 `hp=min(1.0,max_hp)` 刷新）。眩晕改为来源性状态，
  效果：下一轮只能承诺「苏醒」。
- **重伤**（HP ≤5，**定值线**——拍板：全场一条线 L2 零计算；额外心脏玩家窗口相对变窄
  是内甲的合理红利）：先攻 -2，受 AOE 伤害 +1。`[待风洞]`
- **治疗**：医院条目「治疗」：1 行动 + 2 信用点 → +6 HP。`[待风洞]`
- **病毒**：废除二元即死。释放后第 3 个轮末起，未免疫者每轮末 -3 HP（面具/封闭免疫，
  可靠治疗对冲）。从处决器变成压力钟。`[待风洞]`

### 2.5.1 负面效果抗性（两层制，v0.2 新增）

```
有效抗性 = max(通用抗性, 来源免疫 tag)
通用抗性：0–100 常量（balance.json），管辖行动剥夺类：眩晕 / 震荡 / 石化 / 致盲
来源免疫 tag：装备/天赋的叙事身份（陶瓷-电流、防毒面具-病毒），编译为"对该来源抗性 = 100"
```

- **抗性生效 = 降级不归零**（零产出禁令的控制版）：眩晕被抗 → 下轮先攻 −2；
  震荡被抗 → 本轮命中 −20。`[待风洞]` 100 = 真免疫（叙事级，如 G1）。
- **韧性脉冲**：任何行动剥夺类控制**生效后**，通用抗性临时 +40，持续 2 轮递减
  `[待风洞]`——眩晕链 / 震荡锁的系统性灭绝，不再需要逐个控制源打补丁。
- DoT 类（灼烧/病毒）**不**受抗性管辖：它们是压力钟，各有专属对策（获甲扑灭/面具）。

## 2.7 命中 / 闪避 / 擦伤体系（v0.2 新增）

设计纲领：**默认确定性，概率来自投资。** 香草对砍 = 100% 命中，结算与 §2.1 完全一致，
零新增认知；命中骰只在有人为可见性/机动经济掏过钱时出现——复杂度自背原则的落地。

```
基础命中：同地点攻击 100；跨地点攻击 −15（锁定状态抵消）           [待风洞]
闪避来源（可叠加）：
  主动移动（本轮）           +15                                  [待风洞]
  隐身件（对应属性的攻击）    +25                                  [待风洞]
  天赋/状态修正              各表自带
总闪避上限 60 ——"打不中的龟壳"违宪（零产出禁令）                    [待风洞]
闪避成功 = 擦伤：伤害按 ⌈裸伤×25%⌉ 结算，永不为零
```

涌现性质（免费送的，不用调参）：对重甲目标，命中与擦伤的结果本就趋同（都在保底线附近）——
**护甲是坦克的防御，闪避是轻装的防御**，两套防御天然不叠乘，不存在"高甲高闪"恶性组合。

**属性分轨**（与护甲表的主防/副防同构——减伤三角、闪避三角、命中三角叠成完整属性纵深）：

| 属性 | 隐身件（+25 对应闪避 + 行动隐匿） | 探测件（+15 对应命中 + 反隐 + 火控） |
|---|---|---|
| 普 | 隐身衣（商店） | 热成像（商店） |
| 魔 | 隐身术（魔法所） | 探测魔法（魔法所） |
| 科 | 隐形涂层（军事基地） | 雷达（军事基地） |

- **对位规则**：属性 X 探测 = 己方 X 属性攻击 +命中，且**无效化目标的 X 属性隐身**
  （闪避加成与行动隐匿一并失效）。
- **探测是双职业**：反隐 + 火控（喂弓/高斯/电磁的跨地点与精确命中）。军备竞赛空转均衡
  （"全员隐身+全员探测 = 机制等于不存在"）被三重保险拆除：
  ① 数值化组合博弈——覆盖选择跟随局内 meta（"这局杀手都用科系 → 买隐形涂层"），
  全覆盖需 6 次购买且对手换武器属性即落空，理性策略是选择性覆盖；
  ② 份数稀缺——每种 ×2（拍板采用），全员均衡在物理上不可能；
  ③ 探测双职业——哪怕全场无人隐身，探测也不是死投资。
- **锁定**降格为命中 buff：不锁可射（−15），锁定满命中；锁定持续至目标更换地点 2 次。`[待风洞]`
- **远程暴露**：被跨地点攻击命中/擦伤 → 受害者得知射手身份；若射手对受害者处于行动隐匿
  → 仅得知来袭属性。**匿名冷箭归因（拍板）**：匿名冷箭不可被举报（信息不足）；但任何
  在场玩家（含受害者）持有对应属性探测即可正常举报——**探测的第三职业：目击者**。
  刺客 build 成立，对策明确（买探测），被 3 箭经济自限。
- **L1 委托**：裁判直接显示算好的命中率（`对 影：命中 75`），概率计算全部委托 L3。

# 4. 胜利系统：综合评分制

> 活到最后只是加分项。终分公开揭晓于终局（中盘只见组件不见总分）。

## 4.1 总公式

```
终分 = (剧情分 + 喝彩净值 + 战果分) × 存活系数 + 往世分
存活系数：终局存活 ×1.5；中途死亡 ×max(0.5, 存活轮数/总轮数)
往世分：死后以星身份挣得，固定 ×0.5 折算
```

**战果分（拍板）**：每击杀 +3；每累计造成 20 点有效伤害 +1（上限 +5）`[待风洞]`——
伤害线给「打了 8 刀被收头」的玩家保底回报，抚平收头吸血鬼矛盾；机检零成本（伤害量本就在统计）。

## 4.2 喝彩（两用资源：可消耗 / 余额计入终分）

获取事件（每类每局限 1 次，仅收录可机检事件）`[待风洞]`：

| 事件 | 分值 |
|---|---|
| 首杀 | +2 |
| 重伤（HP≤5）状态下完成反杀 | +3 |
| 打破满配（3 外甲）目标的最后一件外甲 | +2 |
| 用仅剩最后一次的限定天赋完成击杀 | +2 |
| 用最后一支箭完成击杀 | +2 `[待风洞]`（v0.2 候选） |
| 锚定监控期内反杀 G5 | +3 |
| 在终焉阶段完成击杀 | +2 |

消耗用途：重掷先攻骰（1 点）/ 单次伤害 +2（1 点，作用于**裸伤**——拍板：被防御正常消化，
对重甲收益自动衰减，与荧光棒 +2 同价对齐）/
**偷看下轮先攻顺序（1 点）**（v0.2 替换已废案的"偷看承诺"）/ 抵消一次犯罪记录（2 点）。`[待风洞]`

反合谋三闸：每类一次；对抗性事件要求目标"非自愿"（本局对你造成过伤害）；

# 6. 经济与地点（v0.2 全面重写：信用点制）

> 凭证二元经济被 v2.0 自己长出的消耗层（箭矢/修甲/治疗/模块）判了死刑——
> "资格开关"只能回答够不够格，回答不了值多少，无法为可重复消耗品定价。

## 6.1 四地点经济（信用点只替换凭证通道，定价范围比直觉小得多）

| 地点 | 支付物 | v2.0 处置 |
|---|---|---|
| 商店 / 医院 | **信用点**（占位名） | 唯一重定价区（约 12 件商品 + 新消耗品） |

## 6.2 收支结构三原则（反龟缩的真正杠杆，比货币粒度重要）

1. **禁止被动收入，禁止 home 产出。** 每轮自动 +X 一类设计一票否决。收入必须出门：
   打工（商店/医院，+2 信用点/次 `[待风洞]`）。旧 home 免费凭证——龟缩经济的心脏——废除。
2. **战斗 = 收入 + 对手的支出。** 击杀掉落含死者钱包；反向回路更重要——
   **修甲收费让攻击变成经济战**：对龟壳的每一刀（磨 ~5 耐久）都在烧他的钱包，
   打不死你，但打得你破产：龟壳的打工收入被迫全填修甲，发育归零。
   防御第一次有了**经常性开支**（旧"修复=纯时间成本"的平价是龟缩毒瘤的另一半）。
3. **手术 = 财产税**：手术费 = 全部信用点（下限 4）。内甲堆叠的进度阀门原样继承，
   语义更顺——倾家荡产换永久改造。

## 6.3 价格表草案（全部 `[待风洞]`，进 balance.json）

```
收入（faucets）：打工 +2（商店/医院） │ 击杀夺财（死者全部信用点）
支出（sinks）  ：箭 ×2 = 1 │ 修甲 +6 耐久 = 1 │ 治疗 +6 HP = 2 │ 防毒面具 = 2
                磨刀石 = 2 │ 小刀 = 1 │ 陶瓷护甲 = 3 │ 隐身衣 / 热成像 = 3
                力量模块 = 3 │ 无限模块 = 4 │ 手术 = 全部（≥4）
```

balance.json 设 `economy.faucets` / `economy.sinks` 两个分区，通胀失衡一眼可见。

   配合加权预算制：移动 0.5 / 持久反制配置 1.5 / 控制 G5 1.5 / 隐身（无探测）1.0；
   变数 = 2.0 + 0.5×命定 `[待风洞]`。可行性求解器（≤5 理想回合）**不动**。
2. **善见天 v3**（随承诺制废案二次转职）：新·善见天 = **锚定监控期间，目标的行动隐匿与
   闪避加成对 G5 无效**（永远被注视——比"看穿承诺"更贴叙事）。对价：监控状态对目标明示（L1 图标）。
3. **追忆新水源**：每轮基础 +1；所在地点每发生一次喝彩级事件额外 +1（打捞名场面的记忆）。
4. **诗的换算**：爱与记忆之诗 n 段 ×5 点（科/普/魔依次，第 4 段起为真伤）；
   诗的「。」原样保留（真伤天花板）；爱愿保留绝对性（关系型豁免条款）。

### 7.6.1 T5 combo 重做定稿（音游谱面，§7.6 拍板 2026-06-20）

**为何重置（不是迁移）**：旧 combo 计"连续 3 轮**获得行动权**"，在 K=N−1（每轮只有先攻垫底一人不动）
下几乎恒真，计数器形同虚设。曾考虑改判"连续 3 轮**有效行动**"，但"有效"要区分命中/擦伤，
得在 action_turn 埋命中检测管线，技术债重。用户拍板：**行动值已不稀缺，没必要在"行动"概念上死磕，
直接回归 T5 的本体——音游**（手册 lore：「锁屏可打」「感谢 Auto Play 先生帮我又拿下一首 FC」
「特殊效果：手感火热」）。

**核心形态（谱面 Chart）**：每隔 `N` 全局轮（balance 全局变量，2.0 轮速远快于旧 90+，N [待风洞]），
系统给 T5 发一张**有序谱面**：1–3 个音符，每音符 =（动作大类 @ 拍点轮）。谱面**提前完整公开**
（遵循公开原则；且把"没靶子→被迫 Miss"的 RNG 惩罚变成**预读谱面+提前走位/备料的策略 puzzle**——
这正是音游玩家的脑回路：背谱、提前预判）。

| 维度 | 定稿 |
|---|---|
| 音符池 | 常规 4 类：`move / attack / interact / special`；`police` 仅在发谱时 T5 当前已有 police 动作可做（是队长 / 场上有犯人可举报）才作**条件高价值音符**塞入，非队长永不被强塞 |
| special 可凑性 | 已核：`蓄力`(持蓄力武器)/`吟唱魔法护盾`·`展开AT力场`(护盾破后重展)/`磨刀`/`释放病毒`(医院)/`取消盾牌`——均非 G7 专属，配合提前展示可备料凑出 |
| 命中口径 | **做了该大类即命中**（读 `last_action_type` 映射大类，**不判成败/擦伤**——音游判按键时机非角色打中没打中，且甩掉命中检测技术债） |
| 判定 | 拍点**当轮**做对大类 = Perfect；**±1 轮**（早/晚，可给"快了/慢了"文案）= Good；窗口外或做错大类 = Miss |
| 顺序 | 音符按拍点时间有序排开；**不因"做的顺序错"判失败**，只因"该拍没做对大类"判 Miss |
| 结算 | 全 Perfect = **FC（全连）**→顶档；0 Miss（全 Perfect/Good）= Clear→中档；有 Miss 有命中 = 残档；全 Miss = 无（**失败无惩罚**，照搬音游） |
| 奖励 | 按档给"**手感火热**"状态：临时 ATK + 小回血 +（**仅 FC**）一次追加行动；全部 balance.json talents.t5 [待风洞]；story_score 随 Perfect 数走 m6_scoring 门控（同其它完结条） |
| 边界 | T5 恰好垫底那拍无法行动 → 该音符 Miss（±1 窗口已软化）；幻想乡压制（`_mythland_talent_suppressed`）时谱面暂停/作废；**追加行动里的命中不喂谱面**（防 combo→追加→再 combo 无限链，CLAUDE.md 明令）；保留献诗钩子（G5 暂缓但不破坏 `activate_poem_bonus`/`trigger_threshold`） |

**实现纪律**：全程 `m7_talents` 门控（off = v1 字节不变，旧 combo 行为原样保留）；纯 `BaseTalent` 钩子
实现（on_round_start 发谱/到点发新谱、on_turn_end 判音符、on_round_end 关窗+结算），不碰不可触碰区；
数值全进 balance.json talents.t5 附 [待风洞]；面向用户文案走 prompts.json（用户填）；验收用
`--force-talent combo` 探针 + 单测，**不看混局胜率**（v1 AI 不会读谱，真实强度待 M8 AI 重写复核）。

## 11.6 BasicAI 战力公式重导出

旧常数（`hp*10 + weapons*15 + ...`）全部失效。新模型评估更简单且连续：

```
有效HP ≈ HP + Σ耐久 × 平均吸收率 + 防御力 × 预期受击数
威胁度 ≈ max(裸伤 − 我的对应防御, 保底) × 命中期望 × 攻击可达性
```

红利：硬克制消失 = 评分函数的 `-50 被克制` 悬崖消失，目标/武器选择变为光滑函数；
命中/闪避作为乘子进威胁度，连续可导。
K 顺序制与现有回合制决策**同构**——无需对手预测模块（承诺制废案的 AI 侧红利）；
StageAI 的 `assess()` 框架直接复用（它已经会玩全员行动制）。
新增决策域：模块配置选择（按局内 meta 调整 = 读对手武器属性分布，GameQuery 现成）、
弹药管理、钩锁双模式择机。
注意：GameQuery 必须消费行动隐匿过滤后的视图（§1.2），禁止 AI 开图。
