## 一、定位与叙事轴

- 原型：小鸟游星野（《Blue Archive》Vol.1 第 3 章）——「大叔我啊，剪短发了」；
- 叙事：铁之荷鲁斯 = 梦前辈的遗物；色彩 = 幸存者愧疚；自我怀疑 → Terror = Vol.1.3 的
  崩溃反转；G5「守夜人」之诗 = 唯一救赎；
- 定位：战术压制角色；SP 与 Cost 咬合保留，2026-10-26 已同步防御层级、T0 配额与
  Terror 预警/致死合同，旧接口不能覆盖本次决议。

## 二、融合装备与光环（继承 M9）

- **铁之荷鲁斯（盾）**：第一次同时持有盾牌 + AT 力场时自动融合（一次性）；初始/最大耐久
  12；受损后 `special 修复 <盾牌/AT力场>` 占 T1、消耗 1 件组件修复 4（已破碎的组件也行）；
  商店普通修甲不修它（DEC-062）；自动修复量为 0；
- **荷鲁斯之眼（枪）**：第一次同时持有电磁步枪 + 高斯步枪时自动融合；弹匣上限 8；
  一次射击耗 1 发并分成 3 弹丸，基础总伤害池 4，分 2/1/1；子弹可为科技/魔法/普通；
- 双融合完成 → 自动习得战术指令 + **2 次自由配发**（每次可选 1 战术道具 / 1 药物 / 2 发子弹）；
- **光环**：3 层可再生的有限护体值，在主动屏障之后、普通外甲之前，挡多少扣多少，
  耗尽后的余量继续结算；每层2、初始1层，未交战R4总池回1，战斗内自动恢复0，不能一层吞任意整击。
  三层首次全亮 → 一次性【战斗续行】免死（HP6、光环清空）；
  Terror 形态下不生效；属基线铁律 6 Death Gate 的 Morph 层。

## 三、Cost 与战术宏（继承 M9）

- **Cost**：初始/每 R0 回满基础上限6；**失却汇流成泉**：上一全局轮次使用过战术宏 → 下个 R0
  回满后 Cost −1（不叠加）；肾上腺素覆盖；
- **战术宏**：T1 `special Hoshino` 进入，占一个标准根行动（复合根容器）；只要 Cost ≥ 1 即可
  进入，**不耗 SP**；逐步执行并扣 Cost，某步不足即中断，已执行步骤不回滚；内部步骤各自
  结算合法性/犯罪/关注/命中，整个宏只登记一次根收尾与系统收尾（DOC-044 口径）；
- 宏动作表（继承 M9）：架盾 2 / 射击 2 / 重新装填 0 / 持盾 1 / 投掷 1 / 服药 0 / 冲刺 1 /
  取消 0 / find·lock 1 / 转向 0 / 排弹 0；
- **架盾**（三层漏斗 Barrier 层，DEC-015–016）：划分正面/背面；取消低伤免费格挡
  阈值，每次成功格挡正伤害都按来袭伤害扣盾耐久，最多扣尽。破盾这一击仍完整拦截，
  之后失效；不扩大原本拦截范围，也不阻止明文绕过屏障的攻击。正面敌人正常离开需多花
  1 回合；架盾期间 G7 无法 move；每 R4 维持1 Cost（水着-Shielder 免费，但受击仍扣耐久）；
- **持盾 / 被动保护（DEC-019）**：未架盾的铁之荷鲁斯按普通外甲属性减伤与耐久计费，
  持盾只提高属性防御，不另建耐久吸收池，不吞破碎余量，不保留永远剩一点耐久的将破线。
  与其他普通外甲同击择一；免费切姿态不修甲。光环按 §二承接，不复制主动架盾特权；
- **临战-Shielder 突击**（对齐基线三态感知）：持盾冲刺到目标地点后——显形目标直接指定、
  隐身目标需 `find` 成功——即可自动冲击并震荡目标，随后进入架盾。

## 四、战术道具与药物（继承 M9）

- 道具（军事基地获取）：破片手雷 / 震撼弹 / 闪光弹 / 烟雾弹 / 燃烧瓶；
- 药物（医院获取，基线铁律 7 菜单保留）：EPO（Cost +1）/ 海豚巧克力（回 1 层光环）/
  **肾上腺素**（全局 1 次，宏外注射占本回合 T0；下个 R0：Cost 回至临时高上限 +
  光环全恢复 + **先攻 +3**——旧 D4+3 对齐新基线；覆盖失却汇流成泉）。

## 五、SP 接口（本次修订核心：SP 与 Cost 咬合）

### 5.1 1 SP 即演式宣言【大叔的午休】（T0，不占 T1）

- 入口：T0 宣言，耗 1 SP，**不占 T1 主行动槽**（同 G1 着装宣言口径）——眯一觉、换个插板，
  T1 照常开宏；
- 效果（二选一）：
  1. **紧急包扎**：立即恢复 2 HP（使用前 HP≤半最大值则为3）；并清除下轮 R0 的「失却汇流成泉」惩罚
     （睡饱了，不算疲劳）；
  2. **更换防弹插板**：尚未破碎的铁之荷鲁斯耐久 +2（或恢复 1 层光环）；不能从耐久0复原盾，
     破盾须用组件和T1修好，再另行架盾；并向荷鲁斯之眼免费压入
     2 发普通子弹（为 2 SP 全弹倾泻备弹）。

### 5.2 2 SP 公演【荷鲁斯之眼·全弹倾泻】（三形态本命大招）

- 前置：持荷鲁斯之眼且弹匣内 ≥ 1 发子弹；
- 入口：2 SP 公演（占 T1；支持基线崩铁式插队夺台；打开魂援/PP 调用点）；
- 消耗：2 SP + **倾泻弹匣内全部剩余 N 发子弹**——N 越多大招越强；自动取所倾泻子弹中
  最优属性结算属性克制双倍碎甲（基线铁律 6）；
- 按当前形态释放本命大招：

| 形态 | 大招 | 效果 |
|---|---|---|
| 水着 / 常态-Shielder | EX【战术镇压】 | 强制将当地所有单位划入正面并直接进入架盾（没有完好的铁之荷鲁斯则不架盾，DEC-057）；对正面全体扇形轰击（随 N 增伤）并施加震荡；N ≥ 4 时可对 1 名主目标挂 `ACTION_SUPPRESSED` 压制 |
| 临战-Archer | NS+EX【集中突破】 | 第一段：弹匣扇形四连喷，对当地全体挂脆弱（易伤 + 外甲磨损增加）；第二段：对主目标 1 发**无视 Barrier** 的穿甲点射，命中后范围爆炸波及当地全体（随 N 增伤碎甲） |
| 临战-Shielder | EX【加强防御态势】 | 可免费跨地冲刺至任意公共建筑（或原地）；落地重砸进入强化架盾（立即恢复铁之荷鲁斯耐久 + 按 N 获得防弹 Barrier；尚未合成铁之荷鲁斯则不架盾，DEC-057）；落地冲击当地全体敌人并施加震荡 |

## 六、色彩、自我怀疑与 Terror（继承 M9）

- 色彩：每有 1 名玩家出局 +2；由 G7 击杀额外 +2；**G0 撤退按"玩家出局"计入 +2**
  （M9 §2.6 口径保留）；
- 色彩 6：自己 T0 可选进入自我怀疑；
- 色彩 10：本体受非致死 HP 伤害 → 恢复穿戴过且已破碎的护甲 → 强制自我怀疑 →
  完整跳过下一标准槽 → 反转为 Terror；额外回合不能代缴，普通压制不能无限推迟转化；
- **Terror**：Cost 为 Null；失去战术指令/道具/药物/铁之荷鲁斯/光环；只能 attack 或 move；
  进入时护甲/光环/铁之荷鲁斯折算额外生命（保底12、上限20，公式见手册 §17.12）；攻击 = 荷鲁斯之眼对全图所有**其他玩家单位**
  分别造成4点 `DIRECT_DAMAGE`，仅 HP 真正归零的致死结果附 `absolute_death`；不是
  命中即删人。全图不穿 G3 隔离边界；首次攻击只能在跳过标准槽后的后续标准槽，不能
  以 ExtraTurn 抢跑。结算后扣 6 额外生命（全歼他人可免代价取得战场胜利，综合评分另算）；
  移动后扣 2 额外生命；无法被举报，警察拒绝攻击/靠近/移动指令；不参与即演/公演；战斗续行不生效。

## 七、三形态与更衣

- **水着-Shielder**：起床获得盾牌；架盾每 R4 免费维持；
- **临战-Archer**：连续射击——每 2 次付费射击后立即追加 1 次免费射击（不耗 Cost/子弹、
  弹丸不飞散、附带破甲损失）；计数跨轮跨宏持续，只在非射击攻击或换形态时重置；
- **临战-Shielder**：起床恢复 1 层光环；持盾冲刺 + 冲击震荡 + 架盾（§三）；
- **起床收益（对齐方案 A）**：R1 私人房间 T0 免费起床领初始包，同时自选初始形态（DEC-057）；水着起床得盾、临战-Shielder
  起床回 1 层光环，临战-Archer 无起床收益；临战-Archer 旧「起床衔接」（起床槽内多选一）随方案 A 退役
  （R1 T1 全员本就 move 出门），保留连续射击计数不因起床重置；
- **更衣**：原「在家 special 更衣花 1 回合」随方案 A（无私宅）退役；改为任意公共建筑
  **T0 小动作**切换形态（整局最多2次，同轮不可再次更衣），不重新获得起床收益。

## 八、G0 / G5 联动

- **G0（黑子）阿拜多斯羁绊**：G0 挂着「星野的防爆盾牌」与 G7 同地时共鸣加成（G0 RFC §三）；
  G0 撤退 → G7 色彩 +2（§六）；
- **G5「守夜人」之诗**：保持手册救援版原文——色彩置 null；若在 Terror 则解除并把剩余额外
  生命转永久生命；恢复战术指令/药物/装备可用性与光环；恢复的铁之荷鲁斯不重新触发融合。
  与 G1「飞萤」诗共同构成"绝境必死态（Terror / 繁育）的唯一救赎"轴。
- 献诗须展示永久改造并由 G7 主动接受；拒绝不退款，永久效果不重复叠加。
