## 一、定位（生态位）

- 欢愉/阿哈/花火：**活人之间的恶作剧、替身嫁祸、当身博弈与全员惊喜礼盒**；
- 与相邻系统绝不撞车：
  - 往世层 Encore = 死者托付本命技能（悲壮传承）；
  - G0 = 阿拜多斯同伴遗物与 AR 火力（战术枪战）——遗物/捡拾叙事优先归 G0，G6 让位于 G0；
  - G6 = 把别人的回合剪成喜剧的导演 + 当身恶作剧 + 遥控惊喜礼盒（拱火嫁祸与读心博弈）；
- 不参考老板等反派做参考——G0~G7 无一反面角色。

## 二、常驻被动【看热闹不嫌事大】（笑点）

- 场上出现闪避成功、普通外甲破碎、实际放弃行动槽、有人拆盒等场面 → +1 枚笑点；
  旧攻击落空映射为闪避成功（包括造成 HP 擦伤），非法指令/A=0/普通屏障拦截不算；
- 每个根行动至多一次被动笑点，首版每全局轮最多获得 3 枚；献诗置满另算。当身成立
  本身不返还架设笑点，不能用自己的玩偶消失冒充普通破甲；
- N0 初始笑点 1；自己主动放弃行动的收益为 0，他人主动选择放弃仍 +1；硬控跳槽不算
  主动放弃，避免自行返还当身费用或把反击震荡自动换回成本；
- 笑点 = 假币：执行 `interact`（购物/治疗等）时每 1 枚笑点抵扣 1 信用点；上限 3。

## 三、T0 小动作【替身玩偶·假面当身】（当身技，高风险高回报）

- 入口（DEC-043）：T0 小动作 + 1 笑点，不耗 SP；持续至自己下个回合开始前；
- **成立**：窗口内第一段以 G6 为目标的合法单体攻击进入结算 → 玩偶吞掉这一段
  （伤害、破甲和附带效果无效）→ 攻击者承受 3 点烟花直达伤害 + 震荡。
  不吞整条连段，不拦范围攻击、DOT 或环境伤害；后续段正常结算；
- SP 只按关注上限结算，本轮额度已用就不再送 1 SP；成立不返笑点。读空时 T0 与
  1 笑点已经付出，不退款；欢愉诗也不取消架设成本。

## 四、1 SP 即演【插入式笑话·移花接木】

- 入口：耗 1 SP、占 T1，指定 1 名其他存活玩家 X 为「冤大头」；**同一玩家不能连续两轮被指定**；
- 二选一：
  1. **刷他的卡**：以 X 所在建筑菜单隔空执行一次 `interact`（装备/物品归 G6）；费用优先
     从 X 钱包强划（至多其实际持有的 2 信用点，不制造负债），不足部分由 G6 自付或
     用笑点抵扣；无法补齐则预检失败，不扣任何一方费用；
  2. **借他的刀**：以 X 的位置与视野、用 G6 自己的武器（或 X 的基础武器面板）攻击与 X
     同地的目标 Y——伤害/破甲/击杀归 G6；犯罪案底/通缉可嫁祸 X，但直接反击追向
     实际施术者 G6。使用 G6 的真实武器资源或 X 的基础武器面板，不消耗 X 的弹药/
     专属次数，不复制技能、宏或连发；所有射程、视野、隔离条件仍须预检。

## 五、2 SP 公演【全员派奖·超大惊喜礼盒】（可崩铁式插队夺台）

- 入口：2 SP 公演；向场上所有其他存活玩家各塞一个超大惊喜礼盒。已有未拆盒时
  保留原盒与进度，不立即引爆，不延后原期限；每人至多持有一个未拆盒。

### 5.1 拆盒规则（额外的 T0 抉择）

- **路径 A（自己拆）**：持有者花自己的 T0 小动作拆开 → 从【六面礼盒池】等概率随机 1 项
  生效（无论大奖还是惊吓，都登记拆盒事件；笑点仍按 §二每根/每轮额度）；
- **响应窗口（DEC-045）**：持有者必须先得到一次能够自主选择的 T0；被压制或失神
  而没有该窗口不算拒拆。该机会之前 G6 不能代拆；首次窗口内可选择自己拆或保留；
- **路径 B（花火代拆）**：获得上述窗口后仍不拆 → 轮到 G6 回合时，G6 可花自己的 T0 指定 1 名持盒
  玩家，从 4~6 号负面效果中**钦定 1 项**对其生效；
- **兜底**：从首次可选 T0 机会之后计两个未来 R4（机会当轮不 tick），仍未拆则随机
  结算 4~6 号负面之一。重复塞盒不重置此计时；不存在可选窗口时不偷跑兜底。
