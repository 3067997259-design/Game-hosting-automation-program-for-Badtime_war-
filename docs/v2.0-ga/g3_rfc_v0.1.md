# V2.0-GA G3「神话之外」RFC v0.1

> **Profile 代号**：`V2.0-GA` ｜ **状态**：候选机制与 N0 初值已填，未实战验收 ｜ **日期**：2026-10-26
> 继承：M9 G3 v0.3 与《连续投影合同 v0.1》的灵魂（投影魔术 / 见证复制 / 固有结界 / 锚点破界 /
> 宝具连发 / 赤原猎风 / 幻想崩坏）；本文按 2026-10-24 设计会话做 **4 刀减负与基线对齐**。
> 上游：[baseline_rfc_v0.1.md](baseline_rfc_v0.1.md)。

## 一、定位与叙事轴

- 原型：英灵卫宫（Archer）的投影魔术与固有结界——「神话之外」= 无限剑制；
- 母题：以魔力换取时间；剑之丘陵的持续齐射，不是一发爆气；**见证理想燃烧的地狱，
  就是被从舞台上刮落（赤原猎风削 SP）**；
- 4 刀减负（对应 M9 病灶）：
  1. 结界外投影不再占整轮 T1（T0 `Trace On`），并补上 1 SP 即演；
  2. 展开即剑丘（剑阵自动常驻 + 兵装池免创建取用）；
  3. 理想燃烧与宝具连发直连（取消"打卡凑式样 ID"）；
  4. 七重圆环/幻想崩坏对齐三层防御漏斗。

## 二、魔力与 SP（职责分离，继承 M9）

- **魔力**：支付投影、维持与超限；**SP**：决定何时展开固有结界——两者不互相替代；
- 首轮魔力：开局 6、常规上限 8、结界外每 R0 恢复 1（唯一常规恢复入口）；
  医院手术三「不老泉·内循环炉」的代价减免
  对接魔力恢复；
- 展开结界扣 2 SP 后建立 4 点临时超额魔力；普通魔力先付、临时后付；
  结界结束时临时魔力清零。

## 三、结界外投影（T0 减负）

- **`Trace On`**：非攻击型持续投影（七重圆环 / 双刀·守势 / 复制武器创建）为
  **T0 小动作**，支付对应魔力，**不占 T1 主行动槽**——T0 撑好防御或抄好武器，T1 直接开火；
- 攻击型投影仍为 T1 攻击根：
  - **投影箭矢**（M9 称「螺旋剑（伪）」，DEC-059 改名）：远程攻击根，创建并立即发射（形态冻结，不支持蓄力）；
  - **双刀·攻势**：近战攻击根，以所选合法近战武器为基础 + 固定加值；
- **双刀·守势**：T0 建立防御标记，下一次以 G3 为目标的攻击取得固定减伤后消耗
  （命中/未命中/A=0/AREA 均消耗；`DIRECT_DAMAGE` 消耗标记但跳过该减伤）；普通
  伤害中该固定减伤按基线 DEC-011 先于外甲计费，不能让外甲重复支付已被它挡住的部分；
- **七重圆环（Rho Aias）**：T0 展开，登记为基线铁律 6 的 **第 1 层 Barrier**——
  远程直接攻击先打圆环，击破当次不向本体溢出；同单位至多一层掩体；
- **见证与复制**（继承 M9）：见证过的普通武器家族可付魔力投影基础型（只复制基础伤害/
  属性/射程，不复制模块/弹药/蓄力/专属标签）；结界外复制品 ×`outside_copy_ratio`；
  复制品不可交易/拾取/掉落；N0 白名单为手册 §17.2 的普通实体武器，不含法术/钩索/融合品/神器；
- 结界外只维持**一个持续投影通道**：新 T0 投影预检成功后，旧持续投影在该回合收尾时清理。

## 四、1 SP 即演（补上 M9 的空缺）

- **鹤翼三连（近战双刀）**：耗 1 SP，本次双刀攻击获得固定加值；命中目标外甲时触发
  连携追击——额外磨损目标外甲耐久且必中；固定磨损部分按基线 DEC-012，在本击扣血
  与普通外甲计费确定后结算，不反向增加本击扣血、不把余量转移到另一件甲；
- **伪·螺旋剑（远程狙击）**：耗 1 SP + 魔力，跨地点轰出一发**无视掩体/屏障**的高爆
  穿甲螺旋剑。

## 五、2 SP 公演：无限剑制（崩铁式插队展开）

- 入口：2 SP 公演，支持基线崩铁式插队夺台；当前地点被替换为固有结界；
- **展开即剑丘**：剑阵**自动常驻**（G3 攻击获命中加成 + 每轮第一次以 G3 为目标的远程
  直接攻击被剑阵 Barrier 拦截）；**已见证的复制武器自动进入兵装池**，随取随用、
  免创建行动与魔力；
- 捕捉：当前地点全部存活玩家 + 敌对/中立 NPC；警察不进入（案件挂起）；外部世界继续
  推进；内外不能跨边界交互；新到原地点者留在结界外；
- **主目标**：展开后公开指定 1 名存活被捕捉单位（幻想崩坏的唯一合法目标；每个 T0 可
  免费改选，属于必要回合设置，不占唯一小动作；死亡/离界即清空）；
- **结界锚点与破界**（继承 M9）：被困者可用普通武器攻击根打锚点（按 A 扣结构耐久），
  或 `break_barrier` 稳定扣耐久（占整个标准行动）；锚点归零 → 强制解除，未行动者
  回原地点后仍按原顺序行动；
- **维持费简化**：每未来 R4 支付 1 魔力，最长 3 个未来 R4，建立轮不 tick；
  不再使用 M9 的五项加法公式。

## 六、理想燃烧、宝具连发与赤原猎风

- **`projection_chain` 宝具连发**（继承连续投影合同）：结界内投影箭矢或伪·螺旋剑的根行动首发结算后，
  可支付递增魔力在同一根行动内连射（含首发至多 3 段，常规费用 2/3/4）；每段独立预检/结算，责任归 G3；
  整条连发只记一次根收尾；连发白名单仅投影箭矢与伪·螺旋剑（DEC-049/059），复制武器不加入；
- **公演插队边界**：受击者在连发中满 SP 只能申请夺台，不能打断连发、衔接的幻想崩坏
  或 G3 的 T2 追击；须等当前回合完整收尾后，按基线铁律 5 复核并兑现申请。
- **累计耗魔计数器**：每根行动独立累计实际支付的投影魔力，达阈值后——
- **赤原猎风**：自该次起、本根行动内后续命中玩家单位的释放附加即时效果：
  **目标 SP −1（下限 0），且目标本全局轮无法触发受击满能量插队公演**（对齐基线铁律 5，
  替代 M9 的公演队列移除）；频率闸：每名玩家每次结界至多一次；即时效果，非控制状态；
- **回路接通**：触发赤原猎风 → **理想燃烧自动点亮** → 可在同一根行动末尾无缝衔接
  终段幻想崩坏（不再需要打卡凑式样数）。

## 七、幻想崩坏与结界结束

- **幻想崩坏**：消耗全部剩余魔力 + 牺牲兵装/防壁/剑阵；对主目标结算一次统一攻击：
  基础伤害 = `4 + min(本次结界累计式样数, 4)`（式样自动累计，
  池中不同复制武器 ID 各计一种 + 双刀/七重圆环/剑阵已登记式样）；普通属性、防御系数0.5 + **双倍耐久计费**
  （对齐基线铁律 6，非 `DIRECT_DAMAGE`）；结算完成后无条件解除结界；
- 也可**不终结**：保留结界（维持费照付），此后仍可独立发动幻想崩坏（需
  `collapse_terminal_min_magic`）；
- 退出路径（继承 M9）：崩坏完成 / 魔力不足 / 锚点被破 / G3 死亡 / 终焉停摆——幂等清理，
  被困者返回原地点，地点不可用则按基线固定建筑次序去未毁公共地点；已结算的
  HP/装备/状态/犯罪/SP 不回滚；
- 控制边界（继承 M9）：普通控制不自动解除结界，只让 G3 失去该槽的主动操作。
