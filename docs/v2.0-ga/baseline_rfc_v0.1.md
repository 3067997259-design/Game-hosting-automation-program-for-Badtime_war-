# V2.0-GA 底层基线 RFC v0.1（十诫）

> **Profile 代号**：`V2.0-GA`（General Availability，即本会话所称「干净基线 / Clean Baseline」）
> **状态**：候选设计，**未实现**。不修改 `legacy` / `v2exp` / `m9-rfc` 的任何行为。
> **日期**：2026-10-26（DEC-001～050 已回写；数值及实现验收仍待完成）
> **数值**：2026-10-26 已补齐首轮 N0，统一以[手册 §17](manual_draft_v0.1.md#十七首轮数值表-n02026-10-26)为数值权威。
> 这是可调初值，未实战验收；实现期再迁入 `data/balance.json` 并校准，不影响当前配置。

## 〇、动机

V2.0-GA 与 M9 的根本区别：M9 是「天赋先行、底层补丁跟进」（引擎里挂了一堆 per-talent
注册表）；V2.0-GA 反过来——**先收口底层规则，让天赋只能挂到本文件定义的 hook 点上**。

病根详见本目录 README §一；本文件只记录口径，不再复述动机。

## 一、铁律 1：计分去水分（无乘数、反苟活）

- **移除**：`talent_score_multiplier`（槽位终分乘数）；`1.5 / 0.5`（生者/死者存活乘数）。
- **终分骨架**：`终分 = 战果分（击杀 + 有效伤害/破甲） + 高光分（剧情章数 + 剩余 PP） + 终幕王冠`。
- **死后不打折**：生前取得的战果分与剧情分，死亡后照常计入。
- **终幕王冠（+6）**：最后存活者必须 **≥1 击杀 或 ≥2 章剧情** 才能戴上；
  0 杀且 <2 章 = 庸碌幸存者，得 0。
- **锁章，不锁钱包（DEC-037）**：战果与已解锁章节永久保留；第 3 章不冻结 PP 余额，
  也不停止后续得分。终分中的 PP 只取终局实际剩余量，花掉的 PP 不得由旧快照重复计分。
  HP 伤害战果只统计实际造成的他人 HP 损失，不计过量伤害；破甲另记，不折成第二笔 HP 伤害。
- **两个结果**：最后存活者与综合评分第一分别公布，前者不自动等于后者；综合评分同分并列。
- 参考：DOC-054（避战拖分）在游戏侧的收口。

## 二、铁律 2：开局单向安全屋（方案 A）

- 开局全员在各自**绝对安全的私人房间**，R1 的 T0 免费执行起床并领取初始包；
- 初始包（已冻结）：弓 + 初始箭矢（固定）+ 小刀/盾牌**二选一**（开局第一个小抉择；
  G0 以 AR 替弓、G7 水着起床额外得盾不受影响）；
- R1 的 T1 **必须 `move` 迈入 5 大公共建筑之一**：商店 / 魔法所 / 医院 / 军事基地 / 警察局；
- **出门落锁**：本局不得再回私宅（原「回家换形态」等需求迁到 T0 整备或医院）；
- 效果：开局无出生点屠杀；残局无躲猫猫死角；RL 动作空间不再需要 `home_pX` 动态槽。

## 三、铁律 3：回合三拍子（T0 免费小动作 → T1 主行动 → T2 收尾）

- **T0**：每回合限 **1 次**免费小动作：起床 / 吃药（含便携急救针）/ 磨刀 / 装卸弓模块 /
  换形态 / `lock` 锁定目标。
- **必要声明不占 T0（DEC-020）**：G2 主控选择、G3 结界主目标选择是回合设置；其他
  明文 T0 技能与上述小动作共享一次额度。G7 宏内操作走宏费用，宏外肾上腺素占 T0。
- **演出行动归属（DEC-021）**：G0 无人机/G1 着装/T3 玉璋/G7 午休属 T0 准备型；
  攻击演出、G5 讲故事/献诗、T6 整备、T7 保险/祝祷占 T1。G2 融合前 A 占 T0 并
  限制 T1 必须 move，B 占 T1；融合后演出均占 T1。大即演只豁免公演位，不赠主行动。
- **T1**：1 次主行动：`move` / `attack` / `interact` / `special`。
- **T2**：登记关注（→ SP，每人每轮实际 +1 上限，继承 M9 口径）、结算
  **StepFollowup（单步战技追击）**，并登记白名单 **ExtraTurn（完整额外行动）**；
  当前回合完整收尾后，先处理合法公演插队，再开始尚未执行的 ExtraTurn。
- **ExtraTurn**：每名玩家每全局轮至多 1 个；来源白名单沿用 T4 或跃 / 地火诗
  （G4 负世燃尽不再派发完整额外行动）。ExtraTurn 有自己的 T0，但禁止公演且不递归再动。
- **根行动与反应（DEC-023）**：G3 连发、G7 宏及宏内免费射击是同一根行动内部步骤；
  G4 烈阳余波是附加效果。G1 繁育击杀再动归为 move/attack 单步追击，与自身同轮其他
  单步追击共用一次额度。暗影步、挑战响应是受限反应，不附赠 T0/T2 或完整回合。
  只有实际授予新行动的效果才分 StepFollowup/ExtraTurn，不把连段强行改成额外回合。
- **预检与付费（DEC-024）**：无合法目标或资源不足时不收费，可重新选择；合法发动后
  遭闪避/拦截不退款。宏与连发逐段预检，已完成步骤不回滚；免费装填/服药受库存与容量限制，
  无效果的空操作不刷关注、资源或剧情。
- **状态合同（DEC-025）**：普通硬控共用一位，压制 > 石化 > 震荡；弱不覆盖强，
  同名刷新而不堆多个跳槽。失神另封 T0；睡眠/自我怀疑是结构状态，普通压制不能无限
  推迟必然转化。石化挣脱在槽开始特殊窗口处理，不占 T0，同槽最多两次，每次正常付 SP；
  成功后正常行动。轮制状态按未来 R4 计时，槽制状态按来源消费下一合法槽。
  擦伤同时登记闪避成功与实际受伤，不登记附带状态所要求的命中；G6 旧落空映射至闪避成功。

## 四、铁律 4：三态感知（砍掉淤血 find）

- 同地点**显形**单位天然面对面，可直接近战/远程攻击——不再需要花一整轮 `find`；
- 感知三态：**暴露（默认）/ 隐匿（隐身）/ 被锁定**；
- `search`（原 `find`）只用于揪出隐身单位；对应属性的探测装备/法术自动看穿隐身；
- `lock` 降级为 T0 小动作：本回合 T1 攻击无视目标移动闪避并获得命中/破甲加成；
- 主动移动提供的闪避加成保留（防"进门即被秒"）。
- 闪避成功改为按伤害下限结算的擦伤，不附带攻击状态、不磨损普通外甲，见铁律 6
  的 DEC-005；移动闪避 +15 个百分点，lock 命中 +15/防御系数 0.75，完整命中表见手册 §17.1。

## 五、铁律 5：SP 与公演夺台（崩铁式插队）

- SP 保持 `0/1/2`；即演固定 −1、公演固定 −2；SP 是能力层级，不是货币；
- **废除 R0 FIFO 报名队列**；每轮仍只有 1 个全局公演位；
- **轮初夺台立即兑现（2026-10-26 已定）**：R1 先攻排定后，愿意公演且满足条件的
  SP=2 玩家按先攻竞争（可用 PP 重掷先攻）；胜者把自己的标准回合移到 **R3 最前**，
  在该回合公演，**R2 仍照常先结算**。这不是按原行动顺序等待的预留票；轮中满 SP
  者不能抢走尚待轮初兑现的位置。
- **兑现与递补**：执行前复核公演是否合法；轮初胜者失去资格时，按先攻在其余愿意
  公演的合法轮初候选中递补。未实际执行不扣公演 SP、不消费公演位，也不凭空消耗
  该候选的标准槽；其后按原行动顺序与控制规则处理。轮初无人能兑现，才向轮中夺台开放。
- **轮中夺台**：回合中被推至 SP=2 时可以提出申请；须本轮公演位仍空、自己本轮标准
  回合尚未开始，并在执行时仍满足公演条件。同一边界有多名合法申请者时按本轮先攻决出。
- **插队边界（2026-10-26 已定）**：当前玩家回合必须完整结算，含攻击、同一主行动内
  的连发/战术宏、濒死处理及 T2 追击与收尾；公演不得切开其中任何一段。收尾后先执行
  合法公演插队，再开始尚未执行的完整额外回合。已开始的 ExtraTurn 同样完整结算后才让位。
- 插队只是**提前消费自己本轮的标准槽**，原位置不再行动；本轮标准回合已开始或已结束
  者不能借插队再行动，只能在下一轮重新竞争，不保留跨轮预约。
- **当前回合公演（DEC-022）**：自己标准回合 T0 达到 SP=2 后，公演位若仍空且其他
  前置满足，可直接以当前 T1 公演；这不是插队，不创建第二个槽。公演位已用则保留 SP，
  选择其他合法主行动。ExtraTurn 不适用此入口。
- **大即演**：部分天赋的 2 SP 演出是「强化即演」，不占聚光灯（G2 全部演出、
  G5 讲故事/献诗）；其余 2 SP 演出为**公演**，走全局聚光灯并可用崩铁式插队夺台
  （G4 焚诏、G5 升格均属此类）——大即演与公演的差别在入口，不在强度。

## 六、铁律 6：三层防御漏斗（屏障 → 外甲 → 生命）

```
[攻击方产出 A] = 基础伤害 × 核心倍率 + 固定加值
  → 第 1 层 Barrier（拦截屏障）：警察防暴盾墙 / G3 七重圆环·剑阵 / G7 架盾 / T4 元亨利贞
  → 第 2 层 Armor（属性减伤 + 耐久计费）：盾牌 / 陶瓷 / 魔法盾 / AT 力场
  → 第 3 层 Death Gate（HP 与濒死门）
```

- **普通外甲底座（DEC-003，2026-10-26 已定）**：采用**属性减伤 + 耐久计费**。
  外甲按攻击属性提供防御值，只减免一次伤害；耐久用于支付这次由外甲承担的减免，
  不再作为第二个吸收池抵挡减伤后的剩余伤害。普通计费为每减免 1 点消耗 1 点耐久；
  明文双倍磨损改用下述 DEC-007 的计费单价。
- **计费示例**：无其他修正、无额外碎甲、耐久足够，且保底不改变结果时，攻击 6 对
  属性防御 3 → HP 扣 3、外甲耐久扣 3；不能在减伤后再用该耐久吸收剩余 3 点。
  耐久归零后外甲破碎，后续攻击不再取得该件防御；击破当次按下述 DEC-006 限制减免。
- **残甲与当次溢出（DEC-006，2026-10-26 已定）**：本次减免同时受属性防御、
  伤害下限与剩余耐久约束，不能用最后 1 点耐久支付完整名义防御。普通计费时，
  剩余 1 耐久最多减免 1 点；未被减免的伤害进入 HP，不另外叠加一笔「破甲溢出伤害」。
  无其他修正、不闪避、单甲时：攻击 4 / 防御 3 / 耐久 1 → HP 扣 3、甲碎；
  攻击 10 / 防御 6 / 耐久 1 → HP 扣 9、甲碎。
- **双倍磨损（DEC-007，2026-10-26 已定）**：每减免 1 点伤害消耗 **2 点耐久**，
  耐久不足直接限制**这一击**能获得的减免；不采用先完成普通减伤、事后再追加磨损的
  算法。无其他修正、不闪避、单甲时：攻击 4 / 防御 3 / 耐久 4 → HP 扣 2、甲碎；
  攻击 10 / 防御 6 / 耐久 4 → HP 扣 8、甲碎。双倍磨损不是 HP 伤害翻倍，也不将
  消耗的耐久折算成额外 HP 伤害。奇数耐久的最后一点按下述 DEC-008 处理。
- **尾数保护（DEC-008，2026-10-26 已定）**：双倍计费时，最后不足 2 点的耐久仍可
  支付最后 1 点减免，这是整数计费的尾数例外；只有实际用到该尾数时才耗尽并碎甲。
  仍须受属性防御与保底限制，不凭空增加减免。无其他修正、不闪避、单甲时，攻击 4 /
  防御 3 / 耐久 3 / 双倍磨损 → 减免 2、HP 扣 2、耐久扣 3 后破碎；若本击只需
  减免 1 点，则只扣 2 耐久、保留尾数 1，不提前清空。
- **碎甲倍率取最高（DEC-009，2026-10-26 已定）**：同一击对同一件普通外甲适用
  多个磨损倍率时只取最高，不相加、不连乘。天赋双倍与属性克制双倍同时成立仍为
  单价 2，不变为 3 或 4；固定数值的独立磨甲不混入倍率比较。
- **每击一件主防甲（DEC-010，2026-10-26 已定）**：对当前攻击属性，系统按每件
  普通外甲的防御、剩余耐久、本击单价与保底，比较其本次实际可减免量，自动选择
  最多的一件；只有被选中的外甲计费，其余作为备用或覆盖其他属性。同一击不叠加
  多件防御，被选中外甲碎裂后本击不再调用另一件接力减伤；后续攻击重新选甲。
  无其他修正、不闪避、普通计费且耐久充足，攻击 8 对防御分别为 3、2 的两件甲，
  只选防御 3 的一件 → HP 扣 5、该甲耐久扣 3、另一件不磨损。
- **取整与同效择甲（DEC-017）**：攻击方产出最终向上取整一次；属性防御经穿甲系数
  修正后向下取整一次，例如 3×0.5→1，不逐项舍入。同效候选依次比较本击普通计费
  较少、当前剩余耐久较多、固定装备 ID 顺序；HP 与耐久均为整数。
- **计费归属**：只登记由外甲承担的减免；闪避、屏障或天赋减伤避免的伤害不能未经
  区分全部记为外甲磨损。普通外甲不再存在同击多甲分摊账目。
- **先普通减伤、后外甲（DEC-011，2026-10-26 已定）**：进入本体普通防御结算后，
  先计入目标易伤与天赋/状态等不耗甲的普通减伤，再由主防甲承担剩余可减免部分，
  最后统一应用伤害下限。外甲只为其实际新增的减免付费；其他减伤已将伤害压至
  保底时，普通外甲减免及减伤计费均为 0。攻击 8 / 其他固定减伤 4 / 甲防 4，普通
  计费且耐久足够 → HP 扣 2、外甲磨损 2，不按名义防御收取 4 耐久。
- **攻击附加固定磨甲（DEC-012，2026-10-26 已定）**：先确定本击扣血及普通外甲
  减免计费，再把附加固定磨损扣在本击主防甲上；这部分独立记账，不乘双倍磨损单价。
  不能反向增加本击 HP 伤害；主防甲已碎或剩余耐久不足时，余量不转 HP、不转另一件
  普通外甲。闪避擦伤、明文归零或完整拦截不能借附加磨甲突破各自的免磨甲边界。
  独立纯磨甲按下述 DEC-014 处理；所有普通外甲本击减免均为 0 时，仍按 DEC-017
  同效次序确定附加磨甲目标，不补收普通减伤费用；目标无甲则该部分无效。
- **独立纯磨甲（DEC-014，2026-10-26 已定）**：属于装备损耗事件，只扣一件普通
  外甲的固定耐久，超过该件剩余耐久的部分丢弃，不转移至其他甲或 HP。目标无外甲时
  只有磨甲部分无效，技能其他部分照常；不把它伪装成基础伤害为 0 的攻击，也不生成
  25% 保底。
- **纯磨甲目标与拦截（DEC-018）**：有主动选择入口时施术者指定一件普通外甲；自动
  效果选当前耐久最高的一件，同耐久按装备 ID。适用屏障先承接固定磨损额，最多扣尽
  屏障值，本次不再磨外甲，超额丢弃；不自动获得穿屏障资格，不把屏障破碎当普通破甲奖。
- **通用破甲奖励（DEC-013，2026-10-26 已定）**：主动击碎他人的普通外甲才具备
  此项奖励资格；自损、卸甲、形态转换不发奖。SP 并入既有关注规则，仍受每人每全局轮
  实际 +1 上限约束，不因同一次破甲另发第二份；通用破甲 PP 奖励每名发起者每全局轮
  最多领取一次，每次 +1 PP。连发、范围攻击与额外回合共享额度，不能每碎一甲重复领取。
  此项上限不替代战果分口径；明文天赋返 SP、专属资源与押注分红随各条款复审。
- **继续移除**：医院永久内甲。本次保留外甲底座，不恢复永久内甲。
- **普通伤害保底（DEC-004，2026-10-26 已定）**：进入本体普通防御结算、且 `A>0`
  的伤害保留 `F = ceil(A × 25%)` 下限；普攻与走普通伤害流程的技能同样适用。
  `A` 为攻击方完成核心倍率、固定加值与虚弱修正后的产出，目标易伤不抬高保底基数。
  普通目标侧增减伤结算完后统一应用下限，普通外甲与固定减伤均不能再次把结果压到
  `F` 以下。25% 为首轮数值基线，比例可在实现期风洞校准。
- **部分承接的余量接口**：普通数值屏障先扣除其实际承担的伤害；若只剩 `A_remaining`
  进入普通防御，该次可用下限为 `min(A_remaining, ceil(A×25%))`。保底不能补回已被
  屏障承担的伤害；全部拦截仍为 0。例如 A=8、临时屏障=7，无其他修正，屏障耗尽后
  只剩 1 点进入本体，不因原保底为 2 而重新生成第 2 点。闪避擦伤同受此余量上限约束。
- **保底边界**：明文 `A=0`、屏障/替身等完整承接、绝对免疫不强行扣本体血；保底
  不是穿透屏障的直达伤害。`DIRECT_DAMAGE` 仍按独立合同令 `H=A`。
- **闪避擦伤（DEC-005，2026-10-26 已定）**：可闪避攻击的闪避判定成功后，若仍
  进入本体结算，则仅造成上述 `F` 点擦伤，不触发本次攻击附带的震荡、灼烧等状态，
  **不磨损普通外甲**。不再经过一次普通外甲减伤或第二次保底；完整承接、绝对免疫等
  明文例外仍先适用。闪避减少的伤害不能记成外甲承担。技能独立事件钩子随各天赋复审。
- **普攻可用性约束（2026-10-26 补充）**：T6 等没有独立伤害演出的角色须以普通
  武器攻击作为个人进攻基准，不能假定其可用技能倍率、穿屏障或直达伤害破局；警察
  支援受执法条件与编队状态限制，不能当作必定可用的替代输出。风洞须检查普攻对
  防御、回血与修甲循环是否仍有推进能力；仅有 1 点保底不等于通过此项平衡验证。
- **碎甲接口**：属性克制与天赋明文「双倍磨损」统一使用 DEC-007；
  固定数值的独立磨甲效果不自动改成该倍率。非整数属性防御的取整、同效择甲、
  纯磨甲的选甲/拦截、无主防甲时的磨甲目标按 DEC-017–018；专属资源按铁律 9 后的事件合同。
  通用破甲奖励为 +1 PP，计分与其他 PP 收支见手册 §17.4。
  旧「碎甲瞬间溢出伤害全额贯通」由 DEC-006 取代，不再保留为并列算法。
- **G7 架盾必耗耐久（DEC-015，2026-10-26 已定）**：取消低伤免费格挡阈值。主动
  架盾在其合法拦截范围内成功格挡每次正伤害时，按来袭伤害扣盾耐久，最多扣尽当前
  耐久；保留正背面、架盾不能移动与维持 Cost（水着免费维持仍不等于受击免耐久消耗）。
- **主动防护破碎当次（DEC-016，2026-10-26 已定）**：G3 七重圆环与 G7 主动架盾，
  对其原本能够拦截的攻击，击破当次仍完整拦截该击，之后失效；不把余量送入本体或
  普通外甲。此为这两类主动防护的明文特权，不扩大其拦截范围，不抵消明文绕过屏障，
  不扩展到普通外甲、G7 持盾/被动保护/光环或其他未获此特权的屏障。
- **普通护体与 G7（DEC-019）**：未架盾的铁之荷鲁斯按普通外甲计费，持盾只提高
  属性防御，不另设耐久吸血池或永远剩一点的将破线。光环是有限护体池，位于主动
  屏障之后、普通外甲之前，挡多少扣多少，耗尽后的余量继续结算。普通临时屏障同样
  允许溢出；只有 DEC-016 两类主动防护有破碎当次完整拦截特权。
- **DIRECT_DAMAGE** 语义继承 M9：令 H=A，跳过属性防御/护甲/普通减伤；仍可被替身/
  重定向/绝对免疫/掩体承接；**不自动等于绝对死亡**；
- **Death Gate 统一顺序**：`absolute_death` → 形态转折（G1 繁育 / G4 救世主 /
  G0 调整呼吸 / G7 战斗续行 / G2 黄昏后首次融合）→ 外部复活（T7 保险）→ 普通死亡。
  每次致死只兑现一个有效替代；替代成功后不把本击超额伤害追入新形态，但连发后续段照常
  结算。G2 黄昏前不能融合，融合后不能重复触发；致死融合先置 HP8，再执行终局效果。
- **保险与落幕（DEC-027–028）**：T7 优先原地复活，地点无效则医院，再按固定建筑
  ID 选择未毁公共地点；首版恢复半最大 HP（向上取整）、SP=0，保留背包并清普通控制/
  灼烧，不修满普通外甲，不刷新每局一次资格或本轮额度。取消此次死亡/击杀，不撤销
  既成伤害与犯罪。兑现只耗尽保险资格，T7 仍可取得关注 SP 并以 T1 祝祷；彼岸最多

| G7 | 完成一次融合 | 双融合并执行战术宏 | 全弹倾泻有效命中，且曾主动架盾承伤 |

## 十四、迁移与验收边界（DEC-050）

目标是单一 GA，旧运行规则归档；旧模型不能冒充兼容新行动空间。2026-10-27用户再次确认
允许破坏性迁移，现已进入[实施准备](implementation_contract_v0.1.md)，代码按该合同分批落实。
实现验收至少覆盖 T6 无警察对抗回血/修甲、单次普攻对 G6 当身、G7 盾与光环耗尽、
十四人公演/第三章可达性、死亡与倒流同时触发、多人同时出局。检查持续交战却没有
任何永久进展的循环；只出现 1 点保底或脚本不崩溃不算平衡通过。
