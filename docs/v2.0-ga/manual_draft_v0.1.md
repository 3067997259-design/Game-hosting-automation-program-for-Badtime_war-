## 一、游戏概述

### 1.1 目标

《起闯战争》是 2 至 6 人的回合制乱斗。玩家在五大公共建筑之间移动、发育、演出并争夺综合评分直到游戏结束，如只剩下最后一名存活的玩家等等（没错，不止这一种可能）。
最后产生两类胜者：

- **最后存活者**：活到最后的玩家；
- **综合评分第一**：谁把这一局打得最精彩。

两者可以是同一个人，也可以不是。
在大部分情况下，玩家HP归零而死亡时将进入往世层（AfterLife）以独特的方法继续参与游戏并积攒评分。
有两类不进入往世层的例外：绝对死亡 与 退场 

### 1.2 信息公开

本游戏有99%的信息公开，属于近完美信息博弈。一般情况下，玩家位置、HP、装备、护甲耐久、状态、先攻、SP、PP、案底与大多数专属资源均公开。需要特别强调的是，本游戏中隐身只影响别人能不能找到你、打不打得中你（没有对应探测、也没把你搜出来的人不能选你当目标，能打你的时候也更难命中），并不导致该玩家任一属性无法被观测到。
（才不是因为懒得给RL训练管线写信念呢！这个游戏在那个还是口口相传和想象力的年代就是这样设计的！）

### 1.3 玩家状态条

每名玩家至少显示：

| 项目                                          | 内容                                                 |
| ------------------------------------------- | -------------------------------------------------- |
| HP                                          | 整数，一般上限为20；首轮完整数值见 §17                             |
| 外层护甲                                        | 每件护甲的属性与耐久                                         |
| 信用点                                         | 唯一经济资源，一般仅在商店打工获得                                  |
| SP                                          | 释放技能需要的资源，一般分为`0 / 1（可释放即演） / 2（可释放公演）`三个等级        |
| PP                                          | 演出积分，最终得分的重要一项。不因为死亡而消失，不能交易或转移，只在少数地方能花掉（比如重掷先攻）。 |
| 装备与弹药                                       | 武器、护甲、道具、模块等                                       |
| 状态                                          | 灼烧、震荡、石化、屏障、爱愿、天赋标记等                               |
| 天赋资源                                        | 追忆、魔力、火种、失熵、Cost、孤独值、色彩等，仅持有者显示                    |

## 二、游戏准备与地图

### 2.1 开局

1. 每名玩家选择一个天赋，或全桌约定无天赋局。
   需要注意的是，一局中允许混用**原初天赋(T(x))** 和 **神代天赋(G(x))**。这一设计是为了降低全桌的认知负担，不过也会出现“别人的能力：进化，倒流时间，将世界推向终末”而你的能力是“被打死了复活一次”这种雷霆情况。再多吐槽一句：神代天赋现在快批发免死了。

2. 游戏开始的第 1 轮，每名玩家出生在自己的**私人房间**，HP 满值，处于"未起床"状态。
   *（在游戏的早期版本是一个玩家一个home。这对RL不太友好，而且地名映射经常出bug。你也可以理解成比赛主办方没钱了只能租一栋公寓给你们住了hhh，这年头一人一个单间也不少了）*

3. 第 1 轮的 T0 阶段：执行**起床**之后领取**入坑福利**：
   默认为 弓 + 初始箭矢（固定）+ 小刀盾牌二选一。有些天赋对初始物资有特殊替换，比如 G0 拿到的弓会被 AR 取代，而 G7 选择水着开局时会额外拿到物资等等。

4. 第 1 轮的 T1阶段：**必须 `move` 进入五大公共建筑之一**——商店 / 魔法所 / 医院 /军事基地 / 警察局。
   *有点像跳伞。这可能是你在整份文档里看到的最接近大逃杀的元素。*

5. **关门之前再怀念一下你温暖的床吧**：本局无法再返回这个房间。
   *必要的眷恋之后就踏上舞台吧。我们急着在十二点之前退房，不然得多收一天钱。*

### 2.2 五大公共建筑

地图由五个可进入地点组成，任意地点之间移动消耗 T1 主行动槽。
*截止到目前*没有相邻或者远近的概念。

| 地点   | 主要功能                                                 |
| ---- | ---------------------------------------------------- |
| 商店   | 唯一可以靠打工获得信用点的地区、小刀、盾牌、磨刀石、陶瓷护甲、隐身衣、热成像仪、力量模块、修甲、箭矢补给 |
| 魔法所  | 法术（1 回合学 1 个）、魔法护盾、魔法弹幕、火矢、魔导模块                      |
| 医院   | 紧急治疗、急救装置、无限模块、G7 专属药、终身一次三选一手术                      |
| 军事基地 | AT 力场、电磁步枪、高斯步枪、雷达、隐形涂层、穿甲/冲击模块、钩索（直接购买，记案底）         |
| 警察局  | 申请队长、举报、防暴编队驻地                                       |

### 2.3 地点摧毁

一般情况下地点是不会被常规效果破坏的。只有在叙事等级足够高，且明确表述相关效果时才能被摧毁。例如 G1。

地点的摧毁几乎是永久的，里面的所有幸存单位会被驱逐至其他仍存在的公共建筑（玩家按先攻从高到低、同先攻按玩家编号排队，依次轮流分到剩下的建筑，建筑的顺序是商店、魔法所、医院、军事基地、警察局；编队跟着队长走，其余非玩家单位都去排在最前面的那座）。场上最后一个仍存在的公共建筑不能被摧毁。警察局被摧毁后，防暴编队立即停机；已有的案底与通缉记录全部保留，暂停执法但不会洗白。

目前只有 G5 献给 T6 的「律法」诗能重建被摧毁的警察局，其他被摧毁的地点没有办法重建。

## 三、回合结构：全局轮次循环（R）和玩家单个回合的结构（T）

### 3.1 全局轮次 R0–R4

每一轮（下文说“第 N 轮”就是指第 N 个全局轮次）都按固定顺序走完 R0～R4 五个阶段：

```text
R0 清晨阶段：世界时钟前进一格 → 结算各天赋的轮初恢复 → 往世层中的死者行动（押注、微光、Encore）
R1 先攻阶段：所有存活玩家掷骰判定先攻（可花 1 PP 重掷） → 满足条件且想在轮初公演的玩家报名抢台
R2 警务阶段：新申请的警察队长正式就任（注意：警察编队的自动攻击在 R4 结算，不在 R2）
R3 行动阶段：轮初抢到公演位的玩家最先行动（若其已不满足条件则按先攻递补）；随后其余玩家按先攻从高到低依次进行自己的标准回合：
    ├─ T0 整备：至多执行 1 次免费小动作（如锁定、磨刀、服药、切换形态）
    ├─ T1 主行动：执行 1 次主行动（移动、攻击、地点交互或特殊操作）
    └─ T2 收尾：结算本回合触发的关注（SP +1）与天赋的单步追击
    * 当前回合完整结束后，按优先级决定下一个回合：轮中抢台公演 → 尚未开始的额外回合 → 下一个标准回合
R4 夜晚阶段：警察编队自动攻击 → 终焉环境伤害 → 灼烧与天赋维护结算 → 生命与光环恢复 → 到期状态清理
```

需要注意的是，在本轮新附加、带有持续轮数的状态（如石化、无人机、繁育、救世主、固有结界等），本轮的 R4 不扣减持续轮数，从下一个 R4 才开始倒计时（来源明确写明持续至本轮 R4 的除外）。

同一批范围伤害会先把所有目标的扣血与濒死处理完毕，再检查游戏是否结束，不会因为结算先后而提前宣布胜利。一旦游戏结束条件成立，后续结算立即停止；G1“胜利判定优先于繁育倒计时”的明文例外保留。

此外，实际轮数与世界时钟刻度是分开计数的。例如 G2 让世界时钟二倍速流动时，只是时钟刻度每次走两格，不会让同一轮里走两遍 R0～R4（§10.2）。

### 3.2 T0：免费小动作（整备）

特定动作可以在 T0 阶段发动，每个回合限 **1 次**，用来省下宝贵的 T1：

- 起床（仅第 1 轮）
- 使用急救装置、服用 G7 专属药物
- 磨刀
- 装卸弓模块 / 切换 AR 改装槽里的强化
- 切换形态或姿态（G1 着装/卸甲、G7 更衣、G4 主动升格、警察队长切换编队姿态）
- `lock` 锁定目标：本回合 T1 攻击无视目标移动闪避，并获得命中与穿甲加成（§5.2）
- 天赋写明在 T0 发动的其他能力
  *在早期版本里，lock和find是占据单独行动的，现在lock变免费了，find直接删掉了——不然实在是太磨蹭了*
  *免费说的不是不消耗资源啦！不消耗标准行动槽而已。*

G2 切换操控的角色、G3 在结界内重新指定主目标属于免费的回合设置，不占用这次 T0；G7 在战术宏内的操作按宏的 Cost 结算，但在宏外注射肾上腺素仍占用 T0（例如本回合已经用了「大叔的午休」，就不能再在宏外扎针）。

### 3.3 T1：主行动

每个回合 1 次，分为四大类动作：

| 类别 | 说明 |
| --- | --- |
| `move <地点>` | 移动到任意其他仍存在的公共建筑 |
| `attack <目标> <武器>` | 攻击同一地点对你暴露的单位（近战），或攻击任意地点对你暴露的单位（远程） |
| `interact <项目>` | 购买、打工、手术、学习法术、修甲、补给、拾取掉落物等地点服务 |
| `special <操作>` | 天赋技能、武器蓄力、隐身、搜索、战术宏等特殊操作 |

*早期版本里有个非常让人头疼的find，用于在两个处于统一地点的玩家之间建立允许近战的社交关系。
事实证明与其让大部分天赋提供绕过它的攻击方式，不如直接取消掉它算了*

`search`（原 find）只用于揪出同一地点的**隐身**单位（占一次 T1）。
*AI coding的经典范例，我真不记得我设计过这个指令*

所有行动均遵循**先预检，后付费**：没有合法目标或资源不足时，行动在发动前直接拒绝，不扣除任何资源，你可以重新选择；合法发动后，即使攻击被闪避或被屏障挡下，已消耗的资源也不退还。回路连接、战术宏这类多步操作会逐段检查，已经结算生效的步骤不会回滚。免费装填或服药仍须有对应的弹药或药物且未超出容量；没有实际效果的空操作不会产生关注、资源或剧情章进度。

### 3.4 T2：追击与额外回合

在 T1 结算完毕后，部分天赋效果会在 T2 阶段带来追加行动，分为两类：

**单步追击**：只能来自天赋写明的效果（例如 G1 完全燃烧或繁育期间的追加一步），只能执行该效果允许的动作；没有独立的 T0，不能发动即演或公演，也不会再次触发下一段追击。每名玩家每轮最多 1 次单步追击，不同来源共用这 1 次。

**额外回合**：在当前回合完整收尾后，为你插入一个完整的行动回合（重新走一遍 T0→T1→T2）。额外回合里只要 SP 足够就可以发动即演或大即演，但**禁止发动公演**。共同限制：

- 每名玩家每一轮最多获得 1 个额外回合，不能储存到下一轮，也不能转给别人；
- 若当前回合结束时有人申请抢台公演，先执行公演回合，再开始你的额外回合（§6.3）；
- 额外回合自己的 T2 阶段不能再生成新的额外回合；
- 若轮到额外回合时你正处于压制或石化状态，该额外回合会被控制直接消耗掉。

### 3.5 被其他玩家感知的不同状态

感知状态分三类：**暴露  / 隐匿（隐身）/ 被锁定**。
感知状态是带方向的，例如A和B都有隐身效果，但只有A有探测，B没有，那么两个人集中在同一地点，不经其他操作时
A的视角下B是暴露，而B的视角下A是隐匿。

- **怎么隐身**：有隐身衣、隐形涂层或隐身术时，花一次 T1 主行动进入隐身。失神时不能隐身（§3.6）。隐身用的道具和法术不会用掉，现形以后还能再隐身。
- **你在他眼里是暴露的**，只要满足下面任意一条：你没有隐身；他在同一地点用 `search`（占一次 T1）把你揪了出来；他有对应的探测。三条都不满足，你在他眼里就是隐匿的。
- **search 只对搜的人有效**：他把你揪出来以后，其他人眼里你还是隐身的；你重新隐身，他也就看不见你了。
- **探测按攻击属性分**：热成像仪对应普通属性，雷达对应科技属性，探测魔法对应魔法属性。比如只有热成像仪的人，可以用普通属性的攻击打隐身的你，换成科技武器就选不了你。被 search 出来以后就不分属性了。
- **看得见**：只要有一种探测，或者已经把你搜出来，就算看得见你。看得见才能对你 lock（§3.2）；T2 的如影随形也按这个口径（§11.2）。
- 能选隐匿的人当目标时，打他照样要多算一项 −25% 的命中（§5.2）。
- 发动攻击这类敌对行动，会让你立刻现形；T2 还没杀过人的时候例外（§11.2）。
- **被锁定**：别人在 T0 对你 lock 以后，他这回合打你有 lock 的加成（§5.2 的命中表）。lock 不会让隐身的你现形。有些效果会记得“谁被我 lock 过”（比如游侠诗），T4 的「群龙无首」会让所有人对 T4 的 lock 失效（§11.4）。

### 3.6 控制裁决

本游戏有若干个可以施加给玩家或者非玩家单位的控制类状态：

| 状态 | 效果 | 备注 |
| --- | --- | --- |
| **震荡** | 下一个行动回合不能发动攻击或使用敌对技能，只能执行移动、非敌对的地点交互或放弃；该回合结束后解除；附加时立即解除架盾与警察盾墙姿态 | |
| **压制** | 下一个行动回合强制跳过，该回合结束后解除 | |
| **石化** | 持续至下一轮的 R4，期间所有行动回合强制跳过。提前解除方式：① 在自身回合开始时，可消耗 1 SP 尝试挣脱（50% 概率成功，每个回合至多尝试 2 次，成功后该回合正常行动）；② 累计受到 2 次有效伤害后自动解除 | T3 独特效果 |
| **睡眠** | 该回合只能执行起床 | 这就是为什么这个游戏叫现在的名字。开局时所有人都在睡（§2.1 起床），目前没有效果能让人重新睡着 |
| **失神** | 下一个行动回合没有 T0 阶段，且附加时立即解除隐身、持续期间无法进入隐身；可与上述控制效果同时生效 | 我已经忘记是谁会施加这个效果了（其实是 G2 影的演出「沉入冰冷的池底」和「都隐没于　淋漓的雨幕无声无息」） |
| **沉沦** | 非玩家单位（如特警、无人机）停机，无法行动或提供加成 | 多少个版本了都是 G2 的专属效果 |

**控制叠加与解除规则**：

- **优先级**：震荡、压制、石化共用同一个普通控制栏位，同一时间只保留优先级最高的一项：**压制 > 石化 > 震荡**。优先级更低的控制无法覆盖更高的控制；附加同名控制时，刷新其持续时间，不叠加回合数。
- **独立状态**：睡眠、G7 的自我怀疑属于结构状态，不占用控制栏位；失神同样独立生效，可与普通控制叠加；灼烧等按层数计算的效果按各自层数上限叠加（§4.6）。
- **挣脱与过期**：石化的挣脱在回合最开始进行，不占用该回合的 T0。震荡、压制与失神若因没有对应回合而一直未被消耗，会在经过两个未来的 R4 后自动过期。
- **擦伤的判定**：闪避成功造成的擦伤同时视为“闪避成功”与“受到实际伤害”（若扣血至少 1 点，同样计入解除石化的有效伤害次数），但不触发攻击附带的控制或减益状态（§5.2）。

### 3.7 增益与减益

本书所说的**增益状态**（buff）和**减益状态**（debuff）是指下表中的临时效果。天赋写明“免疫所有减益”“清空所有 debuff”时，按这张表判定。

| 类别 | 包括 | 不包括 |
| --- | --- | --- |
| 减益状态 | 震荡、压制、石化（普通控制，见上表）和失神；脆弱（受到的普通伤害 +1；技能写明“受到的普通伤害 +X”的短时效果同样视为脆弱）；虚弱（攻击伤害 −1）；闪光（被闪光弹晃到，命中 −15%，§5.2）；惧怖（§11.2）；灼烧（§4.6） | 睡眠、自我怀疑等结构状态；NPC 的沉沦；感知状态（暴露、被锁定，§3.5）；重伤（§4.6）；案底与通缉；爱愿（§13） |
| 增益状态 | 屏障（包括炽愿、光环这类逐层吸收的屏障，§5.1）；隐身（§3.5）；技能、道具或诗篇给出的、写明了持续时间的临时加成（例如 G3 双刀·守势的下一次减伤、G7 肾上腺素的先攻 +3） | 天赋的形态与被动能力；装备与永久改造；世界法则（例如世末之雨）；爱愿 |

- 免疫减益状态时，新的减益状态无法被附加。已经附加的是否清除，以各效果的写法为准，例如 G1 的飞萤之火会先全部清空（§12.2）。免疫减益状态不能抵挡伤害本身。
- 目前没有效果会成批清除增益状态。T7 的复活只清除减益状态，屏障和隐身保留（§11.6）。

## 五、伤害、防御结算顺序与死亡

### 5.1 防御结算顺序

V2.0-GA 统一了防御结算顺序：

```
攻击伤害 A
  → 第 1 层 Barrier（屏障）
      警察防暴盾墙 / G3 七重圆环·剑阵 / G7 架盾 / T4 元亨利贞
  → 第 2 层 Armor（属性减伤 + 耐久计费）
      盾牌 / 陶瓷护甲 / 魔法护盾 / AT 力场
  → 第 3 层 HP（生命与濒死）
```

一次攻击打到人身上，要依次过三道关：先撞屏障，再撞外甲，剩下多少才扣多少血。

第 1 层是**屏障**。屏障是临时的护盾值，来源很多：警察的盾墙、往世层的赐福，还有很多天赋都在这一层挂了自己的东西。它的规则很简单，挡多少扣多少：一记 6 点的攻击打在 4 点的屏障上，屏障扣到 0 碎掉，剩下的 2 点继续往下走。身上同时有好几层屏障时，依次往下扣。

需要注意的是，G3 的七重圆环和 G7 主动架起的盾有个特权：哪怕只剩 1 点耐久，也会把这一下完整挡住，然后才碎掉，一点都漏不到后面。比如架起的盾还剩 3 点耐久，挨了一记 6 点：盾碎了，人一滴血没掉，之后的攻击就没有这面盾可挡了。反过来，它们也没有“小伤免费”的说法，挨 1 点也要扣 1 点耐久。

另外，有些攻击写明了无视屏障，它们直接从第 2 层开始算。

第 2 层是**外甲**。每一下只用身上的一件普通外甲：它按属性挡掉一部分伤害，再为挡下的部分支付耐久，详见 §5.3。
*在 V2.0-exp 里，身上几件外甲的防御会加在一起，磨损再按各自的贡献比例分摊。GA 改成每一下只挑一件甲，减伤和记账都简单多了。*

第 3 层是**生命**。过完前两层还剩多少，就扣多少 HP，但普通伤害有保底（§5.2）。HP 被扣到 0 时进入濒死处理（§5.5）。

有三类伤害不走完整的三层：真伤跳过外甲和减伤（§5.4）；纯磨甲只磨外甲、不扣血（§5.3）；直接判死的效果不看伤害数字（§5.6）。

### 5.2 一次攻击掉多少血

一次普通攻击掉多少血，分三步算：

1. 先算**原始伤害 A**：武器或技能的基础伤害，乘上技能倍率，加上攻击方的加成（磨刀、力量模块等），中了虚弱再减 1，最后向上取整一次。比如用磨过的小刀砍人，基础伤害 4 加上磨刀的 1，A 就是 5。
2. 再过屏障：按 §5.1 扣掉屏障挡下的部分，剩下的才打到本体。
3. 最后是本体结算：先加上目标身上的易伤，再扣掉目标不耗甲的固定减伤，然后由一件外甲挡掉一部分（§5.3），最后检查保底。

打进本体的普通伤害有**保底**，至少是 A 的四分之一（向上取整）。A = 4 时至少 1 点，A = 10 时至少 3 点。甲再厚、减伤再多，也压不到保底以下。
*V2.0-exp 就有这条保底，当时手册里的说法是“几乎可确保不存在打不穿的龟壳”。*

需要注意的是，保底只管打进本体的那部分伤害，不会把屏障挡掉的补回来。A = 8 打在 7 点的普通屏障上，屏障碎掉，只剩 1 点打到本体，这一下就只扣 1 血，不会因为保底变成 2。屏障把整下都挡住时，本体一点不扣。另外，伤害被明文归零（A = 0）、被替身整个挡下、目标对这次伤害绝对免疫，这几种情况也不会硬塞一点保底伤害。

举个完整的例子：你用弓（伤害 4）射一个拿着盾牌的人，假设每一箭都命中。盾牌对普通攻击的防御是 2，耐久 6。每一箭 A = 4，盾牌挡 2 点、花 2 点耐久，对方扣 2 血，保底（1 点）用不上。连续三箭之后，盾牌耐久从 6 变成 4、2、0，碎掉；第四箭没有甲了，扣满 4 血。

目标身上有**易伤**时，受到的普通伤害 +1。天赋或状态给的固定减伤会在外甲之前先扣，外甲只为剩下的部分出力，不会替别的减伤重复付耐久（例子见 §5.3）。

普通的单体攻击要判定一次**命中**。命中率从 100% 起算：

| 情况                 | 命中率  | 备注                                                 |
| ------------------ | ---- | -------------------------------------------------- |
| 目标本轮主动移动过          | −15% | 持续到目标自己的下一个标准行动开始，不叠加                              |
| 目标处于隐匿             | −25% | 前提是你已经能选它当目标（§3.5）                                 |
| 跨地点攻击，并且没有 lock 目标 | −15% | 同一地点没有这一项                                          |
| 本回合 lock 了目标       | +15% | 同时无视“目标移动过”和“跨地点没 lock”这两项惩罚，还让目标外甲的属性防御打七五折（向下取整） |
| 跨地点攻击，并且有一方在烟雾里    | −15% | 道具效果，见 §17                                         |
| 攻击者被闪光弹晃到          | −15% | 道具效果，见 §17                                         |

命中率最低 40%，最高 100%。范围攻击、持续伤害、环境伤害、纯磨甲和写明必中的效果不判定命中。

没命中不是打空，而是**擦伤**：只造成保底的那一点伤害，不挂这次攻击附带的状态（震荡、灼烧等），也不磨外甲。擦伤怎样参与其他规则，见 §3.6。
*V2.0-exp 的手册里管这个叫“被闪避 ≠ 落空”，GA 沿用。*

#### 精确结算（可以跳过）

```text
A    = max(0, ceil(基础伤害 × 技能倍率 + 攻击方加成 − 虚弱))
A余  = 屏障挡完还剩的伤害（没有屏障时 A余 = A；全部挡住则到此为止）
F    = min(A余, ceil(A × 25%))          保底，不超过屏障后的余量
B    = A余 + 易伤 − 不耗甲的固定减伤
C    = 选中的外甲这一下挡掉的量（§5.3），没有外甲时 C = 0
H    = max(B − C, F)                     最终扣血
擦伤：H = F，不磨甲，不挂附带状态
```

扣血以目标剩下的 HP 为上限。战果分只按实际扣掉的血算，溢出的伤害不计（§7.1）。

### 5.3 外甲怎么扣耐久

身上有好几件外甲时，每一下只用一件：自动挑“这一下实际能挡最多”的那件，其他的这一下不出力，也不扣耐久。比的是实际能挡多少，不是面板防御：一件防御 6、只剩 1 点耐久的甲，这一下最多挡 1 点，比不过一件防御 3、耐久充足的甲。挡得一样多时，依次选耗耐久少的、剩余耐久多的，最后按固定的装备编号。被选中的甲这一下碎了，其他甲也不会接着挡。

一般情况下，外甲每挡 1 点伤害扣 1 点耐久，也就是**单价**为 1。比如穿着陶瓷护甲（普通防御 3、耐久 10）挨小刀（伤害 4）：每一下挡 3 点、扣 1 血，耐久从 10 变成 7、4、1；第四下甲只剩 1 点耐久，只能挡 1 点，这一下扣 3 血，甲碎。

有些情况下单价会变成 2，叫**双倍磨损**：

- 属性克制：普通攻击打魔法护盾，魔法攻击打 AT 力场，科技攻击打盾牌或陶瓷护甲；
- 技能写明了双倍磨损，目前有 T1 的斩击、G0 无人机在场时的神秘属性射击和 G7 的最优弹药。

几个来源同时成立也只算双倍，不会变成四倍。双倍磨损时甲的耐久掉得快，同样的耐久能挡下的伤害也更少。

耐久不够时，甲只能挡“剩余耐久付得起”的那部分，挡不住的直接扣血，甲碎掉。挡不住就是挡不住，不会再额外追加一笔“破甲伤害”。

双倍单价下，剩 1 点耐久也还能付最后 1 点减免，付完就碎。比如剩 3 点耐久、这一下要挡 2 点：第一点付 2 耐久，第二点用剩下的 1 耐久付，甲碎。如果这一下只需要挡 1 点，就只扣 2 点耐久、剩下 1 点，不会提前碎。

下表的六个例子都假设没有其他增减伤：

| 原始伤害 A | 甲的防御 | 剩余耐久 | 单价  | 甲挡下 | 扣血  | 耐久消耗       |
| ------:| ----:| ----:| ---:| ---:| ---:| ---------- |
| 4      | 3    | 10   | 1   | 3   | 1   | 3          |
| 4      | 3    | 1    | 1   | 1   | 3   | 1（碎）       |
| 10     | 6    | 1    | 1   | 1   | 9   | 1（碎）       |
| 4      | 3    | 4    | 2   | 2   | 2   | 4（碎）       |
| 4      | 3    | 3    | 2   | 2   | 2   | 3（碎，用上了尾数） |
| 4      | 1    | 3    | 2   | 1   | 3   | 2（剩 1）     |

多件甲的例子：攻击 8，身上两件甲的防御分别是 3 和 2，耐久都够。这时用防御 3 的那件，扣 5 血，它扣 3 点耐久，另一件不动。如果换成“防御 6、耐久 2”和“防御 1、耐久 10”两件，前者挡 2 点就碎了，扣 6 血；后者这一下不接手，耐久还是 10。

天赋或状态给的固定减伤先扣，外甲只为剩下的部分出力，最后再检查保底。比如攻击 8、对方有 4 点固定减伤、外甲防御 4、耐久充足：保底是 2，减伤后还剩 4，外甲只要再挡 2 点就到保底了，于是扣 2 血，甲只花 2 点耐久。如果固定减伤有 6 点，伤害已经压到保底，外甲这一下就不出力，也不扣耐久。

有些攻击写着“额外磨损 X 点耐久”，这叫**附加磨甲**，比如 G0 的全自动扫射。它在这一下算完之后，再从同一件甲上扣 X 点耐久。它不会让这一下多扣血，也不吃双倍磨损，扣不完的部分作废，不会转到别的甲上。例如攻击 6、甲的防御 3、耐久 4、附加磨甲 2：先正常挡 3 点，扣 3 血，耐久剩 1；再被附加磨甲扣掉最后 1 点，甲碎。这一下仍然只扣 3 血。就算这一下外甲没出力（比如伤害已经压到保底），附加磨甲也照样按上面的挑选顺序找一件甲来磨。擦伤不磨甲，附加磨甲也一样。

还有些效果只磨甲、不打人，叫**纯磨甲**，比如 T3 玉璋的「共鸣」。它只扣一件甲的耐久：施术者能指定就用指定的那件，否则磨当前耐久最高的那件，扣光为止，多出来的作废。它不扣血，也没有保底。目标没穿甲，磨甲这部分就什么也不发生，技能的其他效果照常。如果目标身上有能挡这种效果的屏障，就先磨屏障，这一次不再磨甲。

只有把耐久从正数打到 0，才算一次**破甲**。自己卸甲、换形态、把自己的甲弄碎都不算破甲；已经碎了的甲不会被重复算。主动打碎别人的普通外甲有三个好处：战果分 +1（§7.1）；按关注规则可能 +1 SP（§6.2）；拿 1 点 PP，但每人每轮最多拿一次（§7.3）。

#### 精确结算（可以跳过）

```text
对每件还有耐久、能挡这类伤害的普通外甲 i：
  E_i = floor(属性防御 × 穿甲系数)    穿甲系数：lock 0.75，穿甲模块 0.5 / 0.25；多个来源取最低，不连乘
  k_i = 单价                           一般为 1；有双倍磨损来源时为 2，多个来源取最高
  C_i = min(E_i, max(0, B − F), ceil(D_i / k_i))      这件甲这一下能挡多少（D_i 为剩余耐久）
选 C_i 最大的一件 j；并列时依次比：耐久消耗少、剩余耐久多、装备编号
H        = max(B − C_j, F)               B、F 见 §5.2
耐久消耗 W_j = min(D_j, k_j × C_j)     尾数只有真用到时才扣光
附加磨甲 = min(X, D_j − W_j)
```

### 5.4 真实伤害（真伤）

写明是**真实伤害**（简称真伤，程序里叫 `DIRECT_DAMAGE`）的伤害，跳过外甲、属性防御和普通减伤，闪避对它也没用：过完屏障还剩多少，就扣多少血。它仍然会被屏障、替身和绝对免疫挡住，写明无视屏障的除外。

需要注意的是，真伤不等于必死。被真伤打到 0 血，照样可以被免死和复活接住（§5.5），除非这次伤害同时写明了绝对死亡。

常见来源：G0 的十字炮火、终焉阶段每轮 R4 的环境伤害、G7 Terror 形态的攻击。

### 5.5 濒死：结算顺序

HP 被打到 0 的那一刻先别急着宣布死亡，需要按下面的顺序确定是否能给棺材板上钉钉子：

1. 这一下带**绝对死亡**：直接死，后面两步都跳过。绝对死亡只在这一下真的把你打到 0 时才生效，没打死就只是普通伤害。
2. 你自己的**免死**：G1 繁育、G4 救世主、G0 调整呼吸、G7 战斗续行、G2 黄昏后的首次融合。
3. T7 的**复活**：有人给你挂了复活时，由复活接住（§11.6）。

三步都没接住，才是真正的死亡（§5.6）。

需要注意的是：

- 一次致死只会用掉一个。G1 的繁育接住了，就不会顺手把 T7 的复活也用掉。
- 打死你的那一下溢出的伤害，不会追进新形态。但同一招的下一段（比如连发的下一枪）会照常打。
- 同一批范围伤害，会先把所有目标的濒死都处理完，再看谁赢（§3.1）。

### 5.6 死亡的三种结局

|         | 普通死亡             | 绝对死亡                                     | 退场                                 |
| ------- | ---------------- | ---------------------------------------- | ---------------------------------- |
| 怎么发生    | HP 归零，§5.5 里没人接住 | 带绝对死亡的伤害真正致死（G4 天裁、G7 Terror）；G1 繁育倒计时走完 | G0 调整呼吸结束时 HP 不到 6 而撤退；G2 炉心融解耗尽退场 |
| 免死和复活   | §5.5 都没接住才会走到这一步 | 跳过，接不住                                   | T7 的复活接不住                          |
| 算被击杀吗   | 有凶手时算            | 有凶手时算                                    | 不算，没有凶手                            |
| 进往世层    | 进（第九章）           | 不进                                       | 不进                                 |
| SP      | 清零               | 清零                                       | 清零                                 |
| 战果分、剧情章 | 全部保留             | 全部保留                                     | 全部保留                               |
| PP      | 保留，在往世层还能继续挣和花   | 冻结                                       | 冻结                                 |
| 身上的东西   | 白昼开始后全部掉在原地      | 同左                                       | 同左                                 |

“掉在原地”指信用点、弹药、道具、模块、武器和外甲全部留在死亡地点，别人可以花一次 interact 捡走（§4.1）；白昼之前死的，东西不掉。三种结局在终局计分时都不打折（§7.2）。

### 5.7 有效伤害

很多效果的条件写着“造成有效伤害”。满足下面任意一条就算：

- 实际扣掉了至少 1 点 HP（擦伤扣了血也算）；
- 把一件外甲或一层屏障从有耐久打到 0。

不算的情况：被屏障、替身或免疫整个挡住，又没打碎任何东西；只磨了甲但没打碎；伤害被明文归零。

用到它的地方：关注与 SP（§6.2）、剧情章的条件（§7.4）、石化挨两次有效伤害后解除（§3.6）等。

## 六、SP 与演出

### 6.1 SP 是什么

SP 是释放技能需要的资源，分三档：

| SP  | 能做什么                   |
| --- | ---------------------- |
| 0   | 正常行动，不能演出              |
| 1   | 可以即演（花 1 SP）           |
| 2   | 可以即演，也可以大即演或公演（花 2 SP） |

开局每人 1 SP，最多存 2 SP。SP 不能交易，不计入终分，也不能换成别的东西。死亡时 SP 清零。

SP 只管天赋演出，不管行动次数：SP 再多也不会多出一个回合，SP 是 0 也照样能正常行动。

### 6.2 怎样涨 SP：关注

在场上引人注目会得到**关注**，每次关注让 SP +1。下面这些情况会给关注：

| 发生了什么                              | 谁拿关注                 |
| ---------------------------------- | -------------------- |
| 发动一次敌对行动（比如攻击）                     | 发动的人，以及每个目标；打空、被挡住也算 |
| 实际扣了血                              | 扣血的人                 |
| 外甲被打碎                              | 打碎甲的人和被打碎甲的人         |
| 屏障被打碎                              | 屏障的主人                |
| 天赋的非伤害效果真正生效（比如挂上复活、起卦成功，具体看各天赋小节） | 发动的人；有目标的话，目标也拿      |
| 犯罪（比如没用黑市通行证就在军基拿装备）               | 犯罪的人                 |

每人每轮靠关注最多实际涨 1 SP，到下一轮 R0 重新计算。SP 已经是 2 的时候，关注照样会发生，但不会涨到 3，也不占这一轮的额度：比如你这一轮第一次挨打时已经是 2 SP，后来把 SP 花掉了，这一轮再挨打还能涨 1。死去的玩家拿不到关注。

举个例子：这一轮开始时，你、乙、丙都是 0 SP。你攻击乙，你们俩各拿一次关注，都变成 1 SP。同一轮丙也攻击了乙：丙涨到 1；乙这一轮已经涨过了，还是 1。到了下一轮，乙再挨打就能涨到 2。

除了关注，还有几种办法直接加 SP：医院手术「演出！要开始了！」、往世层微光的「启示」，以及一些天赋和诗篇。它们不占关注的每轮额度，但 SP 一样最多 2。少数天赋自己伤到自己时不给关注，各天赋小节会写明。

### 6.3 抢公演位（夺台）

每轮只有**一个公演位**。谁先用掉，这一轮别人就不能公演了；下一轮重新开放，不能提前预约。
*M9 里公演要在 R0 排队报名，排第一的人失效了也不往后递补。GA 改成了现在这样，谁满足条件谁来抢。*

想公演，要同时满足这几条：

- SP 是 2；
- 手上有能用的公演技能；
- 自己这一轮的标准回合还没开始；
- 没有被压制或石化（被震荡时只能用不带攻击的移动或交互类公演）；
- 这一轮的公演位还空着。

公演花 2 SP，只能在自己标准回合的 T1 里用。

抢台的先后看**先攻**，先攻也决定这一轮大家的行动顺序。每轮 R1，每个活着的玩家掷一个 D6，再加上修正：重伤 −2，手术「你的攻击结束了，到我了，没意见吧？」+1，往世层微光的「启示」+2，以及天赋给的修正。点数高的先行动，同点按固定的玩家编号排。掷完不满意，可以花 1 PP 重掷一次，用新掷出的点数，不能反悔；重掷在抢台排序之前结算。

抢台有两个时机。第一个是**轮初**：

1. R1 掷完先攻后，满足条件、又想公演的人报名。
2. R2 照常结算。
3. R3 一开始，按先攻从高到低看报名的人。第一个仍然满足条件的人，把自己这一轮的标准回合提到 R3 最前面，在这个回合的 T1 公演。
4. 排在前面的人如果已经不满足条件了，就往后递补给下一个报名的人。没轮上的人不扣 SP，也不丢回合，按原来的顺序正常行动。
5. 报名的人都不行的话，其他满足条件的人这时也可以抢。

第二个是**轮中**：回合中途被推到 2 SP 的人也可以抢。每当一个回合完整结束，就看一次：自己这一轮的标准回合还没开始、又满足条件的人可以抢；好几个人想抢，按先攻。抢到的人马上开始自己这一轮的标准回合，在 T1 公演。

插队有几条规矩：

- 不能切开别人的回合。当前回合的攻击、同一个主行动里的连发和宏、濒死处理、T2 的追击都结算完，才轮到插队的人。
- 公演插队排在还没开始的额外回合前面；已经开始的额外回合要走完才让位。
- 抢台只是把自己这一轮的标准回合提前用掉，原来的位置不再行动。这一轮已经行动过的人不能靠抢台再动一次，只能等下一轮。

在自己的标准回合里，如果 T0 之后到了 2 SP（比如在 T0 用手术「演出！要开始了！」换了 1 SP），而公演位还空着，就可以直接在这个 T1 公演。这不算插队，也不会多出一个回合。

例子一（轮初）：甲、乙、丙这一轮的先攻是 5、4、2。R1 时甲和丙都是 2 SP，都报了名。R2 结算完，R3 开始：甲排在前面而且还满足条件，于是甲先行动，在 T1 公演，这一轮的公演位就用掉了。之后乙、丙按先攻行动。丙没抢到，2 SP 留着，下一轮再争。

例子二（轮中）：下一轮谁都没报名，先攻顺序是丙、甲、乙，乙有 1 SP。丙在 T1 攻击了乙，乙拿到关注，变成 2 SP。丙的回合结束后，乙申请抢台，于是乙的标准回合提到甲前面，在 T1 公演；然后甲行动。乙原来排在最后的那个位置就没有了。

#### 精确结算（可以跳过）

```text
R3 开始时，以及每个回合完整结束后，按下面的顺序决定下一个行动的人：
1. 公演位还空着：按先攻找第一个“标准回合没开始、满足公演条件、想公演”的人
   （R3 开始时先看 R1 报了名的人，再看其他人）→ 开始他的标准回合，T1 公演
2. 没人抢：有等着开始的额外回合 → 按先攻找最前的一个，开始这个额外回合
3. 都没有：按先攻找下一个还没开始标准回合的人
4. 谁都没有了：进入 R4
```

### 6.4 三种演出

| 演出  | 花多少 SP | 在回合的哪一步                   | 占公演位吗    |
| --- | ------ | ------------------------- | -------- |
| 即演  | 1      | 多数用 T1；少数准备型的在 T0 发动，看各天赋 | 不占       |
| 大即演 | 2      | 看各天赋                      | 不占       |
| 公演  | 2      | 只能是自己标准回合的 T1             | 占，每轮只有一个 |

大即演是 2 SP 的强化即演。它不占公演位，所以也不能用来插队；强度不比公演低，区别只在入口。目前只有 G2 和 G5 有大即演。

即演和大即演都不会多给你一个主行动：用 T1 发动的话，这个回合就不能再普通攻击了。

演出前一样要先预检：没有合法目标、SP 不够，就不能发动，也不扣 SP；发动之后被闪避或被挡住，SP 不退（§3.3）。

### 6.5 什么时候不能演出

- 额外回合里可以即演和大即演，不能公演。
- 单步追击和受限反应都不能演出，它们也没有自己的 T0。
- 被控制时能做什么见 §3.6。这一回合没有 T0（比如中了失神）的话，T0 的准备型即演也就用不了。
- 天赋写明“用完”“失效”的，只是那一项能力。SP 照常涨，其他演出照常用，除非天赋另有写明。

### 6.6 一次行动不重复领奖

你的一次 T0 动作或一次 T1 主行动，连同它里面的所有步骤（连发的每一段、宏里的每一枪、范围攻击的每个目标、附带的余波），算作一个**根行动**。

各种奖励的额度不一样：

| 奖励               | 额度                 |
| ---------------- | ------------------ |
| 关注（SP）           | 每人每轮最多实际 +1（§6.2）  |
| 破甲 PP            | 每人每轮最多一次（§5.3）     |
| 击杀 PP            | 不限，每杀一个都拿（§7.3）    |
| 天赋的专属资源（比如追忆、笑点） | 多数按根行动限次，具体写在各天赋小节 |

按根行动限次的奖励，同一个根行动里只领一次，不会因为打了好几段、打中好几个人就领好几份。

需要注意的是，这些额度只限制奖励，不限制战果。多段、多目标造成的伤害、破甲和击杀，仍然一笔一笔记进战果分（§7.1）。

没有根行动的系统效果，比如 R4 的灼烧和终焉伤害，同一批算作一个根行动。

## 七、计分

### 7.1 终分怎么算

游戏结束时，每个人的终分这样算：

```text
终分   = 战果分 + 高光分 + 终幕王冠
战果分 = 击杀数 × 6 + 对其他玩家造成的实际伤害总量 ÷ 4（向下取整）+ 打碎别人普通外甲的件数 × 1
高光分 = 完成的剧情章数 × 4 + 终局时手里剩下的 PP
终幕王冠 = 6，条件见下
```

几点说明：

- 只算对其他玩家做的事。打警察、无人机这些非玩家单位，或者打自己，都不进战果分。
- 伤害只算实际扣掉的血，溢出的不算（§5.2）。伤害是整局累加之后再除以 4，不是每一下单独取整。
- 打碎一件甲，战果分 +1。破甲还可能带来 PP 和关注（§5.3），它们分开算；破甲也不会再折成一笔伤害。
- 击杀和伤害一般记在动手的人头上。少数天赋会把战果记给别人，看各天赋小节。
- **终幕王冠**只发给唯一的最后存活者，而且他至少有 1 次击杀，或者至少完成了 2 章剧情。0 击杀又不到 2 章的幸存者拿不到王冠。几个人同时活着结束（比如 40 轮兜底）或者同时全灭，都没有王冠。

举个例子：你是最后存活者，整局击杀 2 人，对别人造成了 23 点实际伤害，打碎了 2 件甲，完成 2 章剧情，手里剩 3 PP。

```text
战果分 = 2 × 6 + 23 ÷ 4（向下取整为 5）+ 2 × 1 = 19
高光分 = 2 × 4 + 3 = 11
终幕王冠 = 6（你有击杀）
终分   = 19 + 11 + 6 = 36
```

### 7.2 死后不打折

活着本身不加分，死了也不扣分：生前拿到的战果分、剧情章和 PP，死后照样算。
*早期版本的终分有乘数：活着的人乘 1.5，死了的人乘 0.5，天赋还有各自的槽位乘数。GA 把这些乘数全删了，免得大家靠躲着不打来赢分。*

三种死法的区别见 §5.6：普通死者在往世层还能继续挣 PP、花 PP；绝对死亡和退场的人，PP 停在死的那一刻。

### 7.3 PP 怎么挣，怎么花

PP 是演出积分，终局时手里剩多少，终分里就加多少。

| 怎么挣       | 多少  | 限制                                  |
| --------- | --- | ----------------------------------- |
| 击杀其他玩家    | +2  | 不限                                  |
| 完成一章剧情    | +1  | 每章一次                                |
| 打碎别人的普通外甲 | +1  | 每人每轮最多一次，这一轮碎几件都只拿一次；战果分里的破甲照常一件一件算 |
| 死后在往世层押中  | 分红  | 见 §9.2                              |

同一个行动同时满足好几项，可以分别拿。PP 不会自己涨，也不会自己掉，没有上限；挨打、公演本身、帮别人、空操作都不给 PP。绝对死亡和退场的人 PP 冻结，之后既不挣也不花。

| 怎么花     | 多少  | 限制                     |
| ------- | --- | ---------------------- |
| R1 重掷先攻 | 1   | 每人每轮最多一次（§6.3）         |
| 往世层的微光  | 2   | 死者自己花，或者活着的人替死者付（§9.3） |

完成的剧情章永远算数，但 PP 只看终局时实际剩多少：完成第三章时有 8 PP，后来花了 3，终局这一项算 5，不算 8。

### 7.4 剧情章

每个天赋都有三章剧情。完成一章，终分 +4，同时拿 1 PP。

- 每章只算一次。一个行动同时满足好几章的条件，可以连着解锁。
- 预检失败或者没有效果的空操作不算；条件里说的“有效”按 §5.7 判断。
- 完成的章节永久保留，死了也不丢。

| 天赋  | 第一章         | 第二章         | 第三章                            |
| --- | ----------- | ----------- | ------------------------------ |
| T1  | 斩击造成有效伤害    | 斩击破甲        | 公演穿屏障伤到本体，或斩击击杀                |
| T2  | 隐匿攻击造成有效伤害  | 成功发动如影随形    | 两个不同轮次各有一次演出生效（拿到东西，或惧怖至少挂上一人） |
| T3  | 玉璋实际承担攻击    | 天星成功石化      | 对自己石化的目标完成破甲或击杀                |
| T4  | 完成一次有效起卦    | 累计三种卦象      | 公演生效，且累计四种卦象                   |
| T6  | 合法热线或个人有效攻击 | 整备编队或个人破甲   | 完成一次执法击杀或个人击杀                  |
| T7  | 挂上复活        | 祝祷产生实际治疗或净化 | 复活生效                           |
| G0  | 实际挂载两种强化    | 无人机协同有效射击   | 四件强化都挂载过，且释放过十字炮火              |
| G1  | 进入次级燃烧      | 完全燃烧中有效攻击   | 完成燃烧窗口并存活，或繁育中获救/胜出            |
| G2  | 首次演出生效      | 白键和黑键累计六枚   | 进入任一终局                         |
| G3  | 持续投影在实战生效   | 结界内完成有效连发   | 幻想崩坏造成有效伤害                     |
| G4  | 黎明创世造成有效伤害   | 进入救世主       | 焚诏反击或死星天裁造成有效伤害                |
| G5  | 讲故事生效       | 第二阶段献诗生效    | 升格，或三个不同轮次有效献诗                 |
| G6  | 实际取得笑点      | 当身或插入式笑话成功  | 公演礼盒累计结算三次，可跨公演                |
| G7  | 完成一次融合      | 双融合并执行战术宏   | 全弹倾泻有效命中，且曾主动架盾承伤              |

### 7.5 游戏怎么结束，谁赢

出现下面任何一种情况，游戏结束：

- 只剩一名玩家活着；
- 所有玩家在同一批伤害里同时倒下；
- 第 40 轮的 R4 结算完，还有好几个人活着。这是防止对局失控的兜底，按当时的分数结算。正常对局走不到这一步；
- 少数天赋写明的结局，看各天赋小节。

同一批范围伤害会先把所有人的濒死都处理完，再判断游戏是否结束（§3.1）。

结束后公布两类赢家（§1.1）：

- **最后存活者**：结束时唯一活着的人。同时全灭，或者兜底结束时还有好几个人活着，就没有最后存活者。
- **综合评分第一**：终分最高的人。同分就并列，不按生死分高下。

## 八、警察

警察是场上的公共执法力量，不属于任何玩家。警察局里驻扎着一支 3 人的**防暴编队**，每名特警 HP 6，没有外甲。特警不是玩家：没有自己的回合，打他们不算犯罪，也不进战果分。和警察关系最密切的天赋是 T6（§11.5）。
*早期版本里警察是 3 个各自寻路、各自行动的 NPC，报案还要凑齐 4 类证据。GA 把他们合成了一支跟着队长走的编队。*

### 8.1 案底与通缉

下面两种事会让你留下**案底**：

- 对其他玩家造成实际扣血（少数天赋有免罪的效果，看各天赋小节）；
- 在军事基地拿装备而没有用黑市通行证（§4.5）。

每一桩案子都会记下当时的目击者，也就是和受害者在同一地点、还活着的玩家（军基的案子记拿装备时在场的人）。之后才走过来的人不算目击者。案底是公开的，而且永远不会消失。

有案底才能被挂上**通缉**。受害者或者目击者可以去警察局，花自己的 T1 举报，把犯人挂上通缉，但不能举报自己。少数天赋可以不去警察局、直接远程挂通缉，看各天赋小节。通缉名单按挂上的先后排序，挂上之后不会自己撤销。

被通缉的人会成为编队的合法攻击目标（§8.2），也不能申请当队长（§8.3）。

举个例子：你在商店砍了乙一刀，乙扣了 4 血，当时商店里还有丙。这桩案子的目击者是你、乙、丙。之后乙或者丙去警察局用一个 T1 举报你，你就被挂上了通缉。

### 8.2 编队怎么打人

编队每轮只能攻击**一次**。下面三种攻击共用这一次，谁先用掉就算谁的：

1. 队长在机动姿态下用普通攻击打一个被通缉的人，编队跟着合击同一个人；
2. 队长花自己的 T1 下令攻击，编队立刻开火；
3. 每轮 R4 的警务阶段，编队自动攻击通缉名单里第一个能打的人。

能打的目标要同时满足：被通缉、活着、没有隐身、没被隔离在编队进不去的空间里（比如某些天赋的结界）。不看地点，跨建筑也能打。

编队一次攻击的伤害是 **2 + 存活特警数**，满编是 5，普通属性。T6 可以给编队升级，升级后变成 3 + 存活特警数（满编 6），科技属性。这一击按普通攻击结算：要判定命中（没命中就是擦伤），也会被屏障和外甲挡（第五章）。只有特警全部被控制住时，这一次才打不出来。

编队打出的伤害和击杀算队长的战果；没有队长时，谁的战果都不算。编队攻击本身不算犯罪。

需要注意的是，队长下令攻击一个没被通缉的人，编队不会开火：这一下直接折损 1 名特警，姿态也被打回机动，队长这个回合的 T1 也就白用了。队长自己用武器打人不受这条限制，但会按 §8.1 留下案底。

举个例子：满编的编队在 R4 自动攻击通缉犯乙。乙没有外甲也没有屏障，这一下命中的话扣 5 血；如果之前已经有 1 名特警阵亡，就是 4 点。这一轮之后队长就算再下令，编队也不会打第二次。

### 8.3 当队长

在警察局用 T1 可以申请当队长。条件是：警察正常运作（§8.5），现在没有队长，你没有被通缉。到下一轮的 R2，在所有申请的人里，按先攻排最前、还活着、没被通缉的那个人就任；其他人的申请作废，想当的话得重新申请。

就任之后，编队跟着队长走：队长移动、被钩索拉走、被赶出被摧毁的建筑，编队都跟到同一个地点。队长死了，队长的位置就空出来，编队回到警察局，姿态恢复成机动。

队长可以在 T0 切换编队的姿态，这会用掉这个回合的 T0：

- **机动**（默认）：队长正常移动；队长用普通攻击打通缉犯时，编队跟着合击。
- **盾墙**：队长身上多出一层盾墙屏障。切到盾墙的这一轮，队长不能 move。盾墙姿态下队长打人时编队不跟着合击，但下令攻击和 R4 的自动攻击照常。

*死战不退这一块 cos大叔这一块 队长一天到晚刚发育成型就被星野一个雷霆架盾堵门口，然后10cost一轮五枪点死
现在终于可以让别人尝尝这是什么感受了。无天赋局星野模拟器说是。*

盾墙的耐久来自编队的**盾墙池**：每名存活特警 4 点，满编 12（T6 升级后每人 6 点）。盾墙只挡单体攻击，不挡范围攻击；写明从背后打的攻击也能绕过它。盾墙池是真实的耐久：挡多少扣多少，来回切换姿态不会回满，池子空了就切不成盾墙。任何人都可以在警察局花 T1、付 2 信用点修盾墙，盾墙池 +4，最多回到上限。

### 8.4 怎么对付编队

- 范围攻击会同时打到同一地点的特警，盾墙也挡不住范围攻击。
- 让队长中震荡、被闪光弹晃到（道具和天赋造成的都算），或者用钩索把他拉走，盾墙姿态马上解除，回到机动。
- 直接打特警：近战要在同一地点，弓和枪可以跨地点打。
- 队长一死，编队就回警察局，没人指挥。

### 8.5 警察停摆

下面任何一种情况，警察都会暂停执法：编队不攻击，盾墙失效，也不能申请当队长或者修盾墙。

- 警察局被摧毁（§2.3）；
- 特警全部阵亡，或者全部沉沦；
- 天赋的全局效果让警察停机：G2 的世末之雨、G5 的时间倒流、G7 的Terror（§10.3）。

停摆期间，案底照常记录，也照常可以举报、挂通缉，不会因为停摆被洗白；恢复以后照常执法。几种停摆原因互相独立，解除其中一种不会连带解除别的。阵亡的特警不会自己回来，要靠 T6 的作战再部署补员（§11.5）。

## 九、往世层

### 9.1 死后能做什么

普通死亡的玩家会进入**往世层**（绝对死亡和退场的不进，§5.6）。在往世层里没有回合，不能移动也不能攻击，但每轮 R0 可以做三件事：押注、微光、Encore。它们都不占任何人的回合。

死者手里的 PP 照常计入终分，在往世层挣到的也算（§7.2）。
*早期版本的往世层有 26 种不同的援助要背，GA 只留了这三个按钮。*
读这份手册的时候可能到这里已经注意力稀疏了，往世层被设计得避免你背诵任何新内容。
因为它的三个权能都基于你已经知道的东西。

### 9.2 押注

每轮 R0，死者可以押一名活着的玩家，也可以换成押别人。押注不花钱，只对押下之后发生的事有效，不能等结果出来再改。

被你押的人做到下面这些事，就从固定的奖池里给押中的人分 PP：

| 被押的人做到      | 奖池                  |
| ----------- | ------------------- |
| 击杀一名其他玩家    | 2 PP                |
| 打碎别人的一件普通外甲 | 1 PP（同一个被押的人每轮最多一次） |
| 游戏结束时拿到终幕王冠 | 2 PP                |

好几名死者押中同一个人，就均分这个奖池；分不尽的余数按死者编号轮流每人多给 1。奖池大小是固定的，押的人再多也不会变大。没人押中，这个奖池就不发。

举个例子：甲、乙两名死者都押了丙，丙杀了一个人：奖池 2 PP，甲、乙各拿 1。要是甲、乙、丁三名死者都押了丙，这 2 PP 分三份：每人先分到 0，余下的 2 按编号轮流给甲、乙各 1；下一次再有余数时，从丁开始接着轮。

被押的人死了，押注就落空了，下一轮 R0 记得换人。

### 9.3 微光

每轮 R0，每名死者可以对一名活着的玩家放一次**微光**，花 2 PP，三选一：

| 微光  | 效果                                                                   |
| --- | -------------------------------------------------------------------- |
| 赐福  | 给目标一层 3 点的临时屏障，持续到下一轮的 R4；或者给目标回 2 HP（目标没满血时才能选）                     |
| 启示  | 目标这一轮先攻 +2，并且 SP +1（最多 2）                                            |
| 凝视  | 目标立刻现形（隐身失效），而且下一次被普通伤害打到本体时多受 2 点伤害（和易伤一样算在外甲之前；如果那一下是擦伤，这 2 点就浪费了） |

这 2 PP 可以由死者自己付，也可以由目标付：活着的玩家可以向死者**求援**，由死者放微光、目标付钱。目标拒绝的话不付钱，也不生效。

限制：每名死者每轮最多放一次；同一名活着的玩家每轮最多接受一次微光，几名死者不能给同一个人叠加。付钱的人和受益的人都是公开的。

### 9.4 Encore

每名死者整局有一次 **Encore**：把自己生前天赋的一个简化效果借给一名活着的玩家。原初天赋的死者借出自己 1 SP 即演的简化版；神代天赋的死者从 7 枚简化标记里选一枚借出（§13.3）。借出去的只是这一个效果，不是整套角色能力。

借到的人用的时候，照样要有合法目标和足够的资源。借来的标记一直等到触发才用掉，到游戏结束还没触发就作废。个别天赋借出的效果有限制，看各天赋小节。

## 十、世界时钟

### 10.1 四个阶段

世界时钟决定对局进行到了哪个阶段。阶段按**时钟刻度**划分，不按实际轮数（§10.2）：

| 阶段  | 时钟刻度  | 有什么变化                      |
| --- | ----- | -------------------------- |
| 黎明  | 1～4   | 开局发育期                      |
| 白昼  | 5～10  | 死者身上的东西开始掉在原地（§5.6）        |
| 黄昏  | 11～15 | 一些神代天赋的终局能力从这里开始能用（看各天赋小节） |
| 终焉  | 16 起  | 每轮 R4 所有活着的玩家受到环境伤害（§10.2） |

*某种意义上这就是我们的毒圈，从那个类跳伞机制后第二个有点像大逃杀的机制。*
*早期版本一局常常要打 40 轮左右，GA 用世界时钟把节奏往 15～20 轮压。*

### 10.2 时钟怎么走

第 1 轮的 R0 时钟是 1，之后每轮 R0 走一格。只有 R0 会推进时钟。

时钟刻度和实际轮数是分开数的（不然打着打着突然发现回到第一轮了谁绷得住）。平时两者一样；G2 让时钟加速之后，时钟每次走两格；G5 的时间倒流期间，时钟不走。实际轮数永远每轮 +1。时钟一次走两格也只是刻度变了，不会多出一轮行动，也不会多一次警察攻击、回血或状态计时。

到了终焉，每轮 R4 的环境阶段，所有活着的玩家受到一次真伤，数值是**当前刻度 − 15**：刻度 16 是 1 点，20 是 5 点，之后每格继续 +1。时钟被加速过的话，这个伤害翻倍；时间倒流期间没有终焉伤害。这一下不判定命中，外甲挡不住，屏障能挡（§5.4）。它没有凶手，被它打死不算任何人的击杀；被打到的人照常拿关注（§6.2）。

举个例子：刻度 18 的那一轮，R4 时每个活着的玩家受到 3 点真伤；如果时钟已经被加速过，就是 6 点。

第 40 轮结束时还有好几个人活着的话，按当时的分数结束游戏，见 §7.5。

### 10.3 好几个改变世界的效果同时生效

有几个天赋能改变整个世界的规则：G1 能摧毁地点；G2 的终局能让时钟加速，或者让世末之雨笼罩全场；G5 升格到第三阶段后能让时间倒流；G7 化为 Terror 后，警察会停机。它们同时生效时这样处理：

- G5 的时间倒流期间，时钟不走（就算 G2 已经让时钟加速了也一样），终焉伤害暂停，警察和其他 NPC 停机。普通状态和各天赋自己的倒计时照常走。
- 倒流结束后，如果 G2 之前让时钟加速过，加速继续生效，就算 G2 已经死了或者被救回来了也一样。
- G2 的世末之雨期间，警察和其他 NPC 沉沦停机；雨停后解除，但这期间死掉的 NPC 不会复活。
- 警察停机的几个原因互相独立（§8.5）。比如 T6 的诗把警察局重建了，只要世末之雨或者倒流还在，警察照样停机。
- 地点被摧毁时，里面的玩家按 §2.3 分到其他还立着的建筑，天赋召出来的单位和 NPC 也一起被赶出去。
- 往世层在倒流期间照常每轮 R0 行动，死者不受倒流的限制。

### 11.1 T1「一刀缭断」

*这个游戏还处于口口相传年代就已经存在的元老，只略晚于T4和T7，以及现在构成T2的几个子效果（那时候是独立天赋）*

### 11.2 T2「慈爱的怪盗」

*在写手册说明时突发奇想决定小小重置一下。原型现在为Blue Archive的七囚犯之一，“慈爱之怪盗”清澄晶（Akira）*
*不是我害了你（不给G等级只给了T等级），而是这个Nexon害了你啊（多少年卫星了还没实装）*
*什么时候你实装了给你一个神代的位置好吧*

*「仅凭空话的话，要多少甜言蜜语编不出来呢？」
「最后所有人都会留下相同的话语并离我而去。怀疑、拒绝、排斥……我是个无可救药的怪物啊。」
「但愿有朝一日，真正的理解者能够出现——回去吧，在我不可自已地彻底将你偷走之前。」*

获得如下被动效果：

- 开局时额外获得一件隐身衣。
- 打伤玩家但没打死，不算犯罪；打死照样立案（§8.1）。
- 还没杀过人的时候，攻击不会让自己现形。完成第一次击杀的那一刻立刻现形，之后攻击也会和别人一样现形。
- 你的攻击每有 2 次让对方的外甲扣了耐久，就给自己身上同一种、还没碎、也没满的外甲修 1 点耐久；身上没有同一种甲就没有效果。

在此之外：

- **即演(1 SP)**：占据T1，立刻获得当前地点的一件可获得物品（包括商店的商品，魔法所的法术，军事基地的装备等等）且跳过前置检查，不消耗信用点等消耗资源，无法计入犯罪记录。
- **公演(2 SP)**：占据T1，对同地点的所有其他玩家立刻施加debuff「惧怖」：直到其下一个行动回合开始时，获得脆弱效果（受到的普通伤害 +1，§5.2）并且下一个行动回合不能使用move。两个效果在debuff未能成功被施加时都不生效。

**如影随形**是一个反应：和你在同一地点、你看得见（§3.5）的人主动 move 离开时，你可以花 1 SP 跟过去，然后二选一：自动 lock 对方，你下一次攻击他时享受 lock 的全部加成（§5.2）；或者指定对方的一件与天赋无关的物品，偷窃得手。整局最多用 2 次。它不占你的回合，也不给你额外的 T0 或 T2。

要注意的地方：

- 开局送的隐身衣不会让你自动隐身，想隐身得自己花一次 T1（§3.5）。
- 即演拿东西不花信用点、不用黑市通行证，也不算犯罪；但店里得有货，你得拿得下（持有上限、同一种武器只能有一把），每局限购的东西照样算次数。拿枪会带上它正常的初始子弹。
- 打工、治疗、手术、修甲、补箭补子弹这些是服务，不是东西，拿不了。死者掉在地上的东西还是用普通的 interact 去捡（§4.1）。
- 拿东西不引人注目：不给关注（§6.2），所以这 1 SP 不会被关注补回来。拿东西也不会让你现形。
- 惧怖不判定命中，也不扣血，所以不算犯罪。但它算敌对行动：你杀过人以后再用，会和攻击一样让你现形。
- 惧怖对同一地点的其他玩家都生效，隐身的人也逃不掉；特警等 NPC 不受影响。对状态免疫的人挂不上，脆弱和不能 move 都没有。再挂一次只是刷新，不会叠成两个回合。
- “下一个行动回合”也包括额外回合；那个回合要是被控制跳过了，惧怖也算用掉了。本来就脆弱的人，脆弱不叠加，还是 +1。
- 被惧怖禁止 move 的那个回合，如果你又用了要求这回合只能 move 的效果（比如 G2 的「消失前　做出最温柔的给予」），这次主行动就只能放弃。
- 传送和被强制移走不算主动离开，不会触发如影随形。不跟过去不花 SP，也不用次数。
- 选了 lock：之后你第一次攻击他时享受 lock 的加成，用掉为止；和你那回合自己做的 lock 不叠加。这个 lock 不会让他对你现形。
- 选了偷：能偷一件武器（拳头和天赋专属的除外）、一件没碎的外甲（连同当前耐久）、一个模块（弓上装着的也行）或一件道具；不能偷法术和信用点。偷枪或弓时，它的子弹或箭一起拿走，你装不下的部分留给对方；弓上装的模块也留给对方。你拿不下的东西不能选。
- 如影随形的偷窃不算犯罪，也不会让你现形。
- Encore 借出你的能力时，只借即演拿东西（§9.4）。

| 第一章            | 第二章       | 第三章                                |
| -------------- | --------- | ---------------------------------- |
| 隐身时发动的攻击造成有效伤害 | 成功用一次如影随形 | 在两个不同的轮次，各有一次演出生效：拿到东西，或者惧怖至少挂上一个人 |

献给你的诗：「夜行」（§13.2）。

*以自己或对手墓地的1只怪兽为对象可以发动。将该怪兽特殊召唤至自己场上……
什么，你说这是游戏王原文？这名字不就从游戏王来的？

| 挂复活（即演） | T1   | 1 SP      | 给一名活着的玩家挂上复活，可以是你自己                                   |
| 挂复活（公演） | T1   | 2 SP，占公演位 | 同上，但HP恢复到满。                                           |
| 祝祷（即演）  | T1   | 1 SP      | 场上已经挂着复活、或者复活已经用过时才能用：给一名活着的玩家回 3 HP，清掉他身上的普通状态和能清的灼烧 |

复活有如下特点：

- 全场同时只能挂一个复活，这一份用掉之前不能再挂新的。你死了，你挂上的复活仍然可以正常生效。
- 被挂复活效果的人普通死亡时，先看他自己有没有免死（§5.5）；没有才触发复活：
  - 原地复活；原地的建筑被摧毁了就去医院，医院也没了，就按商店、魔法所、军事基地、警察局的顺序，去第一个还立着的公共建筑；
  - HP 恢复到最大 HP 的一半（向上取整），公演挂的复活恢复到满；SP 变成 0；
  - 背包和装备都保留，特别地，外甲的耐久不恢复，普通状态和灼烧清除，屏障和隐身保留；
  - 有次数限制的天赋能力、这一轮已经用掉的额度，都不会刷新；
  - 这次死亡和击杀取消，但已经造成的伤害和留下的案底不被清除。
- 绝对死亡和退场不在复活范围之内。被挂载效果的人绝对死亡或者退场时，复活回到未挂载状态，需要重新指定被挂载对象。
- 打出这次复活效果的攻击不使得被救的人被关注。

要注意的地方：

- 复活每局只能生效一次，诗篇可以让它再生效一次（§13.2）。复活生效以后只是不能再挂了，关注照样涨 SP，祝祷照样能用。
- Encore 借出只包括祝祷，不包括复活。

| 第一章  | 第二章           | 第三章  |
| ---- | ------------- | ---- |
| 挂上复活 | 祝祷真的回了血或者清了状态 | 复活生效 |

献给你的诗：「彼岸」（§13.2）。

## 十二、神代天赋 G0–G7

*以复刻角色或叙事张力为追求，管理复杂资源，且可以剧烈地改变游戏现实的类boss不对称技能或复杂子游戏系统。
                                                                                              ——Devin wiki*
神代天赋是 V2.0-GA 的设计雄心所在，很大程度上也是这个游戏存在的原因。相比于称之为“天赋”，还是更像“角色”一些。
八个叙事前提不同的，来自不同世界的角色借由这个系统共享同一个战场。在SP/PP的基础上使用完全不同的资源语言（火种 / 魔力 / 追忆 / Cost / 孤独值 / 色彩 / 笑点 / 失熵），相互之间又有预置的交叉影响点。

写在前面：

严格来说，这个名字是不太适合现在的黑子的。她自从第一章终章的剧情结束后已经走出了一周目的阴霾。她接过了白子递过来的头套，将过去伙伴们的武器丢弃在了沙漠里，成为了本周目阿拜多斯在星野前辈之后的第二个守夜人。

很高兴能看到她走出了自己的心结。

借用隔壁的理论：同样的一个人，在不同的世界线里，起点都是一个点。和他有关的信息，从此在时间线上以光速向外扩展，呈现出一个倒锥形，这就是「光锥」。

因此，我们不妨也从这样的一个光锥上选取另外一个点：那个在绝望中弄丢围巾，亲手处决掉荷鲁斯，打碎了时亭之匣，但却因为sensei自愿献祭成为诱骗者而没有被色彩进一步侵蚀，保留了自己意志的黑子。如果基沃托斯没有第二周目而独自来到了这里，会是怎样的场景？

作为「死神」，存活下来直到将整个世界引渡到毁灭，自然是她的责任。但或许，绝望到近乎漠然的她会在这里心生一丝不忍，甚至生出一丝希望——毕竟，这个世界可能也是一个「奇迹的起点」。

这个天赋的原型其实和流萤没什么关系——那时候没有崩铁。我记得好像是有节课下课了，班里的传奇DM（整个游戏的灵感其实是他的，这哥们带D&D团水平也是一绝）问我来不来一盘快攻。我问他怎么个快攻法，他说他开个斑纹——伤害翻倍，伤害减半，但是只能活十个还是十五个轮次，如果结束的时候我没被杀，就是我赢了。

这段记忆留到了六年后。我在思考如何用规则刻画萤萤的弧光时，这段记忆被我打捞了上来。

流萤的故事，从不会做梦的量产铁骑，效忠于不存在的格拉默女皇直至国家、战友与蝗灾一同覆灭，一直到她加入星核猎手，希望从今往后能摆脱失熵症，成为流萤，成为一个平凡的，可以用自己的身体做自己想做任何事的女孩子，已经很长了。将来还会更长。把这么长一个故事复刻成一个技能，那太不聚焦了。所以，我提取了关键词“燃烧”。截止到目前，她的一生都是在燃烧。只不过，过去她在为不存在的女皇而战，而如今，她将为生而战，为了一切自己所爱的继续燃烧。至于作为自机角色的流萤，由于这个游戏现在没有韧性条的概念，自然也没有根据削减韧性出伤的超击破概念，能借鉴的就少些。将来如果做机制升级，倒是有可能加上来。

**炽愿**：超新星每命中 1 个单位，你获得 1 层炽愿；每用超新星击杀 1 个单位，再获得 1 层；最多 3 层。每层炽愿可以吸收 2 点伤害：你受到伤害时，先由其他屏障吸收，剩余部分再由炽愿逐层吸收（§5.1）。一层吸收满 2 点即消失，超出的部分由下一层继续吸收；未吸收满的层保留剩余点数，获得新的炽愿时不会补满它。失熵结算时，若你有炽愿，则直接移除 1 层抵消该次结算（见下），不论该层还剩几点。

**失熵**：从 0 开始，最多 12，所有人可视的状态。每轮 R4 按你本轮到达过的最高形态增加：卸甲 +1，次级燃烧 +2，完全燃烧 +3；若本轮你未发动过攻击（超新星视为攻击），则再 −1。失熵达到 6 或以上时，减少 4，随后进行一次失熵结算：

1. 若有炽愿，消耗 1 层抵消此次结算；
2. 否则，摧毁一件由你选择的外甲；
3. 若没有未破碎的外甲，受到 4 点真伤（§5.4）。

完全燃烧结束时，你回到卸甲常态，并立即进行一次失熵结算，不论当前失熵是多少。

**第三次死亡（繁育）**：每局 1 次。若你本局开启过完全燃烧，且当前处于次级燃烧或完全燃烧，则第一次受到致命伤害时（附带绝对死亡的除外，§5.5）不会死亡，而是进入繁育：

- β模块-天火：HP 变为 8（不超过最大 HP），先攻 +3，攻击伤害 +4，受到的普通伤害 −1；
- 飞萤之火：清空自身所有debuff并无视包含压制、石化、震荡和失神在内的所有debuff（§3.7）；
- α模块-偏时进发：每轮第一次 move 都会被替换成DHGDR-超新星过载：不消耗 SP，不消耗可用次数，伤害 6、灼烧 2 层；结算后永久摧毁落点的建筑（§2.3）；落点可以没有其他单位；
- 坠落在燃烧的天空：在自己的回合内完成击杀后，可以在 T2 追加一步行动：移动或攻击一次，该步也可以是DHGDR-超新星过载（§3.4）；
- 倒计时 3 轮（进入当轮不计），倒计时结束时绝对死亡（§5.6）；期间再受到致命伤害，则正常死亡；
- 若倒计时结束前游戏已经结束（例如只剩你一人存活），你不会死亡。

要注意的地方：

- 完全燃烧的追加一步：你每个回合的 T2 可以再进行一次普通移动或攻击（§3.4）。每轮限一次，与其他追击共用额度；该步不能发动超新星。
- 完全燃烧期间不能主动卸甲，也不能再次开启完全燃烧。进入繁育后不能再切换形态，也不会再次繁育。
- 超新星视为一次 move：无法 move 时（例如受到 T2 的惧怖影响）同样无法发动。超新星不判定命中，处于隐身状态的玩家和特警同样受到伤害。形态的攻击加成不适用于超新星，γ模块-内核脉冲正常生效。
- 失熵按“本轮到达过的最高形态”计算：本轮处于过次级燃烧，即使之后卸甲，仍按次级燃烧增加。
- 失熵结算不视为受到攻击：因失熵失去的 HP 不产生关注（§6.2），也不计为任何人的犯罪；失熵摧毁外甲、炽愿抵消失熵，同样不产生关注。
- 世界时钟进入终焉后（§10.1），失熵不再变化，也不再因达到阈值而结算；完全燃烧结束时的结算仍然进行。繁育期间失熵同样不变。
- 医院手术「演出！要开始了！」使每轮增加的失熵减少 1（§4.4）。

- 所有已见证的武器均可直接用于攻击，无需先投影。
- 主目标只能是被困入的单位。每个 T0 可以重新指定主目标，不占用 T0。

**赤原猎风**：同一次连发累计消耗的魔力达到 5 后（使累计达到 5 的那一发计入），每命中一名玩家，其 SP −1，且本轮无法公演。每次结界中，每名玩家最多受到一次。首次触发时，点亮**理想燃烧的地狱**。

**幻想崩坏**：点亮 理想燃烧的地狱 后，可以在本次连发的最后接续发动，也可以之后用一个 T1 单独发动。消耗你剩余的全部魔力（至少 2 点），对主目标发动一次攻击，正常判定命中：伤害为 4 + 本次结界中投影过的式样数（最多计 4 种），普通属性，外甲的属性防御减半，双倍磨损（§5.3）。结算后结界立即结束。

**火种**：世界通往下一个黎明的希望。初始 0，最多 12，只在人形态下积累：

**终结之始**：人形态受到致命伤害时（附带绝对死亡的除外，§5.5），若火种不少于 6，你不会死亡，而是消耗当前全部火种，化身残缺的救世主：每消耗 1 点火种，余烬生命为 2（12～24），初始毁伤为火种数的 1/4（向下取整，最少 1）。

**永劫燔世，其将背负**：

在救世主形态下：

- 你的 HP 替换为余烬生命，原有 HP 暂存。余烬生命无法被任何手段（包括医院的治疗、急救装置或手术）治疗。
- 救世主形态下不积累火种，持续 3 轮（化身当轮不计）。
- 出现以下任一情况时，你退回人形态，火种、毁伤与场上的「直面烈阳」印记清零：死星天裁结算完毕、3 轮到期、余烬生命耗尽。完整救世主在死星天裁结算完毕或 3 轮到期时恢复原有的 HP；残缺救世主在上述两种情况下以 5 点 HP（不超过原有 HP）回到人形态；余烬生命耗尽时你不会死亡（附带绝对死亡的除外），而是以 1 点 HP 回到人形态。
- 退回人形态后，可以重新积累火种并再次化身。

**灾厄·弑魂焚诏**：

1. 全场其他存活玩家（被结界隔离者除外）秘密选择**迎战**或**拒战**，再同时公开。
2. **迎战者的试炼**：
   - 迎战者按先攻从高到低，各使用一件普通武器对你发动一次攻击：无视距离，正常消耗弹药，没有可用武器则使用拳头。你在本次技能期间对迎战者的攻击获得 2 点固定减伤（§5.2）。迎战者的攻击与你的反击正常产生关注（§6.2），但不计为犯罪。
   - 所有迎战攻击结算完毕后，你获得 **ceil(实际完成迎战人数 / 2)** 点毁伤（最多至 9），并对所有存活的迎战者平分一个 **4 + 2 × 实际完成迎战人数** 点的反击总池（普通伤害，必中）。
   - 实际完成迎战的玩家获得**「直面烈阳」**印记（持续至你退出当前救世主形态）：你下一次发动【支柱·死星天裁】时，其第一段「星火弹射」不会以持有该印记的玩家为目标。
3. **拒战者的代价**：
   - 每有 1 名玩家选择拒战，你立即获得 **+1 毁伤**（最多至 9），且该拒战者附加**脆弱**与**失神**（持续至下一轮的 R4，§3.6、§3.7），并失去 1 点 SP（最低降至 0）。
   - 若全场无人选择迎战（全员拒战），你额外恢复 1 点 SP（即本次技能净消耗 0 SP）。
4. 若迎战者的攻击在途中耗尽了你的余烬生命，你立即退回人形态，焚诏中止，后续的迎战、毁伤获取、反击池与拒战惩罚均不再结算。

**支柱·死星天裁**：设你消耗的毁伤为 D（须 D ≥ 4，上限 9）

1. 此技能的释放不需要指定目标，作用范围为全场所有其他存活玩家（被结界隔离者除外）。
2. **第一段「星火弹射」**：连续坠落 **D 颗**陨石碎片，每颗造成 **2 点普通属性伤害**，不判定命中，逐颗独立结算（正常经过屏障与外甲，可触发破甲）。
   - **落点规则**：每颗碎片随机选择场上 1 名**未持有「直面烈阳」印记**的合法玩家为目标；若场上所有合法玩家均持有该印记（或无人持有），则在所有合法玩家中随机选择。目标在弹射途中死亡后，后续碎片不再分配给该目标。
3. **第二段「死星坠落」**：第一段全部结算完毕后，全场所有仍存活的合法玩家**平分一个 `2 × D` 点的天裁总池**（不判定命中）：
   - 当 **4 ≤ D ≤ 6** 时，该总池为**普通属性伤害**，外甲的属性防御当作 0（仍可被屏障与不耗甲的固定减伤抵消）；
   - 当 **D ≥ 7** 时，该总池升格为**真实伤害**（§5.4）；若该伤害致死，视为**绝对死亡**（§5.6）。
4. 两段全部结算完毕后，你退回人形态。

平分反击池或天裁池时，除不尽的余数按先攻从高到低（同先攻按玩家编号）每人多分配 1 点。

要注意的地方：

- 主动升格不消耗 SP，也不提供额外回合：升格占用 T0，升格后 SP 为 2、毁伤为 3。由于【支柱·死星天裁】要求毁伤至少为 4，刚升格的回合无法直接发动死星天裁，须先通过【创生·血棘渡亡】或【灾厄·弑魂焚诏】积累毁伤。
- 【创生·血棘渡亡】使毁伤增加的效果，每次行动最多生效一次；毁伤只存在于救世主形态，上限为 9。
- 【灾厄·弑魂焚诏】是 1 SP 即演，不占公演位；【支柱·死星天裁】是 2 SP 公演，占公演位。
- 「星火弹射」只以玩家为目标，特警、无人机等非玩家单位不受影响（若需清理同地点非玩家单位或磨甲，请使用【创生·血棘渡亡】的烈阳余波）。
- 被 G3 的结界与你隔离的玩家不参与弑魂焚诏，也不承受死星天裁的弹射与平摊。

然后我就拿着我回忆里的零散规则和G5的初稿去迫害蓝色大肥鱼了。它看完“先是大惊，然后不敢相信”（只是玩了个新三国的梗，它至少装得很冷静），然后把五十几条会导致崩溃的边界模糊条件拍到了我的脸上，最后（并不）谨慎地建议我把锚定整个砍掉。我也有点火气上来了，于是把整个规则书重新手写一遍，明确了几十条边界闭合补丁（在这份手册里已经看不到它们的痕迹了，上一个版本可以），然后把锚定的规矩也重新闭合了一次，它这才恭喜我可以撑地了（又是一个新三梗而已）终于设计出一个堪称独特的东西。嗯，无论如何，我还是感谢它的，没有它找茬的话大概不会有这份手册，也不会有后面的整个程序了。即使在这个版本里我最终只能砍掉了锚定。说不定你有这个实力把它从代码库里挖出来，然后复活呢？

晚安，昔涟。你已经将黎明带给了世界和那些等待救赎的人。祝福你有一天能迎来自己的明天。

即使平时看上去慵懒，星野毫无疑问仍然是二周目阿拜多斯最痛苦的人之一。阿拜多斯只剩下两个人的时候，星野从头到尾都是务实派，她不喜欢梦一天到晚还幻想着能恢复沙漠祭的理想主义气息，也总看不惯她次次被骗。但这并不妨碍两个人是在长夜中某种程度上相依为命的。最后两人发生激烈争吵，随后梦前辈独自进入沙漠寻找遗产，惨死在沙暴中。赶到的星野只来得及抱回了梦前辈的遗体。也就是从此开始，她开始扮演起了梦前辈的样子：开始从非常锐利的进攻转而拿起盾牌（圣遗物属实），留起水母头，用上了自称大叔的口癖，更像是在后辈面前扮演一个像梦一样温柔可靠的前辈。

但这终究只是个皮套，是星野用来扮演梦的皮套。或许这个皮套戴得越久就与她的性格愈发融合，但她的底色没有变——早年的经历让她在皮套底下仍然对大人保持警惕，并且极度珍视自己的同伴。她不愿任何人接触过去那段历史，希望自己一个人挑起大梁，以接近自毁的方式解决那一段过去所遗留下来的问题，这是她认为唯一可靠的解决方式。在 Vol1.3 里，幕后黑手地下生活者利用梦前辈死因的真相设局，彻底撕开了星野伪装成“散漫大叔”的面具。星野为了不让一年级、二年级的后辈（白子、野宫、芹香、绫音）被卷入危机，选择了最绝望的方式：撕毁同伴契约，试图推翻两个人时期的阿拜多斯学生会的合法性（说是白眼狼的 2B 小学怎么学的阅读理解，这明明就是又一次试图把账全都推到自己头上，然后再靠自毁解决）。**创伤应激不是一次热血喊话就能治好的。星野宁可自己化作怪兽堕入深渊，也决不能再承受一次失去后辈的痛苦。**于是所有的苦难她都在一个人承受，不能向后辈解释就得不到她们的理解，为了列车炮的事情想保护她们，还要和她们交战。最终日奈的一句“不理解”让她彻底炸了，陷入自我怀疑进而反转。这一切的逻辑是很通顺的（但是写到这里难免有点心疼）。

基沃托斯七之古则第一条：他人是能被理解的吗？第二条：通过无法理解之物，能否得到理解？
Sensei 也是人，某种意义上他比那些武力或者智力过人、但心智还没完全成熟的学生更像活生生的人。他在剧情里有下头的时候，有陪着学生犯错的时候，但更多时候，他是一个真正优秀的老师。可做老师不代表一旦你觉得自己掏心掏肺了、掌握上帝视角了、拿着大人的卡片想烧命就烧命了，受过重创的学生就必须立刻向你敞开心扉。同样是对大人抱有戒心，SRT 开局把“老师我们最讨厌你了”挂在嘴边，怎么到了宫子那里就能轻易原谅？无非是因为她后期表现得“卑女力”十足、顺从了某些人的爽感预期罢了。现实里辛辛苦苦去偏远地区支教、还要被小孩编排一堆黄段子的支教教师多了去了，那些孩子的情况都远不至于星野这么惨烈——一个亲历挚友惨死、又因为大人的骗局让学校背上九十亿高利贷的少女，对大人抱有本能的戒备与推拒，难道不是再合理不过的人性吗？如果连这种基于惨痛创伤的“不可理解与拒绝沟通”都要被审判为背叛，那所谓的“通过无法理解之物达成理解”，从一开始就只是一句叶公好龙的空话。

二游叙事或许受限于载体——心流混乱、编排不清、影响理解，甚至一度会让人以为 OOC——它的呈现方式确实有很多问题。但如果没有这一段撕开皮套、众叛亲离直至绝望自毁的挣扎，星野就不是我们认识的那个星野了。而文字叙事没能让你直观感受到的沉重，我会在这套规则里让你亲手体验一次：从捡起那面属于死者的盾牌开始，去感受那种每多撑一轮都在透支体力（失却汇流成泉）的疲惫，去看着身边的人一个个倒下直到色彩彻底失控，去在无人理解的自我怀疑中把所有的护甲与光环砸碎成最后燃烧生命的筹码。这就是我为星野写下的答案。

**色彩、自我怀疑与 Terror**：

- 色彩初始为 0。每有一名其他玩家死亡或退场（例如 G0 撤退），色彩 +2；若由你击杀，再 +2。
- 色彩达到 6 时：你可以在 T0 主动进入自我怀疑，本回合剩余部分只能放弃。
- 色彩达到 10 时：你下一次受到伤害并失去 HP 但未死亡时，强制进入自我怀疑，身上已破碎的外甲全部恢复至满耐久。
- 自我怀疑期间你无法执行任何行动，额外回合同样跳过。到你的下一个标准回合时，该回合被跳过，你化为 Terror；再下一个标准回合，你才能首次行动，其间的额外回合不能行动。
- 进入 Terror 时，你的外甲、铁之荷鲁斯和光环全部收起，折算为额外 HP：每件其他外甲 2 点（已破碎的同样计入），加上铁之荷鲁斯剩余耐久的 1/3（向上取整），再加上光环剩余点数；最少 12，最多 20。身上所有状态清除。
- Terror 只能执行 move 或攻击。攻击：对全场所有其他玩家各造成 4 点真伤（§5.4），不判定命中；若该伤害致死，视为绝对死亡（§5.6）；结算后失去 6 点额外 HP。每次 move 失去 2 点额外 HP。
- 其他单位对你造成的 HP 损失同样优先扣除额外 HP。额外 HP 耗尽时，你立即死亡，不论本体 HP 剩余多少。
- Terror 期间警察停机（§8.5），你造成的伤害不计为犯罪。你没有 Cost，不能演出，不能使用战术宏、道具和药物，不能被治疗，也无法使用战斗续行。
- 若一次攻击击杀了其他所有玩家，游戏结束（§7.5），该次攻击不再扣除额外 HP。
- 化为 Terror 后无法复原，只有接受 G5 献出的「守夜人」才能解除；接受后色彩不再增长（§13.1）。

要注意的地方：

- 光环和战斗续行无需融合；战术宏须在两件均合成后方可使用。
- 铁之荷鲁斯只有在架盾时视为屏障；持盾和不架盾时均按普通外甲计算，与你身上的其他外甲相同，每次受到攻击只使用一件（§5.3）。切换姿态不会修复耐久，商店的普通修甲也修不了它。
- 架盾时，最后 1 点耐久也能完整抵挡一次攻击；持盾时，最后 1 点耐久只能按普通外甲减伤。
- 正面可以指定其他地点的敌人，以抵挡其远程攻击；阻止离开的效果只对同一地点的正面敌人有效。
- 已破碎的铁之荷鲁斯无法通过午休修复；须先通过修盾或临战-Shielder 的 EX 修复，再重新架盾。
- 临战-Archer 的付费射击次数跨轮、跨宏累计；使用其他武器攻击、投掷道具、更衣或发动 EX 时清零。
- 整个宏计为一次行动，关注和奖励按一次计算（§6.6）；宏内每一步单独判定命中。
- 若未执行任何步骤就退出宏，视为放弃本次行动。
- Terror 的攻击只以玩家为目标，NPC 不受影响；被 G3 的结界隔离的玩家同样不受影响。

## 十三、G5 十四诗篇

进入第二阶段「黄金裔的同行者」后，G5 可以在 T1 发动大即演【此诗，献予一切生命】，向场上一名玩家献出其天赋专属的诗篇（第一阶段与第三阶段无法献诗）。

**献诗流程与共同规则**：

- **花费**：消耗 2 SP；每少支付 1 SP，可用 2 点追忆代替（即 2 SP、1 SP + 2 追忆、0 SP + 4 追忆均可）。献诗是大即演，占 T1，不占公演位（§6.4）。
- **目标**：场上任一存活且未被结界隔离的玩家。每首诗与目标的天赋一一对应；对自己发动时固定为咏唱「爱与记忆」（§12.6）。
- **展示与抉择**：发动时即扣除 SP 与追忆，随后向目标完整展示该诗篇的**强化效果、爱愿契约以及永久失去的能力**，由目标自主选择**接受**或**拒绝**。目标接受后诗篇才生效；若目标拒绝，效果不发生，G5 已支付的 SP、追忆与本回合 T1 不返还。
- **爱愿**：除 G5 对自己咏唱或双人局外，目标接受诗篇后，同时获得持续 4 轮（接受当轮不计）的**爱愿**。爱愿不属于增益或减益状态（§3.7），无法被清除或免疫。持有爱愿期间，该玩家不能对 G5 造成伤害或附加减益状态（范围攻击会自动避开 G5）；若 G5 主动对持有者发动敌对行动，该持有者身上的爱愿立即解除。
- **重复献诗**：同一名玩家可以多次接受献诗。再次接受时，一次性恢复与消耗型标记会刷新，爱愿持续时间刷新，但永久性改造不会重复叠加。

## 十四、新手指南

### 14.1 一局最短路线

1. **第 1 轮先起床，领初始包**：在 T0 起床，领取弓和 5 支箭，并在小刀与盾牌中二选一。
2. **第 1 轮 T1 必须出门**：从商店、魔法所、医院、军事基地、警察局中选一个进入；出门后本局无法再回私人房间（§2.1）。
3. **缺钱去商店打工**：商店打工是唯一可重复赚取信用点的地点服务（每次 +2 信用点，§4.1）。
4. **配齐攻防装备**：弓和步枪可以跨地点射击，小刀和拳头可以直接攻击同一地点对你暴露的单位；穿上一件外甲能帮你在交战中少掉血（§4.2、§4.3）。
5. **盯紧 SP 和公演位**：SP=1 时可以发动即演；SP=2 时既可以发动大即演（只有 G2、G5 有），也可以抢每轮唯一的公演位，把自己的标准回合提到前面插队开大（§6.3）。
6. **留意世界时钟**：第 5 格（白昼）起，死亡或退场的人身上的东西全部掉在原地；第 11 格（黄昏）起多位神代角色解锁终局能力；第 16 格（终焉）起每轮 R4 全员承受递增的真实伤害（§10.1）。
7. **死后继续参战**：普通死亡会进入往世层，每轮 R0 有三个无需背诵的按钮——押注分红、微光支援、Encore 借出技能，照样能攒 PP 争综合评分第一（第九章）。

### 14.2 常见误解

**Q：先攻掷得最低是不是这一轮就没法行动了？**
A：不是。每名存活且未被控制跳过的玩家每轮都有自己的标准回合，先攻只决定先后顺序和抢公演位的优先级（§6.3）。

**Q：SP 是行动点吗？SP 越多回合越多吗？**
A：不是。SP 主要用来发动天赋演出（即演、大即演、公演；石化时尝试挣脱也要花 SP），不会增加或减少你的回合数；SP 为 0 时照样能正常移动、攻击和交互（§6.1）。

**Q：公演是不是一定比即演更强？**
A：不一定，具体效果看各天赋。公演的核心特权是可以参与“抢台”（在轮初或轮中把自己的标准回合提前插队）；而 G2 和 G5 的 2 SP 大即演不占公演位（因此不能用来插队），但技能强度同样很高（§6.4）。

**Q：真实伤害（真伤）是不是打中就必死？**
A：不是。真伤只是跳过外甲和普通减伤，依然会被屏障（如警察盾墙、七重圆环）和 G6 的当身玩偶挡住；哪怕把人打到 0 血，只要这一下没写明附带“绝对死亡”，对方照样能触发自己的免死或者被 T7 的复活救起来（§5.4、§5.5）。

**Q：普通死亡之后是不是就彻底没事做了？**
A：不是，你只是从选手席转战去了证券交易所。普通死亡会进入往世层（第九章），每轮 R0 可以使用押注、微光和 Encore 继续挣 PP。只有遭遇“绝对死亡”或“退场”的玩家才不进入往世层（§5.6）。

**Q：`lock`（锁定）还要花掉一整回合吗？**
A：不用。在 V2.0-GA 中，`lock` 是 T0 免费小动作，锁定后同一回合的 T1 就能直接发动攻击（§3.2）。

**Q：想放公演还要提前一轮排队吗？**
A：不用。满足条件（SP=2、本轮标准回合尚未开始等）的玩家可以在 R1 报名竞争 R3 首位；若轮初无人公演，轮中刚涨满 2 SP 的玩家也可以在当前回合完整收尾后申请插队公演。详见 §6.3。

**Q：G7 星野一旦化为 Terror 是不是就无敌没救了？**
A：无论是救她还是应对她都有办法：G5 献出的《守夜人》之诗可以直接解除 Terror 并让她恢复正常操控（§13.1）。没有 G5 时，她进入“自我怀疑”后，下一个标准回合会被跳过并化为 Terror，再下一个标准回合才能行动，其他玩家可以趁这段时间集火或利用 G3 结界隔离；且 Terror 每次攻击固定造成 4 点真伤（只有这一下真正把人打死才触发绝对死亡）并自损 6 点额外 HP，撑过几轮她自己就会力竭身亡（§12.8）。

**Q：G5 在轮初第一个公演升格到第三阶段，其他人这一轮就不能动了吗？**
A：照常能动。G5 升格当轮不取消其他人的回合，从下一轮的 R0 起才开启时间倒流与历史动词限制（§12.6）。

**Q：T7 的复活已经救过人了，之后是不是就变成白板了？**
A：不是。用尽的只是“挂复活”的资格；T7 之后依然可以正常获得关注涨 SP，并在 T1 花 1 SP 发动「祝祷」回血和净化状态（若接受《彼岸》之诗还能再重置一次复活资格，§11.6、§13.2）。

**Q：我被压制跳过了回合没法拆礼盒，会被 G6 当成拒拆直接代拆吗？**
A：不会。持盒人必须先获得一次可自主选择的 T0 阶段，才算有过拆盒机会；因压制、石化或失神而没有 T0 的回合不计入，G6 的代拆与两轮超时自爆都从你真正获得过一次 T0 机会后才开始计算（§12.7）。

**Q：G5 昔涟能强行给处于繁育中的 G1 献诗，逼我脱掉机甲变成普通人吗？**
A：不能替你做决定。G5 发出献诗后，系统会先向你完整展示诗篇的强化效果、4 轮爱愿契约以及失去萨姆机甲的永久代价，由你自主选择接受或拒绝；若你拒绝，无事发生，而 G5 已经支付的 SP、追忆和 T1 不会退还（第十三章）。

**Q：一次连发里同时打碎外甲又杀死了人，会给 G5 涨好几点追忆吗？**
A：不会。同一次根行动（包含连发的每一段、战术宏的每一步、范围攻击的全体目标）最多只让 G5 获得 1 点高光追忆；但你实际造成的每一点伤害、破甲和击杀，仍会完整计入你自己的战果分（§6.6、§7.1）。

**Q：为什么神代天赋写得这么长？**
A：因为它们的目标不是成为一排容易平衡的按钮，而是让角色在规则里留下清楚的轮廓。你可以嫌它们麻烦，这很合理；你也可以选 T1，然后把复杂问题处理成一次近战攻击。

## 十六、主持与版本说明

- **公开与保密边界**：游戏默认公开所有玩家的位置、HP、外甲耐久、装备、状态、先攻、SP、PP、案底以及绝大多数天赋资源（§1.2）。仅在全桌秘密选择窗口（如 T4 起卦猜拳、G4 弑魂焚诏的迎战/拒战）收集完所有相关玩家的输入前暂不广播，收齐后同时公开。
- **确定性裁决**：除明确写明的随机判定（R1 先攻掷骰、普通单体攻击命中判定、石化挣脱、随机目标/地点分配、G6 礼盒掷骰）外，其余结算均按固定规则执行，不临时加骰。相同随机种子与相同输入下，整局结果可完全重放。
- **单一数值信源**：本手册第十七章汇总了 V2.0-GA 的首轮标准数值（N0），数值以程序配置文件 `data/balance.json` 中的 `ga` 块为准，两者不一致时以配置为准并修正本章。详细的底层设计决议见同目录下的 `README.md` 与各分册 RFC。

## 十七、首轮数值表 N0（2026-10-26）

本章汇总 V2.0-GA 的全部基础数值、装备价格与天赋参数（N0 初值），供查表与平衡核对使用。

N0 的基准尺度为：**满血 20 HP、常规武器攻击 4、普通治疗 4、普通外甲耐久 6～10**。在此尺度下，高投入的演出爆发可以显著高于普攻，而免费护盾、每轮自动恢复与修甲则受到严格限制，避免单靠防守或吃药把对局拖入死锁。

### 17.14 首轮数值设计算例与调参次序

本节通过几个静态算术例子说明 N0 基准尺度（20 HP / 4 攻 / 4 奶 / 6～10 甲）如何防止死锁：

1. **普攻压得住护甲**：使用无模块弓（伤害 4）连续射击穿着陶瓷护甲（普通防御 3、耐久 10）的目标——前 3 箭每箭扣 1 HP、磨 3 点耐久；第 4 箭甲只剩 1 点耐久，扣 3 HP 并击碎护甲。4 箭累计扣 6 HP 并彻底破甲，之后每箭扣满 4 HP。若在 T0 先 `lock` 目标（外甲防御乘 0.75 向下取整为 2），每箭扣 2 HP、磨 2 点耐久：3 箭就能打掉同样的 6 HP，第 5 箭破甲。
2. **普攻压得住免费护盾**：T3 每轮花 1 SP 补 3 点玉璋屏障，挨一箭（伤害 4）仍会漏 1 点伤害进本体；G7 的午休最多为未破碎的铁之荷鲁斯修 2 点耐久（小于一箭消耗的 4 点），且盾一旦破碎就无法靠午休白嫖复原，必须花一整回合 T1 和一件盾牌/AT 组件去修——从而杜绝了“每轮靠 2 点残盾完美挡下整发攻击、下回合再免费修 2 点”的无赖循环。
3. **普攻压得住买药回血**：在医院做一次紧急治疗需花 2 信用点和 1 个 T1，恢复 4 HP；但挣这 2 信用点需要先在商店打工 1 个 T1。也就是说，“打工 + 治疗”花掉整整两个回合只能回 4 HP，而对手这两回合射你两箭就是 8 点伤害（无甲时净损 4 HP）。T7 的祝祷每次回 3 HP 同样低于一箭的 4 点伤害。
4. **资源与采购节奏**：
   - G6 开局 1 枚笑点，若场上没有外部笑点事件，最多架一次当身；自己主动放弃行动不给笑点，无法原地刷假币。
   - G3 满常规魔力 8 加无限剑制临时魔力 4 共 12 点，打完三段常规回路连接（2 + 3 + 4 = 9 点）后正好剩 3 点魔力，足以接续「幻想崩坏」（至少需 2 点）。
   - G7 合成双神器共需两件防具（2 + 3 = 5 信用点）与两把步枪（3 + 4 = 7 信用点），合计 12 信用点；扣除开局自带的 4 信用点，只需在商店打工 4 次（若选水着开局自带盾牌则只需打工 3 次）即可在中盘完成双合成启动战术宏。

**实战校准优先级**：普通攻击对回血/修甲的净推进速度 → 开局到第一次演出的轮数 → 公演抢台频率与三章个人剧情达成率 → G3 / G7 多段爆发上限 → G2 / G5 终局持续轮数 → 终分各项占比分布。
