## 一、故事定稿（先剧情，后角色）

### 三句定场诗

> 「她和世界打了个赌：在黎明跌入白昼之前，若有人肯为她停下脚步，问一句她的名字，她就赢了这一场轮回。」
>
> 「三千次轮回里，白裙的凡人总是停在雨幕之外，低着眼睛，沉浸在自己的悲伤里——一次，也没有抬头。」
>
> 「于是影子从她脚底爬起，从背后抱住她：『别唱了。我带你跳进炉心，把痛苦烧成纯白，把明天烧成昨天。』」

### 人物

- **光（凡人·天依）**：这一世还在红尘里奔波、沉浸在自己悲伤中的普通女孩；
- **影（歌者·阿绫）**：从轮回尽头走回来的"光的自己"——经历无数次世界毁灭与无人问津，
  被极端抑郁与绝望磨成的里人格；
- **里人格的动机**（《炉心融解》= 遗书内核）：对主人格的**报复，也是扭曲的保护**——
  夺走身体跳进核融合炉，替她终结神明的赌约与痛苦；
- 互文：影 ≈ 盗火行者，光 ≈ 白厄（与 G4/G5 共享轮回母题）。

## 二、物理模型：一体双标

| 项 | 规则 |
|---|---|
| 面板 | 光与影**共享**同一 HP / 背包 / 护甲 / 钱包 / SP |
| 坐标 | 光与影各占一个**地点坐标**（地图上两枚棋子） |
| 回合 | 每轮共 1 个标准回合；回合设置时声明主控【光】或【影】，不占 T0 额度 |
| 残影 | 未主控方不可被单体指定、不参与战斗结算（钉子 3）；其地点被摧毁则立即并回主控坐标（DEC-056）；终焉环境伤只作用于主控坐标 |
| 倾向 | 主控光：实际打工收入 +1；主控影：普通攻击 +2 |

## 三、谱表：孤独值与白键/黑键

- 孤独值初始 2、范围 `0~4`；A 演出降、B 演出升，追光诗可清零，无隐含被动漂移；
- 节拍（钉子 4）：
  - 世界时钟在 R0 每推进一格：孤独 ≤2 → 记 1 白键；孤独 >2 → 记 1 黑键；双倍速跨两格记两次，但不多生成状态 tick；
  - 演出 A → +1 白键（2 SP 版 +2）；演出 B → +1 黑键（同左）；
- 键位不清零、无上限，只比多少。

## 四、1 SP / 2 SP 演出（大即演，永不占聚光灯）

- G2 永远不报名全局公演；她的 2 SP 是「强化即演」（钉子 2）；
- 主控声明决定可选演出（钉子 1）；声明本身不占 T0，小动作与主行动按以下入口支付：

### A（对光）：「消失前　做出最温柔的给予」（2 SP：「绽放的　璀璨花火拥着繁星」）
- 使用本回合 T0；1 SP/2 SP 版都不能再另用一个小动作；
- 光瞬移到影的坐标；共享身体获得一次增益：回 HP / 屏障为 2/2（2 SP 版 4/4）；孤独 −1（2 SP 版 −2）；
- **T1 强制只能 `move`**——短暂驻足后，注定离开。

### B（对影）：「沉入冰冷的池底」（2 SP：「都隐没于　淋漓的雨幕无声无息」）
- 占完整 T1；不能施放后再普通攻击；
- 孤独 +1（2 SP 版 +2）；
- 对影所在建筑所有单位施放【溺音光环】至下个 R4：
  - 非玩家单位 → `SUBMERGED` 沉沦；
  - 玩家 → 脆弱（受伤 +1/+2）+ 失神（下回合 T0 小动作封禁 + 无法隐身）；
- **前期不给 `ACTION_SUPPRESSED`**（没有此剧情张力需要）。

## 五、黄昏锁与终局判决

- **黄昏锁**（钉子 6）：世界时钟进入黄昏前，无任何融合；普通致死先检查合法 T7 保险，无承接则正常死亡
  （杜绝开局送死刷终局）；
- 黄昏后：进入黄昏后的**首个 G2 回合**清点键位（钉子 5）——
  - 白键 ≥ 黑键 → 终局一《世末歌者》；
  - 黑键 > 白键 → 终局二《炉心融解》；
- 黄昏后若 G2 遭普通致死：触发融合并**按当时键位立即裁决终局**（取代死亡）。
- 融合整局只发生一次；普通致死时属于自身形态转折，先于 T7 保险。先建立正数
  起始 HP8，再执行终局效果（炉心腰斩后为4）；炉心不能拿 0 HP 开始烧尽计时。
  已融合者后续致死不重复融合；`absolute_death` 跳过此替代。

## 六、终局一《世末歌者》「一如那些　模糊身影的别离」（白键 ≥ 黑键）——世末之雨

1. 光与影和解合一（双坐标并一）；
2. 【世末之雨】全局常驻法则（至 G2 死亡）：所有非玩家单位在法则期间持续 `SUBMERGED`；
   法则结束后解除，不复活已死 NPC；全场存活玩家普通攻击力 +2；
3. G2 的演出升格：
   - **1 SP「夏夜空　出现在遥远的记忆」**：全图/大范围 AOE 冲刷，**占据完整 T1**（院长式下雨）；
   - **2 SP「将颤抖的双手牵起　迎来每个人的结局」**：占 T1，点名 1 名玩家——不在同地 → 强制拉拽至 G2 所在建筑；
     已在同地 → 挂 `ACTION_SUPPRESSED` 压制；
4. 第 3 章「唯一的听众」永久解锁；PP 仍按终局实际余额计分，不冻结旧钱包。

## 七、终局二《炉心融解》「没有我的明天一定会更加美好」（黑键 > 白键）——没有我的明天

1. 「做了个……的梦」里人格夺舍，光与影在主控所在地点坍缩合一（DEC-056）；
2. 「一点一滴缓慢死去的世界」（核融解裁决）对**全场所有存活玩家**：当前外层护甲耐久、当前 HP、最大 HP
   **同时降至 1/2**（向上取整，不直接致死）；
3. 「一切急速地变化」（2 倍速末日）世界时钟此后以 2 倍速推进；进入终焉后每 R4 灼伤 ×2；
   **此加速永不解除**（即便 G2 退场或被追光诗救回）；G5 倒流期间暂停，结束后恢复；
4. 「包覆于湛蓝而绮丽的光」（反应堆退场）G2 失去操控权，不可被单体指定、不可被治疗，按固定速率烧血
   （每未来 R4 扣 2，建立轮不扣）；以扭曲时剩余血量计算烧尽时间；烧尽 = 正常退场；
5. 第 3 章「纯白终幕」在爆发时立即永久解锁，PP 仍按终局余额计分。
