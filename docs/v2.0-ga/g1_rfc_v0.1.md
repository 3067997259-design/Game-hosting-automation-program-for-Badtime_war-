## 一、定位与叙事轴

- 原型：流萤 / SAM（《崩坏：星穹铁道》）——最后的格拉默铁骑，失熵症少女；
- 母题：**燃烧就是在死**——「想以流萤而非铁骑的身份死去」；卸甲调息 ↔ 着装参战的
  风筝循环，以及必死的第三次死亡（繁育绝唱）；
- 与 G2 的宿命互文：G2 黑键《炉心融解》后的双倍终焉核冬天里，**只有着甲的萨姆毫发无伤**；
- 保留 M9 v0.3 全部骨架；V2.0-GA 修订 5 处（§四终焉抗性分档、§七触发放宽与翻盘补强、
  §九飞萤诗救赎、以及各节的新基线接口对齐）。

## 二、形态阶梯（三段单向上行、可跌落）

### 2.1 卸甲常态「流萤」
- 负修正：攻 −1 / 受击 +1 / 命中惩罚（视力受损——"她曾以为萤火虫很美，后来才知道
  那是因为她视力不行"）；命中 −15 个百分点；
- 发育补偿（DEC-049）：`interact` 费用 −1（有费用项目最低 1）；
  不另加卸甲专属移动闪避，普通移动闪避仍按基线。原免费 find 退役；
- 失熵：每 R4 缓慢累积，**不暂停**——卸甲不是安全，只是更慢地死；
- 调息：本行动回合无攻击类行动 → R4 失熵回落（唯一常规回落通道）；
- 医院手术三「不老泉·内循环炉」的天赋代价减免对接失熵（baseline 铁律 7）。

### 2.2 次级燃烧「SAM·着装」（1 SP 宣言）
- T0 小动作宣言着装，耗 1 SP，**不占 T1**（基线三拍子）；
- 禁 `find`/`interact` 类发育行动——战甲不是用来逛街的；
- 数值加成：相对普通角色攻击 +2、普通固定减伤 1，命中惩罚消除；
- 解锁 DHGDR-超新星过载（§五）；
- 失熵：中速档；
- 卸甲：不付 SP，但占本回合唯一 T0；**当轮失熵按行动开始时的形态档结算**。

### 2.3 完全燃烧（2 SP 公演，须处于次级燃烧）
- 基线公演入口，支持崩铁式插队夺台（铁律 5）；
- 窗口 3 轮（建立轮不 tick）；
- 数值上探：相对普通角色攻击 +3；
- 每 R0 自愈回血（原作强化战技回血）；
- 每轮 T1 主行动后，T2 派发 **StepFollowup(allowed=[move, attack])**——对接基线铁律 3
  （替代 M9 的 `restricted_followup`）；每全局轮至多一次，不可派生；
- 超新星基础伤害 5、灼烧 2 层（已包含形态加值）；
- 失熵：最快档；
- 窗口结束强制跌回卸甲常态并**立即承受一次失熵结算**（不论量表是否达阈值）；
  窗口内不可主动卸甲、不可续杯。

## 三、失熵量表

- 0 起步、有上限的公开量表；速率卸甲 < 次级 < 完全；
- 达阈值 → 当轮 R4 触发失熵结算，随后量表回落（非清零——疾病不会痊愈，只是压回一段）；
- **结算顺序（三层漏斗 Armor 层）**：
  1. 持有炽愿可消耗 1 层完全抵扣；
  2. 否则摧毁 1 件自选外层护甲；
  3. 无外甲时扣 HP——护甲是失熵的消耗性缓冲，卸甲的她被失熵直接啃食血肉；
- 失熵结算不构成"受到攻击"，不触发反击/关注/犯罪；
- **R4 接口**：服从基线警务 → 环境 → 持续伤害/角色维护 → 回复 → 到期清理。
  角色维护内先失熵累积、明文减免、调息，再阈值结算；完全燃烧到期时另执行其强制
  失熵结算。繁育倒计时保留胜利优先例外；倒流不冻结失熵、形态时限或繁育倒计时。
  医院内循环炉使失熵累积 −1（最低 0）。

## 四、终焉环境抗性（V2.0-GA 分档）

- 世界时钟进入终焉：失熵停止累积（已有量表保留，继承 M9 §3.5）；
- **着甲态**（次级燃烧 / 完全燃烧 / 繁育）：**100% 免疫终焉环境灼伤**（含 G2 炉心融解
  翻倍后的双倍终焉）；
- **卸甲态**：实际承担 ceil(环境伤害×50%)——肉体凡胎在火海里仍会灼痛；
- 对应星核猎手的使命：应对"虚无"将宇宙导向的终末结局。

## 五、DHGDR-超新星过载

- 形态门槛：次级燃烧 / 完全燃烧 / 繁育；
- 获取：进入次级 +1；完成击杀 +1；上限 1；
- 发动：`move` 根行动触发，落点可为当前地点；对落点内除己外玩家与警察单位造成
  AOE 伤害 + 穿甲 + 挂灼烧（普通属性，防御系数 0.5，数值按手册 §17.7）；
- 繁育态超新星不消费过载计数（§七）。

## 六、超击破近似

- 次级及以上形态，对受控（震荡/压制/石化）或灼烧/虚弱单位攻击获得固定加值；
- 自洽循环：超新星挂灼烧 → 后续攻击吃增伤，不依赖队友。

## 七、第三次死亡（繁育）——绝境翻盘 3 轮

### 触发（放宽，2026-10-24）
- 每局 1 次：**本局曾开启过至少 1 次完全燃烧，且当前处于 ≥ 次级燃烧状态时受到第一次
  普通致死伤害** → 必定触发（无概率骰；"星核是否还在她体内"的留白放文案层）；
- `absolute_death` 来源直接杀死，不入繁育；
- 防开局碰瓷：没开过完全燃烧就没有第三次死亡；触发权部分在对手（可以不打死她）。

### 内容（继承 M9 v0.3）
- 倒计时 3 轮（建立轮不 tick）；归零 → **绝对死亡**（进白名单，绕过一切免死/复活/T7）；
- 繁育期间再次普通致死 → 正常死亡（星核只有一枚）；
- 初始 HP 置 8（不超最大值），先攻 +3；
- 每轮首次合法 `move` 触发**结构超新星**（不读 SP、不占公演、不耗过载）→ 结算后
  **永久摧毁落点建筑**（缩圈；警察局被毁同步停机；最后安全地点兜底保留）；
- 摧毁后幸存单位按**先攻降序 + actor ID** 驱逐至未毁公共建筑（基线铁律 2，无 `home_pX`）；
- **胜利判定优先于倒计时**——为生而战打到最后一刻赢下来，是她能得到的最好结局。

### 翻盘补强（V2.0-GA 新增，2026-10-24）
- **ATK 提升**：相对普通角色 +4；
- **普通控制免疫**：免疫压制/震荡/石化/失神（世界法则级如 G5 时间倒流仍生效）——
  最后 3 轮绝不罚站等死；
- **击杀再动（流萤二命复刻，DEC-023）**：繁育期间在自己回合内完成击杀，在 T2
  取得一次 move/attack 单步追击，与自身同轮其他单步追击共用一次额度；不附赠 T0，
  不得演出、不递归派生，不加入完整额外回合白名单。

## 八、炽愿

- 超新星每命中 1 单位 +1、每击杀 1 单位额外 +1；上限 3；
- 用途二选一：抵扣 1 次失熵结算；或受击时充当临时 HP。

  - 常态/次级：接受后开启完全燃烧·无垢，细节见诗篇 RFC；不再使用旧降失熵诗版本；
