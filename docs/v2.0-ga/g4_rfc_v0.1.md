## 一、定位与叙事轴

- 原型：白厄 / 卡厄斯兰那——「以旧日余烬为来世破晓，烈阳撕裂长空」；
- 母题：永劫轮回里的英雄——与 G2（盗火×白厄双生）、G5（时间倒流 ∞）共同构成
  V2.0-GA 的轮回叙事轴；
- 保留 M9 v0.3 的核心骨架并按作者改稿重排（DEC-060）：**火种 → 救世主形态 → 毁伤 →
  弑魂焚诏（全桌秘密迎战/拒战，积累毁伤）→ 支柱·死星天裁（弹射 + 平摊）**；
- 针对 2026-09 风洞病灶的三处手术：
  1. 火种经济重构（撤销"敌对外来火种 1→0"）；
  2. 主动升格 + 濒死最低门槛（砍掉 0 火种碰瓷）；
  3. 形态浓缩为 3 轮高爆发（告别 5 轮刮痧）。

## 二、资源：火种（上限 12）

只在人形态积累。三条途径：

| 来源 | 条件 | 增量 |
|---|---|---|
| 此身为炬（被动） | 人形态承受他人有效伤害（HP 损失或外甲破碎） | +1；每轮受击类至多 +2 |
| 黎明创世，地辟天开（1 SP 即演，简称夺火） | 人形态消耗 1 SP 发动斩击；命中并造成有效伤害（DEC-061） | +2 |
| 行向世界终点（环境） | 场上其他玩家阵亡，或建筑被摧毁 | +2 |

- 不计入：DOT 后续 tick、环境/世界时钟伤害、自我消耗（沿用 M9 v0.3 口径）；
- 撤销风洞修正：`敌对外来火种 1→0` 作废，恢复受击攒火——白厄的核心是"用血肉扛下世间
  的恶意"。

## 三、进入救世主形态（两条合法路径）

### 主动升格（完整救世主）
- 条件：火种 = 12，且处于人形态；
- 时机：任意 **T0 小动作**主动燃尽全部 12 火种（不占 T1）；升格后当前 T1 可用血棘渡亡
  或 1 SP 即演焚诏；死星天裁须毁伤 ≥ 4，刚升格时毁伤为 3，同一回合不能发动（负世诗在人形
  态只给火种，升格前接受也补不到毁伤）；升格不另发插队槽，ExtraTurn 不能公演；
- 升格瞬间：SP **置满**为 2（置位，非 +2）；获得余烬生命 24；
  初始毁伤 3；
- M9 的「负世主动燃尽派发完整额外行动」**退役**——升格不创建额外行动槽
  （不制造跨轮行动债，同 v0.3 原则）。

### 终结之始（残缺救世主）
- 条件：人形态遭普通致死，且持有火种 ≥6；
- 结算：消耗当前全部火种 c 进入残缺形态；余烬生命=2c，初始毁伤=max(1,floor(c/4))；
- 火种 < 门槛 → **正常死亡**（Death Gate 不拦截，杜绝 0 火种送死白嫖）；
- `absolute_death` 来源直接杀死，不触发残缺。

## 四、救世主形态（3 轮极境燃烧）

- 持续 3 个未来 R4 tick（建立当轮不 tick，沿基线口径）；
- 形态内不再获得火种；毁伤为形态内局部预算，退出清空；
- **创生·血棘渡亡**（救世主普攻）：占标准根行动，不耗 SP；所选普通武器基础伤害 +2，
  命中并造成有效伤害时毁伤 +2；T2 附带
  【烈阳余波】对同地点其余敌人各纯磨甲 1；余波是附加效果，不派发新回合；
- 不做无条件扩散、不复制十六次弹射拓扑（沿用 v0.3 非目标）。

## 五、焚诏与死星天裁（DEC-060）

### 1 SP 即演：灾厄·弑魂焚诏

- 入口：救世主形态 T1，1 SP 即演，不占公演位，不消耗毁伤，结算后不退出形态；
- 对象：全场其他存活且未被结界隔离的玩家，秘密承诺「迎战 / 拒战」后同时公开；
- **迎战者的试炼**：按先攻降序，各用一件合法普通武器攻击 G4（临时无视距离，弹药照付，
  无武器则拳头；受限反应，不发 T0/T2，不能借响应演出或开战术宏）。G4 对这些攻击享
  2 点固定减伤；迎战攻击与 G4 的反击正常产生关注，但不计犯罪；
- 全部迎战结算后：G4 获 `ceil(完成迎战人数 / 2)` 毁伤（上限 9），对存活迎战者均分
  `4 + 2 × 完成迎战人数` 的普通反击总池（必中）；完成迎战者获「直面烈阳」印记，持续到
  G4 退出本次救世主形态；
- **拒战者的代价**：每名拒战者令 G4 毁伤 +1（上限 9），自身挂脆弱与失神（至下一轮 R4）、
  SP −1（最低 0）；全员拒战时 G4 返还 1 SP（净 0 SP）；
- **强制中断**：迎战途中余烬耗尽 → G4 立即退回人形态，焚诏中止，后续迎战、毁伤、反击与
  拒战惩罚均不结算；
- 待确认（OPEN-012）：焚诏按写法每个 T1 都能用、不设次数上限。

### 2 SP 公演：支柱·死星天裁

- 入口：救世主形态 T1，2 SP 公演（可插队夺台），须毁伤 D ≥ 4，消耗全部毁伤 D（上限 9）；
  不选目标，作用于全场其他存活且未被结界隔离的玩家；
- **第一段「星火弹射」**：D 颗碎片，每颗 2 点普通伤害、必中、逐颗独立结算（正常经过屏障与
  外甲）；每颗随机落在未持有「直面烈阳」的合法玩家身上，全员都有或都没有时在全体合法玩家
  中随机；途中死亡者不再被选；只打玩家，不打特警、无人机等非玩家单位；
- **第二段「死星坠落」**：第一段结束后，全场存活合法玩家均分 `2 × D` 天裁总池（必中）：
  4 ≤ D ≤ 6 为普通伤害且外甲属性防御系数 0（屏障与不耗甲的固定减伤照常）；D ≥ 7 为
  `DIRECT_DAMAGE`，实际致死附 `absolute_death`；
- 两段结算完毕后退回人形态。

### 两者共用

- **固定总池**：焚诏反击池与天裁池都只建立一次再均分，不按人头复制；余数按先攻降序、
  actor ID 逐个 +1；
- **隔离边界**：不穿透结界类隔离（G3 重做后沿用"不穿透隔离层"原则）。

## 六、退场与剧情
