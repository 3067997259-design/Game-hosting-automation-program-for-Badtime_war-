## 一、定位与叙事轴

- 原型：白厄 / 卡厄斯兰那——「以旧日余烬为来世破晓，烈阳撕裂长空」；
- 母题：永劫轮回里的英雄——与 G2（盗火×白厄双生）、G5（时间倒流 ∞）共同构成
  V2.0-GA 的轮回叙事轴；
- 保留 M9 v0.3 的核心骨架：**火种 → 救世主形态 → 毁伤 → 弑魂焚诏（全桌秘密迎战/拒战）
  → 反击与死星天裁**；
- 针对 2026-09 风洞病灶的三处手术：
  1. 火种经济重构（撤销"敌对外来火种 1→0"）；
  2. 主动升格 + 濒死最低门槛（砍掉 0 火种碰瓷）；
  3. 形态浓缩为 3 轮高爆发（告别 5 轮刮痧）。

## 二、资源：火种（上限 12）

只在人形态积累。三条途径：

| 来源 | 条件 | 增量 |
|---|---|---|
| 受难之火（被动） | 人形态承受他人有效伤害（HP 损失或外甲破碎） | +1；每轮受击类至多 +2 |
| 逐火之剑（1 SP 即演「夺火」） | 人形态消耗 1 SP 发动斩击；命中或破甲 | +2 |
| 余烬共鸣（环境） | 场上其他玩家阵亡，或建筑被摧毁 | +2 |

- 不计入：DOT 后续 tick、环境/世界时钟伤害、自我消耗（沿用 M9 v0.3 口径）；
- 撤销风洞修正：`敌对外来火种 1→0` 作废，恢复受击攒火——白厄的核心是"用血肉扛下世间
  的恶意"。

## 三、进入救世主形态（两条合法路径）

### 主动升格（完整救世主）
- 条件：火种 = 12，且处于人形态；
- 时机：任意 **T0 小动作**主动燃尽全部 12 火种（不占 T1）；升格后可按公演入口
  用当前标准回合 T1 公演，须本轮公演位仍空；这是当前回合入口，不另发插队槽。
  公演位已用则保留 SP，执行其他合法主行动；ExtraTurn 不能公演；
- 升格瞬间：SP **置满**为 2（置位，非 +2）；获得余烬生命 24；
  初始毁伤 3；
- M9 的「负世主动燃尽派发完整额外行动」**退役**——升格不创建额外行动槽
  （不制造跨轮行动债，同 v0.3 原则）。

### 濒死转折（残缺救世主）
- 条件：人形态遭普通致死，且持有火种 ≥6；
- 结算：消耗当前全部火种 c 进入残缺形态；余烬生命=2c，初始毁伤=max(1,floor(c/4))；
- 火种 < 门槛 → **正常死亡**（Death Gate 不拦截，杜绝 0 火种送死白嫖）；
- `absolute_death` 来源直接杀死，不触发残缺。

## 四、救世主形态（3 轮极境燃烧）

- 持续 3 个未来 R4 tick（建立当轮不 tick，沿基线口径）；
- 形态内不再获得火种；毁伤为形态内局部预算，退出清空；
- **强化普攻**：占标准根行动，不耗 SP；所选普通武器基础伤害 +2，命中毁伤 +2；T2 附带
  【烈阳余波】对同地点其余敌人各纯磨甲 1；余波是附加效果，不派发新回合；
- 不做无条件扩散、不复制十六次弹射拓扑（沿用 v0.3 非目标）。

## 五、2 SP 公演：灾厄·弑魂焚诏（崩铁式插队夺台）

- 入口：基线公演（2 SP，占全局聚光灯，可插队）；消耗当前全部毁伤 `D`，
  天裁段数 = `D`；
- 结构（继承 M9 v0.3）：

```text
全桌秘密承诺「迎战 / 拒战」
→ 迎战者按先攻降序逐个执行 challenge_response（受限反应，非完整行动）
→ 对迎战者的统一反击池
→ 对拒战者的死星天裁池
→ 公演收尾
```

- **迎战者（DEC-042）**：公演临时解决距离/面对面；玩家自行选择一项合法普通攻击，
  不强制消耗系统选出的最优载荷。弹药正常支付，无可用武器时可拳击；不能借响应发动
  公演、战术宏或整套演出。每完成 1 次合法挑战，天裁段数 −1；不产生犯罪/SP/关注/
  警务额度，也不附赠 T0/T2；
- 收集秘密承诺前公开毁伤与反击/天裁分配规则；不因承诺秘密而隐藏规则预算。
- **拒战者**：平摊剩余段数的死星天裁总池（`DIRECT_DAMAGE`；致死结果附
  `absolute_death`）；
- **固定总池**：反击与天裁都按总池均分，不按人头复制；分配顺序按先攻降序、actor ID；
- **强制中断**：挑战攻击迫使 G4 退出形态 → 停止后续响应，取消反击与天裁，转入退场清理；
- **数值 N0**：反击总池=2D；天裁总池=2×max(0,D−完成挑战人数)，毁伤上限9。
  两池均只建立一次再均分，无目标的池不转给另一组；完整算例见手册 §17.10；
- **隔离边界**：不穿透结界类隔离（G3 重做后沿用"不穿透隔离层"原则）。
