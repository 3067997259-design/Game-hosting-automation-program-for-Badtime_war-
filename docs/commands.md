# 电子裁决系统指令表

以下是游戏系统所有指令的完整梳理，分为主命令解析器、回合内快捷查看指令、以及星野战术宏子系统指令。

---

## 一、主命令解析器（`cli/parser.py`）

所有玩家输入首先经过 `parse()` 函数，第一个词（不区分大小写）作为指令关键字。

### 1. 起床 / 唤醒警察 → `wake` / `wake_police`

| 可接受写法 | 映射到的 action |
|------------|-----------------|
| `wake`, `起床`, `w` | `wake`（自己起床） |
| `wake police1`, `wake 警察xxx` | `wake_police`（唤醒警察，第二参数以 police/警察开头时） |
| `wake_police <ID>`, `唤醒警察 <ID>`, `唤醒 <ID>` | `wake_police` |

- 起床：玩家从未醒状态起床，出现在自己家中
- 唤醒警察：唤醒同地点处于 debuff 状态的警察单位

### 2. 移动 → `move`

| 可接受写法 | 映射到的 action |
|------------|-----------------|
| `move <地点>`, `移动 <地点>`, `m <地点>`, `go <地点>` | `move` |

目的地参数中 `home`、`家`、`回家` 会自动转换为 `home_{player_id}`。

可移动地点共 6 个：`home`, `商店`, `魔法所`, `医院`, `军事基地`, `警察局`。

### 3. 交互 → `interact`

| 可接受写法 | 映射到的 action |
|------------|-----------------|
| `interact <物品>`, `交互 <物品>`, `i <物品>`, `get <物品>`, `拿 <物品>`, `学 <物品>`, `做 <物品>`, `买 <物品>` | `interact` |

物品名缩写映射：`通行证` → `办理通行证`，`办通行证` → `办理通行证`

可交互物品共 27 种，按地点分布：

| 地点 | 可交互物品 |
|------|-----------|
| home | 凭证, 小刀, 盾牌 |
| 商店 | 打工, 磨刀石, 隐身衣, 热成像仪, 陶瓷护甲, 防毒面具 |
| 魔法所 | 魔法护盾, 魔法弹幕, 远程魔法弹幕, 封闭, 地震, 地动山摇, 隐身术, 探测魔法 |
| 医院 | 晶化皮肤手术, 额外心脏手术, 不老泉手术 |
| 军事基地 | 办理通行证, AT力场, 电磁步枪, 导弹控制权, 高斯步枪, 雷达, 隐形涂层 |

### 4. 锁定 → `lock`

| 可接受写法 |
|------------|
| `lock <目标>`, `锁定 <目标>`, `l <目标>` |

远程攻击的前置条件。锁定一个可见的、尚未被自己锁定的目标。

### 5. 找到 → `find`

| 可接受写法 |
|------------|
| `find <目标>`, `找到 <目标>`, `找 <目标>` |

近战攻击的前置条件。需要与目标在同一地点。

### 6. 攻击 → `attack`

| 可接受写法 |
|------------|
| `attack <目标> <武器> [层] [属性]`, `攻击 ...`, `atk ...`, `打 ...` |

武器共 10 种：拳击, 小刀, 警棍, 魔法弹幕, 远程魔法弹幕, 地震, 地动山摇, 电磁步枪, 高斯步枪, 导弹。

### 7. 特殊操作 → `special`

| 可接受写法 |
|------------|
| `special <操作名>`, `特殊 <操作名>`, `sp <操作名>`, `操作 <操作名>` |

操作名缩写映射：`磨` → `磨刀`，`吟唱` → `吟唱魔法护盾`，`展开` → `展开AT力场`，`病毒`/`放毒` → `释放病毒`

可用的特殊操作（条件性出现）：

| 操作名 | 条件 | 效果 | 消耗回合 |
|--------|------|------|----------|
| `磨刀` | 持有磨刀石+未磨小刀 | 小刀伤害→2 | 是 |
| `吟唱魔法护盾` | 已学魔法护盾且外层无魔法护甲 | 重新展开魔法护盾 | 是 |
| `展开AT力场` | 已学AT力场且外层无科技护甲 | 重新展开AT力场 | 是 |
| `蓄力<武器名>` | 持有需蓄力武器且未蓄力 | 为武器蓄力 | 是 |
| `释放病毒` | 在医院且病毒未激活 | 全体感染，4轮后无防护者死亡 | 是 |
| `取消盾牌` | 星野处于架盾/持盾状态 | 取消盾牌状态 | 否 |
| `Hoshino` | 星野战术已解锁 | 进入战术指令宏模式 | 视执行情况 |
| `修复` | 星野铁之荷鲁斯未满 | 消耗盾牌/AT力场修复 | 是 |
| `肾上腺素` | 星野持有肾上腺素且未使用 | 下回合 cost+5 + 光环全恢复 | 否 |
| `更衣<形态>` | 星野在自己家中 | 切换形态 | 是 |

### 8. 举报 → `report`

| 可接受写法 |
|------------|
| `report <玩家名>`, `举报 <玩家名>` |

需在警察局，举报一个有犯罪记录的玩家。

### 9. 集结 → `assemble`

| 可接受写法 |
|------------|
| `assemble`, `集结` |

举报者使用，集结警察出动。

### 10. 追踪指引 → `track_guide`

| 可接受写法 |
|------------|
| `track`, `追踪`, `指引` |

举报者使用，指引警察立刻到达目标位置。

### 11. 加入警察 → `recruit`

| 可接受写法 |
|------------|
| `recruit`, `加入警察`, `入警` |

需在警察局，加入警队并获得三选二奖励。

### 12. 竞选队长 → `election`

| 可接受写法 |
|------------|
| `election`, `竞选`, `竞选队长` |

需在警察局且已加入警察，竞选进度 3/3 后成为队长。

### 13. 队长指定目标 → `designate`

| 可接受写法 |
|------------|
| `designate <玩家名>`, `指定目标 <玩家名>`, `指定 <玩家名>` |

队长专属，指定警察执法目标。

### 14. 研究性学习 → `study`

| 可接受写法 |
|------------|
| `study`, `研究`, `研究性学习` |

队长在警察局使用，威信+1。

### 15. 队长操控警察 → `police_command` / `police_status`

| 可接受写法 | 映射到的 action |
|------------|-----------------|
| `police`（无参数） | `police_status` |
| `police status`, `police 状态`, `police s` | `police_status` |
| `police move <警察ID> <地点>` | `police_command(subcommand=move)` |
| `police equip <警察ID> <装备>` | `police_command(subcommand=equip)` |
| `police equip <警察ID> weapon/武器 <装备>` | `police_command(subcommand=equip, type=weapon)` |
| `police equip <警察ID> armor/护甲 <装备>` | `police_command(subcommand=equip, type=armor)` |
| `police attack <警察ID> <目标>` | `police_command(subcommand=attack)` |
| `police wake <警察ID>` | `police_command(subcommand=wake)` |
| `police_status`, `警察状态`, `警状态` | `police_status` |

`police` 和 `警察` 命令作为首词时进入此分支。

### 16. 放弃 → `forfeit`

| 可接受写法 |
|------------|
| `forfeit`, `放弃`, `f`, `pass`, `skip` |

放弃本次行动。

### 17. 查看类指令（不消耗行动）

| 可接受写法 | 映射到的 action | 效果 |
|------------|-----------------|------|
| `status`, `状态`, `s` | `status` | 查看自己状态 |
| `allstatus`, `全场`, `all`, `a` | `allstatus` | 查看全场状态 |
| `help`, `帮助`, `h`, `?` | `help` | 显示帮助 |

## 二、回合内快捷查看指令（绕过解析器）

在 `ActionTurnManager` 的回合循环中，以下输入在进入 `parse()` 之前被直接拦截处理，不消耗行动也不计入重试次数：

| 输入（不区分大小写） | 效果 |
|----------------------|------|
| `help` | 显示帮助 |
| `status` | 显示自己状态 |
| `allstatus` | 显示全场状态（致盲时显示过时警告） |
| `police` | 显示警察状态 |

这些在插入式笑话（Cutaway Joke）回合和星野战术宏输入模式中同样可用。

## 三、星野战术指令宏子系统（`special Hoshino` 后进入）

通过 `special Hoshino` 进入战术宏模式后，使用独立的 `_parse_tactical_command()` 解析器。输入 `terminal` 结束宏输入。

| 战术动作 | 可接受写法 | Cost | 效果 |
|----------|------------|------|------|
| 架盾 | `架盾`, `deploy`, `shield` | 2 | 进入架盾状态，快照护甲值，划分正面/背面 |
| 射击 | `射击`, `shoot`, `fire` | 2 | 用荷鲁斯之眼射击目标 |
| 重新装填 | `重新装填`, `reload`, `装填` | 0 | 消耗物品装填弹药 |
| 持盾 | `持盾`, `hold`, `举盾` | 1 | 进入持盾状态（吸收伤害） |
| 投掷 | `投掷`, `throw` | 1 | 投掷道具到指定地点 |
| 服药 | `服药`, `medicine`, `med`, `药` | 0 | 使用药物（EPO/海豚巧克力等） |
| 冲刺 | `冲刺`, `dash`, `sprint` | 1 | 移动到目标地点（每宏最多1次） |
| 取消 | `取消`, `cancel` | 0 | 取消架盾/持盾状态 |
| find | `find`, `找`, `找到` | 1 | 在宏内执行 `find` |
| lock | `lock`, `锁定` | 1 | 在宏内执行 `lock` |
| 转向 | `转向`, `turn`, `flip` | 0 | 架盾状态下翻转正面/背面 |
| 排弹 | `排弹`, `reorder`, `排列` | 0 | 重排弹匣顺序（每宏最多1次） |
| terminal | `terminal` | — | 结束宏输入，开始执行 |

注意事项：
1. 大小写不敏感：所有指令的第一个词都会被 `.lower()` 处理
2. 目标解析：玩家目标支持 `player_id` 或玩家名（含大小写不敏感匹配）
3. `split` 指令已废弃
4. 查看类指令不消耗行动

## 四、ish-bosheth 舞台模式指令（G2 Reset v0.6）

以下指令在 G2 展开舞台结界（ish-bosheth）后可用，涵盖声部选择、物料牌操作、二重唱交互等。

### 1. 声部选择（结界展开时）

舞台展开时，每位真实观众通过 `choose` 弹窗选择期望声部：

| 选项 | 对应声部 |
|------|---------|
| `入戏 (Accarezzevole)` | Acc — 消灭 Str |
| `抽离 (Indifferenza)` | Ind — 维持演出 |
| `反抗 (Strappando)` | Str — 灭 Acc 或破幕 |

最终声部由 `ma_non_troppo()` 按 2/2/2 目标自动调整。

### 2. 物料牌操作（T0 物料阶段）

每轮 T0，舞台内单位通过 `choose` 弹窗进行物料牌操作：

| 操作 | 交互方式 | 说明 |
|------|---------|------|
| 摸牌 | 自动（每 T0 摸 1 张） | 牌堆空时洗入弃牌区 |
| 拾取掉落 | `choose` → 选牌名 | 从当前座位掉落物料中拾取 1 张 |
| 打出物料牌 | `choose` → 选牌名 | 从手牌中打出最多 1 张（Soave/Sognando 可额外打 1 张） |
| 换牌 | `choose` → 交易菜单 | 与同座位单位交换手牌，每轮限 1 次 |
| 弃牌 | 如手牌超限(>3) → `choose` 弃至 3 | 超出上限时强制弃牌 |
| 接受/拒绝换牌 | `confirm` | 被请求换牌时选择是否接受 |

**不可打出的牌**：菜单中标注 `(不可打出` 的牌（声部限定不符），不可选择。

### 3. G2 演唱（特殊操作）

G2 在舞台内通过 `special`（演唱）选择歌曲和节奏：

**选歌**：`choose` 弹窗列出当前可用歌曲（含消耗和描述）。选择"放弃演唱"可跳过。

**选节奏**：若歌曲有多个节奏，再次 `choose` 选择具体节奏。

**选听者**：Soave/Sognando/Placido 需选 1 名听者；Zeffiroso 需选 2 名；Before light 无需选听者。

**旋律选座位**：旋律解锁后，G2 选 1-2 个目标座位（含伤害预览）。

### 4. G5 伴唱（duet 模式）

G5 在 G2 演唱前通过 `confirm` 选择是否伴唱：
- 伴唱 → 消耗 2 追忆，本轮歌费减半
- 不伴唱 → 无消耗，歌费不变

### 5. Duet 投票（二重唱 TE）

| 投票类型 | 时机 | 选项 |
|----------|------|------|
| 入场投票 | G5 献诗上台 | `赞成` / `反对` |
| 歌曲投票 | 每轮 R0 选歌 | 列出 G2 提名的 3 个节奏候选 |
| 位移目的地 | 位移 PvP 后（>1.0 伤害） | 可选座位列表 |
| Embrace 拥抱 | 谢幕时 | `拥抱 G2` / `拥抱 G5` / `不拥抱` |
| 安可物品 | 安可触发时 | 第一轮：选地点（商店/警察局/军事基地/魔法所/医院/家）；第二轮：选具体物品 |

### 6. 其他舞台交互

| 指令/操作 | 方式 | 说明 |
|----------|------|------|
| 攻击大红按钮 | `attack <按钮名> <武器>` | duet 模式中攻击按钮贡献热力 |
| 位移 PvP | `attack <目标> <武器>` | duet 模式中攻击对手产生位移 |
| 破幕 | `attack <G2名> <武器>` | Str 真实玩家攻击 G2/投影触发破幕 |
| 离场 | `move home_{pid}` | 离开舞台（有安可层数时失败） |
| forfeit | `forfeit` | 放弃行动回合 |

### 7. StageAI 自动决策（AI 单位）

舞台内所有 AI 单位（Chorus / BasicAI）通过 `StageAI` 模块自动决策，无需手动输入：

| 决策 | 方法 | 逻辑概要 |
|------|------|---------|
| T0 选牌 | `decide_t0()` | 按声部/位置/状态优先级选择最优牌 |
| T1 行动 | `get_command()` | duet: 合作/竞争/混合三姿态；normal: 威胁排序+射程匹配 |
| 换牌 | `decide_trade()` | 同声部换出垃圾→换入本声部专属牌 |
| 投票 | `choose()` | MVP 占位实现（默认赞成/首个选项） |

调试日志标签：`[Stg]`（L1 基本）/ `[Stg·]`（L2 详细）/ `[Stg··]`（L3 完整）。
