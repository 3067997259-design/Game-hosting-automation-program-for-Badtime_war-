## 一、设计目标与非目标

### 1.1 目标

旧 G1 是"常驻数值加成 + 失熵倒计时 + 超新星"的静态组合，玩家对失熵没有任何交互手段，
92.9% 胜率问题疑似 AI 而非数值（见 memory：G1 过强本质可能是 AI 而非数值），但常驻
被动的结构本身也让强度极难调平。重置目标是复刻流萤这个角色**完整的弧光**，而不只是
"燃烧"一个关键词：

1. **卸甲的她是脆弱的普通女孩**——常态带负修正（全 14 天赋唯一），换来发育加速；
2. **穿上战甲才是战士，但燃烧就是在死**——形态阶梯与失熵累积绑定，参战即付生命；
3. **打出节奏而非站桩**——燃烧参战 → 撤离 → 卸甲调息 → 再燃烧的风筝循环，
   恰好回到原作者手册注记中这个天赋的起源（那局靠放风筝赢下的斑纹快攻）；
4. **第三次死亡**——繁育状态是必死的最后绽放，不是免死金牌。

### 1.2 非目标

- 不引入韧性条/削韧系统；超击破以"对受控/受灼烧单位增伤"近似（§五）；
- 不做失熵症的"治愈"机制——剧情至 4.3 未给出解法，机制只做"调息"不做"痊愈"；
- 不给完整额外行动——完全燃烧的"多动"以受限追加动作（ActionGrant 受限授权）实现，
  不进入 B0 完整额外行动白名单；
- "玩家在指挥 SAM 而非扮演流萤"的风味（对齐 G7 先例）只落在 `data/prompts.json`
  文案层（战术终端/SAM 系统播报口吻），不做任何机制。

## 二、形态阶梯

三段形态构成单向上行、可跌落的阶梯。形态是公开信息。

### 2.1 卸甲常态「流萤」（默认）

- **负修正**：攻击输出修正 -⟦bal:talents.g1.unarmored_atk_penalty⟧、
  受到伤害 +⟦bal:talents.g1.unarmored_def_penalty⟧、
  命中值 -⟦bal:talents.g1.unarmored_acc_penalty⟧（视力受损——她曾以为萤火虫很美，
  后来才知道那是因为她视力不行）。
- **发育加速**：卸甲状态下每轮一次免费 `find`（不占行动槽；2026-08-08 终审自
  三候选中选定，直接服务"撤离—再定位—再燃烧"的风筝循环；结构先例为 G7 起床
  受限衔接 B1-D06）。该次免费 `find` 不是攻击类行动，不破坏 §2.1 调息条件。
- **失熵**：每轮 R4 累积 +⟦bal:talents.g1.entropy_gain_unarmored⟧（缓慢累积，
  **不暂停**——现实中的流萤离开战甲几乎无法生存，卸甲不是安全，只是更慢地死）。
- **调息**：卸甲状态下，若她本个行动回合未进行任何攻击类行动，R4 时失熵值
  -⟦bal:talents.g1.entropy_recover⟧（最低 0）。这是唯一的失熵回落通道。

### 2.2 次级燃烧「SAM·着装」（即演，1 SP）

- 换装宣言为 1 SP 即演，占用标准行动槽的 T0 兼容位，**宣言本身不消耗行动槽**
  （与 G4 转折口径统一，2026-08-08 终审裁定）。
- **禁发育**：find / interact 类行动被禁止——战甲不是用来逛街的。
- **数值加成**：攻击输出修正 +⟦bal:talents.g1.sam_atk_bonus⟧、
  受到伤害 -⟦bal:talents.g1.sam_def_bonus⟧，命中负修正消除。
- **超新星过载解锁**（§四）。
- **失熵**：每轮 R4 累积 +⟦bal:talents.g1.entropy_gain_sam⟧。
- 可随时在自己回合宣言卸甲（免费，回到 2.1）；卸甲当轮仍按着装档累积失熵。

### 2.3 完全燃烧（公演，2 SP，须处于次级燃烧中）

- 限时窗口 ⟦bal:talents.g1.full_burn_rounds⟧ 轮（建议 2–3，风洞）。
- **数值上探**：在次级燃烧基础上追加
  +⟦bal:talents.g1.full_burn_atk_bonus⟧ 输出修正。
- **自愈**：每轮 R0 回复 ⟦bal:talents.g1.full_burn_heal⟧ HP
  （对应原作强化战技回血）。
- **受限追加动作**：她的标准行动结算后，本回合内获得一次仅限
  **移动或攻击** 的追加动作（ActionGrant，permission bits 只开 move/attack，
  depth 1，不可再派生）。不进入完整额外行动白名单。
- **超新星强化**：窗口内超新星伤害与灼烧层数上探
  （+⟦bal:talents.g1.full_burn_supernova_bonus⟧）。
- **失熵**：每轮 R4 累积 +⟦bal:talents.g1.entropy_gain_full_burn⟧（最快档）。
- **燃烧殆尽**：窗口结束时强制跌回卸甲常态（2.1），并立即承受一次失熵结算（§三），
  不论量表是否达到阈值。窗口内不可主动卸甲、不可续杯（重复公演）。

## 三、失熵症：从倒计时改为量表

### 3.1 量表

- 失熵值为 0 起步、上限 ⟦bal:talents.g1.entropy_cap⟧ 的公开量表；
  累积速率由当前形态决定（卸甲 < 次级燃烧 < 完全燃烧，见 §二各档）。
- 量表达到阈值 ⟦bal:talents.g1.entropy_threshold⟧ 时，当轮 R4 触发一次
  **失熵结算**，随后量表回落 ⟦bal:talents.g1.entropy_reset_amount⟧
  （非清零——疾病不会痊愈，只是压回一段）。

### 3.2 失熵结算顺序（沿用旧设计的蚀甲缓冲结构）

1. 若持有炽愿（§六），可选消耗 1 层完全抵扣本次结算；
2. 否则优先摧毁 1 件外层护甲；
3. 无外层时，扣 ⟦bal:talents.g1.entropy_armor_loss⟧ 点内层护甲耐久；
4. 完全无甲时，扣 ⟦bal:talents.g1.entropy_hp_loss⟧ 点 HP（不再跳过——
   这就是"护甲对失熵起缓解作用"的机制化：护甲是失熵的消耗性缓冲层，
   卸甲的她被失熵直接啃食血肉）。
5. 失熵结算不构成"受到攻击"，不触发反击/关注/犯罪等任何战斗侧钩子。

### 3.3 删除项

- 删除"固定轮数倒计时 + 行动不足延后"的整套世界时钟挂钩逻辑
  （呼应 memory：绝对轮数挂钩值须 balance 化并复核——此处直接消灭了挂钩本身）；
- 删除超新星发动后"失熵后延 3 轮"（失熵改由形态驱动后无此需求）；
- 删除"因血量低免疫眩晕"（眩晕已在 M9 退役）。

### 3.4 终焉阶段增益

世界时钟进入终焉阶段后，失熵值**停止累积**（已有量表保留、结算照常）。
对应星核猎手的使命——应对"虚无"将宇宙导向的终末结局。仅此一条，不再加码。

## 四、DHGDR-超新星过载

- **形态门槛**：仅次级燃烧 / 完全燃烧 / 繁育状态可用。
- **获取**：进入次级燃烧时获得 1 次过载次数；完成击杀 +1；次数不叠加（上限 1）。
- **发动**：保留"由 move 行动触发、落点可为当前地点"的现有结构。落地后对地点内
  除自己以外的玩家与警察单位造成 ⟦bal:talents.g1.supernova_damage⟧ 点伤害，
  按 ⟦bal:talents.g1.supernova_pierce⟧ 处理穿甲，命中者获得
  ⟦bal:talents.g1.supernova_burn⟧ 层灼烧。
- **伤害属性**：普通属性 + 穿甲（沿用 B2-D06 已批准的属性口径；两段式结算下
  参数化为 `defense_coefficient` 折减，具体系数风洞）。
- **繁育状态下的超新星**：见 §五.4，附带地点摧毁。

## 五、超击破近似与繁育状态

### 5.1 超击破近似（燃烧增伤）

M9 无韧性条。以下规则近似"击破 → 超击破输出窗口"：

- 次级燃烧及以上形态中，G1 对处于**任意控制状态**（震荡/压制/石化）或
  **灼烧/虚弱**的单位造成的伤害 +⟦bal:talents.g1.break_bonus_damage⟧
  （attacker_flat_bonus 位，进两段式合同第一段）。
- 她的超新星本身挂灼烧——"超新星点燃 → 后续攻击吃增伤"即自洽的输出循环，
  不依赖队友，也不需要为她单独发明状态。

### 5.2 繁育状态：触发

- **唯一触发条件**：完全燃烧窗口内受到致死伤害。触发时取代死亡，HP 置为
  ⟦bal:talents.g1.propagation_hp⟧，进入繁育状态。**必定触发，无概率骰**
  ——确定性对 RL/BasicAI/对手博弈推理均更友好；"星核是否还在她体内"的剧情
  留白放在 prompts.json 文案层表达。
- 每局至多触发一次。
- 对手侧的公共知识由此形成："不要在她完全燃烧时把她逼入绝境"本身成为全场博弈
  的一部分——补刀权在对手手里。

### 5.3 繁育状态：内容与倒计时

- **倒计时**：进入时获得固定 ⟦bal:talents.g1.propagation_rounds⟧ 轮倒计时
  （建议 3，风洞）。倒计时归零的 R4，G1 **绝对死亡**——进入绝对死亡白名单
  （与 G5 锚定绝对实现、G4 死星天裁、G7 Terror 并列；T7 保险不赔付，
  见 `m9_t3_t7_migration_rfc_v0.1.md` §2）。
- **极端先攻**：每轮先攻获得 +⟦bal:talents.g1.propagation_initiative⟧ 加成。
- **固定公演槽**：每轮 R4 时 SP 置为 2（set 不是 add，对齐 G4 口径），
  且公演宣言不消耗 SP 以外的资源；标准行动槽正常，仍只有一个。
- **失熵停止结算**——已经不重要了。
- 繁育状态不可主动退出、不可被驱散；期间再次受到致死伤害则正常死亡
  （星核只有一枚）。
- **繁育期间可以获胜**：胜利判定在最后一个对手死亡的瞬间立即生效，优先于
  倒计时。为生而战打到最后一刻赢下来，是她能得到的最好结局。

### 5.4 繁育状态：超新星的地点摧毁（缩圈机制）

繁育状态下的超新星过载在正常结算后，**彻底摧毁**所在地点：

1. 地点获得 `destroyed` 永久标志，本局不再移除；
2. **不可进入**：所有单位（玩家、警察）的 move 目标验证直接拒绝该地点；
3. 地点内幸存单位在结算后被驱逐回各自 home；无 home 可回者（含 home 本身
   被毁的玩家）驱逐至最近的未摧毁地点（平局随机）；
4. 地面物品随地点一并销毁；地点功能永久消失（装备刷新、interact 选项等）；
5. **无豁免地点**：警察局被毁则警察状态机永久瘫痪在当前状态、不再推进；
   玩家 home 被毁则其苏醒/复活类效果的回退点改为"就地"；
6. 摧毁事件写入 event_log（缩圈是公共信息）。

**设计理由（为什么摧毁不是叙事烟花）**：繁育 G1 只剩 3 轮寿命，对手的零成本
最优解本是"全员四散拖满倒计时"。地点摧毁使可站立地图持续收缩，把"躲猫猫三轮"
变成大逃杀式缩圈终局——对手必须在被赶进死角之前做出反抗或抱团的决策。摧毁是
繁育状态的**反拖延引擎**，没有它繁育状态在博弈上不成立。3 轮 ≈ 摧毁 2–3 个
地点，收缩得了局部、收缩不完全图，两侧均有操作空间。

**滥用面评估**：劣势玩家主动在完全燃烧期挨致死伤换 3 轮爆发——可接受。代价是
确定死亡，收益要靠 3 轮内翻盘，且触发权在对手手里（可以不打）。不加补丁，
风洞阶段观察。

## 六、炽愿

- 开局 ⟦bal:talents.g1.ardent_initial⟧ 层，上限 ⟦bal:talents.g1.ardent_cap⟧。
- 超新星每命中 1 个单位 +1，每击杀 1 个单位额外 +1。
- 用途二选一（沿用旧设计）：抵扣 1 次失熵结算（§三.2 第 1 步）；或在受到穿透
  护甲后的伤害时充当 ⟦bal:talents.g1.ardent_temp_hp⟧ 点额外生命值。
- 删除"坠落在燃烧的天空"先攻加成条目（D4/D6 双加成随 B2-D05 旧候选一并退役；
  先攻戏份集中给繁育状态）。

## 八、考证附录（原作者口述稿的核实结果）

- 自机流萤：战技扣血换 144 能量、两动一大；终结技「完全燃烧」提前行动、强化
  普攻/战技、提速提击破效率，强化战技回血并植入火弱点；输出核心为超击破；
  极怕被控（输出窗口依赖敌方受击破状态）——本 RFC §五.1 的增伤近似由此而来。
- Boss 萨姆（2.0）：「次级燃烧」攻击扣自身生命、削减我方治疗；「超新星过载」
  每 2 回合一次；击破后 50% 易伤窗口——§二.2 的命名与形态对应由此而来。
- 3.8「记忆是梦的开场白」：流萤在星核前许下求生愿望（受律令三号误导），最终
  打败祸源并引爆星核；"去为了他们，为我，夺回开拓的权力"——§五繁育状态的
  "必死的最后绽放"结构由此而来。星核是否仍在她体内属剧情留白，机制取必定
  触发、文案保留悬念。
- 背景：最后的格拉默铁骑、失熵症基因疾患、"想以流萤而非铁骑的身份死去"、
  三次死亡即三次自我实现；视力受损细节未检索到一手文本，采信原作者。
