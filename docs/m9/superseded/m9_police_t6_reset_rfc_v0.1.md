## 一、重置目标

警察应是一股由案件驱动、任何玩家都能唤起但不能免费占有的中立公共力量。举报、T6 和
队长分别负责不同层次：

| 身份 | 核心问题 | 可以做什么 | 不能做什么 |
|---|---|---|---|
| 举报者 | “谁应被追缉” | 用证据建立合法通缉 | 精确操控警察 |
| T6 | “案件怎样被发现、警力怎样整备” | 远程举报、特别线索、警察配装 | 免费代替队长下令 |
| 队长 | “警力此刻怎样行动” | 改派、移动、攻击、唤醒 | 凭上任生成新警力或无责任滥权 |

当前实现把举报者连续消耗在“举报—集结—追踪”中；队长上任却生成三名全新警察、关闭
举报并取得完整指挥权。T6 又只获得若干权限补丁，其中远程举报因接口命名不一致而无法
通过真实合法性检查。本稿不保留这种“举报是低配流程、队长是完整模式”的二元结构。

## 二、案件状态机

M9 只保留四个玩家必须理解的概念：

```text
犯罪事实 / 线索
  → 举报并建立通缉
  → 警察自动出动
  → 执法或结案
```

### 2.1 事实、线索与通缉

- 犯罪事实负责记录已经发生的行为；它不等于警察立即取得攻击目标。
- 举报把一份合法证据转化为当前通缉。第一版原型只保留一个当前通缉，不建立多案件队列。
- 举报者必须存活、具备举报资格并能给出真实证据；受害者、目击者和探测归因的精确边界
  留给原型合同，不允许无证据点名任意玩家。
- 有队长时仍可举报。合法案件属于公共层，不因警力已被玩家指挥而关闭。
- 目标死亡、绝对离场、案件被合法撤销或系统进入终焉停摆时结案；清除犯罪记录能否自动
  撤销已有通缉，进入 B5 边界测试。

### 2.2 一次行动完成举报

普通举报占用举报者的一个标准根行动。它成功后立即登记通缉，但不再要求举报者在后续
行动中手动执行 `assemble` 或 `track_guide`：

1. 下一次 R2，负责该案件的警察自动集结并前往目标当时所在地点；
2. R3 中目标若移动离开，便能避开本轮 R4 的执法攻击，但为此支付了自己的标准行动；
3. 下一轮 R2，警察继续根据目标的新位置追踪；
4. 目标留在警察所在地点时，警察才在 R4 执法。

因此举报一次就能产生持续压迫；移动可以拖延警察，但不能免费消除案件。

## 三、警力、执法与掩体

### 3.1 固定警力

- 警力池在开局建立，数量、初始活跃状态和生成地点待风洞。
- 队长上任、换任或死亡不会刷新、复活或重新生成警察，也不会重置其伤势和装备。
- 警察全灭后的恢复只能来自另行登记的最高级效果；普通队长就任与 T6 演出都不能复活
  警力。
- 普通攻击可以把警察作为目标，不再限于 AOE 白名单；袭警仍登记犯罪。

### 3.2 每轮行动责任

每名正常警察在 R4 至多执行一次自动执法攻击。若队长已经在本轮命令该警察立即攻击，
该单位本轮的自动攻击额度视为已使用，不能再次出手。移动、攻击、控制恢复与装备变更
必须分别记录，不能依赖一个含义过载的布尔值。

### 3.3 警察保护改为掩体

正常警察为同地点、未被通缉的单位提供一层不可叠加的 `cover`：

- 多名警察不会叠加多层掩体；
- 被通缉者、失能警察和已经离场的警察不提供这项保护；
- 黄昏按照世界时钟关闭警察掩体，但保留案件与执法；
- 终焉令整套警察系统停摆；
- 具体减伤服从 B0 两阶段伤害与 `25%` 下限，不建立另一条伤害流水线。

## 四、队长：高控制、高责任的公开职位

### 4.1 就任

旧的“先加入警察领取奖励，再反复累计竞选进度”退出 M9 目标规则。候选结构是：干净玩家
在警察局花一个标准根行动公开登记就任；若到下一次 R2 仍存活、合法且职位空缺，则完成
就任。多人同时申请时的优先级、是否允许挑战与取消条件待纸面推演。

就任不会发放免费玩家装备、不会生成警察、不会清空案件，也不会自动给予额外行动。

### 4.2 指挥

队长每次使用自己的标准根行动，只能命令一名警察执行一项：移动、立即攻击、唤醒或改派
案件目标。队长没有通用的警察配装权限；配装是 T6 的天赋核心。队长仍可让警察按公共
通缉自动执法，选择不下令并不暂停案件。

### 4.3 威信

威信是职位责任状态，不是可支付的通用货币：

- 对合法通缉目标的执法不扣威信；
- 命令攻击无辜者、队长本人犯罪或非法篡改案件扣除威信；
- 旧的“研究性学习换威信”循环退役；威信恢复方式与上限待风洞；
- 威信归零时队长下台并成为当前通缉目标；其他玩家的犯罪记录不再被一并清空。

## 五、T6「朝阳好市民」

### 5.1 常驻：特别线索

进入他人之家、无合法许可进入军事基地、释放病毒等行为不再因 T6 在场就秘密改写为全局
犯罪。它们改为生成 T6 可以使用的特别线索；其他玩家不能仅凭这类特别线索完成普通举报。
线索公开程度、T6 死亡后已有线索是否保留，待 B5 原型决定。

### 5.2 标准根行动：市民热线

T6 可以从任意地点执行普通举报，不读取 SP，但仍消耗自己的标准根行动并服从证据、存活、
世界时钟和当前通缉合法性。远程只豁免地点要求，不豁免事实要求。

### 5.3 SP=2 演出：联防整备

T6 的主动演出核心改为警察配装：

- 选择一名存活警察，更换一件许可武器或护甲；
- 每次演出只处理一件装备，不移动警察、不命令攻击、不授予额外行动；
- 装备受白名单和补给地点限制，只属于警察，不能转交玩家或通过死亡掉落刷取；
- 暂无已部署警察时，可以为下一名出动警察登记一份待执行装备订单；订单怎样满足补给地点
  条件留给原型；
- 即演与公演使用同一配装核心；公演额外待遇留给 B4，不预先追加一次警察行动。

现行实现中的警棍、高斯步枪、魔法弹幕与四类护甲白名单可以作为原型输入，不自动成为
M9 的最终列表。

### 5.4 退役项

- 删除 T6 开局修改全局犯罪集合的实现方式；
- 删除“竞选队长所需行动数 −1”；
- 删除以 SP 演出远程举报、随后免费移动或锁定警察的旧候选；
- 不新增好市民点、行政力、举报次数或配装冷却。频率由标准行动与 SP 合同承担。

T6 仍可按普通规则申请队长；成为队长后会同时拥有后勤和指挥能力，但没有就任捷径。

2026-08-08 B5-V6 确认：无人犯罪、无合法案件时，T6 的举报通道自然变窄，不为和平局
新增补偿关注或虚构案件。T6 仍可通过普通攻击、`find` 和其他通用公开事件取得关注；
这种对秩序失灵的依赖是“把秩序变成武器”的身份边界，不是行动硬锁。

## 六、进入 B3 的接口

- G2 舞台是否暂停案件时钟、警察掩体和 R2 自动出动，由 B3 统一定义；舞台内不得继续举报。
- G3 幻想乡默认不带入警察单位、掩体与队长指令；离开后的案件仍按外部时间合同恢复。
- G5「律法」诗篇必须适配“通缉—警力—队长—威信—T6 配装”五个现行概念；未经明文
  最高级白名单，不得生成/复活警察、跳过就任等待或无视终焉停摆。
- 副舞台内部不能借警察指令递归打开外部完整行动或另一场公演。

## 七、待风洞参数与场景

| 类别 | 待验证内容 |
|---|---|
| 警力 | 2/4/6 人局数量、初始活跃状态、死亡后的可恢复性 |
| 案件 | 证据资格、一个通缉是否足够、撤销与改派、目标连续移动 |
| 执法 | R2 到达/R4 攻击节奏、每轮攻击额度、控制与唤醒 |
| 掩体 | 覆盖对象、减伤、黄昏关闭、多人同地点龟缩风险 |
| 队长 | 就任等待、多人申请、威信初值/上限/恢复、非法改派代价 |
| 配装 | 武器护甲白名单、补给地点、待执行订单、死亡与换任继承 |
| T6 | 特别线索可见性、远程举报命中率、配装演出可用率 |

至少推演：无队长举报、有队长举报、目标每轮移动、队长命令与 R4 自动攻击冲突、T6 为
他人队长整备、警力全灭、黄昏撤掩体、终焉停摆，以及 G5「律法」试图绕过停摆。
