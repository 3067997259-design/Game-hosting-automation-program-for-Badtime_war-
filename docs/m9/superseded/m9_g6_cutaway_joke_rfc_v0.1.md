## 一、结论

旧 G6 通过"轮空/forfeit 积累笑点、用笑点借用他人合法行动"的设计与 M9 全员行动和 SP 演出系统冲突。

新 G6 的规则命题是：

> **G6 可以重演他人的公开行动，或盗用他人的天赋身份执行立即结算的演出，
> 制造"你怎么有我的招式"的荒诞感和战术混乱。**

核心机制：
- **即演（1 SP）**：重演上一轮某玩家的标准行动，继承其天赋被动效果
- **公演（2 SP）**：盗用某玩家的天赋身份，执行其 T0 立即结算行动 + 可选标准行动
- 或召唤往世层玩家提供援助（复用援助系统，不消耗 PP）

## 三、核心机制

### 3.1 常驻被动：观察与记录

每个 R4，系统自动记录本轮全场的公开标准行动：

**记录内容：**
- 行动者（player_id）
- 行动类型（move / attack / interact / find / lock）
- 位置（location）
- 目标（target_id，若适用）
- 武器（weapon_id，若适用）
- 天赋被动效果标记（如 T1 的 core_slash、T3 的 starfall）

**不记录：**
- 天赋主动演出（即演/公演）
- 完整额外行动
- 反应步骤（T2 追猎反应、T4 反击）
- 控制替代行动（压制后的 forfeit）

**记录窗口：**
- 默认保留最近 1 轮
- 「欢愉」之诗可延长到 2 轮
- 第一轮开始时记录池为空，G6 不能即演重演；必须先执行普通行动。系统不提供预设
  保底模板（2026-08-08 B5-V3 裁决）

---

### 3.2 即演（1 SP）：重演剧本

**入口：** T0，1 SP 即演，占用标准行动槽

**流程：**
1. 系统显示上一轮的行动记录列表（按时间倒序）
2. G6 选择一个行动
3. 系统检查前置条件：
   - 若该行动需要特定前置（T1 面对面近战、T3 在特定地点），G6 必须满足
   - 若不满足，该行动灰掉不可选
4. G6 以自己的当前状态重新执行该行动：
   - 使用 G6 的位置、装备、资源
   - 可以重新选择目标（若原行动有目标选择）
   - 继承原行动的天赋被动效果（如 T1 的 2.0 倍伤害、T3 的石化）
5. 责任归属：
   - 费用、犯罪、关注、击杀归 G6
   - 不消耗被重演玩家的任何资源

**示例：**
```
R3: T1 在地点 A，面对面攻击玩家 B，触发核心斩击（2.0 倍伤害，防御 ×0.5）

R4: 系统记录"T1 @ 地点 A 执行核心斩击攻击玩家 B"

R5 T0: G6 即演选择"重演 T1 的攻击"
- G6 必须也在某地点与某目标面对面（满足 T1 前置）
- G6 攻击该目标，继承 T1 的核心斩击效果
- 犯罪和击杀归 G6
```

### 3.3 公演（2 SP）：插入式笑话

**入口：** T0，2 SP 公演，占用标准行动槽

**流程：**

#### 路径一：盗用在场玩家的天赋

1. G6 选择一名在场玩家 A（可以是活人或濒死状态）
2. 系统列出 A 在当前 T0 可借用的行动：
   - 检查 A 的天赋，列出所有标记为"立即结算"的 T0 行动
   - 检查 A 的当前 SP，判断哪些行动当前可用
   - 显示可借用列表（可能为空）
3. 若有可借用 T0 行动：
   - G6 选择一个，以 A 的天赋身份执行
   - 使用 G6 的位置、装备、资源、目标选择
   - 继承 A 的天赋效果框架
   - 若需要专属资源（魔力、毁伤），使用临时快照（见 §4）
4. 若该 T0 行动不消耗 A 的标准行动槽（如 T4 六爻、G5 献诗），或 A 无可借用 T0：
   - 系统继续显示 A 的标准行动列表（move/attack/interact/find/lock）
   - G6 选择一个执行，继承 A 的天赋被动效果
5. 责任归 G6：费用、犯罪、击杀
6. **即使 A 本轮已经用过该 T0 行动，G6 仍可借用**（不消耗 A 的 SP）

#### 路径二：召唤往世层援助

1. G6 选择一名往世层玩家 B
2. 系统显示 B 的援助选项（进攻援助 / 支援援助）
3. G6 选择一个，B 从往世层提供援助
4. 援助效果正常应用（伤害加成 / 治疗 / 移除标记等，具体见援助系统）
5. **不消耗 PP**（这是 G6 的天赋效果，不是真正的援助消费）

**荒诞感来源：**
- "G6 突然释放了 T1 的核心斩击" → T1：？？？
- "G6 借用 G3 投影了一把螺旋剑" → G3：这是我的招式！
- "G6 把已经死了的 T1 从往世层叫回来帮忙砍一刀" → 全桌：？？？

## 四、可借用 / 不可借用分类

### 4.1 立即结算判定标准

**可借用**的 T0 行动必须满足：
1. 在一个 T0 演出内完成全部效果
2. 不创建持续多轮的状态或合同
3. 不依赖过于复杂的专属系统（或可以通过临时快照简化）

### 4.2 可借用清单

| 天赋 | 可借用的 T0 行动 | 临时资源处理 |
|---|---|---|
| T1 | 核心斩击（2 SP 公演） | 无需特殊处理 |
| T3 | 天星（2 SP 公演） | 无需特殊处理 |
| T4 | 六爻（免费 T0） | 无需特殊处理；若结果是或跃在渊，G6 获得完整额外行动 |
| T6 | 远程举报（2 SP 公演） | 无需特殊处理；犯罪责任仍归 G6 |
| G2 | 转播/转场（2 SP/1 SP） | 无需特殊处理；影像来源绑定 G6 |
| G3 | 投影武器（1 SP 即演） | 快照 G3 魔力值，G6 获得临时魔力池 |
| G4（救世主形态） | 强化普攻（标准行动） | 可选：快照毁伤值，或不继承毁伤奖励 |
| G5 | 献诗（2 SP 公演） | 无需特殊处理；不可借锚定 |

### 4.3 不可借用清单

| 天赋 | 不可借用的行动 | 理由 |
|---|---|---|
| T5 | 谱面判定 | 被动判定，非主动行动 |
| T2 | 追猎反应 | 反应步骤，非 T0 行动 |
| G3 | 固有结界（2 SP 公演） | 创建持续多轮的结界空间 |
| G4 | 燃尽启动（2 SP 公演） | 创建持续形态，非立即结算 |
| G4 | 灾厄弑魂焚诏（2 SP 公演） | 跨多步骤拉条反击，非立即结算 |
| G5 | 锚定命运（2 SP 公演） | 创建监控期合同，持续多轮 |
| G7 | 战术宏（Cost 消耗） | 依赖专属装备（荷鲁斯之眼）和光环系统，过于复杂 |
| G6 | 重演/插入式笑话 | 递归禁止 |

### 4.4 实现机制：白名单

每个天赋维护一个 `borrowable_t0_actions` 列表：

```python
TALENT_BORROWABLE_T0 = {
```

## 五、临时资源快照

某些天赋的 T0 行动需要专属资源（魔力、毁伤），G6 借用时通过临时快照处理：

### 5.1 G3 投影武器

```
1. 系统快照 G3 当前魔力值（如 8）
2. G6 获得临时魔力池（mana_snapshot=8）
3. G6 选择投影武器（螺旋剑/双刀/七重圆环/已见过的普通武器）
4. 消耗魔力，G6 获得投影武器（实体物品，有耐久）
5. 公演结束后，临时魔力池清除
6. 投影武器保留（直到损坏/丢弃/交易）
```

### 5.2 G4 强化普攻（可选）

**方案 A：快照毁伤**
```
1. 系统快照 G4 当前毁伤值（如 15）
2. G6 获得临时毁伤池（annihilation_snapshot=15）
3. G6 执行强化普攻，继承 G4 的伤害倍率和毁伤获取机制
4. 公演结束后，临时毁伤池清除
```

**方案 B：简化（推荐）**
```
1. G6 执行强化普攻，继承 G4 的伤害倍率
2. 不继承毁伤获取机制（G6 没有毁伤系统）
3. 简单但功能完整
```

建议采用 **方案 B**：避免为单个借用场景引入复杂的临时资源系统。

## 六、责任归属

| 维度 | 归属 | 说明 |
|---|---|---|
| 费用 | G6 | 用 G6 的钱，不消耗被借用者 |
| 犯罪 | G6 | 即使借 T6 远程举报，犯罪责任仍归 G6 |
| 威信 | G6 | 队长身份和威信变化归 G6 |
| 关注 | G6 | 击杀、发现、犯罪登记归 G6 |
| 击杀 | G6 | 击杀数、PP、评分归 G6 |
| SP 消耗 | G6 | 消耗 G6 的 SP，不消耗被借用者 |
| 反击/反伤 | G6 | 攻击救世主触发反击、反伤目标均为 G6 |

## 七、「欢愉」之诗的适配

```
献予「欢愉」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 G6 的玩家
- 效果：目标获得「欢愉的录制」标记；持有该标记时：
  ① 记录窗口延长：即演可以从最近两轮选择行动（而非一轮）
  ② 下一次插入式笑话公演可以借用两名不同玩家（第一个执行完整流程，
     第二个同样执行 T0 + 可选标准行动）
  使用后标记消耗
- 爱愿：若目标非 G6 自己，获得爱愿（6 轮）
```

### 9.2 借用执行

```python
def execute_borrowed_action(g6_player, target_talent, borrowed_action):
    # 检查白名单
    if borrowed_action not in TALENT_BORROWABLE_T0[target_talent]:
        return {"error": "action_not_borrowable"}
    
    # 检查前置条件
    if not check_prerequisites(g6_player, borrowed_action):
        return {"error": "prerequisites_not_met"}
    
    # 临时注入天赋效果
    with talent_effect_override(g6_player, target_talent, borrowed_action):
        # 可能需要临时资源池
        with optional_resource_snapshot(g6_player, target_talent) as snapshot:
            result = execute_action(g6_player, borrowed_action, ...)
    
    # 责任归 G6
    assign_responsibility(g6_player, result)
    return result
```

## 十、待验证问题

### 10.1 数值与平衡

- G6 的战术价值是否足够？（相比其他神代）
- 借用机制是否容易被滥用？（如连续借 T1 核心斩击）
- 往世层援助不消耗 PP 是否过强？

### 10.2 边界细节（2026-08-08 全部裁决关闭）

- ~~G4 强化普攻是否需要继承毁伤机制？（方案 A vs B）~~ → **方案 B**：G6 获得固定
  伤害倍率，不继承毁伤获取机制，公演结束无临时资源清理负担（§5 推荐案获批）。
- ~~已死亡但未进往世层的玩家（如被 G5 锚定绝对实现击杀）能否被借用？~~ →
  **不可借**。往世层援助的对象池就是往世层；绝对实现击杀者不入往世层
  （G5 锚定合同 §4.3），不在可选池。
- ~~G2 的全息影像来源绑定 G6，若 G6 死亡影像如何处理？~~ → **立即落幕**。
  影像至多保留到来源下一行动（G2 RFC §五）；来源死亡即无下一行动，按自然落幕
  处理并写入事件日志。

### 10.3 交互复杂度（2026-08-08 全部裁决关闭）

- ~~T4 或跃在渊被借用后给 G6 完整额外行动，是否会导致连锁复杂度？~~ →
  **不产生完整额外行动**。模板只借行动大类、不复制天赋效果（天赋行动迁移合同
  §七.4）；或跃的 `full_extra` 是 T4 天赋效果，不迁移给 G6。
- ~~G3 投影武器被借用后，G6 获得的投影是否有特殊标记（如"借来的"）？~~ →
  **不涉及**。G6 以自己的装备重演 `attack`；投影武器是 G3 天赋专属资源，不进
  模板池。
- ~~借用 T6 远程举报时，威信变化是否应该同时影响被借用者？~~ → **不可借**。
  远程举报是 T6 天赋根行动，不在模板正面白名单（合同 §七.3：
  move/interact/find/lock/attack）内。

## 十一、与其他系统的接口

| 系统 | 接口点 |
|---|---|
| 行动系统 | 即演/公演占用标准行动槽；借用的 T0 可能不消耗行动槽 |
| SP 系统 | G6 消耗自己的 SP，不消耗被借用者 SP |
| 援助系统 | 召唤往世层援助复用现有援助机制，但不消耗 PP |
| 完整额外行动 | 借 T4 或跃可能给 G6 完整额外行动，需登记来源 |
| 犯罪系统 | 犯罪责任归 G6，即使借用 T6 远程举报 |
| PP/评分 | 击杀和关注归 G6，用于 B4 评分计算 |
