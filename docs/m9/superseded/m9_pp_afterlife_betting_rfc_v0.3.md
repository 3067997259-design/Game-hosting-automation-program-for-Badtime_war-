## 一、结论

M9 需要统一的表演价值货币和死后参与机制。PP（Performance Points）合并旧喝彩和星光，成为生前死后共通的表演精彩度度量。往世层不是"观众"或"菜单式行动"，而是**投资者 + 魂援提供者**的博弈系统。

核心机制：
- **PP 系统**：表演精彩度统一度量，生成于精彩事件，消耗于增益和死后投注/援助
- **投注系统**：死者押注生者，赔率人数反比，黑马机制防卡特尔
- **魂援系统**：生者发起出价、死者接受/拒绝、28 个天赋专属援助效果
- **评分系统**：生死分流计算，PP 独立于存活系数

**v0.3 结构澄清**：魂援是"下半场系统"——往世层为空时援助物理上不可能（首死 ≈ R3–R4）。
所有触发条件与数值按此时间线校准（B5 推演 v0.2 §二）。

## 二、设计哲学

### 2.1 核心问题

V2.0 EXP 的"喝彩"和"星光"是割裂的两套货币：
- 喝彩只能生前用，死后清零
- 星光只能死后获得，生前无法积累
- 死者的行动是固定菜单（观察/干预/投票），影响力有限

这导致：
1. 死亡是断点，不是转折
2. 死者是观众，不是玩家
3. 生前积累的精彩表演不能延续到死后

### 2.2 解决方案：三个统一

| 统一项 | 旧设计 | M9 设计 |
|---|---|---|
| 货币 | 喝彩（生前）+ 星光（死后） | PP（生死共通） |
| 身份 | 生者（玩家）+ 死者（观众） | 生者（演员）+ 死者（投资者） |
| 目标 | 生者争胜利，死者看戏 | 全员争终分，死者押注博弈 |

**核心原则**：
1. PP 在生死之间**连续不断**，死亡不清零
2. 死者通过**投注和援助**影响局势，不是旁观
3. 援助由**生者发起**，死者选择接受/拒绝，双向博弈
4. 黑马机制防止"全押一人"卡特尔

## 三、PP 系统：表演精彩度

### 3.1 PP 的本质

PP 不是"分数"，而是**观众对你表演的认可度**。它回答"你做得有多精彩？"

**关键特性**：
- 生前死后共通（死亡不清零）
- 可用于生前增益和死后投注/援助
- 不使用则衰减（世界的注意不会永久停留）——**死者免衰减**（见 §3.4）

### 3.2 PP 生成事件

| 事件 | PP 增益 | 触发条件 |
|---|---|---|
| 首杀 | +⟦bal:pp.first_kill⟧ | 本局第一次击杀（暂定 +2） |
| 复仇击杀 | +⟦bal:pp.revenge_kill⟧ | 击杀曾击杀过你的玩家（暂定 +3） |
| 破甲击杀 | +⟦bal:pp.armor_break_kill⟧ | 单次攻击破甲并击杀（暂定 +2） |
| 终焉击杀 | +⟦bal:pp.endgame_kill⟧ | 警察进入 dispatched 后的击杀（暂定 +2） |
| 绝境击杀 | +⟦bal:pp.clutch_kill⟧ | HP ≤ 20% 时的击杀（暂定 +2） |
| 完结条进展 | +⟦bal:pp.arc_progress⟧ | 完成天赋特定剧情里程碑（暂定 +1/阶段） |

**铸造纪律（v0.2 新增，A6）**：
- 击杀/完结条事件是仅有的常规铸造源，保证击杀主导 PP 经济；
- **援助不再铸造**（v0.1 的"援助被接受 +1 / 援助改变结果 +2"已删除）：主动援助的
  死者报酬从生者出价中**转移**支付；被动援助的提供者奖励为固定小额铸造
  ⟦bal:pp.aid_passive_reward⟧（暂定 +1），明文承认为有意的死者参与激励；
- `aid_accepted` 键退役，`aid_decisive` 键退役；balance.json 在数值批次同步清理。

### 3.3 PP 消耗（生前）

| 用途 | PP 消耗 | 效果 |
|---|---|---|
| 重掷先攻 | ⟦bal:pp.reroll_initiative⟧（暂定 1） | 重新掷 R1 先攻骰 |
| 加伤 | ⟦bal:pp.bonus_damage⟧（暂定 1） | 单次攻击裸伤 +2 |
| 偷看先攻 | ⟦bal:pp.peek_initiative⟧（暂定 1） | 提前查看下轮全场先攻顺序 |
| 抵消犯罪 | ⟦bal:pp.clear_crime⟧（暂定 2） | 清除一条犯罪记录 |

### 3.4 PP 衰减

**规则**：每个 R4，若玩家本轮**未使用 PP**（包括投注、援助、生前消耗），则：

```
PP -= ⟦bal:pp.decay_rate⟧（暂定 1）
PP = max(PP, ⟦bal:pp.min_floor⟧)（暂定最低保险值 0）
```

**死者免衰减（v0.2 澄清，A6）**：死者不因未使用而衰减。v0.1 的"死者潜伏 +1/轮"
与衰减条件完全相同、完全对冲，实际语义就是免衰减；本版直接写明，删除潜伏条目，
避免把它误读为生成事件。设计意图不变：死者 PP 只增不减（投注/援助激励参与），
生者 PP 必须用掉否则蒸发。

**设计理由**：世界的注意不能永久停留，必须持续产生精彩才能维持 PP。衰减鼓励：
- 生者持续战斗（不躲藏攒 PP）
- 死者主动投注/援助（不旁观攒 PP）

## 四、投注系统：死者的赌局

### 4.1 投注规则

死者可以在任意时刻押注一名生者：

| 规则项 | 内容 |
|---|---|
| 押注对象 | 一名在场生者（不能分散投资） |
| 押注金额 | 任意 PP（至少 1） |
| 赔率 | 存活人数 : 1（6 人存活 = 6:1，5 人存活 = 5:1，...） |
| 换人 | 花费 ⟦bal:pp.transfer_fee⟧（暂定 2 PP）转会费可换押注对象 |
| 结算 | 被押者胜利：赢回本金 + 本金 × 赔率<br>被押者死亡：输掉全部押注 |

**示例**：
```
R5: Alice 死亡，当前 6 人存活
Alice 花 10 PP 押注 Bob（赔率 6:1）

结局 A：Bob 胜利 → Alice 赢回 10 + 10×6 = 70 PP
结局 B：Bob 死亡 → Alice 输掉 10 PP
```

### 4.2 赔率公式与派彩纪律

**已拍板**：简单人数反比，不做强度修正和市场修正

```
赔率 = 当前存活人数 : 1
```

**派彩纪律（v0.2 新增，A6）**：赢者派彩由系统铸造；输家注金销毁。人数反比赔率在
均匀下注下期望收益 ≈ 0（公平赌局），信息优势者的正期望是允许的技战术回报，
不构成系统性通胀。

**设计理由**：
- 简单直接，玩家易于计算
- 博弈性来自"押谁"和"何时押"的判断，不是公式复杂度
- 避免"强度修正"引入元游戏计算负担

### 4.3 黑马机制

**定义**：无任何死者押注的生者为"黑马"

**黑马增益**：
| 援助类型 | 效果 |
|---|---|
| 进攻援助 | +⟦bal:pp.blackhorse_atk⟧ 攻击伤害（暂定 +1） |
| 防御援助 | +⟦bal:pp.blackhorse_def⟧ HP（暂定 +2） |

**黑马胜利加成**：
- 黑马胜利时，终分额外 +⟦bal:pp.blackhorse_bonus⟧（暂定 +10 PP）
- 设计理由："我没有靠任何亡灵的帮助"本身就是传奇

**归属澄清（v0.2 新增，A2）**：黑马增益是独立保底 buff，**不属于援助**——不占用
4 次援助额度，不触发任何援助 PP 奖励，不需要往世层非空。

**博弈结构**：
- 被押注多的玩家：援助选择多、价格便宜（押注者竞争）
- 黑马玩家：保底增益免费，但胜利 PP 加成高
- 死者囚徒困境：如果不押黑马，黑马赢了，所有押错人的死者全部出局

## 五、魂援系统：生者与死者的交易

### 5.1 援助触发规则（v0.2 重写，A1/A2/A5）

每个玩家每局最多使用 **4 次援助**：

| 类型 | 触发方式 | 回合成本 | 次数 |
|---|---|---|---|
| **主动进攻援助** | 自己的行动回合中发起；**一次攻击根行动 + 援助附加**——耗槽的那次攻击即是援助载体，不存在独立的"援助请求"行动 | 消耗标准行动槽（即该次攻击本身） | 每局 1 次 |
| **主动防御援助** | 自己的行动回合中发起；消耗行动槽，挂载一个延迟触发的防御标记 | 消耗标准行动槽 | 每局 1 次 |
| **被动进攻援助** | **自己每局第一次攻击且往世层非空时**自动触发 | 不消耗回合 | 每局 1 次 |
| **被动防御援助** | **自己每局第一次被打至最大 HP ⟦bal:pp.aid_hp_threshold⟧ 以下且往世层非空时**自动触发（暂定 1/5） | 不消耗回合 | 每局 1 次 |

**触发通则（v0.2 新增）**：
- "第一次"一律指**每名玩家自己**的每局第一次，不是全场唯一一次（A2）；
- **往世层非空是触发条件的一部分**（条件合取，A1）：触发条件满足时若无死者，
  被动不触发、**不消耗额度**，顺延至下一次满足时判定。被动援助是保底高光，
  只会迟到，不会缺席；
- 被动防御援助**不锁血**：一击从 1/5 以上直接致死不触发。高爆发流派（如 T1 级
  单发伤害）天然可以绕过被动防御援助——这是有意的可推理后果，不是漏洞（A2）；
- 主动援助给玩家"什么时候叫"的决策空间；被动援助保证每个玩家至少有两次高光
  时刻（第一次出手、第一次濒死）。

### 5.2 援助交易流程（v0.2 拆分主动/被动，A4）

**主动援助（双向博弈）**：

```
1. 生者发起援助（攻击即载体 / 挂载防御标记），选择出价（1-3 PP）
   ↓
2. 系统向所有死者广播，显示出价与当前情境（目标、HP、装备等）
   ↓
3. 死者决策（接受 / 拒绝）
   - 可以援助任何生者（不限于被押者）
   - 无谈判，无还价
   ↓
4. 多个死者同时接受时：只有标价最低的死者成交（价格竞争），其余拒绝
   ↓
5. 援助生效：生者出价 PP **转移**给成交死者；天赋专属援助效果生效；援助公开
```

**被动援助（免费保底 + 系统指派）**：

```
1. 被动触发条件满足（且往世层非空）
   ↓
2. 系统按序指派一名死者提供援助：
   ① 押注该生者 PP 最多的死者；② 无押注时取最早死亡者
   ↓
3. 援助生效：生者不支付 PP；被指派的死者获得
   ⟦bal:pp.aid_passive_reward⟧（暂定 +1，铸造）
```

**博弈点**：
- 生者：主动援助出价太低可能无人接受，出价太高浪费 PP
- 死者：接受低价保护投资，拒绝可能错失收入；被动指派是额外收入通道
- 卡特尔背叛：死者可以援助非被押者赚外快
- 垄断期提示：往世层只有 1 名死者时竞价不成立，该死者接受即成交

3. 原动作降级为使用同一行动者、同一目标和合法武器的一次基础攻击；行动槽与 SP 照常消费，
   遵守“已承诺主动行动不归零”纪律；
4. 非攻击型仪式（锚定、献诗、展开结界）不触发；若无法形成合法基础攻击，则本援助不触发、
   标记保留；
5. 这是对“抢在大招前摇完成前截断武装”的一次性复刻，不恢复 G3 旧版整轮主动/被动
   天赋封锁悬崖。

**设计说明**：
- T3/T4 强力效果（AOE 全场、放逐、当身）需风洞验证
- G3 进攻援助的禁 move 仍待风洞；防御援助已改为单次前摇截断，不再整轮压制
- G5/G6 不区分攻防（符合天赋机制特性）
- G7 直接借用原作战星 EX 技能形态

## 六、评分系统

### 6.1 生者终分

```
生者终分 = (剧情分 + 战果分) × 存活系数 + PP
```

| 项 | 计算 |
|---|---|
| 剧情分 | 完结条进展阶段数 × ⟦bal:scoring.arc_weight⟧（暂定权重） |
| 战果分 | 击杀数 × ⟦bal:m9_system.scoring_m9.kill_weight⟧ + 总伤害 × ⟦bal:m9_system.scoring_m9.damage_weight⟧（暂定权重） |
| 存活系数 | 存活：1.5 / 死亡：0.5 |
| PP | 剩余 PP 直接加入终分 |

**水晶花评分挂接（v0.3，W4）**：一朵水晶花只登记 **`arc_count +1`**，按当前
`arc_weight` 在剧情分中提供 2 分；第一版不提供战斗强化或追忆折扣。水晶花的获得
条件与回溯边界由 [G5 锚定合同 v0.2](m9_g5_anchor_contract_rfc_v0.2.md) 定义，
本版只负责评分侧挂接。

### 6.2 死者终分

```
死者终分 = 剩余 PP + 赌注收益 + 援助收益
```

| 项 | 计算 |
|---|---|
| 剩余 PP | 本局结束时的 PP 值 |
| 赌注收益 | 被押者胜利：本金 × 赔率 / 被押者死亡：-本金 |
| 援助收益 | 每次援助获得的 PP 之和（主动转移 + 被动固定奖励） |

### 6.3 关键特性

**PP 独立于存活系数**：
- 死者可以通过高 PP（援助 + 押注翻倍）反超存活者
- 生者不能单纯靠"活着"赢，必须产生精彩表现

**黑马胜利加成**：
- 无押注者胜利时，终分额外 +⟦bal:pp.blackhorse_bonus⟧（暂定 +10）

## 九、已否决方案（避免重提）

| 方案 | 否决理由 |
|---|---|
| 菜单式往世层 | 选择太少，影响太小，无叙事 |
| 谈判/还价机制 | 太复杂，拖慢节奏 |
| 死者主动发起援助 | 生者没有决定权，破坏双向博弈 |
| 强度修正赔率 | 元游戏计算负担，偏离"押谁"判断 |
| 关注/观察机制 | 完美信息下无意义 |
| 纯赌局无援助 | 死者主动性不足，仍是观众 |
| 被动援助字面触发（空窗打空） | 往世层为空时无提供者，违背保底高光意图（v0.2，A1） |
| 被动援助向生者收费 | 被动是省心保底，强制扣费体验差（v0.2，A4） |
| 援助 PP 奖励全额铸造 | 援助取代击杀成为最大 PP 源，颠覆表演价值定位（v0.2，A6） |
