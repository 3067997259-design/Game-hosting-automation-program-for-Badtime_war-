## 一、结论

G7 保留原设计的核心系统（铁之荷鲁斯、荷鲁斯之眼、光环、Cost、战术宏、Terror），
只做 M9 框架必需的最小适配。

新 G7 的规则命题是：

> **G7 通过即演/公演回复 Cost 和获取补给，用 Cost 驱动的战术宏实现持续战术压制。
> 三形态提供不同的全局加成，鼓励战术切换。Terror 作为色彩 10 特判，失去一切变成纯粹破坏者。**

核心改动：
- **三形态**：从一次性起床收益改为持续全局加成
- **SP 适配**：即演回复 Cost +1，公演回复 Cost 满 + 获取补给
- **战术宏**：不需要 SP，随时可用（只要有 Cost）
- **起床衔接**：临战形态起床后受限菜单（B1 已定）

## 二、核心系统（完全保留）

以下系统保留原设计，只标注数值待风洞：

### 2.1 融合装备

**铁之荷鲁斯（盾）**：
- 第一次同时持有普通盾牌和 AT 力场时，自动融合
- 初始耐久：⟦bal:m9_talents_extended.g7.iron_horus_durability⟧
- 架盾/持盾/被动保护机制完全保留（见原设计）
- 正面/背面划分完全保留

**荷鲁斯之眼（枪）**：
- 第一次同时持有电磁步枪和高斯步枪时，自动融合
- 弹匣上限：8 发
- 3 弹丸射击系统完全保留
- 子弹类型（科技/魔法/普通）完全保留

**自动习得战术指令**：
- 完成双融合后，获得 2 次自由配发机会
- 每次可选择：1 个战术道具、1 种药物，或 2 发某属性子弹

### 2.2 光环系统

- 初始层数：⟦bal:m9_talents_extended.g7.halo_initial_layers⟧
- 每层提供 0.5 HP 护体值
- 一次免死：光环耗尽时免疫第一次致死伤害
- 恢复机制：每个 R0 恢复 X 层（数值待风洞，临战-Shielder 形态 +1）
- 受伤消耗机制保留

### 2.3 Cost 系统（SP 适配）

**Cost 池**：
- 最大值：⟦bal:m9_talents_extended.g7.cost_base_cap⟧（暂定 5）
- 用于编辑战术宏，每个动作消耗不同 Cost

**Cost 回复（新规则）**：
- 每个 R0，根据上一轮行动类型回复：
  ① 若上一轮使用了**即演**：Cost +1（水着形态：+2）
  ② 若上一轮使用了**公演**：Cost 回满到上限
  ③ 若上一轮未使用即演/公演：Cost 不回复（保持当前值）

**删除**：
- 旧的"失却汇流成泉"惩罚（连续使用宏的 Cost 惩罚）

### 2.4 战术宏系统

**完全保留原设计的宏动作**：
- 移动类：冲刺、移位、撤退
- 攻击类：射击、近战、冲击
- 盾牌类：架盾、持盾、取消、转向
- 道具类：使用道具、排弹
- 每个动作的 Cost 消耗保留（数值待风洞）

**宏编辑入口（新规则）**：
- **不需要 SP**，G7 随时可以进入宏编辑（只要有 Cost）
- 在自己的标准行动回合，选择"战术宏"
- 用当前 Cost 编辑宏，Cost 不够做不了复杂动作
- 宏执行完毕后，Cost 清零

### 2.5 战术道具与药物

**战术道具（完全保留）**：
- 手雷、烟雾弹、闪光弹、燃烧瓶
- 一次性消耗品，宏中可使用
- Cost 消耗和效果保留（数值待风洞）

**药物（保留，效果微调）**：
- 肾上腺素：立即回满 Cost 到上限（打破回复规则）
- EPO：移除所有负面标记（震荡/石化/易伤/致盲等），SP +1
- 海豚巧克力：立即回血 +X，下次受伤减少 Y 点
- 止痛药：下次宏编辑时 Cost +Z（突破上限）
- 兴奋剂：本轮所有攻击命中 +A、伤害 +B；下轮 SP 不增长
- 具体数值待风洞

### 2.6 Terror 系统（完全保留 + 同步）

**色彩累积**：
- 场上每有 1 名玩家因任何原因出局：+2 色彩
- 该玩家由 G7 击杀：额外 +2 色彩
- **非击杀出局也计入**（2026-08-09 B5 W10 批准）：例如 G0 调整呼吸失败退场属于
  "玩家出局"，为 G7 提供 +2 色彩，但 G7 非其击杀者则没有额外 +2，也没有击杀计数；
  详见 [G0 RFC v0.2](m9_g0_shiroko_terror_rfc_v0.2.md) §7.3
- 色彩 6：可选择进入"自我怀疑"
- 色彩 10：本体受伤不死则强制进入"自我怀疑"

**自我怀疑 → Terror**：
- 自我怀疑状态下，下一次行动回合被跳过
- 该回合结束时，反转为 Terror

**Terror 形态**：
- Cost 显示为 Null，玩家名覆盖为「星野-Terror」
- 失去所有战术指令、道具、药物、铁之荷鲁斯、光环
- 只允许 attack 和 move
- 进入时，护甲/光环折算为额外生命值（公式保留，数值待风洞）
- Terror 攻击：对全图所有玩家造成伤害，扣除自身额外生命；该伤害登记为
  **`DIRECT_DAMAGE`**（[结算合同 RFC v0.2](m9_resolution_contract_rfc_v0.2.md) §6.6），
  且 **`absolute_death` 为是**——Terror 形态下挂载的复活不生效，生命值归零立即死亡
- Terror 移动：移动后扣除自身额外生命
- **警察不主动靠近或攻击 Terror**（同步到 [警察/T6 RFC v0.2](m9_police_t6_reset_rfc_v0.2.md)
  §3.6）：Terror 从警察合法执法目标池排除，警察不追踪、不列为执法目标
- **Terror 不参与即演/公演**，所有行动与现有设计保持一致

具体数值（额外生命折算、攻击/移动代价）待风洞。

## 三、三形态系统（重做为全局加成）

### 3.1 设计变更

**旧设计**：三形态各有一次性起床收益，之后形态选择意义不大

**新设计**：三形态提供持续的全局加成，鼓励战术切换

### 3.2 三形态定义

**水着-Shielder（持续进攻专精）**：
- 架盾/持盾状态下，正面受到的伤害 -1（最低至 1）
- 架盾每个 R4 不扣 Cost（免费维持）
- 持盾移动不额外消耗 Cost
- **即演 Cost 回复量翻倍**：即演时下个 R0 Cost +2（而非 +1）
- 适用于：守点 + 频繁中等宏进攻

**临战-Archer（远程火力专精）**：
- 射击弹丸飞散范围缩小（命中更稳定，数值待风洞）
- 连续射击机制：每连续 2 次射击，第 3 次免费且必中
- 所有攻击类宏的 Cost 消耗 -1
- 起床后 SP 置 2（保留快速准备特性）
- 适用于：远程输出 + 快速准备

**临战-Shielder（突击防御专精）**：
- 持盾状态下，若一个宏中先冲刺再攻击，该攻击附带震荡（目标下次行动只能受限菜单）
- 架盾/持盾状态下，正面受到的伤害 -1（最低至 1）
- 光环每个 R0 恢复 +1 层（比基础恢复快）
- 适用于：近战突击 + 坚固防御

### 3.3 更衣

- 在家中（安全屋）使用 `special 更衣 <形态>`
- 消耗标准行动槽
- 不需要 SP，不需要 Cost
- 更衣不重新获得起床收益（因为已经是全局加成）

## 四、SP 适配

### 4.1 即演（1 SP）

**入口**：T0，1 SP 即演，占用标准行动槽

**效果**：
- 下个 R0 Cost 回复 +1（水着形态：+2）
- 仅此而已，没有其他特殊能力
- G7 的即演是"小准备"

### 4.2 公演（2 SP）

**入口**：T0，2 SP 公演，占用标准行动槽

**效果**：
1. 下个 R0 Cost 回满到上限
2. 选择获得一个战术道具或药物：
   - 战术道具：手雷 / 烟雾弹 / 闪光弹 / 燃烧瓶
   - 药物：肾上腺素 / EPO / 海豚巧克力 / 止痛药 / 兴奋剂
   - 直接加入 G7 的携带物品，无需回家补给
3. 打开 PP/魂援调用点

### 4.3 战术宏（不需要 SP）

**入口**：在自己的标准行动回合，选择"战术宏"

**流程**：
1. 系统显示当前 Cost 值
2. G7 编辑宏：选择动作序列（射击 → 冲刺 → 攻击 → 持盾 → ...）
3. 每个动作消耗对应 Cost，Cost 不够则不能添加更多动作
4. 确认后执行宏
5. 宏执行完毕后，Cost 清零

**设计意图**：
- 战术宏是 G7 的核心战斗方式，不应被 SP 限制
- G7 通过即演/公演准备 Cost，然后用战术宏战斗
- 与其他天赋的区别：
  - T1：公演 = 核心斩击（直接攻击）
  - G7：公演 = 准备（回 Cost + 拿补给），真正的战术在"战术宏"中

## 五、起床衔接（B1 已定）

### 5.1 临战-Archer / 临战-Shielder

起床后可在同一个起床槽内选择执行至多一个：
- `move`
- 非敌对 `interact`
- `find`
- `lock`
- 或结束行动槽

**不能**：
- 不能攻击
- 不能使用战术宏
- 不能即演/公演
- 不能使用 special

### 5.2 水着-Shielder

无特殊起床衔接（正常起床）。

## 六、典型战斗流程

### 6.1 水着-Shielder 守点流程

```
R1: 公演（下轮 Cost 回满，拿烟雾弹）
R2: 战术宏（5 Cost）：架盾 → 射击 → 射击 → 使用烟雾弹
    Cost 清零，本地点获得烟雾掩护
R3: 即演（下轮 Cost +2，水着加成）
R4: 战术宏（2 Cost）：射击 → 转向
    持续守点输出
R5: 即演（下轮 Cost +2）
R6: 战术宏（2 Cost）：射击 → 取消
    ...
```

**特点**：频繁即演 + 中等宏，持续守点压制

### 6.2 临战-Archer 远程流程

```
R0: 起床 SP=2（Archer 特性）
R1: 公演（下轮 Cost 回满，拿手雷）
R2: 战术宏（4 Cost，攻击宏 -1）：射击 → 射击 → 射击（第 3 次免费必中）→ 使用手雷
    远程清场
R3: 标准行动 move（调整位置）
R4: 公演（下轮 Cost 回满，拿肾上腺素）
R5: 战术宏（5 Cost）：射击 → 射击 → 射击 → 移位
    持续远程压制
```

**特点**：快速准备 + 远程输出稳定

### 6.3 临战-Shielder 突击流程

```
R1: 公演（下轮 Cost 回满，拿肾上腺素）
R2: 战术宏（5 Cost）：持盾 → 冲刺 → 攻击（附带震荡）→ 取消 → 射击
    冲脸震荡，正面减伤 -1 保护自己
R3: 标准行动 attack（受震荡影响，对手下轮受限）
R4: 使用肾上腺素（回满 Cost）
    战术宏（5 Cost）：持盾 → 冲刺 → 攻击 → 射击
    连续突击
```

**特点**：冲锋震荡 + 正面防御 + 光环快恢复

## 八、实现边界

### 8.1 宏编辑 UI

- 显示当前 Cost 值
- 列出可用动作及其 Cost 消耗
- 实时显示剩余 Cost
- 动作序列预览
- 确认 / 取消 / 重置

### 8.2 Cost 计算

```python
# 每个 R0 回复 Cost
def restore_cost_r0(player):
    if player.last_turn_action == 'instant_performance':
        if player.current_form == '水着-Shielder':
            player.cost = min(player.cost + 2, player.cost_cap)
        else:
            player.cost = min(player.cost + 1, player.cost_cap)
    elif player.last_turn_action == 'grand_performance':
        player.cost = player.cost_cap  # 回满
    # else: 不回复
```

### 8.3 公演补给选择

```python
# 公演时选择补给
def grand_performance_supply(player):
    options = {
        'tactical_items': ['手雷', '烟雾弹', '闪光弹', '燃烧瓶'],
        'medicine': ['肾上腺素', 'EPO', '海豚巧克力', '止痛药', '兴奋剂']
    }
    
    choice = player.choose_from_options(options)
    player.add_item(choice)
```
