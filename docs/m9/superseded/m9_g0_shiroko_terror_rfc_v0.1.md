## 一、结论

G0 是 M9 新增的第八个神代天赋，填补原 T5 槽位。不同于其他原初/神代，G0 来自另一个时间线的阿拜多斯，
她的存在本身就是"跨越"。

核心机制：
- **BLACK FANG 465（AR）**：替代弓，箭矢转化为子弹，与无人机协同时属性为"神秘"
- **无人机召唤物**：消耗 SP + HP 召唤，可协同攻击或释放十字炮火
- **遗物支援技**：从已退场玩家遗留中拾取装备，可摧毁换取对应天赋的增强支援
- **调整呼吸**：濒死保护，HP 锁最小值并免疫一定时间，未回满则退场
- **代价机制**：所有核心能力均消耗当前 HP%，体现"燃烧生命战斗"的主题

## 二、设计哲学

### 2.1 为什么是 G0

**身份定位**：
- **不是原初 T 系列**：白子*Terror 来自另一个时间线，不属于本世界的七个原初身份
- **先于神代 G1-G7**：G0 的"零号"代表她是"不在序列中的异数"，超越了神代编号体系
- **与 G7 星野的关联**：同为阿拜多斯成员，共享《Blue Archive》世界观，但白子来自更黑暗的分支时间线

**剧情背景**（基于搜索结果）：
- 白子*Terror 与 Phrenapates（主要反派）和 The Chroma 相关
- 她跨越时间线而来，背负着"已经失去的明天"
- 天赋名"我还欠她们一个明天"指向她已逝的同伴（阿拜多斯成员）

### 2.2 核心主题

| 主题 | 机制体现 |
|---|---|
| **跨越者** | 不使用弓（原初武器），而是 AR（另一个世界的武器） |
| **燃烧生命** | 所有核心能力消耗当前 HP%，越强的能力代价越高 |
| **死者的武器** | 拾取已退场玩家的装备，摧毁换取对应天赋的支援技 |
| **最后的呼吸** | 濒死保护机制，给自己最后的喘息空间 |
| **孤独的战斗** | 无人机是唯一的"同伴"，但也只是机械 |

## 三、常驻被动：BLACK FANG 465 与神秘属性

### 3.1 武器替换

**弓 → AR（突击步枪）**：
- G0 开局不持有弓，而是持有 BLACK FANG 465（AR，突击步枪）
- AR 初始弹匣：⟦bal:talents.g0.ar_magazine⟧（暂定 30 发）
- AR 射程：中远程（与电磁步枪/高斯步枪同级）
- AR 基础伤害：⟦bal:talents.g0.ar_base_damage⟧（暂定与弓相当）

**箭矢转化**：
- 所有"箭矢"类资源（find、交互、掉落）自动转化为"子弹"
- 转化比例：1 箭矢 = ⟦bal:talents.g0.arrow_to_bullet_ratio⟧ 子弹（暂定 3 发）
- AR 不能使用弓的升级模块（穿甲箭、火焰箭等），但可以正常装填子弹

### 3.2 神秘属性（协同攻击专属）

**触发条件**：AR + 无人机同时在场时，AR 的攻击变为"协同攻击"

**神秘属性效果**：
- 命中目标时，系统自动计算三种属性（科技/魔法/普通）对该目标造成的最终伤害
- 选择**最终伤害最高**的属性作为本次攻击的实际属性
- 属性选择在伤害结算前完成，目标无法预判

**示例**：
```
G0 攻击目标 A（持有科技护甲）

系统计算：
- 科技属性：被克制，最终伤害 0
- 魔法属性：克制科技护甲，最终伤害 3.0
- 普通属性：无克制，最终伤害 2.5

选择魔法属性，造成 3.0 伤害
```

**设计理由**：
- 神秘属性不是"第四种属性"，而是"智能选择最优属性"
- 体现 AR + 无人机的协同智能
- 避免被单一护甲完全克制

## 四、无人机召唤物系统

### 4.1 召唤规则

**消耗**：
- 1 SP + ⟦bal:talents.g0.drone_hp_cost⟧% 当前 HP（暂定 20%）
- 占用标准行动槽

**召唤限制**：
- 同时最多存在 1 个无人机
- 无人机持续 ⟦bal:talents.g0.drone_duration⟧ 轮（暂定 3 轮）
- 持续期间每个 R4 倒计时 -1，归零时无人机消失

**无人机属性**：
- 位置：与 G0 相同地点（G0 移动时，无人机同步移动）
- 生命值：⟦bal:talents.g0.drone_hp⟧（暂定 5 HP）
- 可被攻击：其他玩家可以选择攻击无人机（视为独立单位）
- 被摧毁：无人机 HP 归零时立即消失，G0 不受伤害

### 4.2 协同攻击

**触发**：G0 使用 AR 进行 attack 行动时，若无人机在场，自动触发协同

**效果**：
- AR 攻击属性变为神秘属性（见 §3.2）
- 无人机对同一目标附加 ⟦bal:talents.g0.drone_bonus_damage⟧ 点科技属性伤害（暂定 +1）
- 两段伤害独立结算（分别检查护甲、克制）

### 4.3 行为逻辑

**非玩家控制**：
- 无人机不占用独立行动槽（类似警察，但跟随 G0）
- 无人机不会主动攻击，只在 G0 攻击时协同
- 无人机不能执行 move/find/lock 等行动

**与警察系统的区别**：
| 项 | 无人机 | 警察 |
|---|---|---|
| 召唤者 | G0（玩家） | T6 或警察系统 |
| 位置 | 跟随 G0 | 独立地点 |
| 行动 | 协同攻击 | 独立行动槽 |
| 持续时间 | 固定轮数 | 永久（直到死亡） |
| 目标选择 | G0 决定 | 系统决定 |

## 五、即演（1 SP）与公演（2 SP）

### 5.1 即演（1 SP）

**入口**：T0，1 SP 即演，占用标准行动槽

**效果**：召唤无人机（见 §4.1），消耗 1 SP + 20% 当前 HP

**设计理由**：
- 即演只提供召唤功能，不打开公演专属窗口
- 允许 G0 在战术窗口快速部署无人机

### 5.2 公演（2 SP）：十字炮火 or 遗物支援技

**入口**：T0，2 SP 公演，占用标准行动槽

**前置条件**：无人机必须在场（若无人机不在场，公演选项灰掉）

**效果选择**（二选一）：

#### 选项 A：十字炮火

- 消耗：2 SP + ⟦bal:talents.g0.crossfire_hp_cost⟧% 当前 HP（暂定 20%）
- 效果：无人机在当前所在地点释放十字炮火
  - 对该地点所有单位（含 G0 自己）造成 ⟦bal:talents.g0.crossfire_damage⟧ 点真伤（暂定 3 点）
  - 真伤无视护甲、属性克制、减伤效果
  - 无人机在释放后立即消失

#### 选项 B：遗物支援技

- 前置条件：G0 必须持有至少一件"遗物装备"（从已退场玩家遗留中 find 拾取的装备）
- 消耗：2 SP + ⟦bal:talents.g0.relic_support_hp_cost⟧% 当前 HP（暂定 20%）+ 摧毁该遗物装备
- 效果：释放该装备原持有者天赋的**增强支援技**（见 §6）
- 无人机继续保留（不消失）

**设计理由**：
- 十字炮火是高伤害 AOE，但会伤害 G0 自己且消耗无人机
- 遗物支援技需要特定条件（拾取遗物），但保留无人机且提供天赋特化效果

## 六、遗物支援技系统

### 6.1 遗物装备获取

**遗留机制**：
- 玩家退场（死亡/离线）时，其持有的装备掉落在当前地点，成为"遗留"
- 遗留装备可被其他玩家通过 find 拾取
- G0 拾取的遗留装备标记为"遗物装备"，记录原持有者的天赋

**标记规则**：
```
遗物装备 = 普通装备 + 原持有者天赋标签
示例：「星野的荷鲁斯之眼（遗物）」
```

### 6.2 14 个天赋的遗物支援技

G0 摧毁遗物装备时，释放对应天赋的**增强支援技**（比魂援更强，但需要摧毁装备）：

#### 原初天赋（T1-T7，跳过 T5/G0）

| 天赋 | 遗物支援技效果 |
|---|---|
| **T1 一刀缭断** | G0 下次 AR 攻击无视目标所有护甲，伤害 ×⟦bal:talents.g0.relic_t1_mult⟧（暂定 ×1.5） |
| **T2 剪刀手传奇** | G0 获得隐身，持续 ⟦bal:talents.g0.relic_t2_duration⟧ 轮（暂定 2 轮） |
| **T3 天星** | 对 G0 当前地点所有其他单位造成 ⟦bal:talents.g0.relic_t3_damage⟧ 点普通属性伤害并施加石化（暂定 2 伤害） |
| **T4 六爻** | G0 下次受到伤害时，触发一次"否卦"效果（伤害减半） |
| **T6 朝阳好市民** | 在 G0 当前地点召唤一个带警棍的警察单位，立即对该地点有通缉的单位攻击一次 |
| **T7 死者苏生** | G0 获得"临时复活标记"：下次致死伤害时保留 1 HP（一次性） |

#### 神代天赋（G1-G7）

| 天赋 | 遗物支援技效果 |
|---|---|
| **G1 火萤 IV 型** | 对 G0 当前地点所有单位造成 ⟦bal:talents.g0.relic_g1_damage⟧ 点伤害和 ⟦bal:talents.g0.relic_g1_burn⟧ 层灼烧（暂定 2 伤害 + 2 层） |
| **G2 请一直注视着我** | G0 创建一个临时全息影像（持续 1 轮），可执行一次转播攻击 |
| **G3 神话之外** | G0 投影一把螺旋剑（伪），持续 ⟦bal:talents.g0.relic_g3_duration⟧ 轮，武器伤害 +⟦bal:talents.g0.relic_g3_bonus⟧（暂定 2 轮 / +1） |
| **G4 愿负世** | G0 获得 ⟦bal:talents.g0.relic_g4_stacks⟧ 层"余烬护甲"（每层吸收 0.5 伤害，暂定 4 层） |
| **G5 往世的涟漪** | G0 获得 ⟦bal:talents.g0.relic_g5_memory⟧ 点追忆（暂定 6 点） |
| **G6 要有笑声** | G0 立即执行一次即演（重演上一轮某玩家的标准行动），不消耗 SP |
| **G7 大叔我啊，剪短发了** | G0 获得一个临时掩体（生命值等于 G0 当前 HP ×⟦bal:talents.g0.relic_g7_ratio⟧，持续 ⟦bal:talents.g0.relic_g7_duration⟧ 轮，暂定 50% / 2 轮） |

**设计说明**：
- 遗物支援技强度高于魂援（因为需要摧毁装备 + 消耗 20% HP）
- 效果主题贴合原天赋，但简化为单一增益
- G5 支援技给追忆（允许 G0 献诗，产生联动）

## 七、调整呼吸：濒死保护

### 7.1 触发条件

**受到致命攻击时**（会导致 HP ≤ 0 的伤害）：
- 自动触发"调整呼吸"
- 每局最多触发 ⟦bal:talents.g0.breath_max_uses⟧ 次（暂定 1 次）

### 7.2 效果

**进入"调整呼吸"状态**：
- HP 固定为 ⟦bal:talents.g0.breath_min_hp⟧（暂定 1 HP，不能被进一步降低）
- 免疫所有攻击伤害
- 免疫所有 debuff（石化、震荡、灼烧等）
- 持续 ⟦bal:talents.g0.breath_duration⟧ 轮（暂定 2 轮）
- 状态结束时检查 HP：
  - 若 HP < 最大 HP（未回满）：G0 立即退场
  - 若 HP = 最大 HP（已回满）：G0 正常继续

**限制**：
- 调整呼吸期间，G0 可以正常行动（move/find/attack 等）
- 调整呼吸期间，G0 不能召唤新无人机（若无人机已在场则保留）
- 调整呼吸期间，G0 不能使用公演（十字炮火/遗物支援技灰掉）

### 7.3 退场规则

**"退场"不是"死亡"**：
- G0 不进入往世层（不能投注、不能提供魂援）
- G0 不计入击杀关系（最后攻击者不获得击杀数）
- G0 的装备掉落为遗留（其他玩家可拾取）
- G0 的终分按"提前离场"计算（见 §九）

**设计理由**：
- 调整呼吸体现"最后的喘息"，但不是免死金牌
- 若 G0 未能在保护时间内回血，则"燃尽生命"退场
- 退场不是死亡，避免与 T7 复活、往世层等系统冲突

## 八、系统接口与边界

### 8.1 与警察系统的接口

| 项 | 无人机 | 警察 |
|---|---|---|
| 召唤成本 | 1 SP + 20% HP | T6 配装/系统自动召唤 |

| 行动槽 | 无独立行动槽 | 有独立行动槽 |
| 犯罪判定 | 攻击无人机不算犯罪 | 攻击警察算犯罪 |

### 8.2 与魂援系统的接口

| 项 | 遗物支援技 | 魂援 |
|---|---|---|
| 触发 | G0 主动摧毁遗物装备 | 生者出价、死者接受 |
| 成本 | 2 SP + 20% HP + 装备 | 1-3 PP |
| 效果强度 | 增强版（比魂援更强） | 标准版 |
| 次数限制 | 无限制（只要有遗物） | 每局 4 次 |

### 8.3 与 G7 星野的交互

**同作品角色联动**：
- 若 G0 拾取星野的遗物（荷鲁斯之眼/铁之荷鲁斯），遗物支援技效果增强 ⟦bal:talents.g0.g7_synergy_bonus⟧%（暂定 +20%）
- 若 G7 星野对 G0 提供魂援，援助效果增强 ⟦bal:talents.g7.g0_synergy_bonus⟧%（暂定 +20%）
- 设计理由：阿拜多斯成员之间的羁绊

## 九、评分与终局

### 9.1 正常退场（死亡）

- 进入往世层：❌ 否（G0 退场不是死亡）
- 计入击杀：❌ 否（最后攻击者不获得击杀数）
- 装备掉落：✅ 是（成为遗留）
- 终分计算：按"提前离场"公式

### 9.2 终分公式

```
G0 终分 = 基础分 + PP + 遗物支援技使用次数 × ⟦bal:scoring.g0_relic_bonus⟧

基础分 = 击杀数 × ⟦bal:scoring.kill_weight⟧ + 总伤害 × ⟦bal:scoring.damage_weight⟧
```

**特殊加成**：
- 每次成功使用遗物支援技：+⟦bal:scoring.g0_relic_bonus⟧ 分（暂定 +5）
- 调整呼吸后成功回满并存活到最后：+⟦bal:scoring.g0_breath_survive_bonus⟧ 分（暂定 +10）
