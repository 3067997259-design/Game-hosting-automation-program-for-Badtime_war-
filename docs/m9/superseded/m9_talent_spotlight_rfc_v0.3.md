## 一、共同合同

### 1.1 四种演出形态

| 形态 | 玩家何时决定 | SP 合同 | 是否占行动槽 |
|---|---|---|---:|
| 即演 Instant | 自己任一合法 T0 | SP≥1；结算后消耗 1 SP | 默认是；明文 T0 兼容宣言可例外 |
| 公演 Public | 先以 SP=2 自愿报名，取得未来公演位后在 T0 发动 | 必须保持 SP=2；结算后消耗 2 SP | 是 |
| 伏笔 Foreshadow | 即演或公演时布置，满足旧条件后自动兑现 | 布置时按入口消费；兑现不读 SP | 布置时占用；兑现时不占用 |
| 转折 Turning Point | 濒死、死亡、受击或故事条件达成时自动发生 | 不读取 SP | 否 |

SP 是固定的能力层级，不是逐效果货币：SP0 无主动演出，SP1 可即演，SP2 可即演或公演。
所有即演统一消耗 1，所有公演统一消耗 2；天赋 RFC 无权另设价格。

### 1.2 即演与公演不是弱版、强版按钮

两者共享同一个天赋核心。区别来自时机与场面待遇：

- 即演解决“现在必须发动”的战术窗口，不排队，也不接受公演专属魂援、PP、喝彩、
  完结条或 G5 诗篇适配；
- 公演让全桌处理同一场演出，可以取得明文登记的追演、支援、诗篇适配和覆盖层；
- SP1 的真实选择是“现在即演”或“保留并争取一次关注，到 SP2 报名公演”；
- 普通战术天赋的公演增量原则上不超过约 `0.5 SAE`；
- G3、G5 这类大型仪式可以规定完整效果仅公演；
- 达到 SP2 后可以一直保留，不会自动报名，也不会被 R0 强迫表态。

### 1.3 被动与自动转折

常驻被动不读取 SP，也不因别人正在公演而暂停。濒死免死、死亡复活、形态反转等自动转折
同样不由 SP 许可；SP 只负责玩家主动选择的演出时机。

因此：

- G4 未强化时仍可濒死燃尽，但不能主动按下燃尽；
- T7 可以主动决定何时、给谁埋下复活伏笔，真正死亡时自动兑现；
- T2、T6、G7 的被动身份不会被改造成冷却按钮。

### 1.4 专属资源预算

每个天赋最多保留：

1. 一个需要玩家决定如何消费的持久专属资源；
2. 一个自动故事进度或形态状态；
3. 一个演出根入口；
4. 必要的自动转折。

只控制“多久能再发动”的使用次数、充能和冷却应删除，由 SP 负责就绪；真正改变行动计划的
谱面、火种、追忆、魔力等保留。G7 宏 Cost 等局部预算不改写成 SP。

### 1.5 追演与完整额外行动

追演是当前根行动内部的一段限定步骤，不开启新 T0。完整额外行动重新执行完整
T0→T1→T2，因此只作为最高级规则豁免保留。

当前完整额外行动白名单：

- T4「或跃在渊」；
- T5 谱面 FC；
- G5「地火」之诗；
- G5「负世」之诗。

共同边界：同一玩家每全局轮至多一个、立即插入、不能递归、不刷新 SP/关注/公演上限、
不能公演；当前 SP≥1 时可在额外行动 T0 即演并消耗 1 SP。

### 1.6 落幕

一次性天赋永久兑现后进入落幕：玩家仍正常获得标准行动，但该天赋不再通过关注获取 SP，
也不再报名公演。落幕不是死亡或轮空。

## 二、原有十四天赋接入表

### 2.1 原初天赋

| 天赋 | 保留的独特状态 | 即演（1 SP） | 公演（2 SP）增量或专属结算 | 自动/最高级例外 |
|---|---|---|---|---|
| T1 一刀缭断 | 面对面、近战与单次乘算豁免 | 对合法面对面目标发动完整核心斩击 | 可接受魂援或游侠诗移动追演 | 无完整额外行动；删除使用次数 |
| T2 剪刀手 | 犯罪边界、击甲修复、零击杀隐身 | 对已发现或锁定目标发动合法攻击，不免费移动 | 可先追演移动到目标地点再攻击 | 犯罪/发现奖励改为关注；追猎反应整局一次 |
| T3 天星 | 同地点全体、完全穿防、石化 | 对同地点合法单位结算核心效果 | 接受魂援或群星诗适配，不复制第二次攻击 | 删除使用次数；石化 forfeit 不赠 SP |
| T4 六爻 | 猜拳与六种命运结果 | 选择目标并进行一次六爻 | 阴阳诗可指定五种非「或跃」结果，或保留随机 | 「或跃」授予一个完整额外行动 |
| T5 combo | 谱面、拍点、P/G/M、FC/Clear | 奖励关只把一个仍可能 Miss 的音符保底为 Good | 旋律诗处理其余未完成音符，不伪造 Perfect | FC 授予一个完整额外行动 |
| T6 朝阳好市民 | 案件、特别线索、远程举报与警察配装 | 为一名警察整备一件许可装备 | 同一配装核心 + 通用公演待遇，不追加警察行动 | 市民热线是不读 SP 的标准根行动；和平局不补偿虚构案件 |
| T7 死者苏生 | 唯一保险对象与一次性复活 | 公开选择唯一存活目标并挂载伏笔 | 可接受彼岸诗的目标层级适配 | 挂载双向登记关注；死亡自动兑现；兑现后落幕 |

补充边界：

- T1 即演必须保留干脆利落的完整核心，不能削成半次斩击；
- T2 公演是追猎镜头，不是重新获得整回合；
- T4 的完整额外行动来自稀有结果本身，不能被普通公演稳定复制；
- T5 FC 必须来自真实拍点，不得由诗篇或援助伪造；
- T6 无合法案件时仍可普通行动和取得关注，但举报通道自然变窄；
- T7 布置伏笔后不再反复挂载；兑现不占位、不读 SP。

### 2.2 神代天赋 G1–G7

| 天赋 | 保留的独特状态 | 即演（1 SP） | 公演（2 SP）增量或专属结算 | 自动/最高级例外 |
|---|---|---|---|---|
| G1 火萤 | 三段形态、失熵、炽愿、繁育 | 换装宣言；明文 T0 兼容，不消费标准行动槽 | 完全燃烧，开放受限追加动作与公演待遇 | 失熵/繁育自动推进；繁育绝对死亡 |
| G2 请一直注视着我 | 本体、公开全息影像与空间来源 | 转播一次白名单近战，或转场并留下影像 | 同一完整核心 + 通用支援，不恢复旧舞台 | 影像可摧毁、至多保留到下一行动 |
| G3 神话之外 | 魔力、投影、解析、固有结界 | 完整结界不开放即演；结界外投影仍走魔力+普通行动 | 仅公演展开隔离覆盖层；不额外收魔力入场费 | 不生成内部行动；魔力决定持续与投影强度 |
| G4 愿负世 | 火种、救世主、毁伤 | 未强化时无主动即演核心 | 救世主形态的焚诏拉条—反击—天裁 | 致命伤自动燃尽并置 SP=2，不赠行动 |
| G5 往世的涟漪 | 追忆、锚定、献诗、水晶花 | 每个完整周期可即演一次微澜 | 追忆达门槛后锚定或献诗 | 诗篇不得通用生成完整额外行动 |
| G6 要有笑声 | 公开行动模板 | 重演上一轮一个合法模板；首轮池空不可用 | 盗用天赋身份或召唤往世层援助 | 不复制责任与资源；不递归生成行动 |
| G7 星野 | 光环、形态、Cost、宏、Terror | 小准备：下个 R0 回复 Cost | Cost 回满并取得战术物品 + 公演待遇 | 宏本身不读 SP；Terror 后退出演出接口 |

补充边界：

- G1 换装是已登记的不耗槽 T0 宣言，但仍消费 1 SP；
- G2 即演与公演使用同一全息核心，区别只来自公演待遇；
- G3 结界保持低频仅公演定位；魔力不是第三道入场门槛；
- G4 自动转折置 2 不刷新关注上限，也不自动报名；
- G5 微澜消耗 1 SP；完整公演后才重开下一周期的一次微澜；
- G6 第一轮没有上一轮模板，不提供保底池；
- G7 的 3/4 Cost 是宏内部预算，与即演 1 / 公演 2 的 SP 层级无关。

### 2.3 新增 G0 接口

| 天赋 | 保留的独特状态 | 即演（1 SP） | 公演（2 SP） | 自动转折 |
|---|---|---|---|---|
| G0 砂狼白子*Terror | AR、无人机、遗物、调整呼吸 | 消耗当前 HP 部署无人机，占用标准行动槽 | 无人机在场时二选一：十字炮火 / 遗物支援技 | 调整呼吸濒死保护；未恢复则退场而非死亡 |

G0 无人机即演是核心部署而非额外行动；无人机不拥有独立行动槽，只随 G0 攻击协同。

## 三、G5 诗篇适配原则

献诗默认修改目标的**下一次公演**，不修改即演。这让玩家在“现在花 1 SP 使用核心”与
“保留到 SP2、排队等待强化正式演出”之间有真实选择。

| 目标 | 下一次公演的适配方向 |
|---|---|
| T1 游侠 | 可先追演移动到已锁定目标，再检查面对面并斩击 |
| T2 地火 | 追猎不要求预先发现；结算后的隐身仍按现行条件 |
| T3 群星 | 强化弹射或石化，只强化本次公演 |
| T4 阴阳 | 可指定五种非「或跃」结果；追求「或跃」只能保留随机 |
| T5 旋律 | 处理未完成音符，但不能制造 Perfect 或直接赠送 FC |
| T6 律法 | 服从新警务的阶梯结果，不新增警务行动 |
| T7 彼岸 | 扩展可挂载目标层级；死亡兑现仍自动发生 |
| G1 飞萤 | 强化失熵调息与形态循环，不增加演出次数 |
| G2 追光 | 强化全息攻击/影像延寿，不恢复旧舞台 |
| G3 永恒 | 适配魔力、投影通道、理想燃烧或幻想崩坏，不加困人轮数 |
| G4 负世 | 解锁人形主动燃尽；濒死自动燃尽仍保留 |
| G6 欢愉 | 模板窗口扩为最近两轮，仍只重演一个 |
| G7 守夜人 | 提高公演宏临时 Cost，仍限一个攻击载荷 |
| G5 爱与记忆 | 高追忆自我诗篇，占一次公演，不赠额外行动 |

完整额外行动采用正面白名单。未来任何诗篇新增来源都必须同步行动系统并验证递归边界。

## 四、轮内例子

### 4.1 SP1：现在即演还是继续蓄势

T1 开局 SP1，第一轮即可即演完整一刀并回到 SP0；也可以先普通 `find` 或攻击，T2 经
关注升到 SP2，在未来报名游侠诗强化公演。即演与公演的差异首先是**等待选择**，不是
把即演削成残缺核心。

### 4.2 SP2 即演后回到 SP1

玩家已报名公演但战术窗口突然出现，可以退出队列即演；即演消耗 1 SP，玩家回到 SP1。
它必须重新取得一次关注才能再次报名，不能保留原队列位置。

### 4.3 G4 濒死后仍由玩家决定

G4 自动燃尽并置 SP2，不立即取得行动。到下一个合法 T0，玩家可花 1 SP 使用合法即演、
保留 SP2 报名公演，或先做普通行动。

### 4.4 T5 FC 的最高档奖励

T5 取得 FC 后立即插入完整额外行动；它重新经过 T0，当前 SP≥1 时可以即演并消耗 1，
但不能公演，也不能递归获得第二个完整额外行动。

## 五、旧稿继承与失效

v0.2 仍可作为以下内容的历史参考：

- 四种演出形态与专属资源预算；
- 被动、伏笔和转折不读 SP 的边界；
- 即演不排队、公演提供正式场面待遇；
- 完整额外行动的白名单纪律。

下列 v0.2 结论不再具有候选权威：

- SP1 只能等待关注、不能即演；
- 即演必须 SP2，结算后统一归零；
- G5 微澜必须消耗完整 2 SP；
- 以该旧频率口径得到的 P95、发动次数与等待结论。

## 六、重新验证要求

进入实现前至少重新验证：

1. 开局 SP1 的第一轮即演数量；
2. SP1 即演与保留到 SP2 报名公演的选择比例；
3. 每轮即演总数与“一个公演 + 多个即演”的 P95；
4. T1/T3/G1 在连续每轮取得关注时的终结速度；
5. T4/T5 完整额外行动内即演的组合；
6. G0 无人机、G6 重演、G7 小准备等 1 SP 即演的循环频率；
7. G3/G5 公演等待与临时退出改即演的比例；
8. 二十八魂援效果在 HP20 量纲下的横向强度。

在分层 SP 模型、天赋场景卷和运行时风洞完成前，本稿是接口候选，不是数值定稿。
