## 一、结论

新 G2 不再把所有玩家拖入一场副游戏。它的规则命题是：

> **G2 可以公开地同时拥有本体与一个全息行动来源，但仍然只有一个玩家、一个行动。**

G2 在一次演出中部署全息影像，并在“从影像发动一次近战投射”与“让本体转场到影像位置”
之间二选一。影像随后保留到 G2 的下一个行动槽，供一次返场攻击或收束移动使用；其他玩家
可以在此之前将影像摧毁。影像是可摧毁的公开场景物，**不是第二套全桌舞台**，旧全桌舞台
继续冻结。

这项能力操作的是行动的**空间来源**，不是行动数量：

- 不创造额外行动；
- 不生成第二个玩家或召唤物；
- 不改变全桌胜负条件、阵营和普通行动菜单；
- 不使用拉取、震荡、压制、沉沦或地点易伤；
- 不使用歌曲、声部、Regard、物料牌或专用舞台轮次。

## 二、设计身份

旧群控 G2 与现行舞台 G2 共同保留的真正意象是“全息影像劫持注意力”。新设计把这种
劫持从强制控制改成公开的威胁分配：

- 玩家知道哪里是本体、哪里是影像，并自行决定攻击本体、拆除影像、移动离开或承担返场；
- NPC 只会在本来就能合法攻击 G2 时误认影像，不会被全体停机；
- G2 用影像把自己拥有的近战威胁投射进另一个地点，或者提前布置一条转场路线；
- 影像活得越久，G2 的空间选择越多，但不会因此取得第二个行动。

因此，新 G2 的竞争轴是**多重在场与行动来源**，不是坦克、快攻、阵地法师或全桌主持人。

## 三、名词

| 名词 | 规则身份 |
|---|---|
| 本体 | G2 玩家本人；持有生命、装备、状态、位置和全部规则责任 |
| 全息影像 | 来源绑定的公开场景物；没有玩家身份、行动槽和生命值 |
| 转播 | 本体不移动，从影像所在地发动一次全息攻击 |
| 转场 | 本体移动到预定影像位置，原本体位置留下持续影像 |
| 返场 | 在后续行动中再次从尚存影像发动全息攻击 |
| 收束 | 在后续行动中将本体移动到尚存影像的位置并令影像落幕 |
| 进入轮 | 影像创建时所属的全局轮次（影像的出生轮） |
| 实际 ActionGrant | 一个被真正派发并结算至系统收尾的 `ActionGrant`；包括被压制、唤醒、保持石化或 `aid_rest` 消费的槽位；只有派发前失效或未建立的候选授予不算 |
| 完整镜头 | 同一影像在创建行动与 G2 的下一个实际 ActionGrant 中被实际使用，且至少一次全息攻击
  造成伤害的 B4 调用事件 |

规则界面始终公开显示本体位置、影像位置、影像来源与最迟落幕时点。影像不制造真假位置
猜谜，也不修改本作“位置与状态高信息公开”的基础合同。

## 四、发动入口

### 4.1 共同入口

G2 在自己的合法 T0 拥有 `SP≥1` 时可以即演；拥有 `SP=2` 且已经取得本轮公演位时
可以公演：

1. 选择一个普通行动层中的合法地点；
2. 选择“转播”或“转场”；
3. 本次演出占用当前行动槽；
4. 演出完成后按公共分层合同消费 SP：即演 −1，公演 −2；
5. 若场上已有该 G2 的旧影像，先令旧影像落幕，再创建新影像。

即演与公演使用同一个完整核心。公演只额外打开通用魂援、诗篇、PP、喝彩或完结条调用点，
不恢复旧全桌舞台，也不额外赠送一次攻击或移动。

### 4.2 转播

G2 选择影像地点和该地点内的一名合法战斗目标：

1. 在目标地点创建影像；
2. 从影像位置发动一次全息攻击；
3. 本体保持原位置；
4. 攻击结算后，影像继续留在该地点。

若所选地点当前没有合法目标，G2 可以只部署影像而不攻击，但界面必须明确提示本次放弃了
开场攻击。合法性检查前取消选择不消耗 SP；确认部署后即使没有造成伤害也正常消耗演出。

### 4.3 转场

G2 选择一个自己当前能够合法进入的地点：

1. 在目标地点建立瞬时落点影像；
2. 本体移动到该地点；
3. 在本体原位置留下持续影像；
4. 本次不发动全息攻击。

转场是主动特殊位移：

- 计为本轮已经移动，正常参与移动闪避和位置事件；
- 不触发借机攻击，性质接近钩索的自我位移；
- 进入住宅、封闭地点或其他受限位置时，仍按 G2 本人的移动合法性和犯罪责任结算；
- 不允许在同一次行动中转场后再攻击、交互、即演或公演。

## 五、持续影像与下一行动

影像从创建后持续到以下最早事件：

1. 被合法攻击摧毁；
2. G2 死亡、离开普通行动层或失去玩家身份；
3. G2 创建新影像；
4. G2 创建影像后的**下一个实际 ActionGrant**完成系统收尾。

第 4 项的初始自然落幕计数为 1；只有下述“追光延寿例外”可以把它增加为 2。

第 4 项不区分标准行动与完整额外行动。影像不能利用额外行动、控制或队列改动延长寿命。
“实际 ActionGrant”只要求槽位被派发并进入系统收尾，不要求执行根行动：压制、唤醒、
保持石化与 `aid_rest` 都消耗影像寿命；派发前失效或预检失败而未建立的候选授予不消耗。

若影像仍存在，G2 在该下一个行动槽中可以选择：

- **返场**：从影像位置发动一次全息攻击；
- **收束**：消耗本槽，将本体移动到影像位置；该移动不触发借机攻击；
- **本体行动**：从本体执行任意合法普通行动，不使用影像。

三种选择都只使用当前这一个行动槽。默认情况下该槽完成系统收尾后影像落幕；只有下述
追光延寿例外可以把同一影像继续保留，且不会在本体旧位置生成第二个影像。

**追光延寿例外**：若「追光的聚焦」在一次全息攻击中被消费，且该攻击结算后同一
`hologram_id` 仍存在，则该影像的自然落幕计数 `remaining_owner_grants += 1`。影像仍没有
HP，也不抵抗攻击摧毁、新影像替换或来源离场；延后的最后一个槽完成系统收尾后必定落幕。

控制先于影像选项裁决：

- 压制直接消费该槽，随后影像落幕；
- 震荡菜单不开放返场或收束；
- 起床、自我怀疑、保持石化等替代该槽后，影像在公共收尾中落幕；
- 影像不替 G2 承担控制，也不让 G2 绕过演出合法性。

## 六、全息攻击

### 6.1 冻结的全息武器白名单（精确 ID）

全息攻击只能使用带 `hologram_eligible` 正面标签的武器。该标签按**精确武器 ID** 冻结，
不由属性类别自动推导：

| 精确武器 ID | 规则身份 | 说明 |
|---|---|---|
| `punch` | 白名单 | 拳击，普通近战 |
| `knife` | 白名单 | 小刀；**含 `sharpened` 磨刀状态**（磨刀小刀），伤害与使用按磨刀小刀的
  正常公共规则结算 |
| `baton` | 白名单 | 警棍 |
| `magic_barrage` | 白名单 | 魔法弹幕（近战形态） |

以下类别即使碰巧是近战或单体，也**不得**取得 `hologram_eligible`：

- `WeaponRange.RANGED`（远程，如远程魔法弹幕、导弹）；
- `WeaponRange.AREA`（范围，如地震、地动山摇、电磁步枪）；
- `requires_charge=true`（蓄力武器，如高斯步枪、电磁步枪）；
- 弓（`bow` 及弓模块组合）、钩索模式（`hook`）、导弹（`missile`）、荷鲁斯之眼（Horus）；
- 任何天赋攻击、装备特殊操作或场景行动；
- 任何通过旧名称碰巧被归为近战、但未取得 `hologram_eligible` 正面标签的新武器。

白名单不再开放“新武器按类别自动纳入”。新增可投射武器必须逐件登记精确 ID 并取得标签，
否则不能用于全息攻击。本冻结覆盖 v0.1 的“候选包括……”措辞，最终成员不再待风洞。

### 6.2 攻击合同

全息攻击：

- 选择 G2 实际持有、未禁用且当前可用的一件白名单武器；拳击仍按公共规则可用；
- 目标必须与影像处于同一地点，并通过 G2 本人的可见性、隐身和探测检查；
- 为本次攻击临时豁免 `find / ENGAGED_WITH` 近战前置；
- 不建立持续面对面或交战关系；
- 使用正常武器伤害，`skill_core_multiplier=1`，不附加固定增伤或易伤；
- 使用 G2 本人的攻击增益、虚弱、装备状态和费用；
- 目标正常使用护甲、属性防御、闪避、免疫、反击与死亡规则；
- 空间上视为同地点攻击，因此绕过只阻挡远程直接攻击的 `COVERED`；
- 不因目标随后移动而产生来自影像的借机攻击。

若目标因隐身、特殊封闭、普通层离场或其他规则不能被 G2 合法选择，影像不能自行提供探测
或跨层权限。

## 七、行动者与空间来源

全息攻击必须显式区分：

```text
actor_id       = G2
spatial_origin = hologram.location
```

`spatial_origin` 只参与：

- 目标地点与同地点合法性；
- 近战投射的临时前置豁免；
- 掩体是否属于远程阻挡；
- 作用地点与场景展示。

其他责任全部属于 `actor_id`：

- 武器、费用、增益、虚弱和探测；
- 犯罪、案件、匿名归因与威信；
- 伤害、击杀、评分和关注；
- “针对攻击者”的反击、反射、标记与自动转折。

因此：

- 全息攻击永远公开归因于 G2，不能成为匿名冷箭；
- 攻击 G4 救世主时，反击对象仍是 G2 本体；
- 普通反伤沿信号回传至 G2，不由影像免除；
- 目标地点的普通 AOE 不会把 G2 本体视为在那里；
- 影像不让 G2 获得当地警察掩体、地点交互、友方光环或单位人数身份。

实现不得通过临时修改 `player.location` 后再恢复来伪造空间来源；这会污染犯罪、AOE、警务、
日志与并发反应。应在行动信封中显式携带来源。

## 八、影像作为场景物的对象合同

### 8.1 对象身份与生命周期

影像不是 Player、NPC、Chorus、警察或召唤单位：

- 没有行动槽、HP、护甲、装备、控制位和天赋；
- 不接受治疗、复活、诗篇、掩体或正负状态；
- 不执行地点交互、警察指令或自动行动；
- 不计入地点单位数量、击杀数和普通 AOE 目标数；
- 不阻挡移动、交互或其他影像；
- 永远公开可见，不继承 G2 的隐身、闪避和掩体。

每创建一次影像产生一个**唯一的影像对象**（`hologram_id`），携带来源 `actor_id=G2`、
创建地点与创建行动的事件句柄。该对象在 §五 的最早事件发生时终结；终结必须写入事件日志，
日志至少记录创建与终结两个事件及终结原因（摧毁 / 来源死亡 / 新影像替换 / 自然落幕）。

生命周期按**事件驱动**而非轮刻线驱动：

- **进入轮刻线**：影像的进入轮是创建它的 G2 行动所属的全局轮次；R4 边界不会让影像自动
  落幕，也不让它进入“过期”状态；
- 影像寿命只由创建、G2 的下一个实际 ActionGrant 和 §五 清单驱动；
- 涉及“本轮 / 上一轮”的轮次判定（模板窗口、案件推进等）以进入轮为影像的出生轮。

### 8.2 目标性

玩家可以把影像作为 `attack_object` 的公开目标：

- 同地点攻击不要求 `find`；
- 跨地点攻击必须使用本来就能跨地点攻击该位置的手段；
- 攻击正常消耗弹药、蓄力或其他使用成本；
- 影像不建立自身生命值：攻击对它结算为一次性命中判定，见 8.3。

### 8.3 摧毁

只要攻击方得到 `A>0`，包括随后形成擦伤，影像立即消失：

- `A=0`、纯控制、DOT、环境计时和非伤害状态不能摧毁影像；
- 明文覆盖场景物的敌对地点 AOE 也可摧毁影像。

摧毁影像：

- 不向 G2 传递普通伤害；
- 不消耗 G2 护甲、掩体或死亡豁免；
- 不施加震荡、灼烧等命中负载；
- 不产生伤害分、击杀分或普通武器命中玩家的钩子；
- 本身不构成袭击玩家或违法，除非未来场景规则明文另定。

影像不是替 G2 承接攻击的盾牌。玩家始终可以无视影像，按普通规则直接攻击公开位置上的
G2 本体。

### 8.4 关注归属

影像不建立自己的关注身份。所有涉及影像的关注钩子按 `actor_id=G2` 归属：

- 由全息攻击产生的犯罪、击杀、发现、评分与威信变化归 G2；
- 把影像选为根行动目标本身不把关注登记到任何玩家的 SP 上，也不对 G2 造成伤害或状态；
- G2 不因影像的创建、被摧毁或自然落幕获得本 RFC 自设的 SP 奖励；演出自身反应栈内摧毁
  影像时不得让本次演出即时返还 SP。

## 九、NPC 与警察

新 G2 不再让 NPC 进入 `SUBMERGED`。影像只提供一次合法目标替换：

1. NPC 按自身案件、阵营、仇恨和权限判断 G2 是否是合法敌对目标；
2. 只有判断已经成立，且影像位于该 NPC 可以攻击的位置时，NPC 才能把影像当作 G2；
3. 第一个形成 `A>0` 的 NPC 攻击摧毁影像；
4. 后续 NPC 继续按普通规则行动。

警察额外遵守：

- 没有针对 G2 的合法案件或通缉时，影像不能诱使警察违法攻击；
- 影像不建立案件、不伪造证据、不改变 G2 的真实位置；
- 被通缉的 G2 可以用同地点影像吸收一名警察的一次执法攻击；
- 攻击警察的全息攻击仍归因于 G2，并正常建立犯罪和案件；
- 影像不提供警察掩体，也不改变固定警力、队长指挥或 R4 自动攻击额度。

这保留了老 G2 的反警察血统，但把“整群沉沦”收紧为最多一次可预见的 NPC 行动偏转。

## 十、评分与公演调用点

全息攻击造成的有效伤害、破甲和击杀全部归 G2。影像被摧毁本身不提供战果分。

### 10.1 B4 事件候选 `g2_complete_shot`（完整镜头）

本 RFC 登记一个不带数值的 B4 事件候选 `g2_complete_shot`，语义冻结为：

1. **同一影像对象**在创建行动与 **G2 的下一个实际 ActionGrant** 中都被实际使用；
   “实际 ActionGrant”＝真正派发并结算至系统收尾的 ActionGrant；控制消费的槽位会令
   影像落幕，但因没有实际使用影像，不满足本条的“第二次使用”；未派发的授予不计入；
2. 两次使用中至少一次是全息攻击，且该攻击对合法敌对单位造成 `H>0`；
3. 影像不是因被摧毁、G2 死亡或控制消费而结束（§五 第 1/2 项与压制/震荡替代）；
4. 第二次使用可以是返场攻击或收束；
5. **纯部署＋收束不产生事件**：若两次使用中没有任何全息攻击造成 `H>0`（例如转场部署后
   仅收束移动），不登记完整镜头。
6. 追光延寿只延长对象寿命，不扩展完整镜头窗口；若创建后的第一个实际 ActionGrant 没有
   使用影像，则第二个延寿槽即使使用也不登记 `g2_complete_shot`，同一影像至多登记一次。

创建行动中的“使用”可以是转播（部署＋全息攻击）或转场（部署＋本体移动）；只要两次使用
合计满足第 2 项，事件即可成立。事件成立时，B4 按 v0.4 接口登记：即演/公演共享同一完整
核心，公演只额外打开通用支援调用点，不恢复旧舞台。

该事件未来可以供剧情分、PP、喝彩或完结条使用，但本 RFC 不决定分值、次数和反合谋规则。
旧“完成一次完整谢幕”不进入 M9 新 G2。

## 十一、旧 G2 的冻结与退役映射

`v2exp` 当前舞台规则与实现继续作为现行 profile 和历史证据保存；M9 不从其中逐项删减，
而是整体冻结。以下机制不迁入新 G2：

| 旧机制 | M9 处理 |
|---|---|
| 全场或概率拉取 | 退役；玩家位置不被演出强制改变 |
| 眩晕、震荡、沉沦 | 退役；影像只偏转一次合法 NPC 目标 |
| 地点全体易伤 | 退役；不建立区域伤害光环 |
| 五地点座位、全员舞台轮 | 退役；新 G2 始终留在普通行动层 |
| Acc / Ind / Str 声部 | 冻结在旧舞台模式 |
| Regard、稳定值、旋律 | 冻结在旧舞台模式 |
| 物料牌、Chorus、聚光灯、合影 | 冻结在旧舞台模式 |
| 八轮谢幕与阵营结局 | 冻结在旧舞台模式 |
| G2×G5 duet | 不迁移；待 G5 自身成立后另行设计轻量联动 |
| G2 完整谢幕完结条 | 退出 M9；B4 只接收“完整镜头”调用点 |

旧舞台以后若继续开发，应被登记为独立可选模式或终局场景，不能再次作为标准十四天赋的
必继承组件。

## 十二、纸面推演结论

### 12.1 二人局

G2 转播命中对手后，对手至少有四个理性选择：

- 攻击 G2 本体，交换伤害但容许影像返场；
- 花一个攻击摧毁影像，关闭返场；
- 移动离开影像地点，使返场失去原目标；
- 继续交互或承担第二次近战投射。

没有选项剥夺对手行动。G2 又已经取得一次正常强度的开场攻击，不会因对手立即拆影像而
把 2 SP 与整个行动白白浪费。

### 12.2 多人局

影像只影响其所在地和被威胁者。第三方可以拆除、利用 G2 与目标互耗或完全不参与，不需要
进入特殊菜单、阵营和轮次。G2 把影像投进多人地点时也更容易被第三方顺手清除，因此收益
不会随玩家数量无上限增长。

### 12.3 极端装备

允许所有武器时，范围武器会变成跨地图 AOE，高斯步枪会把蓄力处决安全投射到任意地点，
使装备分类和弓的远程层级失去意义。因此 v0.2 冻结 `hologram_eligible` 精确 ID 白名单
（§6.1）；若强度不足，先验证持续窗口、掩体交互和白名单，不通过另加伤害倍率补救。

### 12.4 转场

转场若仍触发借机攻击，只会成为带 SP 门槛的普通移动；若立刻转场并同时攻击，又会接近
额外行动。当前候选保留“占整槽、无攻击、免借机、留下可拆影像”的中间解。

## 十三、待风洞与实现边界

白名单成员与完整镜头事件语义已冻结，不再进入风洞。进入实现前至少统计：

1. 二人局与六人局中，影像被拆、被绕开、成功返场和用于收束的比例；
2. 每次演出的平均有效伤害，以及磨刀小刀、魔法弹幕等白名单武器的选择率；
3. 绕过掩体后对 T6、普通警察保护和 G7 防御姿态的实际影响；
4. 转场免借机带来的存活率、连续逃生率和钩索替代率；
5. 影像吸收警察攻击的次数与案件完成时间；
6. `g2_complete_shot` 的自然达成率与反合谋风险；
7. 即演、公演、普通返场与完整额外行动组合是否出现双重结算。

实现必须：

- 把影像建模为来源绑定的场景物（唯一 `hologram_id`），而不是 Player 或 NPC；
- 在攻击信封中显式携带 `actor_id` 与 `spatial_origin`；
- 以精确武器 ID 白名单驱动 `hologram_eligible`，不从 `WeaponRange.MELEE` 自动推导；
- 让影像创建、摧毁和自然落幕都进入事件日志，并携带终结原因；
- 让控制消费的下一行动仍执行公共收尾并清除影像；
- 按“下一个实际 ActionGrant”而非名义上的下一行动计数完整镜头与影像寿命；
- 不修改 `v2exp` 行为，直到 M9 profile、合同测试和风洞结果另行批准。

本 RFC 冻结的是机制身份、接口和白名单成员；不冻结评分数值、PP、魂援或 G5 诗篇
增强。后四项分别进入 B4/B5 或 G5 专项，不能反向恢复旧舞台。
