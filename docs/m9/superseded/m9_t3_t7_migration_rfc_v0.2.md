## 一、T3 天星（B2-D02）

### 1.1 核心改动

**删除**：
- 次数限制（旧版 K 次或轮次充能）
- "无视属性克制 + 防御 ×50%" 的重复卖点

**保留**：
- 地点 AOE 攻击
- 石化控制效果
- 对友军也造成伤害（需要精准投放）

**新增**：
- SP 演出入口（2 SP 公演）
- 统一石化机制与 M9 控制系统适配

---

### 1.2 完整定义

```
T3：天星

入口：
- 2 SP 公演，占用标准行动槽
- 删除次数限制，只要 SP=2 就可以使用

效果：
① 选择一个地点（普通行动层）
② 对该地点所有单位造成 ⟦bal:m9_talents_extended.t3.starfall_damage⟧ 点伤害
   - 伤害无属性
   - defense_coefficient = 0（完全无视属性防御）
   - 仍受 flat_damage_reduction 影响（如火萤减伤、G4 余烬护甲）
   - 正常经过 25% 下限计算
   - 注意：这不是 `DIRECT_DAMAGE`（结算合同 RFC v0.2 §6.6 只登记 G0 十字炮火、
     G7 Terror 攻击、G4 死星天裁）；天星仍走普通两阶段流水线，只是穿防为 0
③ 命中的单位获得「石化」状态

石化（petrified）：
- 持续时间：⟦bal:m9_talents_extended.t3.petrify_duration⟧ 轮（暂定 2-3 轮，待风洞）
- 石化单位每轮行动时，在 T0 选择：
  
  a) forfeit（放弃行动）
     - 保持石化状态
     - 不获得 SP（2026-08-08 B5-D03 裁决：删除旧稿"SP +1"，v0.5 冻结
       "普通 SP 只由关注推进"；石化者被攻击时仍经焦点身份正常获 SP）
     - 消耗行动槽
  
  b) 尝试挣脱
     - 消耗 1 SP
     - 掷骰判定（50% 概率）：
       * 成功：解除石化，返还本回合行动槽（可以继续行动）
       * 失败：石化继续，行动槽消耗
     - 每轮最多尝试 2 次（若第一次失败且 SP ≥ 1，可再试一次）
  
  c) 被动解除
     - 受到第一次有效伤害：石化不解除，获得"摇晃"标记
     - 受到第二次有效伤害：石化自动解除

特殊交互：
- G5「群星」诗可将石化升级为「尘世之锁」：
  - 不因被其他单位攻击而解除（删除被动解除机制）
  - 只能通过 forfeit 持续到时间结束，或尝试挣脱解除
  - 挣脱判定保持 50% 概率
```

---

### 1.3 设计说明

**伤害属性的选择**：
- 旧版同时写有"无视属性克制"和"防御 ×50%"
- 在 M9 两阶段伤害系统中，这是两个不同的东西：
  - 无视属性克制 = `defense_coefficient = 0`
  - 防御 ×50% = `defense_coefficient = 0.5`（类似 T1）
- 两者不能叠写（真伤不需要穿甲系数）
- 选择 `defense_coefficient = 0` 是因为：
  ① 符合"天星"主题（陨石从天而降，无差别攻击）
  ② 完全无视属性防御，但仍受减伤影响（不过分）
  ③ 与 T1 区分（T1 是有属性 + 穿一半，T3 是无属性 + 完全穿）

**石化机制的改动**：
- 旧版：被攻击后自动解除
- M9 版：需要 2 次有效伤害才解除（鼓励集火）
- 新增"尝试挣脱"机制：消耗 SP + 50% 判定，给被石化者主动权
- forfeit 仍获得 SP，避免石化变成"永久控制"
- 挣脱成功返还行动槽，奖励主动尝试的玩家

---

### 1.4 与其他系统的接口

| 系统 | 接口点 |
|---|---|
| 行动系统 | 2 SP 公演占用标准行动槽 |
| 伤害系统 | 无属性，defense_coefficient = 0；不是 `DIRECT_DAMAGE` |
| 控制系统 | 石化是受限状态，不是压制 |
| G5 诗篇 | 「群星」诗升级石化为「尘世之锁」 |
| PP/评分 | 公演打开调用点；AOE 击杀计入评分 |

|---|---|---:|
| 天星基础伤害 | — | 需风洞，考虑 AOE + 石化 |

## 二、T7 死者苏生（B2-D04）

### 2.1 核心改动

**删除**：
- 在魔法所连续学习两次的前置条件（3 槽消耗）
- 学习进度、学会状态等中间状态

**保留**：
- 挂载伏笔 + 死亡兑现的核心机制
- 复活位置（自己家）、复活 HP、保留物品
- 保险在 T7 死亡后继续存在

**新增**：
- SP 演出入口（即演/公演）
- 与 G5「彼岸」诗的明确交互

---

### 2.2 完整定义

```
T7：死者苏生

入口：
- 即演（1 SP）或公演（2 SP），占用标准行动槽
- 不需要在魔法所，不需要地点限制
- 不需要学习前置

效果：
① 选择一名存活玩家（含自己）
② 在该目标身上挂载「保险伏笔」
   - 唯一标记：同一目标只能有一个伏笔（新伏笔覆盖旧伏笔）
   - 全局公开可见（目标头上显示"已挂载 T7 复活"）
   - 不消耗，不能被驱散
   - 按普通关注合同双向登记：目标作为焦点先登记，T7 作为发起者后登记；仍受每人
     每轮最多 `+1 SP` 的共同上限约束（2026-08-08 B5-V2 裁决）
③ 挂载后 T7 当前不再取得第二个演出入口（即演后仍只能挂载一个目标）

保险伏笔兑现（被动触发）：
当挂载目标死亡时：

① 优先级判定：
   - 目标自己的免死效果（光环、其他天赋） > 
   - 绝对死亡白名单（G5 锚定绝对实现、G4 死星天裁、G7 Terror、G1 繁育倒计时死亡） > 
   - 保险复活

② 若触发复活：
   - 目标在自己家中（安全屋）复活
   - 复活 HP = ⟦bal:m9_talents_extended.t7.revive_hp⟧（暂定 12，待风洞）
   - 保留全部物品（武器、护甲、道具）
   - 立刻处于清醒状态（可以在下轮行动）
   - 恢复已破碎且可再生的护盾：
     * 魔法护盾：恢复到初始值
     * AT 力场：恢复到初始值
     * 不恢复：铁之荷鲁斯、一次性护甲
   - 清理死亡关系：
     * 击杀者不获得击杀计数
     * 犯罪记录不成立
     * PP/评分系统视为"未死亡"

③ 兑现后天赋落幕：
   - 伏笔标记消耗
   - T7 需要重新挂载新伏笔（若 SP 足够）

特殊规则：
- 保险在 T7 持有者死亡后继续存在（伏笔已挂载，独立于 T7 生死）
- 绝对死亡白名单跳过复活：G5 锚定绝对实现、G4 死星天裁、G7 Terror、
  **G1 繁育倒计时归零死亡**（2026-08-09 B5 W7 同步，见
  [G1 火萤 RFC v0.2](m9_g1_firefly_burn_cycle_rfc_v0.2.md) §五.3）
- **`DIRECT_DAMAGE` 不是自动绝对死亡**（2026-08-09 B5 W9 澄清）：
  G0 十字炮火是 `DIRECT_DAMAGE` 但不带 `absolute_death`，仍可被保险复活承接；
  G7 Terror 攻击与 G4 死星天裁因携带 `absolute_death` 标签才跳过复活。因此
  "是否跳过复活"由来源的 `absolute_death` 标签决定，不由 `DIRECT_DAMAGE` 身份推导。
- **home 被毁时的复活回退**（2026-08-09 B5 W8 同步）：若目标家中已被摧毁，
  复活改为"效果结算时的当前位置"就地完成；当前位置也不可站立时，使用 G1 v0.2
  的最后安全地点兜底（见 [G1 火萤 RFC v0.2](m9_g1_firefly_burn_cycle_rfc_v0.2.md) §五.4）
- 若目标始终未死亡，伏笔持续到游戏结束
- 不批量净化 buff/debuff（只恢复护盾，不移除石化/震荡等）
```

### 2.3 与 G5「彼岸」诗的交互

G5「彼岸」诗强化 T7 的复活效果：

```
献予「彼岸」之诗（已定稿）
- 消耗：12 追忆，占标准行动
- 目标：持有 T7 的玩家
- 效果：目标获得「彼岸的守望」标记；当目标因死者苏生复活时：
  ① 复活后 SP 立即置为 2（而非通常的 0）
  ② 复活前可选择携带一件指定的常规装备（武器/护甲）
  使用后标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

**交互逻辑**：
- 「彼岸的守望」标记独立于「保险伏笔」
- 复活触发时，两者效果叠加：
  - 基础复活（T7）：家中复活 + HP=12 + 保留物品 + 恢复护盾
  - 诗篇强化（G5）：SP=2 + 携带指定装备
- 诗篇标记消耗，伏笔标记也消耗

**自动就绪白名单（2026-08-09 B5 W12 同步）**：
- 彼岸诗复活把 SP 置为 2，属于行动系统明文登记的**自动就绪白名单**来源——不是关注、
  不额外排入公演队列、也不刷新本轮关注上限；
- 该来源必须在 [行动系统 RFC v0.7（预期）](m9_action_system_rfc_v0.7.md) 的自动就绪
  白名单中登记（与 G4 濒死燃尽并列），不能靠本迁移合同的草稿单方生效。

### 2.4 设计说明

**删除学习前置的理由**：
- 旧版需要 3 个行动槽（2 次学习 + 1 次挂载）= 至少 3 轮准备
- M9 全员行动后，节奏加快，3 轮准备过慢
- 学习地点限制（魔法所）与 M9 的开放行动哲学冲突
- 简化为"演出直接挂载"，保持天赋核心（复活）同时提升可用性

**保险在 T7 死亡后继续存在**：
- 符合"伏笔"主题：已埋下的伏笔不因 T7 死亡而消失
- 提供战术深度：T7 可以"牺牲自己保护队友"
- 平衡性：T7 死亡后无法挂载新伏笔，只有已挂载的生效

**复活位置固定为家中**：
- 旧版保留此设计
- 防止复活变成"战场急救"（那是其他天赋的职责）
- 复活后需要重新回到战场，给对手反应时间
- home 被毁时的回退兜底见 §2.2 特殊规则（W8 同步）

### 2.5 与其他系统的接口

| 系统 | 接口点 |
|---|---|
| 行动系统 | 即演 1 SP 或公演 2 SP，占用标准行动槽 |
| 死亡系统 | 在死亡检查时触发，优先级低于免死、高于常规死亡 |
| 绝对死亡白名单 | G5 锚定绝对实现、G4 死星天裁、G7 Terror、G1 繁育倒计时死亡跳过复活 |
| 结算合同 | `DIRECT_DAMAGE` 不是自动绝对死亡；是否跳过复活看 `absolute_death` 标签（结算合同 RFC v0.2 §6.6） |

| PP/评分 | 复活清除击杀关系，不计入击杀者的评分 |
| 犯罪系统 | 复活清除犯罪记录 |
