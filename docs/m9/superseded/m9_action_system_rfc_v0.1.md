# M9 全员先攻与舞台位阶行动制 RFC v0.1

> **历史版本 / 请勿用于当前设计。** 本稿的 R0 自动升级 SP 已被纸面推演否决；当前 M9
> 行动候选是 [`m9_action_system_rfc_v0.8.md`](../current/m9_action_system_rfc_v0.8.md)。推荐从
> [`m9/README.md`](../README.md) 进入，本文只保留为设计演化证据。

> **日期**：2026-08-05  
> **状态**：已取代的历史提案，不定义 `m9-rfc` 当前候选或 `v2exp` 现行规则  
> **Profile**：`m9-rfc`  
> **替代目标**：若通过，替代 V2.0EXP 的 K 常量行动配额；不替代 R0–R4 / T0–T2 时序  
> **相关文档**：`../drafts/m9_unified_currency_design.md`、`../../design/v2exp/v2.0_exp_design_draft_v0.2.md`  

本文提出一套新的底层行动机制：**所有存活玩家每轮都获得一个标准行动回合，先攻只决定顺序；SP 不再作为第三种货币，而改为公开的三段舞台位阶，用于控制高光行动的节奏。**

它要解决的首要问题不是行动数值，而是行动资格：正常先攻落后不再剥夺玩家整轮决策权。

---

## 一、设计结论

### 1.1 核心规则

1. 废除 `K = 存活人数 − 1` 的行动配额。
2. 每轮所有存活玩家各获得 **1 个标准行动回合**。
3. 所有人照常进行先攻判定；先攻只决定 R3 的行动顺序。
4. 普通的先攻垫底不再产生“轮空”或“未获得行动权”。
5. SP 改为 **群演 / 配角 / 主角**三段公开位阶，不是可交易、可计分或按价目支付的货币。
6. 三个位阶都能执行完整的标准行动；只有“聚光行动”要求主角位阶。
7. 使用聚光行动后退回群演位阶；正常参与对抗和轮次推进会使位阶重新上升。

### 1.2 一句话定位

```text
先攻回答“谁先做”；标准行动回答“这一轮我做什么”；
SP 回答“我是否要在这一轮打出自己的高光”。
```

### 1.3 非目标

本 RFC 暂不决定：

- 14 个天赋各自的聚光行动效果；
- PP、投注与魂援的完整市场规则；
- 具体平衡数值和 `balance.json` 键；
- 代码实现、AI 策略或 RL 状态空间；
- G6 笑点的新完整经济。

这些问题必须建立在底层行动合同稳定之后处理。

## 二、为什么替代 K，而不是与 K 叠加

现行 V2.0EXP 使用 K 常量顺序行动制：全员判定先攻，排名前 K 者行动，默认每轮稳定有一名玩家轮空。它大幅缓解了旧版“先攻胜者行动、其他人全部等待”的问题，但仍把一次随机排序转换为完整的行动剥夺。

如果在 K 制上再叠加 M9 原稿中的 SP 门槛，玩家会依次面对两层许可：

1. 本轮是否取得行动资格；
2. 取得资格后，SP 是否允许战斗或使用天赋。

这会把硬轮空变成“硬轮空 + 软轮空”。本 RFC 因而要求：**SP 只有在废除常规轮空后才进入底层行动系统。**

全员行动并不是全新的时序。G2 舞台已经采用“所有参与者按先攻排序、全部行动”的局部规则；本 RFC 将这一原则推广到普通对局，同时保留现有顺序结算框架。

## 三、新的全局轮次

```text
R0  轮次开始结算；存活玩家的 SP 位阶自然推进一级
R1  全员先攻判定；产生完整行动顺序，不裁掉任何正常存活玩家
R2  警察状态机推进
R3  所有存活玩家按先攻顺序各执行一个标准行动回合
    额外行动仍按既有规则插入队列
R4  轮末结算；检查胜负、持续效果和世界时钟
```

### 3.1 先攻判定

- 先攻仍使用当前 V2.0EXP 的骰面、修正和同点决胜流程。
- 先攻结果完整公开。
- PP 重掷先攻等效果若保留，只影响顺序，不影响行动资格。
- 先攻高者仍能先抢限量物品、先改变位置、先造成伤害或在目标行动前完成击杀。
- 先攻低者只要在轮到自己时仍存活且未受控制，就一定能行动。

### 3.2 标准行动槽

R1 结束后，行动队列装入所有正常存活玩家，而不是只装入前 K 名：

```text
标准行动队列 = 所有正常存活玩家，按先攻总值降序排列
```

以下情况仍可使玩家没有执行标准行动，但它们必须来自明确的游戏事件，而不是普通先攻落后：

- 在轮到自己前死亡或离开普通行动层；
- 受到眩晕、石化等明确的行动剥夺效果；
- 天赋在 T0 消耗本回合；
- 玩家主动放弃行动；
- 特殊模式以明文规则替代普通行动。

这些事件应继续受控制抗性、免疫或各自限制约束。

## 四、标准行动与聚光行动

### 4.1 标准行动始终可用

只要玩家拥有正常行动回合，下列现有行动不会因 SP 位阶不足而被封锁：

- 起床；
- 移动；
- 交互；
- 锁定；
- 找到；
- 普通攻击与射箭；
- 钩索及常规装备操作；
- 当前规则本来允许的普通特殊操作；
- 警务行动；
- 放弃行动。

因此，群演位阶不是“只能移动和打工”的惩罚层。**任何 SP 版本都不得缩减玩家原本拥有的基础行动集合。**

### 4.2 聚光行动

聚光行动是 M9 新增的高影响力行动接口，而不是第二个行动回合。

- 只有处于主角位阶的玩家，才能在自己的 T0 声明本回合为聚光行动。
- 聚光行动仍然只占用当前的 1 个标准行动槽。
- 声明后，玩家选择一个已经登记的聚光效果，并完成该效果规定的 T1 结算。
- 效果完整进入结算后，无论最终命中、被抵抗或未取得理想结果，玩家都退回群演位阶。
- 如果指令在合法性检查阶段即被拒绝、没有进入结算，则不消耗主角位阶。
- 每名玩家每个全局轮次最多执行 1 次聚光行动；额外行动不能绕过此限制。
- 没有合适时机时，主角玩家可以执行普通标准行动并保留主角位阶。

### 4.3 与既有天赋的迁移纪律

本 RFC 不自动把现有主动天赋加上 SP 门槛。逐天赋审计时，每个主动效果只能被明确归入以下一种：

1. **标准天赋效果**：保持原规则，不受 SP 限制；
2. **聚光增强**：原效果仍可用，主角位阶提供额外版本；
3. **聚光专属**：效果本身只在主角位阶可用，但必须证明低位阶仍有完整可玩行动；
4. **被动/响应效果**：不主动支付 SP，不因位阶不足失效。

不得把所有天赋统一改成“主角才能发动”。这会制造新的软轮空，并抹平角色节奏。

## 五、SP：从货币改为舞台位阶

### 5.1 资源分类

本 RFC 将 M9 原稿的“三货币”重新分类：

| 系统 | 类型 | 可交易 | 计入终分 | 主要用途 |
|---|---|---:|---:|---|
| 信用点 | 经济货币 | 依具体交易规则 | 否 | 购买、修理、治疗 |
| PP | 表演/元货币 | 是 | 是 | 表演消费、投注、魂援、评分 |
| SP | 公开状态轨 | 否 | 否 | 控制聚光行动节奏 |

因此，M9 在全局意义上仍只有信用点与 PP 两种货币；SP 与生命、护甲、充能、Regard 等一样属于状态，而不是第三种通货。

### 5.2 三个位阶

```text
群演 Ensemble  →  配角 Supporting  →  主角 Lead
       ↑                                  │
       └──────── 使用聚光行动后 ─────────┘
```

| 位阶 | 标准行动 | 聚光行动 | 公开性 |
|---|---|---|---|
| 群演 | 完整可用 | 不可用 | 公开 |
| 配角 | 完整可用 | 不可用 | 公开 |
| 主角 | 完整可用 | 可选择使用 | 公开 |

配角是节奏过渡层，不额外删减或增加基础指令。它让其他玩家能够提前一轮看见某人即将进入主角位阶，从而产生可预判的威胁窗口。

### 5.3 初始状态与自然推进

- 所有玩家开局处于 **群演**位阶。
- 每个 R0，仍存活的玩家自然上升 1 个位阶：群演 → 配角 → 主角；主角保持主角。
- 起床不会清空位阶；玩家可能在完成起床后已经接近或进入主角位阶。
- 使用聚光行动后回到群演；在没有任何额外关注事件时，最迟经过两个后续 R0 重新回到主角。

自然推进是防软锁保底。玩家不需要为了恢复 SP 被迫浪费一整个行动“充能”。

### 5.4 对抗关注

每名玩家每个全局轮次至多因对抗关注额外上升 1 个位阶。

当玩家第一次满足以下任一条件时，在对应行动完成结算后上升 1 个位阶：

- 主动发起一个合法的敌对行动并进入结算；
- 成为一个合法敌对行动的明确目标并进入结算。

敌对行动包括攻击、敌对强制位移和明确施加负面状态的效果。一次 AOE、连击或多目标行动对同一玩家每轮仍只触发一次位阶上升。

设计目的：

- 主动制造冲突者更快获得高光机会；
- 被集火者同步获得追赶资源；
- 命中失败不让一整轮投入归零；
- 每轮封顶防止 AOE、盟友互刷或多段攻击制造指数增长。

“盟友假打”是否仍可被利用，需要纸面推演与风洞验证；v0.1 不再加入第二层关系判定。

### 5.5 衰减

v0.1 **不设置常规 SP 衰减**。

理由：

- 聚光行动已经会重置位阶；
- 主角保留高光等待时机，本身是战略选择；
- 对低位阶继续衰减会重新制造软锁；
- 先测试玩家是否普遍囤积主角位阶，再决定是否仅对长期主角增加温和回落。

## 六、关键边界

### 6.1 额外行动

- 额外行动仍插入当前行动之后，沿用既有队列语义。
- 额外行动不触发 R0 的自然位阶推进。
- 对抗关注的每轮上限不因额外行动刷新。
- 已在本轮执行聚光行动者，额外行动只能执行标准行动。
- 任何新增 SP 规则不得形成“聚光 → 额外行动 → 再聚光”的无限链。

全员行动会提高额外行动的相对总量，但不会改变其单次价值；T2、T4、T5、G4、G2 等现存来源仍需专项复核。

### 6.2 控制效果

本 RFC 消除的是由普通先攻排名造成的行动剥夺，不消除有明确来源的控制。

但全员行动后，眩晕等效果从“可能让一个本来就轮空的人继续不能动”变成“稳定移除一个行动”，实际价值会提高。控制抗性、持续轮数和连续控制保护必须重新风洞。

### 6.3 玩家在轮到自己前死亡

先攻低者可能在自己的行动前死亡。这属于战斗结果，不是行动配额剥夺；本 RFC 不提供无条件的死前行动。

魂援中的被动防御窗口若采用，应在伤害结算中提供明确响应机会，而不是修改所有人的标准行动资格。

### 6.4 G2 舞台

G2 舞台已经采用全员排序行动，因此与本 RFC 的行动资格方向一致。舞台内的专属行动限制继续优先。

以下问题留待 G2 × M9 专项决定：

- 舞台期间是否冻结普通 SP 位阶；
- Regard 与 SP 是否完全独立；
- G2 的最优先保底行动是否仍需保留；
- Chorus 是否拥有 SP 位阶。

### 6.5 往世层

死者不进入生者的标准行动队列。PP 投注与魂援使用独立响应窗口，不因“全员行动”获得额外生者行动槽。

## 七、对 V2.0EXP 的直接影响

### 7.1 行动密度

若当前 K 为 `N−1`，全员行动每轮只增加 1 个标准行动，但相对变化会在残局放大：

| 存活人数 N | K=N−1 | 全员行动 | 相对增幅 |
|---:|---:|---:|---:|
| 6 | 5 | 6 | +20% |
| 5 | 4 | 5 | +25% |
| 4 | 3 | 4 | +33% |
| 3 | 2 | 3 | +50% |
| 2 | 1 | 2 | +100% |

这意味着前期仍接近现有行动密度，而一对一残局从“每轮只有先攻胜者行动”变成“双方都行动，先手先结算”。这是有意改变。

### 7.2 必须复核的系统

| 系统 | 影响 |
|---|---|
| 世界时钟 | 每个全局轮次包含更多行动，尤其残局；阶段长度需按总行动数重新观察 |
| 限量营业 | 所有人都能竞争，先攻顺序价值上升但不再使垫底者完全缺席 |
| 先攻修正 | 从“行动资格 + 顺序”降为只影响顺序，整体价值下降 |
| 控制效果 | 稳定移除本来必有的行动，实际价值提高 |
| 额外行动 | 仍强，但不再承担“补回本轮轮空”的隐性价值 |
| 每轮再生/DoT/充能 | 每轮对应更多玩家行动，动作/轮次换算发生变化 |
| 警察状态机 | 同一轮内违法、举报和执法前后的行动数增加 |
| AI/RL | 动作遮罩不再因正常轮空归零；需新增公开 SP 状态和聚光选择 |

### 7.3 天赋级阻塞项

- **G6 笑声**：失去“K=N−1 每轮稳定产生一次未行动事件”的来源，必须重做笑点输入，不能用强制轮空保住天赋经济。
- **T5 combo**：谱面不再因先攻垫底而被迫 Miss，FC 率会上升，需要复核谱面节奏与追加行动奖励。
- **先攻型效果**：所有原 D4/D6/先攻加成只剩排序收益，需重新估值。
- **额外行动型效果**：需要统一检查每轮聚光上限与事件触发上限。

## 八、验证方案

### 8.1 分层实验

为了避免把“取消轮空”和“加入 SP”混成一个不可解释的结果，实验按三层进行：

1. **B0：现行基线**——K=N−1，无 SP；
2. **B1：全员行动**——K=N，只保留先攻排序，无 SP；
3. **B2：全员行动 + SP 位阶**——加入自然推进和对抗关注，但只接少量占位聚光效果；
4. **B3：天赋试点**——选择少量不同复杂度天赋接入正式聚光效果。

只有 B1 相对 B0 的变化可以归因于取消轮空；只有 B2/B3 相对 B1 的变化可以归因于 SP。

### 8.2 核心指标

- 因普通先攻落后导致的非自愿轮空率：目标 **0%**；
- 各玩家标准行动数的方差；
- 首次有效行动等待时间；
- 平均全局轮数与平均总行动数；
- 2–6 人局分别统计的残局长度；
- 先攻排名与胜率的相关程度；
- 群演/配角/主角位阶占用率；
- 聚光行动平均间隔、囤积主角位阶的轮数；
- 控制效果实际移除的行动数；
- T5 FC 率、G6 笑点收入、额外行动频率；
- 平局率、引擎异常率和真人回合耗时。

### 8.3 v0.1 通过标准

进入实现提案前至少满足：

1. SP 位阶不会减少任何玩家的标准行动集合；
2. 无对抗时，聚光使用者在两个后续 R0 内必定重返主角；
3. 单名玩家每轮最多一次对抗关注、一次聚光行动；
4. 2 人残局双方每轮各有一次标准行动机会；
5. G6、T5、控制与世界时钟均已有明确迁移方案；
6. B0/B1/B2 的数据可以分离“全员行动”和“SP”各自造成的变化。

## 十、当前建议

本 RFC 建议先接受以下方向作为纸面推演基线：

> **全员行动、先攻排序、基础行动永不被 SP 封锁；SP 是公开的舞台位阶，主角位阶只用于选择高光行动。**

这不是立即修改 V2.0EXP 的决定。完成 B0/B1/B2 对照、G6/T5 迁移方案与至少一轮六人纸面推演后，才能决定它是否取代 K 常量行动制并进入新的实验 profile。
