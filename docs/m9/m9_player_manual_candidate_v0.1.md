## 卷首：这到底是什么版本

之前有人问我，M9 和 V2.0-exp 到底是什么关系。

简单说，V2.0-exp 是现在能运行的东西，M9 是下一代候选。它把每轮轮空一个人的 K 行动制
拆掉，让所有人都能行动；把天赋从“次数按钮”改成 SP 驱动的即演与公演；再把死者、警察、
神代天赋和十四诗篇重新接到同一套结算上。听起来像装修，实际上差不多是把房梁抬起来再
换地基。请勿在施工现场声称自己已经入住。

这游戏仍然**不适合脱离电子裁判纯手算**。你可以理解规则，可以据此做决定，但不需要拿
计算器替程序结算每一条事件。DM 的工作是主持、解释公开信息和操作裁判，不是成为一台
人肉服务器。好消息是服务器不会嫌你问得多；坏消息是我会。

## 一、游戏概述

### 1.1 目标

《起闯战争》是一款 2 至 6 人的回合制乱斗 MUD。玩家在六个地点之间移动、发育、结盟、
翻脸、演出并争夺综合评分。

终局并行记录两个答案：

- **最后存活者**：谁站到了最后；
- **综合评分第一**：谁把这一局打得最精彩。

两者可以是同一个人，也可以不是。死亡不会把玩家踢出游戏：普通死者进入往世层，继续
投注、交易和提供魂援。只有 `absolute_dead` 不进入往世层。

### 1.2 信息公开

这是高信息游戏。位置、生命、装备、护甲耐久、状态、先攻、SP、公演队列、PP、通缉与
大多数专属资源均公开。隐身只影响侦测与命中，不会把整张状态栏塞进量子叠加态。

匿名冷箭等明文来源可以隐藏攻击者身份；除此之外，不要自行把公开信息改成私密信息。

### 1.3 玩家状态条

每名玩家至少显示：

| 项目 | 内容 |
|---|---|
| HP | 上限 `⟦bal:hp20.player_max_hp⟧`，使用整数生命模型 |
| 外层护甲 | 每件护甲的属性防御与耐久 |
| 信用点 | 生前购买与维护资源 |
| SP | `0 / 1 / 2` 的演出准备度 |
| PP | 生死共通的演出积分，可消费、投注和计入终分 |
| 装备与弹药 | 武器、护甲、道具、箭矢、弓模块等 |
| 状态 | 灼烧、震荡、石化、掩体、爱愿、天赋标记等 |
| 天赋资源 | 追忆、魔力、火种、失熵、Cost 等，仅持有者显示对应条目 |

## 二、游戏准备与地图

### 2.1 开局

1. 每名玩家选择一个天赋，或全桌约定无天赋局。神代天赋认知复杂度很高，开桌前请确认
   大家愿意看别人演出，而不是只愿意看自己赢。
2. 每名玩家从自己的**家**开始，HP 为 `⟦bal:hp20.player_max_hp⟧`，状态为“未起床”。
3. 每人获得一把弓和 `⟦bal:bow.initial_arrows⟧` 支箭；家中可领取小刀与盾牌。
4. 每名玩家开局 SP=1。第一轮自己的 T0 已可即演，但第一个行动槽仍必须先处理起床。
5. 建立固定警力、世界时钟、地点补给与公共事件日志。数量和数值按当前平衡表。

家不产钱。你若决定在家里待到世界毁灭，世界通常会比你的钱包更先满足这个愿望。

### 2.2 六个地点

地图由六个地点组成，任意地点之间移动都消耗一个行动，不检查相邻关系：

| 地点 | 主要功能 |
|---|---|
| 家 | 起始包、部分形态更换与安全屋；不提供经济收入 |
| 商店 | 打工、小刀、磨刀石、陶瓷护甲、隐身/探测装备、弓模块、修甲、箭矢补给 |
| 魔法所 | 法术、魔法护盾、魔法弹幕、火矢与魔导模块 |
| 医院 | 打工、治疗、手术、防毒面具、无限模块、释放病毒 |
| 军事基地 | 通行证、AT 力场、科技武器、雷达、弓模块与钩索 |
| 警察局 | 举报、队长申请与警务系统；被摧毁后警务停机 |

### 2.3 地点摧毁

地点只有在明文最高级效果下才会被摧毁。当前首个来源是 G1 繁育超新星：地点获得永久
`destroyed`，无法进入，地面物品与地点功能消失，幸存单位被驱逐回家；家也不可用时回到
最近安全地点，平局按先攻降序、actor ID 决定。

最后一个仍可站立的地点不能被摧毁。警察局没有剧情护盾：它被毁时警务立即停机。

## 三、轮次、行动与控制

### 3.1 R0 至 R4

每个全局轮次按固定顺序进行：

```text
R0  自动状态与轮初资源、投注开市、公演报名、队列清理并分配唯一公演位
R1  所有正常玩家判定先攻，只决定行动顺序
R2  警察、案件、世界时钟与其他公共状态推进
R3  所有正常玩家依次获得一个标准行动槽
    T0：控制裁决；选择普通行动、即演或本轮公演
    T1：结算一个根行动及至多一次明文追演
    T2：系统收尾、关注/SP、反应与合法额外行动派发
R4  持续效果、形态寿命、警察执法、世界时钟与胜负检查
```

**建立轮 R4 不 tick。** 一个状态在本轮建立，本轮 R4 默认不扣第一段；从之后第一个 R4
开始计时。石化、无人机、繁育、救世主、锚定与固有结界都服从这条，除非来源明文
说建立当轮开始计时。

G2 普通影身没有 R4 寿命；终曲歌者只用有听众的未来 R4 tick 推进一次性剧情里程碑。

### 3.2 标准行动

每名正常存活玩家每轮获得一个标准行动槽。先攻只排序，不再把先攻最低者赶去坐牢。唯一
例外是 G2 的活跃普通影身：它是同一玩家的完整代理 actor，另有自己的先攻与标准槽；不是
full-extra，也不增加第二份 SP/PP/信用点/评分。

| 行动 | 规则 |
|---|---|
| `wake` 起床 | 仅未起床时可用；开局第一个槽强制执行 |
| `move <地点>` 移动 | 移到任意其他地点；主动离开交战可能触发借机攻击 |
| `interact <项目>` 交互 | 购买、打工、学习、手术、修理、补给或地点功能 |
| `find <目标>` 找到 | 与同地点目标建立面对面关系，是近战前置 |
| `lock <目标>` 锁定 | 提高远程命中；弓不锁定也可射击但有惩罚 |
| `attack <目标> <武器>` 攻击 | 使用合法武器攻击合法目标 |
| `shoot <目标>` 射箭 | 弓的跨地点攻击，消耗箭矢；箭落在目标地点可回收 |
| `hook ...` 钩索 | 拉取目标或位移自己，共享冷却，不触发借机攻击 |
| `report` 举报 | 用合法证据建立当前通缉；见第七章 |
| `special <操作>` 特殊操作 | 天赋、装备、蓄力、换装、宏等明文操作 |
| `forfeit` 放弃 | 自愿消费本槽，不提供补偿 |

### 3.3 交战与借机攻击

两名同地点玩家在本轮或上一轮互相造成过伤害，视为**交战**。交战者主动 `move` 离开时，
每名同地点交战对手可免费结算一次借机攻击，每名追击者每轮最多一次。击退、钩索拉取、
驱逐等被动位移不触发借机攻击。

### 3.4 追演、受限追加与完整额外行动

**追演**是根行动内部明文附带的一步：不重进 T0，不得再次演出，不得递归追演，同一根行动
至多一次。

**`restricted_followup`** 是独立但受限的行动授予。它没有玩家 T0，不能即演、公演或换装，
只能执行来源列出的根行动。当前唯一来源是 G1 完全燃烧，每轮至多一次，只能 `move` 或
`attack`。

**完整额外行动**会重新执行完整 T0→T1→T2，允许 SP≥1 时即演，但禁止公演。共同边界：

- 每名玩家每个全局轮次至多一个；
- 立即插入，不能储存或结转；
- 不刷新关注、SP 获取或公演上限；
- 不得递归生成另一个完整额外行动；
- 被控制消费后直接损失。

当前只有三个来源：T4「或跃在渊」、G5「地火」之诗、G4 负世主动燃尽。同轮多个候选的
优先级固定为 **T4 或跃 > 地火 > 负世**；落选者整体丢弃。T5 combo 不属于 M9：它的原槽位
已经转为 G0。

### 3.5 控制裁决

行动槽开始时按以下顺序处理：死亡/离场/流放 → 压制 → 自我怀疑 → 睡眠 → 石化 →
震荡 → 正常行动。

| 状态 | 效果 |
|---|---|
| `SHOCKED` 震荡 | 下一槽只能有限移动、非敌对交互、帮助唤醒或放弃；槽收尾后移除 |
| `ACTION_SUPPRESSED` 压制 | 下一行动槽强制跳过；当前没有普通技能可以施加 |
| `PETRIFIED` 石化 | 可放弃保持、支付 SP 尝试挣脱，或等待两次有效伤害解除 |
| 睡眠 | 该槽只能唤醒 |
| 自我怀疑 | 下一槽跳过，结束时按来源转化，当前主要用于 G7 Terror |
| `EXILED` 流放 | 离开普通行动层，无槽、不可被指定；结束后返回原位或最近安全地点 |
| `COVERED` 掩体 | 地点绑定的临时防御物；远程直接攻击优先命中它 |
| `SUBMERGED` 沉沦 | NPC 停机状态 |

普通控制共用一个控制位，优先级为压制 > 石化 > 震荡。睡眠、自我怀疑和流放是结构状态，
不占这个控制位，也不会被压制顺手清掉。眩晕已经退出 M9 状态表；旧来源统一迁移为震荡。

### 3.6 援助休整

T3 防御魂援可以给玩家登记 `aid_rest`。它消费该玩家**下一次实际获得的行动槽**，本槽没有
根行动、没有演出，但照常系统收尾。`aid_rest` 在控制裁决之前处理，所以压制、石化、震荡
会原样留到再下一槽。微澜不是援助休整，别因为都写着“下一次”就把两个状态焊在一起。

## 四、装备、信用点与世界资源

### 4.1 信用点

信用点继承 V2.0-exp 的经济结构：

- 在商店或医院打工，每次获得 `⟦bal:economy.faucets.打工⟧`；
- 没有被动收入，家不产钱；
- 白昼后击杀会使死者的钱包、装备、模块与剩余弹药掉在死亡地点；
- 拾取地面掉落消耗一个交互行动；
- 医院手术消耗全部信用点，最低 `⟦bal:economy.surgery_min_cost⟧`，相当于财产税。

常见支出仍包括小刀、磨刀石、陶瓷护甲、隐身/探测装备、防毒面具、修甲、箭矢、弓模块、
钩索与治疗。具体价格只看平衡表。

### 4.2 弓与模块

弓是人人都有、唯一常规跨地点的武器。基础伤害 `⟦bal:bow.damage⟧`，箭矢上限
`⟦bal:bow.max_arrows⟧`。商店补给一次获得 `⟦bal:economy.arrow_supply_amount⟧` 支。

弓有两个模块槽。同名模块可双装强化；无限模块独占两个槽且不消耗箭矢，但只发射普通箭。

| 模块 | 来源 | 作用 |
|---|---|---|
| 力量 | 商店 | 增加弓伤害 |
| 火矢 | 魔法所 | 改为魔法属性并施加灼烧 |
| 魔导 | 魔法所 | 增加命中 |
| 穿甲 | 军事基地 | 改为科技属性并降低防御系数 |
| 冲击 | 军事基地 | 同地点命中后击退；双装追加先攻惩罚 |
| 无限 | 医院 | 独占双槽，不消耗箭矢 |

装备或拆卸模块消耗一个行动。地图供应有限，别人买走了就是买走了，直到它随死亡掉回地图。

### 4.3 护甲与耐久

外层护甲使用“属性防御 + 耐久”：吸收的伤害会等量消耗耐久，耐久归零后破碎。多件护甲
共同吸收时，按各自防御贡献分摊，余数交给贡献最高者。

| 护甲 | 主要属性 |
|---|---|
| 盾牌 | 普通 |
| 陶瓷护甲 | 普通 / 科技 |
| 魔法护盾 | 魔法 / 普通 |
| AT 力场 | 科技 / 魔法 |

医院手术提供内层属性防御。内甲没有耐久，不会破碎。只要外甲尚未破碎，攻击不能自行跳过
外甲直打内层或 HP；最后一层被打穿后，剩余伤害才继续进入 HP。

### 4.4 隐身、探测与命中

近战默认需要 `find` 建立面对面；远程需要可见目标，`lock` 提供最佳命中。基础命中通常是
确定性的，以下来源才引入闪避：本轮主动移动、对应属性隐身而攻击者没有探测、跨地点弓箭
未锁定。总闪避受 `⟦bal:accuracy.evasion_cap⟧` 限制。

隐身与探测按普通、魔法、科技三种属性配对：隐身衣/热成像仪，隐身术/探测魔法，隐形
涂层/雷达。擦伤不是另一套命中类型，而是最终伤害恰好等于 `ceil(A×25%)`。

### 4.5 灼烧、重伤与病毒

- 灼烧每层每轮造成 `⟦bal:burn.damage_per_stack⟧` HP 持续伤害，上限
  `⟦bal:burn.max_stacks⟧`；
- HP 高于 0 且不超过 `⟦bal:hp20.severe_injury_threshold⟧` 时为重伤，承受对应范围伤害和
  先攻惩罚；
- 医院释放病毒后，经过 `⟦bal:virus.incubation_rounds⟧` 轮潜伏，每个 R4 对无防毒面具的
  玩家造成 `⟦bal:virus.damage_per_round⟧` HP 伤害。

## 五、伤害、死亡与胜负

### 5.1 两阶段伤害

所有普通攻击先算攻击方结果 `A`，再算承受方结果 `H`：

```text
A = max(0, round_half_up(base_damage × skill_core_multiplier
                         + attacker_flat_bonus − weakness))

E = round_half_up(attribute_defense × defense_coefficient)
H0 = A + vulnerability − flat_damage_reduction − E

若 A > 0：H = max(H0, ceil(A × 25%))
若 A = 0：H = 0
```

一个攻击只取一个核心倍率。虚弱、易伤和普通增减益默认进入固定值项；同名易伤/虚弱取
最高值，不相加。多个防御系数取最低值，不连乘。普通舍入使用 half-up，明文 `ceil` 才向上。

`A=0` 只来自明文攻击归零白名单。它不启用 25% 下限，不消耗护甲或掩体，也不算造成伤害。

### 5.2 有效伤害

以下任一成立，才算一次**有效伤害**：

- `H≥1` 进入本体 HP；
- 一件护甲或掩体耐久归零。

只磨损但没打破耐久、A=0、完全被替身/免疫承接、只打在未破掩体上都不算。T3 石化解除、
G5 变数等全部引用这一个口径。

### 5.3 `DIRECT_DAMAGE`

`DIRECT_DAMAGE` 是唯一的直达伤害身份：攻击方阶段照常计算，目标侧直接令 `H=A`，跳过
属性防御、护甲和普通固定减伤。它仍可被明文替身、重定向、绝对免疫或掩体承接，仍登记
关注、犯罪、伤害和死亡。

它**不自动等于绝对死亡**。G0 十字炮火只有 `DIRECT_DAMAGE`，T7 保险仍可承接；G7 Terror、
G4 死星天裁等还带 `absolute_death`，才会跳过复活。

### 5.4 普通死亡与绝对死亡

普通死亡时：SP 清零、退出公演队列、掉落按世界阶段处理，并进入往世层。普通复活从 SP=0
重新开始，除非「彼岸」诗明文把 SP 置 2。

携带 `absolute_death` 的致死结果进入 `absolute_dead`：

- 跳过普通免死、死亡替代与复活；
- 不进入往世层，不能投注、转仓或提供魂援；
- PP 冻结且不能支出；死亡前已经托管的赌注仍按终局结算；
- 装备照常掉落，终分使用死者公式。

当前绝对死亡来源包括 G5 锚定绝对实现、G4 死星天裁、G7 Terror 攻击和 G1 繁育倒计时。

### 5.5 白昼世界时钟

每幕长度为 `⟦bal:world_clock.segment_base⟧ + 初始玩家数`，依次进入：

| 阶段 | 主要变化 |
|---|---|
| 黎明 | 基础规则，发育与结盟 |
| 白昼 | 地点供应按轮限量；第一次攻击只记嫌疑；开启击杀掉落 |
| 黄昏 | 全局伤害提高、治疗变贵、商店半价；警察掩体关闭但案件继续 |
| 终焉 | 每个 R4 全员承受 `⟦bal:world_clock.apocalypse.end_of_round_true_damage⟧` 点环境 `DIRECT_DAMAGE`；警务完全停摆 |

终焉是毒圈，只是它没有画成圈。你若坚持梅花桩，它会亲自来拔。

## 六、SP、即演与公演

### 6.1 先把 SP 说清楚

SP 是公开的天赋准备度，只回答“你现在能否演出”，不是钱、伤害点数或行动点：

| SP | 权限 |
|---:|---|
| 0 | 正常行动，不能主动演出 |
| 1 | 可以即演 |
| 2 | 可以即演、保留，或报名公演 |

开局每人 SP=1。即演固定消费 1，公演固定消费 2；死亡时 SP 清零，普通复活从 0 重新开始。
`EXILED` 保留原 SP，但离场期间不能演出、取得关注或排队。SP 不交易、不计分、不兑换，也
没有“这招少打一拳，能不能便宜半点”的临时议价。

### 6.2 什么是关注，怎样得到 SP

**关注**是一次公开事件把你登记为“发起者”或“焦点”，不是看台上有几个人。一次有效关注
使你 SP+1，上限 2；每人每个全局轮次最多通过关注**实际增加 1 SP**，额度在下一 R0 重置。

| 事件 | 谁尝试取得关注 |
|---|---|
| A 用普通攻击打 B | 先登记焦点 B，再登记发起者 A；两人分别检查自己的本轮额度 |
| A 对 B 执行会改变生命、位置、控制、资源或公共身份的高影响行动 | B 是焦点，A 是发起者 |
| A 犯罪 | A 是发起者；有直接受害者时，受害者也是焦点 |
| A 参与天赋/RFC 明文登记的公共争夺或高风险事件 | 按该事件写明的参与者登记；没有明文就不能类推 |
| 世界时钟等无行动者的明文环境事件 | 只登记受影响者为焦点，没有虚构的发起者 |
| A 即演/公演攻击 B | B 可以取得焦点关注；A 不能靠自己的演出返还 SP |

关注判断看的是**合法行动已经进入结算所制造的公开风险**，不要求命中或造成伤害：未命中、
被闪避/抵抗、`A=0`，仍可登记。预检失败、无效目标、结算前取消、重复空指令、只改私人界面
则不登记。已经 SP2 时事件仍写日志，但不会加到 3，也不占“本轮实际 +1”额度；若你稍后花掉
SP，本轮之后的第一次有效关注仍可让你 +1。死亡、绝对死亡或离开普通行动层期间不能取得。

普通根行动的关注在该行动 T2 登记；环境事件在自己的公共收尾登记。若别人先行动并把你从
SP1 推到 SP2，你在本轮尚未行动，轮到自己 T0 时就已经可以即演。完整额外行动不会刷新每轮
关注额度。

### 6.3 即演有没有冷却

没有。即演不维护独立 CD、每局次数或“演完停一轮”：只检查你当前 SP≥1、天赋核心合法，
并且当前有可用的普通/完整额外行动槽。

- 在自己 T0 选择即演，预检通过后消费本槽和 1 SP；SP2→1，SP1→0；
- 一个槽只能结算一个即演根行动；若同轮另获完整额外行动且仍有 SP，可以在额外行动再即演；
- 只要外部关注让你重新取得 SP，下一轮可以继续即演；
- 即演不是反应技，不能在别人行动中插入，除非天赋明文写成自动转折；
- 已报名者改用即演会立即退队，不保留原位置。

### 6.4 四种演出身份

| 形态 | 时机 | 消耗 | 是否占槽 |
|---|---|---:|---:|
| 即演 | 自己任一合法 T0 | 1 SP | 默认占；明文 T0 宣言除外 |
| 公演 | SP=2 报名并取得本轮公演位后 | 2 SP | 是 |
| 伏笔 | 即演/公演时布置，条件达成时自动兑现 | 布置时支付 | 兑现不占槽 |
| 转折 | 濒死、死亡、受击或剧情条件自动发生 | 不读 SP | 否 |

即演必须保留天赋完整核心，不得削成半招；但它不开魂援、PP、公演追演、诗篇适配与完结条
待遇。公演的核心通常不比即演多打一遍，它买的是全桌舞台与支援窗口。

合法性预检永远先于消费。无目标、资源不足、结构禁止时，SP、槽位和专属资源都不扣；
预检通过后被闪避、抵抗或打出坏结果，照常消费，不退款。

### 6.5 公演在什么时候报名

SP=2 只代表你**有资格**报名，不会自动入队。报名免费，不占行动、不花 SP，也不需要提前
锁定目标或投影参数。系统只在两个窗口接受新报名：

1. **每个 R0 的公演报名窗口**：自动状态和往世层开市之后、队列清理与本轮舞台分配之前。
   此时入队，如果前面无人且资格有效，本轮就可以取得公演位；
2. **某事件把你从 SP1 推到 SP2 的收尾**：系统立刻询问“保留 / 报名”。此时本轮舞台早已
   在 R0 分完，你只能排后续轮次。

如果你已经 SP2 却在窗口选择保留，就等下一 R0 再申请。队列公开、FIFO；旧成员位置不变，
同一事件双方同时到 2 并报名时焦点对象优先；同一 R0 无法区分先后的新报名按玩家 ID 升序。
全局每轮只有一个公演位。

每个 R0 清理一次队列；队首本人 T0 再检查一次。死亡、离场、SP<2 或失去全部合法公演选项
都会使成员**永久移除**。队首在第二次检查失效，本轮公演位直接空着，不把后面的人临时
抓上台。想再演，请恢复资格后去队尾重新报名。

已经报名的玩家可以主动退队，不花行动或 SP；也可以在自己的 T0 改为即演，退出队列并消费
1 SP。队首通过检查却选择普通行动、即演或主动放弃舞台，也会退队，本轮位置空着且不临时
递补。公演进入结算后消费本次队列项。

### 6.6 自动置 SP2 与落幕

当前只有两个白名单来源可以直接把 SP 设置为 2：

- G4 燃尽完成公共收尾；
- 携带「彼岸」诗的 T7 保险复活。

这是置位，不是关注，不刷新本轮关注上限，不自动报名。G1 繁育不是演出，也不会置 SP2。
一次性天赋永久兑现后进入**落幕**。玩家仍有正常行动，但该天赋不再因关注取得 SP，也不能
报名公演。T7 保险兑现是当前典型来源。落幕不是死亡，更不是“你可以去泡茶了”。

### 6.7 一轮完整例子

四名玩家 A（T1）、B（T2）、C（T4）、D（T6）位于普通行动层同一地点；A/C、C/D 已面对面，
B 已发现并锁定 A，且场上有一名可供 D 整备的存活警察。第 N 轮开始时：A 有 2 SP；B、C、
D 各有 1 SP；公演队列为空，四人的“本轮关注 +1”额度都尚未使用。

**R0：自动状态、报名和公演位**

1. 自动状态与往世层开市完成。
2. 公演报名窗口打开。A 公开报名；报名不花行动或 SP。
3. 系统清理队列。A 仍存活、SP2 且至少有一个合法公演核心，因此有效。
4. A 成为队首，取得第 N 轮唯一公演位。队列中暂时只剩这一个待消费项。

**R1：先攻排序**

本轮顺序为 A→B→C→D。先攻只决定先后，四人都会得到自己的标准行动槽。

**R2：公共推进**

案件、警察和世界时钟照常推进。本例没有事件改变四人的状态。

**R3：四个标准行动**

1. A 在 T0 通过二次检查，公演 T1 斩击 C。预检通过后 A 消费 2 SP，变为 0；即使攻击未
   命中，C 仍是合法公演的焦点。A 的 T2 先给 C 登记关注：C 从 SP1→2。A 不能靠自己的
   公演取得发起者关注。系统立即询问 C，C 选择报名，进入后续队列 `[C]`。
2. B 在 T0 即演攻击 A。B 消费 1 SP，从 1→0；A 作为焦点在 B 的 T2 从 SP0→1。B 不能靠
   自己的即演返还 SP。
3. C 轮到 T0 时已经是 SP2，但本轮公演位属于 A 且已经消费，C 不能抢台。C 选择普通攻击
   D。T2 先登记焦点 D：D 从 SP1→2；再登记发起者 C，但 C 已在上限 2，数值不变。D 立即
   报名，排在 C 后面，队列变为 `[C, D]`。
4. D 尚未行动，因此可以立刻使用刚得到的 SP2。D 选择即演，SP2→1；因为即演会退队，D
   从队列移除，队列恢复为 `[C]`。这说明“R3 中途不能抢公演”不等于“本轮不能即演”。

**R4：持续状态与胜负**

结算持续效果、世界时钟和胜负。本例无人死亡。轮末 A=1、B=0、C=2、D=1，公演队列为
`[C]`。

第 N+1 轮 R0，四人的关注额度重置；C 通过队首检查后取得该轮唯一公演位。D 没有即演 CD：
只要之后重新取得至少 1 SP 并有合法行动槽，下一轮仍可即演。

## 七、案件、警察与 T6

### 7.1 案件状态机

警察只认四件事：

```text
犯罪事实 / 线索 → 举报并建立通缉 → 警察自动出动 → 执法或结案
```

第一版同时只有一个当前通缉。可用于举报的证据只有四类：受害者、事件发生时同地点目击者、
系统归因的探测器、T6 特别线索。已有活跃通缉时，新举报在预检阶段失败，不耗证据、不耗槽。

普通举报占一个标准根行动。成功后，下一 R2 从可出动警察中选择离目标最近者作为 lead，
平局按 NPC ID 升序；lead 追踪目标，只有在 R4 与目标同地点时执法。目标每轮可以花移动拖延，
但不能免费把案件跑没。lead 失能或死亡，下一 R2 重选。

通缉只能因目标死亡、绝对离场、队长合法解职、警察局被毁、终焉停摆或「律法」诗明文
覆写而结案。清除犯罪记录本身不取消通缉。

### 7.2 固定警力与掩体

警力开局建立，队长上任不会生成三名崭新的同事，也不会把已死警察从仓库里拆封。每名正常
警察每个 R4 至多自动执法攻击一次；本轮已被队长命令立即攻击，就不再自动补一枪。

正常警察为同地点、未被通缉的单位提供一层 `COVERED`：来源绑定、R0 刷新、同单位不叠加，
受保护者离开地点或警察失能便立即移除。黄昏关闭掩体，终焉停止整套警务。

警察局被摧毁时：关闭举报与自动推进；清除通缉、队长、威信和掩体；幸存警察保留 HP 与
装备，转为不会自动行动、不接受命令的中立 NPC。

临时演出警察不占编制、不继承案件，只能对当前通缉目标执行登记的一次表演，随后消散。

### 7.3 队长

干净玩家在警察局花一个标准行动公开申请；下一 R2 仍存活、合法、在普通层且职位空缺时
就任。队列按登记时间，平局按先攻降序、玩家 ID；死亡、犯罪或离场会使申请失效。

队长每个标准根行动只能命令一名警察做一件事：移动、立即攻击、唤醒或改派。威信不是钱，
而是责任：合法执法不扣，命令攻击无辜者、本人犯罪或非法改案会扣。威信归零时下台，当前
通缉合法结案，前队长自己成为新通缉目标。

Terror 不在警察合法目标池。警察不会主动追踪或攻击 Terror，也拒绝队长要求其靠近或攻击
Terror 的命令。

### 7.4 T6「朝阳好市民」

**特别线索**把进入他人之家、无许可进军事基地、释放病毒等事件写入公开日志。T6 死亡后
线索仍保留，但只有存活或已复活的 T6 能拿它举报。

**市民热线**是不读 SP 的标准根行动：T6 可从任意地点举报，但仍需合法证据，仍受唯一通缉、
世界阶段与停机限制。远程只豁免地点，不豁免事实。

**联防整备**是 T6 的即演/公演核心：选择一名现存存活警察，为其更换一件合法装备。没有
存活警察时预检失败。每次只换一件，不移动、不命令、不追加攻击。白名单为：

- 武器：警棍、高斯步枪、魔法弹幕；
- 护甲：盾牌、陶瓷护甲、魔法护盾、AT 力场。

装备必须真实来自补给，不免费生成，只属于警察，不能转给玩家或靠击杀刷取。和平局没有
虚构案件补偿，秩序没坏的时候，“好市民”本来就会显得没那么忙。

## 八、PP、往世层、投注、魂援与评分

### 8.1 PP

PP 合并旧喝彩与星光，生者和普通死者都持有，死亡不清零。常规铸造来自击杀、复仇、破甲
击杀、终焉/绝境击杀、完结条与明文演出事件；具体数值使用 `m9_system.pp.*`。

生者可用 PP 重掷先攻、增加攻击方固定伤害、偷看先攻或抵消犯罪，具体费用按平衡表。每个
R4 若本轮完全没有使用 PP，则 PP−1，最低 0；死者免衰减。G0 撤退和 `absolute_dead` 的 PP
冻结，不衰减也不能再花。

### 8.2 往世层投注

普通死者在每个 R0、公演队列清理前的开市窗口投注：

- 选择一名仍在场的生者，下注至少 1 PP；不可分散一笔赌注；
- 赔率为下注时“当前存活人数 : 1”，不根据强度或市场修正；
- 注金进入托管，不能撤回或消费；同目标追加按追加时赔率单独形成 tranche；
- 花费转仓费可把**整仓**存活赌注转给另一名生者，按当前赔率重新定价；
- 被押者死亡，该 tranche 销毁；被押者成为最终胜者，则返还本金和赔率收益；
- 最终胜者可以并列，胜负确定后立即锁市，不能最后一秒补票。

最终胜者先按不含投注派彩与黑马胜利加成的 `base_final_score` 冻结为
`game_winner_snapshot`，同分并列；随后才派彩并给快照中的黑马加分。派彩后的显示终分可以
改变终局排名，但不会反向改写已经冻结的胜者。

无人下注的生者是**黑马**，获得独立保底增益；黑马获胜时终分额外增加
`⟦bal:m9_system.pp.blackhorse_bonus⟧`。黑马不是援助，不占援助额度，也不需要往世层有人。

### 8.3 四次魂援

每名生者每局有四个彼此独立的额度：主动进攻、主动防御、被动进攻、被动防御各一次。

| 类型 | 触发 |
|---|---|
| 主动进攻 | 附着于任意合法攻击根行动；该攻击就是载体 |
| 主动防御 | 用一个标准根行动挂载延迟防御标记 |
| 被动进攻 | 自己每局第一次攻击且往世层非空 |
| 被动防御 | 第一次被敌对伤害打到 HP≤`⟦bal:m9_system.pp.aid_hp_threshold⟧`且仍存活、往世层非空 |

无死者时被动援助不触发、不耗额度，顺延到下一次满足条件。自我扣血不触发被动防御；一击
直接致死也不触发，它不是锁血。公演攻击只是主动进攻的合法载体，不是第五次额度。

主动援助由生者公开出价 1 至 3 PP，死者接受或拒绝。多人接受时，依次选择：对请求者押注
最多者、最早死亡者、ID 最小者。成交后 PP 从生者转移给死者。无人接受时不转账、不生效、
不耗额度；进攻载体照常打，防御标记行动的槽位不返还。

被动援助由系统指派：优先押注请求者最多的死者，否则最早死亡者。生者不付费，提供者获得
`⟦bal:m9_system.pp.aid_passive_reward⟧` PP。

### 8.4 二十六项援助

| 天赋 | 进攻援助 | 防御援助 |
|---|---|---|
| T1 | 本次属性防御 E=0，护甲/掩体照常 | 按本次 H 的比例生成一次不可递归反射攻击 |
| T2 | 削减目标外甲并按实际损失修复自己缺损最多的外甲 | 本轮提高闪避 |

| G2 | 额外销毁 PP，换本次攻击固定加值 | 额外销毁 PP，按比例恢复 HP |
| G3 | 本回合攻击到的单位本轮不能 move，但不占控制位 | 截断下一次攻击型演出的天赋载荷，降级为基础攻击 |
| G4 | 持续期间攻击次数越多，后续攻击固定加值越高 | 受击次数越多，后续来袭固定减伤越高 |
| G5 | 从七枚简化诗篇标记中选一枚 | 同左 |
| G6 | 以自身状态重演一个可复制普通行动模板 | 同左 |
| G7 | 点射并施加易伤，随后对请求者所在地其他单位造成范围伤害 | 冲刺并获得按当前 HP 计算的普通掩体 |

G3 防御援助只截断当前攻击型即演/公演的主动载荷与演出追演，不压制被动或未来行动；原动作
若能形成合法基础攻击，则同一行动者、目标和武器继续攻击，槽与 SP 照常消费。

G5 简化诗篇只能选游侠、群星、阴阳、永恒、飞萤、追光、明天。爱与记忆、锚定、地火、
负世、彼岸、守夜人禁止经魂援复制。

### 8.5 终分

```text
剧情分 = 完结条阶段数 × arc_weight
战果分 = 击杀数 × kill_weight + 总伤害 × damage_weight

生者终分 = (剧情分 + 战果分) × 存活系数 + PP
死者终分 = 剩余 PP + 赌注收益 + 援助收益
```

存活者系数为 1.5，普通死者为 0.5。G0 撤退使用生者公式但系数为 0.5，PP 使用冻结值。
T7 保险成功兑现视为未死亡。G5 每朵水晶花只登记 `arc_count +1`，贡献一段剧情分，不提供
战斗强化或追忆折扣。

死者不是坐牢，只是从选手转职成投资人。至于投资人会不会为了三点 PP 把自己押的人卖掉，
那是市场行为，我不做道德评价。

## 九、原初天赋 T1 至 T4、T6 至 T7

M9 没有 T5。原 T5 槽位已经由 G0「砂狼白子*Terror」取代，因此 T5 combo 的谱面、FC、
完整额外行动和魂援都不进入本 profile；G0 也不因此取得魂援技。`v2exp` 仍可保留自己的
T5，这只是 profile 隔离，不是删除现行代码。

### 9.1 T1「一刀缭断」

一句话概括：一次很不讲道理的近战攻击。次数限制删了以后，“一次”主要是指每次发动。

在自己的 T0，选择同地点、已经面对面的目标和一件近战武器。即演与公演都结算完整核心：

- `skill_core_multiplier=2`；
- `defense_coefficient=0.5`；
- 先乘核心倍率，再加入攻击方固定值；目标只计算一半属性防御；
- 护甲、掩体、25% 下限、命中、替身与死亡仍正常结算。

即演消耗 1 SP；公演消耗 2 SP，并开放魂援与「游侠」诗追演。删除旧使用次数。T1 没有
完整额外行动来源。

### 9.2 T2「剪刀手传奇一突牢玩家」

T2 把“追着人打”拆成几条常驻身份：

- 伤害玩家但未杀死，不视为犯罪；
- 每第二次击中外层护甲时，按原规则修复自己的对应外甲；
- 击杀数为 0 时，攻击不解除自身隐身；
- 合法犯罪、高影响 `find` 与成为 `find` 焦点只走普通关注，不再发完整回合。

即演对已经发现或锁定的目标发动合法攻击，不免费移动。公演可以先追演移动到目标地点，
再攻击，但不是重新获得完整回合。

每局一次**追猎反应**：另一名玩家公开根行动完成后，若 T2 能以自身状态对其合法 `find` 或
`lock`，可立即二选一。它不移动、不攻击、不进 T0、不创建行动槽，费用和责任归 T2。

### 9.3 T3「天星」

天星没有即演入口。T3 必须取得公演位并支付 2 SP，选择任一仍存在的地图地点；不要求施法者
身处或感知该地点。对其中除施法者本人外的所有合法玩家与 NPC
造成 `⟦bal:m9_talents_extended.t3.starfall_damage⟧` 无属性伤害，并施加石化。盟友也会吃，
所以请在“天星从天而降”与“我队友也在下面”之间自行完成一次简单逻辑推理。

天星 `defense_coefficient=0`，完全忽略属性防御，但仍受普通固定减伤、25% 下限、护甲与掩体
规则影响；它不是 `DIRECT_DAMAGE`。公演不追加第二次天星，只结算一次完整核心，并开放
舞台待遇与「群星」诗适配。

**石化**持续 `⟦bal:m9_talents_extended.t3.petrify_duration⟧` 个未来 R4 tick。石化者 T0 可：

1. 放弃本槽并保持石化，不获得 SP；
2. 每次花 1 SP，以 50% 概率挣脱，同一槽、同一全局轮最多尝试两次；成功后本槽仍可正常
   行动，失败后以 `petrified_hold` 收尾；
3. 等待被动解除：第一次有效伤害只获得“摇晃”，第二次有效伤害解除石化。

「群星」诗可把现存石化升级为**尘世之锁**：不再被攻击解除，只能自己挣脱或等到期；同一
T3 再次天星命中会把剩余时间刷新到基础持续时间，重复献诗本身不刷新。

### 9.4 T4「六爻」

选择另一名玩家猜拳，按组合结算六种结果。删除 charges 与轮次充能，只要 SP 和入口合法
就能演出。

| 组合 | 结果 |
|---|---|
| 双剪刀 | 潜龙勿用：选择玩家，造成穿甲伤害 |
| 双石头 | 飞龙在天：复制目标一件外层护甲，不破坏原件；复制耐久 `[待风洞]` |
| 双布 | 元亨利贞：免疫伤害与 debuff 到下一 R0；明文更高优先级效果除外 |
| 剪刀/石头 | 亢龙有悔：禁用一件非拳击武器；无可禁武器则施加震荡 |
| 剪刀/布 | 或跃在渊：父行动与反应栈结束后获得一个完整额外行动 |
| 石头/布 | 群龙无首：清除被发现/锁定并隐身，对手传送到随机地点 |

「阴阳」诗可以指定除或跃外的五种结果，或保留随机。G6 借用六爻若掷出或跃，必须重掷，
不能借别人的骰子给自己印一张额外行动券。

### 9.5 T6「朝阳好市民」

T6 的玩家规则见第七章。简记如下：

- 特别线索写入公开事件日志，只有存活/复活的 T6 能使用；
- 市民热线是任意地点可用的标准举报，不读 SP；
- 即演/公演核心是为现存警察更换一件白名单装备；
- T6 可以按普通规则申请队长，但没有就任捷径；
- 无合法案件时举报自然变窄，不会凭空生成一个倒霉蛋给你维持就业率。

### 9.6 T7「死者苏生」

即演或公演时，公开选择一名存活玩家，包括自己，挂载全局唯一的**保险伏笔**。无需去魔法
所学习，没有地点限制。伏笔不能被驱散、覆盖或重挂；T7 死亡后，已经挂好的保险仍存在。

目标死亡时按顺序处理：

1. 来源带 `absolute_death`：保险不赔付；
2. 目标自己的明文免死效果优先承接；
3. 否则保险承接普通死亡。

保险复活时，目标优先在家复活；家被毁则在效果结算位置，位置也不可站立时去最近安全地点。
复活 HP 为 `⟦bal:m9_talents_extended.t7.revive_hp⟧`，保留物品，恢复可再生的魔法护盾与 AT
力场，不恢复铁之荷鲁斯或一次性护甲；击杀与犯罪关系取消，PP/评分视为未死亡，SP=0。

兑现后伏笔消耗，T7 天赋永久落幕，不能再挂第二次。目标终局前没死，伏笔就留到终局。
「彼岸」诗会在保险复活后把 SP 置 2，并允许携带一件常规近战武器或普通护甲。

## 十、神代天赋 G0 至 G4

神代天赋不是为了少写规则而生的。它们会制造专属资源、例外、场景与结局，逼底层系统为
角色弧光让路。选之前先确认全桌愿意看这台演出机器启动；不然你演到第三页，别人已经在
旁边开第二局斗地主了。

### 10.1 G0「我还欠她们一个明天」砂狼白子*Terror

G0 使用 BLACK FANG 465（AR）替代弓。箭矢按候选比例转为子弹，弹匣与伤害 `[待风洞]`。
AR 与无人机协同时使用**神秘属性**：分别按普通、魔法、科技试算目标侧 H，选择 H 最高的
属性作为实际攻击属性，并用于伤害、护甲耐久与事件登记。

**即演：部署无人机。** 花 1 SP、一个标准行动槽与当前 HP 的
`⟦bal:m9_talents_extended.g0.drone_hp_cost⟧`，建立至多一个公开无人机。无人机无独立行动槽，
随 G0 每次重定位，持续 `⟦bal:m9_talents_extended.g0.drone_duration⟧` 个未来 R4 tick；G0
死亡、撤退或离开普通层时立即消失。攻击无人机不构成犯罪，但会给 G0 登记高影响关注。

**公演：无人机在场时二选一。**

- **十字炮火**：额外支付当前 HP 的
  `⟦bal:m9_talents_extended.g0.crossfire_hp_cost⟧`，对当前地点所有单位，包括 G0 自己，
  结算 `DIRECT_DAMAGE`；无人机消失。本效果不带 `absolute_death`。
- **遗物支援技**：花 HP、摧毁一件标有原持有者天赋的遗物装备，释放对应增强效果；无人机
  保留。它不是魂援，不占四次援助额度。

| 遗物来源 | 支援效果摘要 |
|---|---|
| T1 | 下一次 AR 攻击无视护甲并提高倍率 |
| T2 | 获得短时隐身 |
| T3 | 对地点造成天星式范围伤害与石化 |
| T4 | 获得一次否卦式伤害减半 |
| T6 | 生成临时演出警察，攻击同地点当前通缉目标后消散 |
| T7 | 一次性临时复活标记，致死时保留 1 HP |
| G1 | 地点范围伤害并施加灼烧 |
| G2 | 结算一次无持续 actor 的 `shadow_echo` 基础攻击追演 |
| G3 | 创建短时螺旋剑投影 |
| G4 | 获得余烬护甲 |
| G5 | 私人 `relic_memory` 增加；达到 12 可换一枚简化诗篇标记 |
| G6 | 在本次公演内结算一个可复制普通行动模板追演 |
| G7 | 获得按 HP 比例计算的短时掩体 |

G5 遗物的 `relic_memory` 上限 12；花满 12 只能从游侠、群星、阴阳、永恒、飞萤、追光、
明天中选一枚简化标记。它不授爱愿，不打开锚定互斥。

**调整呼吸**每局可用次数 `[待风洞]`：普通致命攻击来临时自动把 HP 锁到最低值，短时间
免疫普通攻击伤害和普通 debuff，但不免疫压制、自我怀疑或绝对死亡。到期时若未回满 HP，
G0 **撤退**：不死亡、不进往世层、不触发 T7、无击杀者、装备掉落、PP 冻结、终分按生者
公式 0.5，并为 G7 色彩贡献基础 +2。若已回满，则继续游戏。

「明天」诗令遗物支援技在标记存续期间不花 HP、不摧毁遗物，但仍需无人机、2 SP 与行动槽；
每件遗物对象只能享受一次保留。

### 10.2 G1「火萤·燃烧循环」

G1 在三种形态间单向推进：卸甲常态 → 次级燃烧 → 完全燃烧。

**卸甲常态**带有 `[待风洞]` 的命中/攻防负修正，但每轮可免费 `find` 一次。失熵以慢档增长；
若本行动回合没有做攻击类行动，可在 R4 **调息**降低失熵。这是唯一常规回落通道。

在 T0 花 1 SP 宣言着装，进入次级燃烧，**不消费标准行动槽**；主动卸甲免费。次级燃烧提供
数值强化，禁止普通 `find/interact`，解锁超新星过载，失熵增长加快。

**完全燃烧**只能以 2 SP 公演从次级燃烧进入，持续 `[待风洞]`。窗口内每轮 R0 自愈，并在
标准行动结束后获得一个 `restricted_followup`，只可 `move` 或 `attack`，每全局轮一次。
窗口到期强制卸甲并立即结算一次失熵；不能续杯或主动提前卸甲。

**失熵结算顺序**：可花 1 层炽愿完全抵扣 → 否则摧毁一件自选外甲 → 没有外甲时扣 HP。
失熵不是攻击，不触发反击、关注或犯罪。量表结算后回落 `⟦bal:m9_talents_extended.g1.entropy_reset_amount⟧`，
不是清零。

**超新星过载**在次级、完全燃烧或繁育时可由 `move` 根行动触发，对落点除自己外的玩家与
警察单位造成范围伤害、穿甲和灼烧。进入次级燃烧与击杀可获得过载，上限 1。超新星命中/
击杀产生炽愿。

**繁育**只在完全燃烧窗口内承受普通致死时触发，每局一次，替换并结束完全燃烧：

- 倒计时 `⟦bal:m9_talents_extended.g1.propagation_rounds⟧`，归零时绝对死亡；
- 每轮第一次合法 `move` 自动触发一次结构超新星，不读 SP、不占公演、不消费过载；
- 超新星结算后摧毁地点并驱逐幸存者；失熵停止；
- 繁育期间再次受到普通致死会正常死亡，T7 可以承接；
- 若最后一个对手先死亡，胜利检查优先于倒计时。

「飞萤」诗降低每个 R4 的失熵累积并加强调息，但不延长完全燃烧或繁育。

### 10.3 G2「请一直，注视着我」光影双身

G2 是一个玩家身份、两枚完整身体：光身 `G2:light` 与影身 `G2:shadow`。两者各有位置、HP、
装备、状态、先攻和标准行动槽；共享 SP、PP、信用点、评分、犯罪/通缉和天赋。按玩家结算的
效果只算一次，按单位/actor 结算的效果可分别命中两枚身体。

光身标准槽可花 1 SP 即演创建影身，或在取得公演位后花 2 SP 公演创建同一核心。影身固定
出生在光身地点，HP 为 `⟦bal:m9_talents_extended.g2.shadow_hp⟧`，空装备；创建当轮不补行动，
从下一 R1 开始独立排序。场上已有影身或永久资格已消费时不能创建。

影身可完整 `move/interact/find/lock/attack/forfeit`，能拾取、购买、装备和使用真实物品，也
能被攻击、治疗、控制、位移、偷窃、警察、NPC、AOE 与 G3 结界正常指定。它不能使用玩家级
天赋/SP、公演、魂援或额外领取每玩家收益。影身行为的费用和责任归 G2，但反击优先打影身。

影身没有自然时限。HP 归零或在自己的标准槽主动消散时，影身结束但 G2 玩家不死亡；光身
死亡则影身立即消散并结算 G2 玩家死亡。消散时若光身仍存活在普通层，可从影身持有物中
选择至多 `⟦bal:m9_talents_extended.g2.return_item_count⟧` 件合法实物跨地点归还光身，其余
全部掉在影身地点；物品不修复、不刷新、不复制。

#### 《世末歌者》

光身取得公演位且普通影身存活时，可在光身标准槽支付 2 SP 承诺终曲。支付完成后立即永久
写入 `shadow_creation_eligible=false`，影身转为终曲歌者；中断、击溃、复活、回溯、净化或
诗篇都不能恢复资格。歌者保留当前 HP、位置、装备和状态，但立刻失去当前/未来全部行动槽，
可被攻击、治疗、控制和强制位移，终曲区域随它移动。

终曲区域对所在地所有单位一视同仁：

- 攻击区域内单位时 A 获得 `terminal_vulnerability` 固定加值；
- 即将进入 HP 的伤害按 `terminal_damage_share_ratio` 抽出共享池，在区域所有存活 actor 间
  整数均分；总伤害守恒，不重复防御或共享，来源责任不变；
- G2 可在区域内一名非 G2 单位取得实际 ActionGrant 时，整首歌消费一次
  `ACTION_SUPPRESSED`，该槽仍正常 finalization；
- 区域内单位根 move 离开时，以 `terminal_move_redirect_chance` 概率把目的地改回歌者地点；
  强制位移、钩索、传送、回溯不掷。

终曲建立当轮不计；以后每个 R4 区域内有至少一名非 G2 存活 actor 时累计一个听众 tick。
达到 `terminal_witness_ticks` 后一次性登记 `g2_last_song_heard`，增加 arc_count 与完结条 PP，
但歌曲继续。旧全桌舞台、声部、Regard、物料牌与 G2×G5 duet 均不迁入。

### 10.4 G3「神话之外」投影固有结界

#### 资源与恢复

G3 使用**魔力**支付投影。开局魔力为 `⟦bal:m9_talents_extended.g3.magic_initial⟧`，上限
`⟦bal:m9_talents_extended.g3.magic_cap⟧`；不在结界内时，每个 R0 恢复
`⟦bal:m9_talents_extended.g3.magic_recover_r0⟧`。这是唯一常规恢复入口。SP 只决定何时能
公演展开结界，魔力只支付投影和维持，两者不能互相替代。

完整固有结界没有即演入口。结界外投影都是普通根行动，不消耗 SP，也不会附赠第二次攻击。

#### 结界外投影

结界外只有一个**持续投影通道**。双刀守势、七重圆环和复制武器会占用它；新持续投影创建
成功后，旧投影在本行动收尾时消失。预检失败不耗行动/魔力，也不会误删旧投影。螺旋剑和
双刀攻势是一次性攻击，不占持续通道。

| 投影 | 时机与目标 | 成本 | 效果 | 结束 |
|---|---|---:|---|---|
| 螺旋剑（伪） | 一个远程攻击根；选择一个合法目标 | `⟦bal:m9_talents_extended.g3.spiral_cost⟧` 魔力 | 基础伤害 `⟦bal:m9_talents_extended.g3.spiral_damage⟧`，命中 +`⟦bal:m9_talents_extended.g3.spiral_hit_bonus⟧`；只打所选目标，不溅射 | 本次攻击后消失 |
| 双刀·攻势 | 一个近战攻击根；选择面对面目标和一件合法近战武器，拳击也可以 | `⟦bal:m9_talents_extended.g3.dual_blade_cost⟧` 魔力 + 所选武器普通费用 | 基础伤害、属性、射程、命中取所选武器，本次攻击再加 `⟦bal:m9_talents_extended.g3.dual_blade_attack_bonus⟧` 攻击方固定值 | 本次攻击后消失 |
| 双刀·守势 | 一个非敌对标准根行动；目标是自己 | `⟦bal:m9_talents_extended.g3.dual_blade_cost⟧` 魔力 | 建立标记；下一次以 G3 为目标的合法攻击取得 `⟦bal:m9_talents_extended.g3.dual_blade_reduction⟧` 固定减伤 | 那次攻击无论命中、`A=0` 或 AREA 都消费；`DIRECT_DAMAGE` 也消费但跳过减伤；进出结界、死亡或本局结束也清除 |
| 七重圆环 | 一个非敌对标准根行动；目标是自己 | `⟦bal:m9_talents_extended.g3.rho_aias_cost⟧` 魔力 | 建立耐久 `⟦bal:m9_talents_extended.g3.rho_aias_durability⟧` 的普通 `COVERED`；远程直接攻击先打圆环，击破不溢出 | 耐久归零、G3 离开地点/死亡或被替换 |
| 复制武器 | 一个非敌对标准根行动；选择已解析的精确武器 ID | `⟦bal:m9_talents_extended.g3.copy_weapon_cost⟧` 魔力 | 创建临时基础型；本行动只创建，以后再用普通攻击根使用 | G3 死亡、主动解除或被替换 |

双刀守势不是“进入防御模式然后还能攻击”：建立标记本身就吃掉本轮标准行动。七重圆环也
不是免费反应；它同样要先花一个行动展开。两者都受公共 25% 伤害下限与 `DIRECT_DAMAGE`
规则约束。同一单位至多有一层 `COVERED`；圆环与警察/其他掩体比较耐久，只保留较大者，
不能叠成两层。

#### 武器解析与复制

普通武器攻击的**结算地点**是目标所在地点，远程攻击也看目标地点。G3 在结算时存活并位于
那里，且是承受者、旁观者或该武器的实际使用者，才在攻击完成后记录精确武器 ID。取消、
预检失败、天赋攻击、警察配装、神器与场景攻击都不能解析。

可复制对象关闭列举为：拳击、小刀、警棍、魔法弹幕、远程魔法弹幕、地震、地动山摇、
电磁步枪、高斯步枪、弓。复制品只保留**未升级、未蓄力的基础伤害、属性和射程**：

- MELEE/RANGED/AREA 射程照常，所以 AREA 基础型仍按普通范围攻击选目标；
- 不复制磨刀、弹药、蓄力、模块、耐久、震荡和特殊攻击模式；
- 电磁/高斯复制品不能蓄力；弓复制品不需要真实箭矢，也没有模块；
- 结界外基础伤害乘 `⟦bal:m9_talents_extended.g3.outside_copy_ratio⟧` 后 half-up；结界内用完整基础值；
- 复制品不可交易、拾取、转交或掉落，不增加地图真实装备供应。

#### 公演展开无限剑制

| 字段 | 规则 |
|---|---|
| 启动时机 | G3 取得本轮公演位，在自己的 T0 通过合法性预检 |
| 成本 | 2 SP + 本轮标准行动；不扣普通魔力 |
| 临时魔力 | 展开后取得 `⟦bal:m9_talents_extended.g3.public_temp_magic⟧`，普通魔力先花，临时魔力后花；退出清零 |
| 捕捉范围 | G3 当前地点的全部其他存活玩家，以及有独立行动的敌对/中立 NPC；警察不进入，不能挑人 |
| 主目标 | 展开时从其他存活被困单位中公开选一名；只供幻想崩坏使用。每个 G3 的 T0 可免费改选一次 |
| 初始配置 | 展开行动可免费创建兵装、防壁、剑阵中的一个合法通道；不附带攻击、移动、第二次演出或第二个通道。所选项不合法时可改选；全部不合法也照常完成结界展开 |

结界是对当前地点的隔离覆盖，不是新的五轮小游戏。全局 R0–R4、先攻、外部玩家和世界时钟
继续推进；被困者轮到自己时仍使用原来的一个标准行动槽，照常经过 T0/T1/T2。内外双方不能
互相移动、攻击、治疗、支援或交互，新到原地点的人留在外面。

与玩家来源绑定的附属物跟随所有者进入同一侧，例如 G0 无人机随 G0 入界/出界；附属物不能
留在外面跨边界协同，也不计独立捕捉人数。

警察不进入。若被困者是当前案件目标，只暂停与该目标有关的 R2 指派、追踪和案件时钟；
案件不会撤销或加速。结界解除后，从暂停前的 lead、位置与进度继续。结界内不能举报或命令
外部警察。

#### 被困者怎样破界

展开时系统创建一个公开场景物 **结界锚点** `barrier_anchor`，初始耐久为
`⟦bal:m9_talents_extended.g3.barrier_anchor_durability⟧`。它不是玩家或 NPC，没有 HP、护甲、
闪避、属性、行动、犯罪身份或反击。被困者有两种明确选择：

1. **用普通武器攻击锚点**：消费一个普通攻击根，照常检查射程并掷命中；命中后直接扣本次
   攻击方结果 `A` 点锚点耐久，不再计算目标侧 `H`。`A=0` 不扣；
2. **执行 `break_barrier` 破界**：消费整个标准行动，不要求武器、不掷命中，稳定扣
   `⟦bal:m9_talents_extended.g3.break_action_power⟧` 点耐久。

攻击/破界锚点不算伤害单位、犯罪、关注、击杀、反击、魂援或 PP；天赋攻击、直达伤害、
DOT、控制和环境伤害默认不能指定它。多人造成的耐久损失累积。耐久归零时，先做完当前根
行动与系统收尾，再解除结界；本轮尚未行动的人回到原地点后保留本轮标准行动，已经行动的
人不补发第二次；返回者继续按本轮原先攻顺序行动。七重圆环、剑阵和 G3 本体都不能替锚点
承接伤害。

被困者也可正常攻击 G3、七重圆环或拦截剑阵。普通移动不能越过边界，破界不是移动。

#### 三个投影通道

结界内可以同时存在一个兵装、一个防壁和一个剑阵。每个 G3 的 T0 可以免费**选择已经存在的
兵装**供本槽使用；这不创建投影也不攻击。除展开时的一次免费初始配置外，创建/替换投影仍
消费本轮标准行动与对应魔力。

| 通道 | 内容 | 规则 |
|---|---|---|
| 兵装 | 双刀、螺旋剑、一个复制武器 | 攻击仍只有一个载荷；复制武器创建与攻击分属两个行动 |
| 防壁 | 七重圆环 | 每个 R4 另加维持费；仍是普通 `COVERED` |
| 剑阵 | 弹道校正 / 拦截 / 崩坏准备三选一 | 创建或换型花一个行动及 `⟦bal:m9_talents_extended.g3.sword_array_cost⟧` 魔力 |

- **弹道校正**：G3 攻击命中 +`⟦bal:m9_talents_extended.g3.sword_array_hit_bonus⟧`；
- **拦截**：耐久 `⟦bal:m9_talents_extended.g3.sword_array_durability⟧`。每轮第一次以 G3 为目标
  的远程直接攻击先打剑阵，扣 `A` 耐久且不溢出；近战、同地点、AREA、环境与
  `DIRECT_DAMAGE` 绕过。剑阵先于七重圆环；
- **崩坏准备**：幻想崩坏获得 `⟦bal:m9_talents_extended.g3.sword_array_collapse_bonus⟧`
  攻击方固定值，没有其他常驻增益。

#### 理想燃烧与幻想崩坏

本次结界第一次成功使用下列每一种式样时，各登记一个唯一 ID：螺旋剑、双刀攻势、双刀守势、
七重圆环、每个不同的复制武器 ID、剑阵。剑阵换功能仍只算一种，重复创建同一式样不重复。
达到 `⟦bal:m9_talents_extended.g3.ideal_burn_styles⟧` 种后进入**理想燃烧**：后续投影创建费
减少 `⟦bal:m9_talents_extended.g3.ideal_burn_cost_reduction⟧`（最低 0），解锁幻想崩坏，并
在每个 R4 多付 `⟦bal:m9_talents_extended.g3.ideal_burn_upkeep⟧` 维持费。取消、预检失败或
没有完成创建/攻击的式样不登记。

**幻想崩坏**占 G3 的整个标准行动，要求存在存活主目标。它消耗全部剩余魔力、牺牲兵装/
防壁/剑阵，对主目标结算一次普通属性攻击：

```text
基础伤害 = collapse_base_damage
         + collapse_per_style × min(不同式样数, collapse_style_cap)
```

具体值读取 `m9_talents_extended.g3.collapse_*`。目标只计算一半普通属性防御，公共 25% 下限、
护甲与掩体照常；它不是 `DIRECT_DAMAGE`。攻击结算后无条件解除结界。魔力不足、锚点破坏或
G3 死亡造成的强制退出只清理，不免费补发幻想崩坏，也没有额外反噬伤害。

#### 维持与退出

建立当轮 R4 不收费。从下一个 R4 开始，在世界时钟与结界内其他持续 tick 之前支付：

```text
基础维持费
+ 其他仍在结界内的战斗单位数 × 单位维持费
+ 七重圆环维持费（若存在）
+ 剑阵维持费（若存在）
+ 理想燃烧维持费（若已进入）
```

各项读取 `m9_talents_extended.g3.barrier_*` 与 `ideal_burn_upkeep`。普通魔力先付、临时魔力后付；
不足时一分不扣，立即解除，然后继续该 R4。每次成功支付记一个 tick；达到
`⟦bal:m9_talents_extended.g3.max_barrier_rounds⟧` 后，即使仍有魔力，也在该 R4 其他持续
效果结算完、胜负检查之前强制解除。

幻想崩坏完成、维持失败、最大轮数、锚点归零、G3 死亡或终焉最高级事件都会解除。所有
退出路径只清理一次并把存活者送回展开地点；地点已毁则去最近安全地点，平局按地点 ID。
结界内已经发生的伤害、耗弹、状态、犯罪、SP 与关注都不回滚。震荡/石化使 G3 失去当前
受限槽的配置与主动终结机会；压制直接消费下一行动槽及该槽发动机会。控制不会自动关闭
结界，控制结束后的下一个合法 T0 才恢复正常操作。

「永恒」诗降低下一次结界的每轮魔力维持费，并让一名被捕捉者的第一个行动槽受震荡。

### 10.5 G4「愿负世，照拂黎明」救世主轮回

G4 人形态积累**火种**，上限 12。每轮最多从两个入口各取一次、合计 +2：第一次外来敌对
效果 +1，第一次外来正面转移 +1。合法攻击无论命中都算敌对；控制与 debuff 也算；DOT 后续
tick、环境伤害、自我代价不算。外部治疗、献诗、装备/资源转移算正面；自疗和自然恢复不算。

12 火种时，普通致死使 G4 进入完整救世主；不足 12 的普通致死进入残缺救世主并消耗现有
火种；0 火种也会进入残缺形态，按 `ember_floor` 视为至少 1 余烬。每次进入形态把 SP 设置为
2，不新增行动、不刷新关注、不自动报名。退出后火种归零，天赋不会永久失效。

救世主形态的普通攻击替换为单体强化普攻，不耗 SP，正常走攻击与犯罪结算，并获得毁伤。
**毁伤**只在形态内存在，退出清空；公演消耗的毁伤 D 同时成为天裁初始段数。

救世主公演按固定顺序结算：

```text
灾厄·弑魂焚诏
→ 全体秘密选择“攻击 / 拒战”
→ 攻击者按快照先攻降序、actor ID 依次执行挑战反应
→ 对攻击者均分固定总反击池
→ 对拒战者均分剩余段数形成的固定天裁池
→ 公演收尾
```

公演临时解决普通距离与面对面，但不穿透 G3 结界。所有被纳入者都有合法基础攻击载体：
优先选预结算 A 最高的当前合法攻击，完全没有时获得基础拳击。弹药照付，但挑战不产生犯罪、
SP、关注、额外行动或警务攻击额度。普通控制不阻止挑战响应，结构隔离和离场才会。

每完成一次挑战攻击，天裁段数−1，并把攻击者加入反击集合。反击与天裁都使用固定总池，不按
人数复制；均分余数按快照先攻降序、actor ID 分配。若所有人攻击，天裁被集体打断；若无人
攻击，只结算完整天裁。挑战攻击迫使 G4 退出形态时，立即停止后续响应，取消反击与天裁。

反击与天裁登记 `DIRECT_DAMAGE`；只有对某目标造成致死的天裁结果才附 `absolute_death`。

完整救世主持续 6 个未来 R4 tick，照常排公演 FIFO，不插队、不暂停倒计时。形态内普通致死
会被消费：无死亡、无击杀者、无往世层，以 1 HP 退出形态；绝对死亡则直接杀死。自然到期或
普通致死退出只清理形态、毁伤与火种，没有额外攻击或治疗载荷。

「负世」诗可尝试增加火种，并在满 12 时解锁主动燃尽：花一个标准行动进入完整形态，公共
收尾后 SP 置 2，再派发一个完整额外行动。该标准槽不返还。

## 十一、神代天赋 G5 至 G7

### 11.1 G5「往世的涟漪」

G5 开局不是德谬歌，而是有限寿命的**小昔涟**。小昔涟最大 HP 为
`⟦bal:m9_talents_extended.g5.cyrene_hp⟧`，可以正常移动、交互、寻找、锁定和攻击，但不能
锚定或献诗。每一世持续 `⟦bal:m9_talents_extended.g5.cyrene_life_ticks⟧` 个未来 R4 tick；
普通致死或到期都会回家，不算死亡，不建立击杀者、不触发 T7 或往世层，物品留在原地。
`absolute_death` 与绝对离场会跳过轮回，正常令 G5 出局。

小昔涟在普通层期间记录“值得记住的事”：地图任意地点每轮只要有一次攻击造成有效伤害，
就取得 `reminiscence_combat_gain`；若同轮小昔涟至少一次是有效攻击的攻击者或承受有效伤害
的目标，再取得 `reminiscence_combat_personal_bonus`。两项当前各为 1、可以同轮合计 2，
但都不能靠多段攻击重复刷取。摧毁/死亡/回家、所在地发生 B4 §3.2 PP 生成事件时分别取得
对应追忆；三类都没有时只取得少量空转追忆。回家后的下一
R0 才把这一世所得封存，
总上限为 `⟦bal:m9_talents_extended.g5.reminiscence_cap⟧`。封存追忆达到
`⟦bal:m9_talents_extended.g5.demiurge_birth_threshold⟧` 后可选择诞生德谬歌或继续培养；
达到上限或完成 `⟦bal:m9_talents_extended.g5.cyrene_max_incarnations⟧` 世时强制诞生。

德谬歌在 `home` 回到普通层并恢复普通基础 HP，但不捡回以前掉落的物品。此后追忆永远
不再增长：它是锚定与献诗共享的有限总预算。

**微澜**是一次性 1 SP 信息即演：选择合法可感知单位，公开其位置与装备；G5 对其无视
隐身与闪避，直到 G5 下一个实际 ActionGrant 收尾。每一世、德谬歌诞生时，以及德谬歌每次
未来闭合、因果改写或完成献诗后重开一次资格；锚定粉碎不重开，资格永不叠加。微澜不取物、
不增追忆、不伤害目标。

#### 方式一：锚定命运

仅德谬歌可锚定。她必须先报名并取得本轮唯一公演位，随后在本人 T0 花 2 SP、标准行动槽，
并公开选择
`⟦bal:m9_talents_extended.g5.anchor_min_k⟧` 至
`⟦bal:m9_talents_extended.g5.anchor_max_k⟧` 的 K；恰好支付 K 追忆，亲自填写 K 个基础行动：

```text
move(destination) / find(target) / lock(target) / charge(item)
interact(object, explicit_operation) / attack(target, explicit_weapon)
```

每项必须写全对象、武器、地点和交互动词。不能写条件、循环、天赋、诗篇、随机目标或“选
最优武器”。系统按顺序在只读副本中投影，缺前置就在首个非法槽拒绝；不会补 move/find/lock、
不会枚举路径，也不会创建现实行动。整条预检成功且至少产生一个高影响事件后，才消费费用
并建立只覆盖 G5 本人的快照。双人局可以锚定。

系统不询问玩家想要击杀还是获得，而是从每个动作的前后差分抽取：

- `DEFEAT`：唯一单位被击败；
- `DESTROY`：唯一对象被摧毁；
- `RELOCATE`：唯一单位/对象进入明确终点；起点只保留作审计记录；
- `ACQUIRE`：唯一可转移对象归 G5 持有。

建立当轮不 tick，之后每个未来 R4 推进一个脚本槽。候选事件若在自己的截止前由任何来源
真实发生，就算自然实现；位移只要求曾进入指定终点，不要求从投影起点一步直达，第三方
帮助也不会抢走锚定。若尚未发生，截止时用混合状态再投影：玩家写下的 find/lock/charge
与脚本局部位置视为已购买前置，实时读取目标防御、对象耐久/可转移性、目的地，以及来源
武器是否仍存在且由 G5 持有。仍会产生同一事件时，系统只强制写入事件差分，不执行基础
动作、不派发 ActionGrant；普通非槽位费用只在首个强制差分写入前按来源动作付一次，若
再投影直接失败则不扣，强制结果的击杀、犯罪、战果、PP、色彩与案件责任归 G5；同一攻击
强制破甲并击败可生成一次破甲击杀 PP。强制击败带 `absolute_death`。治疗、换甲、修理、
缴械、封路或摧毁物品等只要真的令同一动作不再产生该事件，就会改写因果并终止整条脚本。
G5 死亡或绝对离场则直接粉碎。

| 结果 | 条件 | 结算 |
|---|---|---|
| 未来闭合 | K 槽结束，全部候选已自然/绝对实现 | 安全窄回溯，水晶花 +1，记一次成功锚定 |
| 因果改写 | 某候选截止时无法由同一动作再产生 | 不回溯，水晶花 +1，取消后续候选 |
| 锚定粉碎 | G5 死亡或绝对离场 | 不回溯，无水晶花 |

成功后的**窄回溯**只恢复 G5 的 HP、位置、局部可恢复状态和仍由她持有的原装备槽位；不
回滚耐久、弹药、消耗品、PP、SP、追忆、行动槽、关注，也不复制被转走/摧毁的装备或删除
新取得物。水晶花在回溯后授予，终局只贡献 `arc_count +1` 的剧情分。
本局第二次未来闭合另完成一次 G5 完结条，增加一次独立 `arc_count` 并生成完结条 PP。

#### 方式二：献诗

仅德谬歌可以在取得本轮公演位后花 2 SP、标准行动槽与
`⟦bal:m9_talents_extended.g5.poem_cost⟧` 追忆献诗。
G5 选择持有对应天赋的玩家，授予一首诗，通常附带 6 个未来 R4 tick 的**爱愿**。爱愿不是
buff/debuff，不可驱散：持有者不能伤害 G5 或给 G5 debuff；G5 主动攻击持有者时爱愿立即
破碎，该次攻击照常。目标是 G5 自己或双人局时不施加爱愿。

激活中的锚定阻止献诗；G5 授予的活跃爱愿阻止锚定。爱愿到期后仍在等待的延迟诗篇标记
不会继续阻止锚定。十四首诗见第十二章。

德谬歌没有激活锚定且剩余追忆低于最小 K 时，下一 R0 自动闭合因果；也可在无锚定的本人
T0 主动放弃剩余追忆。她向过去永久退场，不死亡、不触发 T7 或往世层，物品留在原地，
PP 冻结；已经发生的锚定事件、诗篇/爱愿和水晶花继续存在。

### 11.2 G6「要有笑声！」

每个 R4，系统记录本轮已经完成收尾的公开标准根行动，并按类别去重。只记录 `move`、
`interact`、`find`、`lock`、`attack`；不记录原玩家、目标、武器、数值、战果、天赋被动、
演出、额外行动、反应、控制替代、起床、放弃、警察指令或未登记 special。默认保留上一轮，
第一轮池为空。

**即演**花 1 SP，从模板池选一个类别，以 G6 自己的位置、装备、资源、权限和新目标重新执行。
近战仍需面对面，买东西仍要有钱。责任、犯罪、关注与击杀归 G6；绝不继承原行动的天赋
倍率。别人上轮用 T1 砍人，你只能学会“攻击”，不能顺手把二倍伤害抄进作业。

**公演**花 2 SP，互斥二选一：

1. 借用一枚立即结算的白名单天赋核心；
2. 召唤一枚往世层援助，不花 PP、不占任何人的四次额度，提供者获得被动援助 PP。

| 可借来源 | 核心与限制 |
|---|---|
| T1 | 核心斩击，使用 G6 的武器、费用与责任 |
| T2 | 核心攻击，不带基础追猎移动 |
| T3 | 天星范围伤害与基础石化，不读取群星诗 |
| T4 | 六爻；或跃必须重掷，不授完整额外行动 |
| G3 | 只借单体螺旋剑，不借魔力、其他投影或结界 |
| G4 | 固定候选倍率强化普攻，不取得毁伤 |

T6、T7、G1、G5、G6、G7，多轮合同与完整额外行动来源都不可借。预检不合法时在消费
SP 前取消。借用只读来源玩家，不花来源的 SP、资源或责任。

「欢愉」诗把模板窗口扩到最近两轮，并使下一次公演顺序借用两名不同合格玩家/核心，至多
一个攻击核心；使用后或六个未来 R4 tick 到期后消耗。

### 11.3 G7「大叔我啊，剪短发了」

G7 的基础是一套会把规则书摊开占满半张桌子的装备、光环与 Cost 系统。它不是 SP 的附庸：
SP 负责演出，Cost 负责战术宏。

#### 融合、光环与 Cost

第一次同时持有盾牌与 AT 力场，自动融合为**铁之荷鲁斯**；第一次同时持有电磁步枪与高斯
步枪，融合为**荷鲁斯之眼**。每种融合本局只触发一次；守夜人恢复铁之荷鲁斯不会重新融合。

荷鲁斯之眼弹匣上限 8，使用普通/魔法/科技子弹，每发包含三颗弹丸。双融合完成后自动习得
战术指令，并获得两次自由配发：战术道具、药物或两发某属性子弹。

G7 有三层光环，每层提供 `⟦bal:m9_talents_extended.g7.halo_value⟧` 可再生护体值；同一时间
只恢复一层。三层首次全部点亮时获得一次战斗续行：普通致死时免死并把 HP 设为
`⟦bal:m9_talents_extended.g7.halo_revive_hp⟧`，随后永久失效；Terror 中不生效。

Cost 基础上限 `⟦bal:m9_talents_extended.g7.cost_base_cap⟧`，每个 R0 回满。上一轮使用过宏，
下一 R0 回满后因「失却汇流成泉」Cost−1，不叠加。G7 即演“小准备”花 1 SP 和标准槽，使
下个 R0 跳过这次−1。公演花 2 SP，打开魂援/PP 并免费取得一项战术道具或药物，不额外回 Cost。

#### 战术宏

持有两件融合装备时，用标准行动 `special Hoshino` 进入宏，按顺序执行直到 `terminal`。
每步即时扣 Cost；某步不足，宏在该步中断，已经执行的部分不回滚。

整个宏是当前标准 `ActionGrant` 内的一个复合根容器。射击、投掷、`find/lock`、冲刺等内部
步骤各自产生正常领域事件，并独立结算合法性、Cost、犯罪、关注、反应和命中；但内部步骤不
重进 T0、不创建新 `ActionGrant`、不打开普通追演或完整额外行动。整个宏只登记一次
`root_action_performed`，并只做一次根行动与系统收尾。

| 动作 | Cost | 效果 |
|---|---:|---|
| 架盾 | 2 | 铁之荷鲁斯插地，划分正面/背面 |
| 射击 | 2 | 消耗 1 发子弹，结算三颗弹丸 |
| 重新装填 | 0 | 摧毁有属性物品/护甲，填充对应属性子弹 |
| 持盾 | 1 | 展开可移动举盾 |
| 投掷 | 1 | 向地点投掷战术道具 |
| 服药 | 0 | 使用药物 |
| 冲刺 | 1 | 持盾移动，每宏一次 |
| 取消 | 0 | 取消架盾/持盾 |
| find/lock | 1 | 按常规结算 |
| 转向 | 0 | 翻转正面/背面与守点方向 |
| 排弹 | 0 | 重排弹匣，每宏一次 |

架盾时，正面裸伤不超过 `shield_block_threshold` 会被完全格挡；超过阈值则固定消耗铁之荷鲁斯
耐久并无效化剩余伤害。正面敌人正常离开需多花一回合；超新星、强制位移与 G6 模板位移
明文豁免。非水着-Shielder 每个 R4 为架盾支付 1 Cost。

持盾提供固定减法防御，再用盾耐久吸收伤害；击破时仍承接本次溢出。未架盾/持盾时，铁之
荷鲁斯仍提供较低被动防御并吸收伤害，保留将破耐久；之后才由光环、普通护甲与 HP 承接。

战术道具包括破片手雷、震撼弹、闪光弹、烟雾弹、燃烧瓶。药物包括 EPO、海豚巧克力与
全局一次肾上腺素。肾上腺素不占行动，下个 R0 把 Cost 回至临时高上限、恢复全部光环并
获得 D4 加成，覆盖失却汇流成泉。

#### 三形态

| 形态 | 特点 |
|---|---|
| 水着-Shielder | 起床得盾；架盾 R4 免费维持 |
| 临战-Archer | 起床有受限衔接；每两次付费射击后立即免费第三发 |
| 临战-Shielder | 起床恢复一层光环；宏内持盾冲刺后 find 成功会冲击、震荡并架盾 |

临战-Archer 的射击计数跨轮、跨宏保留，只统计付费射击；免费射击后清零。move、防御和换宏
不重置，只有非射击攻击或换形态重置。临战形态起床后可在同一槽内额外选择一次 move、
非敌对 interact、find 或 lock，不能攻击、演出、用宏或 special。

G7 可在家花一个回合换形态，不重复获得起床奖励。

#### 色彩、自我怀疑与 Terror

每名玩家以任何原因出局，G7 色彩 +2；若由 G7 击杀，再 +2。色彩 6 时，G7 可在自己的 T0
选择进入自我怀疑。色彩 10 后，本体受到非致死 HP 伤害时，恢复穿戴过且已破碎的护甲并强制
进入自我怀疑。自我怀疑消费下一行动槽，槽结束后转为 Terror。

Terror 的 Cost 为 Null，失去战术指令、道具、药物、铁之荷鲁斯和光环，只能 attack 或 move。
失去的护甲、荷鲁斯与光环按 `m9_talents_extended.g7.terror_*` 折算为额外 HP，至少达到
`terror_hp_floor`。

Terror 攻击只能使用制式荷鲁斯之眼，对地图上除自己外的所有**玩家单位**分别造成固定
`DIRECT_DAMAGE + absolute_death`；不读弹匣、不花子弹、不享受普通加成。若一击全歼，G7
立即胜利且不付自损；否则攻击后扣 Terror 额外 HP，归零时无击杀者地死亡。Terror move 后也
扣额外 HP。Terror 无法被举报，警察拒绝执法，也不参与即演或公演。

「守夜人」诗是预防性救援，不要求目标已在 Terror：接受后色彩永久置 null，恢复已有战术
可用性与光环；若当时确在 Terror，才解除 Terror 并把剩余额外 HP 转为永久 HP，再从永久
额外 HP 支付不致死代价。曾融合过铁之荷鲁斯则恢复到最低耐久，从未融合则不凭空创建。

## 十二、G5 十四诗篇

仅德谬歌可献诗，花 2 SP、`⟦bal:m9_talents_extended.g5.poem_cost⟧` 追忆和 G5 的标准行动槽。
目标必须持有诗所绑定的天赋；除 G5 自己和双人局
外，目标同时获得爱愿。同目标重复同一首诗通常只刷新时长或计数，不叠加数值；明确例外是
「爱与记忆」段数成长与「负世」自动燃尽加成。

### 12.1 原初诗篇

#### 献予「游侠」之诗（T1）

授予「游侠的锋刃」。下一次 T1 核心斩击**公演**可先 chase-move 到已锁定目标面前，再结算
面对面斩击。它不保证命中、不穿固定减伤，攻击仍走完整伤害管线。使用后消耗，无定时器。

#### 献予「地火」之诗（T2）

目标立即获得一个完整额外行动；若当前没有隐身，立即隐身。该额外行动内完成犯罪或发现
敌人时，必定触发一次由目标选择的 find/lock 追猎反应，不消耗 T2 基础每局一次额度。额外
行动结束后诗篇追猎失效；共同的每轮一个、禁止递归仍适用。

#### 献予「群星」之诗（T3）

授予「群星的弹射」。下一次天星公演命中后，可额外弹射两次，允许指定同一单位，每次造成
`poem_stars_bounce_damage` 无属性、`defense_coefficient=0` 的普通伤害，使用后消耗。

同时，把该 T3 当前仍存续的石化升级为尘世之锁：不被攻击解除，只能被锁者自己挣脱或到期；
同一 T3 再次天星命中会刷新基础石化时长，重复献诗不会。

#### 献予「律法」之诗（T6）

按 T6 当前状态只走第一条满足的分支：

1. 目标有当前通缉：立即结案并清除唯一通缉，不清犯罪/证据，不建立新案件，不绕过停机；
2. 队长空缺：满足资格时以诗篇时间戳进入候选队列，下一 R2 按公共排序决定；
3. 目标已是队长：威信 +2，并为一名现存警察配装一件；
4. 队长由他人担任：为一名现存警察配装一件。

本诗永不创建或复活警察，永不无视终焉。

#### 献予「阴阳」之诗（T4）

授予两个「阴阳的天机」计数。每次 T4 六爻公演可指定五种非“或跃在渊”的结果之一，或照常
随机；每次指定花一个计数。重复献诗把计数刷新到 2，不叠加。

#### 献予「彼岸」之诗（T7）

授予「彼岸的守望」。目标因 T7 保险复活时，复活后 SP 置 2，并可携带一件基础游戏目录内的
常规近战武器或普通护甲；不授额外行动。保险复活或终局时标记消耗。

### 12.2 神代诗篇

#### 献予「永恒」之诗（G3）

下一次固有结界公演每轮魔力维持费降低 `poem_eternity_cost_reduction`；展开时指定一名被
捕捉单位，其第一个行动槽受标准震荡。使用后消耗，不叠加。

#### 献予「爱与记忆」之诗（G5）

目标只能是 G5 自己，不施加爱愿。选定场上至多 n 个单体单位，可重复选择；每段造成
`poem_destiny_stage_damage`：前四段依次为科技、普通、魔法、无视属性，此后均无视属性。

初始段数按 2/4/6 人局为 2/3/4；每次使用后本局永久 +1，上限 6。消耗始终固定 12 追忆。

#### 献予「飞萤」之诗（G1）

授予六个未来 R4 tick 的「飞萤的回响」：每个 R4 降低本轮失熵累积，卸甲调息时额外提高
回落。它不延长完全燃烧或繁育。重复献诗只刷新时长。

#### 献予「欢愉」之诗（G6）

授予「欢愉的延展」：模板记录窗口延长到最近两轮；下一次 G6 公演可顺序借用两名不同合格
玩家/核心，至多一个攻击核心。增强公演使用后或六个未来 R4 tick 到期时消耗。

#### 献予「守夜人」之诗（G7）

目标必须主动接受；拒绝时追忆仍消耗，效果不发生。接受后：

- 色彩永久置 null；
- 若正在 Terror，解除 Terror，把剩余 Terror 额外 HP 转为永久额外 HP；
- 从永久额外 HP 扣除 `min(poem_watchman_spend_cap, 当前永久额外HP)`，不触及基础 HP；
- 本局曾融合铁之荷鲁斯则恢复并令耐久至少为 `poem_watchman_armor_restore`；从未融合不创建；
- 恢复指挥、医疗与战术装备可用性，但不返还已经丢失的物品；
- 光环恢复到初始层数。

Terror 不是施放前置。非 Terror 的 G7 接受后仍会清空色彩、恢复已有系统；只有解除 Terror
与额外 HP 转换需要目标当时处于 Terror。

#### 献予「追光」之诗（G2）

授予「追光的聚焦」。下一次普通影身攻击获得 `poem_spotlight_damage` 固定加值；若造成
有效伤害，攻击后为影身恢复 `poem_spotlight_shadow_heal` HP。若先承诺终曲，标记改为立即
治疗终曲歌者并消费；不再延长不存在的自然落幕。

#### 献予「负世」之诗（G4）

人形态尝试 +2 火种，但会消耗该轮外来正面来源资格，并受每轮总上限 2 截断；救世主形态
则把这份效果转为 `poem_burden_annihilation` 毁伤。

满 12 火种时解锁主动燃尽：花标准行动进入完整救世主，收尾后 SP 置 2，获得一个完整额外
行动。普通致死自动燃尽时，诗篇还会把额外火种转为毁伤；重复献诗可以按平衡键叠加这项
自动燃尽加成。标记在主动燃尽使用或终局时消耗。

#### 献予「明天」之诗（G0）

授予「明天的承诺」：遗物支援技不消耗 HP，且不摧毁遗物，而是把该遗物对象标记为已消费；
每件遗物对象限一次。仍需无人机在场、2 SP 和公演入口。标记持续六个未来 R4 tick 或三次
遗物支援，先到者消耗。

### 12.3 七枚简化标记

B4 的 G5 魂援与 G0 私人追忆只可调用以下七枚标记。它们不是献诗，不花追忆、不要求对应
天赋、不授爱愿、不打开互斥，也不会反向赋予天赋。

| 标记 | 唯一效果 |
|---|---|
| 游侠 | 下一次对已锁定目标的合法近战根攻击前，可 chase-move；移动和攻击须同时合法 |
| 群星 | 下一次攻击造成有效伤害后，对同地点一名合法单位追加一次无属性穿防普通伤害 |
| 阴阳 | 下一次自身根行动随机判定掷两次选一；会授完整额外行动的结果重掷 |
| 永恒 | 下一次支付非 SP 整数能力资源时降低成本，最低 0；不减 HP%、物品或行动槽 |
| 飞萤 | 下一次自身来源 HP 损失或持续伤害 tick 降低，最低 0 |
| 追光 | 下一次合法攻击获得固定加值；若攻击 actor 是接收者控制的存活代理，再治疗该代理 |
| 明天 | 下一次能力需摧毁自有物品或支付自身 HP 时，可免其中一项；其他费用照付 |

没有第八种“差不多也行”版本。标记等待事件始终未发生，就在终局过期。

### 12.4 非现行条目

- 献予「诡计」之诗：`retired`，旧 T5 不良少年已退役；
- 献予「旋律」之诗：`suspended`，尚无 T5 M9 定稿适配；
- G2×G5 duet：`suspended`，旧全桌舞台已冻结。

## 十三、新手指南

### 13.1 一局最短路线

1. **先起床。** 这是你第一个行动，不是教程建议，是规则。
2. **出门赚钱。** 商店与医院可打工，家中没有被动工资。
3. **准备一套能打人的东西。** 弓负责跨地点，近战先 `find`，护甲负责把对手的攻击变成
   你的维修账单。
4. **看 SP，不要只看血。** SP1 可以即演，SP2 可以选择立刻即演或排队公演。等公演不是
   必然更强，而是在等全桌舞台。
5. **关注世界时钟。** 白昼开始掉落，黄昏伤害上升，终焉会把“我再发育一轮”变成遗言。
6. **死后继续玩。** 普通死亡进入往世层；先判断谁值得押，再决定用援助挣钱还是背叛投资。

### 13.2 常见误解

**Q：先攻最低是不是又要轮空？**

A：不是。所有正常玩家都有标准行动，先攻只决定顺序。

**Q：SP 是行动点吗？**

A：不是。SP 只管天赋演出，不增加或删除标准行动槽。

**Q：公演是不是天赋加强版？**

A：核心通常相同。公演多的是魂援、PP、诗篇、追演和全桌镜头，不是稳定再打一遍。

**Q：`DIRECT_DAMAGE` 是不是必杀？**

A：不是。它跳过普通目标侧防御，但仍可被明文承接；是否跳过复活看 `absolute_death`。

**Q：普通死亡就没事做了吗？**

A：你只是从选手席去了证券交易所。`absolute_dead` 才是真正没有往世层操作。

**Q：为什么神代天赋这么长？**

A：因为它们的目标不是成为一排容易平衡的按钮，而是让角色在规则里留下清楚的轮廓。你
可以嫌它们麻烦，这很合理；你也可以选 T1，然后把复杂问题处理成一次近战攻击。

## 十四、术语与指令速查

### 14.1 术语

| 术语 | 含义 |
|---|---|
| 全局轮次 | 一次 R0→R4 的完整循环 |
| 行动槽 | 玩家本轮可执行一次行动的资格 |
| 根行动 | 本槽唯一的主要行动 |
| 追演 | 根行动内部的限定追加步骤，不重开 T0 |
| 完整额外行动 | 重新执行 T0→T2 的稀有白名单行动 |
| SP | 0/1/2 天赋演出准备度 |
| 即演 | 自己 T0 花 1 SP 发动完整核心，不享公演待遇 |
| 公演 | SP2 报名后取得舞台，花 2 SP 发动并打开舞台待遇 |
| PP | 生死共通的演出积分、消费与终分资源 |
| 关注 | 公开风险/焦点事件；通常使 SP+1，每人每轮最多一次 |
| 主目标 | G3 结界内公开指定的一个存活被困单位，只作为幻想崩坏目标 |
| 结界锚点 | G3 展开时创建的可破坏场景物；不是单位，没有 HP、犯罪或关注 |
| 破界 | 被困者消费整个标准行动、无需武器或命中的稳定锚点耐久削减 |
| A / H | 攻击方结果 / 最终进入目标侧的伤害结果 |
| 有效伤害 | H≥1 入 HP，或击破护甲/掩体 |
| `DIRECT_DAMAGE` | 令 H=A 的直达伤害身份，不自动绝对死亡 |
| `absolute_death` | 跳过普通免死与复活的来源标签 |
| `absolute_dead` | 绝对死亡终态，不进入往世层 |
| 爱愿 | G5 献诗契约；不是 buff/debuff，不可驱散 |
| 水晶花 | G5 锚定结果资产，终分登记 `arc_count +1` |
| 落幕 | 一次性天赋兑现后永久停止演出，但玩家仍正常行动 |
