### G0 砂狼白子*Terror `ShirokoTerror9`

- **决策点**：T0 `talent_t0`——无无人机且 SP≥1 → `即演·召唤无人机`（`m9_kind=g0_drone_summon`）；有无人机且 SP≥2 → `公演·十字炮火/遗物支援技`（`m9_kind=g0_performance`）；调整呼吸中 / 已撤退 / SP 不足 → 无 T0。choose 全部为**裸 prompt（无 situation 标签）**：`G0 公演：`（十字炮火 / 遗物支援技）；`遗物支援公演：`（追忆满 12 时：兑换简化诗篇（12 追忆）/ 使用遗物支援技）；`选择要摧毁的遗物装备：`；`选择简化标记诗篇：`（白名单：游侠/群星/阴阳/永恒/飞萤/追光/明天）；`回声追演：选择攻击目标`（G2 遗物）；`要有笑声模板追演：选择类别`（G6 遗物）。关联 special op：无（撤退是自动退场语义，不是命令）。
- **经济与门**：即演召唤 = 1 SP（`dispatch_improvise`，source_id=g0_drone）+ **20% 当前 HP**（half-up，至少 1）；公演 = 2 SP + 20% 当前 HP（需无人机在场，`_ensure_public_seat` 只消费 R0 已固化公演位 + `dispatch_public`，T0 不得临时报名；遗物支援技另需摧毁 1 件遗物装备）。**唯一自残天赋（§4.2）**：每次即演/公演都扣当前 HP 百分比——HP 成本致死走 `finalize_death(cause=g0_hp_cost)`，不算攻击、**不触发调整呼吸**，低血线反复发动 = 自杀风险门。AR 弹匣：BLACK FANG 465 上限 30 发，箭矢→子弹 1:3 转化，每次 AR 命中后 −1 发。
- **核心效果**：召唤无人机（`g0_drone:<pid>` 独立 actor，跟随 G0 地点，固定 3 轮、建立轮不 tick，可被攻击但不构成犯罪、为 G0 记高影响关注）；AR+无人机协同攻击变「神秘」属性（科技/魔法/普通三属性试算取目标侧最高 H）+ 无人机科技伤追加（`m9_prepare_outgoing` 编译 outgoing plan）；公演二选一：十字炮火（地点全员普通属性必中伤害、含 G0 自身、护甲可减免、无人机消失）/ 遗物支援技（摧毁遗物释放原持有者天赋的增强支援技、无人机保留）；调整呼吸 = 非 absolute_death 致死一次保命（HP 锁 1、免疫普通伤害/普通 debuff，2 轮；呼吸期内每次 forfeit 回 4，两次 1→5→9，T+4 未过最大 HP 的 40% 线 → 撤退）。
- **AI 注记**：G0 的好策略是**风险预算而非连招**：每次发动的 20% 当前 HP 成本使低血线发动在 §3.2 公式下 exposure（预期承伤增量）与 resource_cost 双扣，几乎必然亏；无人机价值 = 剩余回合期望 ×（1 科技伤 + 神秘属性选取收益）+ 迫使对手花费非犯罪代价打无人机（换 G0 高影响关注），且建立轮不 tick → 越早召唤越赚。遗物支援技是委托型交互（§4.2）：摧毁哪件遗物按被借槽策略评估，追忆满 12「兑换简化诗篇 vs 使用遗物支援技」是长周期价值折现。呼吸期 BasicAI 先 forfeit 到跨过 40% 止损线，再恢复主战/布局；撤退（is_awake=False、装备掉落、PP 冻结、无击杀关系）是失败态不是战术。世界援助「昨日的同伴」（星野战术压制/绫音急救）是黑马的世界规则遗产，G0 本人无决策权、不为其做预算。
- **决策示例（few-shot，召唤）**：
  - **场景**：SP=1、HP=5/20、无无人机、AR 弹匣 12/30，对手同地点且有护甲。
  - **推理**（引用 §3.2）：召唤成本 = 1 SP + `half_up(5×20%)=1` HP → 支付后 4/20。HP 成本门（§4.2）：当前 HP 百分比使低血线绝对成本小，但剩余血线越低 exposure 越高，且 HP 成本致死不触发调整呼吸；无人机价值 ≈ 每轮 1 科技伤 × 剩余轮数期望（建立轮不 tick ≈ 3 轮）+ 神秘属性对护甲目标的选取收益 + 对手打无人机的关注代价（§3.2 p_hit·E[damage] + control − exposure − resource_cost）。
  - **输出**：HP≥10 发动（10→8，留 2 次普通伤害容错）；HP<6 放弃（5→4 后任何普通致命伤都送进调整呼吸，失去输出节奏，且期间不能召唤/公演）；6≤HP<10 视威胁——无集火可发动，被集火则等一轮。

### G1 火萤IV型-完全燃烧 `G1MythFire9`

- **决策点**：T0 `talent_t0`——卸甲常态且 SP≥1 → `着装宣言：次级燃烧`（`m9_kind=g1_dress`，即演式，不消费行动槽）；次级燃烧 → `火萤宣言`（`m9_kind=g1_dress`，description 列出可用项）；完全燃烧 / 繁育形态 → 无 T0。choose 为**裸 prompt（无 situation 标签）**：`火萤宣言：` → `完全燃烧（公演 2 SP）` / `卸甲宣言（免费）`。关联 special op：无。
- **经济与门**：着装 = 1 SP（`dispatch_improvise`）；完全燃烧 = 2 SP 公演 + R0 已固化公演位（`_ensure_public_seat`），持续 `full_burn_rounds`（3）轮窗口，并即时回复 `full_burn_heal`（2）HP；卸甲免费；SP=0 → 无 T0。
- **核心效果**：四形态状态机（卸甲常态 / 次级燃烧 / 完全燃烧 / 繁育）+ 失熵量表：形态决定攻防修正与每轮失熵累积速率（卸甲 1 / 次级 2 / 完全 3），R4 达阈值 6 结算（炽愿抵扣 → 碎 1 件外甲 → 无甲扣 4 HP）；完全燃烧窗口内受普通致死 → 进入繁育（3 轮倒计时，归零**绝对死亡**，跳过 T7/保险）；繁育期每全局轮第一次合法 move 触发超新星：地点 AOE（8 伤、无视属性）+ 灼烧 + **地点摧毁（写 `m9_destroyed_locations` 事实）** + 逐出回 home（警察局被毁 → 警察永久停机）。
- **AI 注记**：G1 的策略核心是**燃烧节奏**（风筝循环：燃烧参战 → 撤离 → 卸甲调息 → 再燃烧）：着装抬攻击 +3 但失熵加速，卸甲常态是唯一失熵回落通道（免费 find 发育 + 调息 −1），§3.2 的 resource_cost 应把「SP 即演」与「失熵血线」一起折算。失熵量表是公开威胁时钟——对手会在接近阈值时集火逼你结算，好策略要在阈值前主动卸甲脱离。完全燃烧窗口内吃普通致死 = 必死的 3 轮繁育爆发，**触发权在对手手里**（RFC §5.2）：AI 应把它当「最后一搏 + 缩圈引擎」而非免死金牌；繁育倒计时归零是绝对死亡。超新星摧毁落点是全局缩圈策略（把对手往死角赶 vs 保留退路；home 永不摧毁），且每全局轮只触发一次——错过当轮第一次合法 move 不再补。
- **决策示例（few-shot）**：无（约定仅 G0 与 G3 卡各一例）。

### G2 神代天赋-请一直注视着我 `Hologram9`

- **决策点**：T0 `talent_t0`——显示名 `光影双身`（`m9_kind=g2_dualbodies`），description 按条件列出：可创建且 SP≥1 → `创建影身（即演 1 SP）`；可创建且 SP≥2 → `创建影身（公演 2 SP）`；有影身且非终曲歌者且 SP≥2 → `世末终曲承诺（公演 2 SP，永久锁死再造资格）`。choose 为**裸 prompt（无 situation 标签）**：`创建影身：` → `创建影身（即演 1 SP）` / `创建影身（公演 2 SP）`；**终曲承诺无 choose**——T0 执行即提交（条件已由 get_t0_option 门控）。关联 special op：无。
- **经济与门**：即演创建 = 1 SP（`dispatch_improvise`）；公演创建 = 2 SP + 公演位；终曲承诺 = 2 SP + 公演位 + **永久消费 `shadow_creation_eligible`（不可逆，回溯/复活不恢复）**；普通影身无限持续（无 R4 倒计时）。
- **核心效果**：一个玩家两枚完整 actor——光身 + 影身（`G2:shadow@<pid>`，存于 `state.m9_shadows`）：影身有独立标准槽、真实装备与物品，自下一轮 R1 进入先攻（创建当轮不补槽）；影身 HP 归零 = `SHADOW_DISSIPATED`（非玩家死亡：无 T7/往世层/击杀），至多 1 件实物归还光身、其余在影身地点掉落；终曲承诺把影身转 `TERMINAL_SINGER`（无行动槽、完整 unit actor）+ 建立**终曲区域**（写 `终曲区域` 世界事实）：全员易伤 + 伤害共享 + 一次压制 + 概率移动偏转；R4 听众 tick（区域有 ≥1 非 G2 存活单位）首次达 `terminal_witness_ticks`（balance 当前 1）→ `arc_count`+1 + PP。影身击杀光身补第二章（`arc.py` G2 分支），终曲事件给第三章。
- **AI 注记**：G2 决策分两层：①影身经济——SP/PP/信用点共享但身体资源（HP/装备）分离，影身是「第二行动力」也是「第二受击面」，创建时机 = 是否愿意把玩家风险摊到两枚身体（§2 交互矩阵 G2 行：W 影身 + W 终曲区域）；②终曲承诺是**不可逆高阶动作**（§4.2 从零写），永久锁死再造资格换区域效应 + arc/PP，必须在预期听众 tick 足够（区域内持续有人、能活到 3 tick）时才发动，不能用「SP≥2 就放」启发式。消散归还至多 1 件——贵重实物放在影身上要承担丢失风险（其余全部掉落）；攻击影身不算击杀分，但影身造成的伤害/击杀/犯罪全部归 G2。
- **决策示例（few-shot）**：无（约定仅 G0 与 G3 卡各一例）。

### G3 神话之外 `Mythland9`

- **决策点**：T0 `talent_t0`——结界展开中 → `固有结界·行动`（`m9_kind=g3_barrier_action`）；结界外且 SP≥2 → `展开固有结界（公演）`（`m9_kind=g3_barrier_expand`）；结界外且 SP<2 → `投影魔术`（`m9_kind=g3_projection`）。**全部 choose 经 `_choose` 助手带 situation `m9_g3`**（context: phase=T0）：结界外 `选择结界外行动`（展开固有结界/投影魔术）、`选择投影`（螺旋剑（伪）/双刀·攻势/双刀·守势/七重圆环/复制武器）、结界内 `选择结界内行动`（螺旋剑连发/**兵装攻击**（兵装池非空时，v0.3 §7.2）/剑阵/投影创建/破界 [+幻想崩坏 若合法]）、`免费初始配置`（兵装/防壁/剑阵）、`选择剑阵功能`（弹道校正/拦截/崩坏准备）、`选择投影创建`、`选择兵装`（兵装池成员）、`是否超限灌注（消耗临时魔力）？`（灌注/不灌注）、`是否继续连发？`、`是否结算终段幻想崩坏？`、`选择复制武器`、`选择目标`、`指定主目标`。关联 special op：**被困单位（非 G3）** → `special 破界`（固定 `break_action_power` 结构伤害、无武器）或 `special 武器破界`（武器攻击 A 直接扣锚点耐久，`special_op.py` 执行时再 choose 一次武器）——普通 move 离开被拦，这是敌人的反制通道，G3 自身无 special op。
- **经济与门**：结界展开 = 2 SP + 公演位（T0 不得临时报名），2 SP 转化为 `public_temp_magic` 临时超额魔力（仅结界内可用、退出清零）；**魔力账本**：普通魔力先付、临时魔力后付，两者不足则预检失败不扣任何魔力；结界外每 R0 恢复 1（cap 8）；投影只耗魔力不耗 SP（螺旋剑 2 / 双刀 1 / 圆环 2 / 复制 1 / 剑阵 2）；**兵装攻击本身不耗魔力/SP**（v0.3 §7.2：从兵装池取用已存在兵装，结算后保留）；**超限灌注**每次消耗 `armament_overload_cost`（2）点**临时魔力**（普通魔力不动），临时魔力不足则预检失败、攻击照常；**R4 维持费** = 基础 1 + 被困存活人数×1 + 圆环 1 + 剑阵 1 + 理想燃烧 1，建立轮不 tick，**不足不部分支付 → 强制解除**；硬上限 `max_barrier_rounds`（5）tick。
- **核心效果**：把当前地点替换为固有结界（写 `结界` 世界事实）：快照捕捉同地点其他存活玩家与独立 NPC（警察 / G0 无人机不捕捉），主目标公开指定，警察案件挂起（`suspend_for_barrier`），边界隔离（内外不能跨边界攻击/治疗/指定）；结界内沿用全局标准槽行动；螺旋剑连发（递增成本 + 赤原猎风：命中玩家 SP−1 + 移出公演队列）；**兵装池（v0.3 §7.2）**：结界内创建的双刀·守势/复制武器入池，`兵装攻击` 从池中任选一把结算（不重新投影/不付费、结算后保留；双刀 = `dual_blade_base_damage` 近战、复制武器 = 结界内基础值），可**超限灌注**（消耗 `armament_overload_cost` 临时魔力 → `armament_overload_bonus` 固定攻击方加值）；理想燃烧（3 种式样解锁）→ 幻想崩坏（消耗全部魔力、defense_coefficient=0.5 统一攻击主目标、结算后无条件解除）。
- **AI 注记**：G3 是唯一有**敌方反制通道**的槽——被困单位可攻击 G3、集火七重圆环/剑阵、或 `special 破界`/`special 武器破界` 拆锚点（锚点 10 耐久 / 破界每次 2 结构伤 ≈ 5 次即碎），因此展开时机 = 同地点人数与强度权衡：人多 = 更多可复制武器与式样，但维持费与集火压力同步上升（§9：一对多明显缩短结界寿命）。魔力预算决定一切（普通先付、临时后付、不足强制解除）：每轮 R4 前算清「维持费 vs 继续收益 vs 主动幻想崩坏」；**被强制解除没有终结攻击**（§8.2 主动终结 vs 资源耗尽），理想燃烧的额外维持费是倒计时——不要在「差一步崩坏」时把魔力锁进防守。幻想崩坏条件 = 理想燃烧 + 主目标 + 剩余魔力 ≥ 下限 2：要么提前终结，要么主动放人，最差是维持耗尽被强制解除。**兵装池 + 超限灌注（v0.3 §7.2）**：投影一次入池后兵装攻击免费取用——魔力只花在创造与超限，是「魔力锁进防守」的对冲：维持费吃紧时兵装攻击仍零成本输出。超限灌注是临时魔力的进攻出口（不用也随结界清零，存在「不用白不用」激励）：2 临时魔力换 `armament_overload_bonus` 固定加值，应投在斩杀线/高价值目标而非常规补刀；临时魔力同时是维持费兜底（后付通道），要预留「下轮维持费差额」后再考虑灌注。兵装攻击与螺旋剑连发共同登记理想燃烧式样——双刀/复制武器入池即多一式样，推进 3 式样解锁的节奏要算进「何时创建兵装 vs 直接连发」。
- **决策示例（few-shot，维持费 × 兵装池 × 超限灌注）**：
  - **场景**：结界已 tick 2（`barrier_rounds=2`，上限 5），账本 `magic=5/8`、`temp_magic=2`；被困存活 2 人（含主目标）；已建双刀（兵装池 = `["双刀"]`，无圆环/剑阵）、已进理想燃烧（式样 = 螺旋剑 + 双刀守势 = 2/3）；本轮 R4 将至，主目标 HP=4。
  - **推理**（引用 §9 魔力预算 + §7.2 兵装池/超限灌注 + §3.2 折算）：维持费 = 基础 1 + 人数 2×1 + 理想燃烧 1 = **4**；账本 5+2=7 ≥ 4 → 可付（普通 4 先付，临时 2 不动）。兵装攻击零成本（池中双刀 `dual_blade_base_damage`=3 近战）→ 每 T0 免费输出 3 伤；**超限灌注**：2 临时魔力 → +2 伤，刚好把主目标 HP 4 打到斩杀线（3+2=5 ≥ 4），但临时魔力也是下轮维持费兜底（若普通归零，临时 2 恰够下轮维持）——灌注会透支维持安全垫。
  - **输出**：本 R4 用普通魔力支付维持（临时 2 保留）；下一 T0 对主目标执行**兵装攻击 + 超限灌注**（5 伤斩杀）——若命中即完成终结前的关键削减，随后视破界压力决定是否主动幻想崩坏（式样 2/3，再登记 1 式样即解锁完整崩坏伤害）；若主目标未被击杀，下轮维持费优先动用普通魔力，临时魔力归零也不至强制解除。
