## 一、范围与继承规则

本合同冻结 T4、G4、T2、G6、G7 在 M9 行动底层上的第一批迁移语义，并登记 T5 不迁入 M9：
原 T5 槽位已经转为 G0。合同关闭旧 K 行动制留下的完整额外行动、轮空充能、借用行动者身份
和专用追加字段。它不裁决具体数值，不修改 V2 玩家手册，也不表示当前代码已经实现。

除本文明确覆写的部分外，五个活跃天赋继续继承上游合同：

- 每名存活玩家每轮取得一个标准行动槽，先攻只决定顺序；
- 即演、公演、自动转折和副舞台使用各自已批准入口；
- 完整额外行动只能由明文白名单的 `ActionGrant(kind=full_extra)` 创建；
- 同一玩家每轮最多取得一个完整额外行动，完整额外行动不得递归生成完整额外行动；
- 完整额外行动允许即演、禁止公演，不刷新关注或 SP 上限；
- 控制若消费行动槽，该槽及其发动机会一并损失。

本文引用的行动系统、结算合同与 G4 版本以当前 v0.8 / v0.3 / v0.3 为唯一对接目标，不再
保留旧版过渡执行分支。

## 二、公共派发顺序

天赋在行动中产生反应或完整额外行动时，统一按以下顺序结算：

```text
父行动效果
→ 系统收尾
→ 根行动收尾
→ 演出收尾（如适用）
→ 因父行动打开的合法反应栈
→ 反应栈清空
→ 派发合法的 full_extra ActionGrant
```

反应步骤不是行动槽，不得进入 T0，也不得自行创建完整额外行动。多个候选完整额外行动按
结算合同的来源白名单、每轮上限和深度规则过滤，不继承当前代码按字段检查顺序形成的隐形
优先级。

## 三、T4：或跃在渊

1. T4 删除 `charges`、轮次充能和以两个连续回合解释补偿的旧结构。
2. 正常随机得到或跃在渊时，只创建一个 `full_extra`；该授予在父行动及反应栈全部完成后
   派发。
3. 阴阳之诗只能主动指定其余五种结果，不能直接指定或跃在渊；正常随机仍可得到它。
4. 亢龙有悔原有的眩晕输出迁移为震荡。
5. 该完整额外行动遵循公共限制：允许即演、禁止公演、不刷新关注/SP 上限，被控制消费时
   直接损失。

## 四、T5：M9 退役登记

T5 combo 不迁入 M9。原 T5 槽位已由 G0 取代，因此 M9 不创建谱面、不判定 Perfect/Good/Miss、
不结算 FC/Clear，也不从 T5 授予 `full_extra`。现行 `v2exp` 的 T5 仍由其自身 profile 维护；
不得把该历史实现泄漏回 M9。

## 五、G4：燃尽转折

1. 濒死自动燃尽只完成形态转折（完整或残缺救世主），**不创建行动槽**，不授予完整额外
   行动。
2. 负世诗解锁的主动燃尽占用一个**标准行动槽**：完成形态转折；触发它的行动或伤害事件
   完成全部公共收尾后，将 G4 的 SP **设置为 2**（不是增加 2），然后在反应栈清空后派发
   **恰好一个**带来源的 `full_extra`（来源标记为 G4 负世主动燃尽）。
3. 该完整额外行动遵循公共完整额外行动限制：同一玩家每全局轮至多一个、立即插入、不得
   递归生成完整额外行动、允许即演、禁止公演、不刷新关注或 SP 上限；被控制消费时直接
   损失。
4. 负世主动燃尽已经消费的标准行动槽不会恢复；SP 置 2 这份就绪留到下一个合法 T0，而
   授予的完整额外行动立即插入在当前根行动及反应栈完成之后。
5. 自动燃尽若发生在 G4 本轮待执行的标准行动之前，可在之后的该行动使用 SP；若 G4 已经
   行动，则保留到后续轮次。
6. SP 置 2 不刷新本轮关注上限，也不自动报名公演。

救世主形态的完整机制（火种、完整/残缺形态、毁伤、焚诏拉条—反击—天裁、形态寿命与
退场技）由 [`m9_g4_savior_cycle_rfc_v0.3.md`](m9_g4_savior_cycle_rfc_v0.3.md)
定义；本合同只冻结燃尽转折在行动底层的槽位、SP 置位与 `full_extra` 派发语义。火种上限的
代码/数值信源漂移由 B2 或 B5 处理，不在本合同中顺带改值。

## 六、T2：关注与追猎反应

1. 删除犯罪、警觉和响应窗口创建完整回合的三条专用通道；T2 不因这些事件获得天赋专属
   SP 奖励。
2. 合法犯罪、高影响 `find`、成为 `find` 焦点只走普通关注规则，共享每人每轮最多 `+1 SP`
   的上限。
3. 伤人未杀免罪、攻击回盾和零击杀隐身仍是 T2 常驻身份。
4. 原隐藏响应收缩为整局一次的“追猎反应”：另一名玩家的公开根行动完成后，若 T2 能以
   自身状态合法地对该行动者执行 `find` 或 `lock`，可立即执行其中一个。
5. 追猎反应不得移动、攻击、进入 T0 或创建行动槽。费用、权限、犯罪、关注和结果全部归
   T2 自己。
6. 追猎反应完成后，才派发父行动产生的完整额外行动。

T2 的演出核心保持上游定义：即演攻击一个已发现或锁定目标；只有公演可取得追猎移动。

## 七、G6：类别模板重演与公演借用（镜像 G6 RFC v0.2）

1. 删除笑点、轮空充能、自愿放弃阈值、强制 D4/D6、借用其他玩家状态与责任的旧结构。
2. 每个 R4 从本轮已完成公共收尾的公开根行动中生成**类别模板**，并按行动大类去重。
3. 第一版正面白名单只有 `move`、`interact`、`find`、`lock`、`attack`。起床、放弃、控制替代、
   天赋演出、警察指令、副舞台和未登记 `special` 不进入模板池。
4. G6 选择模板类别后，必须以自己的位置、装备、资源、权限和合法目标重新选择参数。模板
   **不复制**原行动者、目标、武器、数值、战果、额外行动，**也不继承**任何原天赋被动、
   效果或数值。
5. 费用、犯罪、威信、关注、物品和击杀全部归 G6；重演动作是该行动槽的根行动。
6. 当前没有合法参数的类别不可选。所有类别都不合法时，在消费 SP 前取消演出。
7. 公演提供两条**互斥**路径，本次公演二选一，不叠加、不追加标准行动：
   - **路径一：借用一枚立即结算的白名单天赋核心**。白名单冻结为：T1 核心斩击；T2 无基础
     追猎的核心攻击；T3 天星；T4 六爻（或跃在渊结果重掷直到非或跃，**不产生完整额外
     行动**）；G3 仅简单投影；G4 强化普攻（固定候选倍率，不取得毁伤）。排除 T6、T7、
     G1、G2（完整影身/终曲不能在一次借用中结清）、G5、
     G6、G7 以及所有多轮/合同/完整额外行动来源。借用核心使用 G6 自身的资源、位置与目标，
     **不消耗来源玩家的 SP、资源或责任**。
    - **路径二：召唤一枚往世层援助**。不消耗 PP，不占 G6 或提供者的四次援助额度；
      提供者获得系统铸造的 `m9_system.pp.aid_passive_reward` PP。
8. 欢愉之诗只把模板窗口从上一轮扩展为最近两轮，并提供一次公演内顺序借用**两名不同
   合格玩家/核心**的能力，其中**至多一个攻击型核心**，禁止递归借用 G6 自己。
9. G0 的 G6 遗物支援不是即演（2026-08-09 B5 W10 裁决）：它在 G0 的本次公演内部结算一个
   G6 `copyable` 模板追演；不另收 SP、不进入 T0、不授予完整额外行动。

G6 的完整借用白名单、执行语义与案例见
[`m9_g6_cutaway_joke_rfc_v0.2.md`](m9_g6_cutaway_joke_rfc_v0.2.md)；本合同只冻结其在
行动底层的模板与借用边界，细节正文服从 G6 RFC。以后若开放警察指令或某项 `special`，必须
逐项加入正面 `copyable` 白名单。

## 八、G7：起床受限衔接

1. 临战-Archer 每次合法起床后，可在同一起床槽内执行至多一个 `move`、非敌对 `interact`、
   `find`、`lock`，或直接结束。
2. 这不是 `ActionGrant`，不重新进入 T0，也不能攻击、使用警察指令、`special`、即演或公演。
3. 若执行衔接动作，该动作是本槽唯一根行动，执行对应根行动收尾；整个槽仍只执行一次系统
   收尾，并登记 `resolution_kind=wake_followup`。
4. 单纯起床后结束登记 `root_action_performed=false`。
5. 光环、战术 Cost、宏疲劳、融合装备、弹药、色彩和 Terror 都是局部战斗资源或状态，继续
   保留，不统一改成 SP。
6. 铁之荷鲁斯零修复量但仍进入冷却的框架列入 B5 清理候选。

## 九、退役映射

| 旧结构 | B1 目标 |
|---|---|
| T4 `hexagram_extra_turn=2` | 单个带来源的 `full_extra` |
| T5 谱面、FC 与通用追加字段 | 不迁入 M9；原槽位转为 G0 |
| G4 主动燃尽后的补偿回合 | 占用标准槽完成转折；公共收尾后 SP 置 2，反应栈清空后派发一个带来源的 `full_extra` |
| T2 犯罪/警觉/响应完整回合 | 普通关注 + 整局一次追猎反应 |
| G6 轮空笑点和借用他人合法行动 | 自身状态重演类别模板；公演二选一（借用白名单核心 / 往世层援助） |
| G6 借用核心复制来源天赋数值 | 不复制天赋被动/效果/数值；T4 或跃重掷、无完整额外行动 |
| G7 起床后完整 T0/T1/T2 | 同一起床槽内一次受限根行动衔接 |
| G0 的 G6 遗物“免费即演” | 本次公演内结算一个 `copyable` 模板追演，不另收 SP、不进 T0、不授完整行动 |

## 十、实施与测试边界

B1 至此完成设计收口，B5 v0.4 W3/W12 已并入 v0.2，本版镜像 G6 v0.2；本合同没有授权把自身
写入 `v2exp` 手册或当前实现。以后进入实现批次时，至少需要合同测试覆盖：

- 反应栈先于完整额外行动，且同一玩家每轮最多一个、不可递归；
- T5 不出现在 M9 天赋池、谱面调度、完整额外行动来源或魂援来源中；
- G4 自动燃尽不创建行动槽；负世主动燃尽占用标准槽、在公共收尾后置 SP2，并在反应栈
  清空后派发恰好一个带来源的 `full_extra`；该 `full_extra` 遵循每轮上限、不可递归、
  允许即演、禁止公演；
- G0 的 G6 遗物支援只在其公演内结算一个 `copyable` 模板追演，不另收 SP、不进 T0、不授
  完整行动；
- T2 追猎反应的合法性、整局一次限制和责任归属；
- G6 模板记录、去重、参数重选、SP 保留和责任归属；借用白名单只读来源、T4 或跃重掷无
  `full_extra`、G2 不出现在借用 UI/兼容别名、往世层不耗 PP/无配额；
- G7 起床衔接只执行一次系统收尾。

下一批处理 T1、T3、T6、T7、G1；G4 救世主核心已由
[`m9_g4_savior_cycle_rfc_v0.3.md`](m9_g4_savior_cycle_rfc_v0.3.md) 承接，不重开
本合同已经冻结的行动时序。
