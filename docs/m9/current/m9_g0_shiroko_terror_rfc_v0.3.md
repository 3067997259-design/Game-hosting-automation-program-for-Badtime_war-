## 一、结论

G0 是 M9 新增的第八个神代天赋，填补原 T5 槽位。不同于其他原初/神代，G0 来自另一个时间线的阿拜多斯，
她的存在本身就是"跨越"。

核心机制：
- **BLACK FANG 465（AR）**：替代弓，箭矢转化为子弹，与无人机协同时属性为"神秘"
- **无人机召唤物**：消耗 SP + HP 召唤，可协同攻击或释放十字炮火
- **遗物支援技**：从已退场玩家遗留中拾取装备，可摧毁换取对应天赋的增强支援
- **调整呼吸**：濒死保护，HP 锁最小值并免疫普通攻击伤害与普通 debuff，未回满则退场
- **代价机制**：所有核心能力均消耗当前 HP%，体现"燃烧生命战斗"的主题

## 二、设计哲学

### 2.1 为什么是 G0

**身份定位**：
- **不是原初 T 系列**：白子*Terror 来自另一个时间线，不属于本世界的七个原初身份
- **先于神代 G1-G7**：G0 的"零号"代表她是"不在序列中的异数"，超越了神代编号体系
- **与 G7 星野的关联**：同为阿拜多斯成员，共享《Blue Archive》世界观，但白子来自更黑暗的分支时间线

**剧情背景**（基于搜索结果）：
- 白子*Terror 与 Phrenapates（主要反派）和 The Chroma 相关
- 她跨越时间线而来，背负着"已经失去的明天"
- 天赋名"我还欠她们一个明天"指向她已逝的同伴（阿拜多斯成员）

### 2.2 核心主题

| 主题 | 机制体现 |
|---|---|
| **跨越者** | 不使用弓（原初武器），而是 AR（另一个世界的武器） |
| **燃烧生命** | 所有核心能力消耗当前 HP%，越强的能力代价越高 |
| **死者的武器** | 拾取已退场玩家的装备，摧毁换取对应天赋的支援技 |
| **最后的呼吸** | 濒死保护机制，给自己最后的喘息空间 |
| **孤独的战斗** | 无人机是唯一的"同伴"，但也只是机械 |

## 三、常驻被动：BLACK FANG 465 与神秘属性

### 3.1 武器替换

**弓 → AR（突击步枪）**：
- G0 开局不持有弓，而是持有 BLACK FANG 465（AR，突击步枪）
- AR 初始弹匣：⟦bal:m9_talents_extended.g0.ar_magazine⟧（暂定 30 发）
- AR 射程：中远程（与电磁步枪/高斯步枪同级）
- AR 基础伤害：⟦bal:m9_talents_extended.g0.ar_base_damage⟧（暂定与弓相当）

**箭矢转化**：
- 所有"箭矢"类资源（find、交互、掉落）自动转化为"子弹"
- 转化比例：1 箭矢 = ⟦bal:m9_talents_extended.g0.arrow_to_bullet_ratio⟧ 子弹（暂定 3 发）
- AR 不能使用弓的升级模块（穿甲箭、火焰箭等），但可以正常装填子弹

### 3.2 神秘属性（协同攻击专属）

**触发条件**：AR + 无人机同时在场时，AR 的攻击变为"协同攻击"

**神秘属性效果（v0.3）**：
- 命中目标时，系统自动按三种属性（科技/魔法/普通）各自计算目标侧的最终造成伤害 `H`
- 选择**最终造成伤害最高**的属性作为本次攻击的**实际攻击属性**
- 该实际属性同时用于**伤害结算、护甲耐久结算与事件登记**（破甲/击破判定、属性相关事件），
  而不仅是伤害数字（v0.3）
- 属性选择在伤害结算前完成，目标无法预判

**示例（服从两阶段防御模型，2026-08-09 B5 W10 批准）**：
```
G0 攻击目标 A（持有科技护甲），攻击方阶段已得最终攻击伤害 A

系统分别以三种属性试算目标侧最终造成伤害 H：
- 科技属性：科技护甲对该属性有较高属性防御，H = 1.2
- 魔法属性：克制科技护甲，属性防御折半，H = 3.0
- 普通属性：无克制，H = 2.5

选择魔法属性，本次攻击的实际属性为魔法：
- 伤害按魔法属性结算为 3.0
- 目标护甲耐久按魔法属性结算（魔法克制科技护甲，耐久消耗照常）
- 事件（破甲/击破等）按魔法属性登记
```

**设计理由**：
- 神秘属性不是"第四种属性"，而是"智能选择最优属性"；
- 体现 AR + 无人机的协同智能；
- 避免被单一护甲完全克制——但**普通克制不把攻击归零**，每次试算都必须走完整的两阶段
  防御公式，不能在防御前按克制直接取 0（见 [结算合同 RFC v0.3](m9_resolution_contract_rfc_v0.3.md) §6.2）。

## 四、无人机召唤物系统

### 4.1 召唤规则

**消耗**：
- 1 SP + ⟦bal:m9_talents_extended.g0.drone_hp_cost⟧% 当前 HP（暂定 20%）
- 占用标准行动槽

**召唤限制**：
- 同时最多存在 1 个无人机
- 无人机持续 ⟦bal:m9_talents_extended.g0.drone_duration⟧ 轮（暂定 3 轮）
- **持续时间以未来 R4 tick 倒计时（v0.3）**：建立回合当轮（establishment R4）**不减计数**；
  自下一个 R4 起每个 R4 计数 -1，归零时无人机消失

**无人机属性**：
- 位置：与 G0 相同地点；**G0 每次重定位（move / 冲刺 / 位移类效果）时，无人机同步跟随每一次
  重定位**（v0.3）
- **消失条件（v0.3）**：除计数归零外，G0 死亡、撤退退场或离开普通层时，无人机立即消失
- 生命值：⟦bal:m9_talents_extended.g0.drone_hp⟧（暂定 5 HP）
- 可被攻击：其他玩家可以选择攻击无人机（视为独立单位）
  - 攻击无人机**不构成犯罪**（v0.3 明确）
  - **攻击无人机为 G0 登记"高影响关注"**（关注指向无人机所有者 G0，走关注/SP 结算，v0.3）
  - 无人机**不提供掩体保护、不具有警察身份**（不占警力、不提供警察掩体、不参与案件/执法，
    v0.3）
- 被摧毁：无人机 HP 归零时立即消失，G0 不受伤害

### 4.2 协同攻击

**触发**：G0 使用 AR 进行 attack 行动时，若无人机在场，自动触发协同

**效果**：
- AR 攻击属性变为神秘属性（见 §3.2）
- 无人机对同一目标附加 ⟦bal:m9_talents_extended.g0.drone_bonus_damage⟧ 点科技属性伤害（暂定 +1）
- 两段伤害独立结算（分别检查护甲、克制）

### 4.3 行为逻辑

**非玩家控制**：
- 无人机不占用独立行动槽（类似警察，但跟随 G0）
- 无人机不会主动攻击，只在 G0 攻击时协同
- 无人机不能执行 move/find/lock 等行动

**与警察系统的区别**：
| 项 | 无人机 | 警察 |
|---|---|---|
| 召唤者 | G0（玩家） | T6 或警察系统 |
| 位置 | 跟随 G0（每次重定位同步） | 独立地点 |
| 行动 | 协同攻击 | 独立行动槽 |
| 持续时间 | 固定轮数（未来 R4 tick） | 永久（直到死亡） |
| 目标选择 | G0 决定 | 系统决定 |
| 犯罪判定 | 攻击无人机不算犯罪 | 攻击警察算犯罪 |
| 掩体/警察身份 | 无 | 有（提供警察掩体） |

## 五、即演（1 SP）与公演（2 SP）

### 5.1 即演（1 SP）

**入口**：T0，1 SP 即演，占用标准行动槽

**效果**：召唤无人机（见 §4.1），消耗 1 SP + 20% 当前 HP

**设计理由**：
- 即演只提供召唤功能，不打开公演专属窗口
- 允许 G0 在战术窗口快速部署无人机

### 5.2 公演（2 SP）：十字炮火 or 遗物支援技

**入口**：T0，2 SP 公演，占用标准行动槽

**前置条件**：无人机必须在场（若无人机不在场，公演选项灰掉）

**效果选择**（二选一）：

#### 选项 A：十字炮火

- 消耗：2 SP + ⟦bal:m9_talents_extended.g0.crossfire_hp_cost⟧% 当前 HP（暂定 20%）
- 效果：无人机在当前所在地点释放十字炮火
  - 对该地点所有单位（含 G0 自己）造成 ⟦bal:m9_talents_extended.g0.crossfire_damage⟧ 点伤害（暂定 3 点）
  - 该伤害登记为 **`DIRECT_DAMAGE`**（[结算合同 RFC v0.3](m9_resolution_contract_rfc_v0.3.md) §6.6）：
    直接令 `H=A`，跳过属性防御、护甲与普通固定减伤；仍可被明文替身/重定向/绝对免疫承接，
    仍走普通伤害、关注与死亡流程，**不带 `absolute_death` 标签**
  - 无人机在释放后立即消失

#### 选项 B：遗物支援技

- 前置条件：G0 必须持有至少一件"遗物装备"（从已退场玩家遗留中 find 拾取的装备）
- 消耗：2 SP + ⟦bal:m9_talents_extended.g0.relic_support_hp_cost⟧% 当前 HP（暂定 20%）+ 摧毁该遗物装备
- 效果：释放该装备原持有者天赋的**增强支援技**（见 §6）
- 无人机继续保留（不消失）

**设计理由**：
- 十字炮火是高伤害 AOE，但会伤害 G0 自己且消耗无人机
- 遗物支援技需要特定条件（拾取遗物），但保留无人机且提供天赋特化效果

## 六、遗物支援技系统

### 6.1 遗物装备获取

**遗留机制**：
- 玩家退场（死亡/离线）时，其持有的装备掉落在当前地点，成为"遗留"
- 遗留装备可被其他玩家通过 find 拾取
- G0 拾取的遗留装备标记为"遗物装备"，记录原持有者的天赋

**标记规则**：
```
遗物装备 = 普通装备 + 原持有者天赋标签
示例：「星野的荷鲁斯之眼（遗物）」
```

### 6.2a G5 遗物：私人追忆池与简化诗篇（v0.3）

- G0 持有私人 `relic_memory`，上限 **12**；每次 G5 遗物支援技（§6.2 G5 行）使其 **+6**（暂定）。
- 当 `relic_memory` 达到 **12** 时，G0 可以在一次**遗物支援技公演**中**花费全部 12 点
  `relic_memory`**，为自己获得一首**简化标记诗篇**（reduced marker poem）。
- 只允许从 [B4 RFC v0.4](m9_pp_afterlife_betting_rfc_v0.4.md) 的 G5 援助可合格白名单中选取：
  **游侠 / 群星 / 阴阳 / 永恒 / 飞萤 / 追光 / 明天**（G5 诗篇全集见
  [G5 诗篇 RFC v0.1](m9_g5_poems_rfc_v0.1.md) §2.15）。
- **禁止选取**：爱与记忆（Love-Wish）、锚定类、地火（完整额外行动来源）、负世（完整额外行动
  来源）、彼岸、守夜人。
- 简化标记不要求 G0 持有对应天赋；精确触发、消耗和过期语义只按
  [G5 诗篇 RFC v0.1](m9_g5_poems_rfc_v0.1.md) §2.15，诗篇目标为 G0 自己。

**设计说明（2026-08-09 B5 修订）**：
- 遗物支援技强度高于魂援（因为需要摧毁装备 + 消耗 20% HP）；
- 效果主题贴合原天赋，但简化为单一增益；
- G5 支援技改走私人追忆池，避免无上限追忆；追忆池只服务 G0 自身献诗；
- **遗物支援技不属于魂援，不占 B4 四次魂援额度**：它是 G0 天赋自己的消耗（SP + HP +
  装备），只是强度参照魂援定价，实现者不得把它挂进魂援次数计数；
- G6 支援技是模板追演，不是即演、不是第二个行动槽、也不得递归再触发天赋；
- T6 支援技是临时演出警察，见 §6.4 与警察 RFC v0.3 §3.5。

### 6.3 `+20%` 联动的落点（2026-08-09 B5 W10 批准，v0.3 保留）

所有 G0/G7 之间的 `+20%` 联动（§8.3）以及遗物支援技内部的百分比放大，只作用于：

- 整数**伤害**（`A` 或 `H` 的最终值）；
- 整数**治疗**；
- **护盾 / 掩体耐久**；

最终四舍五入（**half-up，对半分时向上取整**）。**不得**增加持续时间、使用次数、SP、
Cost 或单位数量。持续轮数、层数、SP、Cost、召唤物数量等非数值项不受 `+20%` 影响。

### 6.4 与魂援 / 警察系统的边界

| 项 | 遗物支援技 | 魂援 |
|---|---|---|
| 触发 | G0 主动摧毁遗物装备 | 生者出价、死者接受 |
| 成本 | 2 SP + 20% HP + 装备 | 1-3 PP |
| 效果强度 | 增强版（比魂援更强） | 标准版 |
| 次数限制 | 无限制（只要有遗物），**但不占 B4 四次魂援额度** | 每局 4 次 |

| 项 | 临时演出警察（T6 遗物） | 固定警力 |
|---|---|---|
| 来源 | 遗物支援技一次性生成 | 开局建立的固定警力池 |
| 编制 | 不占编制 | 占编制 |
| 案件 | 不读取、不推进、不结案；只攻击**当前通缉**目标（v0.3） | 读取并推进当前通缉 |
| 处置 | 执行后立即消散 | 保留到死亡/终焉/停机 |

## 七、调整呼吸：濒死保护

### 7.1 触发条件

**受到致命攻击时**（会导致 HP ≤ 0 的伤害）：
- 自动触发"调整呼吸"
- 每局最多触发 ⟦bal:m9_talents_extended.g0.breath_max_uses⟧ 次（暂定 1 次）
- **`absolute_death` 不进入本触发器**：死亡阶段先检查来源标签；带 `absolute_death` 的
  致死结果直接进入结算 v0.3 的 `absolute_dead`，不消耗调整呼吸次数，也不改写为撤退

### 7.2 效果

**进入"调整呼吸"状态**：
- HP 固定为 ⟦bal:m9_talents_extended.g0.breath_min_hp⟧（暂定 1 HP，不能被进一步降低）
- 免疫**普通攻击伤害**与**普通 debuff**（石化、震荡、灼烧等）
- **免疫边界（v0.3）**：调整呼吸**不**免疫 `ACTION_SUPPRESSED`（压制）与自我怀疑——
  这些结构/最高级控制照常消费行动槽；状态已经建立后若再受到带 `absolute_death` 的致死
  结果，仍直接进入 `absolute_dead`，不走 §7.3 撤退
- 持续 ⟦bal:m9_talents_extended.g0.breath_duration⟧ 轮（当前 2 轮）
- **forfeit 回血（呼吸重设计，2026-09 风洞）**：呼吸期内每次选择 forfeit，
  恢复 ⟦bal:m9_talents_extended.g0.breath_forfeit_heal⟧ HP（当前 4）——进入时 1 HP，
  两次 forfeit 为 1 → 5 → 9
- **止损判定（呼吸重设计）**：触发后第 4 轮（T+4）检查 HP：
  - 若 HP > 最大 HP × ⟦bal:m9_talents_extended.g0.breath_recovery_threshold_pct⟧
    （当前 40%，即 20 HP 模型的 8 HP）：G0 正常继续
  - 否则：G0 立即撤退（§7.3）

**限制**：
- 调整呼吸期间，G0 可以正常行动（move/find/attack 等）
- 调整呼吸期间，G0 不能召唤新无人机（若无人机已在场则保留）
- 调整呼吸期间，G0 不能使用公演（十字炮火/遗物支援技灰掉）

### 7.3 撤退状态（v0.3 重写：退场语义收紧）

**"退场"不是"死亡"，而是"撤退"（retreat）**：
- G0 **不进入往世层**：不能投注、不能提供魂援/援助
- G0 **不触发 T7** 复活/保险流程，不计入击杀关系（最后攻击者不获得击杀数）
- 撤退后 G0 **不能行动、不能被指定为目标**（普通攻击/效果不再能以其为目标）
- G0 的 **PP 冻结**：不衰减、不可支出
- G0 的装备掉落为遗留（其他玩家可拾取）
- 终分按 [B4 RFC v0.4](m9_pp_afterlife_betting_rfc_v0.4.md) 评分公式计算，**存活系数取 0.5**
  （见 [评分指针 RFC v0.1](m9_pp_afterlife_scoring_rfc_v0.1.md)）
- 本局的世界援助可按
  [G0 世界援助合同 v0.1](m9_g0_world_poem_aid_rfc_v0.1.md)继续生效，但它是世界规则留下的
  机制遗产，**不恢复撤退 G0 的行动、目标资格、资源或决策权**；
- **计入 G7 色彩"玩家出局"（2026-08-09 B5 W10 批准）**：调整呼吸失败退场是玩家出局，
  按 G7 色彩累积规则为 G7 提供 +2 色彩（非 G7 击杀则无额外 +2，也不产生击杀者）；
  见 [G7 战术压制 RFC v0.3](m9_g7_tactical_suppression_rfc_v0.3.md) §二.6

**设计理由**：
- 调整呼吸体现"最后的喘息"，但不是免死金牌
- 若 G0 未能在止损窗口内把 HP 抬过 40% 线，则"燃尽生命"退场
- 退场不是死亡，避免与 T7 复活、往世层等系统冲突

结界内被指定并协同攻击；G0 返回时一并返回。无人机不能单独留在边界另一侧提供跨界攻击。

## 九、评分与终局

### 9.1 正常退场（撤退）与终局

- 进入往世层：❌ 否（G0 退场是撤退不是死亡）
- 计入击杀：❌ 否（最后攻击者不获得击杀数）
- 装备掉落：✅ 是（成为遗留）
- PP：冻结（不衰减、不可支出，v0.3）
- 终分计算：**改用 B4 评分公式**，存活系数 0.5（v0.3）
- G7 色彩"玩家出局"：✅ 计入（§7.3）

### 9.2 终分公式（v0.3 改用 B4 公式）

G0 不再使用自定终分公式。终分按 [B4 RFC v0.4](m9_pp_afterlife_betting_rfc_v0.4.md) 与
[评分指针 RFC v0.1](m9_pp_afterlife_scoring_rfc_v0.1.md) 的公式结算：

```
撤退/生者终分 = (剧情分 + 战果分) × 存活系数 + PP
```

- 存活系数：G0 撤退取 **0.5**
- 剧情分、战果分权重见 B4 评分指针
- 死者/往世层公式不适用于 G0（G0 不进往世层）
