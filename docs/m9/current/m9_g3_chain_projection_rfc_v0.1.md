## 一、结论

幻想崩坏从"爆气式一次性统一攻击"重置为"**连续投影（宝具连发）→ 终段崩坏**"两段结构：

1. 固有结界内，螺旋剑（伪）这类"创建并立即发射"的攻击型投影，在首发攻击载荷结算后，
   G3 可以支付**递增魔力**进入同一根行动内的 `projection_chain` 连发子循环，逐段连射；
2. 每根行动设有**累计耗魔计数器**；某次投影释放时累计耗魔达到阈值 X 后，该次及后续
   释放命中玩家单位时附加即时效果「**赤原猎风**」：目标 SP −1 并被移出公演队列；
3. 连射停止后，G3 可以选择结算**终段「幻想崩坏」**（沿用 G3 v0.2 §8.2 的统一攻击与
   解除结界语义），也可以保留结界继续。

**主题依据**：无限剑制是剑之丘陵的持续齐射，不是一发爆气；连发结构直接借鉴对象同时是
崩铁的红A（连续释放技能组），「赤原猎风」命名自红A专武。M9 有明确致敬对象的天赋几乎都是
理想主义者（阿拜多斯两位除外），SP 与公演队列正是"理想/舞台之心"的机制化身——见证理想
燃烧的地狱，就是被从舞台上刮落。

## 二、连续投影合同（结界内）

### 2.1 适用白名单

- **仅固有结界内**可用；结界外投影维持单发形态，保护结界外的魔力恢复经济（G3 v0.2 §3.3）。
- 第一版可连发式样**仅螺旋剑（伪）**；复制武器攻击是否加入连发名单待风洞，默认不可。
- 双刀、七重圆环、剑阵、初始配置等非"立即发射"式样不产生连发。

### 2.2 连发结构

1. 首个螺旋剑根行动按 G3 v0.2 §4.1 正常结算（若理想燃烧已激活，先应用 v0.2 §8.1 的
   投影创建费用减免；随后支付实际费用并进入 A/H 两阶段）；
2. 根行动的首发攻击载荷结算完成后，G3 可以选择支付递增成本，在同一根行动内追加一段
   同式样连发；
   逐段重复，直到段数用尽、魔力不足或 G3 主动停止；
3. 每根行动的追加连发段数上限 ⟦bal:m9_talents_extended.g3.chain_max_repeats⟧（首轮值 2，
   即单根行动至多 3 发）；
4. 第 n 段追加连发的魔力成本为
   `spiral_cost + (n−1) × ⟦bal:m9_talents_extended.g3.chain_cost_step⟧`
   （首轮 `step=2`，等于当前 `spiral_cost`，即线性递增；待风洞）；
5. `projection_chain` 是**关闭列举的根行动内部子循环**，不是行动 v0.8 §2.3 的普通追演，
   也不是 `ActionGrant`：不重新进入 T0、不产生行动槽、不刷新 SP/关注/公演/每轮上限、
   不授予完整额外行动。本文登记其为第一项根内连发白名单；行动 RFC 下次升版应收容该身份。
   启动连发子循环的根行动不能同时打开普通追演；若两者都合法（例如 G0 世界援助的星野
   追演），首发载荷后由玩家二选一，未选项整体丢弃。子循环结束后才进入根行动收尾；
6. 每段独立选择目标并逐段合法性预检：支付该段成本前先预检，预检失败则不支付该段成本、
   连射立即结束，已消费部分不返还；每段是完整的普通 A/H 两阶段攻击（属性普通，命中、
   护甲、掩体、25% 下限照常），不自创伤害乘区，不是 `DIRECT_DAMAGE`；
7. 各段的击杀、犯罪、关注与战果归 G3；关注登记照常。
8. 每段写入独立攻击事件，但整条连发只记一次 `root_action_performed`、只进入一次根行动与
   系统收尾。魂援、诗篇与其他"本次攻击"附加载荷默认只挂首发攻击，不复制到每个连发段，
   来源必须明文允许 `projection_chain` 才可例外。

### 2.3 累计耗魔计数器

每根行动从 0 开始累计 G3 在该根行动内**实际支付**的全部投影魔力（应用理想燃烧减免后的
首发费用与全部连发段成本）。计数器随根行动收尾清零，不跨根行动保留；结界维持费用、其他式样的
创建成本不计入本计数器。

## 三、「赤原猎风」即时效果

### 3.1 触发与内容

某次投影释放（根行动首发或连发段）时，若本根行动累计耗魔 ≥
⟦bal:m9_talents_extended.g3.chain_gale_threshold⟧（X，首轮值 6，待风洞），则自该次起、
本根行动内后续每次释放命中玩家单位时，附加即时效果「赤原猎风」：

- 目标 **SP −1**（下限 0；目标 SP=0 时该项无事发生）；
- 若目标在公演队列中，立即按行动 v0.8 §6.2 的失效移除纪律**移出队列**：目标若是本轮
  公演位持有者，则本轮公演位保持为空、不递补；目标若只是队列中的未来成员，则当前公演位
  不受影响。两种情况都属于永久移除，目标满足条件后可重新报名并从队尾排起。

### 3.2 性质与边界

- 「赤原猎风」是**即时效果**，不进入结算合同 v0.3 §3 的通用状态名录，不是控制状态，
  不被控制抗性/控制免疫拦截；
- 它与该次伤害同批次结算：明文替身、重定向或绝对免疫若承接了该次伤害，赤原猎风随之
  不生效；`A=0` 或未命中的释放不附加；
- **频率闸**：同一 `player_id` 每次结界至多被施加一次；同一根行动内不得重复施加。该频率
  是冻结结构，不作为数值旋钮；
- G2 光身、普通影身与终曲歌者共享同一 `player_id`、SP 与公演资格；命中任一身体都扣共享
  SP 并消耗该 `player_id` 本次结界的赤原猎风资格，不得借双 actor 重复扣减；
- 赤原猎风不额外登记第二次关注；关注仍只来自承载它的攻击事件；
- 本效果是 M9 首例**敌意 SP 扣减**与第二例**强制公演队列移除**（首例为失效检查）；
  行动 RFC 下次升版时应把"敌意 SP 扣减"收容为公共类目，本文先行登记。

## 四、终段「幻想崩坏」

连射停止后（段数用尽、魔力不足或 G3 主动停止），若理想燃烧已经激活（G3 v0.2 §8.1），
且 G3 仍有至少 ⟦bal:m9_talents_extended.g3.collapse_terminal_min_magic⟧ 点魔力（首轮值 2），G3 可以
选择在同一根行动内立即结算终段：

- 消耗全部剩余魔力、牺牲当前兵装/防壁/剑阵；
- 对主目标结算一次统一攻击：基础伤害 `collapse_base_damage + collapse_per_style ×
  min(不同式样数, collapse_style_cap)`（half-up），属性普通、`defense_coefficient=0.5`、
  正常进入 A/H 两阶段并应用以 A 为基准的 25% 下限，不是 `DIRECT_DAMAGE`；
- 剑阵"崩坏准备"的固定加值照常作用；
- 结算完成后无条件解除结界（G3 v0.2 §10.1 路径 1）。

G3 也可以选择不结算终段：结界与剩余魔力保留，维持费用照付；此后的标准行动仍可按
G3 v0.2 §8.2 的原始形态独立发动幻想崩坏（不要求先连发），但同样必须满足
`collapse_terminal_min_magic`。"主动终结与资源耗尽"的区分不变：被迫退出没有终结攻击。

## 五、与 G3 v0.2 的局部取代明细

| v0.2 条目 | 本版裁决 |
|---|---|
| §4.1"不是额外攻击，也不能在一次普通攻击后免费追加" | 结界外不变；结界内螺旋剑可按 §二进入付费 `projection_chain` 子循环 |
| §8.2"幻想崩坏占用 G3 自己当前的一个标准行动" | 保留独立发动路径；新增"连射后同根终段"路径（§四） |
| §8.1 理想燃烧（门槛/费用减免/R4 额外维持） | 不变；费用减免不作用于连发段成本（连发成本按 §2.2 公式独立计算） |
| §九 维持费用、§10.1 退出路径、§十控制边界 | 全部不变；连发不减免维持费，控制照常中断当前根行动（未结算的连发段随之损失） |
| §7.1 兵装通道 | 不变；连发不创建新的持续投影对象 |

  后续连发段随主动载荷一并截断。

## 七、待风洞数值与观察项

- `m9_talents_extended.g3.chain_max_repeats=2`、`chain_cost_step=2`
  （等于当前 `spiral_cost`）、`chain_gale_threshold=6`、
  `collapse_terminal_min_magic=2`（终段最低剩余魔力）；
- 观察项：单根行动总伤出（连发+终段）在 HP20 量纲下是否越过单回合击杀线；递增成本对
  魔力预算的实际约束；赤原猎风对公演队列的扰动频率；二人局与六人局差异；连发是否挤压
  防壁/剑阵的魔力份额（防守反制叙事是否保留）；
- 复制武器加入连发名单的候选评估。

## 八、验收场景（Given/When/Then）

1. Given 结界外；When G3 发动螺旋剑根行动；Then 单发结算，无连发提示。
2. Given 结界内、魔力充足；When 螺旋剑根行动完成；Then G3 可支付递增成本追加至多
   `chain_max_repeats` 段同式样连发，每段独立预检与选目标。
3. Given 某段连发预检失败；When 选择该段；Then 不支付该段成本、连射结束、行动槽已消费。
4. Given 本根行动累计耗魔首次达到阈值；When 该次释放命中 SP=2 且在公演队列的玩家；
   Then 目标 SP −1 并被移出公演队列，可按 v0.8 §6.2 重新报名。
5. Given 目标 SP=0；When 赤原猎风触发；Then SP 项无事发生，队列项照常检查。
6. Given G2 光身已在本次结界承受赤原猎风；When 后续释放命中其影身；Then 不再次扣共享 SP。
7. Given 理想燃烧已激活、连射停止且剩余魔力达到终段下限；When G3 选择终段；Then 消耗全部剩余魔力、牺牲三通道、
   对主目标统一攻击并解除结界；When G3 不选择终段；Then 结界保留、维持费照付。
8. Given 理想燃烧已激活但剩余魔力低于终段下限；When 连射停止；Then 不能白拿幻想崩坏，
   只能保留结界或按资源耗尽路径退出。
9. Given G3 在连发中途被压制；When 当前根行动被消费；Then 未结算的连发段与终段机会一并
   损失，结界按 §10.1 维持。
