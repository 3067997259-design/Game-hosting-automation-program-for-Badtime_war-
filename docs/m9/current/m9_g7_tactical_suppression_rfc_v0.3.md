## 一、结论

G7 忠实恢复手册（V2 玩家手册）当前语义——融合装备、光环、Cost 与「失却汇流成泉」、
战术宏及其消耗、正面/背面、战术道具与药物、被动保护、色彩反转与 Terror——并只做 M9
框架必需的最小适配（SP 演出入口、`DIRECT_DAMAGE` + `absolute_death` 登记、警察执法排除）。

新 G7 的规则命题是：

> **G7 以融合装备（铁之荷鲁斯 + 荷鲁斯之眼）为地基，用 Cost 驱动的战术宏实现持续战术压制。
> 每个 R0 回满 Cost，连续宏受「失却汇流成泉」约束。三形态提供不同的全局加成。Terror 作为
> 色彩 10 特判，失去一切变成纯粹破坏者。**

核心改动（相对 v0.2）：
- **忠实恢复手册机制**：融合、光环、架盾/持盾/被动保护、正背面、宏动作与 Cost、消耗品
- **恢复「失却汇流成泉」**：上一全局轮次使用过战术宏 → 下个 R0 回满后 cost -1；肾上腺素覆盖
- **Archer 第三发连续**：计数跨轮、跨宏持续，只在非射击类攻击或更换形态时重置
- **Terror 攻击制式化**：只用荷鲁斯之眼、只打其他玩家单位、`DIRECT_DAMAGE` + `absolute_death`、
  无普通加成、攻击后扣额外生命、全歼即胜不扣代价
- **警察拒绝目标/移动指令**：不主动靠近/攻击 Terror，拒绝队长攻击 Terror / 移动警察到
  Terror 所在地的指令
- **守夜人之诗**：改用作者手册救援版本原文，不改写 Cost 与爱愿赠礼

## 二、核心系统（手册语义忠实恢复）

以下系统按 V2 手册当前语义恢复，只标注数值待风洞。

### 2.1 融合装备

**融合一次性（v0.3 澄清）**：融合只在**第一次**同时持有对应组件时发生，且每件只触发一次；
由「守夜人」之诗恢复的铁之荷鲁斯**不会重新触发融合**。

**铁之荷鲁斯（盾）**：
- 第一次同时持有普通盾牌和 AT 力场时，自动融合为特殊无属性护盾「铁之荷鲁斯」
- 初始耐久：⟦bal:m9_talents_extended.g7.iron_horus_durability⟧（手册口径 20，数值待风洞）
- 受损后通过 `special 修复 <盾牌/AT力场>` 消耗一件盾牌/AT 力场修复
  ⟦bal:m9_talents_extended.g7.iron_horus_repair⟧ 点耐久（手册口径 +8），最高不超过上限
- 不处于架盾/持盾时的自动修复框架保留，但修复量现为 0，不依赖为续航来源（手册口径）

**荷鲁斯之眼（枪）**：
- 第一次同时持有电磁步枪和高斯步枪时，自动融合为特殊武器「荷鲁斯之眼」
- 初始不携带子弹，弹匣上限 8 发
- 3 弹丸射击系统与子弹类型（科技/魔法/普通）完全保留（手册口径）

**自动习得战术指令**：
- 完成双融合后，自动习得战术指令，并获得 2 次自由配发机会
- 每次可选择：1 个战术道具、1 种药物，或 2 发某属性子弹

### 2.2 光环系统（手册口径）

- 持有 **3 层**「光环」，每层点亮时提供 ⟦bal:m9_talents_extended.g7.halo_value⟧ 点可再生
  护体值（手册口径 3）
- 光环被消耗后黯淡并进入恢复队列；同一时间最多只有 1 层处于恢复中；当前冷却公式按存活
  人数自动计算
- 三层光环首次全部点亮时，获得一次性的「战斗续行」免死：受到致命伤害时自动免疫此次死亡，
  并将生命值设为 ⟦bal:m9_talents_extended.g7.halo_revive_hp⟧（手册口径 12）
- 触发后永久失效；**Terror 形态下不生效**

### 2.3 Cost 系统与「失却汇流成泉」（v0.3 恢复手册语义）

**Cost 池**：
- 特殊体力条 cost，基础上限：⟦bal:m9_talents_extended.g7.cost_base_cap⟧（手册口径 5）
- **每个 R0 回满到基础上限**（手册语义恢复）

**失却汇流成泉（v0.3 恢复）**：
- 若**上一全局轮次使用过战术指令宏**，则下一轮 R0 回满后 **cost -1**（不叠加）
- **肾上腺素可以覆盖这次代价**（见 §2.5）

**删除 v0.2 的"即演/公演驱动 Cost 回复"**：Cost 回复回到手册的 R0 回满制；即演/公演只
保留 M9 通用演出入口（见 §四），不再承担 Cost 回复。

### 2.4 战术宏系统（手册语义恢复）

**入口**：持有铁之荷鲁斯与荷鲁斯之眼后，在自己的标准行动回合使用 `special Hoshino` 进入
战术指令宏；系统逐条读取战术动作，直到输入 `terminal` 结束。

**执行规则**：
- 宏内动作按顺序执行并逐步扣 cost；某一步 cost 不足时，宏在该步骤中断，已经执行的动作
  不会回退
- **不需要 SP**，只要有 Cost 即可进入
- 整个宏是当前标准 `ActionGrant` 内的一个**复合根容器**，不会为内部步骤创建新的
  `ActionGrant`；宏结束时只登记一次 `root_action_performed=true`，并只执行一次根行动收尾与
  系统收尾。
- 每个成功执行的内部步骤仍产生其正常领域事件：射击/冲击产生攻击事件，投掷产生道具事件，
  `find/lock` 产生对应信息事件，冲刺产生移动事件。每一步独立进行合法性预检、支付 Cost 与
  普通资源，并独立结算犯罪、关注、反应、命中和“本次攻击”钩子。
- 内部步骤不是新的根行动：不重进 T0、不打开普通追演、不授予完整额外行动，也不触发
  “每个根行动一次”的钩子多次；宏内多个攻击事件仍各自触发“每次攻击”类钩子。

**宏动作与消耗（手册口径，数值待风洞）**：

| 动作 | cost | 效果 |
|---|---|---|
| 架盾 | 2 | 铁之荷鲁斯插地，划分正面/背面（§2.4a） |
| 射击 | 2 | 消耗 1 发子弹，3 颗弹丸各 2 点对应属性伤害（§2.4b） |
| 重新装填 | 0 | 摧毁 1 件有属性的物品/护甲，为荷鲁斯之眼填充 4 发对应属性子弹；超出弹匣上限丢弃 |
| 持盾 | 1 | 铁之荷鲁斯展开为可移动举盾（§2.4c） |
| 投掷 | 1 | 向指定地点投掷一个战术道具（§2.5） |
| 服药 | 0 | 使用自身携带的一种药物（§2.5） |
| 冲刺 | 1 | 持盾状态下移动到指定地点；每个宏最多 1 次 |
| 取消 | 0 | 取消架盾或持盾；也可通过宏外 `special 取消盾牌` 执行 |
| find/lock | 1 | 按常规 find/lock 结算；架盾状态下 find 成功把目标纳入正面 |
| 转向 | 0 | 架盾状态下翻转正面/背面，并切换"阻止离开/阻止进入"的守点口径 |
| 排弹 | 0 | 重排弹匣顺序；每个宏最多 1 次 |

#### 2.4a 架盾（cost 2）

- 将铁之荷鲁斯插入地面，划分「正面」与「背面」；当前地点内已存在的其他单位划为正面，
  之后进入该地点的单位默认划为背面；`find` 找到的目标额外归入正面，断开面对面关系后再次
  主动 find 归入背面
- 架盾期间，来自正面的裸伤若 ≤ ⟦bal:m9_talents_extended.g7.shield_block_threshold⟧
  （手册口径 6），被完全格挡；若超过该阈值，则铁之荷鲁斯扣除
  ⟦bal:m9_talents_extended.g7.shield_overflow_durability_cost⟧（手册口径 3）耐久并无效化
  本次剩余伤害
- 处于正面的敌人若想正常 move 离开，需要额外多花 1 回合；明确豁免只有超新星过载、
  强制位移与 G6 插入式笑话的模板位移，其他来源不得按相似措辞类推
- 架盾期间 G7 无法正常 move；每个 R4 最后检查一次维持 cost：水着-Shielder 免费，其他形态
  扣 1 cost；cost 不足、铁之荷鲁斯归零或陷入控制效果时架盾结束

#### 2.4b 射击（cost 2）

- 消耗 1 发子弹，使用荷鲁斯之眼射击；每发子弹包含 3 颗弹丸，每颗弹丸造成
  ⟦bal:m9_talents_extended.g7.eye_pellet_damage⟧ 点对应属性伤害（手册口径 2）
- **普通射击**：3 颗弹丸全部命中选定目标
- **持盾射击**：2 颗弹丸必中，第 3 颗有概率飞散
- **架盾射击**：正面只有 1 个目标时 1 颗必中、另外 2 颗各自可能飞散；正面有多个目标时
  选定目标至少吃 1 颗，剩余 2 颗在正面单位中随机分配
- **临战-Archer 额外射击**（§3.2）：不消耗 cost 和子弹；若触发破甲，不再追加旧版"真伤"，
  而是使目标最外层可破护甲额外失去
  ⟦bal:m9_talents_extended.g7.archer_break_armor_loss⟧ 耐久（手册口径 6）

#### 2.4c 持盾（cost 1）

- 铁之荷鲁斯展开为可移动举盾（priority 最高承接）
- 持盾时提供 ⟦bal:m9_talents_extended.g7.hold_defense⟧ 点减法防御（手册口径 5），随后用
  自身耐久吸收剩余伤害；若被击破，吸收本次溢出并结束持盾
- 持盾期间不能 interact
- 持盾**不会**因 R4 cost 不足自动结束，但会因铁之荷鲁斯归零、控制效果或 `special 取消盾牌`
  主动取消而结束

#### 2.4d 铁之荷鲁斯的被动保护

- 不处于架盾/持盾时，铁之荷鲁斯仍作为特殊防线介入伤害：先提供
  ⟦bal:m9_talents_extended.g7.passive_defense⟧ 点减法防御（手册口径 3），再用自身耐久吸收
  伤害，但保留 ⟦bal:m9_talents_extended.g7.passive_break_reserve⟧ 耐久作为将破保留线
  （手册口径 2）；溢出的部分优先由光环护体值吸收，再继续进入常规护甲与 HP 结算

### 2.5 战术道具与药物（手册语义恢复）

**战术道具（从军事基地获取；一个行动通常只能获取 1 样，最多同时持有 2 样）**：
- 破片手雷：造成小额普通伤害并施加「脆弱」，使后续破甲概率提高
- 震撼弹：对目标地点除自己外单位施加震荡；可作用于警察单位
- 闪光弹：造成致盲，目标在持续期间无法查看行动与状态；警察被致盲期间不自动攻击、
  不执行队长命令、不提供保护
- 烟雾弹：展开烟雾。进入烟雾获得隐身；其他单位在烟雾中不能 find/lock，已有 find/lock
  解除；警察在烟雾中不自动攻击、不提供保护
- 燃烧瓶：叠加灼烧，逻辑同 G1 火萤的燃烧体系
- 架盾状态下，道具只对执行结束时仍处于正面的单位生效

**药物（从医院获取；习得战术指令后当前实现不检查消费资格）**：
- EPO：立刻使 cost +1
- 海豚巧克力：恢复 1 层光环
- 肾上腺素：**全局仅能使用 1 次**，通过宏外 `special 肾上腺素` 注射，不消耗行动回合；
  下一个 R0 生效：cost 回满至 ⟦bal:m9_talents_extended.g7.adrenaline_cap⟧（手册口径 10，
  临时突破基础上限），所有光环立刻恢复，并获得 D4 +3；此后的 R0 恢复按基础上限回满，
  突破期间剩余的 cost 不因超出基础上限被扣除；**覆盖「失却汇流成泉」代价（v0.3）**

### 2.6 色彩反转与自我怀疑（v0.3 忠实恢复手册）

**色彩累积**：
- 场上每有 1 名玩家因任何原因出局：+2 色彩
- 该玩家由 G7 击杀：额外 +2 色彩
- **非击杀出局也计入**（2026-08-09 B5 W10 批准）：例如 G0 调整呼吸失败撤退属于"玩家出局"，
  为 G7 提供 +2 色彩，但 G7 非其击杀者则没有额外 +2，也没有击杀计数；
  详见 [G0 RFC v0.3](m9_g0_shiroko_terror_rfc_v0.3.md) §7.3

**色彩 6（v0.3 明确时点）**：
- 色彩达到 6 时，**在自己回合开始（T0）**可以选择是否进入「自我怀疑」

**色彩 10（v0.3 明确触发）**：
- 色彩达到 10 时，若本体生命值受到**非致死** HP 伤害，**在该伤害结算后立即触发**：
  不陷入眩晕，所有**穿戴过且已破碎的护甲恢复**，然后**强制进入「自我怀疑」**

**自我怀疑 → Terror**：
- 自我怀疑状态下，下一次行动回合被跳过
- 该回合结束时，反转为 Terror

### 2.7 Terror 系统（v0.3 制式化，忠实恢复手册 + 合同登记）

**Terror 形态**：
- cost 显示为 Null，玩家名覆盖为「星野-Terror」
- 失去所有战术指令、战术道具、药物、铁之荷鲁斯与光环，只允许执行 attack 和 move
- 进入 Terror 时，失去反转发生时的所有护甲与光环，并折算为额外生命值：每件护甲
  +⟦bal:m9_talents_extended.g7.terror_armor_per_piece⟧（手册口径 +3）；铁之荷鲁斯按剩余
  耐久 / ⟦bal:m9_talents_extended.g7.terror_horus_divisor⟧（手册口径 4）销毁并折算额外
  生命值；每层光环 +⟦bal:m9_talents_extended.g7.terror_halo_per_layer⟧（手册口径 +3）；
  若总额低于 ⟦bal:m9_talents_extended.g7.terror_hp_floor⟧，补正到该保底值（手册口径 12）

**Terror 攻击（v0.3 制式化）**：
- 固定且**只能使用荷鲁斯之眼**发起
- 目标：**地图上除自己以外的所有玩家单位**（不包含警察、无人机等非玩家单位，v0.3）
- 对每个合法目标分别建立 `A=⟦bal:m9_talents_extended.g7.terror_attack_damage⟧` 的同一批次
  攻击结算；不读取弹匣，也不消耗子弹
- 伤害身份：**`DIRECT_DAMAGE` + `absolute_death`**（[结算合同 RFC v0.3](m9_resolution_contract_rfc_v0.3.md)
  §6.6）——Terror 形态下挂载的复活不生效，生命值归零立即死亡
- **不享受任何普通伤害加成**（无普通增益、无属性克制）
- 伤害结算**后**扣除 ⟦bal:m9_talents_extended.g7.terror_attack_cost⟧ 点 Terror 额外生命值
  （手册口径 6）
- **若这一击已经全歼场上其他玩家，直接判定 G7 胜利，不再扣除代价**（v0.3 保留手册语义）
- 若未全歼且代价令 Terror 生命归零，G7 作为自我代价死亡，不生成击杀者

**Terror 移动（v0.3 明确代价）**：
- 移动完成后扣除 ⟦bal:m9_talents_extended.g7.terror_move_cost⟧ 点 Terror 额外生命值
  （手册口径 2）；不足以支付也可以移动，但归零后判定死亡

**警察拒绝目标/移动指令（v0.3 双侧登记）**：
- Terror 攻击正常违法，但无法被举报
- 警察不主动靠近或攻击 Terror，**也拒绝队长下达的攻击 Terror / 移动警察到 Terror 所在地点
  的指令**（同步到 [警察/T6 RFC v0.3](m9_police_t6_reset_rfc_v0.3.md) §3.6）
- **Terror 不参与即演/公演**，所有行动与现有设计保持一致

具体数值（额外生命折算、攻击/移动代价）待风洞。

## 三、三形态系统（手册语义 + M9 衔接）

### 3.1 百变星野（初始形态）

- 入场时选择一种形态；起床时的额外收益只在起床时结算
- 之后可在家中通过 `special 更衣 <形态>` 花费 1 回合换形态，但不会重新获得起床收益

### 3.2 三形态定义（手册语义恢复）

**水着-Shielder（持续进攻专精）**：
- 起床获得盾牌
- 架盾每个 R4 不扣 cost（免费维持）
- 适用于：守点 + 频繁中等宏进攻

**临战-Archer（远程火力专精）**：
- 起床后获得受限行动衔接（见 §五）
- **连续射击（v0.3 明确连续性）**：每完成 2 次付费战术「射击」，第二次结算后立即对一名
  当前合法目标追加 1 次免费射击；免费射击不消耗 cost 与子弹、弹丸不飞散、有破甲概率
  （破甲使目标最外层可破护甲额外失去 6 耐久）
- **连续计数跨轮、跨宏持续**：只统计付费「射击」；免费射击不计数。免费射击结算后计数
  清零。计数器还会在发生**非射击类攻击**或**更换形态**时重置；move/防御/换宏不重置
- 适用于：远程输出 + 快速准备

**临战-Shielder（突击防御专精）**：
- **起床恢复 1 层光环**（v0.3 恢复手册）
- **起床衔接（v0.3 恢复手册）**：持盾状态下，若一个战术宏中**先冲刺、再 `find` 成功**，
  可**自动冲击并震荡目标**，随后**进入架盾**
- 架盾/持盾正面减伤与光环恢复按手册口径
- 适用于：近战突击 + 坚固防御

## 四、SP 适配（M9 通用演出入口）

G7 的战术系统已按手册语义恢复（Cost 每个 R0 回满、失却汇流成泉、肾上腺素）。M9 通用 SP 层
只提供演出入口，**不改写手册机制**：

### 4.1 即演（1 SP）

**入口**：T0，1 SP 即演，占用标准行动槽

**效果**：下个 R0 不受「失却汇流成泉」影响（cost 回满后不减 1）。这是 G7 的"小准备"，
让连续宏不被惩罚打断。仅此而已，没有其他特殊能力。

### 4.2 公演（2 SP）

**入口**：T0，2 SP 公演，占用标准行动槽

**效果**：
1. 打开魂援/PP 调用点
2. 免费获得一项补给：一个战术道具（手雷/烟雾弹/闪光弹/燃烧瓶）或一种药物
   （EPO/海豚巧克力/肾上腺素），直接加入携带物品，无需回家
3. Cost 回复由手册的 R0 回满制承担，公演不额外叠加

### 4.3 战术宏（不需要 SP）

- 在自己的标准行动回合选择"战术宏"，使用 `special Hoshino` 进入
- 只要有 Cost 即可使用（§2.4）；逐步执行并扣 cost，不足则中断
- 与其他天赋的区别：T1 公演 = 核心斩击（直接攻击）；G7 公演 = 补给 + 魂援窗口，真正的战术
  在"战术宏"中

## 五、起床衔接（B1 已定 + v0.3 恢复手册收益）

### 5.1 临战-Archer / 临战-Shielder

起床后可在同一个起床槽内选择执行至多一个：
- `move`
- 非敌对 `interact`
- `find`
- `lock`
- 或结束行动槽

**不能**：攻击、使用战术宏、即演/公演、`special`。

**专属起床收益（v0.3 恢复手册）**：
- 临战-Archer：无额外行动（旧"1 个额外行动回合"已被 M9 白名单删除），但**连续射击计数不因
  起床重置**
- 临战-Shielder：**恢复 1 层光环**（手册语义恢复）

### 5.2 水着-Shielder

- 无受限菜单（正常起床）；起床获得盾牌，架盾每个 R4 免费维持（§3.2）

## 六、典型战斗流程

### 6.1 水着-Shielder 守点流程

```
R1: 公演（拿烟雾弹，打开魂援窗口）
R2: 战术宏（5 Cost）：架盾 → 射击 → 投掷烟雾弹
    正面划分，本地点获得烟雾掩护
R3: 即演（下个 R0 豁免失却汇流成泉）
R4: 战术宏（2 Cost）：射击 → 转向
    持续守点输出
R5: 即演（下个 R0 豁免）
R6: 战术宏（2 Cost）：射击 → 取消
    ...
```

**特点**：架盾免费维持 + 连续宏；依靠即演豁免失却汇流成泉。

### 6.2 临战-Archer 远程流程

```
R0: 起床（受限行动衔接）
R1: 公演（拿手雷，打开魂援窗口）
R2: 战术宏（5 Cost）：射击 → 射击（第二次结算后自动免费射击）→ 投掷手雷
    远程清场；连续计数跨轮保留
R3: 标准行动 move（调整位置；非射击攻击不重置计数，move 不重置）
R4: 公演（拿肾上腺素）
R5: 战术宏（4 Cost）：射击 → 射击（第二次结算后自动免费射击）
    持续远程压制；计数仍在延续
```

**特点**：快速准备 + 远程输出稳定；第三发连续计数跨轮、跨宏持续。

### 6.3 临战-Shielder 突击流程

```
R0: 起床（恢复 1 层光环）
R1: 公演（拿肾上腺素）
R2: 战术宏（5 Cost）：持盾 → 冲刺 → find（成功 → 自动冲击并震荡目标）→ 进入架盾
    冲脸震荡，随后架盾建立正面
R3: 标准行动 attack（受震荡影响，对手下轮受限）
R4: 使用肾上腺素（下个 R0 cost 至 10，覆盖失却汇流成泉）
    战术宏（5 Cost）：架盾 → 射击 → 取消
    连续突击
```

**特点**：起床光环 + 冲刺-find 自动冲击震荡 + 正面防御。

献予「守夜人」之诗

### 8.2 Cost 计算（v0.3 手册模型）

```python
# 每个 R0 回复 Cost（手册：回满基础上限；失却汇流成泉 -1，肾上腺素覆盖）
def restore_cost_r0(player):
    player.cost = player.cost_cap          # 手册：每个 R0 回满基础上限
    if player.adrenaline_active:           # 肾上腺素（全局一次）覆盖
        player.cost = player.adrenaline_cap # 临时突破基础上限
        player.halo = player.halo_max      # 所有光环立刻恢复
        # +D4 3 由掷骰层处理
    elif player.ignore_lost_spring_next_r0:
        player.ignore_lost_spring_next_r0 = False  # 即演豁免只消费一次
    elif player.used_macro_last_round:
        player.cost -= 1                   # 失却汇流成泉（不叠加）
```
