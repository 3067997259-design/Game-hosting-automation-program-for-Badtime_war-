## 一、重置目标

警察应是一股由案件驱动、任何玩家都能唤起但不能免费占有的中立公共力量。举报、T6 和
队长分别负责不同层次：

| 身份 | 核心问题 | 可以做什么 | 不能做什么 |
|---|---|---|---|
| 举报者 | “谁应被追缉” | 用证据建立合法通缉 | 精确操控警察 |
| T6 | “案件怎样被发现、警力怎样整备” | 远程举报、特别线索、警察配装 | 免费代替队长下令 |
| 队长 | “警力此刻怎样行动” | 改派、移动、攻击、唤醒 | 凭上任生成新警力或无责任滥权 |

当前实现把举报者连续消耗在“举报—集结—追踪”中；队长上任却生成三名全新警察、关闭
举报并取得完整指挥权。T6 又只获得若干权限补丁，其中远程举报因接口命名不一致而无法
通过真实合法性检查。本稿不保留这种“举报是低配流程、队长是完整模式”的二元结构。

## 二、案件状态机

M9 只保留四个玩家必须理解的概念：

```text
犯罪事实 / 线索
  → 举报并建立通缉
  → 警察自动出动
  → 执法或结案
```

### 2.1 事实、线索、通缉与结案

- 犯罪事实负责记录已经发生的行为；它不等于警察立即取得攻击目标。
- 举报把一份合法证据转化为当前通缉。第一版原型只保留**一个当前通缉**，不建立多案件
  队列。
- **证据资格关闭列举**为四类：
  1. **受害者**（对自身的伤害/袭击事实）；
  2. **事件发生时同地点的目击者**；
  3. **系统归因的探测器**（detector 类效果归因的来源）；
  4. **T6 特别线索**。
  不允许无证据点名任意玩家，也不开放第五条自由证据类别。
- **活跃通缉期间的举报前检**：已存在当前通缉时，新的举报尝试在**合法性前置**即失败——
  不消耗证据、不消耗举报者的标准根行动，也不产生新的案件或线索消费。
- **结案条件关闭列举**：当前通缉只能因下列事件之一结案：
  1. 目标死亡；
  2. 目标**绝对离场**；
  3. **队长合法解职**（按 §4.3 合法撤销通缉）；
  4. **警察局被摧毁停机**（§3.4）；
  5. 系统进入**终焉停摆**；
  6. G5「律法」之诗的明文覆写：立即清除唯一当前通缉并结案，但**不清除犯罪记录或
     证据**，不建立新案件，也不能在警察局停机或终焉停摆后恢复系统。
  清除犯罪记录**不**取消当前通缉；被清罪者若仍在通缉中，警察继续按通缉执法。
- 有队长时仍可举报。合法案件属于公共层，不因警力已被玩家指挥而关闭。

### 2.2 一次行动完成举报

普通举报占用举报者的一个标准根行动。它成功后立即登记通缉，但不再要求举报者在后续
行动中手动执行 `assemble` 或 `track_guide`：

1. 下一次 R2，系统为当前通缉指派**一名执法警察（lead）**：选择与目标**地图距离最近**的
   可出动警察；地图距离相同时按 **NPC ID 升序**决胜；被指派警察前往目标当时所在地点；
2. 若被指派警察随后**失能或死亡**，下一次 R2 从剩余可出动警力中**重新指派**；
3. R3 中目标若移动离开，便能避开本轮 R4 的执法攻击，但为此支付了自己的标准行动；
4. 下一轮 R2，警察继续根据目标的新位置追踪；
5. 目标留在警察所在地点时，警察才在 R4 执法。
6. 目标被 G3 固有结界捕捉时，案件与 lead 绑定原样挂起：R2 不重新指派、不移动，R4 不
   自动攻击；lead 仍是普通存活警察，可接受针对其他合法事项的队长命令。目标退出后，
   下一 R2 从挂起点恢复追踪。

因此举报一次就能产生持续压迫；移动可以拖延警察，但不能免费消除案件。第一版始终只有
**一名 lead** 自动追踪/执法，其余警力原地观望，除非队长另行合法下令。

## 三、警力、执法与掩体

### 3.1 固定警力

- 警力池在开局建立，数量、初始活跃状态和生成地点待风洞。
- 队长上任、换任或死亡不会刷新、复活或重新生成警察，也不会重置其伤势和装备。
- 警察全灭后的恢复只能来自另行登记的最高级效果；普通队长就任与 T6 演出都不能复活
  警力。
- 普通攻击可以把警察作为目标，不再限于 AOE 白名单；袭警仍登记犯罪。

### 3.2 每轮行动责任

每名正常警察在 R4 至多执行一次自动执法攻击。若队长已经在本轮命令该警察立即攻击，
该单位本轮的自动攻击额度视为已使用，不能再次出手。移动、攻击、控制恢复与装备变更
必须分别记录，不能依赖一个含义过载的布尔值。若警察在 R4 前被流放、沉沦、致盲、死亡
或停机，则本轮自动攻击不执行；额度不结转。

### 3.3 警察保护改为掩体（`COVERED`）

正常警察为同地点、未被通缉的单位提供一层不可叠加的掩体。掩体语义按结算合同 RFC v0.3
§3.4 登记为 `COVERED`，并按**受保护单位**逐一结算：

- **来源绑定**：掩体绑定一名同地点、活跃（可行动且未被通缉的）警察；该来源不存在
  （死亡、失能、离场、被通缉）或与受保护单位不同地点时，覆盖立即移除；
- **不叠加**：同一单位至多拥有一层警察掩体，多名警察不叠加，较大的耐久替换较小者；
- **R0 刷新**：每个 R0 重新核对来源合法性、同地点与覆盖对象；
- **移动/来源损失移除**：受保护单位主动或被强制离开地点、或来源警察移动/失能/离场时，
  覆盖立即失去；
- **覆盖对象**：被通缉者、失能警察和已经离场的警察不提供这项保护；
- 黄昏按照世界时钟关闭警察掩体，但保留案件与执法；
- 终焉令整套警察系统停摆；
- 具体减伤服从 B0/B5 两阶段伤害与 `25%` 下限，不建立另一条伤害流水线。

### 3.4 警察局摧毁：停机收尾（2026-08-09 B5 W6 批准）

警察局被摧毁时（例如 G1 繁育缩圈的地点摧毁），立即执行停机收尾：

1. **关闭新举报**：不能再建立新的当前通缉；T6 市民热线与普通举报在本局不再产出案件；
2. **停止自动推进**：R2 集结 / 追踪与 R4 自动执法攻击不再推进；警察状态机整体停摆；
3. **清除当前状态**：当前通缉、队长职位与威信、以及所有警察掩体立即清除；
4. **幸存警察转为中立 NPC**：保留各自 HP 与装备，但不再自动行动、不接受指令，也不
   提供掩体或执法；他们只是“留在原地、不会再行动”的中立 NPC，既不计入死亡，也不被
   当作可复活警力；
5. **停机警力的攻击边界**：停机后的中立 NPC 即使因未来场景规则或明文效果发起攻击，命中
   仍作为**犯罪事实**登记（袭警口径保留），但**不执行执法**——不推进案件、不结案、不
   提供掩体，也不视为警察自动执法；
6. 与其他文档的同步：[G1 火萤燃烧循环 RFC v0.3](m9_g1_firefly_burn_cycle_rfc_v0.3.md)
   §五.4 的警察局摧毁指向本文；终焉停摆仍按 §3.3 关闭整套系统。

### 3.5 临时演出警察（2026-08-09 B5 W6 批准）

G0/T6 遗物支援技与 B4 魂援登记的“临时演出警察”，是一次性演出单位，不是固定警力：

- **不占编制**：不进入固定警力池，不影响警力总数或恢复规则；
- **不继承案件**：不读取、不推进、不结案现有通缉；不参与 R2/R4 自动推进；
- **执法范围关闭**：只以**当前通缉目标**为唯一可执法目标；若演出时无当前通缉、或目标
  不在可到达地点，演出按命令无法执行处理，不自行扩大目标池；
- **一次性**：执行登记的表演（如对当前通缉单位攻击一次）后，在本次效果结算完成时
  立即**消散**，不留在场上；
- 它是“演出警察”，服从演出收尾与责任归属，不能成为队长、不能提供持续掩体、不能被
  用来恢复或扩充固定警力。

### 3.6 袭警与豁免

- 非豁免的 AOE / 范围伤害命中警察，照常登记袭警犯罪（B5 W6）。
- 只有明文豁免（例如快照明确排除中立 NPC、或效果登记为不构成犯罪）才不登记。
- **Terror 从合法执法目标池排除**：警察不主动攻击、不追踪、不将其列为执法目标，也不会
  因 Terror 造成伤害而回应（见 G7 战术压制 RFC v0.3 §二.7）。

## 四、队长：高控制、高责任的公开职位

### 4.1 就任与申请人队列

旧的“先加入警察领取奖励，再反复累计竞选进度”退出 M9 目标规则。候选结构是：干净玩家
在警察局花一个标准根行动公开登记就任申请；若到下一次 R2 仍存活、合法且职位空缺，则
完成就任。

申请人队列规则冻结为：

- **排序**：按**最早登记**优先；
- **同时登记决胜**：同一登记时点以**先攻降序**、再以**玩家 ID** 决胜；
- **取消**：R2 就任判定前可主动撤销登记，不占队位；
- **失效**：登记后**死亡、犯罪或离场**使登记失效，自动让出队位；
- **不开放挑战**：就任不以挑战、决斗或队长在场时的强制替换改变队首。
- **律法诗候选**：诗篇分支 2 免除“在警察局花标准行动”这一步，但仍要求系统未停机、
  目标存活/在普通层/无犯罪且队长职位空缺；它以诗篇结算事件的时间戳加入同一申请队列，
  不插队、不替换已有候选、不重复登记，并在下一 R2 按上述排序与失效规则统一判定。

就任不会发放免费玩家装备、不会生成警察、不会清空案件，也不会自动给予额外行动。

### 4.2 指挥

队长每次使用自己的标准根行动，只能命令一名警察执行一项：移动、立即攻击、唤醒或改派
案件目标。队长没有通用的警察配装权限；配装是 T6 的天赋核心。队长仍可让警察按公共
通缉自动执法，选择不下令并不暂停案件。

**Terror 命令排除**：处于 Terror 形态的队长，其**移动与立即攻击命令被警察拒绝**（与
Terror 从合法执法目标池排除同源，见 §3.6）；唤醒、改派与其他指令按公共合法性处理，
警察不因 Terror 队长的命令主动靠近或攻击 Terror。

### 4.3 威信与解职

威信是职位责任状态，不是可支付的通用货币：

- 对合法通缉目标的执法不扣威信；
- 命令攻击无辜者、队长本人犯罪或非法篡改案件扣除威信；
- 旧的“研究性学习换威信”循环退役；威信恢复方式与上限待风洞；
- **威信归零时队长下台**：下台使当前通缉**合法解除**（§2.1 结案条件之三），队长自身
  转为当前通缉目标；其他玩家的犯罪记录不再被一并清空；
- 队长合法解职（合法撤销通缉）是结案条件之一，普通队长辞职不自动结案。

## 五、T6「朝阳好市民」

### 5.1 常驻：特别线索（持久化）

进入他人之家、无合法许可进入军事基地、释放病毒等行为不再因 T6 在场就秘密改写为全局
犯罪。它们改为生成 T6 可以使用的特别线索；其他玩家不能仅凭这类特别线索完成普通举报。

线索持久化冻结为：

- 特别线索写入**事件日志**；
- 线索的事件、来源、嫌疑目标与时间戳对全桌公开；只有使用权限受下条限制，高信息公开
  不等于其他玩家可拿它举报；
- **T6 死亡后线索仍保留**在事件日志中；
- 但只有**存活或已复活**的 T6 玩家可以使用；其他玩家（包括刚接过 T6 身份的替代者之外
  的任何人）不能仅凭特别线索完成普通举报；

### 5.2 标准根行动：市民热线

T6 可以从任意地点执行普通举报，不读取 SP，但仍消耗自己的标准根行动并服从证据、存活、
世界时钟和当前通缉合法性（§2.1 举报前检同样适用）。远程只豁免地点要求，不豁免事实要求。

### 5.3 SP=2 演出：联防整备

T6 的主动演出核心改为警察配装：

- 选择一名**存活**警察，更换一件许可武器或护甲；**演出时必须存在存活警察**，否则
  前置不满足，在消费 SP 前取消演出；
- **删除“为下一名出动警察登记待执行装备订单”的旧候选**：配装演出只针对已存活、可到达
  的警察，不预登记未来订单；
- 每次演出只处理一件装备，不移动警察、不命令攻击、不授予额外行动；
- **装备白名单精确冻结**为当前已实现列表，不免费生成新装备（no free spawn）：
  - 武器：`baton`（警棍）、`gauss_rifle`（高斯步枪）、`magic_barrage`（魔法弹幕）；
  - 护甲：`shield`（盾牌）、`ceramic_armor`（陶瓷护甲）、`magic_shield`（魔法护盾）、
    `at_field`（AT力场）。
  白名单只决定**可更换的武器/护甲类型**；装备的获得与替换仍受补给地点和数量限制；
- 装备只属于警察，不能转交玩家或通过死亡掉落刷取；
- 即演与公演使用同一配装核心；公演额外待遇留给 B4，不预先追加一次警察行动。

### 5.4 退役项

- 删除 T6 开局修改全局犯罪集合的实现方式；
- 删除“竞选队长所需行动数 −1”；
- 删除以 SP 演出远程举报、随后免费移动或锁定警察的旧候选；
- 删除待执行装备订单；
- 不新增好市民点、行政力、举报次数或配装冷却。频率由标准行动与 SP 合同承担。

T6 仍可按普通规则申请队长；成为队长后会同时拥有后勤和指挥能力，但没有就任捷径。

2026-08-08 B5-V6 确认：无人犯罪、无合法案件时，T6 的举报通道自然变窄，不为和平局
新增补偿关注或虚构案件。T6 仍可通过普通攻击、`find` 和其他通用公开事件取得关注；
这种对秩序失灵的依赖是“把秩序变成武器”的身份边界，不是行动硬锁。

## 六、进入 B3 的接口

- G2 v0.3 不建立舞台或暂停警务：影身行为的犯罪/案件归 G2，共享通缉下警察按位置合法
  选择光身或影身；击溃影身不等于逮捕/击杀 G2，也不自动结案。终曲区域不暂停案件时钟、
  警察掩体、举报或 R2 自动出动，区域效果对在场警察/NPC 正常生效。
- **G3 幻想乡（固有结界）默认不捕捉警察**：被困目标的警察案件/进程（R2 执法警察指派、
  追踪与案件时钟）在目标被困期间**挂起**，目标退出结界后恢复；结界内不得继续举报
  （G3「神话之外」投影固有结界 RFC v0.2 §5.4）。
- G5「律法」诗篇必须适配“通缉—警力—队长—威信—T6 配装”五个现行概念；未经明文
  最高级白名单，不得生成/复活警察、跳过就任等待或无视终焉停摆。
- 副舞台内部不能借警察指令递归打开外部完整行动或另一场公演。
