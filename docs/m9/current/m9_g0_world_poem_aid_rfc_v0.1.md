## 一、结论

1. B4 v0.4 §4.3 的黑马援助玩家可见名改为「**此诗，献予世界**」——一首没有具名赠予对象的
   诗，暗示它来自昔涟：世界把支援赠予没有任何死者押注的人。机制键名 `blackhorse_*` 与
   黑马胜利加成（暂定 +10 终分）**不变**，防止数值信源漂移。
2. 若本局天赋池含 G0，「此诗，献予世界」的增益内容由「**昨日的同伴**」两式替换：
   - 进攻支援「**星野的战术压制**」：黑马攻击命中后追加一段基础近战追演，被命中单位
     获得震荡；
   - 防御支援「**绫音的急救**」：每个 R4，黑马所在地点**所有单位**回复少量 HP。
3. G0 本人**不提供、不结算、不获得**任何 PP 或资源：她不是援助者，援助是世界规则对她
   的转述。她是外来者，没有偏向，只在这个世界延续上个世界未竟的遗憾——帮助自己的伙伴。
4. 本合同解决的是“G0 离场后仍以机制遗产影响棋局”，**不是**“撤退玩家继续获得操作或
   决策”。撤退 G0 仍是纯旁观者；是否要恢复玩家决策权属于另一项设计目标，不能从世界援助
   的存在反推。

## 二、动机

- G0 撤退是现行最彻底的出局态（G0 v0.3 §7.3）：不进往世层、不能投注、不能提供魂援、
  PP 冻结、不能行动、不可被指定。撤退玩家从那一刻起是纯旁观者。本设计只让 G0 以
  “世界援助的内容”留下机制遗产，而**不开启任何一条已冻结边界**（往世层、魂援、retreat
  不能行动），也不宣称恢复撤退玩家的博弈决策。
- 原设依据：Boss 白子*Terror 使用那个世界**死去的同伴**的武器战斗。奥空绫音的 EX 是范围
  治疗，星野的 EX 是战术压制；在本游戏语境下落为上述两式。
- 附带红利：黑马援助本不需要往世层非空，本设计同样保留这一性质，并在激活门槛（§四）
  之后为"无人押注"提供真正的差异化体验。

## 三、更名条款（无 G0 的局）

「此诗，献予世界」完全继承 B4 v0.4 §4.3 的现行黑马机制：

- 定义不变：无任何死者押注的生者为黑马；
- 增益不变：进攻 +⟦bal:m9_system.pp.blackhorse_atk⟧、防御 +⟦bal:m9_system.pp.blackhorse_def⟧；
- 胜利加成不变：黑马胜利终分 +⟦bal:m9_system.pp.blackhorse_bonus⟧（暂定 +10），
  "我没有靠任何亡灵的帮助"本身就是传奇；
- 归属纪律不变：不属于魂援、不占 4 次援助额度、不触发任何援助 PP 奖励、不需要往世层非空；
- 死者囚徒困境不变：不押黑马而黑马赢了，所有押错人的死者全部出局。

## 四、G0 替换版「昨日的同伴」（本局含 G0）

### 4.1 适用与激活

- **适用条件**：本局天赋池含 G0。G0 存活、撤退或绝对离场均不影响本条款——援助是她留下
  的遗产，不是她本人的行动。
- **激活门槛**：本局存在至少一笔有效押注后，「昨日的同伴」才开始生效。开局全员无押注的
  普惠窗口不触发本援助，防止前期全员免费震荡/回血的通胀（待风洞验证）。
- **接受者**：当前所有黑马（无任何死者押注的存活玩家），与原黑马定义一致；G0 自己存活
  且无押注时也可以是接受者——同伴也守护她。
- 每个 R0 开市结束、全部 tranche 与转仓落定后，系统重算本轮的"已有有效押注"与黑马快照；
  进攻支援和 R4 治疗都读取该快照。本轮中途的死亡不把已死亡者保留为黑马，也不让其他人
  临时补入；下一 R0 再统一重算。

### 4.2 进攻支援「星野的战术压制」

每名黑马每个全局轮次**第一次**合法攻击根行动命中后，对同一目标追加一段基础近战追演：

- 追演以黑马自己的当前状态结算；无合法近战武器时退化为基础拳击（参照 G4 焚诏
  `challenge_punch` 先例）；
- 支援镜头只为本段追演临时解决与原目标的距离/面对面要求，不移动双方、不改变地点，也不
  免除武器本身的费用；因此远程攻击同样可以呼叫星野冲锋，但不能借此取得真实位移；
- 单目标攻击沿用原目标；AREA/多目标攻击命中多个单位时，黑马从实际命中单位中公开选择
  一个作为追演目标；没有实际命中单位时不触发，且不消耗本轮首次命中资格；
- 追演是根行动内部的限定步骤（行动 v0.8 §2.3）：不重新进入 T0、不产生行动槽、不刷新
  SP/关注/公演/每轮上限、不授予完整额外行动；
- 该追演命中时，目标获得「**震荡**」（标准受限行动菜单；同级不叠加；目标已有更高优先级
  控制时不覆盖）；
- **不设压制版本**。援助后门不恢复高位控制——见 DOC-036 与 B5-V5：G3 防御魂援正是从
  "整轮天赋封锁"降级为"前摇截断"的同一先例；
- 追演的击杀、犯罪、关注与战果归黑马本人，与原黑马增益的责任口径一致。
- 若同一根行动还可进入关闭列举的根内子循环（当前仅 G3 `projection_chain`），在首发载荷
  结算后由玩家二选一：执行星野追演，或进入该子循环；未选项整体丢弃，本根行动内不得叠加。

### 4.3 防御支援「绫音的急救」

每个 R4，每名存活黑马所在地点的**所有单位**回复
⟦bal:m9_system.pp.world_poem_g0_heal⟧ 点 HP（首轮值 1，待风洞）：

- 治疗不分敌我：包含敌方玩家、警察、无人机、影身与其他非玩家单位。战场救护无差别——
  何时离开混战区、何时留下来吃治疗，是黑马的真实决策；
- 同一地点同一 R4 至多结算一次绫音急救；多名黑马共享地点时不叠加治疗；
- 回复不超过各自最大 HP；死亡/已离场单位不回复；
- 不治疗 G2 终曲区域的场景物与结界锚点等无 HP 对象（无 HP 对象自然不适用）；
- 每笔治疗登记 `source_kind=WORLD_RULE`、`source_id=world_poem_g0_aid`，没有 player provider。
  因此它不满足 G4“其他玩家或受控单位提供的外来正面转移”，不给 G4 增加火种。

### 4.4 纪律

- 与黑马同源：**不属于魂援、不占四次援助额度、不触发援助 PP 奖励、不需要往世层非空**；
- G0 不因此获得任何 PP、关注、SP、评分成分或决策权；她不是援助交易的任何一方；
- 本援助不适用 G0×G7 `+20%` 联动（G0 v0.3 §8.3）：世界援助不是 G0 的天赋效果，也不是
  G7 对 G0 的魂援；
- 本援助不改变 26 项魂援名单、四次额度与投注结算。

## 五、已考虑方案（避免重提）

| 方案 | 裁决 |
|---|---|
| 撤退 G0 进入往世层成为援助提供者 | **否决**：撞三条冻结边界（G0 不进往世层、G0 无魂援、retreat 不能行动），并模糊死亡/撤退/绝对死亡三档终态 |
| 进攻支援附带压制 | **否决**：DOC-036 / B5-V5 先例——援助通道不得恢复高位控制 |
| 无激活门槛（开局即生效） | **否决**：开局全员无押注，全员免费震荡+回血是前期通胀 |
| 由撤退 G0 每轮选择一名黑马接受支援 | **否决**：与"她没有偏向"的主题矛盾；且会给撤退状态偷偷塞回决策权 |

## 七、待风洞数值与观察项

- `m9_system.pp.world_poem_g0_heal=1`：R4 全员回血的节奏影响；
- 进攻支援追演的基础伤害口径（拳击/武器基础值）与震荡的加入率；
- 激活门槛（存在至少一笔有效押注）的实际触发轮次；
- 观察项：黑马人数较多时全员追演+震荡的强度；治疗救起敌方单位的"资敌"事件频率；
  G0 撤退玩家的主观体验（叙事在场是否缓解冷落感，真人局评估）。

## 八、验收场景（Given/When/Then）

1. Given 本局无 G0；When 出现黑马；Then 援助为「此诗，献予世界」，数值增益与 +10 终分不变。
2. Given 本局含 G0 且尚无任何有效押注；When R4 到来；Then 「昨日的同伴」不生效。
3. Given 本局含 G0 且已存在有效押注；When 黑马的攻击根行动命中；Then 追加一段基础近战
   追演，追演命中时目标获得震荡；目标已有压制/石化时不覆盖。
4. Given 黑马 G3 的螺旋剑首发命中且可进入 `projection_chain`；When 追加窗口开放；Then
   玩家只能选择星野追演或投影连发子循环之一，不能在同一根行动中同时取得。
5. Given 本局含 G0 且援助已激活；When R4；Then 每名存活黑马所在地点所有单位回复
   `world_poem_g0_heal` 点 HP，不超过各自最大 HP；多名黑马共享地点时只回复一次。
6. Given G0 已撤退；When 黑马满足条件；Then 两式支援照常生效，G0 不获得任何 PP/关注/评分。
7. Given G7 与 G0 同局；When 进攻支援追演命中；Then 不适用 `+20%` 联动放大。
8. Given 黑马所在地的 G4 仍为人形态；When 绫音急救回复其 HP；Then 治疗事件来源为
   `WORLD_RULE`，G4 不获得外来正面转移火种。
