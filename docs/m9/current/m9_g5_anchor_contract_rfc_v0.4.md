## 一、重置结论

G5 不再是从开局到终局保持同一形态、等待追忆达到固定门槛后反复声明结果的角色。M9
把她拆成同一玩家身份的三段生命：

```text
CYRENE（小昔涟，有限寿命）
  -> HOME（回家、封存这一世的追忆）
  -> CYRENE（可继续转世）或 DEMIURGE（德谬歌诞生）
  -> PAST（追忆耗尽或主动闭合因果后，向过去退场）
```

锚定也不再从“我要某人死亡”这种结果句开始。德谬歌支付追忆购买 K 个未来槽位，亲自
写出 K 个基础行动。系统只按顺序投影这些明确行动，再从状态差分中抽取击败、摧毁、位移、
获得四类候选事件。现实中的玩家围绕这些**已经公开的具体事件**行动：帮助它提前发生，
或改变现实，使产生该事件的同一动作不再成立。

本合同明确禁止三件事：

1. 系统不得替 G5 选择武器、目标、交互动词或目的地；
2. 系统不得补 `move/find/lock/charge` 前置、枚举模板或搜索最短路径；
3. 投影行动不是现实额外行动，绝不创建 `ActionGrant`。

## 二、同一身份的三段状态机

### 2.1 共同身份

- `CYRENE`、`HOME`、`DEMIURGE`、`PAST` 共用同一个玩家 ID、分数、信用点、PP、犯罪责任
  与每轮标准行动资格；任何时刻至多一个形态在普通层活动。
- 轮回不创建召唤物、分身或第二行动槽，不复制物品，不刷新一次性全局资源。
- 默认分类是封闭的：标记为 `player_identity` 的 T7 保险、诗篇/爱愿、信用点/PP/评分、
  犯罪记录/通缉和永久天赋进度在回家期间继续计时/存续；其余未明文标为身份级的 HP、
  装备、位置、面对面/锁定、控制、灼烧及临时战斗标记均属 `body_local`，回家时清除或按
  掉落规则留在世界。新状态必须在创建时选择两类之一，不能临场猜测。
- 所有状态转换都写入显式事件；不得从“HP 又变正数”反推复活或转世。

### 2.2 `CYRENE`：小昔涟

- 开局以小昔涟进入普通层；最大 HP 使用
  `⟦bal:m9_talents_extended.g5.cyrene_hp⟧`，其余基础行动、信用点与装备规则正常。
- 小昔涟可以 `move / interact / find / lock / attack`，也可以使用 §四的微澜；不能锚定，
  不能献诗。
- 每一世持续 `⟦bal:m9_talents_extended.g5.cyrene_life_ticks⟧` 个未来 R4 tick。建立这一世
  的当轮不扣 tick。
- 黎明/白昼中，普通致死或寿命归零触发 `CYRENE_HOMECOMING`，不是死亡：不建立击杀者、
  不触发 T7、不进入往世层、不结算死亡投注，也不触发以“玩家死亡”为条件的效果。
- 从黄昏开始，普通致死或寿命归零不再允许继续轮回：先封存本世追忆并留下物品，随后立即
  令德谬歌诞生；这次强制诞生不补最低追忆、不派发额外行动。若小昔涟已在黄昏前回家，
  则在进入黄昏后的首个 R0 按同一规则强制诞生。
- 终焉阶段，或场上只剩最后两个仍有资格继续游戏的玩家身份时，小昔涟的普通致死与寿命
  归零都按正常死亡合同结算；此优先级高于黄昏强制诞生，因此可以触发 T7/保险、击杀、
  往世层与死亡投注。残局人数不计已进入往世层或完成不可逆退场的身份，但计入正在接受
  本次致死裁决的小昔涟。
- 寿命归零的正常死亡裁决每一世只触发一次；若保险将其救回，已归零的计时器不会在后续
  R4 重复触发同一到期事件，但此后的再次致死仍按终焉/双人残局普通死亡规则处理。
- `absolute_death`、绝对离场或规则明文写明“跳过转折”的来源不触发回家，直接按其原合同
  结算；G5 因此可能在德谬歌诞生前真正出局。
- 回家时，所持世界物品全部留在离开地点；信用点、PP、得分和封存追忆属于玩家身份，
  不掉落。这样轮回不会复制装备，也不能用寿命传送货物。
- 回家立即移出公演队列，但 SP 不因“死亡”清零；下一世或德谬歌回到普通层后若 SP=2，
  必须在合法报名窗口重新报名，不能继承旧队列位置。

### 2.3 `HOME`：回家与封存

- `HOME` 不在地图中，不能行动、被指定或取得新的世界物品；它只持续到下一 R0 的轮回
  结算。
- `HOME` 结算属于 R0“自动状态”步骤，先于公演报名窗口；同一 R0 回到普通层的小昔涟或
  德谬歌若满足 SP2，可参加随后打开的普通报名窗口。
- 若世界已经进入黄昏，`HOME` 的唯一合法结算是立即诞生德谬歌；不得再开始下一世。
- 下一 R0 先结算上一轮中小昔涟仍在普通层时记录的追忆，再把本世临时追忆封存进唯一的
  `reminiscence` 池，最高
  `⟦bal:m9_talents_extended.g5.reminiscence_cap⟧`。
- 已完成世数小于
  `⟦bal:m9_talents_extended.g5.cyrene_max_incarnations⟧` 且封存追忆低于诞生门槛时，
  自动开始下一世。
- 封存追忆达到
  `⟦bal:m9_talents_extended.g5.demiurge_birth_threshold⟧` 后，玩家可在本次回家时选择继续
  转世以培养更多追忆，或令德谬歌诞生。
- 达到追忆上限或用尽最大世数时，强制诞生；即使追忆低于门槛也不会软锁。培养质量直接
  决定德谬歌最终拥有多少次锚定槽位或献诗机会。

### 2.4 `DEMIURGE`：德谬歌

- 德谬歌在 `home` 地点进入普通层，恢复普通玩家的基础最大 HP 与当前 HP，清除小昔涟的
  寿命计数和临时形态状态；不恢复之前掉落的物品。
- 从这一刻起，追忆池不再增长。它是本局剩余时间内锚定与献诗共享的**有限总预算**，
  不能通过回溯、死亡、诗篇、G0 私人 `relic_memory` 或任何简化诗篇补充。
- 德谬歌可以使用微澜、锚定与献诗。德谬歌普通死亡按正常死亡合同结算，不再转世。
- 德谬歌一旦死亡或进入其他终局状态，待触发的 `CAUSAL_CLOSURE` 取消；同一玩家不能同时
  取得死亡/往世层与 retreat 两种终态。

### 2.5 `PAST`：闭合因果

- 仍存活并处于普通层的德谬歌没有激活中的锚定，且剩余追忆低于
  `⟦bal:m9_talents_extended.g5.anchor_min_k⟧` 时，下一 R0 自动触发 `CAUSAL_CLOSURE`。
- 德谬歌也可在无激活锚定的本人 T0 主动闭合因果，放弃剩余追忆。
- 闭合后进入 `PAST`：不能行动、不能被指定、不触发死亡/T7、不进往世层；装备留在原地，
  PP 冻结，终分使用评分合同的 retreat 口径。它是一次且不可逆的最终退场。
- 已发生的世界事件、已授予的诗篇/爱愿及水晶花都不回滚；各自按原生命周期继续。

## 三、追忆：只在小昔涟阶段培养

追忆仍来自“值得记住的事”，但只有小昔涟在普通层的时间片能记录；`HOME`、`DEMIURGE`
与 `PAST` 都不产生追忆。每个 R0 对上一轮有效时间片按类别各结算一次：

| 上一轮事件 | 本世临时追忆 |
|---|---:|
| 地图上至少一次攻击造成有效伤害 | +`⟦bal:m9_talents_extended.g5.reminiscence_combat_gain⟧` |
| 上述有效攻击中，小昔涟至少一次是攻击者或承受有效伤害的目标 | 额外 +`⟦bal:m9_talents_extended.g5.reminiscence_combat_personal_bonus⟧` |
| 至少一件护甲/对象被摧毁，或任一单位死亡/小昔涟回家 | 额外 +`⟦bal:m9_talents_extended.g5.reminiscence_loss_gain⟧` |
| 小昔涟所在地发生 B4 §3.2 登记的 PP 生成事件 | 额外 +`⟦bal:m9_talents_extended.g5.reminiscence_pp_event_gain⟧` |
| 三类均未发生 | +`⟦bal:m9_talents_extended.g5.reminiscence_idle_gain⟧` |

- 基础战斗追忆观察全地图，不要求战斗发生在小昔涟所在地；这样即使其他玩家不主动攻击
  小昔涟，世界中的战斗仍会成为她这一世的记忆。
- 亲历战斗奖励与基础战斗奖励可以同轮叠加：当前初始值为全局有效战斗 +1，小昔涟作为
  有效攻击的攻击者或承受有效伤害的目标再 +1，合计 2。她只是被未命中/未造成有效伤害的
  攻击选中时，不取得亲历奖励。
- 同类一轮只记一次；基础战斗与亲历奖励各至多一次，不能靠多段攻击反复刷取。
- “PP 生成事件”只包含 B4 §3.2 的首杀、复仇击杀、破甲击杀、终焉击杀、绝境击杀五类，
  且死亡地点必须等于当时小昔涟所在地；“完结条进展”没有地点，不进入本行。
- 回家 R0 先完成该轮应得记录，再封存；普通致死本身可进入“损失”类别，但不会被算作
  一次正常玩家死亡。
- 未封存的本世临时追忆不能支付任何效果；轮回期间也不能被偷取、转让或清零。
- 德谬歌诞生时只保留已经封存的追忆，随后彻底关闭本表。
- 追忆保留小数，不在 R0、回家或诞生时取整；K 必须是整数且只扣整数追忆，未消费的小数
  继续保留，闭合条件也用未取整的真实余额比较。

## 四、微澜

微澜继续是 1 SP 信息型即演：

- 选择一个合法可感知单位，公开其当前位置与已装备物；
- G5 对其无视隐身/闪避，直到 G5 下一个实际结算的 `ActionGrant` 结束；
- 不取得物品、不造成伤害、不增加或封存追忆；
- 每一世小昔涟开始时有一次资格；德谬歌诞生时重开一次；
- 德谬歌每次锚定以“未来闭合”或“因果改写”结束、或完成一次献诗公演后再重开一次；
  `ANCHOR_SHATTERED` 不重开，资格永不叠加；
- 压制、唤醒、`aid_rest`、标准行动与完整额外行动只要实际进入公共 finalization，都会
  消耗正在持续的“无视隐身/闪避”；未建立的预检失败候选不消费。

## 五、锚定入口：用追忆购买 K 槽未来

### 5.1 入口与费用

- **形态**：仅 `DEMIURGE`。
- **时机**：本人 T0，已按行动 v0.8 报名并取得本轮唯一公演位，支付 2 SP，占用本人的
  标准行动槽。只有 SP2、没有公演位时不能发动。
- **K**：玩家公开选择一个整数，满足
  `⟦bal:m9_talents_extended.g5.anchor_min_k⟧ <= K <= ⟦bal:m9_talents_extended.g5.anchor_max_k⟧`。
- **追忆费用**：恰好 K 点。每一点追忆购买一个脚本槽，不再按击杀/获取分类固定 K3/K6，
  也没有首次 24、后续 12 的双门槛。
- **声明**：提交恰好 K 条基础行动组成的 `AnchorScript`；脚本和全部参数全桌公开。
- **预检顺序**：先严格投影并确认至少抽取一个候选事件；通过后再消费 2 SP、标准行动槽
  与 K 追忆，并建立 §八快照。预检失败不消费。
- **并发**：同一 G5 同时至多一个锚定。激活锚定阻止献诗；活跃爱愿阻止锚定。双人局
  不再禁用锚定，因为反制已落在具体候选事件的实时状态，而不依赖第三名玩家计数。

### 5.2 封闭动作语法

第一版只接受下列基础根动作；每条都必须写全对象 ID 与必要参数：

```text
move(destination_id)
find(target_id)
lock(target_id)
charge(item_id)
interact(object_id, operation, explicit_parameters)
attack(target_id, weapon_id)
```

- actor 永远是 G5；不能让其他玩家、NPC、召唤物或未来的自己执行动作。
- `interact` 必须写明操作，例如 `pickup / transfer / buy / open / destroy / activate`；只写
  “交互某物”不合法。
- 不接受 `forfeit`、演出、诗篇、天赋核心、警察指令、反应、完整额外行动、条件分支、循环、
  随机目标、模糊描述或“使用最优武器”。
- 每条动作必须在前面动作产生的投影状态中合法。缺少移动、面对面、锁定、蓄力、资源或
  权限时，系统直接指出首个非法槽；不得自动补前置。

## 六、顺序投影与候选事件抽取

### 6.1 投影模型

系统从锚定入口的公开普通层状态建立只读副本，按槽 1 到槽 K 顺序执行玩家填写的动作：

- 没有其他单位行动，没有 R0/R2/R4 tick，没有反应、AI 选择或环境推进；
- 使用普通移动、交互、装备与伤害规则；目标当前护甲、防御、耐久和所有公开状态均生效；
- 需要命中/随机判定的基础动作采用“无外界干扰的规范成功分支”，不掷骰、不搜索替代分支；
- 指定武器、物品或费用不足即非法，不自动换武器、借钱或选择另一个对象；
- 投影只写副本，不改变真实地图，不消费真实弹药/信用点，不派发行动槽。

复杂度为 `O(K * 单步结算)`；不存在 `O(A^K)` 枚举、模板候选、最短命数或 MCTS。

### 6.2 四类候选事件

每执行一条投影动作，比较动作前后状态，只抽取以下高影响差分：

| 类型 | 精确谓词 |
|---|---|
| `DEFEAT` | 一个动作前仍在普通层存活的唯一单位进入死亡 |
| `DESTROY` | 一个有唯一对象 ID 的护甲、物品、掩体或地点对象从存在/可用变为摧毁 |
| `RELOCATE` | 唯一单位或对象进入明确终点；动作前起点仍记录作审计证据 |
| `ACQUIRE` | 唯一可转移对象的持有者变为 G5 |

- 候选事件记录 `script_id / slot_index / event_index / subject_id / before / after / source_action`
  与该动作的显式普通费用。
- `ACQUIRE` 已表达物品进入 G5 持有区时，不再为同一对象重复生成实现细节型
  `RELOCATE`；攻击在同一结算中先破坏护甲再击败单位时，两项都保留并按原结算顺序排列。
- 完全相同的事件只登记第一次；不同起点/终点或不同对象仍是不同事件。
- `find / lock / charge` 通常不产生候选事件，但仍占一个已购买槽，并可成为后续动作的
  投影前置。
- 整条脚本没有任何候选事件时，入口预检失败。系统不得要求玩家先声明想抽取哪一类结果。

## 七、现实监控：事件能否成为真的

### 7.1 槽位时钟

- 支付完成后立即公开脚本、候选事件及各自的 `slot_index`；建立当轮 R4 不 tick。
- 此后每个未来 R4 推进一个脚本槽。普通 R4 持续状态、世界时钟与其他来源事件先结算并
  写日志，再处理槽 i；胜负检查在该槽处理后进行。槽 i 的候选事件按投影原顺序逐项结算；
  没有候选事件的槽只推进时钟。
- 同一 R4 有多个 G5 锚定槽截止时，按锚定建立事件时间戳升序、再按所有者玩家 ID 升序
  处理；前一个锚定写入的事件立即进入公共日志，可以自然实现后一个锚定的同事件候选。
- 监控期间 G5 继续正常取得每轮标准行动，可以亲自帮助或破坏候选事件，但不能再次锚定
  或献诗。脚本本身不替 G5 行动。
- 因为激活锚定期间没有第二个合法 G5 公演核心，行动 v0.8 的公开选项存在性检查会把 G5
  移出公演队列；锚定结束后若仍为 SP2，必须在下一个合法窗口重新报名。

### 7.2 自然实现

候选事件从锚定建立后到自身截止 tick 前，若现实事件日志已经出现相同对象 ID 与相同状态
变化，就标记 `MATERIALIZED_NATURALLY`：

- 不要求由 G5 完成；第三方击败目标、把物品交给 G5或把单位推到指定地点都能使未来成真；
- `RELOCATE(subject, destination)` 只要求该对象在监控期内曾进入指定终点，不要求从投影
  记录的原起点一步直达；`home -> shop -> station` 可以自然实现“进入 station”；
- 事件发生后即锁定实现，后来复活、离开目的地或再次转移物品不抹除“这件事发生过”；
- 普通事件保留原来源、击杀者、犯罪与资源结算，锚定不改写功劳归属。

这取代 v0.3 的“第三方抢先即失败”。新锚定关注事件是否发生，不争夺唯一作者署名。

### 7.3 截止时再投影

截止时仍未自然实现，系统用**同一条事件来源动作**做一次严格的混合状态再投影：

- 玩家声明的目标、武器、物品、交互动词和目的地不得更换；
- **脚本局部帧**：G5 的位置、面对面/锁定关系、蓄力状态及其他由已成功前缀与
  `find / lock / charge` 建立的局部前置，使用入口投影到该槽时的值；这些前置已经由 K
  槽追忆购买，不要求现实中的 G5 再执行一次。声明阶段仍必须由玩家亲自写出，系统不补齐；
- **实时外部帧**：目标单位/对象、防御、耐久、可移动/可转移性、目的地，以及来源武器/
  工具是否仍存在且由 G5 持有，读取截止时真实状态。声明过 `charge` 可提供投影蓄力，
  但被摧毁、夺走的工具不会因脚本复原；
- 事件来源动作所需的弹药、信用点、消耗品等普通非槽位费用必须仍可支付；实现时支付一次；
- 同一来源动作生成多个候选时，普通费用在该动作第一次需要强制实现时只支付一次，不按
  候选数量重复扣除；随后同槽失败也不退款；
- 若该来源动作在写入任何强制候选前就无法再产生首个待决事件，则不扣其普通费用；锚定
  已支付的 SP、行动槽与 K 追忆仍不返还；
- 若再投影仍会产生完全相同的候选事件，系统只强制写入该事件差分，标记
  `MATERIALIZED_BY_ANCHOR`；不执行整条基础动作，也不触发根行动/额外行动钩子；
- 强制 `DEFEAT` 带 `absolute_death`，跳过防御、免死与复活；其他类型在兼容性检查通过后
  以最高优先级写入目标差分，并执行该差分必需的所有权、掉落与离场清理。
- 所有 `MATERIALIZED_BY_ANCHOR` 事件的责任来源统一登记为 G5 / `g5_anchor`：击杀、犯罪、
  战果、PP、G7 色彩与案件等事件后果归 G5；但它不是根行动，不触发攻击次数、行动记录、
  关注或“完成一次攻击根”等钩子。自然实现仍保留自然来源。
- 同一投影攻击按顺序强制 `DESTROY(armor)` 与 `DEFEAT(unit)` 时，B4 把它识别为同一来源
  动作的“破甲击杀”，可以生成对应 PP；不得因差分拆成两项而丢失或重复生成。
- 同槽候选不是原子事务：按投影顺序逐项做“自然日志检查 -> 必要时再投影”。首个失败
  立即取消尚未处理的同槽/后续候选，但已经自然或强制实现的事件不回滚。

### 7.4 因果改写与连锁失败

若同一来源动作在实时世界中不再能产生该事件，标记 `CAUSAL_REWRITE`，整条脚本立即失败，
同槽后续事件及以后槽位全部取消：

- 治疗、换甲、修理、保护或提高耐久，可让原本致死/摧毁的动作不再产生该结果；
- 伤害或削甲可帮助原动作在截止时产生结果；
- 夺走、摧毁来源武器或耗尽其必要费用，可切断攻击/交互事件；
- 令目的地永久封闭、令对象不可移动，可切断位移；
- 摧毁、消费、封印或令对象绝对不可转移，可切断获得；
- G5 死亡或绝对离场不是普通改写，而是 `ANCHOR_SHATTERED`：立即清理且不授水晶花。

没有通用“变数 +1”计数。每个反制必须真的改变某个候选事件所读取的现实事实。

### 7.5 示例

德谬歌支付 3 追忆写下：

```text
1. move(station)
2. find(player_A)
3. attack(player_A, crystal_sword)
```

入口投影抽取槽 1 的 `RELOCATE(G5, home, station)` 和槽 3 的 `DEFEAT(player_A)`。第一个未来
R4 前若 G5 已正常到达车站，位移自然实现；否则车站仍可进入且 G5 未被绝对禁足时，锚定
强制位移。第三个 R4 前任何人击败 A 都会自然实现死亡；若无人做到，则用同一把晶化剑和
A 的实时 HP/护甲再投影。治疗或换甲可以让该剑不再致死而打破未来，其他人先削甲则可能
帮助它在截止时绝对实现。系统从未替 G5 选择晶化剑，也没有给她三次现实行动。

## 八、结果、回溯与水晶花

### 8.1 入口快照

严格预检通过后，依次消费 2 SP、标准行动槽与 K 追忆，再为 G5 建立快照。快照只覆盖 G5
本人，不覆盖世界、其他玩家、警察、案件或候选事件。

### 8.2 结果表

| 结果 | 条件 | 回溯 | 水晶花 |
|---|---|---:|---:|
| 未来闭合 | K 个槽完成，全部候选事件已自然或绝对实现 | 是 | +1 |
| 因果被改写 | 任一候选在截止时无法由同一来源动作再产生 | 否 | +1 |
| 锚定粉碎 | G5 在监控期死亡或绝对离场 | 否 | 0 |

- 未来闭合计为一次成功锚定；本局第二次未来闭合只触发一次 G5 完结条，额外登记
  `arc_count +⟦bal:m9_talents_extended.g5.double_anchor_arc_count⟧`，并作为 B4 §3.2 的
  “完结条进展”生成一次 PP。M9 不读取服务 `v2exp` 的旧 `finale.g5_double_anchor` 裸分键。
- 因果被改写仍授予一朵花：G5 没有赢得那个未来，但记住了世界添加的新答案。
- 水晶花在回溯结束后授予，只登记
  `arc_count +⟦bal:m9_talents_extended.g5.crystal_flower_arc_count⟧`；不提供战斗强化或追忆。

### 8.3 安全窄回溯

未来闭合后，所有已经实现的候选事件保留；G5 本人回到 §8.1 快照：

- 恢复 HP、位置、G5 局部可回溯状态和仍由 G5 持有的原装备槽位；
- 不回滚装备耐久、弹药、消耗品、信用点、PP、SP、追忆、行动槽或关注；
- 不复制被转移/偷走/摧毁的装备，不删除监控期新取得的世界物品；
- 清除脚本、候选事件、临时再投影状态与目标引用，不留下幽灵监控器；
- 回溯本身不重新触发 `RELOCATE` 候选、移动钩子或根行动事件。

失败不回溯。回溯不能补回用于购买 K 槽未来的追忆。

## 十、技术边界

### 10.1 与现有锚定代码的关系

- `engine/anchor_resolver.py` 的目标分类、模板选择、命数、变数和最短候选搜索不迁入 M9。
- `engine/anchor_templates.py` 不提供默认脚本或“推荐最优路径”。
- `engine/anchor_eval.py::simulate_path` 只能作为历史原型参考；它当前只投影单一目标、允许
  `attack(None)` 自动选武器并依赖 `goal=kill/break_armor`，不满足本合同。
- M9 实现应建立严格 `AnchorScriptProjector`：输入恰好 K 条封闭动作，输出逐槽状态差分、
  候选事件与首个非法动作；它不接受结果目标，也不返回最短命数。

### 10.2 AI、RL 与 AIRI

- BasicAI 可以用自身启发式**填写**脚本，但引擎不得替任何控制器补动作；填不出合法脚本
  就不发动。
- RL 动作空间需要表达“开始编写 / 追加一个带参数基础动作 / 提交或取消”，观测包含 G5
  形态、剩余世数、封存追忆、脚本槽、候选事件及截止槽；不再观察命数/变数。
- AIRI 获得完整公开脚本和候选事件，可围绕具体未来叙事，不读取求解器黑箱。

### 10.3 Profile 隔离

本 RFC 不修改 `talents/g5/`、`engine/anchor_resolver.py`、`engine/anchor_eval.py`、现行 V2 手册、
duet 实现或 `talents.g5.* / anchor.*` 数值。它们继续服务 `v2exp`，直到另有明确迁移批次。

## 十一、验收场景

1. **黎明/白昼普通致死回家**：Given 世界尚未进入黄昏且场上多于两个有效身份，小昔涟被
   普通攻击降至 0 HP；When 处理致死；Then 进入 `HOME`，不创建击杀者/T7/往世层，物品
   留在原地，下一 R0 封存本世追忆。
2. **绝对死亡截断**：Given 同一状态；When 来源带 `absolute_death`；Then 不回家，按绝对死亡
   合同出局，德谬歌不诞生。
3. **培养选择**：Given 回家后追忆达到诞生门槛且仍有剩余世数；When R0 自动状态；Then
   玩家可诞生或再转世，并可参加随后报名窗口。达到上限/最大世数时只能诞生。
4. **显式脚本拒绝**：Given 德谬歌已取得公演位，且 `attack(A, sword)` 缺少面对面或锁定
   前置；When 玩家未在前槽
   写 `move/find/lock`；Then 指出首个非法槽，不自动补动作，不消费 SP/追忆/槽位。
5. **不先声明结果**：Given 合法 K 槽脚本；When 投影；Then 系统只从差分抽取四类事件，
   从未询问 `goal=kill/break/acquire/arrive`。
6. **第三方帮助**：Given 候选为 `DEFEAT(A)`；When 第三方在截止前击败 A；Then 事件自然实现，
   功劳归第三方，锚定继续，不按抢先失败。
7. **实时改写**：Given 投影中的最后一击恰好致死；When A 在截止前获得足以存活的护甲；
   Then 同一武器再投影不再产生 `DEFEAT`，整条脚本因果改写，G5 不回溯但得花。
8. **绝对实现不是额外行动**：Given 截止再投影仍产生同一事件；When 强制写入；Then 只结算
   事件差分和显式普通费用，不派发 `ActionGrant`，不触发根行动/攻击次数钩子；击杀、犯罪、
   战果、PP、色彩与案件责任统一归 G5 / `g5_anchor`。
9. **成功窄回溯**：Given 全部候选实现；When 第 K tick 收尾；Then 世界事件保留，G5 回到
   支付后快照，K 追忆不返还，回溯后授花。
10. **有限终局**：Given 存活的德谬歌无激活锚定且追忆低于最小 K；When 下一 R0；Then
    唯一一次 `CAUSAL_CLOSURE` 进入 `PAST`，不死亡、不进往世层，既有诗篇与花保留。
    Given 德谬歌在该 R0 前已死亡；Then 取消闭合，保留唯一死亡终态。
11. **全局战斗与亲历加成**：Given 小昔涟处于普通层；When 上一轮地图另一处有攻击造成
    有效伤害、但小昔涟未参与；Then 下一 R0 获得一次 `reminiscence_combat_gain`。Given 同轮
    另有一次有效攻击由小昔涟发起或对她造成有效伤害；Then 再获得一次
    `reminiscence_combat_personal_bonus`，多段攻击不继续叠加。
12. **黄昏强制毕业**：Given 黄昏、场上多于两个有效身份且小昔涟普通致死或寿命归零；
    When 结算本世结束；Then 封存已有追忆、留下物品并立即诞生德谬歌，不赠追忆或行动。
    Given 小昔涟在黄昏前已经 `HOME`；Then 黄昏后的首个 R0 直接诞生德谬歌。
13. **终焉与双人残局死亡**：Given 终焉阶段或仅余两个有效身份；When 小昔涟普通致死或
    寿命归零；Then 不回家也不诞生德谬歌，进入正常死亡链。Given T7/保险救回寿命到期的
    小昔涟；Then 同一世的到期事件不在后续 R4 重复触发。

## 十二、风洞数值

所有数值只从 `data/balance.json` 的 `m9_talents_extended.g5.*` 读取。第一轮必须观察：

- 小昔涟普通致死率、平均完成世数、平均德谬歌诞生轮次；
- 诞生时追忆的 P25 / 中位数 / P75，以及低事件桌是否经常不足一次献诗；
- K 的选择分布、每点追忆产生的候选事件数、候选事件自然实现率与绝对实现率；
- 第一项候选失败导致后缀取消的比例；
- 两人局与六人局中帮助/改写来源的数量差；
- 德谬歌诞生到 `CAUSAL_CLOSURE` 的轮数和锚定/献诗组合。
- 目标移动不会单独切断已购买的面对面/锁定局部帧，锚定追随目标的强度；
- 两次未来闭合默认产生两朵花加一次完结条（合计 3 个 `arc_count`）的剧情分强度。

2026-08-13 的首轮 500 局固定种子风洞中，加入世界时钟强制毕业后，G5 为 59 胜 / 203 次
登场（29.1%）；改动前同规模风洞约为 46–47%。这说明规则显著移除了“小昔涟永不主动进入
德谬歌即可苟到终局”的收益，同时没有造成 0% 或落入本轮最低胜率组。该结果只冻结时点与
死亡路径，追忆、寿命、血量和锚定成本仍属于数值风洞项。

数值可风洞，以下结构不可用调参静默改写：追忆只在小昔涟阶段产生、德谬歌预算有限、
K 点追忆购买 K 个玩家自写槽、系统不搜索、结果由差分抽取、脚本不生成真实行动、事件按槽
截止再投影、第三方同结果算帮助、成功才回溯、追忆不足后因果闭合退场。
黄昏结束小昔涟阶段、终焉/双人残局恢复正常死亡链，同样属于结构裁决，不得用数值键绕过。
