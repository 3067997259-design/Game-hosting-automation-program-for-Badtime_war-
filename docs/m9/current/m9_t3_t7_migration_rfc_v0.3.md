## 一、T3 天星（B2-D02）

### 1.1 核心改动

**删除**：
- 次数限制（旧版 K 次或轮次充能）
- "无视属性克制 + 防御 ×50%" 的重复卖点

**保留**：
- 地点 AOE 攻击（完整核心）
- 石化控制效果
- 命中友军也受伤害（需要精准投放）

**新增**：
- **仅 2 SP 公演**：天星没有即演入口；
- 公演在**实际执行时**读取发动者的当前所在地点并原地释放，不提供地点选择 UI
  （2026-08-11 追加裁决；报名公演时不锁定、不保存目标地点）；
- 统一石化机制与 M9 控制系统适配；
- 施法者自身**不被**自己的天星命中（v0.3 冻结）。

### 1.2 完整定义

```
T3：天星

入口（v0.3 冻结）：
- 只能在取得公演位后以 2 SP 公演，占用标准行动槽；天星没有 1 SP 即演入口
- 公演结算一次完整核心，同时打开舞台待遇、魂援/PP 调用点与 G5「群星」诗适配
- 删除次数限制，只要公演位与 SP 允许就可以使用

效果：
① 在公演实际执行时读取发动者的**当前所在地点**并原地释放；不提供地点选择 UI，
   公演报名时不保存、不锁定目标地点
② 对该地点内**除施法者本人以外**的所有合法单位造成
   ⟦bal:m9_talents_extended.t3.starfall_damage⟧ 点伤害
   - 命中所有其他合法玩家与 NPC（包括盟友；中立警察与中立普通 NPC 按

   - 伤害无属性
   - defense_coefficient = 0（完全无视属性防御）
   - 仍受 flat_damage_reduction 影响（如火萤减伤、G4 余烬护甲）
   - 正常经过 25% 下限计算
   - 注意：这不是 `DIRECT_DAMAGE`（结算合同 RFC v0.3 §6.6 只登记 G0 十字炮火、
     G7 Terror 攻击、G4 死星天裁与终焉世界时钟）；天星仍走普通两阶段流水线，只是穿防为 0
   - 施法者本人不命中（v0.3 冻结）：天星从头顶落下，不会击中自己
③ 命中的单位获得「石化」状态

石化（petrified）：
- 持续时间：⟦bal:m9_talents_extended.t3.petrify_duration⟧ 轮（暂定 2-3 轮，待风洞）；
  按行动 v0.8 的“建立轮 R4 不 tick”口径，从效果建立之后第一个 R4 开始计数
- 石化单位每轮行动时，在 T0 选择：
  
  a) forfeit（放弃行动）
     - 保持石化状态
     - 不获得 SP（2026-08-08 B5-D03 与 v0.3 冻结：删除旧稿"SP +1"，v0.5 冻结
       "普通 SP 只由关注推进"；石化者被攻击时仍经焦点身份正常获 SP）
     - 消耗行动槽
  
   b) 尝试挣脱
     - 这是同一行动槽 T0 内的一个**至多两次子循环**；每次尝试各消耗 1 SP
     - 每次掷骰判定（50% 概率）：
       * 第一次成功：解除石化，结束子循环；本行动槽尚未消费，可以继续正常行动
       * 第一次失败：石化继续，但先不结算行动槽；若仍有 1 SP，可立即选择第二次，
         也可拒绝重试并让本槽以 `petrified_hold` 结算
       * 第二次成功：解除石化；本行动槽尚未消费，可以继续正常行动
       * 第二次失败：石化继续，本槽以 `petrified_hold` 结算
     - 同一全局轮次最多两次；额外行动槽不会重置这个次数上限
  
  c) 被动解除
     - “有效伤害”使用结算 v0.3 §6.7 的统一口径（H≥1 入 HP 或击破护甲/掩体）

- G5「群星」诗可将石化升级为「尘世之锁」：
  - 不因被其他单位攻击而解除（删除被动解除机制，v0.3 冻结）
  - 只能通过**被锁者自己的 T0 挣脱**解除，或通过 forfeit 持续到时间结束
  - 时间**不被延长**：尘世之锁不新增或叠加持续时间
  - **重施刷新**：尘世之锁生效期间，若被锁单位再次被**施加该锁的同一名 T3** 的天星
    命中，则把剩余时间刷新为基础石化持续时间；重复献诗本身不刷新。锁不会消失，也不
    会因刷新退回普通石化
  - 挣脱判定保持 50% 概率
```

### 1.3 设计说明

**公演单一入口（2026-08-10 裁决）**：
- 天星只能以 2 SP 公演结算**一个完整 AOE + 石化核心**，没有 1 SP 即演版本；
- 公演同时打开舞台层待遇（魂援/PP/喝彩调用点、G5「群星」诗适配），但**没有第二次伤害段**；
- 投放地点是**公演实际执行时发动者的当前所在地点**（2026-08-11 追加裁决）：执行时读取
  发动者所在地点，取消地点选择 UI；公演报名时不锁定地点；只有当前地点内除发动者外的
  其他合法单位受影响。天星不再支持远程投放，以「站在哪、砸哪」约束其强度。

**伤害属性的选择**：
- 旧版同时写有"无视属性克制"和"防御 ×50%"
- 在 M9 两阶段伤害系统中，这是两个不同的东西：
  - 无视属性克制 = `defense_coefficient = 0`
  - 防御 ×50% = `defense_coefficient = 0.5`（类似 T1）
- 两者不能叠写（真伤不需要穿甲系数）
- 选择 `defense_coefficient = 0` 是因为：
  ① 符合"天星"主题（陨石从天而降，无差别攻击）
  ② 完全无视属性防御，但仍受减伤影响（不过分）
  ③ 与 T1 区分（T1 是有属性 + 穿一半，T3 是无属性 + 完全穿）

**排除施法者自身（v0.3）**：
- 旧表述只写“对友军也造成伤害”，未明确自己是否被命中；
- v0.3 明确：施法者不命中自己，但**所有其他**地点内合法玩家与 NPC（含盟友）都命中，
  保持“需要精准投放”的战术含义。

**石化机制的改动**：
- 旧版：被攻击后自动解除
- M9 版：需要 2 次有效伤害才解除（鼓励集火），有效伤害走结算 v0.3 统一口径
- 新增"尝试挣脱"机制：消耗 SP + 50% 判定，给被石化者主动权
- forfeit 不获得 SP（v0.3 冻结），与“普通 SP 只由关注推进”一致
- 挣脱成功返还行动槽，奖励主动尝试的玩家

## 二、T7 死者苏生（B2-D04）

### 2.1 核心改动

**删除**：
- 在魔法所连续学习两次的前置条件（3 槽消耗）
- 学习进度、学会状态等中间状态
- v0.2“同一目标只能有一个伏笔（新伏笔覆盖旧伏笔）”与兑现后“T7 需要重新挂载
  新伏笔”的**矛盾文本**（v0.3 删除，见 §2.2 一次性保险）

**保留**：
- 挂载伏笔 + 死亡兑现的核心机制
- 复活位置（自己家）、复活 HP、保留物品
- 保险在 T7 死亡后继续存在（已挂载伏笔独立于 T7 生死）

**新增**：
- SP 演出双入口（即演/公演）
- 与 G5「彼岸」诗的明确交互
- **全局一次性保险**：T7 全场只能挂载并兑现一次；兑现后天赋永久落幕
- 普通死亡与普通复活后的 SP 冻结为 `0`

---

### 2.2 完整定义

```
T7：死者苏生

入口：
- 即演（1 SP）或公演（2 SP），占用标准行动槽
- 不需要在魔法所，不需要地点限制
- 不需要学习前置

全局一次性保险（v0.3 冻结）：
- T7 同一时刻全场只存在一个「保险伏笔」（全局唯一标记），挂载后**不得覆盖、
  不得重新挂载**；该标记是公开信息
- 兑现后伏笔标记消耗，T7 天赋**永久落幕**：不再能挂载第二个伏笔，也无法通过
  SP 或任何来源重新挂载
- 保险在 T7 持有者死亡后继续存在（伏笔已挂载，独立于 T7 生死）；T7 死后已挂载
  的伏笔仍正常兑现
- 任何“覆盖旧伏笔 / 重挂新伏笔”的旧文本在 v0.3 删除，防止与一次性语义矛盾

效果：
① 选择一名存活玩家（含自己），挂载全局唯一「保险伏笔」
   - 全局公开可见（目标头上显示"已挂载 T7 复活"）
   - 不消耗，不能被驱散
   - 按普通关注合同双向登记：目标作为焦点先登记，T7 作为发起者后登记；仍受每人
     每轮最多 `+1 SP` 的共同上限约束（2026-08-08 B5-V2 裁决）

保险伏笔兑现（被动触发）：
当挂载目标死亡时：

① 优先级判定（v0.3 明确）：
   1. **`absolute_death` 标签来源**（G5 锚定绝对实现、G4 死星天裁、G7 Terror、
      G1 繁育倒计时死亡）：跳过复活，保险不赔付；
   2. 目标自己的明文免死效果（光环、其他天赋）高于普通死亡，按其自身规则处理；
   3. 以上均不适用时，保险复活承接普通死亡。

② 若触发复活：
   - 目标在自己家中（安全屋）复活；home 被毁时按下方回退顺序处理
   - 复活 HP = ⟦bal:m9_talents_extended.t7.revive_hp⟧（暂定 12，待风洞）
   - 保留全部物品（武器、护甲、道具）
   - 立刻处于清醒状态（可以在下轮行动）
   - 恢复已破碎且可再生的护盾：
     * 魔法护盾：恢复到初始值
     * AT 力场：恢复到初始值
     * 不恢复：铁之荷鲁斯、一次性护甲
   - 清理死亡关系：
     * 击杀者不获得击杀计数
     * 犯罪记录不成立
     * PP/评分系统视为"未死亡"
   - **复活后 SP=0**（v0.3 冻结）：普通死亡清 SP、普通复活也从 SP=0 重新开始；
     只有 G5「彼岸」诗的明确强化可以把复活后 SP 置为 2（见 §2.3）

③ 兑现后天赋落幕：
   - 伏笔标记消耗
   - T7 天赋**永久落幕**：全场一次性，不能重新挂载（v0.3 冻结，删除旧“重新挂载
     新伏笔”文本）

复活位置回退顺序（v0.3 明确）：
1. 目标家中（安全屋）；
2. home 被毁：改为“效果结算时的当前位置”就地完成；
3. 当前位置也不可站立：使用 G1 v0.3 的最后安全地点兜底
   （见 [G1 火萤 RFC v0.3](m9_g1_firefly_burn_cycle_rfc_v0.3.md) §五），平局按
   确定性顺序裁决（先攻降序、再 actor ID，不做随机）。

特殊规则：
- **`DIRECT_DAMAGE` 不是自动绝对死亡**（2026-08-09 B5 W9 澄清）：
  G0 十字炮火是 `DIRECT_DAMAGE` 但不带 `absolute_death`，仍可被保险复活承接；
  G7 Terror 攻击与 G4 死星天裁因携带 `absolute_death` 标签才跳过复活。因此
  "是否跳过复活"由来源的 `absolute_death` 标签决定，不由 `DIRECT_DAMAGE` 身份推导。
- **绝对死亡绕过**（结算 v0.3 §6.8）：携带 `absolute_death` 标签的致死结果绕过
  普通死亡替代、死亡免疫与复活，除非来源明文声明优先级更高。
- 若目标始终未死亡，伏笔持续到游戏结束；T7 始终不落幕，但伏笔全局唯一、不可重挂。
- 不批量净化 buff/debuff（只恢复护盾，不移除石化/震荡等）
```

### 2.3 与 G5「彼岸」诗的交互

G5「彼岸」诗强化 T7 的复活效果：

```
献予「彼岸」之诗（已定稿）
- 消耗：`⟦bal:m9_talents_extended.g5.poem_cost⟧` 追忆，占标准行动
- 目标：持有 T7 的玩家
- 效果：目标获得「彼岸的守望」标记；当目标因死者苏生复活时：
  ① 复活后 SP 立即置为 2（而非通常的 0）
  ② 复活前可选择携带一件指定的常规装备（武器/护甲）
  使用后标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

**交互逻辑**：
- 「彼岸的守望」标记独立于「保险伏笔」
- 复活触发时，两者效果叠加：
  - 基础复活（T7）：家中复活 + HP=12 + 保留物品 + 恢复护盾 + **SP=0**（普通复活）
  - 诗篇强化（G5）：**把复活后 SP 置为 2** + 携带指定装备
- 诗篇标记消耗，伏笔标记也消耗（一次性保险照常落幕）

**普通复活 SP=0 与彼岸例外（v0.3 冻结）**：
- 普通死亡、普通 T7 复活都把 SP 置为 `0`（对齐行动 v0.8 §4.4）；
- 只有 G5「彼岸」诗登记为“把复活后 SP 置为 2”的**自动就绪白名单**来源——不是关注、
  不额外排入公演队列、也不刷新本轮关注上限；
- 该来源已在 [行动系统 RFC v0.8](m9_action_system_rfc_v0.8.md) 的自动就绪
  白名单中登记（与 G4 濒死燃尽并列），不能靠本迁移合同的草稿单方生效。

### 2.4 设计说明

**删除学习前置的理由**：
- 旧版需要 3 个行动槽（2 次学习 + 1 次挂载）= 至少 3 轮准备
- M9 全员行动后，节奏加快，3 轮准备过慢
- 学习地点限制（魔法所）与 M9 的开放行动哲学冲突
- 简化为"演出直接挂载"，保持天赋核心（复活）同时提升可用性

**一次性保险（v0.3）**：
- “死而复生”作为救赎叙事的唯一兑现，全局一次更符合“死者苏生”的传奇强度；
- 全局唯一标记消除 v0.2“覆盖旧伏笔”与“兑现后重新挂载”的文本矛盾；
- 兑现后 T7 永久落幕，使 T7 的强度预算可集中在一发完整复活上，不必为无限重挂
  削弱每次复活数值。

**保险在 T7 死亡后继续存在**：
- 符合"伏笔"主题：已埋下的伏笔不因 T7 死亡而消失
- 提供战术深度：T7 可以"牺牲自己保护队友"
- 平衡性：T7 死后无法挂载新伏笔，只有已挂载的生效

**复活位置固定为家中**：
- 旧版保留此设计
- 防止复活变成"战场急救"（那是其他天赋的职责）
- 复活后需要重新回到战场，给对手反应时间
- home 被毁时的回退兜底见 §2.2（确定性的就地回退 → 最后安全地点）

### 2.5 与其他系统的接口

| 系统 | 接口点 |
|---|---|
| 行动系统 | 即演 1 SP 或公演 2 SP，占用标准行动槽；普通复活后 SP=0 |

| 结算合同 | `DIRECT_DAMAGE` 不是自动绝对死亡；是否跳过复活看 `absolute_death` 标签（结算合同 RFC v0.3 §6.6/§6.8） |
| G5 诗篇 | 「彼岸」诗强化复活效果；复活置 SP2 需在行动 v0.8 自动就绪白名单登记 |
| PP/评分 | 复活清除击杀关系，不计入击杀者的评分 |
| 犯罪系统 | 复活清除犯罪记录 |
