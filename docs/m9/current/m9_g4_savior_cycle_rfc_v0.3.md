## 一、设计目标与非目标

G4 不再是“濒死后取得一段攻击力与范围伤害加成”的一次性被动。目标形态是一个可重复的
救世主循环：人形态积累火种，救世主形态用强化普攻与强化技能积累毁伤，再以一次公开的
Boss 公演结算反击和死星天裁，退场后从头踏上下一次轮回。

本稿不会照搬原作中只为 PVE 敌群服务的出伤拓扑。特别是：

- 不复制十六次随机弹射再追加一次均摊；
- 不让人数成为无条件的范围伤害乘区；
- 不以真实完整行动拉条制造跨轮行动债；
- 不让一次公演递归打开其他天赋演出或完整额外行动。

## 二、资源与形态生命周期

### 2.1 火种与轮回

1. 火种上限固定为 **12**；`balance.json` 中的 20 不进入 M9 目标规则。
2. 火种只在人形态积累；救世主形态中不再获得火种。
3. 完整进入救世主时消耗 12 火种。每次进入形态都把 SP **设置为 2**，不是 `+2`，且不
   刷新本轮关注上限、不创建行动槽、不自动报名公演。
4. 退出救世主后火种回到 0，天赋不落幕、不永久失效，重新开始下一次轮回。
5. 救世主形态仍可按普通关注合同取得 SP；达到 2 后由玩家决定保留或报名合法公演。

**火种来源（W2 冻结，v0.3 逐类枚举）**：火种只在人形态通过以下两个入口积累，每全局
轮次合计至多 +2：

| 来源 | 条件 | 增量 |
|---|---|---|
| 外来敌对效果 | 人形态每轮**第一次**外来敌对效果 | +1 |
| 外来正面转移 | 人形态每轮**第一次**外来正面转移 | +1 |

**外来敌对效果（v0.3 明确枚举）**——每轮只计**第一次**满足任一：

- 其他玩家或受 G4 以外玩家控制的单位对 G4 发起的**合法攻击**（无论命中与否，合法
  攻击即计入）；
- 对 G4 施加的**控制类效果**（震荡、压制、石化等普通/高级控制）；
- 对 G4 施加的**负面效果**（debuff、伤害性标记、削弱类效果）。

**不计入外来敌对**：

- 持续伤害 DOT 的后续 tick（只有施加该 DOT 的那次效果计一次）；
- 环境 / 世界时钟伤害；
- G4 自己的自我消耗、自我 debuff。

**外来正面转移（v0.3 明确枚举）**——每轮只计**第一次**满足任一：

- 其他玩家或受其他玩家控制的单位对 G4 的**外部治疗**（HP 恢复，含魂援/援助类）；
- 对 G4 的**诗篇效果**（献诗、爱愿等正面诗篇施加）；
- 对 G4 的**装备/资源转移**（给予武器、护甲、道具、资源）。

**不计入外来正面转移**：

- G4 自己的自疗、自我增益、自我装备；
- 环境自然恢复 / 世界时钟治疗；
- G0 世界援助「昨日的同伴/绫音的急救」：其 `source_kind=WORLD_RULE`，没有其他玩家或受控
  单位作为提供者。即使实际回复了 G4 的 HP，也不产生火种。

- 退役旧的“限定使用次数来源额外 +1”口径：没有一次性来源能把单轮火种推到 2 以上；
- 上限 2 与进入门槛 12 一起保证：一轮完整积累至少需要 6 个事件轮，普通只挨打路径约
  12 轮，六人集火不能一轮灌满。

**进入条件（W2 冻结，v0.3 补全地板）**：

- **12 火种**：进入**完整救世主形态**；
- **未满 12 遭致命伤**：进入**残缺救世主形态**并消耗当前全部火种，保留“致命伤自动
  转折”承诺；残缺形态仍自动把 SP 置为 2；
- **0 火种遭致命伤（v0.3 冻结）**：火种为 0 时受到普通致死伤害，仍进入残缺救世主
  形态，按 **1 余烬等效最低地板**缩放——引用新数值键
  `⟦bal:m9_talents_extended.g4.ember_floor⟧`（数值待风洞，语义为“相当于持有 1 火种”
  的最低余烬生命与最短持续时间）；残缺形态照常消耗（0 火种）、退出后火种为 0；
  该地板保证“零火种必死”不会绕过形态流程，也让回血/余烬不因归零而失去保护意义；
- 满 12 后默认储存在人形态，**仍只在致命伤时自动进入**；「负世」诗才解锁主动进入
  （§七）；
- 火种只缩放余烬生命和最大持续时间，**不恢复旧攻击力 / AOE 固定加成**（见 §八退役）。

**残缺救世主（W2 冻结，v0.3 补全）**：

- 残缺形态与完整形态共享毁伤与 Boss 公演核心（焚诏拉条—反击—天裁）；
- 残缺形态不保证能在短寿命内排到公演，也不恢复任何旧攻击力 / AOE 固定加成；
- 残缺形态的余烬生命与持续时间由当前（消耗时）火种量缩放，火种为 0 时按
  `⟦bal:m9_talents_extended.g4.ember_floor⟧` 最低地板（数值待风洞）；
- 残缺形态退出后火种为 0，仍回到人形态进入下一次轮回。

### 2.2 毁伤

毁伤是救世主形态内的局部预算：进入形态后建立，退出时清空，不能带回人形态。毁伤上限、
入场值、强化普攻获取量和开启公演的最低值均待风洞；唯一冻结的结构是：本次公演消耗的
毁伤量 `D` 同时成为死星天裁的初始“天裁段数”。

天裁段数是一个伤害预算标尺，不代表调用伤害流水线 `D` 次。最终只生成明文登记的批量
伤害结算。

## 三、救世主形态内的普通行动

### 3.1 强化普攻

救世主形态内的普通攻击替换为天赋自带的强化普攻：

- 占用本人的标准根行动，不消耗 SP、不创建额外行动；
- 第一版只建立一个单体攻击负载，不保留无条件扩散；
- 正常经过属性、防御、护甲、伤害下限、犯罪与死亡结算；
- 结算后获得待风洞数量的毁伤。

玩家仍可选择移动或其他合法普通行动；没有使用强化普攻就不取得该次毁伤。

### 3.2 强化技能与公演根入口

强化技能不直接复制“令敌人获得完整行动”。它与死星天裁合并为一个需要 SP=2 和足够毁伤
的 Boss 公演根入口：

```text
灾厄·弑魂焚诏
→ 全体秘密承诺“攻击 / 拒战”
→ 拉条反应攻击
→ 对攻击者的统一反击
→ 对拒战者的死星天裁
→ 公演收尾
```

这份全桌批量版本属于公演，不开放为普通即演。是否以后提供不拉全桌的较小即演版本，必须
另行登记，不能从本稿自动推导。

## 四、焚诏拉条窗口

### 4.1 建立快照与减伤

公演开始时：

1. 消耗本次毁伤，记录 `D`，天裁段数设为 `D`；
2. 对除 G4 外的所有存活玩家建立参与快照，公演临时解决距离与面对面要求，但不解决武器费用；
3. G4 获得只在本次拉条反应攻击期间生效的救世主减伤；
4. 临时可达性只用于挑战攻击；NPC 使用与玩家相同的秘密二选一，由其普通战斗效用决策，
   不读取其他承诺。只有减伤与攻击数值留待风洞。

**纳入边界（W3 冻结，v0.3 明确）**：

- 除 G4 外的所有存活玩家都进入秘密承诺，并由公演临时解决距离/面对面，不解决武器费用；
- 中立警察与未登记为合法战斗单位的普通 NPC **不纳入**（v0.3 保留：除非该 NPC/警察
  已在快照前把 G4 视为合法敌对目标，或已收到对其的合法指令）；
- **合法攻击载体（v0.3 冻结）**：每个纳入快照的玩家/受控单位都必须拥有可用的合法
  挑战攻击——公演领域为每名纳入者提供**一个合法基础攻击载体**：
  - 该载体从该单位当前合法攻击中选择**预结算 `A` 最高**者；平局依次取消耗的弹药/道具
    数量最少者、装备槽 ID 最小者、攻击 action ID 字典序最小者，正常产生攻击结算；
  - 若当前没有任何合法攻击可用（无武器、无弹药、被禁止等），退化为**基础拳击**
    `⟦bal:m9_talents_extended.g4.challenge_punch⟧`（普通近战基础载荷，数值待风洞）；
  - 正常弹药/道具消耗照常发生；临时可达性与面对面由公演领域临时解决；
  - 不产生犯罪、不产生 SP、不产生关注、不产生额外行动与警务自动攻击额度
    （挑战豁免，§4.3 犯罪豁免口径适用）。
- **普通层控制不封锁反应**：震荡、石化、压制、睡眠与自我怀疑只改写 `ActionGrant`，
  不消费、清除或阻止 `challenge_response`；这些状态在挑战后原样保留。死亡、撤退、流放、
  结界隔离或其他“已经不在同一合法作用域”的结构状态才令单位不进入快照。
- **隔离边界优先**：公演临时解决普通距离与面对面，但不穿透 G3 固有结界。G4 在结界内时
  只纳入同一结界内的其他合法战斗单位；G4 在外时排除所有被结界捕捉者。其他明文隔离
  覆盖层同理。

### 4.2 秘密承诺

所有参与者先秘密提交“攻击救世主”或“拒绝攻击”。在全部选择锁定前，不公开已经有多少
人攻击、天裁还剩多少段。电子裁判可以依次收集但延迟广播；实体桌面使用同时出牌或手势。

秘密承诺用于阻止后选择者观察到别人已经削弱天裁后再无风险拒战。AI 与非玩家单位必须从
同一份提交时快照决策，不能读取尚未公开的其他选择。

### 4.3 拉条反应，不是完整行动

选择攻击的单位按本轮先攻顺序立即执行一次 `challenge_response`：

- 它是当前公演中的受限反应步骤，不是 `ActionGrant(kind=full_extra)`；
- 不进入 T0/T1/T2，不消耗或预支本轮、下轮的标准行动槽；
- 只能结算一个正面白名单攻击载荷（§4.1 合法基础攻击载体），不能移动、交互、发动
  天赋、公演或警察指令；
- 不刷新或产生 SP、关注、公演位与完整额外行动；
- 武器费用、弹药和固有攻击责任正常归响应者；
- **犯罪豁免（W3 冻结，v0.3 保留）**：`challenge_response` 是受邀挑战，**不登记攻击
  G4 的犯罪**；挑战响应不产生 SP、关注、额外行动和警务自动攻击额度；
- 每完成一个合法挑战攻击，天裁段数 `−1`，最低为 0，并把响应者标记为反击对象。

**与 R3 的唯一接线顺序（v0.3）**：G4 的公演根行动在此暂停；全部承诺锁定后，所有选择
攻击者按公演快照的先攻降序、再按 actor ID 逐个完成响应。响应者本轮标准行动已用或尚未
轮到都不影响该反应，也不会删除、预支或重排其标准行动。全部响应、统一反击与天裁结算完毕，
G4 的公演才进入演出/系统收尾；随后全局 R3 从 G4 在原先行动队列中的下一项继续。任何
`challenge_response` 都不能插到另一个响应中间，也不能另开 T0 或反应栈。

真实完整行动拉条会迫使已行动者借用下一轮、未行动者从后续队列删除，并重新打开 T0 与
递归收益。本稿明确不采用这种行动债模型。

## 五、反击、死星天裁与真正打断

### 5.1 目标分流与固定总池

选择攻击的单位进入“反击对象”集合；拒绝攻击的单位进入“天裁对象”集合。两者互斥：

- G4 对全部反击对象只建立一个**固定总反击池** `counter_total(D)`，在全部攻击者间均分；
- 剩余天裁段数形成**固定总伤害池** `judgment_total = S × J`（`S = max(D − a, 0)`），只在
  天裁对象之间分配；
- 天裁伤害不会按天裁对象人数复制，人数只改变同一总伤害池怎样分配；
- 若无人攻击，不结算反击，完整天裁池由全部拒战者分配；
- 若所有参与者都攻击，天裁视为被集体打断，只结算统一反击。

**分配与取整（W3 冻结，v0.3 确定性平局）**：

- 反击与天裁都使用固定总池，**不按人头复制伤害**，不重新引入人数乘区；
- 均分后的余数按公演快照中的**固定顺序逐点分配**，禁止随机丢失或复制伤害；
- **固定池顺序（v0.3 冻结）**：参与者的分配/余数顺序按**先攻降序，再按 actor ID**
  排序（即从先攻最高的单位开始逐点分配），不做随机，与 G1 v0.3 最后安全地点同一口径；
- 每段天裁对应的总伤害 `J`、反击池 `counter_total(D)` 的具体函数与均分取整细节继续留给
  数值风洞。

### 5.2 强制退场中断公演

若挑战攻击在窗口中迫使 G4 退出救世主形态：

1. 停止尚未执行的挑战反应；
2. 取消本次统一反击；
3. 取消本次死星天裁；
4. 转入合法的退场技与形态清理。

因此“攻击救世主”不仅削减一个天裁段数；集火成功可以真正打断整次蓄力。攻击者承担反击
风险，拒战者承担随着拒战人数减少而集中的天裁风险，不存在无条件安全的搭便车位置。

### 5.3 死星天裁的伤害身份

死星天裁是明文登记的批量伤害结算，不是“不看伤害值直接判死”：

- 天裁与统一反击统一登记为结算合同 `DIRECT_DAMAGE`：跳过属性防御、护甲和普通固定减伤，
  直接令 `H = A`；仍可被明文替身/重定向/绝对免疫承接，仍触发伤害、关注和死亡流程；
- **只有致死结果**才附带 `absolute_death` 标签：该目标跳过 T7 并进入绝对死亡白名单；
- `absolute_death` 不改变伤害值，也不提前于伤害流水线触发；
- G4 侧不再自造“真伤”语义；`DIRECT_DAMAGE` 与 `absolute_death` 的公共定义以
  [`m9_resolution_contract_rfc_v0.3.md`](m9_resolution_contract_rfc_v0.3.md) 为准。

## 六、形态寿命、致死处理与公演队列

**完整形态寿命（W3 冻结，v0.3 保留 6 tick）**：完整形态持续 **6 个完整 R4 tick**——
从进入形态之后的第一个 R4 开始计数，**进入形态的当轮 R4 不扣**（对齐行动 v0.8
“建立轮 R4 不 tick”口径）。

- 仍按公演 FIFO 排队，不插队、不暂停倒计时；
- 六人最坏初始队列下，G4 可在最后一轮取得一次公演；队首失效也不会扩大上界；
- 未强化 G4 没有主动即演核心，不能靠“改即演”在队列中抢跑；若形态寿命在取得公演位
  前结束，形态自然退场并结算退场技。

**残缺形态寿命**：残缺形态的持续时间由当前火种量缩放，火种为 0 时按
`⟦bal:m9_talents_extended.g4.ember_floor⟧` 最低地板（待风洞）；若在取得公演位前结束，
同样自然退场并结算退场技。

**救世主形态内承受致死（v0.3 冻结）**：

- **普通致死伤害**：在救世主形态内被普通致死伤害命中时，该致死被**消耗**——
  G4 **不会死亡、没有击杀者、不进入往世层**；余烬生命若已耗尽，G4 以 **1 HP**
  退出救世主形态，并结算一次**退场技**（§八），随后以人形态继续游戏；
  该致死不产生死亡/击杀/往世层记录；
- **`absolute_death` 致死（v0.3 冻结）**：携带 `absolute_death` 标签的致死绕过上述
  消耗，**直接杀死 G4**（结算 v0.3 §6.8；例如 G5 锚定绝对实现、G7 Terror、G4 死星
  天裁的致死结果本身）——救世主形态不豁免绝对死亡；
- 绝对死亡后的往世层、PP、托管与终分统一服从结算 v0.3 §6.8 的 `absolute_dead` 合同，
  不在 G4 局部另设例外；
- 自然退场（寿命结束）不受影响，照常结算退场技（§八）。

## 七、负世诗主动进入

「负世」之诗允许满 12 火种的人形 G4 **主动进入**完整救世主形态（W2/W3）：

- 主动进入与致命伤自动进入是两条独立入口；满 12 后默认仍在人形态，无致命伤、无负世诗
  时不得进入；
- 负世诗主动进入在后续行动系统白名单中登记为一个**完整额外行动来源**
  `ActionGrant(kind=full_extra)`——该白名单口径**优先于 B1 行动合同 v0.1 中“负世主动
  燃尽不创建行动”的旧文本**，以后续行动系统 RFC
  （[`m9_action_system_rfc_v0.8.md`](m9_action_system_rfc_v0.8.md)）为准；
- 主动进入消耗 12 火种、把 SP 置为 2，其余形态规则与完整形态一致（寿命 6 tick、队列
  规则、退场技）。

## 八、退场收尾与现行加成退役

救世主因持续时间结束或普通致死消耗退出时，只执行**退场收尾**，第一版没有额外攻击、
治疗或“退场技”载荷：清空余烬生命、毁伤、公演临时状态与形态计时，火种置 0，返回人形。
自然到期保留当时本体 HP；普通致死消耗按 §六固定以 1 HP 返回。退场不读取 SP、不占行动槽、
不产生关注/PP/犯罪，也不重新打开公演。`absolute_death` 不执行退场收尾，直接走死亡清理。

目标实现应退役以下旧结构：

- `spent=True` 导致的天赋永久失效；
- 按火种换算的近战固定攻击力加成；
- 无条件范围攻击固定加成；
- 形态内整段只可使用一次的“破晓一击”；
- 限定使用次数来源额外 +1（W2）。

余烬生命或等价的固定形态生命池可以保留为 Boss 形态骨架，但不再与简单攻击力加成捆绑；
火种只缩放余烬生命与最大持续时间，具体数值、控制免疫及压制优先级必须服从 B0 结算合同
并进入 B5。
