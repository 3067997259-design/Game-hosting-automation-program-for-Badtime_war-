## 一、设计目标与非目标

### 1.1 目标

旧 G1 是"常驻数值加成 + 失熵倒计时 + 超新星"的静态组合，玩家对失熵没有任何交互手段，
92.9% 胜率问题疑似 AI 而非数值（见 memory：G1 过强本质可能是 AI 而非数值），但常驻
被动的结构本身也让强度极难调平。重置目标是复刻流萤这个角色**完整的弧光**，而不只是
"燃烧"一个关键词：

1. **卸甲的她是脆弱的普通女孩**——常态带负修正（全 14 天赋唯一），换来发育加速；
2. **穿上战甲才是战士，但燃烧就是在死**——形态阶梯与失熵累积绑定，参战即付生命；
3. **打出节奏而非站桩**——燃烧参战 → 撤离 → 卸甲调息 → 再燃烧的风筝循环，
   恰好回到原作者手册注记中这个天赋的起源（那局靠放风筝赢下的斑纹快攻）；
4. **第三次死亡**——繁育状态是必死的最后绽放，不是免死金牌。

### 1.2 非目标

- 不引入韧性条/削韧系统；超击破以"对受控/受灼烧单位增伤"近似（§五）；
- 不做失熵症的"治愈"机制——剧情至 4.3 未给出解法，机制只做"调息"不做"痊愈"；
- 不给完整额外行动——完全燃烧的"多动"以受限追加动作（ActionGrant 受限授权）实现，
  不进入 B0 完整额外行动白名单；
- "玩家在指挥 SAM 而非扮演流萤"的风味（对齐 G7 先例）只落在 `data/prompts.json`
  文案层（战术终端/SAM 系统播报口吻），不做任何机制。

## 二、形态阶梯

三段形态构成单向上行、可跌落的阶梯。形态是公开信息。

### 2.0 换装 / 卸甲宣言（v0.3 统一口径）

换装与卸甲都是**T0 兼容宣言**，需要在一个已被授予的槽位（标准行动或完整额外行动）
内声明：

- **着装**（→ 次级燃烧）：1 SP 即演式宣言，进入效果结算后消耗 1 SP；
  **宣言本身不消费行动槽**（与 G4 转折口径统一，2026-08-08 终审裁定，v0.3 保留）；
- **卸甲**（→ 卸甲常态）：免费宣言，不消耗 SP；
- 两者都不把槽位标记为 `spent`；宣言完成后的槽位仍可用于其他 T0 兼容内容或普通行动；
- 宣言的合法性预检先于 SP/槽位消费，预检失败不扣 SP、不占槽位（行动 v0.8 §4.3）。

### 2.1 卸甲常态「流萤」（默认）

- **负修正**：攻击输出修正 -⟦bal:m9_talents_extended.g1.unarmored_atk_penalty⟧、
  受到伤害 +⟦bal:m9_talents_extended.g1.unarmored_def_penalty⟧、
  命中值 -⟦bal:m9_talents_extended.g1.unarmored_acc_penalty⟧（视力受损——她曾以为萤火虫很美，
  后来才知道那是因为她视力不行）。
- **发育加速**：卸甲状态下每轮一次免费 `find`（不占行动槽；2026-08-08 终审自
  三候选中选定，直接服务"撤离—再定位—再燃烧"的风筝循环；结构先例为 G7 起床
  受限衔接 B1-D06）。该次免费 `find` 不是攻击类行动，不破坏 §2.1 调息条件。
- **失熵**：每轮 R4 累积 +⟦bal:m9_talents_extended.g1.entropy_gain_unarmored⟧（缓慢累积，
  **不暂停**——现实中的流萤离开战甲几乎无法生存，卸甲不是安全，只是更慢地死）。
- **调息**：卸甲状态下，若她本个行动回合未进行任何攻击类行动，R4 时失熵值
  -⟦bal:m9_talents_extended.g1.entropy_recover⟧（最低 0）。这是唯一的失熵回落通道。

### 2.2 次级燃烧「SAM·着装」（1 SP 宣言）

- **入口**：按 §2.0 着装宣言进入（T0 兼容、耗 1 SP、不消费槽位）。
- **禁发育**：find / interact 类行动被禁止——战甲不是用来逛街的。
- **数值加成**：攻击输出修正 +⟦bal:m9_talents_extended.g1.sam_atk_bonus⟧、
  受到伤害 -⟦bal:m9_talents_extended.g1.sam_def_bonus⟧，命中负修正消除。
- **超新星过载解锁**（§四）。
- **失熵**：每轮 R4 累积 +⟦bal:m9_talents_extended.g1.entropy_gain_sam⟧。
- **卸甲**：按 §2.0 在自己回合宣言卸甲（免费，回到 2.1）；**卸甲当轮仍按着装前的
  着装档累积失熵**（v0.3 冻结：以本轮行动开始时的形态档位结算失熵，防止“临收尾
  换回慢档”规避累积）。

### 2.3 完全燃烧（公演，2 SP，须处于次级燃烧中）

- 限时窗口 ⟦bal:m9_talents_extended.g1.full_burn_rounds⟧ 轮（建议 2–3，风洞）。
- **数值上探**：在次级燃烧基础上追加
  +⟦bal:m9_talents_extended.g1.full_burn_atk_bonus⟧ 输出修正。
- **自愈**：每轮 R0 回复 ⟦bal:m9_talents_extended.g1.full_burn_heal⟧ HP
  （对应原作强化战技回血）。
- **受限追加动作**：她的标准行动结算后，本回合内获得一次仅限**移动或攻击**的受限追加
  授予 `ActionGrant(kind=restricted_followup, source_id=g1_full_burn)`：不重新开放玩家 T0，
  只在控制预检后执行一个 `move` 或 `attack` 根行动并进入普通系统收尾；
  `allow_instant=false`、`allow_public=false`、`refresh_limits=false`、`depth=1`，不可再派生
  任何追加授予。它不进入完整额外行动白名单。每全局轮至多一次，只能由本轮的**标准行动**
  派生；完整额外行动、其他 `restricted_followup` 或反应不能再次派生。
- **超新星强化**：窗口内超新星伤害与灼烧层数上探
  （+⟦bal:m9_talents_extended.g1.full_burn_supernova_bonus⟧）。
- **失熵**：每轮 R4 累积 +⟦bal:m9_talents_extended.g1.entropy_gain_full_burn⟧（最快档）。
- **燃烧殆尽**：窗口结束时强制跌回卸甲常态（2.1），并立即承受一次失熵结算（§三），
  不论量表是否达到阈值。窗口内不可主动卸甲、不可续杯（重复公演）。

## 三、失熵症：从倒计时改为量表

### 3.1 量表

- 失熵值为 0 起步、上限 ⟦bal:m9_talents_extended.g1.entropy_cap⟧ 的公开量表；
  累积速率由当前形态决定（卸甲 < 次级燃烧 < 完全燃烧，见 §二各档）。
- 量表达到阈值 ⟦bal:m9_talents_extended.g1.entropy_threshold⟧ 时，当轮 R4 触发一次
  **失熵结算**，随后量表回落 ⟦bal:m9_talents_extended.g1.entropy_reset_amount⟧
  （非清零——疾病不会痊愈，只是压回一段）。

### 3.2 失熵结算顺序（v0.3 冻结：只损坏外层护甲）

1. 若持有炽愿（§六），可选消耗 1 层完全抵扣本次结算；
2. 否则**摧毁 1 件外层护甲**——失熵只损坏外层护甲（v0.3 冻结：删除 v0.2 未定义的
   “内层护甲耐久”第 3 步；外层全部清空后直接进入第 3 步 HP 损失）：
   - 若存在多个外层护甲，由持有者选择被摧毁的一件（不随机）；
   - 一层一层蚀甲：每多触发一次失熵结算就再摧毁一件外层护甲；
3. 完全无甲（无任何外层护甲）时，扣 ⟦bal:m9_talents_extended.g1.entropy_hp_loss⟧
   点 HP——这就是"护甲对失熵起缓解作用"的机制化：护甲是失熵的消耗性缓冲层，
   卸甲的她被失熵直接啃食血肉。
4. 失熵结算不构成"受到攻击"，不触发反击/关注/犯罪等任何战斗侧钩子。

### 3.3 R4 固定结算顺序（v0.3 冻结）

每个全局轮次 R4 内，G1 的结算严格按以下顺序执行，不得交错：

```text
1. 世界/终局检查
2. 繁育倒计时结算（若在繁育状态）——硬性绝对终止，先于一切失熵
3. 计算本轮失熵累积（按当前形态档位）
4. 若持有「飞萤的回响」，从**本轮待加入的累积量**中减去
   `poem_firefly_entropy_reduction`，最低把本轮累积降到 0，再把结果加入量表
5. 卸甲调息减量（卸甲常态且本行动回合无攻击类行动时）；持有「飞萤的回响」时，
   调息额外回落 `poem_firefly_rest_boost`
6. 失熵阈值结算（达到阈值触发 §3.2，随后量表回落）
7. 完全燃烧窗口到期结算（燃烧殆尽）
```

- **繁育倒计时**排在失熵之前：倒计时归零立即绝对死亡，跳过当轮失熵累积与失熵结算；
  繁育状态不再累积失熵（见 §五.3），该步实际为空。
- 任何来源都不能把失熵结算提前到繁育倒计时之前，也不能把调息减量放在累积之前。
- 世界/终局检查最先执行，与行动 v0.8 的 R4 公共阶段保持同源。

### 3.4 删除项

- 删除"固定轮数倒计时 + 行动不足延后"的整套世界时钟挂钩逻辑
  （呼应 memory：绝对轮数挂钩值须 balance 化并复核——此处直接消灭了挂钩本身）；
- 删除超新星发动后"失熵后延 3 轮"（失熵改由形态驱动后无此需求）；
- 删除"因血量低免疫眩晕"（眩晕已在 M9 退役）；
- 删除 v0.2 未定义的"内层护甲耐久"损耗步骤（§3.2，v0.3）。

### 3.5 终焉阶段增益

世界时钟进入终焉阶段后，失熵值**停止累积**（已有量表保留、结算照常）。
对应星核猎手的使命——应对"虚无"将宇宙导向的终末结局。仅此一条，不再加码。

## 四、DHGDR-超新星过载

- **形态门槛**：仅次级燃烧 / 完全燃烧 / 繁育状态可用。
- **获取**：进入次级燃烧时获得 1 次过载次数；完成击杀 +1；次数不叠加（上限 1）。
- **发动**：保留"由 move 行动触发、落点可为当前地点"的现有结构。落地后对地点内
  除自己以外的玩家与警察单位造成 ⟦bal:m9_talents_extended.g1.supernova_damage⟧ 点伤害，
  按 ⟦bal:m9_talents_extended.g1.supernova_pierce⟧ 处理穿甲，命中者获得
  ⟦bal:m9_talents_extended.g1.supernova_burn⟧ 层灼烧。
- **伤害属性**：普通属性 + 穿甲（沿用 B2-D06 已批准的属性口径；两段式结算下
  参数化为 `defense_coefficient` 折减，具体系数风洞）。
- **繁育状态下的超新星**：见 §五.4，附带地点摧毁；繁育超新星**不消费过载计数**
  （v0.3 冻结，见 §五.3）。

## 五、超击破近似与繁育状态

### 5.1 超击破近似（燃烧增伤）

M9 无韧性条。以下规则近似"击破 → 超击破输出窗口"：

- 次级燃烧及以上形态中，G1 对处于**任意控制状态**（震荡/压制/石化）或
  **灼烧/虚弱**的单位造成的伤害 +⟦bal:m9_talents_extended.g1.break_bonus_damage⟧
  （attacker_flat_bonus 位，进两段式合同第一段）。
- 她的超新星本身挂灼烧——"超新星点燃 → 后续攻击吃增伤"即自洽的输出循环，
  不依赖队友，也不需要为她单独发明状态。

### 5.2 繁育状态：触发

- **唯一触发条件**：完全燃烧窗口内受到**普通致死伤害**。触发时取代死亡，HP 置为
  ⟦bal:m9_talents_extended.g1.propagation_hp⟧，进入繁育状态。**必定触发，无概率骰**
  ——确定性对 RL/BasicAI/对手博弈推理均更友好；"星核是否还在她体内"的剧情
  留白放在 prompts.json 文案层表达。
- **绝对死亡不入繁育（v0.3 冻结）**：携带 `absolute_death` 标签的**来袭伤害**绕过
  繁育替代，直接杀死 G1（例如 G7 Terror 攻击、G4 死星天裁、G5 锚定绝对实现；
  结算 v0.3 §6.8）。普通致死伤害在完全燃烧窗口内才触发繁育。
- 每局至多触发一次。
- 对手侧的公共知识由此形成："不要在她完全燃烧时把她逼入绝境"本身成为全场博弈
  的一部分——补刀权在对手手里。

### 5.3 繁育状态：内容与倒计时

- **倒计时**：进入时获得固定 ⟦bal:m9_talents_extended.g1.propagation_rounds⟧ 轮倒计时
  （建议 3，风洞）。按行动 v0.8“建立轮 R4 不 tick”，从进入之后第一个 R4 开始扣。
  倒计时归零的 R4，G1 **绝对死亡**——登记进绝对死亡白名单
  （与 G5 锚定绝对实现、G4 死星天裁、G7 Terror 并列；T7 保险不赔付，
  见 [`m9_t3_t7_migration_rfc_v0.3.md`](m9_t3_t7_migration_rfc_v0.3.md) §二）。
- **倒计时死亡绕过一切免死/复活（v0.3 冻结）**：繁育倒计时归零的绝对死亡**绕过
  所有死亡替代、死亡免疫、T7 保险复活与返场扩展**（除非来源明文更高优先）；
  G1 在繁育期间若因**后来的普通致死伤害**死亡，则**可以**使用 T7 等普通复活
  承接（倒计时之外，普通致死照常走死亡流程）。
- **极端先攻**：每轮先攻获得 +⟦bal:m9_talents_extended.g1.propagation_initiative⟧ 加成。
- **繁育替换并结束完全燃烧窗口**（2026-08-09 B5 W7 批准）：进入繁育时，完全燃烧
  窗口**立即结束并被繁育状态替换**——不再按 §2.3 的"燃烧殆尽"跌落回卸甲常态，
  也不再继续按完全燃烧档累积失熵；繁育有自己的行动结构。
- **结构超新星，而非固定公演槽**（2026-08-09 B5 W7 批准）：删除旧候选"每轮 R4
  SP 置为 2 + 固定公演槽"。繁育状态下，**每个全局轮次的第一次合法 `move` 根行动**
  可以触发一次繁育超新星：
  - 它是繁育的**结构能力，不是演出**——不读 SP、不占用或请求公演位、不打开魂援 /
    诗篇 / PP 响应窗口，也不授予完整额外行动；
  - **不消费过载计数（v0.3 冻结）**：繁育超新星独立于 §四 的 DHGDR 过载计数，
    不受“每轮一次/击杀 +1/上限 1”约束；繁育形态下的每次首个合法 `move` 都可
    稳定触发，无需过载资源；
  - 仍占用正常的 `move` 标准行动槽：该槽先执行移动并结算，再于同一根行动内触发
    超新星，不赠送第二个行动槽；
  - 每个全局轮次至多触发一次；错过当轮第一次合法 `move`，本轮不再补触发。
- **失熵停止结算**——已经不重要了（R4 顺序中繁育倒计时先于失熵，且繁育不累积）。
- 繁育状态不可主动退出、不可被驱散；期间再次受到普通致死伤害则正常死亡
  （星核只有一枚）。
- **繁育期间可以获胜**：胜利判定在最后一个对手死亡的瞬间立即生效，优先于
  倒计时。为生而战打到最后一刻赢下来，是她能得到的最好结局。

### 5.4 繁育状态：超新星的地点摧毁（缩圈机制）

繁育状态下的超新星过载在正常结算后，**彻底摧毁**所在地点：

1. 地点获得 `destroyed` 永久标志，本局不再移除；
2. **不可进入**：所有单位（玩家、警察）的 move 目标验证直接拒绝该地点；
3. 地点内幸存单位在结算后被驱逐回各自 home；无 home 可回者（含 home 本身
   被毁的玩家）驱逐至最近的未摧毁地点；
4. 地面物品随地点一并销毁；地点功能永久消失（装备刷新、interact 选项等）；
5. **无豁免地点（警察局）**：警察局被毁则同步警察 / T6 联合重置 RFC v0.3 §3.4
   的停机收尾——关闭新举报与 R2/R4 自动推进、清除通缉/队长/掩体，幸存警察转为
   不自动行动的中立 NPC；
6. 摧毁事件写入 event_log（缩圈是公共信息）。

**home 就地回退（2026-08-09 B5 W8 批准）**：玩家 home 被毁后，其苏醒/复活类
效果的回退点改为"效果结算时的当前位置"就地完成；若当前位置也已不可站立，则使用
下述最后安全地点兜底。

**最后安全地点兜底（2026-08-09 B5 W8 批准，v0.3 确定性平局）**：

- 若地图上不存在任何未摧毁地点，"最近未毁地点"没有解。此时最后一个可站立地点
  **不可被普通繁育超新星摧毁**：伤害照常结算，但该地点的摧毁**失败**，并广播
  "世界已无处可退"；
- 该兜底只防空集，不削弱前两次缩圈；
- **平局裁决确定性（v0.3 冻结）**：多单位同时被驱逐或需要回退时，占用顺序按
  **先攻降序，再按 actor ID** 排序（即从高处先分配，不做随机），与 G4 v0.3 固定
  池顺序同一口径。

**设计理由（为什么摧毁不是叙事烟花）**：繁育 G1 只剩 3 轮寿命，对手的零成本
最优解本是"全员四散拖满倒计时"。地点摧毁使可站立地图持续收缩，把"躲猫猫三轮"
变成大逃杀式缩圈终局——对手必须在被赶进死角之前做出反抗或抱团的决策。摧毁是
繁育状态的**反拖延引擎**，没有它繁育状态在博弈上不成立。3 轮 ≈ 摧毁 2–3 个
地点，收缩得了局部、收缩不完全图，两侧均有操作空间。

**滥用面评估**：劣势玩家主动在完全燃烧期挨致死伤换 3 轮爆发——可接受。代价是
确定死亡，收益要靠 3 轮内翻盘，且触发权在对手手里（可以不打）。不加补丁，
风洞阶段观察。
