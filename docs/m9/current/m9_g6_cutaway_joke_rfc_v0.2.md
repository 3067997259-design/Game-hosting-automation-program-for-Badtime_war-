## 一、结论

旧 G6 通过"轮空/forfeit 积累笑点、用笑点借用他人合法行动"的设计与 M9 全员行动和 SP 演出
系统冲突；v0.1 又同时存在“即演继承天赋效果”与“模板不复制效果”“远程举报可借”与
“远程举报不可借”等自相矛盾的正文。

新 G6 的规则命题是：

> **G6 可以重演他人公开行动的动作类别，或在公演时借用一枚立即结算的白名单天赋核心 /
> 召唤一枚往世层援助，制造"你怎么有我的招式"的荒诞感和战术混乱。**

核心机制：
- **即演（1 SP）**：从当前窗口选择一个行动**类别模板**（move / interact / find / lock /
  attack），用 G6 自己的状态、装备、资源和目标重新执行，**不继承任何原天赋被动、效果或
  数值**；
- **公演（2 SP）**：两条**互斥**路径二选一——
  - **路径一**：借用一枚立即结算的白名单天赋核心（§四）；
  - **路径二**：召唤一枚往世层援助（§六，不消耗 PP、无死者配额）。

即演与公演各自独立成立，互不叠加；公演不能同时走两条路径。

## 三、核心机制

### 3.1 常驻被动：观察与记录

每个 R4，系统自动记录本轮已完成公共收尾的公开标准根行动，并按**行动类别**去重：

**记录内容（仅类别模板）：**
- 行动类别（`move` / `interact` / `find` / `lock` / `attack`）
- 行动者（player_id，仅用于展示）
- 位置（location，供合法性展示）

**不记录：**
- 原行动的天赋被动、效果与数值（模板不携带任何原天赋加成）；
- 原行动者、目标、武器、战果与额外行动；
- 天赋主动演出（即演/公演）；
- 完整额外行动；
- 反应步骤（T2 追猎反应、T4 反击）；
- 控制替代行动（压制后的 forfeit）；
- 起床、放弃、警察指令、副舞台和未登记 `special`。

**记录窗口：**
- 默认保留最近 1 轮（上一轮）
- 「欢愉」之诗可延长到最近 2 轮
- 第一轮开始时记录池为空，G6 不能即演重演；必须先执行普通行动。系统不提供预设
  保底模板（2026-08-08 B5-V3 裁决）

### 3.2 即演（1 SP）：重演类别模板

**入口：** T0，1 SP 即演，占用标准行动槽

**流程：**
1. 系统显示当前窗口的行动类别模板列表（去重后）
2. G6 选择一个类别
3. 系统检查前置条件：若该类别需要特定前置（例如近战需满足 G6 自身的面对面条件），G6
   必须满足；不满足则该类别灰掉不可选
4. G6 以自己的当前状态重新执行该动作：
   - 使用 G6 的位置、装备、资源
   - 可以重新选择目标（若该动作有目标选择）
   - **不继承**原行动的任何天赋被动、效果或数值
5. 责任归属：费用、犯罪、关注、击杀归 G6；不消耗被重演玩家的任何资源

**示例：**
```
R3: T1 在地点 A，面对面攻击玩家 B，触发核心斩击（2.0 倍伤害，防御 ×0.5）

R4: 系统记录类别模板 "attack @ 地点 A"（不记录 T1 的核心斩击数值）

R5 T0: G6 即演选择 "attack" 模板
- G6 必须满足自身攻击前置
- G6 以自己的武器攻击该目标，无 2.0 倍核心斩击加成
- 犯罪和击杀归 G6
```

### 3.3 公演（2 SP）：两条互斥路径

**入口：** T0，2 SP 公演，占用标准行动槽

G6 在本次公演中选择且只能选择一条路径：

- **路径一**：借用一枚立即结算的白名单天赋核心（§四）；
- **路径二**：召唤一枚往世层援助（§六）。

选定路径后，本次公演内部不切换到另一条路径，也不在借用核心之外追加普通标准行动或模板
重演。

### 3.4 路径一：借用白名单天赋核心

1. G6 选择一名在场玩家 A（可以是活人或濒死状态）
2. 系统列出 A 在本次公演可借用的白名单核心（§四）
3. G6 选择一个核心，以该核心的动作框架立即结算一次效果：
   - 使用 G6 的位置、装备、资源、目标选择
   - 不消耗 A 的 SP、行动槽、专属资源或责任
   - 不读取、不推进 A 的多轮/合同/额外来源
4. 借用核心结算完成后，本次公演结束；不追加标准行动

### 3.5 路径二：召唤往世层援助

1. G6 选择一名往世层玩家 B
2. 系统显示 B 的援助选项（进攻援助 / 防御援助）
3. G6 选择一个，B 从往世层提供援助
4. 援助效果按援助系统正常应用
5. **不消耗 PP**（G6 天赋效果）；不消耗往世层配额；提供者获得**系统铸造**的被动奖励
   （§六）

**荒诞感来源：**
- "G6 突然释放了 T1 的核心斩击" → T1：？？？
- "G6 借用 G3 投影了一把螺旋剑" → G3：这是我的招式！
- "G6 把已经死了的 T1 从往世层叫回来帮忙砍一刀" → 全桌：？？？

## 四、借用白名单（冻结）

### 4.1 可借用核心

| 天赋 | 可借用核心 | 执行语义 |
|---|---|---|
| T1 | 核心斩击 `core_slash` | 对合法目标结算 T1 核心：`skill_core_multiplier=2`、`defense_coefficient=0.5`；武器、加值、费用与责任用 G6，不继承 T1 其他被动 |
| T2 | 核心攻击（不含基础追猎） | 直接攻击；**不附带**追猎移动或“发现即免费追猎”的前置待遇 |
| T3 | 天星 `starfall` | 按 T3 v0.3 结算同地点 AOE + 基础石化，排除 G6 自身；不读取群星诗、尘世之锁或来源 T3 状态 |
| T4 | 六爻 `hexagram_cast` | 结算六爻；若结果为**或跃在渊**，重掷直到非或跃；**不产生完整额外行动** |
| G3 | 螺旋剑（伪）立即发射 | 只借用 G3 v0.2 §4.1 的单体螺旋剑攻击，读取其基础伤害/命中；不溅射其他单位、不消耗来源 G3 魔力、不留下投影，也不允许双刀/七重圆环/复制武器/固有结界 |
| G4 | 强化普攻（固定候选倍率） | 救世主形态强化普攻使用**固定候选倍率**；**不取得毁伤**，不继承毁伤获取 |

### 4.2 排除清单（不可借用）

| 排除对象 | 理由 |
|---|---|
| T6 | 市民热线/举报是天赋根行动，不在立即结算核心范围 |
| T7 | 复活伏笔是多轮合同/一次性兑现 |

## 五、借用核心的执行语义

- 借用核心使用 **G6 自己的 SP 之外的全部自身资源**：位置、装备、费用、目标选择与合法性；
- **不消耗来源玩家的 SP、资源、责任**，也不读取来源玩家的多轮/合同状态；
- 犯罪、威信、关注、击杀与评分全部归 G6；
- 反击/反伤等“针对攻击者”的效果指向 G6；
- 若 G6 当前状态无法合法满足核心的前置，该核心在消费 SP 前取消；
- 借用核心在一个公演内结算完成，不创建持续多轮的状态或合同；
- “只用 G6 状态”不删除核心本身的固有倍率、目标范围或即时控制：T1 的倍率/穿防与 T3
  的 AOE/基础石化属于被借核心；来源玩家的被动、诗篇、资源、成长与多轮合同才不继承；
- G2 已从借用白名单删除；旧 `broadcast/transfer` 名称不得作为隐藏兼容入口保留。

## 六、往世层援助

- **不消耗 PP**：这是 G6 的天赋效果，不是真正的援助消费；
- **无死者配额**：不占用往世层的投注/配额额度；
- **提供者被动奖励**：往世层提供者获得系统铸造的
  `m9_system.pp.aid_passive_reward` PP；不生成追忆，也不从 G6 或任何玩家账户扣除；
- 援助效果仍按援助系统正常结算（伤害加成 / 治疗 / 移除标记等）。
- 该路径是 G6 公演效果，**不消耗 G6 自己的四次魂援额度**，也不消耗提供者或其他玩家的
  四次额度；不得再由本次效果打开第二个援助交易窗口。

### 6.1 起床衔接的模板记录

G7 等来源在起床槽内实际执行的 `move` / `interact` / `find` / `lock` 若完成根行动收尾，
按该根行动类别进入 G6 模板池；单纯 `wake`、起床后结束或没有根行动的槽位不记录。

|---|---|---|

### 10.2 借用执行

```python
def execute_borrowed_core(g6_player, source_talent, core):
    # 检查白名单
    if core not in G6_BORROWABLE_CORE.get(source_talent, []):
        return {"error": "action_not_borrowable"}

    # 检查前置（使用 G6 自身状态）
    if not check_prerequisites(g6_player, core):
        return {"error": "prerequisites_not_met"}

    # 特殊裁决
    if source_talent == 't4_hexagram':
        result = roll_hexagram()
        while result == 'or_leap':
            result = roll_hexagram()          # 或跃重掷，无 full_extra

    # 以 G6 身份执行，不注入来源天赋效果
    result = execute_core(g6_player, core)

    # 责任归 G6
    assign_responsibility(g6_player, result)
    return result
```

## 十一、与其他系统的接口

| 系统 | 接口点 |
|---|---|
| 行动系统 | 即演/公演占用标准行动槽；借用核心在公演内立即结算，不追加标准行动 |
| SP 系统 | G6 消耗自己的 SP，不消耗被借用者 SP |
| 援助系统 | 召唤往世层援助复用现有援助机制，但不消耗 PP、无死者配额 |
| 完整额外行动 | 借用核心不产生完整额外行动（T4 或跃重掷）；T4 的 `full_extra` 不迁移给 G6 |
| 犯罪系统 | 犯罪责任归 G6，即使借用核心 |
| PP/评分 | 击杀和关注归 G6，用于 B4 评分计算 |
| G2 | 不在借用白名单；不允许从一次公演生成持续代理标准槽或永久终曲资格 |

- T4 或跃重掷的期望收益与重掷次数上限（无上限但收敛）；
- G2 必须持续从借用 UI、模板与兼容别名中排除；

- 借用核心在 G6 死亡、被控制或来源同时消失时的清理。

### 12.3 交互复杂度

- 借用核心是否与来源玩家的多轮合同产生意外交互（应不读取来源状态）；
- 往世层系统铸造奖励的具体来源与数量（B4 定）；
- 公演双路径互斥是否在 UI 上清晰可辨识。
