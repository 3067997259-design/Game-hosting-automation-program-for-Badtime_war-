## 一、结论

普通轮次只维护三个互不替代的概念：

| 层级 | 数据 | 只回答的问题 |
|---|---|---|
| 行动槽 | `available / spent` | 这一轮能做几件事？ |
| 先攻 | 一个公开排序值 | 这一轮什么时候做？ |
| SP | `0 / 1 / 2` | 个人天赋是否准备好？ |

底层合同是：

1. 每名正常存活玩家每轮获得一个标准行动槽；
2. 先攻只排列所有正常玩家的行动顺序，不淘汰行动者；
3. SP 不增加、删除或购买行动槽；
4. SP 达到 2 后，玩家自己决定何时即演，也可以自愿报名公演；
5. 公演队列只安排正式舞台待遇，不再拥有普通天赋的发动许可；
6. 完整额外行动保留为最高级奖励，但必须由明文白名单授予并受防递归边界约束。

## 二、标准行动槽

### 2.1 基础数量

每个全局轮次开始时，每名正常存活玩家获得一个标准行动槽。标准行动可以用于：

- 起床；
- 移动；
- 交互；
- 寻找、锁定或攻击；
- 警务行动；
- 普通特殊行动；
- 即演天赋；
- 本轮公演。

选择其中一个根行动后，该槽进入 `spent`。不存在可拆分消费的行动点，也不存在
`K = 存活人数 - 1` 的行动人数配额。

### 2.2 先攻

```text
标准行动队列 = 全部正常存活玩家，按先攻总值降序排列
```

先攻仍决定抢占物品、位移、攻击、控制和破坏演出条件的先后；普通先攻落后不再导致轮空。

### 2.3 追演

追演是当前根行动内部明文列出的一段附加步骤，不是第二个行动槽：

- 不重新进入 T0；
- 只能执行技能写明的行动类别；
- 不得再次发动天赋或公演；
- 不得继续产生追演；
- 同一根行动至多一次追演。

追演适合表达“移动后攻击”“举报后令警察移动”等连续镜头。

## 三、完整额外行动：最高级规则豁免

完整额外行动不被删除。它与无视属性克制伤害、绝对免死一样，是少量效果可以明确取得的
高级规则豁免，而不是普通天赋的通用频率工具。

### 3.1 定义

完整额外行动会创建一个新的标准行动槽，并完整执行 T0→T1→T2。它可以选择普通行动或
符合条件的即演，但不能取得第二个公演位。

### 3.2 硬边界

1. 效果必须带有明文的“授予 1 个完整额外行动”规则；“立刻行动”“追击”等旧措辞不能
   自动解释为完整额外行动；
2. 同一玩家每个全局轮次最多获得并执行一个完整额外行动；
3. 完整额外行动立即插入在当前根行动完成之后，不能储存到以后轮次；
4. 额外行动期间产生的任何“再获得完整额外行动”均不生效；
5. 不刷新每轮 SP 获取上限、关注上限、公演上限或一次性效果；
6. 不得用于发动公演；拥有 2 SP 时仍可即演，结算后正常清空 SP；
7. 副舞台内部若另有局部行动结构，必须明确是否允许该豁免，默认不带入也不带出。

### 3.3 首批候选白名单

- T4「或跃在渊」的稀有随机结果；
- T5 谱面达成 FC 的最高档奖励。

G5 诗篇或其他神代效果若要授予完整额外行动，必须在天赋 RFC 中逐项登记并重新评估，
不能批量继承旧版所有“次数 +1”或“立刻行动”。

## 四、SP：公开的二段就绪轨

### 4.1 状态

| SP | 状态 | 权限 |
|---:|---|---|
| 0 | 退场 | 正常行动，天赋未准备 |
| 1 | 蓄势 | 正常行动，等待下一次有效关注 |
| 2 | 就绪 | 可以即演或报名公演 |

开局 SP 为 1。SP 不交易、不计分、不兑换，也没有逐项行动价目表。

### 4.2 获取

一次已登记的有效关注令 SP +1，上限 2。每名玩家每个全局轮次最多通过关注增加 1 SP。

关注以公开行动的意图和风险为准，不依赖命中骰：

- 成为他人合法敌对或高影响行动的焦点；
- 主动执行会改变其他玩家生命、位置、控制、资源或公共身份的行动；
- 参与明文登记的公共争夺或高风险事件。

自我循环、无效目标、重复空指令和只改变私人界面的操作不产生关注。同一事件中焦点对象
先登记，发起者后登记；该顺序只用于同时报名时的先后，不额外给予 SP。

普通 SP 只由关注推进。个别自动转折若需要把表演时机交还玩家，可以明文“将 SP 置为 2”；
这不是关注，不额外排入公演队列，也不刷新本轮关注上限。首批候选仅登记 G4 濒死燃尽后的
就绪交还，其他天赋不能由旧版充能或次数奖励类推取得。

### 4.3 使用与回落

即演或公演进入效果结算后，演出者的 SP 在 T2 归零。失败、被抵抗或收益不理想不返还；
若在合法性检查前取消，则保留 SP。

一次演出不能给发起者自己返还关注。额外行动也不刷新本轮 SP 获取上限。

## 五、即演

任何拥有 2 SP 且其天赋允许即演的玩家，都可以在自己的普通或完整额外行动 T0 选择即演：

- 不需要本轮公演位；
- 占用当前行动槽；
- 结算天赋的核心效果；
- 不打开公演专属魂援、PP、喝彩和完结条窗口；
- 不取得只登记给公演的追演或 G5 诗篇适配；
- 结算后 SP 归零；若已在公演队列中则同时退出。

即演解决战术窗口。它不是反应技：除非技能明文为自动转折，玩家只能在自己的 T0 发动。

## 六、自愿公演

### 6.1 报名

达到 2 SP 不再自动入队。玩家可以公开选择：

- 保留 2 SP，等待未来即演；
- 报名公演；
- 报名后在轮到前改为即演，并退出队列。

报名不消耗行动。队列只包含已经承诺等待正式演出的玩家，因此删除 v0.4 的 R0 三人询问、
准备不足让位和自动 `L` 入队。

### 6.2 队列

公演使用公开 FIFO：

1. 按公开报名时间入队；
2. 同一事件双方同时到达 2 SP 并同时报名时，焦点对象优先；
3. 每个 R0 清理失效成员后，队首成为本轮唯一公演持有者；
4. R3 中途报名者从下一轮开始排；
5. 玩家退出或即演只会让后续排期提前，不会把别人向后推；
6. 持有者死亡、离场或失去全部合法选项时，本轮不临时递补。

### 6.3 公演待遇

公演仍占用持有者自己的行动槽。它可以获得：

- 技能登记的公演追演；
- 魂援响应窗口；
- G5“下一次公演”诗篇适配；
- 公演相关 PP、喝彩和完结条；
- G2、G3、G5 等需要全桌停下来处理的副舞台或仪式。

普通战术天赋的公演额外战斗预算原则上不高于约 0.5 SAE，避免把即演做成故意残缺的
假选择。副舞台、一次性伏笔和外部强化另行登记。

## 七、轮次接线

```text
R0  结算自动状态
    清理公演队列
    队首取得本轮唯一公演位

R1  所有正常玩家判定先攻
    只排列顺序，不裁掉任何玩家

R2  推进警察、世界时钟和公共状态

R3  所有正常玩家依次使用一个标准行动槽
    T0：处理控制；选择普通行动、2 SP 即演或持有者公演
    T1：结算一个根行动及至多一次追演
    T2：标记行动完成；登记关注与 SP；必要时插入一个完整额外行动

R4  结算持续效果、形态时间、世界时钟和胜负
```

时序边界：

- 别人在自己行动前使自己从 1 SP 到 2 SP，本轮轮到时即可即演；
- 自己通过本轮根行动才升到 2 SP，因为行动槽已经用完，通常留到下一轮；
- R3 中途达到 2 SP 不能临时取得公演位，但可以在尚未行动时即演；
- 完整额外行动若于 T2 获得，立即插入；它不改变其他人的原先顺序。

## 八、控制与离场

控制效果应限制或替换行动内容，不再修改一个隐形行动值：

| 状态 | 默认处理方向 |
|---|---|
| 睡眠 | 当前行动只能起床 |
| 眩晕 | 当前行动菜单受限，由控制规则给出挣脱/防御等选项 |
| 石化 | 禁止明文类别，但不隐式扣行动点 |
| 自我怀疑 | 明文把下一行动替换为反转结算 |
| 死亡/离开普通层 | 不进入普通行动队列 |

具体控制菜单需要单独设计；本 RFC 只冻结“不要再用行动值乘除和零点结算”的边界。

---

## 九、副舞台

G2 舞台、G3 幻想乡等可以拥有局部行动结构，但必须：

- 明确外部世界暂停还是继续；
- 进入时冻结或清理哪些普通状态；
- 离开时清空局部行动预算；
- 默认不把普通完整额外行动带入或带出；
- 不允许同一玩家同时取得外部标准行动和内部完整行动。

副舞台的复杂性封装在内部，不反向污染普通行动槽、先攻和 SP。

## 十、旧机制迁移

| 旧概念 | v0.5 处理 |
|---|---|
| K 行动人数 | 删除，全员一个标准行动槽 |
| 数值行动点 | 删除，改为 `available / spent` |
| D4 争行动权 | 改为只排列先攻 |
| 普通额外行动 | 改成追演、先攻或 SP |
| 最高档额外行动 | 明文白名单保留完整额外行动 |
| 数值型 SP 消费 | 改成 0/1/2 就绪状态 |
| 达到就绪自动入队 | 删除，玩家自愿报名 |
| 公演队列垄断发动 | 删除，即演不排队 |
| R0 三人询问 | 删除，只处理已报名者 |
| 控制扣行动值 | 改为限制或替换行动内容 |

## 十一、验证状态

v0.4 的纸面模型假设“全桌每轮最多发动一个天赋”，不能证明 v0.5 的同轮爆发安全。进入
实现前必须重建模型，至少统计：

1. 每轮即演数量分布，以及“一个公演 + 多个即演”的 P95；
2. 从 SP=2 到玩家主动使用的等待时间；
3. 即演、公演和长期保留 2 SP 的比例；
4. 完整额外行动与即演的同轮组合；
5. 双人 15/30 轮和六人 15/30/45 轮的个人发动次数；
6. G2/G3/G5 副舞台报名后的实际等待时间。

在这些验证完成前，v0.5 是已批准方向的设计候选，不是可直接修改引擎的数值定稿。
