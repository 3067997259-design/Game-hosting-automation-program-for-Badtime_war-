## 一、共享入口与全局规则

### 1.1 公演入口（共享）

- **形态**：仅德谬歌（`DEMIURGE`）；小昔涟与 `HOME` 不能献诗。
- **时机**：T0，G5 已报名并取得本轮唯一公演位后支付 2 SP，占用自己的标准行动槽
  （与锚定同级，服从行动系统 v0.8）；只有 SP2 而没有公演位不能献诗。
- **消耗**：`⟦bal:m9_talents_extended.g5.poem_cost⟧` 追忆；追忆是德谬歌诞生后不再增长的
  有限总预算。
- **目标**：选择一名持有对应天赋的玩家（每首诗绑定一个天赋槽位；目标缺该天赋即不可用）。
- **爱愿**：目标获得「爱愿」——除非目标就是 G5 自己，或对局为双人局。
- **重复献诗**：对同一目标重复使用同一首诗，只刷新爱愿与相关标记的剩余时长，不叠加
  诗篇数值。显式例外只有两处：「爱与记忆」的段数成长与「负世」的自动燃尽加成（§二 7 / 13）。
- **简化标记例外**：B4 的 G5 魂援与 G0 私人 `relic_memory` 只调用 §2.15 的简化标记，
  不属于献诗，不要求接收者持有对应天赋，不消耗追忆、不授予爱愿，也不触发献诗/锚定
  互斥或“完成献诗后重开微澜”。除此之外，任何渠道都不能绕过天赋绑定。

### 1.2 爱愿合同

- **持续**：从目标获得爱愿起，持续 **6 个未来 R4 tick**（`poem_lovewish_ticks`）。
- **不施加**：目标为 G5 自己，或双人局（对齐“双人局通常不施加爱愿”先例）。
- **身份**：爱愿**不是 buff 也不是 debuff**——它是献诗契约的连带条款，不可被驱散、
  无法被效果无视、不参与增益/减益结算或任何豁免。
- **行为约束**：爱愿持有者不能伤害 G5，也不能对 G5 施加 debuff。
- **破碎**：G5 主动攻击爱愿持有者时，爱愿立刻破碎（该次攻击正常结算）。

### 1.3 与锚定的互斥

- **一个激活中的锚定**阻止 G5 献诗（锚定监控期内不可献诗）。
- G5 存在由其授予且**尚未失效的爱愿**时，不可发动锚定。
- **延迟标记例外**：爱愿到期后仍存续的诗篇延迟标记（如「群星的弹射」「明天的承诺」
  等一次性 / 定时标记）**不阻止** G5 锚定。互斥只绑在爱愿存续期，不绑在标记存续期。

```
- 爱愿：正常施加。G0 目标通常不是 G5，走共享爱愿（§1.2）；仅当 G5 自身恰好持有 G0 且
  目标是 G5 自己时才无爱愿——这正是共享规则的默认情形，无需特殊豁免。
- 生命周期：6 ticks 或 3 uses，先到者。
- 叠加：不叠加；每件遗物对象限一次。
```

### 15. B4 / G0 简化标记诗篇（非献诗入口）

以下七项是 §1.1“简化标记例外”的**完整白名单与唯一效果**。接收者每次只取得一枚所选
标记；同名不叠加，只刷新。标记不会反向授予对应天赋：

| 简化标记 | 唯一效果 | 消耗点 |
|---|---|---|
| 游侠 | 接收者下一次对已锁定目标发起合法近战根攻击时，可在攻击前 `chase-move` 到目标地点；移动与攻击必须在预检时同时合法 | 攻击根建立时 |
| 群星 | 接收者下一次攻击对单位造成有效伤害后，可指定该单位所在地的一名合法单位（可以是原目标），追加 1 次 `poem_stars_bounce_damage` 无属性、`defense_coefficient=0` 的普通伤害；不施加或升级石化 | 弹射结算后 |
| 阴阳 | 接收者下一次由自身根行动发起的随机判定可掷两次并选择一个结果；任何会授予完整额外行动的结果都视为不合法并重掷 | 选定结果后 |
| 永恒 | 接收者下一次支付非 SP 的整数能力资源成本时，成本减少 `poem_eternity_cost_reduction`，最低为 0；HP 百分比成本、物品销毁与行动槽不属于该整数资源 | 合法支付后 |
| 飞萤 | 接收者下一次将承受自身来源的 HP 损失或持续伤害 tick 时，伤害减少 `poem_reduced_firefly_damage_reduction`，最低为 0 | 减伤后 |
| 追光 | 接收者下一次合法攻击获得 `poem_spotlight_damage` 固定攻击方加值；若攻击 actor 是接收者控制的存活代理 actor，造成有效伤害后恢复该代理 `poem_spotlight_shadow_heal` HP，否则无第二效果 | 攻击结算后 |
| 明天 | 接收者下一次能力效果需要摧毁一件自有物品或支付自身 HP 成本时，预检后选择免除其中一项；若只有一项则免除该项，SP、行动槽与其他成本照付 | 能力结算后 |

若标记等待期间对应事件始终未发生，则在本局结束时过期。B4 与 G0 不得使用“减半或类似
版本”自行生成第八种解释。
