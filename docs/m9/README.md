## 一分钟理解当前方案

| 问题 | 当前 M9 候选答案 |
|---|---|
| 每轮谁能行动？ | 每名正常存活玩家都有一个标准行动槽；G2 活跃普通影身是唯一额外代理标准槽例外 |
| 先攻做什么？ | 只决定这些行动的先后顺序，不淘汰行动者 |
| SP 是什么？ | `0 / 1 / 2` 的公开能力层级：0 无演出、1 可即演、2 可即演或公演；不是货币或逐效果价目表 |
| SP 怎样消费？ | 即演固定消耗 1；公演固定消耗 2。SP1 的选择是现在即演，或保留到 SP2 等待公演 |
| 即演与公演差在哪？ | 即演保留天赋完整核心；公演增加魂援、诗篇、PP、追演或副舞台待遇 |
| 被动和濒死效果怎么办？ | 常驻被动不读 SP；濒死、死亡、反转等自动转折也不由 SP 许可 |
| 额外行动还存在吗？ | 存在，但仅是明文白名单授予的最高级规则豁免 |
| 完整额外行动来源 | T4「或跃在渊」、G5「地火」诗与 G4 负世主动燃尽 |
| M9 有哪些天赋？ | 原初 T1–T4、T6–T7，加神代 G0–G7，共 14 个；G0 已取代原 T5 槽位 |
| T3 天星怎样释放？ | 仅能以 2 SP 公演，选择任一仍存在的地图地点；无即演入口 |
| 十四套天赋资源怎么办？ | 只保留会改变玩家决策的专属状态；纯次数、充能和冷却交给 SP |

普通轮次的阅读顺序是：

```text
R0 自动状态与公演排期
  → R1 全员先攻排序
  → R2 公共状态推进
  → R3 每个正常玩家一个标准行动槽；G2 普通影身另有自己的代理标准槽
       ├─ 普通行动
       ├─ SP≥1 即演（−1）
       └─ SP=2 的公演持有者公演（−2）
  → T2 登记关注；少数白名单效果可立即插入一个完整额外行动
  → R4 持续状态与胜负
```

## 已冻结的设计方向

1. 废除 `K=N−1` 的普通行动配额；全员拥有标准行动。
2. 先攻保留，但只排序。
3. SP 是能力层级，不是货币，也不增减行动槽：SP0 无演出、SP1 可即演、SP2 可即演或
   公演；即演固定 −1，公演固定 −2，不允许逐效果定价。
4. 主动天赋不再全部挤进每轮唯一发动位；玩家可以即演。
5. 公演采用自愿报名，只负责正式舞台待遇和副舞台。
6. 即演不能被故意削成残缺版；普通公演的增量原则上不超过约 `0.5 SAE`。
7. 常驻被动与自动转折不读取 SP。
8. 完整额外行动明文白名单保留，并受每人每轮一个、禁止递归等共同边界约束。
9. 完整额外行动只有 T4「或跃在渊」、G5「地火」诗和 G4 负世主动燃尽三个来源；不得从
   退役 T5 或普通 G5 援助类推出第四个来源。
10. G4 濒死仍自动燃尽；转折后把 SP 置为 2，但不凭空增加行动。
11. 眩晕退出 M9 通用状态；震荡是普通受限行动，压制是未来白名单的最高级跳过控制。
12. 伤害分为攻击方 `A` 与承受方 `H` 两阶段，`25%` 下限以 `A` 为基准。
13. 所有已授予行动槽统一进入系统收尾；根行动与演出钩子按显式事实触发。
14. R3 使用带来源、递归深度和权限位的 `ActionGrant`，不再只排玩家 ID。
15. G4 火种上限为 12；救世主退场后重新积累而不永久落幕。形态内以毁伤开启“焚诏拉条—
    统一反击—死星天裁”公演，真实数值留给风洞。火种来源（W2，2026-08-09）：人形态每轮
    敌对/正面转移各首个 +1、每轮上限 2；未满 12 遭致命伤仍进入残缺救世主并消耗全部火种；
    完整形态首轮风洞起点 6 个 R4 tick；反击与天裁用固定总池均分（W3）。
16. 警察改为案件驱动的固定中立力量：举报一次建立通缉并由 R2 自动出动；队长指挥现有
    警力且承担威信责任；T6 保留远程举报和特别线索，以 SP 演出负责警察配装。警察局被毁
    即停机收尾（W6，2026-08-09）：关闭新举报与自动推进，清除通缉/队长/掩体，存活警察
    成为不自动行动的中立 NPC；Terror 排除于合法执法目标池；G0/T6 遗物只生成一次性
    临时演出警察。
17. G2 最新重置（2026-08-10）：光身与影身共享一个玩家身份，但都是有位置、HP、装备、
    状态、先攻和标准槽的完整 actor；影身无限持续、使用真实物品，消散时至多一件合法实物
    跨地点归还光身。光身可用 2 SP 公演把影身永久承诺给《世末歌者》：立即永久失去再造
    影身资格，影身变为无行动槽歌者，在所在地建立全员易伤、伤害守恒共享、一次压制与概率
    离场移动偏转区域。旧全桌舞台和 duet 仍不迁入。
18. G3 不再迁移单目标时停猜拳。新核心以魔力投影螺旋剑、双刀、七重圆环和见证过的普通
    武器；2 SP 公演把当前地点替换为捕捉全部战斗单位的固有结界，但全局行动顺序继续，
    不生成内部行动。无限剑制开放兵装/防壁/剑阵并存，并以理想燃烧—幻想崩坏收束。
19. G5 最新重置（2026-08-10）：开局为有限寿命的小昔涟，普通致死/到期回家并封存追忆；

    行动，系统顺序投影并从差分抽取击败/摧毁/位移/获得事件；不声明预设结果、不搜索路径、
    不生成真实行动。候选事件按槽截止自然实现或以同一来源动作对实时状态再投影；成功安全
    窄回溯并得水晶花，因果改写不回溯但得花，来源死亡则粉碎。追忆不足后德谬歌向过去
    闭合退场。十四诗篇正文不改，只限德谬歌使用同一有限预算。
