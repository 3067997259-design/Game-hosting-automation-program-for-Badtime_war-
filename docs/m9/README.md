## 一分钟理解当前方案

| 问题 | 当前 M9 候选答案 |
|---|---|
| 每轮谁能行动？ | 每名正常存活玩家都有一个标准行动槽 |
| 先攻做什么？ | 只决定这些行动的先后顺序，不淘汰行动者 |
| SP 是什么？ | `0 / 1 / 2` 的公开就绪状态，不是货币、行动点或价目表 |
| SP=2 后怎么办？ | 玩家可在自己的 T0 即演，也可自愿报名未来公演；可以继续保留 |
| 即演与公演差在哪？ | 即演保留天赋完整核心；公演增加魂援、诗篇、PP、追演或副舞台待遇 |
| 被动和濒死效果怎么办？ | 常驻被动不读 SP；濒死、死亡、反转等自动转折也不由 SP 许可 |
| 额外行动还存在吗？ | 存在，但仅是明文白名单授予的最高级规则豁免 |
| 首批完整额外行动来源 | T4「或跃在渊」与 T5 FC |
| 十四套天赋资源怎么办？ | 只保留会改变玩家决策的专属状态；纯次数、充能和冷却交给 SP |

普通轮次的阅读顺序是：

```text
R0 自动状态与公演排期
  → R1 全员先攻排序
  → R2 公共状态推进
  → R3 每人一个标准行动槽
       ├─ 普通行动
       ├─ 2 SP 即演
       └─ 公演持有者公演
  → T2 登记关注；少数白名单效果可立即插入一个完整额外行动
  → R4 持续状态与胜负
```

## 已冻结的设计方向

1. 废除 `K=N−1` 的普通行动配额；全员拥有标准行动。
2. 先攻保留，但只排序。
3. SP 是就绪状态，不是货币，也不增减行动槽。
4. 主动天赋不再全部挤进每轮唯一发动位；玩家可以即演。
5. 公演采用自愿报名，只负责正式舞台待遇和副舞台。
6. 即演不能被故意削成残缺版；普通公演的增量原则上不超过约 `0.5 SAE`。
7. 常驻被动与自动转折不读取 SP。
8. 完整额外行动明文白名单保留，并受每人每轮一个、禁止递归等共同边界约束。
9. T4「或跃在渊」与 T5 FC 是首批白名单来源；G5 不能稳定复制它们。
10. G4 濒死仍自动燃尽；转折后把 SP 置为 2，但不凭空增加行动。

“已冻结”只表示后续 M9 设计应以此为前提，不表示已经修改 `v2exp` 或代码。

## 尚未冻结的内容

- 关注事件的最终枚举、反刷规则与 UI 表达；
- 睡眠、眩晕、石化等控制状态的新行动菜单；
- 信用点、PP、投注、魂援与往世层的重写版本；
- 十四天赋迁移后的完整数值；
- 即演并发、公演等待和完整额外行动的模型结果；
- M9 迁入 `v2exp` 的版本计划与代码实现。

这些问题应该各自形成小型 RFC 或审计，不再继续向一份“完全 M9 手册”无限追加。
