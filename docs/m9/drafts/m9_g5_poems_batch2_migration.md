## 一、献予「飞萤」之诗（G1 火萤燃烧循环）

### 当前 V2
- 消耗：12 追忆
- 效果：减少额外行动持续时间消耗、减少过载触发伤害阈值、额外行动最后一次自动执行超新星过载

### M9 冲突
G1 已整体重写为三段形态阶梯（卸甲/次级燃烧/完全燃烧）+ 失熵量表系统 + 繁育状态。旧版的"额外行动持续时间"与"过载触发伤害阈值"机制已不存在。

### 迁移方案（已定稿）

```
献予「飞萤」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 G1 的玩家
- 效果：
  ① 目标获得「飞萤的回响」标记；持有该标记时，每个 R4 的失熵累积
     -⟦bal:m9_talents_extended.g5.poem_firefly_entropy_reduction⟧（暂定 -1 或 -2，风洞定），
     最低降至 0（不能使失熵值变负）
  ② 目标在卸甲常态下使用「调息」时，失熵回落额外 +⟦bal:m9_talents_extended.g5.poem_firefly_rest_boost⟧
     （暂定 +1，风洞定）
  ③ 标记持续 ⟦bal:m9_talents_extended.g5.poem_firefly_duration⟧ 轮（暂定 6 轮），时间结束后消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
新 G1 的核心张力是"失熵累积 vs 调息回落"的燃烧-撤退循环。飞萤之诗强化这个循环的两端：减缓失熵累积速度（给更长的作战窗口），提升调息效率（更快恢复）。不碰繁育状态（那是必死的最后绽放，不应被诗篇延长），不碰完全燃烧窗口（那是 G1 核心限制）。数值保守起步，风洞时与 G1 本体失熵速率协调。

### 待裁决
- 失熵减缓具体数值（-1 或 -2）
- 调息额外回落数值（+1 或 +2）
- 标记持续轮数（建议 6 轮，与爱愿时长一致）

## 二、献予「欢愉」之诗（G6 插入式笑话）

### 当前 V2
- 消耗：12 追忆
- 效果：缩短冷却时间、不取整、克制不会直接被吞、命中更好

### M9 冲突
- G6 已删除冷却时间，改用 SP 演出入口
- "不取整"在新系统中无对应物
- "克制不会直接被吞"在新攻击流水线中无对应物
- "命中更好"在新系统中需重新定义

### 迁移方案（已定稿）

```
献予「欢愉」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 G6 的玩家
- 效果：
  ① 目标获得「欢愉的延展」标记；持有该标记时：
     - 行动记录窗口从默认的 1 轮延长到 2 轮
     - 即演（1 SP）可以从最近两轮的行动记录中选择
  ② 目标下一次公演（2 SP）盗用天赋时，可以指定两名不同在场玩家，分别借用
     其 T0 立即结算行动或标准行动，在同一个公演槽内依次执行（按指定顺序）；
     使用后此增强效果消耗
  ③ 标记持续到增强公演使用后消耗，或 ⟦bal:m9_talents_extended.g5.poem_joy_max_duration⟧ 轮
     （暂定 6 轮）后超时消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
G6 RFC §4 已经明确记录了欢愉之诗的方向："延长记录窗口到 2 轮，下一次借用可以从两个不同玩家选择"。本方案拆成两个效果：①常驻延长窗口（给即演更多选择），②一次性增强公演（可以"拼接"两个玩家的招式，制造更荒诞的组合）。数值保守，不碰 SP 消耗或责任归属。

### 待裁决
- 增强公演是"两个玩家依次"还是"两个玩家融合成一次行动"（建议依次，实现简单）
- 标记超时轮数（建议 6 轮）

## 三、献予「守夜人」之诗（G7 战术压制）

### 当前 V2
- 消耗：12 追忆
- 效果：从 Terror 召回，初始形态改为临战-Shielder，恢复部分光环和 Cost，立即获得一个战术道具和一个药物

### M9 冲突
无直接冲突。G7 RFC §7 已明确记录用户原话："色彩和 Terror 需要风洞的只有数值，没有机制……守夜人之诗不用改，最大作用仍然是把 Terror 拉回来，提供戏剧张力。"

### 迁移方案（完全保留）

```
献予「守夜人」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 G7 且处于 Terror 状态的玩家
- 前置条件：目标必须处于 Terror 状态（色彩 10，已失去一切）
- 效果：
  ① 解除 Terror 状态
  ② 目标切换至临战-Shielder 形态
  ③ 恢复光环至 ⟦bal:m9_talents_extended.g5.poem_watchman_halo_restore⟧ 层（暂定 3 层，风洞定）
  ④ 恢复 Cost 至 ⟦bal:m9_talents_extended.g5.poem_watchman_cost_restore⟧（暂定 3，风洞定）
  ⑤ 立即获得一个战术道具（手雷/烟雾弹/闪光弹/燃烧瓶，G7 选择）和一个药物
     （肾上腺素/止痛药/战地兴奋剂，G7 选择）
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
完全保留 V2 设计。Terror 是 G7 色彩 10 的"失去一切变成纯粹破坏者"特判，守夜人之诗是唯一能把 G7 从 Terror 拉回来的通道，提供"守夜人终于找到他了"的戏剧张力。数值（光环恢复层数、Cost 恢复值）待风洞，机制不变。

### 待裁决
- 光环恢复层数（建议 3 层，保守）
- Cost 恢复值（建议 3，约 60% 满值）
- 是否允许 G5 自己对自己使用（若 G5 持有 G7 且进 Terror）——建议允许，但无爱愿

## 四、G2×G5 duet 形式化退役（B3-D11/D12）

### 当前 V2
在 G2 舞台内由 G5 献诗发起，全桌投票决定是否接受；接受后进入 duet 特殊仪式（G2 歌唱、G5 献诗、双方获得特殊增益、全桌观众投票评价）。

### M9 冲突
- 旧 G2 全桌舞台（序曲、开幕、Chorus、声部、Regard、物料牌、投票机制）已整体冻结
- 新 G2 是"本体 + 全息影像"的双位置系统，不创建副舞台
- 新 G5 的锚定已改为 24/48 追忆双阶段系统，与旧 duet 的献诗消耗不兼容

### 形式化退役文档

```
G2×G5 duet
- 状态：suspended（暂时冻结）
- 退役日期：2026-08-08（M9 B3 批次）
- 依赖机制（已冻结）：
  ① 旧 G2 舞台的序曲/开幕流程
  ② Chorus 观众单位与声部分配
  ③ Regard 投票系统
  ④ 物料牌抽取与结算
  ⑤ 旧 G5 的灵活献诗消耗（12 追忆单次）
- 退役理由：
  依赖机制已随 G2 重置整体冻结。新 G2 的全息影像系统与新 G5 的锚定/献诗
  系统无法支撑旧 duet 的全桌仪式结构。
- 未来可能性：
  待新 G2 全息在场机制与新 G5 锚定/献诗系统各自成熟后，可能设计新的轻量
  G2×G5 联动形式（不在十四诗篇内，而是作为独立特殊机制）。可能方向包括：
  - 全息影像与锚定实体的双重存在互动
  - 献诗对全息影像的特殊增强
  - 锚定实体对 G2 歌曲的回响
  但具体设计需等两个天赋各自稳定后重新评估。
- 文档处理：
  ① 在 G5 诗篇列表中标记 `status: suspended`
  ② 旧 duet 机制文档（若存在）移至 `docs/archive/v2_duet_mechanism.md`
  ③ 在 `docs/m9/README.md` 和 `document_registry.json` 中记录退役事实
```

### 与 retired 的区别
- **retired**（永久退役）：目标天赋已删除（如 T5 旧不良少年），诗篇永久失去对象
- **suspended**（暂时冻结）：依赖机制冻结，但未来可能以新形式复活；为后续设计保留命名空间
