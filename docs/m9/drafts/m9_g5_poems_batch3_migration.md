## 一、献予「地火」之诗（T2 剪刀手传奇）

### 当前 V2
- 消耗：12 追忆
- 效果：立刻行动一次，犯罪再动和紧急战斗策略的触发次数立刻被重置；若无隐身则给予隐身

### M9 冲突
- T2 B1 已批准：犯罪/发现改为普通关注（不再送专属额外行动）；隐藏响应改为一次 find/lock 追猎反应
- "立刻行动"需白名单审查
- T2 已无"触发次数"概念

### 迁移方案（已定稿）

```
献予「地火」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T2 的玩家
- 效果：
  ① 目标立即获得一个完整额外行动（登记进完整额外行动白名单）
  ② 若目标当前无隐身效果，立即获得隐身
  ③ 标记持有者在该额外行动内完成犯罪或发现敌人时，必定触发一次追猎反应
     （find 或 lock，由玩家选择）
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
**保留"立刻行动"并登记进完整额外行动白名单**。理由：T2 老版本的核心强度来自多额外回合和战斗增益，删除立刻行动会使本诗失去主题。删除"重置触发次数"（T2 无次数概念），改为"必定触发追猎反应"（符合 T2 新身份：关注 + 反应步骤）。保留给隐身（地火主题）。

### 完整额外行动白名单登记
- **来源**：献予「地火」之诗
- **条件**：G5 对持有 T2 的玩家献诗
- **效果**：目标立即获得一个完整额外行动
- **与 T4/T5 并列**：白名单扩展为 4 个（T4 或跃 / T5 FC / 地火诗 / 负世诗）

## 二、献予「彼岸」之诗（T7 死者苏生）

### 当前 V2
- 消耗：12 追忆
- 效果：复活后立刻获得额外行动 + 行动前获得任意物品 + 允许指定往世层玩家满血返场

### M9 冲突
- "立刻行动"需白名单审查
- "任意物品"边界模糊
- "往世层返场"依赖未定稿的往世层系统（可能等 G7/G8 定稿）

### 迁移方案（已定稿）

```
献予「彼岸」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T7 的玩家
- 效果：目标获得「彼岸的守望」标记；当目标因死者苏生复活时：
  ① 复活后 SP 立即置为 2（而非通常的 0）
  ② 复活前可选择携带一件指定的常规装备（近战武器/护甲，不含特殊/扩展物品）
  使用后标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
**删除"立刻行动"**（T7 不需要依赖额外回合，复活本身已是强力效果）。改为"复活后 SP=2 快速准备 + 携带装备"，保留复活增强主题但不依赖未完成系统。删除"任意物品"（改为指定常规装备，避免边界模糊）、删除"往世层返场"（等 G7/G8 定稿，不在诗篇内提前实现）。

## 三、献予「追光」之诗（G2 请一直注视着我）

### 当前 V2
- 消耗：12 追忆
- 效果：易伤效果提高至 1 点，最大使用次数 +1；每次再发动本诗，易伤再提高 0.5 点

### M9 冲突
- 新 G2 全息在场 RFC 已明确：不使用旧 Regard 系统，全息攻击不附加固定增伤或易伤
- G2 已无"使用次数"概念

### 迁移方案（已定稿，名称暂定）

```
献予「追光」之诗（暂定名称）
- 消耗：12 追忆，占标准行动
- 目标：持有 G2 的玩家
- 效果：目标获得「追光的聚焦」标记；持有该标记时：
  ① 下一次全息攻击（转播或返场）伤害 +⟦bal:m9_talents_extended.g5.poem_spotlight_damage⟧
     （暂定 +1，风洞定）
  ② 该次全息攻击若造成有效伤害（命中且 damage > 0），影像持续时间延长 1 轮
     （影像不在 G2 下一个行动结束后落幕，而是延迟到第二个行动结束后）
  使用后标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 待后续处理
- **名称**：「追光」可能与新 G2 主题不完全匹配，待统一命名
- **数值**：伤害加成具体值需风洞

### 设计说明
删除"易伤"（G2 无此机制）、"使用次数 +1"（G2 无次数）、"递增"（首次迁移不堆叠）。改为"单次全息攻击增伤 + 影像延寿"，符合新 G2 的双位置战术核心（公开影像 + 转播/转场）。

## 四、献予「负世」之诗（G4 愿负世，照拂黎明）

### 当前 V2
- 消耗：12 追忆
- 效果：额外 +2 火种；追加主动启动方式（花 1 回合启动后立刻获得额外行动）；自动触发时再额外 +1 火种；每次再发动本诗，自动触发火种再 +2

### M9 冲突
- G4 RFC 已批准：12 火种轮回，主动燃尽已删除补偿回合
- "花 1 回合启动后立刻额外行动"需白名单审查

### 迁移方案（已定稿）

```
献予「负世」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 G4 的玩家
- 效果：目标获得「负世的火种」标记（计数器初始值 1）；持有该标记时：
  
  ① 立即效果：目标火种 +2（若当前在人形态，计入火种池；若在救世主形态，
     转化为 ⟦bal:m9_talents_extended.g5.poem_burden_annihilation⟧ 点毁伤，暂定 +5，风洞定）
  
  ② 解锁主动燃尽：若目标当前在人形态且火种 ≥ 12，可在自己的 T0 消耗当前
     标准行动槽主动进入救世主形态；进入后立即获得一个完整额外行动
     （登记进完整额外行动白名单，与 T4/T5 并列）
  
  ③ 自动燃尽增强：若目标因濒死自动燃尽触发，额外 +2 火种（在进入形态时生效，
     转化为毁伤）；每次再发动本诗，计数器 +1，自动触发额外火种按 `2 × 计数器` 计算
  
  标记持续到使用主动燃尽、或本局结束
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
**保留"主动启动立刻行动"并登记进完整额外行动白名单**。理由：符合救世主"绝境爆发"主题，主动燃尽是 G4 玩家的战术选择（提前触发转折换取行动优势），立即行动是这个选择的合理回报。火种 +2 在人形态和救世主形态分别有不同效果（火种池 vs 毁伤），保持双形态的资源转化逻辑。自动触发增强保留递增机制（每次再献诗，自动触发火种增益递增）。

### 完整额外行动白名单登记
- **来源**：献予「负世」之诗 + 主动燃尽
- **条件**：G5 献诗后，G4 在人形态且火种 ≥12，消耗标准行动槽主动进入救世主形态
- **效果**：进入救世主形态后立即获得一个完整额外行动
- **与 T4/T5/地火诗并列**：白名单扩展为 4 个
