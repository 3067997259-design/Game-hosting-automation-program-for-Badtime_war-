## 一、献予「游侠」之诗（T1 一刀缭断）

### 当前 V2
- 消耗：12 追忆
- 效果：技能可用次数 +1

### M9 冲突
T1 已删除 `uses_remaining` 次数概念，改用 SP=2 演出入口。次数 +1 无对象。

### 迁移方案（已定稿）

```
献予「游侠」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T1 的玩家
- 效果：目标获得「游侠的锋刃」标记；持有该标记时，下一次 T1 核心斩击：
  ① 必定命中（无视目标闪避值）
  ② 无视目标"受到伤害降低"效果（如火萤减伤、救世主余烬护甲等）
  使用后标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
新体系下 T1 删除次数限制后，失去了旧版的命中加成和减伤穿透。本诗针对性补偿这两个痛点，让一次斩击成为"完美的必杀"。符合游侠主题，且不滥用额外行动白名单。

## 二、献予「群星」之诗（T3 天星）

### 当前 V2
- 消耗：12 追忆
- 效果：天星落下造成伤害后，持有者额外指定两次目标（可同一单位）各造成 0.5 无视属性克制伤害；石化不因被攻击而自动解除

### M9 冲突
无直接冲突。T3 B2 候选已确认保留石化、推荐普通属性穿甲。

### 迁移方案
```
献予「群星」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T3 的玩家
- 效果：
  ① 目标获得「群星的弹射」标记；持有该标记时，下一次天星命中后，额外指定
     至多两次目标（可重复同一单位），各造成 ⟦bal:m9_talents_extended.g5.poem_stars_bounce_damage⟧
     点无视属性克制伤害；使用后标记消耗
  ② 目标当前持有的石化效果改为「群星锁定」：不因被其他单位攻击而解除，只能
     由目标自己在 T0 选择解除
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 待裁决
- 弹射伤害数值（建议起点 0.5，风洞定）
- 「群星锁定」是否完全免疫解除（包括 T3 自己再次天星是否能覆盖）

**推荐**：保留，主题清晰且无冲突。

## 三、献予「律法」之诗（T6 朝阳好市民）

### 当前 V2
- 消耗：12 追忆
- 效果：清除犯罪/赋予警察岗位/上任队长；威信 +2；指定警察立刻行动；召唤新警察（解除永久禁用、无视终焉）

### M9 冲突
- 警察无独立行动槽，不能"立刻行动"
- 不能无视终焉召唤警力
- 不能"解除警察局永久禁用"（警察局是地点，非天赋能改）

### 迁移方案
```
献予「律法」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T6 的玩家
- 效果（按目标当前状态判定，优先级从上到下）：
  
  1. 若目标有通缉：清除目标身上的全部通缉案件
  
  2. 若目标无通缉且不是警察：授予警察岗位（需服从警察系统当前人数上限；
     若已满员则此项无效）
  
  3. 若目标已是警察但非队长，且队长空缺：目标上任队长
  
  4. 若目标已是队长：威信 +2；且可为一名当前场上存活的警察单位配装一件
     T6 提供的装备（⟦bal:m9_talents_extended.t6.remote_equip_options⟧，如额外警棍/盾牌/
     陶瓷护甲）
  
  5. 若以上条件均不满足：目标下次远程举报公演的追忆消耗 -6（从 12 降到 6）

- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 待裁决
- 是否接受"阶梯判定"结构（根据目标状态给不同效果）
- T6 配装选项的具体白名单（需与警察 RFC 协调）
- 效果 5 的兜底折扣是否足够强

**推荐**：接受完全重写，删除所有与新警察系统冲突的部分。

## 五、献予「阴阳」之诗（T4 六爻）

### 当前 V2
- 消耗：12 追忆
- 效果：天赋可发动次数 +1；下两次天赋触发时，跳过判定，由玩家指定触发的效果

### M9 冲突
T4 已删除轮次充能与次数概念，改用 SP 演出入口。六种卦象结果保留。

### 迁移方案（已定稿）

```
献予「阴阳」之诗
- 消耗：12 追忆，占标准行动
- 目标：持有 T4 的玩家
- 效果：目标获得「阴阳的天机」标记（计数器初始值 2）；持有该标记时，T4 六爻
  公演可以直接选择其余五种结果之一（**不含或跃在渊**），不掷骰；每次使用后计数器 -1，
  归零时标记消耗
- 爱愿：若目标非 G5 自己，获得爱愿（6 轮）
```

### 设计说明
保留“指定卦象”核心功能，删除次数 +1。**不得指定或跃在渊**：完整额外行动必须保持稀有
随机来源，阴阳诗不能把它稳定复制；玩家仍可放弃指定并正常掷骰取得或跃。

### 关联改动：T4 或跃在渊本体
```
或跃在渊（M9 版本）
- 父行动与反应栈结算后，立即插入一个完整额外行动
- 该额外行动不消耗六爻持有者的本轮标准行动槽
```

本改动已同步到 [天赋行动迁移合同 v0.3](../current/m9_talent_action_contract_rfc_v0.3.md)；
阴阳诗只指定其余五种结果。

## 七、「爱与记忆」之诗（G5 自身）

### 当前 V2
- 消耗：`min(24, 12 + 4 × 已使用次数)`，最终超过 24 后无法再用
- 效果：选定不超过 n 个单位各受伤害；段数成长（开局人数决定基础段数，每次 +1 段）

### M9 冲突
**递增消耗到 24+ 后无法再用，与锚定首次门槛 24 冲突**（同一追忆池）。

### 迁移方案（已定稿）

```
「爱与记忆」之诗
- 消耗：固定 12 追忆，占标准行动
- 目标：G5 自己
- 效果：选定场上不超过 n 个单体单位（可重复，可含警察/NPC），各自受到
  ⟦bal:m9_talents_extended.g5.poem_destiny_stage_damage⟧ 点伤害；前 4 段依次为
  科技/普通/魔法/无视属性克制，第 5 段起均为无视属性克制
- 段数 n：
  - 基础值由开局人数决定：2 人局=2 段，4 人局=3 段，6 人局=4 段
  - 每次使用后永久 +1 段
  - **上限**：最多 ⟦bal:m9_talents_extended.g5.poem_destiny_max_stages⟧ 段（暂定 6 或 8，风洞定）
- 说明：不施加爱愿（目标是自己）
```

### 设计说明
删除递增消耗公式（与锚定 24 门槛冲突），改为固定 12。段数成长保留，但加上限防止后期失控（旧版段数无限成长 + 可集火少数单位 = 1v1 残局神器）。伤害数值需在 HP20 新体系下重新风洞。

## 八、G2×G5 duet 退役（B3-D11）

### 当前 V2
- 在 G2 舞台内由 G5 献诗发起，全桌投票决定是否接受
- 接受后进入 duet 特殊仪式（具体机制见旧 V2 duet 文档）

### M9 冲突
- 旧 G2 全桌舞台已整体冻结（序曲、开幕、Chorus、声部、Regard、物料牌、投票机制）
- 新 G2 是"本体 + 全息影像"的双位置系统，不创建副舞台

### 迁移方案（已定稿）

```
G2×G5 duet
- 状态：suspended（暂时冻结，非永久退役）
- 理由：依赖旧 G2 全桌舞台的投票、Chorus、声部、Regard 与物料系统，已随旧舞台
  整体冻结
- 未来可能性：待新 G2 全息在场与 G5 锚定/献诗各自成立后，可能设计新的轻量联动
  形式（不在十四诗篇内，而是作为独立特殊机制）
- 文档处理：在诗篇列表标记 `status: suspended`，旧 duet 机制文档保留在
  `docs/archive/` 供历史查询
```

### 设计说明
不写 `retired`（永久退役），而是 `suspended`（暂时冻结），为未来可能的 G2×G5 新联动保留空间。

| 诗篇 | 迁移结论 | 核心改动 | 风洞数值 |
