## 〇、设计哲学

### 0.1 问题：当前货币体系的混乱

V2.0 EXP 已经有太多"货币"：

- **信用点**：经济资源，用于购买物品、修甲、治疗；
- **喝彩**：表演资源，用于重掷、加伤、偷看、抵消犯罪；
- **星光**：死后资源，用于死者行动；
- **天赋货币**：G2 的 Regard、G5 的命数/变数、G7 的 Cost/Terror、G4 的火种、T5 的 combo……

这些货币各自为政，玩家需要同时管理 5+ 种资源，认知负担爆炸。更严重的是，**每个新天赋都要发明一种新货币**，这违反了 V2.0 宪法"不得引入第三种货币"的精神。

### 0.2 解决方案：三货币统一

将所有货币统一为三种，每种货币有明确的职责边界：

| 货币 | 本质 | 回答的问题 | 叙事隐喻 |
|---|---|---|---|
| **信用点 (Credits)** | 经济资源 | "我能买什么？" | 钱包 |
| **SP (Stage Presence)** | 行动潜能 | "我能做什么？" | 舞台存在感 |
| **PP (Performance Points)** | 表演价值 | "我做得有多好？" | 观众的掌声 |

**核心原则**：

1. 三种货币**互不兑换**，各司其职；
2. SP 统一**所有行动和天赋**的消耗；
3. PP 统一**生前喝彩和死后星光**；
4. 信用点保持不变，继续作为经济货币。

### 0.3 设计红线

1. **SP 不能是价目表**——SP 决策应该是战略性的（"什么时候行动"），不是战术性的（"能不能行动"）；
2. **PP 不能让死亡变成出局**——死者必须能继续影响游戏；
3. **往世层不能是菜单**——死者不能每轮从固定选项里挑一个行动；
4. **不得引入第四种货币**；
5. **完美信息前提下，不能依赖信息差**——手册 §2.2 明确"高信息公开"，死者的价值必须在判断力和干预，不在信息优势。

## 一、信用点系统（保持不变）

信用点系统基本保持不变，详见 v0.2 设计草案 §6：

- **获取**：打工（1 行动 = 2 信用点）、击杀掉落；
- **用途**：购买物品、修甲、治疗；
- **限制**：无被动收入，必须通过行动获得。

**唯一变化**：治疗/修甲现在需要 **SP + 信用点**双重成本（1 SP + 2 信用点）。

## 二、SP 系统：舞台存在感

### 2.1 SP 的本质

SP 不是"行动点"，而是**舞台存在感**。它代表观众（和游戏世界）对你的关注程度。

**关键区别**：
- 行动点是机械的："我有 3 点，可以花 2 点做这件事"；
- 舞台存在感是叙事的："我是配角，可以做一些重要的事；我是主角，可以做改变游戏的事"。

### 2.2 SP 的层级

SP 有三个叙事层级：

| SP 值 | 层级 | 叙事含义 | 能做什么 |
|---|---|---|---|
| 0-3 | **群演 (Ensemble)** | 你是背景的一部分 | 基础行动（移动、打工、观察） |
| 4-6 | **配角 (Supporting Role)** | 你有重要的戏份 | 战斗行动（攻击、使用武器） |
| 7-10 | **主角 (Lead Role)** | 你是舞台的中心 | 天赋行动（使用天赋、特殊物品） |

**关键**：你不是"有 5 点 SP"，而是"你是配角"。你不是"花 2 点 SP"，而是"从主角变成配角"。

### 2.3 SP 的生成

SP 的生成是**情境性的**，不是机械性的：

| 情境 | SP 变化 | 叙事解释 |
|---|---|---|
| 每轮开始 | +1 SP | 观众一直在看着你 |
| 被攻击 | +1 SP | 你被迫成为焦点 |
| 完成天赋目标 | +2 SP | 你成为了主角 |
| 连续 3 轮未被攻击 | -1 SP | 观众开始忘记你 |
| 被多人同时攻击 | +2 SP | 你是全场的焦点 |

### 2.4 SP 的消耗

当你采取行动时，你的 SP **层级下降**：

| 行动类型 | SP 变化 | 叙事解释 |
|---|---|---|
| 基础行动 | 保持当前层级 | 你还是在背景中 |
| 战斗行动 | 主角 → 配角，配角 → 群演 | 你消耗了存在感 |
| 天赋行动 | 主角 → 群演 | 你耗尽了主角光环 |
| 紧急行动 | 保持当前层级 + 信用点 | 你寻求了帮助 |

### 2.5 SP 的衰减

如果你不使用 SP，观众会开始忘记你：

- 每轮结束时，如果你的 SP 没有变化，**SP -1**；
- 这意味着：你不能永远躲着，你必须行动来维持存在感。

### 2.6 SP 的情境修饰

为了避免"价目表"感，SP 的消耗是**情境性的**：

| 情境 | SP 成本修饰 | 叙事解释 |
|---|---|---|
| 你在连续击杀 | -1 SP | 你在状态中，观众为你疯狂 |
| 你很久没有攻击 | +1 SP | 你生疏了，观众对你陌生 |
| 目标正在看着你 | +1 SP | 你紧张了，观众盯着你 |
| 你在安全位置 | -1 SP | 你放松了，观众不关注你 |
| 你在危险位置 | +1 SP | 你紧张了，观众盯着你 |

**已确认**：SP 系统的骨架（层级、生成、消耗、衰减）已确认。  
**待定**：SP 的具体数值（生成率、消耗量、衰减率）需要风洞校准。

## 三、PP 系统：表演精彩度

### 3.1 PP 的本质

PP（Performance Points）是**表演精彩度**的统一度量，合并了生前的喝彩和死后的星光。

**核心思想**：你的表演有多精彩，不分生前死后。

### 3.2 PP 的生成

PP 从**表演事件**中生成：

| 事件 | PP | 叙事解释 |
|---|---|---|
| 首杀 | +2 | 你打响了第一枪 |
| 复仇 | +3 | 你完成了复仇 |
| 破甲 | +2 | 你打破了龟壳 |
| 终焉击杀 | +2 | 你在末日中收割 |
| 最后一箭击杀 | +2 | 你用最后一支箭完成击杀 |
| 完结条进展 | +1/阶段 | 你推进了角色弧光 |
| 死者潜伏 | +1/轮 | 你在后台观看演出 |
| 援助被接受 | +1 | 你的帮助有价值 |
| 援助改变了结果 | +2 | 你的帮助改变了局势 |

### 3.3 PP 的消耗

PP 可以用于**生前增益**和**死后行动**：

| 用途 | PP 成本 | 身份 |
|---|---|---|
| 重掷先攻 | 1 PP | 生者 |
| +2 伤害（作用于裸伤） | 1 PP | 生者 |
| 偷看下轮先攻 | 1 PP | 生者 |
| 抵消犯罪记录 | 2 PP | 生者 |
| 投注 | 任意 PP | 死者 |
| 援助 | 1-3 PP（生者出价） | 死者 |

### 3.4 PP 的衰减

**已拍板**：PP 会衰减——"世界的注意不可能长时间维持在你身上"。

规则：**如果你这轮没有使用 PP（投注或援助），你的 PP 衰减一个待定值**（走 balance.json），但 PP 不会低于**最低保险值**（待定，避免直接扣光）。

- 衰减值：待定，风洞校准；
- 最低保险值：待定，风洞校准。

## 四、往世层：赞助投注 + 魂援

### 4.1 核心概念

死者不是"从菜单里选行动"，而是**把 PP 押在一个生者身上，然后通过援助来保护自己的投资**。

**核心循环**：

```
死亡 → 把 PP 押在一个生者身上（投注）
  ↓
观看游戏，等待关键时刻
  ↓
被押者处于关键时刻 → 生者出价（1-3 PP）→ 死者接受/拒绝
  ↓
接受 → 援助生效，改变时刻的性质
拒绝 → 什么都不发生
  ↓
被押者赢 → 死者赢回赌注 × 赔率
被押者死 → 死者输掉赌注
```

### 4.2 投注规则

- 你死后，可以立即押注（也可以等几轮再押）；
- 你只能押一个生者（不能分散投资）；
- 你可以换人押注，但要花 2 PP 的"转会费"；
- 赔率实时计算，基于：存活人数 + 被押者的强度 + 押注市场。

### 4.3 赔率计算

**已拍板**：赔率采用简单的人数反比公式。

```
赔率 = 存活人数 : 1（6 人存活 = 6:1，5 人存活 = 5:1，...）
```

不做强度修正和市场修正——简单直接，博弈性来自"押谁"和"何时押"的判断，不是公式复杂度。

### 4.4 援助规则

**已拍板**：
- 援助由**生者发起**，死者同意；
- 生者出价（1-3 PP），死者接受或拒绝；
- **无谈判，无还价**——生者出价 → 死者接受/拒绝，双方都需要谨慎；
- 死者可以援助**任何生者**（不限于被押者），只要收益够高；
- **援助公开**——即使交易过程不公开，效果生效后也会公开，加博弈没有必要；
- **多个死者同时援助同一个生者时，只有出价最低的死者能援助**（价格竞争，多个押注者争相降价，生者受益）。

#### 援助触发时机（已拍板）

参考动作游戏的"进攻援助"和"防御援助"，以及群星之战（All Star Battle）的主动/被动援助系统：

**每个玩家每局最多使用 4 次援助**：

| 类型 | 触发方式 | 回合成本 | 次数 |
|---|---|---|---|
| **主动进攻援助** | 玩家主动发起 | 消耗回合 | 1 次 |
| **主动防御援助** | 玩家主动发起 | 消耗回合 | 1 次 |
| **被动进攻援助** | 全局第一次发起攻击（含星野战术宏） | 不消耗回合 | 1 次 |
| **被动防御援助** | 全局第一次被打至最大生命值 1/5 以下 | 不消耗回合 | 1 次 |

**关键设计**：
- **主动援助**：给玩家"什么时候叫"的决策空间——你可以选择在关键时刻主动发起；
- **被动援助**：保证每个玩家至少有两次高光时刻——第一次出手和第一次濒死；
- **主动援助消耗回合**：它是"你主动选择的一次行动"，不是免费的；
- **被动援助不消耗回合**：它是"系统自动触发的"，不需要你做选择；
- **被动防御援助不锁血**：如果一下从 1/5 以上被打死，不触发——它是"危急时刻的救命稻草"，不是"免死金牌"。

### 4.5 黑马增益

**已拍板**：
- 如果一个生者**没有任何死者押注**，他获得一个**低强度的通用增益**；
- 黑马增益的强度**不超过**天赋援助的强度——它是"安慰奖"，不是"首选策略"；
- 如果黑马赢了，他的 PP 加成比有赞助者的胜利**更高**——"我没有靠任何亡灵的帮助"本身就是一种传奇。

**黑马增益效果**（已拍板）：
- **进攻援助**：+N 攻击（N 待定，走 balance.json）；
- **防御援助**：+N 血量（N 待定，走 balance.json）。

**博弈结构**：
- 被押注多的玩家：援助选择多、价格便宜（押注者竞争）；
- 无人押注的玩家：要么用便宜的保底增益，要么花高价叫非押注者的援助；
- 死者的囚徒困境：如果不押黑马，黑马赢了，所有押错人的死者全部出局。

### 4.6 卡特尔背叛

**已确认**：死者可以援助非被押者，这创造了"卡特尔背叛"的博弈点。

**博弈结构**：
- 如果所有死者都押同一个胜者，他们形成一个"卡特尔"；
- 卡特尔的集体利益是帮助被押者赢；
- 但个体死者可能背叛——援助一个非被押者，赚更多 PP；
- 背叛的连锁反应：背叛改变了赔率，让留在卡特尔里的人也动摇；
- **结论**：卡特尔天然不稳定，死者会自然分散投注，不会全部押同一个人。

### 4.7 魂援使用规则

**每个玩家每局最多使用 4 次援助**：

| 类型 | 触发方式 | 回合成本 | 次数 |
|---|---|---|---|
| **主动进攻援助** | 玩家主动发起 | 消耗回合 | 1 次 |
| **主动防御援助** | 玩家主动发起 | 消耗回合 | 1 次 |
| **被动进攻援助** | 全局第一次发起攻击（含星野战术宏） | 不消耗回合 | 1 次 |
| **被动防御援助** | 全局第一次被打至最大生命值 1/5 以下 | 不消耗回合 | 1 次 |

**设计参考**：群星之战（All Star Battle）的援助系统——主动援助给玩家"什么时候叫"的决策空间，被动援助保证每个玩家至少有两次高光时刻。

**被动防御援助规则**：不锁血——如果一下从 1/5 以上被打死，不触发。

#### 设计说明

**T3/T4 的当身/潮流分化**：
- T3：跳过回合换免疫——你主动选择"消失"来躲避一切；
- T4：免疫下一次伤害——你不消失，但下一次攻击无效；
- 同样是防御，节奏完全不同。

**G4 的递增/递减**：
- 火种是 G4 专属资源，对其他玩家没意义；
- 所以翻译成通用语言：攻击递增（越打越疼）和防御递减（越挨越硬）。

**G5/G6 不区分攻防**：
- G5 的献诗和 G6 的插入式笑话本来就不是攻防二元的机制；
- 强行区分攻防会破坏天赋的核心体验。

**G7 的战星 EX 模式**：
- 直接借用原作技能形态（战星-攻击模式 EX / 战星-防御模式 EX）；
- 进攻援助是"点射 + AOE 溅射"，防御援助是"冲刺 + 掩体"。

**有几个效果可能有平衡问题，但先不定**：
- T3 进攻援助（AOE 命中所有玩家）——可能太强；
- T4 进攻援助（放逐）——可能太强；
- G3 进攻援助（禁用 move）和防御援助（压制天赋）——可能太强；
- G6 不区分攻防（插入式笑话）——可能太强。

这些留给风洞校准。

## 五、博弈结构分析

### 5.1 生者的决策树

```
我是生者，我需要援助。

情况 A：我有多个押注者
  → 我有多个援助来源，价格竞争激烈
  → 我可以低价甚至免费获得援助
  → 我的优势：选择多、价格便宜

情况 B：我只有一个押注者
  → 我只有一个援助来源，价格由对方定
  → 我可能需要出高价才能获得援助
  → 我的劣势：选择少、价格贵

情况 C：我没有押注者
  → 我有黑马增益（免费，但不如天赋援助强）
  → 或者我出高价叫非押注者的援助
  → 我的选择：用保底 或 花高价
```

### 5.2 死者的决策树

```
我是死者，我需要赚 PP。

决策 1：押谁？
  → 押强者：稳赢但赔率低 → 赚少但稳
  → 押弱者：险赢但赔率高 → 赚多但险
  → 押黑马：没人押但有增益 → 高风险高回报

决策 2：援助谁？
  → 援助被押者：保护投资，可能低价甚至免费
  → 援助非被押者：赚外快，可以高价
  → 不援助：攒 PP，但 PP 会衰减

决策 3：背叛吗？
  → 如果大家都押了 Bob，我押了 Alice
  → Bob 赢了，我输；Alice 赢了，我赢
  → 我可以在关键时刻援助 Alice，帮翻盘
```

### 5.3 黑马的决策树

```
我是没人押注的黑马。

决策 1：依赖黑马增益
  → 免费，但不如天赋援助强
  → 适合保守打法

决策 2：花高价叫援助
  → 非押注者的援助价格高
  → 但如果死者觉得帮我赢能赚更多 PP，他可能会帮

决策 3：利用"没人押"的叙事
  → 如果我赢了，我的 PP 加成比有赞助者的胜利更高
  → 死者们会纠结：要不要押我？
```

## 六、终局评分

终局评分使用**三货币的综合**：

```
生者终分 = (剧情 + 战果) × 存活系数 + PP
死者终分 = 剩余 PP + 赌注收益 + 援助收益
```

- **剧情**：完结条进展（天赋特定）；
- **战果**：击杀和伤害；
- **存活系数**：存活 1.5，死亡 0.5；
- **PP**：表演精彩度。

**关键**：PP 是独立于存活系数的，这意味着死亡玩家可以通过 PP 反超存活玩家。

## 八、已否决方案（避免重提）

以下方案已经讨论过并否决，不要再重提：

| 方案 | 否决理由 |
|---|---|
| **菜单式往世层**（死者每轮从三个固定行动里选一个） | 选择太少，影响太小，没有叙事 |
| **聚光灯状态系统**（On Stage/Backstage，Backstage 不能被攻击） | 不能被攻击会造成龟壳 |
| **动量系统**（Momentum，简化的 SP） | 主题感弱，没有 memorable moments |
| **谈判/还价机制**（生者出价 → 死者还价 → 生者接受/拒绝） | 太复杂，拖慢节奏 |
| **关注/观察机制**（死者花 PP 获得额外信息） | 完美信息下无意义 |
| **纯赌局**（死者只下注，不援助） | 死者主动性不足，还是观众 |
| **魂援由死者主动发起**（死者选择何时援助，生者被动接受） | 生者没有决定权，不符合"生者发起，死者同意"的方向 |
