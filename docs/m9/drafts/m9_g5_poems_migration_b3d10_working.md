## 一、评估框架

每首诗需回答：

1. **目标天赋的 M9 状态** — 已冻结 / 候选 / 未决 / 未开工
2. **V2 效果摘要** — 当前玩家会读到的效果
3. **M9 冲突点** — 与已批准合同的直接冲突
4. **迁移建议** — 保留 / 重写 / 退役，以及具体改动方向
5. **待裁决** — 需要用户或作者明确点头的问题

## 八、完整额外行动白名单审查（横切问题）

当前四首诗包含"立刻行动"：地火、彼岸、飞萤、负世。

**B0/B1 已明确**：完整额外行动是最高级白名单奖励，首批来源只有 T4 或跃在渊与 T5 FC。

**三种处理方式**：

### A. 全部删除，改为间接增益
- 地火 → 刷新追猎反应
- 彼岸 → 复活后 SP 快速准备
- 飞萤 → 下次超新星 SP 折扣
- 负世 → 火种上限提升

**优点**：干净，不扩散白名单  
**缺点**：四首诗都被大幅削弱，G5 方式二的吸引力下降

### B. 全部保留，扩展白名单
将四首诗登记为"通过 G5 献诗授予的完整额外行动来源"，与 T4/T5 并列。

**优点**：保留诗篇原味  
**缺点**：白名单从 2 个扩展到 6 个（T4/T5/地火/彼岸/飞萤/负世），可能失控

### C. 选择性保留（推荐）
只保留 1-2 首最符合主题的，其余改写：

- **保留「彼岸」**：复活后立刻行动符合"死者苏生"的戏剧性，且触发条件严格（必须先死亡）
- **保留「负世」或「飞萤」其一**：G4/G1 是救世主/火萤主题，"绝境爆发"合理
- **删除「地火」**：T2 已有追猎反应，不需要额外行动

**优点**：平衡原味与控制，白名单扩展到 4 个（T4/T5 + 彼岸 + 负世或飞萤）  
**缺点**：需要逐个说服作者
