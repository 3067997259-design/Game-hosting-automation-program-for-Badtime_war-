> 本手册是**人类玩家的规则说明书**。起闯战争已脱离桌面推演体系，依托电子裁决程序运行；

## 一、游戏概述

起闯战争是一局 2–6 人的**回合制大逃杀**。你扮演一名被卷入"起闯战争"的参战者，在一张六地点
的地图上移动、发育、结盟、厮杀，并争夺最高的**综合评分**。

### 1.1 这不是"活到最后就赢"

V2.0 的胜负由**综合评分制**裁定——

```
终分 = （剧情分 + 喝彩净值 + 战果分） × 存活系数 + 往世分
```

- **活到最后只是加分项**（计入"存活系数"），不再是唯一目标。一味龟缩苟活、不产出，终分会很难看。
- 评分四源：**剧情分**（达成"完结条"等叙事里程碑）、**喝彩**（打出名场面，见第十二章）、
  **战果分**（击杀与有效伤害）、**往世分**（死后在往世层的作为）。
- **中盘只见组件、不见总分**；精确终分在**终局统一揭晓**。
- **双轨获胜**：终分第一与"最后存活者"并列记录——你可以是赢家，也可以是活到最后的那个，二者未必是同一人。

### 1.2 死亡不等于出局

被击杀者**坠入往世层、化作一颗星**：不能再直接造成伤害，但仍能用"星光"拨动生者的命运、
并继续为自己积累**往世分**（见第十二章）。

### 1.3 残局与终结

为避免残局陷入"谁都不动"的僵局，游戏设有**残局终结机制**（白昼世界时钟的"终焉"阶段等，见第十一章）
持续施压，推动对局走向结束。

## 二、组件与信息公开

### 2.1 地图与地点

地图由六个地点构成：**家（home）/ 商店 / 魔法所 / 医院 / 军事基地 / 警察局**。
任意地点之间移动均为一次行动（无邻接限制）。各地点的供应见第六章。

### 2.2 信息公开原则

起闯战争是**高信息公开**的博弈：玩家的位置、装备、心血、状态标记等对所有人可见（隐身/探测另有规则，见第九章）。
唯一的私密信息是少数"匿名"来源（如匿名冷箭的归因，见第九章）。**公开是博弈的前提**——
你能看见别人在攒什么、走向哪里，别人也能看见你。

### 2.3 玩家状态条（L1 清单）

每名玩家随时可查看以下状态：

- **心血**：上限 20（整数血量模型，见第八章）。
- **外甲耐久条**：每件外甲的剩余耐久（见第八章）。
- **钱包**：信用点余额（经济，见第七章）。
- **箭矢**：n / 6（弓的弹药）+ 升级模块双槽（见第六章）。
- **状态图标**：眩晕/震荡/石化、灼烧层数、隐身/探测、各天赋专属标记等。

## 三、游戏准备

### 3.1 初始状态

每名玩家以 20 点心血开局，位于自己的**家**，初始处于"未起床"状态。

### 3.2 起始包（家中资源）

每人开局获得：

- **弓** + 3 支箭（人手一份的跨地点武器，见第六章）；
- 在家可拾取**小刀 / 盾牌**的资格。

> 注：家**不再产出任何经济资源**（信用点只能在外面挣，见第七章）。

### 3.3 游戏开始

游戏从第一个全局轮次开始。每名玩家的**首个行动回合必须用于"起床"**；起床后方可进行其它行动。

## 四、时序与流程

### 4.1 全局轮次（Round）的标准结构

游戏以"全局轮次"推进，每轮依次结算：

1. **轮次开始结算**：持续效果计时、天赋的"轮次开始"效果、病毒倒计时（若挂在轮首）、
   白昼世界时钟阶段推进（见第十一章）。
2. **先攻判定与行动权分配**（见 4.3）。
3. **警察状态机推进**（见第十章）。
4. **行动回合**：取得行动权者按先攻顺序依次行动（见 4.2）。
5. **轮次结束结算**：警察执法、病毒与死亡判定、持续效果计时、检查胜负与残局终结，进入下一轮。

### 4.2 行动回合（Action Turn）的标准结构

每个行动回合分三步：

1. **回合开始**：触发"回合开始"类天赋效果。
2. **指令输入**：执行一个行动类型（见第五章）。
3. **回合结束**：触发"回合结束"类效果。

某些效果会插入**额外行动回合**（如部分天赋）；额外回合在当前回合之后按规则插入。

### 4.3 K 常量行动制（取代旧"行动权争夺"）

V2.0 废除了旧版"D4 掷骰争夺行动权"与"未行动保底加成"，改为更清爽的 **K 常量行动制**：

- 每个全局轮次，**固定有 K 名玩家获得行动权**：
  ```
  K = max(1, 当前存活人数 − 1)
  ```
  默认 `k_sitout_count = 1`，即**每轮只有先攻垫底的 1 人轮空**，其余全部行动。
- **先攻**由 d6 + 各类修正决定；行动权按先攻从高到低分配，行动也按此顺序进行。
- **轮空不再是惩罚**：没有"未行动保底加成"这种补偿了——在新规则下人人几乎每轮都能动，坐一轮是常态而非吃亏。
- **放弃行动（forfeit）**仍是合法选择（主动跳过，无补偿）。

### 4.4 交战与借机攻击

- **交战状态**：两名玩家处于同一地点，且本轮或上一轮之间彼此发生过伤害，即视为"交战中"。
- **借机攻击**：交战中若一方**主动移动**离开该地点，每名与其同地点的交战对手获得 **1 次免费攻击结算**
  （走正常命中/闪避，见第九章；移动者本次不享受移动带来的闪避加成）。每名追击者每轮限 1 次。
- **豁免**：**被动位移**（被击退、被钩锁拉拽等）不触发借机攻击。

## 五、行动类型

每个行动回合，玩家执行**一个**行动。可选类型如下。

### 5.1 起床

仅"未起床"者可用，也是其首个行动回合的**强制选择**。起床后该状态永久解除。

### 5.2 移动

移动到任意其它地点（无邻接限制，一次一地）。注意：处于交战中主动移动会触发对手的**借机攻击**（见 4.4）；
被动位移（被击退/被拉拽）不算主动移动。

### 5.3 交互

在当前地点办理该地点提供的事务，统称"交互"：获取物品 / 学习法术 / 进行手术 / 办理通行证 /
补给箭矢 / 修理护甲 / 治疗 / 打工等（各地点供应见第六章，费用见第七章）。部分项目需多个回合完成（进度保留）。

### 5.4 锁定（远程命中前置）

对一名玩家建立"锁定"标记。**锁定不再是远程攻击的硬前置**——弓未锁定也能射，只是命中更低
（见第九章）；锁定 = 拉满该目标的远程命中。

### 5.5 找到（近战前置）

与同地点的一名玩家建立"面对面（交战）"关系，是近战攻击的前置。

### 5.6 攻击

用一件武器攻击一名合法目标（近战需面对面，通用远程需可见）。命中与伤害结算见第八、九章。

### 5.7 射箭（弓）

弓的专属攻击动词，是**唯一的常规跨地点武器**：

- 跨地点合法；**不需锁定**（锁定只加命中）。
- 消耗 1 支箭（无限模块豁免）；射出的箭落在**目标所在地点**的箭堆，可由"找到"行动免费拾回（风险换弹药）。
- 伤害/属性/附带效果由已装的升级模块决定（见 6.2）。

> 例：你在商店、敌人在魔法所。你 `射箭` 跨地点命中（未锁定，吃命中惩罚）；这支箭落在魔法所，
> 谁先到谁能 `找到` 捡走。

### 5.8 钩锁

军事基地的神器（全图唯一），科技属性，**双模式共享 2 轮冷却**：

- **拉人**：将任意地点的一名玩家拽到你所在地点，附 2 点科技伤害（走命中/闪避）。
  被闪避（擦钩）= 不位移，但目标本轮全部闪避加成失效。
- **拉己**：把自己钩向任意地点。**不触发借机攻击**（机械把你拽走，对手刀砍空气）。

### 5.9 特殊操作

天赋/装备的专属操作，统称"特殊操作"，例如：**蓄力**（给需蓄力的武器充能）、重新展开魔法护盾/AT 力场、
磨刀、释放病毒（在医院）、取消架盾等。具体由你持有的物品/天赋决定。

### 5.10 放弃行动

主动跳过本回合，无补偿（合法选择）。

### 6.1 各地点供应

### 6.2 弓与升级模块系统

远程三层架构：**弓（人手一份）→ 钩锁（神器）→ G7 荷鲁斯之眼（天赋顶点）**。

**弓**：起始装备，裸伤 3，普通属性（基础箭），跨地点。箭初始 3、
上限 6；补给 2 支 / 1 信用点。

**升级模块**：弓有**双槽**；每种全图 **×2 份**（份数稀缺，抢完即止，死亡回流）；
**同名双装强化**；装卸为 1 行动、随处可做。

| 模块 | 来源 | 单装 | 双装 |
|---|---|---|---|
| 力量 | 商店 | 裸伤 +2 | +4 |
| 火矢 | 魔法所 | 属性→魔法，+1 灼烧 | +2 灼烧 |
| 魔导 | 魔法所 | 命中 +15 | +30 |
| 穿甲 | 军事基地 | 属性→科技，防御按 0.5 计 | 防御按 0.25 计 |
| 冲击 | 军事基地 | 同地点命中→击退至随机地点 | 击退 + 目标下轮先攻 -2 |
| 无限 | 医院 | **神器×1，独占双槽**：不耗箭，恒为基础普通箭（白板 3 伤） | 不可叠 |

> 例：你装了**双力量模块**，弓裸伤 3 → 3+4；
> 但占满双槽，就没法再带穿甲/火矢——配置取舍是博弈的一部分。

### 6.3 钩锁

军事基地的神器（需通行证），全图唯一。用法见 5.8。它继承了旧导弹的"攻城/反龟缩"职责——
把龟缩者拖出家门、拽回逃兵、将通缉犯钩进警察局。

### 6.4 手术 / 法术 / 学习（多回合）

部分项目需跨多个回合完成，进度保留：魔法所的法术学习、医院的手术（终身一次，见第七章财产税）等。

## 七、信用点经济

V2.0 废除旧"购买凭证"二元经济，改用**信用点**（统一通货）。设计目标：消灭龟缩——
让防御与苟活都背上**经常性开支**。

### 7.1 收入（faucets）

- **打工**：在商店/医院打工，+2 信用点 / 次。
- **击杀夺财**：击杀掉落含死者全部信用点（见 7.4）。
- **禁止被动收入**：没有"每轮自动 +X"，家也不产出——**收入必须出门挣**。

### 7.2 支出（sinks）

| 项目 | 信用点 |
|---|---|
| 小刀 | 1 |
| 磨刀石 | 2 |
| 陶瓷护甲 | 3 |
| 隐身衣 / 热成像仪 | 3 |
| 防毒面具 | 2 |
| 修理陶瓷护甲（+6 耐久） | 1 |
| 补给箭矢（2 支） | 1 |
| 力量模块 / 无限模块 | 3 / 4 |
| 钩锁 | 2 |
| 手术（财产税） | **全部信用点**（下限 4） |

### 7.3 经济战与财产税

- **修甲收费 = 攻击变经济战**：对龟壳的每一刀都在磨它的护甲耐久、逼它花钱修——
  打不死你，但能打到你破产、发育归零。防御第一次有了经常性开支。
- **手术 = 财产税**：消耗你**全部**信用点（下限 4）换永久身体改造（内甲），倾家荡产。

> 例：你莽夫流，反复 `射箭` 磨对面陶瓷护甲耐久；他被迫每隔几轮回商店花
> 1 信用点修甲，打工收入全填进去，攒不出第二件装备。

### 7.4 击杀掉落

进入白昼阶段后启用（见第十一章）：死者的**装备、模块、剩余箭矢、钱包**全部掉落原地，1 行动拾取。
稀缺品（模块/神器）经击杀回流市场——杀掉狙击手就能抢他的无限模块。

## 八、护甲与伤害（HP20 数值模型）

V2.0 改用**整数血量模型**：心血上限 20，所有伤害为整数。
护甲不再是"另一条血条"，而是**减法防御 + 耐久**。

### 8.1 核心伤害公式

```
单次伤害 = max( 裸伤 − 目标对该攻击属性的防御总和 ,  ⌈裸伤 × 25%⌉ )
```

即"减法防御 + 保底线"：再厚的甲，**怎么打都至少掉 ⌈裸伤的四分之一⌉**（保底比例
0.25）。"打不中的龟壳"不存在。

> 例：裸伤 4 的武器打"对该属性防御 3"的目标 → max(4−3, ⌈4×0.25⌉) = max(1, 1) = **1 伤害**；
> 打无防御目标 → max(4, 1) = **4 伤害**。

### 8.2 外甲：防御表 + 耐久

每件外甲有一张**防御表**（属性 → 防御值，主防高/副防低）和**耐久**：

- 攻击被外甲减伤时，**吸收量（= 裸伤 − 实伤）按 1:1 消耗耐久**；耐久归零即破碎（防御归零）。
- 多件外甲同时防御：吸收量**按各甲对该属性的防御贡献比例**分摊到各自耐久，余数给贡献最高者。

| 外甲 | 防御表 | 耐久 |
|---|---|---|
| 盾牌 | 普 −2 | 8 |
| 陶瓷护甲 | 普 −3 / 科 −1 | 12 |
| 魔法护盾 | 魔 −3 / 普 −1 | 12 |
| AT 力场 | 科 −3 / 魔 −1 | 12 |

### 8.3 内甲：永久属性防御

内甲（通过医院**手术**获得，如晶化皮肤）是**永久的属性防御**，**没有耐久、不会破**，
直接计入"该属性防御总和"。

### 8.4 属性与防御表（硬克制已废除）

V2.0 **取消了"属性被克制 = 整次攻击无效"的硬克制**。属性差异改由**防御表**表达：
同一件甲对不同攻击属性给出不同防御值（主防、副防、或未列即 0）。被"克制"的武器照样有效，只是面对更高防御、伤害更低。

> 例：陶瓷护甲对普通 −3、对科技仅 −1。
> 拿科技弓打它，比普通武器更划算——但都不会"无效"。

### 8.5 选层与溢出

- 外甲未全破时攻击**自动导向外层**，不能越过外甲直击内层。
- 最后一件内层防御被打穿后，**溢出伤害转移到心血**。

### 8.6 穿甲与真伤

- **穿甲**（如穿甲箭模块）：目标防御**按系数折算**后再代入公式（防御打折，更易破）。
- **真伤**（部分天赋/诗）：无视属性防御直击（仍可被特定绝对效果阻挡）。

## 九、命中与战斗状态

### 9.1 命中 / 闪避 / 擦伤

V2.0 默认**确定命中**（命中率 100）——香草对砍必中，零额外认知。
**概率只在有人为投资时才出现**：

| 闪避来源 | 命中 |
|---|---|
| 目标本轮主动移动 | −15 |
| 目标隐身（攻击属性∈其隐身集且你无对应探测，见 9.4） | −25 |
| 跨地点远程**未锁定** | −15 |

闪避总和封顶 60（命中下限不低于 100−封顶）。**被闪避 ≠ 落空 = 擦伤**：
按保底线结算少量伤害，且不触发武器附带效果（震荡/灼烧等）。

> 例：你射一个本轮移动过、且你未锁定的远程目标 → 命中 100 − 15
> − 15。掷未过则擦伤保底。

### 9.2 生命、重伤、死亡

- 心血降至 0 即死亡（坠入往世层成星，见第十二章）。
- **重伤**：心血处于 0 与 5 之间时，承受额外不利
  （受 AOE 伤害 +1、先攻 -2）。

### 9.3 眩晕 / 震荡 / 石化

- **眩晕**：失去下个行动回合。
- **震荡**（电流武器）：眩晕的电流变体；陶瓷护甲（未破）免疫电流震荡。
- **石化**：下回合二选一结算；细节见相关天赋。
- 负面状态有**抗性两层制**（韧性脉冲等）削弱其堆叠，见设计草案。

### 9.4 隐身 · 探测 · 可见 · 锁定 · 面对面

- **可见 / 锁定 / 面对面**：远程命中加成靠锁定；近战靠面对面（见第五章）。
- **隐身与探测按属性分轨**（各分普通/魔法/科技三系）：

| 隐身（降命中） | 探测（反隐 + 火控） |
|---|---|
| 隐身衣（普通）/ 隐身术（魔法）/ 隐形涂层（科技） | 热成像仪（普通）/ 探测魔法（魔法）/ 雷达（科技） |

  当攻击属性落在目标的隐身集、且攻击者**无对应属性探测**时，该次攻击吃隐身闪避（9.1）。
- **匿名冷箭**：跨地点冷箭信息不足时不可被举报（归因规则，见第十章）。

### 9.5 灼烧（DoT）

灼烧每层每轮直扣 1 点心血，上限 3 层；
作为持续伤害**不受属性防御/抗性管辖**。火矢模块、燃烧类天赋共用此层。

### 9.6 病毒

在医院"释放病毒"后，潜伏 2 轮，此后每个轮末对未免疫者
扣 3 点心血（防毒面具免疫）。病毒是施压钟，不再是即死处决器。

## 十、警察系统

警察是一股**可夺取的中立秩序**：玩家可以举报违法者、上任队长、指挥警察单位。

### 10.1 警察保护（已重做）

受警察保护者，**每个全局轮次内免疫"小于阈值的单体伤害"**（阈值 [待风洞]）。
它不再是"站在这儿就单体免伤"的龟壳——要打穿保护，需要**更大的单次伤害**或 **AOE**。

### 10.2 警察单位与执法

警察单位：心血 12，警棍伤害 4。满足条件时在轮末执法攻击违法者。

### 10.3 状态机

警察按 `闲置 → 举报 → 集结 → 出动` 推进：有人举报违法者后进入举报，逐步集结、出动执法。

### 10.4 威信与队长

- **队长**由竞选产生，可指挥警察单位。
- **威信**：攻击无辜者 −1、队长犯罪 −1；威信归零则解除队长身份，原队长成为唯一违法者。

### 10.5 犯罪名单与匿名

违法行为（伤害无辜、进入他人之家、释放病毒等）会被记入犯罪名单。**匿名冷箭**信息不足时不可被举报（见 9.4）。

### 10.6 分级坠落（随白昼）

警察随世界时钟**分级坠落**（见第十一章）：**黄昏**取消警察保护、但保留执法与状态机；
**终焉**警察系统全部停摆。秩序随白昼渐崩。

## 十一、白昼世界时钟

世界时钟把一局分成四幕，越往后压力越大，逼对局走向终结。

**段长 = 6 + 初始人数**（按人数缩放；下表为 6 人局示例）。

| 阶段 | 轮次（6人示例） | 规则变化 |
|---|---|---|
| **黎明** | 1–12 | 基础规则；发育与结盟。 |
| **白昼** | 13–24 | 地点**限量营业**（每地点每条目每轮 1 次，先攻争夺；含箭矢补给与模块）；每人首次攻击记"嫌疑"不记罪；**击杀掉落启用**。 |
| **黄昏** | 25–36 | 全体造成伤害 +1；治疗费用 ×2；商店半价；眩晕来源效果 +1 轮；**警察保护下线**。 |
| **终焉** | 37+ | 每轮末全体 −2 真伤（叙事级豁免无效）；喝彩分值 ×2；**警察系统全部停摆**。 |

终焉的"每轮末真伤"是**残局终结的压力阀**——拖得越久，所有人掉血越快，僵局无处可躲。

## 十二、评分 · 喝彩 · 往世层

### 12.1 终分总公式

```
终分 = （剧情分 + 喝彩净值 + 战果分） × 存活系数 + 往世分
```

- **存活系数**：终局存活 ×1.5；中途死亡 ×max(0.5, 存活轮数 / 总轮数)。
- **战果分**：每击杀 +3；每累计 20 点有效伤害 +1（上限 +5）。
- 中盘只见组件、不见总分；精确终分**终局揭晓**。

### 12.2 喝彩（两用资源）

打出"名场面"可获喝彩点（**每类每局限 1 次**，反合谋）：

| 事件 | 喝彩 |
|---|---|
| 首杀 | +2 |
| 重伤（HP≤5）状态下反杀 | +3 |
| 打破满配（3 外甲）目标的最后一件外甲 | +2 |
| 用最后一支箭完成击杀 | +2 |
| 在终焉阶段完成击杀 | +2 |

喝彩是**两用资源**：余额计入终分，也可消耗（重掷先攻 / 单次裸伤 +2 / 偷看下轮先攻顺序 / 抵消一次犯罪记录 等）。

### 12.3 完结条（剧情分大额块）

达成叙事里程碑得大额剧情分（进度半公开）：

| 天赋 | 完结条 | 剧情分 |
|---|---|---|
| G2 注视 | 完成一次完整谢幕 | +15 |
| G4 愿负世 | 救世主毕业（状态结束时存活，此后再存活 5 轮） | +12 |
| G5 涟漪 | 完成 2 次成功锚定 | +15 |

（试点 3 个，后续逐步为全部神代补完结条。）

### 12.4 往世层（死者成星）

被击杀者**坠入往世层、化作一颗星**（不出局）：

- 每轮获 1 点星光（上限 3）。
- **星光行动**（每轮 1 次，对同一玩家每 2 轮限 1 次）：
  - **拨弄命运**（1 星光）：某玩家本轮先攻 ±1。
  - **预兆**（2 星光）：在某地点投下预兆，下轮第一个交互者 ±2 HP。
  - **加冕**（2 星光）：某玩家下一个喝彩事件分值 ×2。
- 星光行动产生**往世分**（×0.5 折算计入本人终分）。
- 星**不能直接造成伤害或击杀**；被锚定击杀者**不能成为星**。
