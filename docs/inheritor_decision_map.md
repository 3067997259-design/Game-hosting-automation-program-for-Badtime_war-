## 0. 一句话定位

**作者赌的是"意图"，不是"机制"。** 他真正反复盖章的是"角色复刻式设计必须有迹可循、
必须让全桌目光在某刻聚焦到表演上"；至于具体用什么机制实现（三首歌 / 物料牌 / 锚定公式 /
架盾宏），是他给出的**一组解法，不是唯一解法**。继承者可以重做实现而不背叛作者——
前提是过得了"有迹可循"这一关。

## 1. 核心坐标系：意图神圣，实现可谈判

### 1.1 三层划分

| 层 | 定义 | 例 |
|---|---|---|
| **S1 神圣意图** | 作者多次盖章、且为它对抗过反对意见的价值观 | 演出优先；角色有迹可循；神代=演出机器；6 人平衡基准 |
| **S2 已盖章实现** | 作者已实装、且明确表态"就这样了"的具体机制 | G2 舞台本体、G5 锚定本体、G7 星野套件、V2.0 底层 |
| **P 可谈判实现** | 机制细节、数值、扩展形态 | 歌曲数量、物料牌种类、锚定公式、完结条范围、全部 `[待风洞]` 数值 |

### 1.2 判读规则

1. **S1 不可谈。** 任何让"角色特征不可辨认"的改动都背叛作者。
2. **S2 慎谈，但可谈。** 作者盖章的是"这套机制实现了这个角色"，不是"机制本身"。
   重做实现时，必须能回答验证器问题。
3. **P 可谈。** 数值零阻力；机制细节需要先认领角色特征的替代体现。
4. **同一个 S2 内部，谈判强度不同。** 作者对"砍掉锚定本体"有强反弹（见 §4），
   对"G4 救世主要不要抬一手"则主动松口（见 §3.2 G4）。动手前查证据索引。

### 1.3 验证器（每次改动的必答题）

> **这个角色的哪个特征，通过改后的什么新机制体现？**

改掉任何机制后，如果答不上来，或者答案变成"哦那个角色特征其实无所谓"——停手。
"有迹可循"是作者的硬标准，不是可选项。

## 3. 逐项明细

### 3.1 底层世界（V2.0 地基，S2）

**意图**：消灭"行动权饥荒 / 硬克制归零 / 叹息之墙 / 无毒圈梅花桩"四个 V1 顽疾。
作者在日记中逐条自白过动机（坐牢感、RL 奖励信号尖锐、反制警察靠补丁、残局僵持）。

| 机制 | 意图 | 现状 | 可谈判空间 |
|---|---|---|---|
| K 行动制 | 全员参与，只留 1 人坐牢保戏剧性 | 已实装，`k_sitout_count=1` | 参数本身就是"台面旋钮"（草案 1.1） |
| HP20 减法防御 + 保底 | 消除"打不穿"；硬克制废除 | 已实装，⌈25%⌉ 保底 | 数值全 `[待风洞]` |
| 信用点经济 | 龟缩背上经常性开支 | 已实装，禁被动收入 | 数值全 `[待风洞]` |
| 白昼时钟 | 自带毒圈，残局自我收束 | 已实装，四幕 | 段长/倍率 `[待风洞]` |
| 综合评分制 + 往世层 | 活到最后不再是唯一答案 | 已实装，终分公式 | 权重 `[待风洞]` |
| 弓/钩索/位移三件套 | 远程重置 + 反龟缩 | 已实装，导弹退役 | 数值 `[待风洞]`；钩索已全图唯一 |

> **注意**：这些是"宪法级"改动，M0–M6 有 golden 回放冻结。改参数可行，改结构=重做。

### 3.2 神代天赋（G1–G7）

#### G1 火萤
- **意图**："强、快、像流星砸进人群，但必须为燃烧自己付出代价"（手册）。
- **现状**：已按宪法"乘法变加法"（`attack_bonus=3` / `defense_reduction=2`）。
- **谈判空间**：数值（P）。结构性判断：作者对 G1 的态度是"数值型"，无情感盖章，
  属于可放心微调的一档。历史胜率 16.9% 属中位。

#### G2 舞台（S2，慎谈）
- **意图（S1）**：演出感、"最后一曲不能少了观众"、"我并不介意设计一个游戏中的游戏
  来表现这一主旨"（日记 Ver1.96）。
- **现状（S2）**：三声部 + Regard + 17 种物料牌 + 三首歌六节奏 + 旋律阈值 + G2×G5 duet。
  代码约 3000+ 行，14 天赋中最大。
- **背景**：作者承认 G2 初始**无角色对应**，是"反制警察体系的控制版天星"（日记）；
  舞台叙事是事后补立的传。
- **谈判空间**：歌曲/牌种/公式全部可重做（P），**只要"需要观众"的弧光还在**。
  重做方向示例：精简物料牌、合并声部、降低 Regard 学习成本——都可谈。
  但要注意：这是作者亲手写的最长个人叙事，动实现前必须展示新实现的"演出感"。
- **M9 候选**：旧全桌舞台只保留为历史材料；当前以共享一个玩家身份的光身/影身双 actor
  承接“多重在场”，再以永久消费影身资格的《世末歌者》终曲和听众里程碑承接“最后一曲
  不能少了观众”。影身有真实 HP/装备/标准槽且无限持续；终曲歌者无槽，只建立局部区域，
  不恢复全桌阵营副游戏。规则见 `docs/m9/current/m9_g2_holographic_presence_rfc_v0.3.md`。

#### G3 神话之外
- **意图**："把别人拖进小黑屋重算"（手册 Q&A）。
- **现状**：即时连续决斗，外部不停轮（已修正"全局暂停"旧病）。**天赋压制（二元悬崖）**
  在 changelog 挂"暂缓复核"。
- **谈判空间**：压制悬崖的重设计空间较大（作者已挂账）；胜率历史垫底（12.3%），
  是作者最不满意的神代之一。
- **M9 候选**：已重置为魔力投影、固有结界覆盖层、剑阵与幻想崩坏；全局行动顺序继续，
  不再创建同步小黑屋，规则见 `docs/m9/current/m9_g3_reality_marble_rfc_v0.2.md`。

#### G4 愿负世（W，作者松口）
- **意图**：绝境背负感、致敬白厄、"最像自机角色本尊"（手册）。
- **现状**：火种 + 救世主 + 完结条。
- **谈判空间**：**最大**。手册原文："救世主状态只是个巨额攻击力加成，反而显得没有
  那么具有张力了，**要不要将来抬一手呢**。"——全手册唯一作者主动对天赋强度表达
  "不满意、想改"的地方。这是继承者最值得接的活。
- **M9 候选**：十二火种、残缺/完整救世主、挑战响应、焚诏、统一反击与死星天裁已经
  收口，规则见 `docs/m9/current/m9_g4_savior_cycle_rfc_v0.3.md`；只剩数值风洞与实现迁移。

#### G5 涟漪（S2，强盖章）
- **意图（S1）**：时间线操纵、命运下注、"与命运抗争"、昔涟的角色转译。
- **现状（S2）**：锚定（命数/变数/开拓/回档）+ 献诗十四首 + duet。
- **盖章记录（最强）**：作者自称"全游戏第一个神代天赋""倒逼整个世界的规则被严谨化，
  也是我做 RL 训练的源动力之一""时至今日，它还是我最得意的设计之一"（手册）。
  以及 deepseek 建议"把锚定整个砍掉"，作者"火气上来了，把整个规则书重新手写一遍"
  （手册）——**唯一一次为保住设计而对抗 AI 建议**。
- **谈判空间**：锚定**本体**几乎不可谈（强反弹），但命数/变数/开拓的公式与实现可重做。
  M9 最新候选以小昔涟轮回培养、德谬歌有限预算和玩家自写 K 槽脚本承接“时间线操纵、
  命运下注、与命运抗争”：系统从动作投影差分抽取事件，不再替玩家搜索路径。锚定见
  `docs/m9/current/m9_g5_anchor_contract_rfc_v0.4.md`，十四诗篇唯一正文见
  `docs/m9/current/m9_g5_poems_rfc_v0.1.md`；
  v0.3 与旧批次迁移稿只作历史证据。
- **新手指南彩蛋**：手册 Q&A 说"现在这个游戏只需要让 DM 当吟游诗人了之后反而不
  是很忌讳这一点了"——作者对 G5 的门槛问题已有妥协方案（DM 仲裁），不是钉子户。

#### G6 要有笑声！
- **意图**："把节奏断点变成笑话"（手册 Q&A），从废案区复活。
- **现状**：笑点 + 插入式笑话（借用任意合法行动，收益归己/责任归人）。
  已机制削弱过一次（V1.93 hotfix，自认"逼格没那么高了"）。插入式笑话的借用逻辑
  需要复杂枚举，是 AI/RL 的老大难。
- **谈判空间**：自身 D4 投递退役挂"暂缓复核"；其余数值可调。作者对 G6 的态度是
  乐子式的，无情感盖章。
- **M9 候选**：删除笑点和身份借用，改为以自身状态重演公开行动模板；借用核心和责任边界
  已冻结于 `docs/m9/current/m9_g6_cutaway_joke_rfc_v0.2.md`。

#### G7 星野（S2，工程事故式盖章）
- **意图**："盾要有，光环要有，荷鲁斯之眼要有，Terror 要有，掩体推进的感觉也要有"
  （手册），以及对列车大战/色彩反转剧情的角色理解辩护（日记长文）。
- **现状**：光环 + 铁之荷鲁斯 + 荷鲁斯之眼 + cost 宏 + 正背面 + 三形态 + 战术道具 +
  药物 + 色彩/Terror。代码量 14 天赋前列。
- **盖章记录**：作者对它是"认了"而不是"得意"："工程事故""生米煮成熟饭了，
  不开锅吃等什么？""是这个游戏在努力适配她"（手册）。
- **谈判空间**：所有细节可重做（P），但工作量巨大，且"这个游戏在适配她"这句话
  意味着作者接受它的复杂度作为既成事实。继承者若想动，应从"降低对手理解成本"
  入手（例：正背面可视化、宏的界面化），而非砍机制。
- **M9 候选**：三形态、Cost、宏、连续射击、Terror、色彩与守夜人召回已形成唯一结构合同，
  见 `docs/m9/current/m9_g7_tactical_suppression_rfc_v0.3.md`。

## 5. 修改安检清单

对任何改动（包括继承者自己、AI 协作者），动手前按序过一遍：

1. **定性**：这项改动落在哪一层？S1 / S2 / W / O / P？
   - 落在 S1 → 停手，另找解法。
   - 落在 S2 → 先写"新实现如何让角色有迹可循"的答案。
   - 落在 W / O / P → 可推进，但看第 2–4 条。
2. **验证器**：这个角色的哪个特征，通过改后的什么新机制体现？
3. **查证据**：作者对这件事有没有表态？（用 §4 索引）松口 / 盖章 / 静默？
   - 静默 ≠ 授权。作者没说过的话，不能当他说过。
4. **工程面**：是否影响 golden 回放 / 风洞？涉及 `controllers/`、`engine/`、
   `stats_runner.py` 的改动，提交前必须跑 `python stats_runner.py --players 6 --games 50`
   烟雾（CLAUDE.md 大规模重构纪律）。
5. **禁区**：不碰 CLAUDE.md 列出的不可触碰区域；新天赋交互一律走钩子。
6. **回写**：讨论有结论后，更新本地图的决策态与证据索引。

## 6. 使用示例（演示怎么用）

**例 1：想重做 G2 舞台以降低门槛**
- 定性：S2（舞台本体），落 P（实现细节）。
- 验证器：G2 的"需要观众、最后一曲、演出感"特征，新实现如何体现？
  答：精简后仍保留"谢幕 + 完结条 + 观众在场"的核心意象 → 通过。
- 查证据：作者只盖章"演出感"与"游戏中的游戏"，未盖章"必须 17 种物料牌" → 可谈。
- 风险提示：作者对 G2 有强叙事投资，方案需展示演出感不缩水。

**例 2：想做"往世层 × 死者苏生"交互**
- 定性：W（作者明确"正在考虑"）。
- 验证器：T7 苏生"把死者从坟里拽回来"的意象，与往世层"死者成星"意象天然相合 → 通过。
- 查证据：手册 12.4 已写明意图 → 属于接作者的活，不是越权。
- 工程面：全新功能，需评估往世层状态机与苏生钩子的接线。

**例 3：想把 T5 combo 重新加入 M9**
- 定性：`v2exp` 历史层仍有 T5，但作者已确认 M9 的原 T5 槽位由 G0 取代。

- 处理：若未来确需恢复，必须新建后续 RFC，先决定新槽位与援助资格；不能从 `v2exp` 静默继承。
