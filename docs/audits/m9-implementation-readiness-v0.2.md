### 1.2 G3 连续投影结构语义

| 项 | 语义 | 边界 |
|---|---|---|
| 适用白名单 | 仅固有结界内；第一版仅螺旋剑（伪）可连发 | 结界外维持单发（保护结界外魔力恢复经济）；复制武器待风洞默认不可；双刀/七重圆环/剑阵/初始配置不连发 |
| 连发结构 | 首发按 G3 v0.2 §4.1 结算（理想燃烧减免先行）→ 追加段数上限 `chain_max_repeats=2`（单根至多 3 发） | 第 n 段成本 `spiral_cost + (n−1)×chain_cost_step`；逐段独立预检+选目标；预检失败不付该段、连射结束、已消费不返还 |
| 子循环身份 | `projection_chain` 是关闭列举的根行动内部子循环，不是普通追演、不是 `ActionGrant` | 不刷新 T0/槽/SP/关注/公演/每轮上限；不授完整额外行动；整条连发一次 `root_action_performed`、一次根收尾与系统收尾 |
| 载荷复制 | 魂援/诗篇/其他"本次攻击"附加载荷默认只挂首发 | 来源必须明文允许 `projection_chain` 才可复制 |
| 累计耗魔计数器 | 每根行动从 0 累计实际支付的投影魔力（含减免后首发+全部连发段） | 根收尾清零；结界维持费、其他式样创建成本不计入 |
| 赤原猎风 | 累计耗魔 ≥ `chain_gale_threshold=6` 后，自该次起后续每次命中玩家单位的释放附加：SP−1（下限 0）+ 移出公演队列（v0.8 §6.2 失效纪律，永久移除、可重新报名） | 即时效果非控制状态（不免疫、不抗性拦截）；与该次伤害同批次；替身/重定向/绝对免疫承接伤害则不附加；`A=0` 或未命中不附加 |
| 频率闸 | 同一 `player_id` 每次结界至多被施加一次；同根不得重复 | 冻结结构非数值旋钮；G2 光身/影身/终曲歌者共享 `player_id`/SP/公演资格，不得借双 actor 重复扣减 |
| 终段幻想崩坏 | 连射停止后，理想燃烧已激活且剩余魔力 ≥ `collapse_terminal_min_magic=2` 可选同根终段：清空剩余魔力+牺牲三通道+统一攻击（`collapse_base_damage + collapse_per_style×min(式样数, cap)`，普通属性、`defense_coefficient=0.5`、A/H 两阶段、A 基准 25% 下限，非 `DIRECT_DAMAGE`）→ 无条件解除结界 | 可不选终段：结界与魔力保留、维持费照付；独立发动路径保留但同样满足下限；被迫退出无终结攻击 |
| 与既有 G3 的边界 | v0.2 §4.1/§8.2 仅在连发与同根终段范围内被取代 | 魔力/SP 职责分离、捕捉、破界、剑阵、警察边界、§九维持费、§10.1 退出路径不变 |

## 二、新增共同纪律

1. **援助追演与根内连发是两类不同的根内步骤**：星野追演=限定步骤（一次，挂"第一次合法攻击命中"）；
   `projection_chain`=关闭列举子循环（可多段，逐段付费）。两者在同一个根行动内互斥（二选一）。
   任何实现都不允许把根内步骤升级为独立行动、追演额度或完整额外行动。
2. **敌意 SP 扣减与强制公演队列移除**：赤原猎风是 M9 首例敌意 SP 扣减与第二例强制队列移除。
   实现必须先走 v0.8 §6.2 的失效/永久移除机器，再扣 SP（下限 0）；两件事独立判定（SP=0 时队列项照常）。
3. **世界援助的来源纪律**：任何世界援助效果都没有 player provider——`WORLD_RULE`/`world_poem_g0_aid`
   是唯一登记，不满足 G4 外来正面转移、G0×G7 联动、魂援额度或援助 PP 的任何条件。
4. **黑马快照时序**：只在 R0 开市结束、tranche 与转仓落定后重算；轮中死亡不改快照。
5. **数值键纪律**（DOC-048）：`world_poem_g0_heal`、`chain_max_repeats`、`chain_cost_step`、
   `chain_gale_threshold`、`collapse_terminal_min_magic` 五个键已登记 v0.4.6 首轮值，全部 `[待风洞]`；
   实现只读 `data/balance.json`，不得另设默认值或第二信源。

## 三、Given / When / Then 验收场景

### A. G0 世界援助（源自合同 §八，逐条核对）

1. **无 G0 局继承黑马**：Given 本局无 G0；When 出现黑马；Then 援助为「此诗，献予世界」，
   数值增益与 +10 终分不变（`blackhorse_*` 键照旧）。
2. **激活门槛**：Given 本局含 G0 且尚无任何有效押注；When R4 到来；Then 「昨日的同伴」不生效。
3. **进攻支援**：Given 本局含 G0 且已存在有效押注；When 黑马的攻击根行动命中；Then 追加一段
   基础近战追演，追演命中时目标获得震荡；目标已有压制/石化时不覆盖。
4. **追演×连发互斥**：Given 黑马 G3 的螺旋剑首发命中且可进入 `projection_chain`；When 追加窗口
   开放；Then 玩家只能选择星野追演或投影连发子循环之一，不能在同一根行动中同时取得。
5. **防御支援**：Given 本局含 G0 且援助已激活；When R4；Then 每名存活黑马所在地点所有单位回复
   `world_poem_g0_heal` 点 HP，不超过各自最大 HP；多名黑马共享地点时只回复一次。
6. **G0 撤退后照常**：Given G0 已撤退；When 黑马满足条件；Then 两式支援照常生效，
   G0 不获得任何 PP/关注/评分。
7. **无 G0×G7 联动**：Given G7 与 G0 同局；When 进攻支援追演命中；Then 不适用 `+20%` 联动放大。
8. **治疗不喂火种**：Given 黑马所在地的 G4 仍为人形态；When 绫音急救回复其 HP；Then 治疗事件
   来源为 `WORLD_RULE`，G4 不获得外来正面转移火种。

### B. G3 连续投影（源自合同 §八，逐条核对）

9. **结界外单发**：Given 结界外；When G3 发动螺旋剑根行动；Then 单发结算，无连发提示。
10. **结界内连发**：Given 结界内、魔力充足；When 螺旋剑根行动完成；Then G3 可支付递增成本
    追加至多 `chain_max_repeats` 段同式样连发，每段独立预检与选目标。
11. **段预检失败**：Given 某段连发预检失败；When 选择该段；Then 不支付该段成本、连射结束、
    行动槽已消费。
12. **赤原猎风首触发**：Given 本根行动累计耗魔首次达到阈值；When 该次释放命中 SP=2 且在公演
    队列的玩家；Then 目标 SP −1 并被移出公演队列，可按 v0.8 §6.2 重新报名。
13. **SP=0 边界**：Given 目标 SP=0；When 赤原猎风触发；Then SP 项无事发生，队列项照常检查。
14. **双 actor 频率闸**：Given G2 光身已在本次结界承受赤原猎风；When 后续释放命中其影身；
    Then 不再次扣共享 SP。
15. **终段选择**：Given 理想燃烧已激活、连射停止且剩余魔力达到终段下限；When G3 选择终段；
    Then 消耗全部剩余魔力、牺牲三通道、对主目标统一攻击并解除结界；When G3 不选择终段；
    Then 结界保留、维持费照付。
16. **终段下限**：Given 理想燃烧已激活但剩余魔力低于终段下限；When 连射停止；Then 不能白拿
    幻想崩坏，只能保留结界或按资源耗尽路径退出。
17. **压制中断**：Given G3 在连发中途被压制；When 当前根行动被消费；Then 未结算的连发段与
    终段机会一并损失，结界按 §10.1 维持。
