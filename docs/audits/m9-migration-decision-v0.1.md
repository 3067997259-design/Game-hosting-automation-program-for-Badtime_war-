## 一、决策原则

1. **结构冻结才可进**：合同正文的"选择权、时点、目标、生命周期与失败分支"已冻结
   （README「尚未冻结的内容」原文），机制层（`engine/m9/`）已按冻结结构落地并可独立
   运行（`tools/m9_rfc_smoke.py` exit=0）；
2. **数值不进**：全部 `[待风洞]` 数值保持 `data/balance.json` 占位，迁移不携带任何
   数值单值化；风洞完成前不得把 m9-rfc 行为接入 `v2exp` 现行 profile；
3. **接入需作者拍板**：本表只给建议，`v2exp` 接入代码必须由作者批准后另做
   （本目标停止线：不将 m9-rfc 行为接入 v2exp 现行 profile 除非迁移决策通过）；
4. **先原型后迁移**：README 门槛明确要求 W1 指标（首轮即演数、连续即演长度、六人每轮
   演出总数、公演队列空置率）与 v0.8 合同重跑模型通过后，才讨论迁入。
