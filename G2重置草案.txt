# 神代天赋2.「请一直，注视着我」Reset v0.7

> 「舞台不会因为无人理解而消失。」
> 「但如果无人注视，歌声终将坍塌。」
> 「你可以入戏，可以冷眼旁观，也可以亲手撕开帷幕。」
> 「而我，只想把这首歌唱到最后。」

---

# 0. 设计定位

G2 Reset 是一场把全局拖入特殊舞台层的强制演出。

`ish-bosheth` 展开后，游戏短暂进入一个由三声部、Chorus、物料牌、Regard、安定値和旋律构成的舞台副游戏。

核心目标：

1. 打断当前地图秩序；
2. 将真实观众分配到三个声部（Acc/Ind/Str 固定阵营）；
3. 让三方围绕不同结局竞争；
4. 通过公开物料牌提升行动效率、交易博弈和阵营烈度；
5. 通过安定値（旋律伤害修正系统）制造"轻甲被奶/重甲被打"的非对称博弈；
6. 让 G2 在台上调度局势，尽可能打满旋律并完成谢幕。

# 3. 结界展开：`ish-bosheth`

## 3.1 分布式舞台

G2 传送回家（`home_{player_id}`，舞台中心）。5 个标准地点成为 5 个观众座位（商店/魔法所/警察局/医院/军事基地）。非 G2 参与者优先留原地（若位置恰好是座位），否则分配到空余座位。空位由 Chorus 填充，总观众数≥6 以支持 2/2/2 声部结构。

## 3.2 行动权

舞台内 **全员行动**（D4 仅决定顺序，不决定谁行动）。G2 固定 D4=0，获得 R3 最优先保底回合。G2 只能 special（演唱）或 forfeit。

## 3.3 舞台限制

禁止普通地点交互（商店打工/医院手术/军事基地取装备/警察局举报等）。禁止 report。

## 3.4 入场清理

清除隐身、即时关系（find/lock/engage）、星野架盾/持盾。警察原地 Submerged（冻结）。所有单位获 `liberamente_vivace` 成员标记。未起床者强制起床。

---

# 4. 舞台单位

## 4.1 真实观众

非 G2 参与者被分配到一个声部（Acc/Ind/Str），该声部在本场演出中视为固定临时阵营。仅「改签票」可以改变声部。

## 4.2 Chorus

总观众数不足 6 时，自动创建 Chorus 补齐。Chorus 持有声部、1 张物料牌、随机武器/护甲。Chorus 注册到 `game_state.players`（不加入 `player_order`），可被 attack/find/AOE 命中。

**Chorus 声部攻击限制**：
- Acc: 攻击 Str 单位
- Str: 攻击 Acc 单位 + G2
- Ind: 仅攻击持有物料牌的 Chorus
- 不攻击 Indifferenza + 无牵连/聚光灯/安可的单位

---

# 5. 三声部系统

声部在开场由 `ma non troppo` 分配（目标 2/2/2），不可自由切换。

| 声部 | 目标 | 攻击谁 | 不能攻击谁 |
|------|------|--------|-----------|
| Acc | 消灭 Str | Str 真实/Chorus + 持牌 Chorus | G2 / Ind 真实 / Acc 同声部 |
| Str | 灭 Acc 或破幕 | Acc 真实/Chorus + G2 + G2 投影 | Ind 真实 / Str 同声部 |
| Ind | 维持演出至完整谢幕 | 持牌 Chorus | 真实玩家 |

# 6. 阵营结局与奖励

每个 R4 检查阵营胜利条件：

| 结局 | 触发条件 | 奖励 |
|------|---------|------|
| Acc 狂热终幕 | 无 Str 存活 + Acc 存活 | D4/D6+1，下次伤害+0.5 |
| Str 撕幕终幕 | 无 Acc 存活 + Str 存活；或破幕 | D4/D6+1，清除自身标记；破幕者额外 D4+1 |
| G2/Ind 完整谢幕 | 持续 8 R4 未触发上述条件 + Acc/Str 均存活 | D4/D6+1，恢复 0.5 HP；G2 隐身 + 按 Chorus 存活率追加奖励 |
| 静默终幕 | Acc/Str 同时不存在 + Ind 存在 | Ind D4+1；G2 隐身 |
| 空场退场 | 无真实非 G2 玩家 | 无奖励；G2 隐身 |

# 7. Regard（v0.7 修订）

## 7.1 初始值

```text
Regard = clamp(3 + P + 0.5×C + 0.5×N, 4, 8)
P = 真实观众数, C = Chorus 数, N = Submerged 单位数
```

上限 8。

## 7.2 R4 变化（Ind 翻倍）

```text
ΔRegard = -1.0 (基础衰减)
        + 1.0 × Ind 真实观众 (v0.7 翻倍)
        + 0.5 × Ind Chorus       (v0.7 翻倍)
        - 0.5 × Str 真实观众
        - 0.25 × Str Chorus
        (Acc 不影响 Regard)
```

所有 Regard 变化通过 `adjust_regard()` 统一追踪，累计 `|ΔRegard|` 到 `cumulative_delta_regard`。

## 7.3 Regard 归零/超时

待谢幕（`pending_curtain`）→ 下个 R0 触发谢幕。最大持续 8 R4。

# 9. 旋律系统（v0.7：安定値 + 累计解锁）

## 9.1 解锁机制

不再由固定轮次解锁，而是通过 **累计 |ΔRegard|**（`cumulative_delta_regard`）解锁。每次 Regard 变化（唱贵歌、R4 衰减、撕票等）都会累计。

| 名称 | 累计解锁 | 使用次数 | base_dmg 序列 |
|------|---------|---------|--------------|
| 序曲 | 开幕免费 | 1 次 | [1.0, 0.5, 0.5, 0.5] |
| 旋律·第一音节 | ≥3.0 | 1 次 | [1.0, 0.5, 0.5, 0.5] |
| 旋律·第二间章 | ≥7.0 | 1 次 | [1.0, 1.0, 0.5, 0.5] |
| 旋律·第三间章 | ≥11.0 | 1 次 | [2.0, 2.0, 1.0, 1.0] |

G2 激进消费（唱贵歌=累计加速）或保守（保 Regard=累计靠 R4 自然增长）都能达到解锁阈值。

## 9.2 目标选择

G2 选 1-2 个座位，最多命中 4 个目标。衰减系数：第 1 目标=1.0，第 2=0.6，第 3=0.4，第 4=0.2。

## 9.3 安定値（每目标独立计算）

```text
安定値 = (base_安定 + armor_mod) × armor_mult × decay_factor

base_安定 = clamp(cumulative_delta_regard / 6 - 0.5, -0.5, +1.5)
total_defense = max_hp + 护甲当前HP + talent特殊(raw_hp/炽愿×0.5/铁之荷鲁斯HP)
pivot = 3.5 (被 Riposato/Dolente 覆盖为 5.0/2.0)
armor_mod = (total_defense - pivot) × 0.4
armor_mult = 1.0 (Placido×0.5, Zeffiroso×2, 旋律命中后清除)
decay = 1.0/0.6/0.4/0.2 (反光板强制 1.0)
```

安定値 > 0 → 增伤。安定値 < 0 → 治疗。旋律命中后所有 `_stability_*` 标记即时清除。

## 9.4 声部特效

命中且存活后触发：
- **Acc** — 狂热：下次攻击 Str 伤害 +0.5
- **Ind** — 回声：摸 1 张物料牌
- **Str** — 裂音：Regard -0.25 + 下次攻击 G2 伤害 +0.5

## 9.5 设计意图

天然惩罚叠甲的重装单位（旋律暴击），鼓励轻甲敏捷单位参与演出（旋律治疗）。G2 通过 song 消费和 pivot 调整来控制旋律的方向。

# 11. 破幕

只有 **Strappando 真实玩家**可完成破幕。方式：
1. 移动到 G2 家 + attack 造成致命伤害
2. 使用后台通行证生成 G2 投影 + attack 投影

破幕时 G2 不死亡（HP 恢复攻击前），结界以 break 理由结束，Str 阵营胜利，破幕者额外 D4+1。

Chorus 不能破幕——其攻击使 G2 HP 降至 max(0.5, 攻击前)，Regard -1。

---

# 12. Embrace（相拥伤害）

`ish-bosheth` 内所有非 G2 且持有 `liberamente_vivace` 的单位造成伤害时自动标记为 Embrace——绕过天赋特殊防护（G1 炽愿、G7 铁之荷鲁斯、警察保护等），但不绕过普通护甲。

> 注意：安定値系统上线后，Embrace 的"穿透特殊防御"功能与旋律安定値的"重甲挨打"存在重叠。将来安定値成熟后考虑移除 Embrace 自动标记。

# 13. 其他机制

- **离场**: `move home_{pid}`。有安可层数时失败（消耗回合，安可-1）。离场后清除舞台状态。
- **聚光灯**: Soave/Sognando 授予。持续至下个 R4。提供额外行动回合、tempHP/ATK。
- **安可**: Placido/Zeffiroso 授予。阻止离场，逐层消耗。
- **G2 投影**: 后台通行证生成。攻击投影 = 攻击 G2（可破幕/Regard-1）。
- **ma non troppo**: 仅开场运行，分配 2/2/2 声部。Chorus 补足缺口。

# 15. 致敬与灵感来源

**结界命名：`ish-bosheth`（伊施波设）**
来自《蔚蓝档案》空崎日奈（礼服）的 EX 技能名。日奈的 EX 初始消耗6费用，释放后进入不可移动的集中射击模式，并重新抽取EX至牌堆顶，转化为第一/二/三旋律逐一奏响——这正是 G2 "舞台上只能演唱"和三段旋律递进的原型。

**三乐章旋律结构**
致敬日奈（礼服）的 EX 技能机制：第一/第二旋律倍率相同、第三乐章倍率翻倍。G2 的序曲→第一音节→第二间章→第三间章继承了这一递进结构，但改为累计 ΔRegard 解锁而非固定轮次，以适应桌面游戏的节奏。

**安定値（Stability）**
反向借鉴了《蔚蓝档案》的"安定值"概念。在 BA 中，安定值决定伤害浮动范围，礼奈有无视安定值波动保持伤害最大值的buff；在 G2 中，安定値被改写为一个**带符号的伤害修正系数**——正=增伤、负=治疗——受累计 ΔRegard、目标总防御 HP、pivot（Before light 调整）和卡牌标记等多因素影响。这使旋律不再是固定输出，而是 G2 动态调控舞台压力的工具。

**24K钛合金狗牌**
名字致敬了10年代晚期互联网“亮瞎了我的24K钛合金狗眼”表情包/梗。

**其他卡牌命名**
物料牌系统整体致敬同人展会/演唱会周边文化：前排票、小卡交换、聚光合影、应援连呼等命名都来自这类场景。后台通行证（Str 破幕牌）来自演出的后台文化。改签票（唯一阵营改签权）来自票务术语。

# 16. G5 献诗 × G2 舞台：双人演出 TE（设计草案 v0.1）

> 「如果这场最盛大的演出最终注定会结束……」
> 「那命运至少应该补偿给你，应得的花束。」

当往世的涟漪（G5）踏入 ish-bosheth 的舞台层，两套独立的记忆系统——追忆与累计 ΔRegard——在此共振。两个叙事体系在同一个舞台上交织：**台下的人不再只是观众，她走上台，成为演出的一部分**。

## 16.1 设计定位

G2 的五个 BE 结局都指向同一件事——**舞台是孤独的**。狂热终幕是台下杀红了眼，撕幕终幕是台下亲手毁了演出，完整谢幕是"撑到了最后，但没有人真正在听"。

G5 是唯一的例外。她的献诗系统天生就是"改变他人的命运"——而在这套 TE 中，她选择**把诗唱给舞台本身**。

这是**改写演出的命运**——从无人注视的独唱，变为有人并肩的双人演出。

## 16.2 触发条件

### 时机

G5 在 ish-bosheth 激活期间，选择 T0 发动方式二（献诗增强）→ 选择 G2 为目标。

### 全场投票

```
是否允许发动的投票权分布：
  每个真实观众（含 G2、G5）：1 票
  G2 1 票
  G5 1 票
通过条件：赞成票 ≥ 总票数的 50%
平票：视为不通过

选歌时的投票权分布：
  每个真实观众（含 G2、G5）：1 票
  每个 Chorus：1 票
  G2 额外 +1 票（合计 2 票）
  G5 额外 +1 票（合计 2 票）
```

### 通过 → 进入 TE

- G5 移动到 G2 所在位置（舞台中心 / home_{g2_pid}）
- G2 和 G5 均获得双人演出行动限制（同 16.4）
- Regard 重置为 4（保证至少第一轮演出顺利进行）
- 三声部热力值计数器初始化为 `Acc=0, Ind=0, Str=0`
- G5 的 12 追忆预算公开可见

### 不通过 → 追忆不返还

- G5 消耗的追忆和行动回合不返还
- G5 留在台下，演出继续按正常 BE 路径推进
- G5 在同一次演出中不可再次献诗上台

## 16.3 核心循环

```
每轮循环：

R0: 两个「大红按钮」dummy 刷新在两个随机不同座位
    热力值计数器公开展示（Acc / Ind / Str）

投票选歌: G2 提名 3 个节奏候选 → 所有观众投票（含 Chorus）
          G2 + G5 各持 2 票，其余每人/Chorus 各持 1 票
          得票最高者当选

R3: 所有单位行动
    · 打按钮 → 造成伤害 = 为该声部贡献等量热力值 → 按钮消失
    · 位移 PvP → 不造成伤害，仅位移（见 16.5）
    · 上供舞台 → 使用物料牌对 G2/G5 → 低保热力（见 16.6）

R4: 热力值总合 × 转化率 → 折算为 Regard 注入
     G2 唱当选歌曲 → 消耗 Regard → 歌曲效果生效
     G5 可选伴唱（见 16.8）
     Regard ≤ 0 → 进入谢幕
     Regard > 0 → 继续下一轮（最多 8 轮）
```

## 16.4 双人演出行动限制

G2 和 G5 的行动被统一为：

| 可执行 | 说明 |
|--------|------|
| special（演唱） | 消耗 Regard，触发本轮歌曲效果 |
| forfeit | 放弃回合 |
| T0 物料阶段 | 摸牌、拾取、打出（同正常演出） |

G2 和 G5 **不能**打按钮、位移 PvP、或执行其他行动类型。

G2 的贡献方式：唱对歌。
G5 的贡献方式：伴唱 + 追忆预算管理。

## 16.5 位移 PvP

TE 模式下，玩家间直接攻击不造成伤害，而是产生位移效果。护甲和武器的意义从"保命/输出"转变为"站位控制权争夺"。

### 规则

```
造成伤害 ≤ 1.0:
  → 被攻击单位不受伤
  → 50% 概率：被强制位移到随机另一个座位
  → 50% 概率：无事发生

造成伤害 > 1.0:
  → 被攻击单位不受伤
  → 50% 概率：被强制位移到随机另一个座位
  → 50% 概率：攻击者指定位移到任意一个座位
```

### 武器的新意义

| 伤害档次 | 代表武器 | PvP效果 |
|----------|---------|--------|
| ≤1.0 | 小刀(1.0)、警棍(1.0) | 仅能赌随机弹飞，战术价值有限 |
| >1.0 | 磨过的刀(2.0)、高斯步枪(2.0) | 有概率精准流放对手到最差座位 |

阈值线正好位于 1.0——魔法弹幕和警棍的使用者站在赌运气的边缘，而持有高斯步枪且愿意交蓄力或者有其他增伤/减伤天赋的话，就拥有真正的站位控制力。

### Chorus

Chorus 同样适用位移 PvP 规则（不受伤，仅位移）。流放对方 Chorus 可以削弱其声部抢按钮的能力。

## 16.6 大红按钮

### 基本规则

```
· 每轮 R0 在两个随机不同座位各召唤一个「大红按钮」dummy（HP 无限，不死亡）
· 每个按钮每轮只能被攻击一次
· 被攻击后：造成伤害 = 为该攻击者声部贡献等量热力值
· 被攻击后立刻消失（该轮不再可用）
· 下轮 R0 重置 → 重新在两个随机座位刷新（可能与上轮相同）
```

### 三声部的按钮竞争

两个按钮，三个声部（+ 各自的 Chorus）。每一轮必然有至少一个声部抢不到按钮。

| 战术 | 描述 |
|------|------|
| **前排票** | 直接飞到按钮旁——不需要高 D4 也能抢到按钮 |
| **聚光合影** | 把对手从按钮旁拉走（破坏其站位） |
| **荧光棒** | 打按钮时伤害 +0.5（对 Str 改为 +1.0）→ 直接转化为热力 |
| **应援连呼** | 让 Acc Chorus 立刻打按钮——多一个打手 |
| **狗牌** | 按钮无属性，但狗牌保留以备 PvP 破防 |

### 低保路径（上供舞台）

没抢到按钮的声部可以对 G2/G5 使用物料牌获得固定小额热力：

| 牌 | 上供效果 |
|----|---------|
| 花束 | 给 G2 或 G5  固定热力 |
| 反光板 | 保护目标 + 固定热力 |
| 场刊整理 | 双方各摸 1 + 双方声部各 + 小额热力 |
| 荧光棒 | 改为对舞台使用，本声部 + 固定热力 |

## 16.7 歌曲系统（双人演出版）

三首歌六个节奏，在 TE 模式下改为影响热力产出和竞争模式：

### 追寻那道光

| 节奏 | Regard | 效果 |
|------|--------|------|
| Soave | 1 | 选择一个声部 → 该声部本轮按钮伤害 ×1.5。G2 摸 1 牌。 |
| Sognando | 2 | 选择一个声部 → 该声部内任意单位移动到按钮所在座位 + 该声部本轮按钮伤害 ×1.5。 |

博弈：G2 可以"点名"落后声部帮追分，也可以强化领先声部扩大差距。

### 拼接遗憾

| 节奏 | Regard | 效果 |
|------|--------|------|
| Placido | 1 | 选择一个目标 → 本轮对该目标的 PvP 位移免疫（不被弹飞）。+0.5 tempHP。 |
| Zeffiroso | 2 | 选择两个座位 → 两座位上所有单位互换位置。复活一个死 Chorus。 |

博弈：Placido 保你的打手不被流放。Zeffiroso 是声部级别的强制位移。

### Before light

| 节奏 | Regard | 效果 |
|------|--------|------|
| Riposato | 2 | 本轮热力→Regard 转化率 ×1.5。所有按钮伤害不分声部，统一计入公共池。 |
| Dolente | 3 | 召唤第三个按钮（随机空余座位）。所有按钮伤害 ×1.3。 |

博弈：Riposato 是最深的战术——它抹掉声部区分，全员往同一个池子里打，是"危险时刻的休战协议"。Dolente 高费高风险——三个按钮更分散，更难靠 PvP 覆盖，但总热力上限更高。

### 投票选歌

每轮 G2 提名 3 个节奏候选 → 所有观众（含 Chorus）按 16.2 的票权投票 → 得票最高者当选。

G2 和 G5 的 4 票总和在总票池中约占 25-40%——可以影响但不能独裁。G2 需要拉拢至少一个声部才能通过自己想要的歌。

## 16.8 G5 伴唱与安可

### 伴唱

```
G5 在 G2 唱歌前可选择是否伴唱：
  → 消耗 X 追忆（X 待定，约 2）
  → 本轮歌曲 Regard 花费 -50%（向下取整，最低 0）
  → 总计消耗不能超过 12 追忆
```

### 追忆预算（公开）

G5 的剩余追忆全程公开可见。12 追忆 = 最多伴唱 6 次（若每次 2 追忆）。

### 安可

```
触发条件：
  演出来到第 8 轮（达到上限）
  AND G5 追忆剩余 = 12（零消耗，完全未使用）

效果：
  G2 + G5 合唱双人曲 —— 安可！
  所有在场真实观众从游戏中自选一件物品。
  选择方式（两轮）：
    第一轮：选择获取地点（如商店、警察局、军事基地、魔法所、医院、家）
    第二轮：从该地点可获取的物品列表中选择具体物品

  安可奖励叠加在正常热力排名奖励之上。
```
```
若 G5 追忆有消耗但未耗尽，无安可。
（与斗地主同理——大小王可以炸，也可以拆开出。憋到底拿安可，中途用掉帮大家撑过低谷。）
```

## 16.9 热力排名与谢幕

### 排名结算

演出结束时（达到第 8 轮或 Regard 耗尽），按三声部累计热力值排名：

| 排名 | 奖励 |
|------|------|
| 第 1 声部 | 全员 D4/D6+2，下次伤害 +0.5，获得「打榜王」特殊标记 |
| 第 2 声部 | 全员 D4/D6+1，tempHP +0.5 |
| 第 3 声部 | 全员 D4+1 |

### Embrace（谢幕拥抱）

谢幕时，每个真实观众可选执行 `special embrace <玩家名>`：

| 拥抱对象 | 效果 |（暂定）
|----------|------|
| G2 | 「歌者的祝福」：下一次攻击伤害 +0.5，持续 2 轮 |
| G5 | 「涟漪的余韵」：下一次被攻击时免伤 0.5，持续 2 轮 |

按热力排名追加：

| 排名 | Embrace 效果 |
|------|-------------|
| 第 1 声部 | 效果翻倍（×2） |
| 第 2 声部 | 效果正常（×1） |
| 第 3 声部 | 效果减半（×0.5） |

所有声部获取奖励结束后，G2和G5会相互拥抱，双方获得对方的最高等级奖励。

### 演出提前结束

若 Regard 在达到第 8 轮之前耗尽：

| 达到轮次 | 结算 |
|----------|------|
| 6-7 轮 | 排名奖励正常，Embrace 效果降为正常的 0.75 |
| 4-5 轮 | 排名奖励减半，Embrace 效果降为正常的 0.5 |
| ≤3 轮 | 演出崩溃：无排名奖励，仅 G2+G5 获少量补偿 |

### 安可叠加

若触发安可（第 8 轮 + G5 追忆全满），安可的自选物品奖励**叠加**在排名和 Embrace 之上。

## 16.10 TE 的博弈结构

### 投票阶段

- **优势声部**（人多/装备好）→ 倾向反对，走正常路径独占阵营胜利收益
- **劣势声部**→ 倾向赞成，在 TE 中重新洗牌争夺热力排名
- **脆皮玩家**→ 倾向赞成——TE 中不掉人，不会被安定値暴击打死
- **G5 需要拉拢刚好过半**——多一张浪费追忆，少一张直接失败追忆不返还

### 演出阶段

这本质上是一个**公共品博弈 + 排名竞争**：

| 层 | 描述 |
|----|------|
| **公共品** | 总热力值 → Regard → 演出能否撑到 8 轮（所有人都想要安可） |
| **排名竞争** | 各声部热力排名决定最终奖励等级（独占排他） |
| **搭便车诱惑** | 让别人打按钮，自己留着武器 PvP 压制对手 |

经典困境：人人搭便车 → 总热力不足 → 第 5 轮散场 → 全员低保。
最优解：**让拿最强武器的玩家去打按钮，无论他的声部**——这是被博弈逼出来的理性选择。

### G5 的安可困境

| 路径 | G5 做什么 | 对 G2 影响 | 对全体影响 |
|------|----------|-----------|-----------|
| 伴唱辅助 | 消耗追忆帮 G2 减费 | 可以唱贵歌 → 热力爆发 | 稳定撑到 8 轮，排名奖励正常，无安可 |
| 憋安可 | 一滴追忆都不花 | 只能唱便宜歌 → 热力拮据 | 极难撑到 8 轮，但撑到了全员超级奖励 |

G5 的每次伴唱决策——帮不帮——都是用安可的可能性交换本轮的安全感。

## 16.11 正常路径收益增强

为了使"反对投票走正常战争"与"赞成投票进 TE"形成真正的博弈，五个 BE 的收益需增强：

| 结局 | 增强后收益 |
|------|-----------|
| Acc 狂热终幕 | D4/D6+1，全员伤害+0.5，Acc 成员恢复 0.5 HP |
| Str 撕幕终幕 | D4/D6+1，清除自身标记，破幕者翻找 G2 家获得随机物品 |
| Ind 完整谢幕 | D4/D6+1，恢复 0.5 HP，G2 隐身，Ind 成员摸 1 牌 |
| 静默终幕 | Ind D4+1，G2 隐身 |
| 空场退场 | 无奖励，G2 隐身 |

增强逻辑：如果你确信自己声部能灭掉对方，独占收益应大于 TE 的二等/三等排名奖励。
