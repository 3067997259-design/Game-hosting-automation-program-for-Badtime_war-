# 神代天赋2.「请一直，注视着我」Reset v0.7

> 「舞台不会因为无人理解而消失。」
> 「但如果无人注视，歌声终将坍塌。」
> 「你可以入戏，可以冷眼旁观，也可以亲手撕开帷幕。」
> 「而我，只想把这首歌唱到最后。」

# 0. 设计定位

G2 Reset 是一场把全局拖入特殊舞台层的强制演出。

`ish-bosheth` 展开后，游戏短暂进入一个由三声部、Chorus、物料牌、Regard、安定値和旋律构成的舞台副游戏。

核心目标：

1. 打断当前地图秩序；
2. 将真实观众分配到三个声部（Acc/Ind/Str 固定阵营）；
3. 让三方围绕不同结局竞争；
4. 通过公开物料牌提升行动效率、交易博弈和阵营烈度；
5. 通过安定値（旋律伤害修正系统）制造"轻甲被奶/重甲被打"的非对称博弈；
6. 让 G2 在台上调度局势，尽可能打满旋律并完成谢幕。

# 3. 结界展开：`ish-bosheth`

## 3.1 分布式舞台

G2 传送回家（`home_{player_id}`，舞台中心）。5 个标准地点成为 5 个观众座位（商店/魔法所/警察局/医院/军事基地）。非 G2 参与者优先留原地（若位置恰好是座位），否则分配到空余座位。空位由 Chorus 填充，总观众数≥6 以支持 2/2/2 声部结构。

## 3.2 行动权

舞台内 **全员行动**（D4 仅决定顺序，不决定谁行动）。G2 固定 D4=0，获得 R3 最优先保底回合。G2 只能 special（演唱）或 forfeit。

## 3.3 舞台限制

禁止普通地点交互（商店打工/医院手术/军事基地取装备/警察局举报等）。禁止 report。

## 3.4 入场清理

清除隐身、即时关系（find/lock/engage）、星野架盾/持盾。警察原地 Submerged（冻结）。所有单位获 `liberamente_vivace` 成员标记。未起床者强制起床。

---

# 4. 舞台单位

## 4.1 真实观众

非 G2 参与者被分配到一个声部（Acc/Ind/Str），该声部在本场演出中视为固定临时阵营。仅「改签票」可以改变声部。

## 4.2 Chorus

总观众数不足 6 时，自动创建 Chorus 补齐。Chorus 持有声部、1 张物料牌、随机武器/护甲。Chorus 注册到 `game_state.players`（不加入 `player_order`），可被 attack/find/AOE 命中。

**Chorus 声部攻击限制**：
- Acc: 攻击 Str 单位
- Str: 攻击 Acc 单位 + G2
- Ind: 仅攻击持有物料牌的 Chorus
- 不攻击 Indifferenza + 无牵连/聚光灯/安可的单位

---

# 5. 三声部系统

声部在开场由 `ma non troppo` 分配（目标 2/2/2），不可自由切换。

| 声部 | 目标 | 攻击谁 | 不能攻击谁 |
|------|------|--------|-----------|
| Acc | 消灭 Str | Str 真实/Chorus + 持牌 Chorus | G2 / Ind 真实 / Acc 同声部 |
| Str | 灭 Acc 或破幕 | Acc 真实/Chorus + G2 + G2 投影 | Ind 真实 / Str 同声部 |
| Ind | 维持演出至完整谢幕 | 持牌 Chorus | 真实玩家 |

---

# 6. 阵营结局与奖励

每个 R4 检查阵营胜利条件：

| 结局 | 触发条件 | 奖励 |
|------|---------|------|
| Acc 狂热终幕 | 无 Str 存活 + Acc 存活 | D4/D6+1，下次伤害+0.5 |
| Str 撕幕终幕 | 无 Acc 存活 + Str 存活；或破幕 | D4/D6+1，清除自身标记；破幕者额外 D4+1 |
| G2/Ind 完整谢幕 | 持续 8 R4 未触发上述条件 + Acc/Str 均存活 | D4/D6+1，恢复 0.5 HP；G2 隐身 + 按 Chorus 存活率追加奖励 |
| 静默终幕 | Acc/Str 同时不存在 + Ind 存在 | Ind D4+1；G2 隐身 |
| 空场退场 | 无真实非 G2 玩家 | 无奖励；G2 隐身 |

# 7. Regard（v0.7 修订）

## 7.1 初始值

```text
Regard = clamp(3 + P + 0.5×C + 0.5×N, 4, 8)
P = 真实观众数, C = Chorus 数, N = Submerged 单位数
```

上限 8。

## 7.2 R4 变化（Ind 翻倍）

```text
ΔRegard = -1.0 (基础衰减)
        + 1.0 × Ind 真实观众 (v0.7 翻倍)
        + 0.5 × Ind Chorus       (v0.7 翻倍)
        - 0.5 × Str 真实观众
        - 0.25 × Str Chorus
        (Acc 不影响 Regard)
```

所有 Regard 变化通过 `adjust_regard()` 统一追踪，累计 `|ΔRegard|` 到 `cumulative_delta_regard`。

## 7.3 Regard 归零/超时

待谢幕（`pending_curtain`）→ 下个 R0 触发谢幕。最大持续 8 R4。

# 9. 旋律系统（v0.7：安定値 + 累计解锁）

## 9.1 解锁机制

不再由固定轮次解锁，而是通过 **累计 |ΔRegard|**（`cumulative_delta_regard`）解锁。每次 Regard 变化（唱贵歌、R4 衰减、撕票等）都会累计。

| 名称 | 累计解锁 | 使用次数 | base_dmg 序列 |
|------|---------|---------|--------------|
| 序曲 | 开幕免费 | 1 次 | [1.0, 0.5, 0.5, 0.5] |
| 旋律·第一音节 | ≥3.0 | 1 次 | [1.0, 0.5, 0.5, 0.5] |
| 旋律·第二间章 | ≥7.0 | 1 次 | [1.0, 1.0, 0.5, 0.5] |
| 旋律·第三间章 | ≥11.0 | 1 次 | [2.0, 2.0, 1.0, 1.0] |

G2 激进消费（唱贵歌=累计加速）或保守（保 Regard=累计靠 R4 自然增长）都能达到解锁阈值。

## 9.2 目标选择

G2 选 1-2 个座位，最多命中 4 个目标。衰减系数：第 1 目标=1.0，第 2=0.6，第 3=0.4，第 4=0.2。

## 9.3 安定値（每目标独立计算）

```text
安定値 = (base_安定 + armor_mod) × armor_mult × decay_factor

base_安定 = clamp(cumulative_delta_regard / 6 - 0.5, -0.5, +1.5)
total_defense = max_hp + 护甲当前HP + talent特殊(raw_hp/炽愿×0.5/铁之荷鲁斯HP)
pivot = 3.5 (被 Riposato/Dolente 覆盖为 5.0/2.0)
armor_mod = (total_defense - pivot) × 0.4
armor_mult = 1.0 (Placido×0.5, Zeffiroso×2, 旋律命中后清除)
decay = 1.0/0.6/0.4/0.2 (反光板强制 1.0)
```

安定値 > 0 → 增伤。安定値 < 0 → 治疗。旋律命中后所有 `_stability_*` 标记即时清除。

## 9.4 声部特效

命中且存活后触发：
- **Acc** — 狂热：下次攻击 Str 伤害 +0.5
- **Ind** — 回声：摸 1 张物料牌
- **Str** — 裂音：Regard -0.25 + 下次攻击 G2 伤害 +0.5

## 9.5 设计意图

天然惩罚叠甲的重装单位（旋律暴击），鼓励轻甲敏捷单位参与演出（旋律治疗）。G2 通过 song 消费和 pivot 调整来控制旋律的方向。

# 11. 破幕

只有 **Strappando 真实玩家**可完成破幕。方式：
1. 移动到 G2 家 + attack 造成致命伤害
2. 使用后台通行证生成 G2 投影 + attack 投影

破幕时 G2 不死亡（HP 恢复攻击前），结界以 break 理由结束，Str 阵营胜利，破幕者额外 D4+1。

Chorus 不能破幕——其攻击使 G2 HP 降至 max(0.5, 攻击前)，Regard -1。

---

# 12. Embrace（相拥伤害）

`ish-bosheth` 内所有非 G2 且持有 `liberamente_vivace` 的单位造成伤害时自动标记为 Embrace——绕过天赋特殊防护（G1 炽愿、G7 铁之荷鲁斯、警察保护等），但不绕过普通护甲。

> 注意：安定値系统上线后，Embrace 的"穿透特殊防御"功能与旋律安定値的"重甲挨打"存在重叠。将来安定値成熟后考虑移除 Embrace 自动标记。

# 13. 其他机制

- **离场**: `move home_{pid}`。有安可层数时失败（消耗回合，安可-1）。离场后清除舞台状态。
- **聚光灯**: Soave/Sognando 授予。持续至下个 R4。提供额外行动回合、tempHP/ATK。
- **安可**: Placido/Zeffiroso 授予。阻止离场，逐层消耗。
- **G2 投影**: 后台通行证生成。攻击投影 = 攻击 G2（可破幕/Regard-1）。
- **ma non troppo**: 仅开场运行，分配 2/2/2 声部。Chorus 补足缺口。

# 15. 致敬与灵感来源

**结界命名：`ish-bosheth`（伊施波设）**
来自《蔚蓝档案》空崎日奈（礼服）的 EX 技能名。日奈的 EX 是 6 费演奏型技能，释放后进入不可移动的集中射击模式，抽取三乐章旋律逐一奏响——这正是 G2 "舞台上只能演唱"和三段旋律递进的原型。

**三乐章旋律结构**
致敬日奈（礼服）的 EX 技能机制：第一乐章是铺垫、第二乐章是主力输出、第三乐章终幕倍率翻倍。G2 的序曲→第一音节→第二间章→第三间章继承了这一递进结构，但改为累计 ΔRegard 解锁而非固定轮次，以适应桌面游戏的节奏。

**安定値（Stability）**
反向借鉴了《蔚蓝档案》的"安定值"概念。在 BA 中，安定值决定伤害浮动范围；在 G2 中，安定値被改写为一个**带符号的伤害修正系数**——正=增伤、负=治疗——受累计 ΔRegard、目标总防御 HP、pivot（Before light 调整）和卡牌标记等多因素影响。这使旋律不再是固定输出，而是 G2 动态调控舞台压力的工具。

**24K钛合金狗牌**
名字致敬了一种特别耐咬的宠物身份牌——用在 Acc 限定牌上，取"咬住不放"的意象（Acc 是进攻方）。

**其他卡牌命名**
物料牌系统整体致敬同人展会/演唱会周边文化：前排票、小卡交换、聚光合影、应援连呼等命名都来自这类场景。后台通行证（Str 破幕牌）来自演出的后台文化。改签票（唯一阵营改签权）来自票务术语。
