## 一、游戏概述

### 1.1 目标

《起闯战争》是 2 至 6 人的回合制乱斗。玩家在五大公共建筑之间移动、发育、演出并争夺综合评分直到游戏结束，如只剩下最后一名存活的玩家等等（没错，不止这一种可能）。
最后产生两类胜者：

- **最后存活者**：活到最后的玩家；
- **综合评分第一**：谁把这一局打得最精彩。

两者可以是同一个人，也可以不是。
在大部分情况下，玩家HP归零而死亡时将进入往世层（AfterLife）以独特的方法继续参与游戏并积攒评分。
有两类不进入往世层的例外：绝对死亡 与 退场 

### 1.2 信息公开

本游戏有99%的信息公开，属于近完美信息博弈。一般情况下，玩家位置、HP、装备、护甲耐久、状态、先攻、SP、PP、案底与大多数专属资源均公开。需要特别强调的是，本游戏中隐身只影响别人能不能找到你、打不打得中你（没有对应探测、也没把你搜出来的人不能选你当目标，能打你的时候也更难命中），并不导致该玩家任一属性无法被观测到。
（才不是因为懒得给RL训练管线写信念呢！这个游戏在那个还是口口相传和想象力的年代就是这样设计的！）

### 1.3 玩家状态条

每名玩家至少显示：

| 项目 | 内容 |
|---|---|
| HP | 整数，一般上限为20；首轮完整数值见 §17 |
| 外层护甲 | 每件护甲的属性与耐久 |
| 信用点 | 唯一经济资源，一般仅在商店打工获得 |
| SP | 释放技能需要的资源，一般分为`0 / 1（可释放即演） / 2（可释放公演）`三个等级  |
| PP | 演出积分，最终得分的重要一项。不因为死亡而消失，不能交易或转移，只在少数地方能花掉（比如重掷先攻）。 |
| 装备与弹药 | 武器、护甲、道具、模块等 |
| 状态 | 灼烧、震荡、石化、屏障、爱愿、天赋标记等 |
| 天赋资源 | 追忆、魔力、火种、失熵、Cost、孤独值、色彩等，仅持有者显示 |

## 二、游戏准备与地图

### 2.1 开局

1. 每名玩家选择一个天赋，或全桌约定无天赋局。
需要注意的是，一局中允许混用**原初天赋(T(x))** 和 **神代天赋(G(x))**。这一设计是为了降低全桌的认知负担，不过也会出现“别人的能力：进化，倒流时间，将世界推向终末”而你的能力是“被打死了复活一次”这种雷霆情况。再多吐槽一句：神代天赋现在快批发免死了。

2. 游戏开始的第 1 轮，每名玩家出生在自己的**私人房间**，HP 满值，处于"未起床"状态。
*（在游戏的早期版本是一个玩家一个home。这对RL不太友好，而且地名映射经常出bug。你也可以理解成比赛主办方没钱了只能租一栋公寓给你们住了hhh，这年头一人一个单间也不少了）*

3. 第 1 轮的 T0阶段：执行**起床** 之后领取**入坑福利**：
默认为 弓 + 初始箭矢（固定）+ 小刀盾牌二选一。有些天赋在这里进行了hook，比如G0拿到的弓会被AR取代，而G7的水着开局会额外拿到物资等等。

4. 第 1 轮的 T1阶段：**必须 `move` 进入五大公共建筑之一**——商店 / 魔法所 / 医院 /军事基地 / 警察局。
*有点像跳伞。这可能是你在整份文档里看到的最接近大逃杀的元素。*

5. **关门之前再怀念一下你温暖的床吧**：本局无法再返回这个房间。
*必要的眷恋之后就踏上舞台吧。我们急着在十二点之前退房，不然得多收一天钱。*

### 2.2 五大公共建筑

地图由五个可进入地点组成，任意地点之间移动消耗 T1 主行动槽。
*截止到目前*没有相邻或者远近的概念。

| 地点 | 主要功能 |
|---|---|
| 商店 | 唯一可以靠打工获得信用点的地区、小刀、盾牌、磨刀石、陶瓷护甲、隐身衣、热成像仪、力量模块、修甲、箭矢补给 |
| 魔法所 | 法术（1 回合学 1 个）、魔法护盾、魔法弹幕、火矢、魔导模块 |
| 医院 | 紧急治疗、急救装置、无限模块、G7 专属药、终身一次三选一手术 |
| 军事基地 | AT 力场、电磁步枪、高斯步枪、雷达、隐形涂层、穿甲/冲击模块、钩索（直接购买，记案底） |
| 警察局 | 申请队长、举报、防暴编队驻地 |

### 2.3 地点摧毁

一般情况下地点是不会被常规效果破坏的。只有在叙事等级足够高，且明确表述相关效果时才能被摧毁。
例如G1.
地点的摧毁几乎是永久的，所有幸存单位被驱逐至其他公共建筑（按先攻降序 +
actor ID 分配）。最后一个仍可站立的公共建筑不能被摧毁。警察局被毁后防暴
编队立即停机，案件与通缉记录保留，暂停执法而不洗白。
目前只有 G5 献给 T6 的「律法」诗能重建被摧毁的警察局，其他被摧毁的地点没有办法重建。

## 三、回合结构：全局轮次循环（R）和玩家单个回合的结构（T）

### 3.1 全局轮次 R0–R4

每个全局轮次（下文说“第 N 轮”就是指第 N 个全局轮次）都按固定顺序走完 R0～R4 五个阶段：

```text
R0  世界时钟推进一次；天赋 on_round_start；往世层内玩家行动
R1  所有正常玩家判定先攻；愿意公演的合法 SP=2 玩家竞争 R3 首位
R2  队长就任、编队与案件状态推进（需要注意的是，齐射不在R2结算）
R3  轮初公演胜者先兑现（失效则递补）；其余标准槽按先攻依次执行
    T0：1 次免费小动作（整备）
    T1：1 次主行动
    T2：登记关注（→SP）；结算 StepFollowup，登记 ExtraTurn
    完整收尾后：合法公演插队 → 尚未开始的 ExtraTurn → 后续标准槽
R4  警务齐射 → 环境伤害 → 持续伤害与角色维护 → 回复 → 到期清理
```

需要注意的是，对于一个在本轮进入，有倒计时的状态（石化、无人机、繁育、救世主、固有结界等）
本轮 R4 不结算倒计时，从之后第一个R4 开始计时。除非来源明确要求。

同一批范围伤害先处理所有目标与濒死，再检查终局，避免因遍历先后提前宣布胜利。
终局成立就停止后续 tick；G1“胜利优先于繁育倒计时”的明文例外保留。
此外，实际全局轮次数和世界时钟是分开计数的。例如G2的世界时钟二倍速加速，不会让一个全局轮次内完整遍历两遍R0-R4。

### 3.2 T0：免费小动作（整备）

特定动作可以在T0阶段发动，每回合限 **1 次**，节省出 T1：

- 起床（仅首轮）
- 用急救装置、吃 G7 专属药
- 磨刀
- 装卸弓模块 / AR 遗物切换
- 换形态（G1 着装/卸甲 / G7 更衣 / G4 主动升格）
- `lock` 锁定目标：本回合 T1 攻击无视目标移动闪避，并获得命中/破甲加成
- 天赋明文归属 T0 的其他宣言
*在早期版本里，lock和find是占据单独行动的，现在lock变免费了，find直接删掉了——不然实在是太磨蹭了*
*免费说的不是不消耗资源啦！不消耗标准行动槽而已。*

G2 选择角色、G3 结界主目标选择属于必要回合设置，不占小动作；G7 宏内操作走宏的
费用和库存，宏外肾上腺素占 T0。例如 G7 本回合已经午休，就不能再在宏外扎针。

### 3.3 T1：主行动

每回合 1 次，四大类动词：

| 动词 | 说明 |
|---|---|
| `move <地点>` | 移动到任意其他公共建筑；主动离开交战可能触发借机攻击 |
| `attack <目标> <武器>` | 攻击同地点显形单位（近战）或跨地点（远程）；同地点显形无需先 find |
| `interact <项目>` | 购买、打工、手术、学法术、修甲、补给等地点功能 |
| `special <操作>` | 天赋专属、装备特殊操作、战术宏等明文操作 |

*早期版本里有个非常让人头疼的find，用于在两个处于统一地点的玩家之间建立允许近战的社交关系。
事实证明与其让大部分天赋提供绕过它的攻击方式，不如直接取消掉它算了*

`search`（原 find）只用于揪出同地点的**隐身**单位。
*AI coding的经典范例，我真不记得我设计过这个指令*

**先预检，后付费。** 没有合法目标、资源不足等在发动前拒绝，不收费，可重新选择。
合法发动后遭闪避或屏障拦截不退款；连发、战术宏逐段检查，已经生效的步骤不回滚。
免费装填/服药仍要有弹药/药物且未超容量；空操作不制造关注、资源或剧情事件。

### 3.4 T2：追击与额外行动

对一个玩家的行动回合，T2阶段可能获得以下两类行动：

**StepFollowup（单步战技追击）**：只能来自天赋效果，只能执行天赋效果允许的动词，
没有独立 T0，不能即演或公演，不递归生成下一个追击。

**ExtraTurn（完整额外行动）**：重新执行完整 T0→T1→T2，允许 SP≥1 时即演，
但禁止公演。共同边界：

- 每名玩家每个全局轮次至多 1 个；
- 当前回合完整收尾后插入；若此时有合法公演插队，先执行公演回合，再开始额外回合；
  不能储存，不能转移；
- ExtraTurn的T2阶段不能再插入其他ExtraTurn；
- 被控制消费后直接损失。


### 3.5 被其他玩家感知的不同状态

感知状态分三类：**暴露  / 隐匿（隐身）/ 被锁定**。
感知状态是带方向的，例如A和B都有隐身效果，但只有A有探测，B没有，那么两个人集中在同一地点，不经其他操作时
A的视角下B是暴露，而B的视角下A是隐匿。

### 3.6 控制裁决
本游戏有若干个可以施加给玩家或者非玩家单位的控制类状态：

| 状态 | 效果 | 备注 |
|---|---|---|
| `SHOCKED` 震荡 | 下一槽只能有限移动、非敌对交互或放弃；槽收尾后移除 | |
| `ACTION_SUPPRESSED` 压制 | 下一行动槽强制跳过 | |
| `PETRIFIED` 石化 | 可放弃保持、花 1 SP 以 50% 概率挣脱（同槽至多 2 次），或挨两次有效伤害被动解除 | T3独特效果 |
| 睡眠 | 该槽只能唤醒 | 这就是为什么这个游戏叫现在的名字。开局时所有人都在睡（§2.1 起床），目前没有效果能让人重新睡着 |
| 失神 | 封禁下个回合 T0 小动作并禁止隐身，可以与其他针对T1的控制效果叠加生效 | 我已经忘记是谁会施加这个效果了（其实是 G2 的演出「唱着无人问津的歌」） |
| `SUBMERGED` 沉沦 | NPC 停机 | 多少个版本了都是G2的专属效果 | 

普通控制共用一个控制位，优先级：压制 > 石化 > 震荡。
睡眠与自我怀疑是结构状态，不占控制位。弱控制不覆盖强控制，一个控制效果持续期间添加新的同名控制效果，则计时器被后添加的效果刷新而非叠加持续时间。
石化挣脱是槽开始的特殊处理，不占正常 T0；同槽最多两次、每次付 1 SP，成功后
正常行动。轮制状态按未来 R4 计时，槽制状态按来源消费槽；灼烧等明文层数效果
按自己的层数上限处理，不能用“同名刷新”偷偷取消其叠层。

擦伤同时属于“闪避成功”和“实际受伤”，不属于附带状态所要求的命中。

## 四、装备、信用点与地点经济

### 4.1 信用点

- **商店打工**是唯一可重复主动赚取信用点的地点交互行动，每次 +2 信用点；
*早期版本允许在医院打工，在 V2.0-GA 中该交互被移除*
- 白昼后击杀使死者背包、装备与剩余弹药掉在死亡地点，拾取消耗一个 interact；
- 礼盒等明文奖励仍可给信用点，不据此增加第二个打工入口；
- 普通修甲占 T1 并支付费用，不能通过免费切姿态修复。

### 4.2 武器

**弓**是标准跨地点武器，开局人人携带（G0 以 AR 替换）。基础伤害 4，初始箭矢 5 支，
箭矢上限 10，商店花 1 信用点补给一次 5 支。武器、模块与价格全表见 §17.2。

弓有两个模块槽：

| 模块 | 来源 | 作用 |
|---|---|---|
| 力量 | 商店 | 增加弓伤害 |
| 火矢 | 魔法所 | 改为魔法属性 + 灼烧 |
| 魔导 | 魔法所 | 增加命中 |
| 穿甲 | 军事基地 | 改为科技属性 + 降防御系数 |
| 冲击 | 军事基地 | 命中后击退；双装追加先攻惩罚 |
| 无限 | 医院 | 独占双槽，不消耗箭矢，只发普通箭 |

G0专属 AR 不能装普通弓模块，有专属遗物改装槽，见 §12.1。

### 4.3 外层护甲
*早期版本中有内层护甲的概念，现在已经被移除。*

外层护甲是你可以获得的，用来提高你对应属性防御的道具。
它在你收到对应属性伤害时提供伤害减免，并根据吸收的伤害扣除自己的耐久。
它有两个属性：属性防御和耐久。属性防御决定这一击由外甲减免的伤害，耐久支付这次减免；
一般情况下为每减免 1 点伤害消耗 1 点耐久。

例如无其他修正、无额外碎甲、耐久足够且保底不改变结果时，攻击 6 对属性防御 3：
HP 扣 3，护甲耐久扣 3。耐久归零后破碎，后续攻击不再取得该件防御。

需要注意的是，无论防御多高，打进本体的普通伤害必然大于等于原始值的25%（被屏障挡掉的部分除外，见 §5.2）；

## 五、伤害、防御结算顺序与死亡

### 5.1 防御结算顺序

V2.0-GA 统一了防御结算顺序：

```
攻击伤害 A
  → 第 1 层 Barrier（屏障）
      警察防暴盾墙 / G3 七重圆环·剑阵 / G7 架盾 / T4 元亨利贞
  → 第 2 层 Armor（属性减伤 + 耐久计费）
      盾牌 / 陶瓷护甲 / 魔法护盾 / AT 力场
  → 第 3 层 HP（生命与濒死）
```

一次攻击打到人身上，要依次过三道关：先撞屏障，再撞外甲，剩下多少才扣多少血。

第 1 层是**屏障**。屏障是临时的护盾值，来源很多：警察的盾墙、往世层的赐福，还有很多天赋都在这一层挂了自己的东西。它的规则很简单，挡多少扣多少：一记 6 点的攻击打在 4 点的屏障上，屏障扣到 0 碎掉，剩下的 2 点继续往下走。身上同时有好几层屏障时，依次往下扣。

需要注意的是，G3 的七重圆环和 G7 主动架起的盾有个特权：哪怕只剩 1 点耐久，也会把这一下完整挡住，然后才碎掉，一点都漏不到后面。比如架起的盾还剩 3 点耐久，挨了一记 6 点：盾碎了，人一滴血没掉，之后的攻击就没有这面盾可挡了。反过来，它们也没有“小伤免费”的说法，挨 1 点也要扣 1 点耐久。

另外，有些攻击写明了无视屏障，它们直接从第 2 层开始算。

第 2 层是**外甲**。每一下只用身上的一件普通外甲：它按属性挡掉一部分伤害，再为挡下的部分支付耐久，详见 §5.3。
*在 V2.0-exp 里，身上几件外甲的防御会加在一起，磨损再按各自的贡献比例分摊。GA 改成每一下只挑一件甲，减伤和记账都简单多了。*

第 3 层是**生命**。过完前两层还剩多少，就扣多少 HP，但普通伤害有保底（§5.2）。HP 被扣到 0 时进入濒死处理（§5.5）。

有三类伤害不走完整的三层：真伤跳过外甲和减伤（§5.4）；纯磨甲只磨外甲、不扣血（§5.3）；直接判死的效果不看伤害数字（§5.6）。

### 5.2 一次攻击掉多少血

一次普通攻击掉多少血，分三步算：

1. 先算**原始伤害 A**：武器或技能的基础伤害，乘上技能倍率，加上攻击方的加成（磨刀、力量模块等），中了虚弱再减 1，最后向上取整一次。比如用磨过的小刀砍人，基础伤害 4 加上磨刀的 1，A 就是 5。
2. 再过屏障：按 §5.1 扣掉屏障挡下的部分，剩下的才打到本体。
3. 最后是本体结算：先加上目标身上的易伤，再扣掉目标不耗甲的固定减伤，然后由一件外甲挡掉一部分（§5.3），最后检查保底。

打进本体的普通伤害有**保底**，至少是 A 的四分之一（向上取整）。A = 4 时至少 1 点，A = 10 时至少 3 点。甲再厚、减伤再多，也压不到保底以下。
*V2.0-exp 就有这条保底，当时手册里的说法是“几乎可确保不存在打不穿的龟壳”。*

需要注意的是，保底只管打进本体的那部分伤害，不会把屏障挡掉的补回来。A = 8 打在 7 点的普通屏障上，屏障碎掉，只剩 1 点打到本体，这一下就只扣 1 血，不会因为保底变成 2。屏障把整下都挡住时，本体一点不扣。另外，伤害被明文归零（A = 0）、被替身整个挡下、目标对这次伤害绝对免疫，这几种情况也不会硬塞一点保底伤害。

举个完整的例子：你用弓（伤害 4）射一个拿着盾牌的人，假设每一箭都命中。盾牌对普通攻击的防御是 2，耐久 6。每一箭 A = 4，盾牌挡 2 点、花 2 点耐久，对方扣 2 血，保底（1 点）用不上。连续三箭之后，盾牌耐久从 6 变成 4、2、0，碎掉；第四箭没有甲了，扣满 4 血。

目标身上有**易伤**时，受到的普通伤害 +1。天赋或状态给的固定减伤会在外甲之前先扣，外甲只为剩下的部分出力，不会替别的减伤重复付耐久（例子见 §5.3）。

普通的单体攻击要判定一次**命中**。命中率从 100% 起算：

| 情况 | 命中率 | 备注 |
|---|---|---|
| 目标本轮主动移动过 | −15% | 持续到目标自己的下一个标准行动开始，不叠加 |
| 目标处于隐匿 | −25% | 前提是你已经能选它当目标（§3.5） |
| 跨地点攻击，并且没有 lock 目标 | −15% | 同一地点没有这一项 |
| 本回合 lock 了目标 | +15% | 同时无视“目标移动过”和“跨地点没 lock”这两项惩罚，还让目标外甲的属性防御打七五折（向下取整） |
| 跨地点攻击，并且有一方在烟雾里 | −15% | 道具效果，见 §17 |
| 攻击者被闪光弹晃到 | −15% | 道具效果，见 §17 |

命中率最低 40%，最高 100%。范围攻击、持续伤害、环境伤害、纯磨甲和写明必中的效果不判定命中。

没命中不是打空，而是**擦伤**：只造成保底的那一点伤害，不挂这次攻击附带的状态（震荡、灼烧等），也不磨外甲。擦伤怎样参与其他规则，见 §3.6。
*V2.0-exp 的手册里管这个叫“被闪避 ≠ 落空”，GA 沿用。*

#### 精确结算（可以跳过）

```text
A    = max(0, ceil(基础伤害 × 技能倍率 + 攻击方加成 − 虚弱))
A余  = 屏障挡完还剩的伤害（没有屏障时 A余 = A；全部挡住则到此为止）
F    = min(A余, ceil(A × 25%))          保底，不超过屏障后的余量
B    = A余 + 易伤 − 不耗甲的固定减伤
C    = 选中的外甲这一下挡掉的量（§5.3），没有外甲时 C = 0
H    = max(B − C, F)                     最终扣血
擦伤：H = F，不磨甲，不挂附带状态
```

扣血以目标剩下的 HP 为上限。战果分只按实际扣掉的血算，溢出的伤害不计（§7.1）。

### 5.3 外甲怎么扣耐久

身上有好几件外甲时，每一下只用一件：自动挑“这一下实际能挡最多”的那件，其他的这一下不出力，也不扣耐久。比的是实际能挡多少，不是面板防御：一件防御 6、只剩 1 点耐久的甲，这一下最多挡 1 点，比不过一件防御 3、耐久充足的甲。挡得一样多时，依次选耗耐久少的、剩余耐久多的，最后按固定的装备编号。被选中的甲这一下碎了，其他甲也不会接着挡。

一般情况下，外甲每挡 1 点伤害扣 1 点耐久，也就是**单价**为 1。比如穿着陶瓷护甲（普通防御 3、耐久 10）挨小刀（伤害 4）：每一下挡 3 点、扣 1 血，耐久从 10 变成 7、4、1；第四下甲只剩 1 点耐久，只能挡 1 点，这一下扣 3 血，甲碎。

有些情况下单价会变成 2，叫**双倍磨损**：

- 属性克制：普通攻击打魔法护盾，魔法攻击打 AT 力场，科技攻击打盾牌或陶瓷护甲；
- 技能写明了双倍磨损，目前有 T1 的斩击、G0 无人机在场时的神秘属性射击和 G7 的最优弹药。

几个来源同时成立也只算双倍，不会变成四倍。双倍磨损时甲的耐久掉得快，同样的耐久能挡下的伤害也更少。

耐久不够时，甲只能挡“剩余耐久付得起”的那部分，挡不住的直接扣血，甲碎掉。挡不住就是挡不住，不会再额外追加一笔“破甲伤害”。

双倍单价下，剩 1 点耐久也还能付最后 1 点减免，付完就碎。比如剩 3 点耐久、这一下要挡 2 点：第一点付 2 耐久，第二点用剩下的 1 耐久付，甲碎。如果这一下只需要挡 1 点，就只扣 2 点耐久、剩下 1 点，不会提前碎。

下表的六个例子都假设没有其他增减伤：

| 原始伤害 A | 甲的防御 | 剩余耐久 | 单价 | 甲挡下 | 扣血 | 耐久消耗 |
|---:|---:|---:|---:|---:|---:|---|
| 4 | 3 | 10 | 1 | 3 | 1 | 3 |
| 4 | 3 | 1 | 1 | 1 | 3 | 1（碎） |
| 10 | 6 | 1 | 1 | 1 | 9 | 1（碎） |
| 4 | 3 | 4 | 2 | 2 | 2 | 4（碎） |
| 4 | 3 | 3 | 2 | 2 | 2 | 3（碎，用上了尾数） |
| 4 | 1 | 3 | 2 | 1 | 3 | 2（剩 1） |

多件甲的例子：攻击 8，身上两件甲的防御分别是 3 和 2，耐久都够。这时用防御 3 的那件，扣 5 血，它扣 3 点耐久，另一件不动。如果换成“防御 6、耐久 2”和“防御 1、耐久 10”两件，前者挡 2 点就碎了，扣 6 血；后者这一下不接手，耐久还是 10。

天赋或状态给的固定减伤先扣，外甲只为剩下的部分出力，最后再检查保底。比如攻击 8、对方有 4 点固定减伤、外甲防御 4、耐久充足：保底是 2，减伤后还剩 4，外甲只要再挡 2 点就到保底了，于是扣 2 血，甲只花 2 点耐久。如果固定减伤有 6 点，伤害已经压到保底，外甲这一下就不出力，也不扣耐久。

有些攻击写着“额外磨损 X 点耐久”，这叫**附加磨甲**，比如 G0 的全自动扫射。它在这一下算完之后，再从同一件甲上扣 X 点耐久。它不会让这一下多扣血，也不吃双倍磨损，扣不完的部分作废，不会转到别的甲上。例如攻击 6、甲的防御 3、耐久 4、附加磨甲 2：先正常挡 3 点，扣 3 血，耐久剩 1；再被附加磨甲扣掉最后 1 点，甲碎。这一下仍然只扣 3 血。就算这一下外甲没出力（比如伤害已经压到保底），附加磨甲也照样按上面的挑选顺序找一件甲来磨。擦伤不磨甲，附加磨甲也一样。

还有些效果只磨甲、不打人，叫**纯磨甲**，比如 T3 玉璋的震波。它只扣一件甲的耐久：施术者能指定就用指定的那件，否则磨当前耐久最高的那件，扣光为止，多出来的作废。它不扣血，也没有保底。目标没穿甲，磨甲这部分就什么也不发生，技能的其他效果照常。如果目标身上有能挡这种效果的屏障，就先磨屏障，这一次不再磨甲。

只有把耐久从正数打到 0，才算一次**破甲**。自己卸甲、换形态、把自己的甲弄碎都不算破甲；已经碎了的甲不会被重复算。主动打碎别人的普通外甲有三个好处：战果分 +1（§7.1）；按关注规则可能 +1 SP（§6.2）；拿 1 点 PP，但每人每轮最多拿一次（§7.3）。

#### 精确结算（可以跳过）

```text
对每件还有耐久、能挡这类伤害的普通外甲 i：
  E_i = floor(属性防御 × 穿甲系数)    穿甲系数：lock 0.75，穿甲模块 0.5 / 0.25；多个来源取最低，不连乘
  k_i = 单价                           一般为 1；有双倍磨损来源时为 2，多个来源取最高
  C_i = min(E_i, max(0, B − F), ceil(D_i / k_i))      这件甲这一下能挡多少（D_i 为剩余耐久）
选 C_i 最大的一件 j；并列时依次比：耐久消耗少、剩余耐久多、装备编号
H        = max(B − C_j, F)               B、F 见 §5.2
耐久消耗 W_j = min(D_j, k_j × C_j)     尾数只有真用到时才扣光
附加磨甲 = min(X, D_j − W_j)
```

### 5.4 真实伤害（真伤）

写明是**真实伤害**（简称真伤，程序里叫 `DIRECT_DAMAGE`）的伤害，跳过外甲、属性防御和普通减伤，闪避对它也没用：过完屏障还剩多少，就扣多少血。它仍然会被屏障、替身和绝对免疫挡住，写明无视屏障的除外。

需要注意的是，真伤不等于必死。被真伤打到 0 血，照样可以被免死和保险接住（§5.5），除非这次伤害同时写明了绝对死亡。

常见来源：G0 的十字炮火、终焉阶段每轮 R4 的环境伤害、G7 Terror 形态的攻击。

### 5.5 濒死：谁先接住你

HP 被打到 0 的那一刻先别急着宣布死亡，按下面的顺序找人接住：

1. 这一下带**绝对死亡**：直接死，谁也接不住，后面两步都跳过。绝对死亡只在这一下真的把你打到 0 时才生效，没打死就只是普通伤害。
2. 你自己的**免死**：G1 繁育、G4 救世主、G0 调整呼吸、G7 战斗续行、G2 黄昏后的首次融合。
3. T7 的**复活保险**：有人给你挂了保险时，由保险接住（§11.6）。

三步都没接住，才是真正的死亡（§5.6）。

需要注意的是：

- 一次致死只会用掉一个。G1 的繁育接住了，就不会顺手把 T7 的保险也用掉。
- 打死你的那一下溢出的伤害，不会追进新形态。但同一招的下一段（比如连发的下一枪）会照常打。
- 同一批范围伤害，会先把所有目标的濒死都处理完，再看谁赢（§3.1）。

### 5.6 死亡的三种结局

| | 普通死亡 | 绝对死亡 | 退场 |
|---|---|---|---|
| 怎么发生 | HP 归零，§5.5 里没人接住 | 带绝对死亡的伤害真正致死（G4 天裁、G7 Terror）；G1 繁育倒计时走完 | G0 调整呼吸结束时 HP 不到 6 而撤退；G2 炉心融解耗尽退场 |
| 免死和保险 | §5.5 都没接住才会走到这一步 | 跳过，接不住 | T7 保险不赔 |
| 算被击杀吗 | 有凶手时算 | 有凶手时算 | 不算，没有凶手 |
| 进往世层 | 进（第九章） | 不进 | 不进 |
| SP | 清零 | 清零 | 清零 |
| 战果分、剧情章 | 全部保留 | 全部保留 | 全部保留 |
| PP | 保留，在往世层还能继续挣和花 | 冻结 | 冻结 |
| 身上的东西 | 白昼开始后全部掉在原地 | 同左 | 同左 |

“掉在原地”指信用点、弹药、道具、模块、武器和外甲全部留在死亡地点，别人可以花一次 interact 捡走（§4.1）；白昼之前死的，东西不掉。三种结局在终局计分时都不打折（§7.2）。

### 5.7 有效伤害

很多效果的条件写着“造成有效伤害”。满足下面任意一条就算：

- 实际扣掉了至少 1 点 HP（擦伤扣了血也算）；
- 把一件外甲或一层屏障从有耐久打到 0。

不算的情况：被屏障、替身或免疫整个挡住，又没打碎任何东西；只磨了甲但没打碎；伤害被明文归零。

用到它的地方：关注与 SP（§6.2）、剧情章的条件（§7.4）、石化挨两次有效伤害后解除（§3.6）等。

## 六、SP 与演出

### 6.1 SP 是什么

SP 是释放技能需要的资源，分三档：

| SP | 能做什么 |
|---|---|
| 0 | 正常行动，不能演出 |
| 1 | 可以即演（花 1 SP） |
| 2 | 可以即演，也可以大即演或公演（花 2 SP） |

开局每人 1 SP，最多存 2 SP。SP 不能交易，不计入终分，也不能换成别的东西。死亡时 SP 清零。

SP 只管天赋演出，不管行动次数：SP 再多也不会多出一个回合，SP 是 0 也照样能正常行动。

### 6.2 怎样涨 SP：关注

在场上引人注目会得到**关注**，每次关注让 SP +1。下面这些情况会给关注：

| 发生了什么 | 谁拿关注 |
|---|---|
| 发动一次敌对行动（比如攻击） | 发动的人，以及每个目标；打空、被挡住也算 |
| 实际扣了血 | 扣血的人 |
| 外甲被打碎 | 打碎甲的人和被打碎甲的人 |
| 屏障被打碎 | 屏障的主人 |
| 天赋的非伤害效果真正生效（比如挂上保险、起卦成功，具体看各天赋小节） | 发动的人；有目标的话，目标也拿 |
| 犯罪（比如没用黑市通行证就在军基拿装备） | 犯罪的人 |

每人每轮靠关注最多实际涨 1 SP，到下一轮 R0 重新计算。SP 已经是 2 的时候，关注照样会发生，但不会涨到 3，也不占这一轮的额度：比如你这一轮第一次挨打时已经是 2 SP，后来把 SP 花掉了，这一轮再挨打还能涨 1。死去的玩家拿不到关注。

举个例子：这一轮开始时，你、乙、丙都是 0 SP。你攻击乙，你们俩各拿一次关注，都变成 1 SP。同一轮丙也攻击了乙：丙涨到 1；乙这一轮已经涨过了，还是 1。到了下一轮，乙再挨打就能涨到 2。

除了关注，还有几种办法直接加 SP：医院手术「演出！要开始了！」、往世层微光的「启示」，以及一些天赋和诗篇。它们不占关注的每轮额度，但 SP 一样最多 2。少数天赋自己伤到自己时不给关注，各天赋小节会写明。

### 6.3 抢公演位（夺台）

每轮只有**一个公演位**。谁先用掉，这一轮别人就不能公演了；下一轮重新开放，不能提前预约。
*M9 里公演要在 R0 排队报名，排第一的人失效了也不往后递补。GA 改成了现在这样，谁满足条件谁来抢。*

想公演，要同时满足这几条：

- SP 是 2；
- 手上有能用的公演技能；
- 自己这一轮的标准回合还没开始；
- 没有被压制或石化（被震荡时只能用不带攻击的移动或交互类公演）；
- 这一轮的公演位还空着。

公演花 2 SP，只能在自己标准回合的 T1 里用。

抢台的先后看**先攻**，先攻也决定这一轮大家的行动顺序。每轮 R1，每个活着的玩家掷一个 D6，再加上修正：重伤 −2，手术「你的攻击结束了，到我了，没意见吧？」+1，往世层微光的「启示」+2，以及天赋给的修正。点数高的先行动，同点按固定的玩家编号排。掷完不满意，可以花 1 PP 重掷一次，用新掷出的点数，不能反悔；重掷在抢台排序之前结算。

抢台有两个时机。第一个是**轮初**：

1. R1 掷完先攻后，满足条件、又想公演的人报名。
2. R2 照常结算。
3. R3 一开始，按先攻从高到低看报名的人。第一个仍然满足条件的人，把自己这一轮的标准回合提到 R3 最前面，在这个回合的 T1 公演。
4. 排在前面的人如果已经不满足条件了，就往后递补给下一个报名的人。没轮上的人不扣 SP，也不丢回合，按原来的顺序正常行动。
5. 报名的人都不行的话，其他满足条件的人这时也可以抢。

第二个是**轮中**：回合中途被推到 2 SP 的人也可以抢。每当一个回合完整结束，就看一次：自己这一轮的标准回合还没开始、又满足条件的人可以抢；好几个人想抢，按先攻。抢到的人马上开始自己这一轮的标准回合，在 T1 公演。

插队有几条规矩：

- 不能切开别人的回合。当前回合的攻击、同一个主行动里的连发和宏、濒死处理、T2 的追击都结算完，才轮到插队的人。
- 公演插队排在还没开始的额外回合前面；已经开始的额外回合要走完才让位。
- 抢台只是把自己这一轮的标准回合提前用掉，原来的位置不再行动。这一轮已经行动过的人不能靠抢台再动一次，只能等下一轮。

在自己的标准回合里，如果 T0 之后到了 2 SP（比如在 T0 用手术「演出！要开始了！」换了 1 SP），而公演位还空着，就可以直接在这个 T1 公演。这不算插队，也不会多出一个回合。

例子一（轮初）：甲、乙、丙这一轮的先攻是 5、4、2。R1 时甲和丙都是 2 SP，都报了名。R2 结算完，R3 开始：甲排在前面而且还满足条件，于是甲先行动，在 T1 公演，这一轮的公演位就用掉了。之后乙、丙按先攻行动。丙没抢到，2 SP 留着，下一轮再争。

例子二（轮中）：下一轮谁都没报名，先攻顺序是丙、甲、乙，乙有 1 SP。丙在 T1 攻击了乙，乙拿到关注，变成 2 SP。丙的回合结束后，乙申请抢台，于是乙的标准回合提到甲前面，在 T1 公演；然后甲行动。乙原来排在最后的那个位置就没有了。

#### 精确结算（可以跳过）

```text
R3 开始时，以及每个回合完整结束后，按下面的顺序决定下一个行动的人：
1. 公演位还空着：按先攻找第一个“标准回合没开始、满足公演条件、想公演”的人
   （R3 开始时先看 R1 报了名的人，再看其他人）→ 开始他的标准回合，T1 公演
2. 没人抢：有等着开始的额外回合 → 按先攻找最前的一个，开始这个额外回合
3. 都没有：按先攻找下一个还没开始标准回合的人
4. 谁都没有了：进入 R4
```

### 6.4 三种演出

| 演出 | 花多少 SP | 在回合的哪一步 | 占公演位吗 |
|---|---|---|---|
| 即演 | 1 | 多数用 T1；少数准备型的在 T0 发动，看各天赋 | 不占 |
| 大即演 | 2 | 看各天赋 | 不占 |
| 公演 | 2 | 只能是自己标准回合的 T1 | 占，每轮只有一个 |

大即演是 2 SP 的强化即演。它不占公演位，所以也不能用来插队；强度不比公演低，区别只在入口。目前只有 G2 和 G5 有大即演。

即演和大即演都不会多给你一个主行动：用 T1 发动的话，这个回合就不能再普通攻击了。

演出前一样要先预检：没有合法目标、SP 不够，就不能发动，也不扣 SP；发动之后被闪避或被挡住，SP 不退（§3.3）。

### 6.5 什么时候不能演出

- 额外回合里可以即演和大即演，不能公演。
- 单步追击和受限反应都不能演出，它们也没有自己的 T0。
- 被控制时能做什么见 §3.6。这一回合没有 T0（比如中了失神）的话，T0 的准备型即演也就用不了。
- 天赋写明“用完”“失效”的，只是那一项能力。SP 照常涨，其他演出照常用，除非天赋另有写明。

### 6.6 一次行动不重复领奖

你的一次 T0 动作或一次 T1 主行动，连同它里面的所有步骤（连发的每一段、宏里的每一枪、范围攻击的每个目标、附带的余波），算作一个**根行动**。

各种奖励的额度不一样：

| 奖励 | 额度 |
|---|---|
| 关注（SP） | 每人每轮最多实际 +1（§6.2） |
| 破甲 PP | 每人每轮最多一次（§5.3） |
| 击杀 PP | 不限，每杀一个都拿（§7.3） |
| 天赋的专属资源（比如追忆、笑点） | 多数按根行动限次，具体写在各天赋小节 |

按根行动限次的奖励，同一个根行动里只领一次，不会因为打了好几段、打中好几个人就领好几份。

需要注意的是，这些额度只限制奖励，不限制战果。多段、多目标造成的伤害、破甲和击杀，仍然一笔一笔记进战果分（§7.1）。

没有根行动的系统效果，比如 R4 的灼烧和终焉伤害，同一批算作一个根行动。

## 七、计分

### 7.1 终分怎么算

游戏结束时，每个人的终分这样算：

```text
终分   = 战果分 + 高光分 + 终幕王冠
战果分 = 击杀数 × 6 + 对其他玩家造成的实际伤害总量 ÷ 4（向下取整）+ 打碎别人普通外甲的件数 × 1
高光分 = 完成的剧情章数 × 4 + 终局时手里剩下的 PP
终幕王冠 = 6，条件见下
```

几点说明：

- 只算对其他玩家做的事。打警察、无人机这些非玩家单位，或者打自己，都不进战果分。
- 伤害只算实际扣掉的血，溢出的不算（§5.2）。伤害是整局累加之后再除以 4，不是每一下单独取整。
- 打碎一件甲，战果分 +1。破甲还可能带来 PP 和关注（§5.3），它们分开算；破甲也不会再折成一笔伤害。
- 击杀和伤害一般记在动手的人头上。少数天赋会把战果记给别人，看各天赋小节。
- **终幕王冠**只发给唯一的最后存活者，而且他至少有 1 次击杀，或者至少完成了 2 章剧情。0 击杀又不到 2 章的幸存者拿不到王冠。几个人同时活着结束（比如 40 轮兜底）或者同时全灭，都没有王冠。

举个例子：你是最后存活者，整局击杀 2 人，对别人造成了 23 点实际伤害，打碎了 2 件甲，完成 2 章剧情，手里剩 3 PP。

```text
战果分 = 2 × 6 + 23 ÷ 4（向下取整为 5）+ 2 × 1 = 19
高光分 = 2 × 4 + 3 = 11
终幕王冠 = 6（你有击杀）
终分   = 19 + 11 + 6 = 36
```

### 7.2 死后不打折

活着本身不加分，死了也不扣分：生前拿到的战果分、剧情章和 PP，死后照样算。
*早期版本的终分有乘数：活着的人乘 1.5，死了的人乘 0.5，天赋还有各自的槽位乘数。GA 把这些乘数全删了，免得大家靠躲着不打来赢分。*

三种死法的区别见 §5.6：普通死者在往世层还能继续挣 PP、花 PP；绝对死亡和退场的人，PP 停在死的那一刻。

### 7.3 PP 怎么挣，怎么花

PP 是演出积分，终局时手里剩多少，终分里就加多少。

| 怎么挣 | 多少 | 限制 |
|---|---|---|
| 击杀其他玩家 | +2 | 不限 |
| 完成一章剧情 | +1 | 每章一次 |
| 打碎别人的普通外甲 | +1 | 每人每轮最多一次，这一轮碎几件都只拿一次；战果分里的破甲照常一件一件算 |
| 死后在往世层押中 | 分红 | 见 §9.2 |

同一个行动同时满足好几项，可以分别拿。PP 不会自己涨，也不会自己掉，没有上限；挨打、公演本身、帮别人、空操作都不给 PP。绝对死亡和退场的人 PP 冻结，之后既不挣也不花。

| 怎么花 | 多少 | 限制 |
|---|---|---|
| R1 重掷先攻 | 1 | 每人每轮最多一次（§6.3） |
| 往世层的微光 | 2 | 死者自己花，或者活着的人替死者付（§9.3） |

完成的剧情章永远算数，但 PP 只看终局时实际剩多少：完成第三章时有 8 PP，后来花了 3，终局这一项算 5，不算 8。

### 7.4 剧情章

每个天赋都有三章剧情。完成一章，终分 +4，同时拿 1 PP。

- 每章只算一次。一个行动同时满足好几章的条件，可以连着解锁。
- 预检失败或者没有效果的空操作不算；条件里说的“有效”按 §5.7 判断。
- 完成的章节永久保留，死了也不丢。

| 天赋 | 第一章 | 第二章 | 第三章 |
|---|---|---|---|
| T1 | 斩击造成有效伤害 | 斩击破甲 | 公演穿屏障伤到本体，或斩击击杀 |
| T2 | 隐匿攻击造成有效伤害 | 成功暗影步 | 两个不同轮次完成演出有效攻击 |
| T3 | 玉璋实际承担攻击 | 天星成功石化 | 对自己石化的目标完成破甲或击杀 |
| T4 | 完成一次有效起卦 | 累计三种卦象 | 公演生效，且累计四种卦象 |
| T6 | 合法热线或个人有效攻击 | 整备编队或个人破甲 | 完成一次执法击杀或个人击杀 |
| T7 | 挂上保险 | 祝祷产生实际治疗或净化 | 保险兑现 |
| G0 | 实际挂载两种遗物 | 无人机协同有效射击 | 四遗物均有挂载/过载记录，且释放十字炮火 |
| G1 | 进入次级燃烧 | 完全燃烧中有效攻击 | 完成燃烧窗口并存活，或繁育中获救/胜出 |
| G2 | 首次演出生效 | 累计六枚键位 | 进入任一终局 |
| G3 | 持续投影在实战生效 | 结界内完成有效连发 | 幻想崩坏造成有效伤害 |
| G4 | 夺火斩有效命中 | 进入救世主 | 焚诏实际结算反击或天裁伤害 |
| G5 | 讲故事生效 | 第二阶段献诗生效 | 升格，或三个不同轮次有效献诗 |
| G6 | 实际取得笑点 | 当身或移花接木成功 | 公演礼盒累计结算三次，可跨公演 |
| G7 | 完成一次融合 | 双融合并执行战术宏 | 全弹倾泻有效命中，且曾主动架盾承伤 |

### 7.5 游戏怎么结束，谁赢

出现下面任何一种情况，游戏结束：

- 只剩一名玩家活着；
- 所有玩家在同一批伤害里同时倒下；
- 第 40 轮的 R4 结算完，还有好几个人活着。这是防止对局失控的兜底，按当时的分数结算，正常对局走不到这一步；
- 少数天赋写明的结局，看各天赋小节。

同一批范围伤害会先把所有人的濒死都处理完，再判断游戏是否结束（§3.1）。

结束后公布两类赢家（§1.1）：

- **最后存活者**：结束时唯一活着的人。同时全灭，或者兜底结束时还有好几个人活着，就没有最后存活者。
- **综合评分第一**：终分最高的人。同分就并列，不按生死分高下。

## 八、警察

警察是场上的公共执法力量，不属于任何玩家。警察局里驻扎着一支 3 人的**防暴编队**，每名特警 HP 6，没有外甲。特警不是玩家：没有自己的回合，打他们不算犯罪，也不进战果分。和警察关系最密切的天赋是 T6（§11.5）。
*早期版本里警察是 3 个各自寻路、各自行动的 NPC，报案还要凑齐 4 类证据。GA 把他们合成了一支跟着队长走的编队。*

### 8.1 案底与通缉

下面两种事会让你留下**案底**：

- 对其他玩家造成实际扣血（少数天赋有免罪的效果，看各天赋小节）；
- 在军事基地拿装备而没有用黑市通行证（§4.5）。

每一桩案子都会记下当时的目击者，也就是和受害者在同一地点、还活着的玩家（军基的案子记拿装备时在场的人）。之后才走过来的人不算目击者。案底是公开的，而且永远不会消失。

有案底才能被挂上**通缉**。受害者或者目击者可以去警察局，花自己的 T1 举报，把犯人挂上通缉，但不能举报自己。少数天赋可以不去警察局、直接远程挂通缉，看各天赋小节。通缉名单按挂上的先后排序，挂上之后不会自己撤销。

被通缉的人会成为编队的合法攻击目标（§8.2），也不能申请当队长（§8.3）。

举个例子：你在商店砍了乙一刀，乙扣了 4 血，当时商店里还有丙。这桩案子的目击者是你、乙、丙。之后乙或者丙去警察局用一个 T1 举报你，你就被挂上了通缉。

### 8.2 编队怎么打人

编队每轮只能攻击**一次**。下面三种攻击共用这一次，谁先用掉就算谁的：

1. 队长在机动姿态下用普通攻击打一个被通缉的人，编队跟着合击同一个人；
2. 队长花自己的 T1 下令攻击，编队立刻开火；
3. 每轮 R4 的警务阶段，编队自动攻击通缉名单里第一个能打的人。

能打的目标要同时满足：被通缉、活着、没有隐身、没被隔离在编队进不去的空间里（比如某些天赋的结界）。不看地点，跨建筑也能打。

编队一次攻击的伤害是 **2 + 存活特警数**，满编是 5，普通属性。T6 可以给编队升级，升级后变成 3 + 存活特警数（满编 6），科技属性。这一击按普通攻击结算：要判定命中（没命中就是擦伤），也会被屏障和外甲挡（第五章）。只有特警全部被控制住时，这一次才打不出来。

编队打出的伤害和击杀算队长的战果；没有队长时，谁的战果都不算。编队攻击本身不算犯罪。

需要注意的是，队长下令攻击一个没被通缉的人，编队不会开火：这一下直接折损 1 名特警，姿态也被打回机动，队长这个回合的 T1 也就白用了。队长自己用武器打人不受这条限制，但会按 §8.1 留下案底。

举个例子：满编的编队在 R4 自动攻击通缉犯乙。乙没有外甲也没有屏障，这一下命中的话扣 5 血；如果之前已经有 1 名特警阵亡，就是 4 点。这一轮之后队长就算再下令，编队也不会打第二次。

### 8.3 当队长

在警察局用 T1 可以申请当队长。条件是：警察正常运作（§8.5），现在没有队长，你没有被通缉。到下一轮的 R2，在所有申请的人里，按先攻排最前、还活着、没被通缉的那个人就任；其他人的申请作废，想当的话得重新申请。

就任之后，编队跟着队长走：队长移动、被钩索拉走、被赶出被摧毁的建筑，编队都跟到同一个地点。队长死了，队长的位置就空出来，编队回到警察局，姿态恢复成机动。

队长可以在 T0 切换编队的姿态，这会用掉这个回合的 T0：

- **机动**（默认）：队长正常移动；队长用普通攻击打通缉犯时，编队跟着合击。
- **盾墙**：队长身上多出一层盾墙屏障。切到盾墙的这一轮，队长不能 move。盾墙姿态下队长打人时编队不跟着合击，但下令攻击和 R4 的自动攻击照常。

盾墙的耐久来自编队的**盾墙池**：每名存活特警 4 点，满编 12（T6 升级后每人 6 点）。盾墙只挡单体攻击，不挡范围攻击；写明从背后打的攻击也能绕过它。盾墙池是真实的耐久：挡多少扣多少，来回切换姿态不会回满，池子空了就切不成盾墙。任何人都可以在警察局花 T1、付 2 信用点修盾墙，盾墙池 +4，最多回到上限。

### 8.4 怎么对付编队

- 范围攻击会同时打到同一地点的特警，盾墙也挡不住范围攻击。
- 让队长中震荡、被闪光弹晃到，或者用钩索把他拉走，盾墙姿态马上解除，回到机动。
- 直接打特警：近战要在同一地点，弓和枪可以跨地点打。
- 队长一死，编队就回警察局，没人指挥。

### 8.5 警察停摆

下面任何一种情况，警察都会暂停执法：编队不攻击，盾墙失效，也不能申请当队长或者修盾墙。

- 警察局被摧毁（§2.3）；
- 特警全部阵亡，或者全部沉沦；
- 天赋的全局效果让警察停机：G2 的雨幕、G5 的时间倒流、G7 的失控形态（§10.3）。

停摆期间，案底照常记录，也照常可以举报、挂通缉，不会因为停摆被洗白；恢复以后照常执法。几种停摆原因互相独立，解除其中一种不会连带解除别的。阵亡的特警不会自己回来，补员靠 T6。

## 九、往世层

### 9.1 死后能做什么

普通死亡的玩家会进入**往世层**（绝对死亡和退场的不进，§5.6）。在往世层里没有回合，不能移动也不能攻击，但每轮 R0 可以做三件事：押注、微光、Encore。它们都不占任何人的回合。

死者手里的 PP 照常计入终分，在往世层挣到的也算（§7.2）。
*早期版本的往世层有 26 种不同的援助要背，GA 只留了这三个按钮。*

### 9.2 押注

每轮 R0，死者可以押一名活着的玩家，也可以换成押别人。押注不花钱，只对押下之后发生的事有效，不能等结果出来再改。

被你押的人做到下面这些事，就从固定的奖池里给押中的人分 PP：

| 被押的人做到 | 奖池 |
|---|---|
| 击杀一名其他玩家 | 2 PP |
| 打碎别人的一件普通外甲 | 1 PP（同一个被押的人每轮最多一次） |
| 游戏结束时拿到终幕王冠 | 2 PP |

好几名死者押中同一个人，就均分这个奖池；分不尽的余数按死者编号轮流每人多给 1。奖池大小是固定的，押的人再多也不会变大。没人押中，这个奖池就不发。

举个例子：甲、乙两名死者都押了丙，丙杀了一个人：奖池 2 PP，甲、乙各拿 1。要是甲、乙、丁三名死者都押了丙，这 2 PP 分三份：每人先分到 0，余下的 2 按编号轮流给甲、乙各 1；下一次再有余数时，从丁开始接着轮。

被押的人死了，押注就落空了，下一轮 R0 记得换人。

### 9.3 微光

每轮 R0，每名死者可以对一名活着的玩家放一次**微光**，花 2 PP，三选一：

| 微光 | 效果 |
|---|---|
| 赐福 | 给目标一层 3 点的临时屏障，持续到下一轮的 R4；或者给目标回 2 HP（目标没满血时才能选） |
| 启示 | 目标这一轮先攻 +2，并且 SP +1（最多 2） |
| 凝视 | 目标立刻现形（隐身失效），而且下一次被普通伤害打到本体时多受 2 点伤害（和易伤一样算在外甲之前；如果那一下是擦伤，这 2 点就浪费了） |

这 2 PP 可以由死者自己付，也可以由目标付：活着的玩家可以向死者**求援**，由死者放微光、目标付钱。目标拒绝的话不付钱，也不生效。

限制：每名死者每轮最多放一次；同一名活着的玩家每轮最多接受一次微光，几名死者不能给同一个人叠加。付钱的人和受益的人都是公开的。

### 9.4 Encore

每名死者整局有一次 **Encore**：把自己生前天赋的一个简化效果借给一名活着的玩家。原初天赋的死者借出自己 1 SP 即演的简化版；神代天赋的死者从 7 枚简化标记里选一枚借出（§13.3）。借出去的只是这一个效果，不是整套角色能力。

借到的人用的时候，照样要有合法目标和足够的资源。借来的标记一直等到触发才用掉，到游戏结束还没触发就作废。个别天赋借出的效果有限制，看各天赋小节。

## 十、世界时钟

### 10.1 四个阶段

世界时钟决定对局进行到了哪个阶段。阶段按**时钟刻度**划分，不按实际轮数（§10.2）：

| 阶段 | 时钟刻度 | 有什么变化 |
|---|---|---|
| 黎明 | 1～4 | 开局发育期 |
| 白昼 | 5～10 | 死者身上的东西开始掉在原地（§5.6） |
| 黄昏 | 11～15 | 一些神代天赋的终局能力从这里开始能用（看各天赋小节） |
| 终焉 | 16 起 | 每轮 R4 所有活着的玩家受到环境伤害（§10.2） |

*早期版本一局常常要打 40 轮左右，GA 用世界时钟把节奏往 15～20 轮压。*

### 10.2 时钟怎么走

第 1 轮的 R0 时钟是 1，之后每轮 R0 走一格。只有 R0 会推进时钟。

时钟刻度和实际轮数是分开数的。平时两者一样；G2 让时钟加速之后，时钟每次走两格；G5 的时间倒流期间，时钟不走。实际轮数永远每轮 +1。时钟一次走两格也只是刻度变了，不会多出一轮行动，也不会多一次警察攻击、回血或状态计时。

到了终焉，每轮 R4 的环境阶段，所有活着的玩家受到一次真伤，数值是**当前刻度 − 15**：刻度 16 是 1 点，20 是 5 点，之后每格继续 +1。时钟被加速过的话，这个伤害翻倍；时间倒流期间没有终焉伤害。这一下不判定命中，外甲挡不住，屏障能挡（§5.4）。它没有凶手，被它打死不算任何人的击杀；被打到的人照常拿关注（§6.2）。

举个例子：刻度 18 的那一轮，R4 时每个活着的玩家受到 3 点真伤；如果时钟已经被加速过，就是 6 点。

第 40 轮结束时还有好几个人活着的话，按当时的分数结束游戏，见 §7.5。

### 10.3 好几个改变世界的效果同时生效

有几个天赋能改变整个世界的规则：G1 能摧毁地点；G2 的终局能让时钟加速，或者让雨幕笼罩全场；G5 能让时间倒流；G7 进入失控形态后，警察会停机。它们同时生效时这样处理：

- G5 的时间倒流期间，时钟不走（就算 G2 已经让时钟加速了也一样），终焉伤害暂停，警察和其他 NPC 停机。普通状态和各天赋自己的倒计时照常走。
- 倒流结束后，如果 G2 之前让时钟加速过，加速继续生效，就算 G2 已经死了或者被救回来了也一样。
- G2 的雨幕期间，警察和其他 NPC 沉沦停机；雨幕结束后解除，但这期间死掉的 NPC 不会复活。
- 警察停机的几个原因互相独立（§8.5）。比如 T6 的诗把警察局重建了，只要雨幕或者倒流还在，警察照样停机。
- 地点被摧毁时，里面的玩家按 §2.3 分到其他还立着的建筑，天赋召出来的单位和 NPC 也一起被赶出去。
- 往世层在倒流期间照常每轮 R0 行动，死者不受倒流的限制。

## 十一、原初天赋 T1–T4、T6–T7

原初天赋一共六个。原来的 T5 已经退役，它的位置给了神代的 G0。
*早期版本的 T5 是一个打连击的天赋，后来还改成过音游谱面，GA 没有保留它。*

下面每个天赋按同样的顺序写：一句话说明、被动、怎么用、要注意的地方、三章剧情。献给它的诗篇统一写在第十三章。表里“即演”“公演”的规则见第六章。

### 11.1 T1「一刀缭断」

一记很不讲道理的近战斩击。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 斩击（即演） | T1 | 1 SP | 用拳头或小刀砍同一地点的一个目标，伤害是武器基础伤害的 2 倍，磨甲按双倍算 |
| 斩击（公演） | T1 | 2 SP，占公演位 | 同上，而且这一刀无视目标的屏障 |

要注意的地方：

- 只有武器的基础伤害翻倍，磨刀之类的加成在翻倍之后再加：小刀砍是 8，磨过的小刀砍是 4 × 2 + 1 = 9，拳头砍是 4。
- 双倍磨损按 §5.3 计算；和属性克制同时成立也还是双倍，不会更多。
- 公演的这一刀无视屏障，直接从外甲开始算（§5.1）。
- 斩击照常判定命中，照常有保底；把人打死照常走濒死处理（§5.5）。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 斩击造成有效伤害 | 斩击打碎外甲 | 公演斩击在目标有屏障时照样伤到本体，或者斩击击杀 |

献给你的诗：「游侠」（§13.2）。

### 11.2 T2「剪刀手传奇一突牢玩家」

擅长隐身偷袭、贴身追击的刺客。

被动：

- 打伤玩家但没打死，不算犯罪；打死照样立案（§8.1）。
- 还没杀过人的时候，攻击不会让自己现形。完成第一次击杀的那一刻立刻现形，之后攻击也会和别人一样现形。
- 你的攻击每有 2 次让对方的外甲扣了耐久，就给自己身上同一种、还没碎、也没满的外甲修 1 点耐久；身上没有同一种甲就没有效果。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 偷袭（即演） | T1 | 1 SP | 用自己的武器攻击同一地点的一个目标，伤害 +1 |
| 追击（公演） | T1 | 2 SP，占公演位 | 先移动到目标所在的地点再攻击，伤害 +1；可以打别的地点的目标 |

**暗影步**是一个反应：和你在同一地点的人主动 move 离开时，你可以花 1 SP 跟过去，并且自动 lock 对方，你下一次攻击他时享受 lock 的全部加成（§5.2）。整局最多用 2 次。它不占你的回合，也不给你额外的 T0 或 T2。

要注意的地方：

- 偷袭和追击都要能看见目标，打隐身的人得先有探测或者先把他找出来（§3.5）。
- 追击时的那次移动和攻击是同一个行动，不算一次 move，所以拿不到移动闪避（§5.2）。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 隐身时攻击造成有效伤害 | 成功用出一次暗影步 | 在两个不同的轮次，各用演出打出一次有效伤害 |

献给你的诗：「地火」（§13.2）。

### 11.3 T3「天星」

一边给自己架起岩障，一边召来天星把整个地点的人石化。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 玉璋（即演） | T0 | 1 SP | 给自己一层 3 点的屏障，持续到下下轮的 R4；同时对同一地点随机一个敌人造成 1 点纯磨甲（§5.3） |
| 天星（公演） | T1 | 2 SP，占公演位 | 对同一地点的所有其他单位（包括隐身的人和特警）造成 4 点无属性伤害，外甲的属性防御当作 0，被打到的人石化 |

要注意的地方：

- 玉璋是普通的有限屏障，挡多少扣多少，没有整击的特权（§5.1）。再放一次玉璋会把屏障刷新回 3 点，不叠加。
- 震波随机挑的敌人可能是特警。挑中的人没穿甲，磨甲这部分就没有效果，玉璋的屏障照样有。
- 天星不判定命中。外甲的属性防御当作 0，所以外甲既不帮对方减伤，也不会被磨；屏障和普通减伤照常有效，保底照常算。
- 石化持续到下一轮的 R4。没挣脱的话会一直跳过回合；怎么挣脱、怎么被打醒见 §3.6。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 玉璋的屏障实际挡下伤害 | 天星成功石化一个人 | 对被自己石化的目标打碎外甲或者击杀 |

献给你的诗：「群星」（§13.2）。

### 11.4 T4「六爻」

靠猜拳决定结果的天赋。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 起卦（即演） | T1 | 1 SP | 和一名其他玩家猜拳，不限地点 |
| 起卦（公演） | T1 | 2 SP，占公演位 | 最多和两名其他玩家分别猜拳；双人局只选唯一的对手也可以 |

猜拳时，你和对方各自秘密出石头、剪刀或者布，两边都出完才同时公开。两人出的组合决定卦象，不分谁出的哪个：

| 组合 | 卦象 | 效果 |
|---|---|---|
| 剪刀 + 剪刀 | 潜龙勿用 | 对对方造成 6 点伤害，外甲的属性防御当作 0；这一下要判定命中 |
| 石头 + 石头 | 飞龙在天 | 你挑对方一件普通外甲，复制一件给自己，耐久和上限都和原件一样；对方的甲不受影响。对方没有外甲就没有效果 |
| 布 + 布 | 元亨利贞 | 你免疫所有伤害和状态，一直到下一轮 R0；每轮最多生效一次；挡不住直接判死的效果 |
| 剪刀 + 石头 | 亢龙有悔 | 你挑对方一件武器禁用到下一轮的 R4，拳头不能禁；对方没有能禁的武器，就改为让他震荡 |
| 剪刀 + 布 | 或跃在渊 | 你得到一个额外回合（§3.4）；每轮最多一个，额外回合里起卦不会再给 |
| 石头 + 布 | 群龙无首 | 你进入隐身，持续到下下轮的 R4，所有人对你的 lock 失效；对方被随机传送到另一个还立着的公共建筑 |

要注意的地方：

- 没有诗篇帮忙的时候，不能自己挑结果。
- 公演时每个目标分别猜拳，结果各算各的。
- 卦象真正起了作用才算一次有效起卦。比如“飞龙在天”遇上没穿甲的人，“元亨利贞”这一轮已经生效过，都不算。
- Encore 借出六爻时，不借能给额外回合的“或跃在渊”：借到的人抽到它，就重新猜。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 完成一次有效起卦 | 累计出过三种不同的卦象 | 用公演起过卦，并且累计出过四种卦象 |

献给你的诗：「阴阳」（§13.2）。

### 11.5 T6「朝阳好市民」

和警察站在一边的普通市民。自己没有伤害技能，靠警察编队和普通武器作战。警察的规则见第八章。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 市民热线 | T0 | 不花 SP，也不花钱 | 给一名有案底、还没被通缉、还活着的人挂上通缉，不用去警察局；警察停摆时也能挂 |
| 整备（即演） | T1 | 1 SP | 给编队升级一项（见下） |
| 整备（公演） | T1 | 2 SP，占公演位 | 同上；如果现在没有队长，还可以把编队叫到你所在的地点，马上开一次火，或者立起盾墙保护你 |

整备能升的三项：

- 攻击升级：编队攻击改为 3 + 存活特警数（满编 6），科技属性；
- 盾墙升级：盾墙池每名特警多 2 点，当前值也一起加；
- 补员：复活 1 名阵亡的特警，HP 6。

要注意的地方：

- 攻击和盾墙各只能升一次，满了就不能再选。
- 警察局被摧毁或者警察停摆时（§8.5），整备用不了；补员只要警察局还在、警察没停机就能用，特警全灭也能补。
- 公演叫来的编队开火，算编队这一轮唯一的那次攻击（§8.2），战果记在你头上；立起盾墙的那一轮你不能 move。
- 整备只能强化场上真实存在的那一支编队，不会多出第二支。
- 你没有自己的伤害演出，个人输出靠普通武器。警察停摆的时候，三章也可以全靠自己打（见下表）。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 热线成功挂上通缉，或者自己打出有效伤害 | 整备成功升级一项，或者自己打碎外甲 | 一次记在你头上的击杀：自己杀的，或者你带领、叫来的编队杀的 |

献给你的诗：「律法」（§13.2）。

### 11.6 T7「死者苏生」

给别人买复活保险的人。

| 怎么用 | 什么时候 | 花费 | 效果 |
|---|---|---|---|
| 挂保险（即演） | T1 | 1 SP | 给一名活着的玩家挂上复活保险，可以是你自己 |
| 挂保险（公演） | T1 | 2 SP，占公演位 | 同上 |
| 祝祷（即演） | T1 | 1 SP | 场上已经挂着保险、或者保险已经用过时才能用：给一名活着的玩家回 3 HP，清掉他身上的普通状态和能清的灼烧 |

保险怎么赔：

- 全场同时只能有一份保险，这一份用掉之前不能再挂新的。你死了，已经挂上的保险照样有效。
- 被保险的人普通死亡时，先看他自己有没有免死（§5.5）；没有的话，由保险接住：
  - 原地复活；原地的建筑被摧毁了就去医院，医院也没了就去第一个还立着的公共建筑；
  - HP 恢复到最大 HP 的一半（向上取整），SP 变成 0；
  - 背包和装备都保留，外甲不会修好，身上的状态和灼烧清掉；
  - 每局一次的能力、这一轮已经用掉的额度，都不会刷新；
  - 这次死亡和击杀取消，但已经造成的伤害和留下的案底照样算。
- 绝对死亡和退场不赔。被保险的人绝对死亡或者退场时，这份保险直接作废。
- 被保险救回来的那一下伤害，不给被救的人关注。

要注意的地方：

- 保险每局只能兑现一次，诗篇可以让它再兑现一次（§13.2）。保险兑现以后只是不能再挂了，关注照样涨 SP，祝祷照样能用。
- Encore 借出你的能力时，只借祝祷，不借保险。

| 第一章 | 第二章 | 第三章 |
|---|---|---|
| 挂上保险 | 祝祷真的回了血或者清了状态 | 保险兑现 |

献给你的诗：「彼岸」（§13.2）。

## 十二、神代天赋 G0–G7

神代天赋是 V2.0-GA 的设计雄心所在。它们不是"比原初天赋更强的按钮"，而是
八种叙事前提不同的规则系统，共享同一个战场。每个角色使用完全不同的资源
语言（火种 / 魔力 / 追忆 / Cost / 孤独值 / 色彩 / 笑点 / 失熵），彼此不通用、
不可转换，但相互之间有预置的交叉影响点。

认知复杂度很高。开桌前请确认大家愿意看别人演出，而不是只愿意看自己赢。

### 12.1 G0「我还欠她们一个明天」——砂狼白子*Terror

来自另一条时间线的阿拜多斯。燃烧生命战斗的孤独枪手，背负逝去同伴的遗物。

**BLACK FANG 465（AR）**：开局以 AR 取代弓，箭矢按 1:3 转化为子弹（初始
15 / 上限 30）。两种射击模式：

- **点射（1 发）**：基础伤害 4；
- **全自动扫射（3 发）**：本次伤害 +2，且额外削减目标 2 点外甲耐久。

AR 不能装普通弓模块，有专属双**【遗物改装槽】**，T0 小动作切换挂载。

**阿拜多斯遗物（开局自带 4 件）**：

| 遗物 | 挂载效果 |
|---|---|
| 星野的破裂圆盾 | 每轮获得 2 点临时屏障；场上有 G7 时另有羁绊加成 |
| 野宫的机枪弹链 | 全自动扫射附带溅射，刮擦同地点另一随机敌人 |
| 芹香的瞄准挂件 | AR 攻击视为已 lock（无视移动闪避 + 破甲加成提升） |
| 绫音的破碎眼镜 | 当轮实际付过技能 HP 后，该轮 R4 回 1 HP；每轮一次 |

**1 SP 即演【深渊无人机·神秘协同】**：消耗 1 SP + 当前 HP 的 20%（向上取整，
最低 1，不致死）；T0 部署不占 T1。无人机持续 3 个未来 R4 tick，随 G0 移动，
可被攻击（不算犯罪）。无人机在场时 AR 射击转为**神秘属性**——对一切普通/
魔法/科技外甲均触发克制（双倍碎甲）；每次 AR 攻击协同追加 +1，无人机 HP4。

**2 SP 公演【黑洞·十字炮火】**（可崩铁式插队）：入口需无人机在场；消耗
2 SP + 当前 HP 的 30%（最低保留 1 HP）。对当前建筑内除 G0 外所有敌对单位
造成 `DIRECT_DAMAGE`（恢复真伤口径，撤销风洞"普通属性必中"修正，不再自伤）。
无人机释放后消失（超载自毁）。

**遗物绝唱（可选）**：释放时摧毁 1 件挂载遗物，附赠绝唱——
星野盾 → 震荡全场 + 自身屏障拉满；野宫弹链 → 炮火伤害翻倍；芹香挂件 →
炮火穿过有限数值屏障，仍受替身/绝对免疫承接，不另附普通磨甲；绫音眼镜 → 炮火结束后将自身 HP 抬回安全线。

**调整呼吸（Death Gate · 最后的 15 秒）**：每局 1 次；普通致死触发
（`absolute_death` 不触发）。锁 1 HP，清除普通控制；两轮窗口内阻止普通、直达、
DOT 与环境伤害造成的 HP 损失，绝对死亡致死来源仍可斩杀；自身技能代价照付。
期间装填免费但仍受库存/容量约束，仅实际造成的敌方 HP 损失可吸血，不从屏障损耗、
过量伤害或自损吸血（每根实际 HP 损失汇总的 50%，向下取整）。2 轮结束 HP ≥ 6
→ 逆转成功继续战斗；否则撤退。

**撤退（体面谢幕）**：不算被击杀（不产生凶手人头），不进往世层；PP 冻结；
战果分/剧情分 100% 全额保留；第三章不额外冻结一个旧 PP 快照；
计入"玩家出局"事件（G7 色彩 +2）。

**第 3 章弧光「我还欠她们一个明天」**：本局内挂载/过载过全部四件阿拜多斯
遗物，且轰出过十字炮火；全部三章见 §7.4。

**G5「明天」诗**：黑子打工信用点额外 +1，所有商店/医院/军基消耗 −1（最低
1）；下一次十字炮火不消耗自身 HP，且可同时过载触发 2 件遗物绝唱而不摧毁任
何遗物；若释放时正处于调整呼吸，立即恢复 6 HP 跨过止损线。

### 12.2 G1「火萤·燃烧循环」——流萤 / SAM

最后的格拉默铁骑，失熵症少女。**燃烧就是在死**——卸甲调息与着装参战的
风筝循环，以及必死的第三次死亡。

**三态阶梯（单向上行，可跌落）**：

| 形态 | 进入 | 失熵速率 | 行为约束 |
|---|---|---|---|
| 卸甲常态「流萤」 | 起始态 | 慢速 | 攻 −1 / 受击 +1 / 命中惩罚；可发育 |
| 次级燃烧「SAM·着装」 | T0 宣言，1 SP | 中速 | 禁 find/interact；解锁超新星 |
| 完全燃烧 | 2 SP 公演（须次级） | 最快 | 窗口 3 轮；T2 StepFollowup(allowed=[move,attack]) |

卸甲不是安全，只是更慢地死。每 R4 失熵缓慢累积，不暂停；本行动回合无攻击
类行动则 R4 失熵回落（唯一常规回落通道）。
卸甲发育补偿确定为有费用的 interact 减 1（最低 1），不再额外
叠卸甲移动闪避。主动卸甲不付 SP，但占唯一 T0；医院手术「演出！要开始了！」按 §4.4 减少失熵累积。

**失熵量表**：0 起步、有上限的公开量表。达阈值 → 当轮 R4 触发结算，随后
回落（不清零——疾病不会痊愈，只是压回一段）。结算顺序（三层漏斗 Armor 层）：

1. 持有炽愿可消耗 1 层完全抵扣；
2. 否则摧毁 1 件自选外甲；
3. 无外甲时扣 HP——卸甲的她被失熵直接啃食血肉。

失熵结算不构成"受到攻击"，不触发反击/关注/犯罪。

**终焉环境抗性（V2.0-GA 分档）**：着甲态 100% 免疫终焉灼伤（含 G2 炉心融解
翻倍后的双倍终焉）；卸甲态实际承担 ceil(环境伤害×50%)。这对应星核猎手的使命——
应对虚无导向的终末结局。G2 炉心融解后的双倍终焉核冬天里，只有着甲的萨姆
毫发无伤。

**DHGDR-超新星过载**：形态门槛次级及以上。获取：进入次级 +1，完成击杀 +1，
上限 1。发动：`move` 根行动触发（落点可为当前地点），对落点内除己外玩家与
警察造成 AOE 伤害 + 穿甲 + 挂灼烧（普通属性 + `defense_coefficient` 折减）。

**超击破近似**：次级及以上形态，对受控（震荡/压制/石化）或灼烧/虚弱单位
攻击获得固定加值 +1。自洽循环：超新星挂灼烧 → 后续攻击吃增伤，
不依赖队友。

**第三次死亡（繁育）——3 轮必死倒计时**：

触发：每局 1 次。**本局曾开启过至少 1 次完全燃烧，且当前处于 ≥ 次级燃烧状态
时受到第一次普通致死伤害** → 必定触发（无概率骰）。`absolute_death` 来源
直接杀死，不入繁育。防开局碰瓷：没开过完全燃烧就没有第三次死亡；触发权
部分在对手（可以不打死她）。

内容：倒计时 3 轮（建立轮不 tick）；归零 = **绝对死亡**（进白名单，绕过一切
免死/复活/T7）。繁育期间再次普通致死 = 正常死亡（星核只有一枚）。

**繁育态效果**：
- 先攻 +3，繁育初始 HP 置 8（不超最大值）；
- 每轮首次合法 `move` 触发**结构超新星**（不读 SP、不占公演、不耗过载）→
  结算后**永久摧毁落点建筑**（缩圈；警察局被毁同步停机；最后安全地点兜底
  保留）；幸存单位按先攻降序 + actor ID 驱逐至未毁公共建筑；
- **ATK 提升**：相对普通角色 +4（完全燃烧为 +3）；
- **普通控制免疫**：免疫压制/震荡/石化/失神（世界法则级如 G5 时间倒流仍生效）；
- **击杀再动（流萤二命复刻）**：繁育期间自己回合完成击杀，T2 获得一次 move/attack
  单步追击，与自身同轮其他追击共用一次额度；没有新 T0，不演出、不递归，不是 ExtraTurn。

**胜利判定优先于倒计时**——为生而战打到最后一刻赢下来，是她能得到的最
好结局。

**炽愿**：超新星每命中 1 单位 +1，每击杀 1 单位额外 +1，上限 3。
用途二选一：抵扣 1 次失熵结算；或受击时充当临时 HP。

**G5「飞萤」诗**：
- 分支 A（G1 常态或次级燃烧）【仲夏夜的烟花】：接受后免费开启一次持续 2 轮的【完全
  燃烧·无垢】——不需 2 SP、不占聚光灯；享受火力加成、R0 自愈与 T2 追击，
  但**期间失熵增长为 0**，窗口结束退回常态且不触发强制失熵结算；
- 分支 B（G1 已处于繁育 3 轮必死倒计时）【以流萤之名活下去】：立即抹除
  必死倒计时，HP 恢复至 12（不超最大值）；代价——萨姆机甲消散，本局永久失去
  次级/完全燃烧/超新星能力，同时永久治愈失熵（量表移除）并抹除卸甲常态的
  负修正。她不再是格拉默的铁骑，而是一个健康的普通女孩。

### 12.3 G2「请一直，注视着我」——歌者×凡人

三句定场诗：

> 「她和世界打了个赌：在黎明跌入白昼之前，若有人肯为她停下脚步，问一句她
> 的名字，她就赢了这一场轮回。」
>
> 「三千次轮回里，白裙的凡人总是停在雨幕之外，低着眼睛，沉浸在自己的悲伤
> 里——一次，也没有抬头。」
>
> 「于是影子从她脚底爬起，从背后抱住她：『别唱了。我带你跳进炉心，把痛苦
> 烧成纯白，把明天烧成昨天。』」

**一体双标（物理模型）**：

| 项 | 规则 |
|---|---|
| 面板 | 光与影**共享**同一 HP / 背包 / 护甲 / 钱包 / SP |
| 坐标 | 光与影各占一个地点坐标（地图上两枚棋子） |
| 回合 | 每轮共 1 个标准回合；选择主控光/影是回合设置，不占 T0 |
| 残影 | 未主控方不可被单体指定、不参与战斗结算；其地点被摧毁则自动并回主控坐标；终焉环境伤只作用于主控坐标 |
| 倾向 | 主控光：实际打工收入 +1；主控影：普通攻击 +2 |

**孤独值与白键/黑键**：孤独值初始 2、范围 0~4。世界时钟在 R0 每推进一格：孤独 ≤2
记 1 白键，孤独 >2 记 1 黑键。演出 A 降孤独积白键，演出 B 升孤独积黑键。键位
不清零、无上限，只比多少——这是你整场对局的累积历史，不可悔棋。
双倍速跨两格就记两次节拍，但不多结算一轮行动、回复或状态。

**1 SP / 2 SP 演出（大即演，永不占聚光灯）**：G2 永远不报名公演，她的 2 SP
是强化即演。免费主控声明决定可选演出；A 使用 T0，B 使用 T1，融合后演出均占 T1：

**A（对光）·擦肩的驻足**：光瞬移到影的坐标；回 HP / 屏障分别为 2/2，2 SP 版为
4/4，共享身体只领一次；孤独 −1（2 SP 版 −2）；**T1 强制只能 `move`**——短暂驻足后，
注定离开。

**B（对影）·唱着无人问津的歌**：孤独 +1（2 SP 版 +2）；对影所在建筑所有
单位施放【溺音光环】至下个 R4：非玩家单位 → `SUBMERGED` 沉沦；玩家 → 脆弱
（受伤 +1/+2）+ 失神（下回合 T0 小动作封禁 + 无法隐身）。

**黄昏锁与终局判决**：

- **黄昏锁**：世界时钟进入黄昏前无融合，普通致死检查合法 T7 保险，无承接才死亡；
- 黄昏后首个 G2 回合清点键位——白键 ≥ 黑键 → 终局一《世末歌者》；黑键 >
  白键 → 终局二《炉心融解》；
- 黄昏后若 G2 遭普通致死：触发融合并按当时键位立即裁决终局（取代死亡）。
- 融合整局一次，在自身形态转折层先于保险；建立正数起始 HP 后再执行终局效果
  （置 8，再执行炉心等效果）。已融合者不能反复融合，绝对死亡跳过此替代。

**终局一《世末歌者》（白键 ≥ 黑键）——世末之雨**：
1. 光与影和解合一（双坐标并一）；
2. 【世末之雨】至 G2 死亡：所有非玩家单位在法则期间持续沉沦；法则结束解除，
   不复活已死 NPC；全场存活玩家普通攻击力 +2；
3. G2 演出升格——1 SP【倾盆的雨音】全图 AOE（占完整 T1）；2 SP【请一直，
   注视着我】点名 1 名玩家：不在同地强制拉拽至 G2 所在建筑，已在同地挂
   `ACTION_SUPPRESSED` 压制；
4. 第 3 章「唯一的听众」永久解锁；PP 仍按终局实际余额计分。

**终局二《炉心融解》（黑键 > 白键）——没有我的明天**：
1. 里人格夺舍，光与影坍缩合一；
2. 【核融解裁决】对全场所有存活玩家：当前外甲耐久、当前 HP、最大 HP 同时
   降至 1/2（向上取整，不直接致死）；
3. 【2 倍速末日】世界时钟此后以 2 倍速推进；进入终焉后每 R4 灼伤 ×2；**此
   加速永不解除**（即便 G2 退场或获救）；倒流只暂停，结束后恢复；
4. 【反应堆退场】G2 失去操控权，不可被单体指定、不可被治疗，按固定速率烧
   血（每未来 R4 扣 2）；以扭曲时剩余血量计算烧尽时间；烧尽 = 正常退场；
5. 第 3 章「纯白终幕」在爆发时永久解锁；PP 不另锁旧快照。

"即便 G2 死后时钟加速不解除"是全游戏最激进的机制决策。叙事上完美——里
人格的愤怒已经点火，夺走发起者的性命也无法撤回末日。平衡上需要最严格的
风洞校准：2 倍速 + 炉心腰斩 + 双倍灼伤三重叠加，在 20 轮快节奏局里可能
把终焉阶段压缩到实质上无法正常行动。

**G5「追光」诗**：
- 分支（G2 未进终局，黄昏前）：孤独值立即清零，谱表 +2 枚白键；下一次对光
  释放演出 A 时解除"T1 强制只能 move 离开"的限制（光与影可并肩停留自由行动）；
- 分支（G2 已堕入黑键《炉心融解》烧血等死）【劫后余音】：立即停止烧血退场
  并归还玩家操控权；**不**逆转成《世末歌者》（不触发全图 NPC 沉沦与院长大
  雨）——里人格已在炉心爆发中替她燃尽，G2 恢复单人状态，获得常驻 2 点固定
  减伤（雨幕），且普通攻击保留影的 +2 穿透加值。

### 12.4 G3「神话之外」——士郎

英灵卫宫的投影魔术与固有结界——「神话之外」= 无限剑制。母题：以魔力换
取时间；剑之丘陵的持续齐射，不是一发爆气。

**魔力与 SP（职责分离）**：魔力支付投影、维持与超限；SP 决定何时展开固有
结界——两者不互相替代。开局魔力 6，常规上限 8，结界外每 R0 恢复 1（唯一常规恢复入口）。

**结界外投影（T0 减负）**：非攻击型持续投影为 **T0 小动作**，支付对应魔力，
不占 T1：

- **七重圆环（Rho Aias）**：T0 展开，登记为三层漏斗第 1 层 Barrier——远程
  直接攻击先打圆环，击破当次不向本体溢出；
- **双刀·守势**：T0 建立防御标记，下一次以 G3 为目标的攻击取得固定减伤后
  消耗（`DIRECT_DAMAGE` 消耗标记但跳过该减伤）；
- **见证与复制**：见证过的普通武器家族可付魔力投影基础型（只复制基础伤
  害/属性/射程，不复制模块/弹药/蓄力/专属标签）；结界外只维持**一个持续
  投影通道**，新 T0 投影成功后旧持续投影在该回合收尾清理。

**攻击型投影仍为 T1 攻击根**：
- **螺旋剑（伪）**：远程攻击根，创建并立即发射；
- **双刀·攻势**：近战攻击根，以合法近战武器为基础 + 固定加值。

**1 SP 即演**（补 M9 空缺）：
- **鹤翼三连（近战双刀）**：1 SP，本次双刀获得固定加值；命中外甲时触发连携
  追击——额外磨损外甲耐久且必中；固定磨损部分按 §5.3 DEC-012，在本击扣血与普通
  外甲计费确定后结算，不反向增加本击扣血、不把余量转移到另一件甲；
- **伪·螺旋剑（远程狙击）**：1 SP + 魔力，跨地点轰出一发**无视掩体/屏障**
  的高爆穿甲螺旋剑。

**2 SP 公演【无限剑制】**（可崩铁式插队展开）：当前地点被替换为固有结界。

**展开即剑丘**：剑阵**自动常驻**（G3 攻击获命中加成 + 每轮第一次以 G3 为
目标的远程直接攻击被剑阵 Barrier 拦截）；已见证的复制武器自动进入**兵装池**，
随取随用、免创建行动与魔力。

**捕捉**：当前地点全部存活玩家 + 敌对/中立 NPC；警察不进入（案件挂起）；
外部世界继续推进；内外不能跨边界交互。

**主目标**：展开后公开指定 1 名存活被捕捉单位（幻想崩坏的唯一合法目标；
每个回合设置时可免费改选，不占小动作；死亡/离界即清空）。

**结界锚点与破界**：被困者可用普通武器攻击根打锚点（按 A 扣结构耐久），
或 `break_barrier` 稳定扣耐久（占整个标准行动）；锚点归零 → 强制解除，未
行动者回原地点后仍按原顺序行动。

**维持费简化**：每未来 R4 支付 1 魔力，最长 3 个未来 R4，建立轮不 tick。
各投影费用、锚点与伤害见 §17.9，不再使用 M9 五项加法公式。

**宝具连发与赤原猎风**：

- **`projection_chain` 宝具连发**：结界内螺旋剑根行动首发结算后，可支付递增
  魔力在同一根行动内连射（含首发最多 3 段，费用 2/3/4）；每段独立预检/结算；只允许螺旋剑，
  复制武器不进入连发白名单；
- **累计耗魔计数器**：每根行动独立累计实际支付的投影魔力，达阈值后——
- **赤原猎风**：自该次起、本根行动内后续命中玩家单位的释放附加即时效果：
  **目标 SP −1（下限 0），且目标本全局轮无法触发受击满能量插队公演**（对
  齐基线铁律 5，替代 M9 公演队列移除）；频率闸：每名玩家每次结界至多一次；
- **回路接通**：触发赤原猎风 → **理想燃烧自动点亮** → 可在同一根行动末尾
  无缝衔接终段幻想崩坏（不再需要打卡凑式样数）。

**幻想崩坏**：消耗全部剩余魔力 + 牺牲兵装/防壁/剑阵；对主目标结算一次统一
攻击：基础伤害 = `4 + min(本次结界累计式样数, 4)`
（式样自动累计）；普通属性、防御系数0.5 + **双倍耐久计费**（非 DIRECT_DAMAGE）；
结算完成后无条件解除结界。也可不终结保留结界（维持费照付），此后独立发动
幻想崩坏（需 `collapse_terminal_min_magic`）。

**G5「永恒」诗**：立即为 G3 恢复 4 点魔力（可突破上限转为临时魔力）；下一
次固有结界内，螺旋剑【宝具连发】首段免费（0 魔力）且连发上限 +1 段；展开
时照常指定 1 名被捕捉单位首槽震荡。

### 12.5 G4「愿负世，照拂黎明」——白厄

白厄 / 卡厄斯兰那——「以旧日余烬为来世破晓，烈阳撕裂长空」。母题：永劫轮
回里的英雄。与 G2（盗火×白厄双生）、G5（时间倒流 ∞）共同构成轮回叙事轴。

**资源：火种（上限 12）**——只在人形态积累。三条途径：

| 来源 | 条件 | 增量 |
|---|---|---|
| 受难之火（被动） | 人形态承受他人有效伤害（HP 损失或外甲破碎） | +1；每轮受击类至多 +2 |
| 逐火之剑（1 SP 即演「夺火」） | 人形态消耗 1 SP 发动斩击；命中或破甲 | +2 |
| 余烬共鸣（环境） | 场上其他玩家阵亡，或建筑被摧毁 | +2 |

不计入：DOT 后续 tick、环境/世界时钟伤害、自我消耗。撤销风洞修正
"敌对外来火种 1→0"——白厄的核心是用血肉扛下世界的恶意，受击攒火必须恢复。

**进入救世主形态（两条路径）**：

**主动升格（完整救世主）**：火种 = 12 且人形态；任意 T0 小动作主动燃尽全部
12 火种（不占 T1）；若公演位仍空，可直接用当前标准回合 T1 公演；否则保留 SP
选其他主行动。ExtraTurn 禁公演，不另外创建一个插队槽。
升格瞬间 SP 置满为 2；获得**余烬生命** 24；初始毁伤 3。

**濒死转折（残缺救世主）**：人形态遭普通致死且持有火种 ≥6；消耗当前全部火种 c
进入残缺形态；余烬生命为 2c，初始毁伤 max(1,floor(c/4))。火种 < 门槛 → 正常死亡（不拦截，杜绝 0 火种碰
瓷）；`absolute_death` 来源直接杀死。

M9 的"负世主动燃尽派发完整额外行动"**退役**——升格不创建额外行动槽。

**救世主形态（3 轮极境燃烧）**：持续 3 个未来 R4 tick（建立轮不 tick）；
形态内不再获得火种；毁伤为形态内局部预算，退出清空。

**强化普攻**：占标准根行动，不耗 SP；所选普通武器基础伤害 +2，命中毁伤 +2；T2 附带
【烈阳余波】对同地点其余敌人各纯磨甲 1。不做无条件扩散，不复制
十六次弹射拓扑；余波是附加效果，不再赠送一个行动槽。

**2 SP 公演【灾厄·弑魂焚诏】**（可崩铁式插队）：消耗当前全部毁伤 D，天裁段
数 = D。结构：

```text
全桌秘密承诺「迎战 / 拒战」
→ 迎战者按先攻降序逐个执行 challenge_response（受限反应，非完整行动）
→ 对迎战者的统一反击池
→ 对拒战者的死星天裁池
→ 公演收尾
```

- **迎战者**：临时解决距离/面对面，由玩家选择一项合法普通攻击，弹药照付，无可用
  武器可拳击；不强制最佳载荷，不借机公演或开宏。每次合法挑战天裁段数 −1；不产生
  犯罪/SP/关注/警务额度，也不附赠 T0/T2；
- **拒战者**：平摊剩余段数的死星天裁总池（`DIRECT_DAMAGE`；致死结果附
  `absolute_death`）；
- **固定总池**：反击与天裁都按总池均分，不按人头复制；分配顺序按先攻降序、
  actor ID；
- 秘密承诺前公开毁伤与两种池的分配规则，玩家知道迎战/拒战各意味着什么；
- **强制中断**：挑战攻击迫使 G4 退出形态 → 停止后续响应，取消反击与天裁，
  转入退场清理；
- **隔离边界**：不穿透结界类隔离（G3 重做后沿用"不穿透隔离层"原则）。

这是一个复合博弈：迎战有风险（你要攻击救世主），但可以降低其他人的天裁
压力；拒战更安全，但集体拒战会让天裁集中到所有人头上；合力抗争（全部迎
战）可通过强制中断退出形态彻底规避天裁。这不是简单的打 BOSS，而是全桌
的利益协商。

**退场**：天裁结算后 / 3 tick 到期 / 余烬血条被打空 → 退出形态，火种归零，
回人形态（可再次逐火）。章节按 §7.4，PP 按终局实际余额计分。

**G5「负世」诗**：人形态立即 +4 火种（无视每轮受击上限）；救世主形态立即
+4 毁伤；**【永劫的烈阳】**：白厄进入救世主形态后，3 轮倒计时**冻结**（只
要余烬生命未归零，形态永不因回合到期退出），且救世主攻击额外附带烈阳火伤；
**代价**：救世主形态存续期间，每个 T0 自动给自己挂 1 层【灼烧】（R4 真实
扣血，不可被常规净化免疫）。
必须在献诗时向 G4 展示永久改造和灼烧代价，由其主动接受；拒绝不退款，永久效果不叠加。

**宿命联动**：白厄常驻灼烧 → 恰好被 G1 流萤的超击破（对灼烧目标增伤）克
制——兑现"G1 与 G4 相互 counter"的原始设计。

### 12.6 G5「往世的涟漪」——昔涟 / 德谬歌

机制原型：ASBR 恩里克·普奇（最终）三阶演进——白蛇 → C-MOON → 天堂制造。
叙事轴：哀丽秘榭的小昔涟 → 黄金裔的同行者 → 记忆星神·德谬歌。

硬约束：昔涟不是死神，是执笔记录、陪伴、最后以自身走向过去换来明天的人。
压制开拓不是她做的事；手填 K 步脚本废除（RL 时间债不可接受）。

**资源：【追忆】**：场上高光事件（破甲/公演/阵亡）+1；T0 小动作「执笔」+1；
上限 12。追忆不是 SP，不交易、不计分，只驱动昔涟自己的三阶段。
每个根行动至多取得一次高光追忆，执笔另算；第一、第二阶段继续增长，第三阶段停止。

**阶段一「哀丽秘榭的讲述者」（开局态）**：正常 20 HP 入场，可正常移动/交互/
攻击。演出【讲故事】（2 SP 大即演，占 T1、不占聚光灯）：选择同地点一名其他玩家——
自己追忆 +2；目标 **SP 置 0**，同时 **HP +1**（温柔的抚慰：废掉其爆发，又
给一口防斩杀的奶）。

**进阶**：追忆 ≥ 6 且支付 1 SP（T0），升入阶段二。

**阶段二「黄金裔的同行者」（C-MOON 式纯数值）**：常驻被动【记忆的重量】——
按当前追忆加普通攻击与固定减伤，各为 floor(追忆/6)，最多各 2；代付后同步下降，不取历史峰值。
演出【此诗，献予一切生命】（基础 2 SP；**每少付 1 SP 可用 2 层追忆代替**：2 SP / 1 SP+2 追忆 /
0 SP+4 追忆；大即演，占 T1、不占聚光灯）：

- 对他人：展示效果和代价，支付成本并发出，目标主动接受后授诗篇强化 + 挂爱愿；
  拒绝不退资源或 T1（期间目标不能伤害昔涟；昔涟攻击
  则破碎）；
- 对自己：咏唱「爱与记忆」，对至多 n 目标射科技/普通/魔法/无视属性多段箭
  （初始段数 1+ceil(初始人数/2)，每次使用后下次 +1、最多 6；每目标最多 2 段，见 §17.11）。

**停在阶段二平推是完全成立的玩法**——对应"不上天堂制造也能赢"。
三个不同轮次有效献诗也能完成第三章，不必为剧情分强行升格。

**阶段三「我的明天叫做昨天」（记忆星神·德谬歌）**：

升格条件：第二阶段、世界时钟已到黄昏、当前追忆 ≥ 12 且支付 2 SP，使用公演入口。
完成后进入第三阶段，但**不删除本轮其他人的任何行动槽**；下一 R0 才启动倒流、
NPC 停机与动词约束。即使 G5 在 R3 首位公演，其余人本轮仍照常行动。

**时间倒流（历史动词倒放）**：下一 R0 起世界时钟停走，历史指针从升格实际轮 N 的
R_{N-1} 起递减。每轮 R0 公布所有存活玩家在对应历史标准回合执行过的**根行动
动词**（move / attack / interact / special 四大类）。除德谬歌外，每名玩家本
轮必须执行与历史相同的动词类型（具体对象/地点/武器自由重选）。
不读宏内步骤、追击或额外回合；历史无行动或当前确无该动词合法动作时免责自由选。
例如历史为 interact，但当前没有任何合法交互，则不因程序无选项惩罚玩家；仅嫌费用
高不算无法执行。普通状态与角色自身倒计时继续，倒流不冻结所有计时器。

**违逆命运惩罚（逐层叠加，满血满盾也扛不住连续忤逆）**：
1. 第 1 次：震碎 1 层屏障 / 扣 4 点外甲耐久（无甲则 −2 HP）；
2. 第 2 次：4 点 `DIRECT_DAMAGE` + 震荡；
3. 第 3 次起：`6 + 2×(次数−3)` 点 `DIRECT_DAMAGE` 且 **SP 清零**。

倒流期间（钉子 9）：世界时钟停走（终焉灼伤暂停；G2 双倍速暂停）；德谬歌
豁免动词约束、保留基础行动但不可再献诗；死者不行动、不受约束；德谬歌被
击杀 → 倒流立即终止，她按正常死亡进往世层。

**∞ 闭环（钉子 10）**：倒流指针抵达 R1 的瞬间（R1 的起床**不需要重演**）：
先保存战果、章节、PP 实际余额与存活者的计分快照，再把幸存面板展示为未起床并定格
结算。重置的是终幕表现，不清空已取得的成绩，也不真的重新开一局。

**第三阶段德谬歌不能献诗**；第二阶段可对他人献诗或对自己使用爱与记忆，见 §13。

### 12.7 G6「要有笑声！」——花火 / 阿哈

欢愉是活人之间的恶作剧、替身嫁祸、当身博弈与全员惊喜礼盒。与往世层
Encore（死者托付本命技能）和 G0（阿拜多斯遗物战术枪战）绝不撞车——G6 是
把别人的回合剪成喜剧的导演。

**常驻被动【看热闹不嫌事大】（笑点）**：闪避成功、普通外甲破碎、实际放弃行动槽、
有人拆盒等 → +1 笑点；每根行动至多一次，首版每轮最多获得 3 枚，献诗置满另算。
当身成立不返架设成本，非法指令/A=0/普通屏障拦截不算落空。笑点 = 假币：执行
`interact`（购物/治疗等）时每 1 枚笑点抵扣 1 信用点；上限 3。

**T0 小动作【替身玩偶·假面当身】**（当身技，高风险高回报）：T0 架设【当身
姿态】，支付 1 笑点、不耗 SP，持续至自己下个回合开始前。

- **成立**：第一段合法单体攻击被玩偶吞掉，该段伤害/破甲/附带效果无效；攻击者承受
  3 点烟花直达伤害 + 震荡。SP 走关注额度，不另送第二份，也不返笑点；
- 不拦范围攻击、DOT、环境伤害，不吞整条连段。例如三连射只挡第一枪，后两枪照常；
- **读空**：至下个回合开始没有符合条件的攻击，已付 T0 和 1 笑点不退款。

当身消耗真实资源；普攻能消耗它，不能每轮免费挡刀再把全部成本赚回来。

**1 SP 即演【插入式笑话·移花接木】**：耗 1 SP、占 T1，指定 1 名其他存活玩家 X 为
"冤大头"；**同一玩家不能连续两轮被指定**。二选一：

1. **刷他的卡**：以 X 所在建筑菜单隔空执行一次 `interact`（装备/物品归
   G6）；最多强划 X 实际持有的 2 信用点，不制造负债；不足部分 G6 自付或笑点抵扣，
   无法补齐则预检失败、不扣双方费用；
2. **借他的刀**：以 X 的位置与视野、用 G6 自己的武器（或 X 的基础武器面
   板）攻击与 X 同地的目标 Y——伤害/破甲/击杀归 G6；犯罪案底/通缉可以嫁祸 X，
   直接反击追向实际施术者 G6。不消耗 X 的弹药/专属次数，不复制技能、宏或连发；
   仍需满足视野、射程和隔离条件。

**2 SP 公演【全员派奖·超大惊喜礼盒】**（可崩铁式插队夺台）：向场上所有其
他存活玩家各塞一个【超大惊喜礼盒】。已有未拆盒时保留旧盒和进度，不立即引爆，
也不延后原期限；每人至多一个未拆盒。

### 12.8 G7「大叔我啊，剪短发了」——小鸟游星野

战术宏、融合装备、SP/Cost 与 Terror 构成其战术循环；防御层级和首次攻击预警按本节执行。

**融合装备**：

- **铁之荷鲁斯（盾）**：第一次同时持有盾牌 + AT 力场时自动融合（一次性）；
  受损后 `special 修复`消耗 1 件组件修复；
- **荷鲁斯之眼（枪）**：第一次同时持有电磁步枪 + 高斯步枪时自动融合；弹
  匣上限 8；每次射击消耗 1 发，分成 3 弹丸，总基础伤害 4，分 2/1/1；属性可为科技/魔法/普通；
- 双融合完成 → 自动习得战术指令 + 2 次自由配发（每次可选 1 战术道具 /
  1 药物 / 2 发子弹）。

**光环**：3 层、每层 2，初始 1 层；未交战 R4 总池回 1，战斗内自动回 0。
三层首次全亮 → 一次性【战斗续行】免死（HP6，光环清空）；Terror 形态下不生效；属三层漏斗 Death Gate 的
Morph 层。
光环是有限护体池，在主动屏障之后、普通外甲之前；按实际承伤扣值，耗尽后余量继续，
不是一层吞任意整击。

**Cost 与战术宏**：每 R0 回满基础上限 6；**失却汇流成泉**——上一全
局轮使用过战术宏 → 下个 R0 回满后 Cost −1（不叠加）；肾上腺素覆盖。

**战术宏**：T1 `special Hoshino` 进入，占一个标准根行动（复合根容器）；
只要 Cost ≥ 1 即可进入，**不耗 SP**；逐步执行并扣 Cost，某步不足即中断，
已执行步骤不回滚。宏动作表（Cost）：

| 动作 | Cost |
|---|---|
| 架盾 / 射击 | 2 |
| 重新装填 / 取消 / 转向 / 排弹 / 服药 | 0 |
| 持盾 / 投掷 / 冲刺 / find·lock | 1 |

**架盾**（三层漏斗 Barrier 层，DEC-015–016）：划分正面/背面；取消低伤免费格挡
阈值，每次成功格挡正伤害都按来袭伤害扣盾耐久，最多扣尽。破盾这一击仍完整拦截，
之后失效；只在原本合法的拦截范围内生效。正面敌人正常离开需多花 1 回合；**架盾
期间 G7 无法 move**；每 R4 维持 Cost（水着-Shielder 免费，但受击仍扣耐久）。

**持盾 / 被动保护**：未架盾的铁之荷鲁斯按普通外甲择一减伤、耐久计费；持盾只提高
属性防御，没有额外耐久吸收池、不吞破碎余量、不保留永远剩一点的将破线。免费切姿态
不会修甲。例如主动架盾最后 1 耐久能完整挡一击，普通持盾最后 1 耐久只能支付相应减免。

**战术道具与药物**：

- 道具（军基）：破片手雷 / 震撼弹 / 闪光弹 / 烟雾弹 / 燃烧瓶；
- 药物（医院）：EPO（Cost +1）/ 海豚巧克力（回 1 层光环）/**肾上腺素**
  （全局 1 次，宏外注射占本回合 T0；下个 R0：Cost 回至临时高
  上限 + 光环全恢复 + 先攻 +3——覆盖失却汇流成泉）。

**SP 接口（本次修订核心：SP 与 Cost 咬合）**——

**1 SP 即演【大叔的午休】**（T0，不占 T1）：T0 宣言，耗 1 SP。眯一觉、换个
插板，T1 照常开宏。二选一：

1. **紧急包扎**：立即恢复 2 HP（使用前 HP≤半最大值时为 3）；并清除下轮
   R0 的失却汇流成泉惩罚（睡饱了，不算疲劳）；
2. **更换防弹插板**：尚未破碎的铁之荷鲁斯耐久 +2（或恢复 1 层光环）；并向荷鲁斯之眼
   免费压入 2 发普通子弹（为 2 SP 全弹倾泻备弹）。耐久0不能靠午休复原盾，须另花组件和T1修复。

**2 SP 公演【荷鲁斯之眼·全弹倾泻】**（三形态本命大招）：前置——持荷鲁斯
之眼且弹匣内 ≥ 1 发子弹；2 SP 公演（占 T1；支持崩铁式插队夺台）；消耗
2 SP + **倾泻弹匣内全部剩余 N 发子弹**——N 越多大招越强；自动取所倾泻子弹
中最优属性结算属性克制双倍碎甲。按当前形态释放本命大招：

| 形态 | 大招 | 效果 |
|---|---|---|
| 水着 / 常态-Shielder | EX【战术镇压】 | 强制将当地所有单位划入正面并直接进入架盾；对正面全体扇形轰击（随 N 增伤）并施加震荡；N ≥ 4 时可对 1 名主目标挂 `ACTION_SUPPRESSED` |

**色彩、自我怀疑与 Terror**：

- 色彩：每有 1 名玩家出局 +2；由 G7 击杀额外 +2；**G0 撤退按"玩家出局"计
  入 +2**；
- 色彩 6：自己 T0 可选进入自我怀疑；
- 色彩 10：本体受非致死 HP 伤害 → 恢复穿戴过且已破碎的护甲 → 强制自我怀
  疑 → 完整跳过下一标准槽 → 反转为 Terror；额外槽不能代缴，普通压制不能无限延期。

**Terror**（全游戏最具破坏力的状态）：Cost 为 Null；失去战术指令/道具/药
物/铁之荷鲁斯/光环；只能 attack 或 move；进入时护甲/光环/铁之荷鲁斯折算

额外生命；无法被举报，警察拒绝攻击/靠近/移动
指令；不参与即演/公演；战斗续行不生效。

效果不发生）；接受后——色彩永久置 null；若在 Terror 则解除并把剩余额外
HP 转永久 HP；扣 min(2, 永久额外 HP) 恢复铁之荷鲁斯（曾融合则耐久 ≥2，

与 G1 飞萤诗共同构成"绝境必死态（Terror / 繁育）的唯一救赎"轴。如果当局
没有 G5，就没有解除 Terror 并恢复战术形态的救赎入口；其他玩家仍可利用预警、
承接规则、隔离或合力攻击应对，Terror 不等于必然全歼。

  态存续期间，每个 T0 自动给自己挂 1 层【灼烧】（R4 真实扣血，不可被常规
  净化免疫）；
- 宿命联动：白厄常驻灼烧 → 恰好被 G1 流萤超击破克制。

**6. 献予「爱与记忆」之诗（G5 自身）**——*以追忆为弓，命运为箭*
- 基础段数 1+ceil(初始人数/2)，2/4/6 人局为 2/3/4；每次使用后下次 +1，最多 6。
  每目标至多 2 段、每段基础 2；固定加值只入总池一次，详见 §17.11。依次科技/普通/魔法，
  第 4 段起无属性；不施加爱愿。

**7. 献予「欢愉」之诗（G6）**——*把整张桌子都变成你的马戏团*
- ① G6 笑点立即回满至 3；
- ② 授「欢愉的延展」标记（4 个未来 R4 tick）：当身升级【双面假面】（反
  噬翻倍至 6 点烟花；读空 → 玩偶自动飞向敌人炸开）；G6 花 T0 代拆时可一次
  性引爆已获得响应窗口的未拆礼盒；当身仍付 T0＋1 笑点，不因成立返笑点；
- 重复献诗只刷新标记，不叠加。

**8. 献予「守夜人」之诗（G7）**——*向走向过去的少女说出你的愿望吧*
- 需 G7 主动接受（拒绝则本次 SP/追忆与 T1 照耗、效果不发生）；接受后：色彩永久置 null；
  若在 Terror 则解除并把剩余额外 HP 转永久 HP；扣 min(2, 永久额外 HP) 恢复
  铁之荷鲁斯；恢复战术指令/药物/装备可用性；光环恢复初始层数。

### 13.2 原初六诗

## 十四、新手指南

### 14.1 一局最短路线

1. **先起床，领初始包。** 私人房间出门就回不来，刀/盾二选一先决定。
2. **R1 必须出门**：进商店/魔法所/医院/军事基地/警察局之一。
3. **赚钱**：商店打工是唯一经济入口，没人在家里发工资。
4. **准备一套能打人的东西**：弓负责跨地点，近战同地显形直接打，护甲负责
   把对手的攻击变成你的维修账单。
5. **看 SP，不要只看血**：SP=1 可以即演，SP=2 可以选择立刻即演或参与夺台。
   等公演不是必然更强，而是在等全桌舞台——崩铁式插队让你能抢台。
6. **关注世界时钟**：白昼开始掉落，黄昏是神代终局集中期，终焉会把"我再
   发育一轮"变成遗言。
7. **死后继续玩**：普通死亡进入往世层；三个按钮零背诵——押注、微光、
   Encore。

### 14.2 常见误解

**Q：先攻最低是不是又要轮空？**
A：不是。所有正常玩家都有标准行动，先攻只决定顺序。

**Q：SP 是行动点吗？**
A：不是。SP 只管天赋演出，不增加或删除标准行动槽。

**Q：公演是不是天赋加强版？**
A：核心通常相同。公演多的是聚光灯、往世层 Encore、诗篇适配与夺台竞争；强
度看天赋。大即演（G2 全部演出、G5 讲故事/献诗）不占聚光灯但强度同样高。

**Q：`DIRECT_DAMAGE` 是不是必杀？**
A：不是。它跳过普通目标侧防御，但仍可被明文承接；是否跳过复活看
`absolute_death`。

**Q：普通死亡就没事做了吗？**
A：你只是从选手席去了证券交易所。三个按钮：押注、微光、Encore。`absolute_
dead` 才是真正没有往世层操作。

**Q：lock 还要花整轮吗？**
A：不用。V2.0-GA 里 lock 是 T0 小动作，T1 直接攻击。

**Q：公演还要排队吗？**
A：不用。轮初愿意公演的合法 SP=2 玩家按先攻竞争，胜者将标准回合提前到 R3
最前兑现。轮初无人兑现时，轮中满 SP 者可申请在当前玩家回合完整收尾后插队；
不能打断连招，也不能让已经行动的人多一次标准回合。详见 §6.3。

**Q：G7 Terror 没救了？**
A：守夜人诗是解除 Terror、恢复战术形态的救赎入口。没有 G5 时仍可利用预警合力
攻击、隔离与明文承接应对；Terror 是定值伤害真正致死时才绝对死亡，不是命中即死。

**Q：G5 第一个公演，我这轮就不能动了吗？**
A：仍能动。升格不删除本轮其他人的槽，下一 R0 才启动倒流规则。

**Q：T7 已经救过人，是不是以后只有普攻？**
A：仍可取得关注 SP，并用 T1 花 1 SP 祝祷；用尽的是保险资格。彼岸只能再开一次保险。

**Q：我被压制所以没法拆礼盒，算我拒绝吗？**
A：不算。必须先给你一次可以选择的 T0，之后 G6 才能代拆，自动爆炸计时也从该机会后开始。

**Q：昔涟能直接把繁育中的我变成普通人吗？**
A：不能替你决定。她发出诗后，你先看到强化、爱愿和失去机甲的代价，再接受或拒绝；
拒绝不发生改造，施法方已支付的资源与 T1 不退。

**Q：连发里的每次破甲、公演和击杀都给昔涟追忆吗？**
A：同一个根行动最多给一次高光追忆；不同目标的实际伤害仍分别记战果。资源限频与战果
记录是两件事。

**Q：为什么神代天赋这么长？**
A：因为它们的目标不是成为一排容易平衡的按钮，而是让角色在规则里留下清
楚的轮廓。你可以嫌它们麻烦，这很合理；你也可以选 T1，然后把复杂问题处理
成一次近战攻击。

## 十六、主持与权威边界

DM 应公开位置、HP、装备、状态、先攻、SP、夺台窗口、PP、案底与可见天赋
资源；收集 G4 秘密承诺时延迟广播；在规则没有随机决胜时不得临时掷骰。所

GA 尚未实现；当前文本里的首版值不代表该配置已经包含 GA 数值。后续至少检验 T6 无
警察对抗回血/修甲、单普攻对当身、G7 防护耗尽、十四人公演与章节可达性、死亡与倒流
并发、多人同时出局，检查持续交战但没有永久进展的循环。迁移目标是单一 GA，旧模型
不能当作兼容新行动空间；文本检查不能代替这些运行与平衡验收。

本手册 v0.1 草稿整合的权威来源：

## 十七、首轮数值表 N0（2026-10-26）

这一节把“先填一版没有明显大问题的数值”落成可以直接取用的表。所有值都是设计初值，
尚未经过 GA 对局验证；调整时原位改表，不并存多个数值版本。机制继续服从前文与 RFC，
旧代码、M9 配置和历史风洞记录不自动补齐 GA。后续程序只从配置读数，本次不改配置或代码。

N0 的尺度是 **20 HP、常规攻击 4、一次普通治疗 4、普通外甲耐久 6～10**。
高投入爆发可以显著超过普攻；免费再生、每轮恢复、攻击段数和资源返还必须有边界。
本次数值调整包括：G7 午休由草案 4/6 HP 降为 2/3、补盾由 6 降为 2；G6 自己主动
放弃行动的笑点收益为 0；这些初值优先避免单普攻角色被永久防守循环锁死。

### 17.1 开局、取整与命中

| 项目 | N0 初值及适用范围 |
|---|---|
| 通用开局 | 最大/当前 HP 20；信用点 4；SP 1；PP 0；无默认外甲，初始包仍选刀或盾 |
| 初始远程资源 | 弓 1 把、箭 5 支，持有上限 10；G0 替为 AR 与子弹 15，上限 30 |
| 先攻 | 每全局轮独立 D6 + 明文修正；同值按固定 actor ID，不另掷隐形骰 |
| 基础命中 | 100%；普通单体攻击按命中率掷一次；未命中仍结算擦伤，非伤害归零 |
| 移动闪避 | 主动 move 后 +15 个百分点，持续至自身下个标准槽开始；不叠加 |
| 隐匿闪避 | 合法可攻击的隐匿目标 +25 个百分点；没有目标资格时先搜索，不能靠掷骰越过隐匿 |
| 跨地射击 | 未 lock 时命中 −15 个百分点；同地无此罚值 |
| lock | 本回合命中 +15 个百分点、忽略移动闪避、属性防御系数 0.75 |
| 命中封顶 | 普通命中率 clamp(基础 + 加成 − 惩罚 − 闪避, 40%, 100%)；必中为 100% |

### 17.14 首轮检查与调整顺序

以下是数值表的静态推演口径，不是 GA 引擎跑分：

1. T6 用无模块弓A4打普通防御3/耐久10：前3击各掉HP1、磨甲3；第4击掉HP3、磨甲1。
   4击累计掉HP6且外甲耗尽；之后每击4。锁定后防御floor(3×0.75)=2，推进更快。
2. T3 每轮补玉璋3仍会被A4留下1点本体伤害；G7每轮补盾2小于一次A4架盾消耗4。
   破盾后午休不能从0补盾，须消耗组件和T1修复，避免“2耐久挡整击、再免费补2”的循环。
   G7战斗内光环不自动再生，普通弓不能被“1层挡整击”误实现成永远无伤。
3. 普通治疗付2回4，先打工再治疗需2个T1；在每轮吃一发A4的无甲例子里，两轮净损HP4。
   T7祝祷回3也低于无甲A4；临时针剂/手术/药物另有费用或次数边界。
4. G6初始1笑点若没有外部笑点事件，只能架一次当身；自己放弃不补回1笑点。
5. G3满资源三连发后仍能留3魔力用于终段；G5两人/六人局的基础箭数是2/4，单目标最多2段。
6. G7两件防具价5、两枪价7，开局4信用点再打工4次可支付全部12；跨地点和4次购买仍占行动，
   可以在中盘完成，不要求先攒几十轮。水着自带盾能省2；免费配发不反向刷新融合。

后续实测优先调：普攻对回血/修甲的净推进 → 开局到第一次演出的轮数 → 公演与章节可达性
→ G3/G7多段爆发 → G2/G5终局时长 → 得分分布。一次调整记录参数、原因和同场景前后结果，
不为一个天赋直接叠上新机制。40轮兜底、零永久进展循环或某角色始终无法完成章节都要单列。

**本轮已做的检查（2026-10-26）**：用独立算术脚本检查普通伤害/屏障/减伤/耐久组合
748,800例，确认扣血不超过屏障后余量、耐久不透支、整次承接为0；检查G3费用、G4总池
守恒、G5人数/段数、G7宏基础输出与初期采购账。另枚举G7无限SP、免费架盾、每轮吃A4的
纯防守简化模型：在没有外援、组件/药物与免死的条件下，午休/光环选择无法无限存活。
这只验证这些算术与循环边界，没有运行GA引擎，没有测胜率、控制连锁、走位或十四人平衡。
