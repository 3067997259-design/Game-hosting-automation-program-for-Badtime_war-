## 卷首：为什么又来一个版本

M9 是一次很诚实的中期成果，但它留下了七个已知病根：计分有乘数所以可以苟活、
残局有私宅所以没碰撞、`find` 占整轮所以发育期太长、公演排队有官僚机构所以
抢台没博弈、警察是三个各自行动的 NPC 所以难以驾驭、往世层有二十六张牌要背、
对局平均四十轮所以膀胱是瓶颈。

V2.0-GA 不是在这些病根上各打一块补丁，而是先重写底层十条规则，再让十四个
天赋重新接到干净的挂钩上。结果是：规则更少，天赋更大，对局更短。

这游戏仍然**不适合脱离电子裁判纯手算**。规则你可以理解，但不要成为一台
人肉结算服务器。DM 的工作是主持，不是帮程序打工。

## 一、游戏概述

### 1.1 目标

《起闯战争》是 2 至 6 人的回合制乱斗。玩家在五大公共建筑之间移动、发育、
结盟、翻脸、演出并争夺综合评分。

终局并行记录两个答案：

- **最后存活者**：谁站到了最后；
- **综合评分第一**：谁把这一局打得最精彩。

两者可以是同一个人，也可以不是。死亡不把玩家踢出游戏：普通死者进入往世层，
继续押注和借出技能。只有 `absolute_dead` 什么都不做。

### 1.2 信息公开

这是高信息游戏。位置、HP、装备、护甲耐久、状态、先攻、SP、PP、案底与
大多数专属资源均公开。隐身只影响侦测与命中，不会把整张状态栏塞进量子叠加态。

### 1.3 玩家状态条

每名玩家至少显示：

| 项目 | 内容 |
|---|---|
| HP | 上限 `[待风洞]`，整数生命模型 |
| 外层护甲 | 每件护甲的属性与耐久（Armor 层） |
| 信用点 | 唯一经济资源，商店打工获得 |
| SP | `0 / 1 / 2` 演出准备度 |
| PP | 生死共通的演出积分，计入终分 |
| 装备与弹药 | 武器、护甲、道具、模块等 |
| 状态 | 灼烧、震荡、石化、屏障、爱愿、天赋标记等 |
| 天赋资源 | 追忆、魔力、火种、失熵、Cost、孤独值、色彩等，仅持有者显示 |

## 二、游戏准备与地图

### 2.1 开局

1. 每名玩家选择一个天赋，或全桌约定无天赋局。
2. 每名玩家从自己的**私人房间**开始，HP 满值，状态为"未起床"。
3. R1 的 T0：在私人房间免费起床，领取**初始包**：弓 + 初始箭矢（固定）+
   **小刀或盾牌二选一**（开局第一个决策；G0 以 AR 替弓，G7 水着起床额外得盾
   不受此影响）。
4. R1 的 T1：**必须 `move` 进入五大公共建筑之一**——商店 / 魔法所 / 医院 /
   军事基地 / 警察局。
5. **出门落锁**：本局不得再回私人房间。

最后这条解决了三件事：残局无躲猫猫死角，开局无出生点屠杀，RL 动作空间不再
因私宅动态膨胀。家是起点，不是保险箱，更不是终局掩体。

### 2.2 五大公共建筑

地图由五个可进入地点组成，任意地点之间移动消耗 T1 主行动槽，不检查相邻关系：

| 地点 | 主要功能 |
|---|---|
| 商店 | **全图唯一打工入口**、小刀、磨刀石、陶瓷护甲、隐身衣、热成像仪、力量模块、修甲、箭矢补给 |
| 魔法所 | 法术（1 回合学 1 个）、魔法护盾、魔法弹幕、火矢、魔导模块 |
| 医院 | 紧急治疗、便携急救针、无限模块、G7 专属药、终身一次三选一手术 |
| 军事基地 | AT 力场、电磁步枪、高斯步枪、雷达、隐形涂层、穿甲/冲击模块、钩索（直接购买，记案底） |
| 警察局 | 申请队长、举报、防暴编队驻地 |

### 2.3 地点摧毁

地点只有在明文最高级效果下才能被摧毁。当前来源是 G1 繁育的结构超新星：
地点获得永久 `destroyed`，所有幸存单位被驱逐至其他公共建筑（按先攻降序 +
actor ID 分配）。最后一个仍可站立的公共建筑不能被摧毁。警察局被毁后防暴
编队立即停机，案件与通缉全部失效。

## 三、回合结构：三拍子

### 3.1 全局轮次 R0–R4

每个全局轮次按固定顺序进行：

```text
R0  天赋 on_round_start；SP 夺台窗口开放；世界时钟与往世层开市
R1  所有正常玩家判定先攻（只决定顺序）；多名 SP=2 者竞争本轮公演位
R2  警察状态推进；防暴编队自动执法
R3  所有正常玩家依次获得一个标准行动槽
    T0：1 次免费小动作
    T1：1 次主行动
    T2：登记关注（→SP）；结算 StepFollowup 或 ExtraTurn
R4  天赋 on_round_end；持续效果 tick；世界时钟推进；胜负检查
```

**建立轮 R4 不 tick。** 状态在本轮建立，本轮 R4 不扣第一段；从之后第一个
R4 开始计时。石化、无人机、繁育、救世主、固有结界都服从这条，除非来源
明文说建立当轮开始计时。

### 3.2 T0：免费小动作

每回合限 **1 次**，不占 T1：

- 起床（仅首轮）
- 吃药（便携急救针 / G7 专属药）
- 磨刀
- 装卸弓模块 / AR 遗物切换
- 换形态（G1 着装/卸甲 / G7 更衣 / G4 主动升格）
- `lock` 锁定目标：本回合 T1 攻击无视目标移动闪避，并获得命中/破甲加成
- G2 声明本回合主控【光】或【影】
- 天赋明文归属 T0 的其他宣言

lock 不再是独立的根行动，它是一个开启攻击加成的准备动作。

### 3.3 T1：主行动

每回合 1 次，四大类动词：

| 动词 | 说明 |
|---|---|
| `move <地点>` | 移动到任意其他公共建筑；主动离开交战可能触发借机攻击 |
| `attack <目标> <武器>` | 攻击同地点显形单位（近战）或跨地点（远程）；同地点显形无需先 find |
| `interact <项目>` | 购买、打工、手术、学法术、修甲、补给等地点功能 |
| `special <操作>` | 天赋专属、装备特殊操作、战术宏等明文操作 |

`find` 退出日常行动表。同地点**显形**单位天然面对面，可直接攻击。
`search`（原 find）只用于揪出同地点的**隐身**单位。

### 3.4 T2：追击与额外行动

T2 有两种行动授予，上限严格：

**StepFollowup（单步战技追击）**：来源天赋明文派发，只能执行来源列出的动词，
没有独立 T0，不能即演或公演，不递归生成下一个追击。

**ExtraTurn（完整额外行动）**：重新执行完整 T0→T1→T2，允许 SP≥1 时即演，
但禁止公演。共同边界：

- 每名玩家每个全局轮次至多 1 个；
- 立即插入，不能储存或结转；
- 不递归生成另一个 ExtraTurn；
- 被控制消费后直接损失。

当前白名单来源：**T4 或跃在渊 / G5「地火」诗**。每轮多个候选时优先级固定
为 T4 or跃 > 地火，落选者丢弃。

M9 的七种追加通道（ActionGrant / restricted_followup / wake_followup /
chase_move / projection_chain / 战术宏复合容器 / grant_extra_turn）在此
统一收口为上述两种，不再单独追踪。

### 3.5 感知三态：不再花整轮 find

感知状态只有三种：**暴露（默认）/ 隐匿（隐身）/ 被锁定**。

- 同地点显形单位天然面对面，T1 直接攻击，无需先花一整轮 `find`；
- `search` 只用于揪出**隐身**单位，对探测装备/法术自动看穿隐身；
- 主动移动仍提供闪避加成（不是"进门即被秒"）；
- `lock` 是 T0 小动作，不再占整个 T1。

### 3.6 控制裁决

行动槽开始时按顺序处理：死亡/离场 → 压制 → 自我怀疑 → 睡眠 → 石化 → 震荡 → 正常行动。

| 状态 | 效果 |
|---|---|
| `SHOCKED` 震荡 | 下一槽只能有限移动、非敌对交互或放弃；槽收尾后移除 |
| `ACTION_SUPPRESSED` 压制 | 下一行动槽强制跳过 |
| `PETRIFIED` 石化 | 可放弃保持、花 1 SP 以 50% 概率挣脱（同槽至多 2 次），或挨两次有效伤害被动解除 |
| 睡眠 | 该槽只能唤醒 |
| 自我怀疑 | 该槽跳过，结束后按来源转化（G7 主要来源） |
| `SUBMERGED` 沉沦 | NPC 停机状态（G2《世末之雨》全场非玩家单位永久沉沦） |

普通控制共用一个控制位，优先级：压制 > 石化 > 震荡。睡眠与自我怀疑是
结构状态，不占控制位。

## 四、装备、信用点与地点经济

### 4.1 信用点：商店是唯一入口

- **商店打工**是全图唯一常规经济来源，每次 +`[待风洞]` 信用点；
- 医院打工在 V2.0-GA 中**已退役**；
- 白昼后击杀使死者背包、装备与剩余弹药掉在死亡地点，拾取消耗一个 interact；
- 没有被动收入。

### 4.2 武器

**弓**是标准跨地点武器，开局人人携带（G0 以 AR 替换）。基础伤害 `[待风洞]`，
箭矢上限 `[待风洞]`，商店补给一次 `[待风洞]` 支。

弓有两个模块槽：

| 模块 | 来源 | 作用 |
|---|---|---|
| 力量 | 商店 | 增加弓伤害 |
| 火矢 | 魔法所 | 改为魔法属性 + 灼烧 |
| 魔导 | 魔法所 | 增加命中 |
| 穿甲 | 军事基地 | 改为科技属性 + 降防御系数 |
| 冲击 | 军事基地 | 命中后击退；双装追加先攻惩罚 |
| 无限 | 医院 | 独占双槽，不消耗箭矢，只发普通箭 |

G0 专属 AR（BLACK FANG 465）不能装普通弓模块，有专属遗物改装槽，见 §10.1。

### 4.3 护甲：外层 Armor

外层护甲使用"属性防御 + 耐久"：吸收的伤害等量消耗耐久，耐久归零后破碎。
克制/匹配属性攻击对外甲耐久造成**双倍磨损**（属性克制机制，见 §五）。

| 护甲 | 主要属性 |
|---|---|
| 盾牌 | 普通 |
| 陶瓷护甲 | 普通 / 科技 |
| 魔法护盾 | 魔法 / 普通 |
| AT 力场 | 科技 / 魔法 |

V2.0-GA **删除**医院永久内层护甲（晶化皮肤 / 额外心脏 / 不老泉内甲手术）。

### 4.4 医院：删内甲、删病毒、三选一手术

保留 / 新增：

- **紧急治疗**：当场回血并清灼烧；
- **便携急救针**：限持 1 枚，T0 扎针 +4 HP `[待风洞]`；
- **无限模块**；
- **G7 专属药**：EPO / 海豚巧克力 / 肾上腺素。

V2.0-GA **删除**：晶化皮肤、额外心脏、不老泉三项永久内甲手术；释放病毒；
防毒面具；医院打工。

**终身一次·三选一终极改造手术**（手术费 = 清空全部信用点，下限 4）：

| 手术 | 效果 |
|---|---|
| 终极电力生命维护仪 | 最大 HP +8 `[待风洞]`；每 R4 若本轮未交战自动回 2 HP |
| 超频神经反射 | 常驻先攻 +1；`move` 落地后可再执行本回合尚未用的 T0 小动作 |
| 不老泉·内循环炉 | G1 失熵 / G3 魔力 / G0 烧血类天赋代价减免；每局限 2 次 T0 付 3 HP 换 +1 SP 或解控 |

手术费是"清空钱包"而非固定价格，意味着你要自己判断什么时候买。信用点
攒着不花在终局没有用武之地。

### 4.5 军事基地：通行证退役，案底登记

重型装备（AT 力场 / 电磁步枪 / 高斯步枪 / 雷达 / 隐形涂层 / 穿甲·冲击模块
/ 钩索）**直接购买，废除通行证回合税**。

代价改变形式：每次在军基 `interact` 取装备，自动写入**公开案底**。T6 可
凭案底远程挂通缉，防暴编队可合法集火。

持有【黑市通行证】（1 信用点，军基可购）：拿装备当轮不记案底。

### 4.6 灼烧与重伤

- 灼烧每层每 R4 造成 `[待风洞]` HP 持续伤害，上限 `[待风洞]` 层；
- HP 高于 0 且不超过 `[待风洞]` 时为重伤，承受对应范围的先攻惩罚；
- **病毒在 V2.0-GA 中已退役**（随医院改造一并删除）。

## 五、伤害、防御漏斗与死亡

### 5.1 三层防御漏斗

V2.0-GA 统一了防御计算顺序：

```
攻击伤害 A
  → 第 1 层 Barrier（屏障）
      警察防暴盾墙 / G3 七重圆环·剑阵 / G7 架盾 / T4 元亨利贞
  → 第 2 层 Armor（外甲耐久吸收）
      盾牌 / 陶瓷护甲 / 魔法护盾 / AT 力场 / G7 铁之荷鲁斯光环
  → 第 3 层 HP（生命与濒死）
```

攻击必须按序穿透每层，不能跳层直打 HP。

### 5.2 两阶段伤害

```text
A = max(0, round_half_up(base_damage × skill_core_multiplier
                         + attacker_flat_bonus − weakness))

H0 = A + vulnerability − flat_damage_reduction − E   （E = 属性防御 × defense_coefficient）
H  = max(H0, 0)    （V2.0-GA 删除 25% 擦伤下限公式）
```

`A=0` 只来自明文攻击归零白名单，不消耗护甲或掩体。

### 5.3 属性克制：双倍碎甲

克制/匹配属性攻击对目标外甲耐久造成**双倍磨损**（不是双倍 HP 伤害）。
碎甲瞬间溢出伤害全额贯通进入 HP；同时攻击者获得 **+1 SP** 与 **+1 PP**
（破甲高光奖励）。

### 5.4 `DIRECT_DAMAGE`

令目标侧直接 H=A，跳过属性防御/护甲/普通固定减伤。仍可被明文替身、
重定向、绝对免疫或掩体承接。**不自动等于绝对死亡**。

### 5.5 Death Gate：濒死三顺序

致死结果按以下顺序处理：

1. **absolute_death**：直接绝对死亡，跳过后两层；
2. **形态转折**（Morph）：G1 繁育 / G4 救世主 / G0 调整呼吸 / G7 战斗续行；
3. **外部复活**（Resurrect）：T7 保险承接。

### 5.6 普通死亡与绝对死亡

**普通死亡**：SP 清零，进入往世层；战果分与剧情分**不打折**（铁律 1，
死后分数照常计入）；已达成第 3 章则当场锁分。

**绝对死亡（absolute_dead）**：跳过普通免死与复活；不进入往世层；
PP 冻结，不衰减也不能再花；装备照常掉落。

当前绝对死亡来源：G4 死星天裁、G7 Terror 攻击、G1 繁育倒计时归零。

### 5.7 有效伤害

以下任一成立才算一次有效伤害：H≥1 进入本体 HP；或一件护甲/掩体耐久归零。

## 六、SP、夺台与演出

### 6.1 SP：能力层级，不是货币

| SP | 权限 |
|---|---:|
| 0 | 正常行动，不能主动演出 |
| 1 | 可以即演（−1 SP） |
| 2 | 可以即演，或参与夺台竞争 |

SP 不交易、不计分、不兑换，也没有"这招打折便宜点"的临时议价。
死亡时 SP 清零，普通复活从 0 重新开始。

### 6.2 怎样得到 SP：关注

**关注**是公开事件把你登记为焦点或发起者，每次有效关注使 SP+1，上限 2；
每人每全局轮次通过关注至多实际 +1，下个 R0 重置。

| 事件 | 谁取得关注 |
|---|---|
| A 攻击 B | B 为焦点，A 为发起者；各自检查本轮额度 |
| A 对 B 执行高影响行动 | B 为焦点，A 为发起者 |
| A 犯罪 | A 为发起者；有受害者时受害者为焦点 |
| 承受环境/世界时钟伤害 | 受影响者为焦点，无发起者 |

已经 SP=2 时事件仍写日志，但不加到 3；若之后花掉 SP，本轮之后第一次关注
仍可使 SP+1。

### 6.3 夺台：崩铁式插队（废除 FIFO 报名队列）

每轮仍只有 **1 个全局公演位**。两个夺台窗口：

**窗口一（R1 先攻排定后）**：多名 SP=2 的玩家按先攻值竞争；先攻相同时
可消耗 PP 重掷先攻争取优先。胜出者取得本轮公演位。

**窗口二（回合中被推至 SP=2 的瞬间）**：若本轮公演位尚未被消费，可立即
插队，提前消费自己本轮的标准槽（本轮已行动者顺延到下一轮轮初）。

夺台的本质是**提前消费自己本轮的标准槽**，不是凭空多一次行动。

### 6.4 演出类型

| 形态 | 时机 | SP 消耗 | 是否占聚光灯 |
|---|---|---|---|
| 即演 | 自己任一合法 T0 | −1 | 否 |
| 公演 | SP=2 且取得本轮公演位 | −2 | 是 |
| **大即演** | T0 宣言，明文标注 | −2（或追忆代替） | **否**（强化即演，不抢台） |

**大即演**是 V2.0-GA 新增区分：G2 全部演出与 G5 讲故事/献诗属于大即演，
不占聚光灯，不可崩铁式插队夺台，但强度不低于公演。区别在于入口，不在于强度。

### 6.5 落幕

一次性天赋永久兑现后进入落幕：该天赋不再因关注取得 SP，不能再演出；
但玩家本人仍正常行动。T7 保险兑现是当前典型来源。

## 七、计分：打出来的分

### 7.1 终分骨架

```text
终分 = 战果分 + 高光分 + 终幕王冠
```

**战果分**：击杀数 × 击杀权重 + 有效伤害/破甲 × 伤害权重（`[待风洞]`）

**高光分**：完成的剧情章数 × 章节权重 + 剩余 PP（`[待风洞]`）

**终幕王冠（+`[待风洞]`，最后存活者专属）**：必须 ≥1 击杀**或** ≥2 章剧情
才能戴上。0 击杀且 <2 章的庸碌幸存者得 0。

### 7.2 死后不打折

V2.0-GA **删除** `1.5 / 0.5` 生者/死者存活乘数与槽位天赋乘数。
生前取得的战果分与剧情分，死亡后照常计入，不缩水。

活着本身不再值钱，打出东西才值钱。

### 7.3 第 3 章锁分

任何角色完成自己第 3 章弧光，当场锁定已获分数：此后死亡不影响这部分分数，
不参与任何形式的折扣。

## 八、警察：防暴编队

### 8.1 从三个 NPC 到一支军队

V2.0-GA 删除 3 个独立警察 NPC 的寻路与逐个指挥，以及 4 类证据报案链。

**平时**：治安小队驻守警察局；目击/受害者/T6 热线可挂通缉；每轮 R4 对通缉
犯执行齐射。

**队长就任**：合法玩家在警察局申请后，下一 R2 就任。特警编入随身
**【防暴编队】**，随队长同地点移动，不再逐个搬运。

### 8.2 两个姿态（T0 免费切换）

**防暴盾墙（防御）**：在队长正面建立 Barrier（每存活特警 4 点 `[待风洞]`）
+ 全军蓄力齐刺（伤害随特警数 +1/人 `[待风洞]`）；**架盾期间本轮不可 `move`**
——死战不退，因为编队结构决定了退不了。

**火力压制（机动）**：正常移动；队长攻击时特警协同合击。

### 8.3 破阵途径（反制设计）

这是刻意给出的，不是规则漏洞：

- 范围 AOE 同时刮特警与队长（盾墙不挡 AOE）；
- 震荡 / 钩索 / 闪光弹强制瓦解盾墙姿态；
- 命令特警攻击无辜者 → 威信反噬 → 特警哗变减编。

### 8.4 通缉与案底

案底：目击、受害者、T6 市民热线均可写入。军基取装备自动写入案底（见 §4.5）。

被挂通缉后：防暴编队在 R4 自动对通缉犯执行合法集火。通缉只因目标死亡、
队长合法解职、警察局被毁或 T6「律法」诗覆写而结案。

## 九、往世层：三个按钮

### 9.1 从二十六张牌到三个按钮

V2.0-GA 删除 26 种独立攻防魂援表。往世层不需要背诵任何新内容，因为它的
三个权能都基于你已经知道的东西。

### 9.2 权能一【押注】

死后选 1 名生者为选中之人，其每次击杀 / 破甲 / 夺冠时按比例分红。押注是
纯粹的投资行为，你没有能力控制那个人的决策。这一点在残局尤其明显。

### 9.3 权能二【微光】

每轮花 2 PP，从三个按钮里选一个，零新增背诵：

- **赐福**：目标 +3 临时屏障（Barrier 层）或回 2 HP `[待风洞]`；
- **启示**：目标先攻 +2 且 +1 SP；
- **凝视**：目标破隐（自动看穿隐身）+ 下次受击 +2 `[待风洞]`。

生者也可付 PP 向死者求援，方向是双向的。

### 9.4 权能三【Encore 英灵凭依】

每名死者整局 1 次，把生前 1 SP 即演的核心效果借给 1 名生者（神代借 7 枚简
化标记，见 §十二）。直接复用既有技能，不创造任何新文本。

## 十一、原初天赋 T1–T4、T6–T7

V2.0-GA 没有 T5。原 T5 槽位已转为 G0（神代零号），T5 combo 的一切不迁入
本 profile。以下六人是本版基线对齐快审后的结果，骨架保留，接口更新。

### 11.1 T1「一刀缭断」

一句话概括：一次很不讲道理的近战攻击。对象是同地点、已显形的目标（无需
先 find），需持有合法近战武器。

核心：`skill_core_multiplier=2`，额外对目标外甲造成**双倍碎甲磨损**（对齐
三层漏斗，碎甲溢出伤害全额贯通）。护甲、掩体、命中与死亡结算正常进行。

- **1 SP 即演**：消耗 1 SP，结算完整核心；
- **2 SP 公演（可崩铁式插队）**：公演特权——本次斩击**无视目标第 1 层 Barrier**，
  一刀连盾带人劈开；开放往世层 Encore 与「游侠」诗追演。

「游侠」诗：下一次 T1 斩击可无视距离 chase-move 到任意已 lock 目标面前出刀；
若这一刀击碎外甲或完成击杀，返还 1 SP。

### 11.2 T2「剪刀手传奇一突牢玩家」

T2 的几条常驻身份：

- 伤害玩家但未杀死，不视为犯罪；
- 每第 2 次击中外层护甲时，按原规则修复自己对应外甲；
- 击杀数为 0 时，攻击不解除自身隐身；
- 1 SP 即演对同地显形目标直接攻击；2 SP 公演先 `move` 追到目标地点再攻击。

**暗影步（如影随形）**（V2.0-GA 更新，对齐基线铁律 4）：当与 T2 同地点的
目标主动 `move` 离开时，若 T2 持有 ≥1 SP，可选择消耗 1 SP——立即跟进移动
到同一目的地，并自动对目标挂 `lock`。**每局限 2 次**。

旧追猎反应（免费 find/lock）随基线铁律 4（同地显形免 find）贬值退役，以
暗影步替代。

「地火」诗：立即获得 1 个 ExtraTurn；立即进入隐匿；重置本局暗影步触发次数
至满额（2 次），且下一次暗影步无需消耗 1 SP。

### 11.3 T3「天星」

**1 SP 即演【玉璋护盾 / 地心岩脊】**（T0 宣言，不占 T1）：耗 1 SP，为自己
展开一层岩障（Barrier 层，耐久 `[待风洞]`），并对同地点随机 1 名敌人造成
1 点震波外甲磨损。填补 SP=1 时的空白期。

**2 SP 公演【天星】**（可崩铁式插队）：在当前地点对除己外所有合法单位造成
无属性穿防 AOE（`defense_coefficient=0`，仍受普通减伤/护甲/掩体约束，不是
`DIRECT_DAMAGE`）并施加**石化**。盟友也会吃，所以请在天星下落前确认队友不
在覆盖范围内。

石化者 T0 可：放弃本槽保持；花 1 SP 以 50% 概率挣脱（同一槽至多 2 次）；
或等待两次有效伤害被动解除。

「群星」诗：场上由该 T3 施加的石化升级为**尘世之锁**（不再因受击解除，只
能自行挣脱或到期）；立即为 T3 免费套满额玉璋护盾；下一次天星后额外弹射
2 颗无属性穿防流星。

### 11.4 T4「六爻」

选择另一名玩家猜拳，按组合结算六种结果。无使用次数限制，只检查 SP 与入口合法。

| 组合 | 卦象 | 效果 |
|---|---|---|
| 双剪刀 | 潜龙勿用 | 对目标造成穿甲伤害 |
| 双石头 | 飞龙在天 | 复制目标一件外层护甲（不破坏原件） |
| 双布 | 元亨利贞 | 免疫伤害与 debuff 至下一 R0（= 顶格 Barrier） |
| 剪刀/石头 | 亢龙有悔 | 禁用一件非拳击武器；无可禁则震荡 |
| 剪刀/布 | 或跃在渊 | 当轮获得 1 个 ExtraTurn（基线白名单来源） |
| 石头/布 | 群龙无首 | 清除被发现/锁定并隐身；对手传送到随机建筑 |

**2 SP 公演特权（可崩铁式插队）**：同时对**两名**目标起卦（对两人各自独立
猜拳结算），核心翻倍。改判（自选结果）方向已否决——那会让猜拳博弈失去意义。

「阴阳」诗：获得 2 层「阴阳的天机」，下两次发动六爻时无需猜拳，直接钦定
一种卦象（除或跃以外的五种）必定生效。

### 11.5 T6「朝阳好市民」

T6 的完整警察系统规则见第八章。演出快查：

**被动【特别线索】**：进入他人房间、无许可进军基、释放病毒（已退役，不再
适用）等事件写入公开案底；T6 死亡后线索仍保留，但只有存活/复活的 T6 能使用。

**T0 小动作【市民热线】**：场上有犯罪写入案底后，T6 可在 T0 免费挂【全城
通缉】（不占 T1），无需到警察局，被通缉者成为防暴编队合法集火对象。

**演出【联防军需整备】**：
- 1 SP 即演：为防暴编队整建制升级一项（高斯齐射阵列 / 盾墙耐久强化 / 补充 1 名阵亡特警编制）；
- 2 SP 公演（可插队）：整建制升级 + 若场上无队长，可直接呼叫防暴编队空降
  当前建筑，执行一次齐射执法或立起盾墙。

「律法」诗：若警察局曾被摧毁停机，直接重建并唤醒防暴编队；立即补满 3 名
特警满编并全员升级最高阶装备，空降至 T6 所在建筑，免费执行一次全军蓄力
齐刺或满额防暴盾墙。

### 11.6 T7「死者苏生」

即演或公演时，公开选择一名存活玩家（含自己），挂载全局唯一的**复活保险
伏笔**。无需去魔法所学习，无地点限制。T7 死亡后已挂好的保险仍存在。

目标普通致死时按顺序结算（Death Gate 第三层）：
1. `absolute_death` 来源：保险不赔付；
2. 目标自身明文免死效果优先；
3. 否则保险承接，在家 / 结算位置 / 最近安全地点复活，HP `[待风洞]`，SP=0；
   保留物品，恢复可再生护甲；击杀与犯罪关系取消，PP/评分视为未死亡。

兑现后伏笔消耗，T7 天赋永久落幕。

**补 1 SP 即演【生者的祝祷】**（填补挂保险后/落幕后的白板期）：当场上已有
保险伏笔或保险已兑现落幕时，T7 可耗 1 SP 为任意目标立即回 3 HP `[待风洞]`
并清除负面状态。

「彼岸」诗：若保险未触发——目标因保险复活时 SP 置满为 2，并免费获得一件
护甲与近战武器；若保险已触发——直接**重启 T7 天赋，为其挂上第 2 枚复活
保险**。

## 十二、神代天赋 G0–G7

神代天赋是 V2.0-GA 的设计雄心所在。它们不是"比原初天赋更强的按钮"，而是
八种叙事前提不同的规则系统，共享同一个战场。每个角色使用完全不同的资源
语言（火种 / 魔力 / 追忆 / Cost / 孤独值 / 色彩 / 笑点 / 失熵），彼此不通用、
不可转换，但相互之间有预置的交叉影响点。

认知复杂度很高。开桌前请确认大家愿意看别人演出，而不是只愿意看自己赢。

### 12.1 G0「我还欠她们一个明天」——砂狼白子*Terror

来自另一条时间线的阿拜多斯。燃烧生命战斗的孤独枪手，背负逝去同伴的遗物。

**BLACK FANG 465（AR）**：开局以 AR 取代弓，箭矢按 1:3 转化为子弹（初始
15 / 上限 30 `[待风洞]`）。两种射击模式：

- **点射（1 发）**：基础伤害；
- **全自动扫射（3 发）**：本次伤害 +2 `[待风洞]`，且额外削减目标 2 点外甲
  耐久 `[待风洞]`。

AR 不能装普通弓模块，有专属双**【遗物改装槽】**，T0 小动作切换挂载。

**阿拜多斯遗物（开局自带 4 件）**：

| 遗物 | 挂载效果 |
|---|---|
| 星野的破裂圆盾 | 每轮获得 2 点临时屏障；场上有 G7 时另有羁绊加成 |
| 野宫的机枪弹链 | 全自动扫射附带溅射，刮擦同地点另一随机敌人 |
| 芹香的瞄准挂件 | AR 攻击视为已 lock（无视移动闪避 + 破甲加成提升） |
| 绫音的破碎眼镜 | 自身因技能烧血后，每 R4 缓回 1~2 HP |

**1 SP 即演【深渊无人机·神秘协同】**：消耗 1 SP + 当前 HP 的 20%（向上取整，
最低 1，不致死）；T0 部署不占 T1。无人机持续 3 个未来 R4 tick，随 G0 移动，
可被攻击（不算犯罪）。无人机在场时 AR 射击转为**神秘属性**——对一切普通/
魔法/科技外甲均触发克制（双倍碎甲）；每枪协同追加 +1~2 `[待风洞]`。

**2 SP 公演【黑洞·十字炮火】**（可崩铁式插队）：入口需无人机在场；消耗
2 SP + 当前 HP 的 30%（最低保留 1 HP）。对当前建筑内除 G0 外所有敌对单位
造成 `DIRECT_DAMAGE`（恢复真伤口径，撤销风洞"普通属性必中"修正，不再自伤）。
无人机释放后消失（超载自毁）。

**遗物绝唱（可选）**：释放时摧毁 1 件挂载遗物，附赠绝唱——
星野盾 → 震荡全场 + 自身屏障拉满；野宫弹链 → 炮火伤害翻倍；芹香挂件 →
炮火必中且破甲强化；绫音眼镜 → 炮火结束后将自身 HP 抬回安全线。

**调整呼吸（Death Gate · 最后的 15 秒）**：每局 1 次；普通致死触发
（`absolute_death` 不触发）。锁 1 HP，清除普通控制；2 个全局轮次内免疫普通
攻击伤害（仅 `absolute_death` 可斩杀）。期间子弹装填免费，造成的有效伤害
按比例转化为自身 HP（吸血比例 `[待风洞]`）。2 轮结束 HP ≥ 6（30%，`[待风洞]`）
→ 逆转成功继续战斗；否则撤退。

**撤退（体面谢幕）**：不算被击杀（不产生凶手人头），不进往世层；PP 冻结；
战果分/剧情分 100% 全额保留（V2.0-GA 无生死乘数）；已达成第 3 章则满额锁分；
计入"玩家出局"事件（G7 色彩 +2）。

**第 3 章弧光「我还欠她们一个明天」**：本局内挂载/过载过全部四件阿拜多斯
遗物，且轰出过十字炮火（条件 `[待风洞]` 细化）。

**G5「明天」诗**：黑子打工信用点额外 +1，所有商店/医院/军基消耗 −1（最低
1）；下一次十字炮火不消耗自身 HP，且可同时过载触发 2 件遗物绝唱而不摧毁任
何遗物；若释放时正处于调整呼吸，立即恢复 6 HP 跨过止损线。

### 12.2 G1「火萤·燃烧循环」——流萤 / SAM

最后的格拉默铁骑，失熵症少女。**燃烧就是在死**——卸甲调息与着装参战的
风筝循环，以及必死的第三次死亡。

**三态阶梯（单向上行，可跌落）**：

| 形态 | 进入 | 失熵速率 | 行为约束 |
|---|---|---|---|
| 卸甲常态「流萤」 | 起始态 | 慢速 | 攻 −1 / 受击 +1 / 命中惩罚；可发育 |
| 次级燃烧「SAM·着装」 | T0 宣言，1 SP | 中速 | 禁 find/interact；解锁超新星 |
| 完全燃烧 | 2 SP 公演（须次级） | 最快 | 窗口 3 轮；T2 StepFollowup(allowed=[move,attack]) |

卸甲不是安全，只是更慢地死。每 R4 失熵缓慢累积，不暂停；本行动回合无攻击
类行动则 R4 失熵回落（唯一常规回落通道）。

**失熵量表**：0 起步、有上限的公开量表。达阈值 → 当轮 R4 触发结算，随后
回落（不清零——疾病不会痊愈，只是压回一段）。结算顺序（三层漏斗 Armor 层）：

1. 持有炽愿可消耗 1 层完全抵扣；
2. 否则摧毁 1 件自选外甲；
3. 无外甲时扣 HP——卸甲的她被失熵直接啃食血肉。

失熵结算不构成"受到攻击"，不触发反击/关注/犯罪。

**终焉环境抗性（V2.0-GA 分档）**：着甲态 100% 免疫终焉灼伤（含 G2 炉心融解
翻倍后的双倍终焉）；卸甲态减免 50% `[待风洞]`。这对应星核猎手的使命——
应对虚无导向的终末结局。G2 炉心融解后的双倍终焉核冬天里，只有着甲的萨姆
毫发无伤。

**DHGDR-超新星过载**：形态门槛次级及以上。获取：进入次级 +1，完成击杀 +1，
上限 1。发动：`move` 根行动触发（落点可为当前地点），对落点内除己外玩家与
警察造成 AOE 伤害 + 穿甲 + 挂灼烧（普通属性 + `defense_coefficient` 折减）。

**超击破近似**：次级及以上形态，对受控（震荡/压制/石化）或灼烧/虚弱单位
攻击获得固定加值 `[待风洞]`。自洽循环：超新星挂灼烧 → 后续攻击吃增伤，
不依赖队友。

**第三次死亡（繁育）——3 轮必死倒计时**：

触发：每局 1 次。**本局曾开启过至少 1 次完全燃烧，且当前处于 ≥ 次级燃烧状态
时受到第一次普通致死伤害** → 必定触发（无概率骰）。`absolute_death` 来源
直接杀死，不入繁育。防开局碰瓷：没开过完全燃烧就没有第三次死亡；触发权
部分在对手（可以不打死她）。

内容：倒计时 3 轮（建立轮不 tick）；归零 = **绝对死亡**（进白名单，绕过一切
免死/复活/T7）。繁育期间再次普通致死 = 正常死亡（星核只有一枚）。

**繁育态效果**：
- 高先攻加成 `[待风洞]`；
- 每轮首次合法 `move` 触发**结构超新星**（不读 SP、不占公演、不耗过载）→
  结算后**永久摧毁落点建筑**（缩圈；警察局被毁同步停机；最后安全地点兜底
  保留）；幸存单位按先攻降序 + actor ID 驱逐至未毁公共建筑；
- **ATK 提升**：在完全燃烧基础上再上探 `[待风洞]`；
- **普通控制免疫**：免疫震荡/石化/失神（世界法则级如 G5 时间倒流仍生效）；
- **击杀再动（流萤二命复刻）**：繁育期间在自己回合内完成击杀，立即额外获
  得 1 次行动（每全局轮限 1 次）——无破韧概念，以击杀代替二命。

**胜利判定优先于倒计时**——为生而战打到最后一刻赢下来，是她能得到的最
好结局。

**炽愿**：超新星每命中 1 单位 +1，每击杀 1 单位额外 +1，上限 `[待风洞]`。
用途二选一：抵扣 1 次失熵结算；或受击时充当临时 HP。

**G5「飞萤」诗**：
- 分支 A（G1 未进繁育）【仲夏夜的烟花】：立即免费开启一次持续 2 轮的【完全
  燃烧·无垢】——不需 2 SP、不占聚光灯；享受火力加成、R0 自愈与 T2 追击，
  但**期间失熵增长为 0**，窗口结束退回常态且不触发强制失熵结算；
- 分支 B（G1 已处于繁育 3 轮必死倒计时）【以流萤之名活下去】：立即抹除
  必死倒计时，HP 恢复至 12 `[待风洞]`；代价——萨姆机甲消散，本局永久失去
  次级/完全燃烧/超新星能力，同时永久治愈失熵（量表移除）并抹除卸甲常态的
  负修正。她不再是格拉默的铁骑，而是一个健康的普通女孩。

### 12.3 G2「请一直，注视着我」——歌者×凡人

三句定场诗：

不清零、无上限，只比多少——这是你整场对局的累积历史，不可悔棋。

**1 SP / 2 SP 演出（大即演，永不占聚光灯）**：G2 永远不报名公演，她的 2 SP
是强化即演。T0 主控声明决定可选演出：

**A（对光）·擦肩的驻足**：光瞬移到影的坐标；双方获得增益（回 HP / 屏障
`[待风洞]`）；孤独 −1（2 SP 版 −2）；**T1 强制只能 `move`**——短暂驻足后，

**B（对影）·唱着无人问津的歌**：孤独 +1（2 SP 版 +2）；对影所在建筑所有

### 12.4 G3「神话之外」——士郎

英灵卫宫的投影魔术与固有结界——「神话之外」= 无限剑制。母题：以魔力换
取时间；剑之丘陵的持续齐射，不是一发爆气。

**魔力与 SP（职责分离）**：魔力支付投影、维持与超限；SP 决定何时展开固有
结界——两者不互相替代。开局 `magic_initial` `[待风洞]`，上限 `magic_cap`
`[待风洞]`，结界外每 R0 恢复 `magic_recover_r0` `[待风洞]`（唯一常规恢复入口）。

**结界外投影（T0 减负）**：非攻击型持续投影为 **T0 小动作**，支付对应魔力，
不占 T1：

- **七重圆环（Rho Aias）**：T0 展开，登记为三层漏斗第 1 层 Barrier——远程
  直接攻击先打圆环，击破当次不向本体溢出；
- **双刀·守势**：T0 建立防御标记，下一次以 G3 为目标的攻击取得固定减伤后
  消耗（`DIRECT_DAMAGE` 消耗标记但跳过该减伤）；
- **见证与复制**：见证过的普通武器家族可付魔力投影基础型（只复制基础伤
  害/属性/射程，不复制模块/弹药/蓄力/专属标签）；结界外只维持**一个持续
  投影通道**，新 T0 投影成功后旧持续投影在该回合收尾清理。

**攻击型投影仍为 T1 攻击根**：
- **螺旋剑（伪）**：远程攻击根，创建并立即发射；
- **双刀·攻势**：近战攻击根，以合法近战武器为基础 + 固定加值。

**1 SP 即演**（补 M9 空缺）：
- **鹤翼三连（近战双刀）**：1 SP，本次双刀获得固定加值；命中外甲时触发连携
  追击——额外磨损外甲耐久且必中；
- **伪·螺旋剑（远程狙击）**：1 SP + 魔力，跨地点轰出一发**无视掩体/屏障**
  的高爆穿甲螺旋剑。

**2 SP 公演【无限剑制】**（可崩铁式插队展开）：当前地点被替换为固有结界。

**展开即剑丘**：剑阵**自动常驻**（G3 攻击获命中加成 + 每轮第一次以 G3 为
目标的远程直接攻击被剑阵 Barrier 拦截）；已见证的复制武器自动进入**兵装池**，
随取随用、免创建行动与魔力。

**捕捉**：当前地点全部存活玩家 + 敌对/中立 NPC；警察不进入（案件挂起）；
外部世界继续推进；内外不能跨边界交互。

**主目标**：展开后公开指定 1 名存活被捕捉单位（幻想崩坏的唯一合法目标；
每个 T0 可免费改选；死亡/离界即清空）。

**结界锚点与破界**：被困者可用普通武器攻击根打锚点（按 A 扣结构耐久），
或 `break_barrier` 稳定扣耐久（占整个标准行动）；锚点归零 → 强制解除，未
行动者回原地点后仍按原顺序行动。

**维持费简化**：每 R4 支付固定魔力维持费（建立轮不 tick；固定值与最长持续
轮数 `[待风洞]`，建议 3 轮）——砍掉 M9 五项加法公式。

**宝具连发与赤原猎风**：

- **`projection_chain` 宝具连发**：结界内螺旋剑根行动首发结算后，可支付递增
  魔力在同一根行动内连射（段数上限 `[待风洞]`）；每段独立预检/结算；
- **累计耗魔计数器**：每根行动独立累计实际支付的投影魔力，达阈值后——
- **赤原猎风**：自该次起、本根行动内后续命中玩家单位的释放附加即时效果：
  **目标 SP −1（下限 0），且目标本全局轮无法触发受击满能量插队公演**（对
  齐基线铁律 5，替代 M9 公演队列移除）；频率闸：每名玩家每次结界至多一次；
- **回路接通**：触发赤原猎风 → **理想燃烧自动点亮** → 可在同一根行动末尾
  无缝衔接终段幻想崩坏（不再需要打卡凑式样数）。

**幻想崩坏**：消耗全部剩余魔力 + 牺牲兵装/防壁/剑阵；对主目标结算一次统一
攻击：伤害 = `collapse_base_damage + collapse_per_style × 本次结界累计式样数`
（式样自动累计）；普通属性 + **强力破甲**（对齐三层漏斗，非 DIRECT_DAMAGE）；
结算完成后无条件解除结界。也可不终结保留结界（维持费照付），此后独立发动
幻想崩坏（需 `collapse_terminal_min_magic`）。

**G5「永恒」诗**：立即为 G3 恢复 4 点魔力（可突破上限转为临时魔力）；下一
次固有结界内，螺旋剑【宝具连发】首段免费（0 魔力）且连发上限 +1 段；展开
时照常指定 1 名被捕捉单位首槽震荡。

### 12.5 G4「愿负世，照拂黎明」——白厄

白厄 / 卡厄斯兰那——「以旧日余烬为来世破晓，烈阳撕裂长空」。母题：永劫轮
回里的英雄。与 G2（盗火×白厄双生）、G5（时间倒流 ∞）共同构成轮回叙事轴。

**资源：火种（上限 12）**——只在人形态积累。三条途径：

| 来源 | 条件 | 增量 |
|---|---|---|
| 受难之火（被动） | 人形态承受他人有效伤害（HP 损失或外甲破碎） | +1；每轮受击类至多 +2 |
| 逐火之剑（1 SP 即演「夺火」） | 人形态消耗 1 SP 发动斩击；命中或破甲 | +2 |
| 余烬共鸣（环境） | 场上其他玩家阵亡，或建筑被摧毁 | +2 |

不计入：DOT 后续 tick、环境/世界时钟伤害、自我消耗。撤销风洞修正
"敌对外来火种 1→0"——白厄的核心是用血肉扛下世界的恶意，受击攒火必须恢复。

**进入救世主形态（两条路径）**：

**主动升格（完整救世主）**：火种 = 12 且人形态；任意 T0 小动作主动燃尽全部
12 火种（不占 T1）；升格后可按公演入口（含崩铁式插队）直接携 2 SP 上舞台。
升格瞬间 SP 置满为 2；获得**余烬生命**（护体血条 `[待风洞]`）；初始毁伤 3。

**濒死转折（残缺救世主）**：人形态遭普通致死且持有火种 ≥ 门槛（建议 4~6
`[待风洞]`）；消耗当前全部火种进入残缺形态；余烬生命与初始毁伤按消耗火种
量缩放（初始毁伤 1 起步）。火种 < 门槛 → 正常死亡（不拦截，杜绝 0 火种碰
瓷）；`absolute_death` 来源直接杀死。

M9 的"负世主动燃尽派发完整额外行动"**退役**——升格不创建额外行动槽。

**救世主形态（3 轮极境燃烧）**：持续 3 个未来 R4 tick（建立轮不 tick）；
形态内不再获得火种；毁伤为形态内局部预算，退出清空。

**强化普攻**：占标准根行动，不耗 SP；命中造成高额伤害且毁伤 +2；T2 附带
【烈阳余波】对同地点其余敌人溅射磨损 `[待风洞]`。不做无条件扩散，不复制
十六次弹射拓扑。

**2 SP 公演【灾厄·弑魂焚诏】**（可崩铁式插队）：消耗当前全部毁伤 D，天裁段
数 = D。结构：

```text
全桌秘密承诺「迎战 / 拒战」
→ 迎战者按先攻降序逐个执行 challenge_response（受限反应，非完整行动）
→ 对迎战者的统一反击池
→ 对拒战者的死星天裁池
→ 公演收尾
```

- **迎战者**：公演临时解决距离/面对面；以自身合法攻击中最优载荷攻击 G4；
  每完成 1 次合法挑战，天裁段数 −1；不产生犯罪/SP/关注/警务额度；
- **拒战者**：平摊剩余段数的死星天裁总池（`DIRECT_DAMAGE`；致死结果附
  `absolute_death`）；
- **固定总池**：反击与天裁都按总池均分，不按人头复制；分配顺序按先攻降序、
  actor ID；
- **强制中断**：挑战攻击迫使 G4 退出形态 → 停止后续响应，取消反击与天裁，
  转入退场清理；
- **隔离边界**：不穿透结界类隔离（G3 重做后沿用"不穿透隔离层"原则）。

这是一个复合博弈：迎战有风险（你要攻击救世主），但可以降低其他人的天裁
压力；拒战更安全，但集体拒战会让天裁集中到所有人头上；合力抗争（全部迎
战）可通过强制中断退出形态彻底规避天裁。这不是简单的打 BOSS，而是全桌
的利益协商。

**退场**：天裁结算后 / 3 tick 到期 / 余烬血条被打空 → 退出形态，火种归零，
回人形态（可再次逐火）。第 2/3 章弧光与锁分沿用基线铁律 1。

**G5「负世」诗**：人形态立即 +4 火种（无视每轮受击上限）；救世主形态立即
+4 毁伤；**【永劫的烈阳】**：白厄进入救世主形态后，3 轮倒计时**冻结**（只
要余烬生命未归零，形态永不因回合到期退出），且救世主攻击额外附带烈阳火伤；
**代价**：救世主形态存续期间，每个 T0 自动给自己挂 1 层【灼烧】（R4 真实
扣血，不可被常规净化免疫）。

**宿命联动**：白厄常驻灼烧 → 恰好被 G1 流萤的超击破（对灼烧目标增伤）克
制——兑现"G1 与 G4 相互 counter"的原始设计。

### 12.6 G5「往世的涟漪」——昔涟 / 德谬歌

机制原型：ASBR 恩里克·普奇（最终）三阶演进——白蛇 → C-MOON → 天堂制造。
叙事轴：哀丽秘榭的小昔涟 → 黄金裔的同行者 → 记忆星神·德谬歌。

硬约束：昔涟不是死神，是执笔记录、陪伴、最后以自身走向过去换来明天的人。
压制开拓不是她做的事；手填 K 步脚本废除（RL 时间债不可接受）。

**资源：【追忆】**：场上高光事件（破甲/公演/阵亡）+1；T0 小动作「执笔」+1；
上限 `[待风洞]`。追忆不是 SP，不交易、不计分，只驱动昔涟自己的三阶段。

**阶段一「哀丽秘榭的讲述者」（开局态）**：正常 20 HP 入场，可正常移动/交互/
攻击。演出【讲故事】（2 SP 大即演，不占聚光灯）：选择同地点一名其他玩家——
自己追忆 +2；目标 **SP 置 0**，同时 **HP +1**（温柔的抚慰：废掉其爆发，又
给一口防斩杀的奶）。

**进阶**：追忆 ≥ 6 且支付 1 SP（T0），升入阶段二。

**阶段二「黄金裔的同行者」（C-MOON 式纯数值）**：常驻被动【记忆的重量】——
追忆层数直接加常驻 ATK / DEF（换算率 `[待风洞]`）。演出【此诗，献予一切生
命】（基础 2 SP；**每少付 1 SP 可用 2 层追忆代替**：2 SP / 1 SP+2 追忆 /
0 SP+4 追忆；大即演，不占聚光灯）：

- 对他人：授黄金裔诗篇强化 + 挂【爱愿】（期间目标不能伤害昔涟；昔涟攻击
  则破碎）；
- 对自己：咏唱「爱与记忆」，对至多 n 目标射科技/普通/魔法/无视属性多段箭
  （n `[待风洞]`）。

**停在阶段二平推是完全成立的玩法**——对应"不上天堂制造也能赢"。

**阶段三「我的明天叫做昨天」（记忆星神·德谬歌）**：

升格条件：追忆 ≥ 12 且支付 2 SP，走基线公演插队夺台（全游戏世界法则级聚光
灯时刻）；瞬间**斩断当前全局轮次**：本轮先攻排在其后的未行动者，其行动槽
被抹去。

**时间倒流（历史动词倒放）**：世界时钟停止向前，改为**逐轮倒放**：倒流指
针从 R_{N-1} 起递减。每轮 R0 公布所有存活玩家在对应历史轮次执行过的**根行动
动词**（move / attack / interact / special 四大类）。除德谬歌外，每名玩家本
轮必须执行与历史相同的动词类型（具体对象/地点/武器自由重选）。

**违逆命运惩罚（逐层叠加，满血满盾也扛不住连续忤逆）**：
1. 第 1 次：震碎 1 层屏障 / 扣 4 点外甲耐久（无甲则 −2 HP）；
2. 第 2 次：4 点 `DIRECT_DAMAGE` + 震荡；
3. 第 3 次起：`6 + 2×(次数−3)` 点 `DIRECT_DAMAGE` 且 **SP 清零**。

倒流期间（钉子 9）：世界时钟停走（终焉灼伤暂停；G2 双倍速暂停）；德谬歌
豁免动词约束、保留基础行动但不可再献诗；死者不行动、不受约束；德谬歌被
击杀 → 倒流立即终止，她按正常死亡进往世层。

**∞ 闭环（钉子 10）**：倒流指针抵达 R1 的瞬间（R1 的起床**不需要重演**）：
所有幸存玩家面板重置回"未起床"的最初状态，镜头定格，**直接终局结算**——
不做真·无限循环。你可以设计"时间倒流"这个机制，但你不能真的做一个无限
循环的游戏。

**G5 自身不献诗**——十四诗篇是阶段二献予他人的能力，见 §13。

### 12.7 G6「要有笑声！」——花火 / 阿哈

欢愉是活人之间的恶作剧、替身嫁祸、当身博弈与全员惊喜礼盒。与往世层
Encore（死者托付本命技能）和 G0（阿拜多斯遗物战术枪战）绝不撞车——G6 是
把别人的回合剪成喜剧的导演。

**常驻被动【看热闹不嫌事大】（笑点）**：场上出现滑稽场面（攻击落空、碎甲、
forfeit、当身成立、有人拆开礼盒）→ +1 枚【笑点】。笑点 = 假币：执行
`interact`（购物/治疗等）时每 1 枚笑点抵扣 1 信用点；上限 3。

**T0 小动作【替身玩偶·假面当身】**（当身技，高风险高回报）：T0 架设【当身
姿态】（不耗 SP、不耗笑点；姿态持续至自己下个回合开始前）。

- **成立**：窗口内第一名以 G6 为目标的攻击进入结算 → 玩偶吞掉该击（本次
  伤害与破甲完全无效化）→ 攻击者承受 3 点烟花伤害（无视护甲 `[待风洞]`）
  + 震荡 → G6 获得 1 SP + 1 笑点；
- **落空**：到下回合开始无人攻击 G6 → 本次 T0 白花（无任何收益）。

读对白吃一刀反咬一口，读空白费一个小动作。这是全游戏最干净的"高风险高
回报"。

**1 SP 即演【插入式笑话·移花接木】**：耗 1 SP，指定 1 名其他存活玩家 X 为
"冤大头"；**同一玩家不能连续两轮被指定**。二选一：

1. **刷他的卡**：以 X 所在建筑菜单隔空执行一次 `interact`（装备/物品归
   G6）；费用优先从 X 钱包强划（至多 2 信用点 `[待风洞]`），超出部分由 G6
   自付或用笑点抵扣；
2. **借他的刀**：以 X 的位置与视野、用 G6 自己的武器（或 X 的基础武器面
   板）攻击与 X 同地的目标 Y——伤害/破甲/击杀归 G6；触发的犯罪案底/通缉/
   敌方反击全部记在 X 头上。

**2 SP 公演【全员派奖·超大惊喜礼盒】**（可崩铁式插队夺台）：向场上所有其
他存活玩家各塞一个【超大惊喜礼盒】（已有未拆盒者：刷新并立即引爆旧盒，
旧盒按随机负面结算）。

**拆盒规则（额外的 T0 抉择）**：
- **路径 A（自己拆）**：持有者花自己 T0 拆开 → 从六面礼盒池等概率随机 1 项
  生效（有人拆盒 G6 都 +1 笑点）；
- **路径 B（花火代拆）**：持有者不拆 → 轮到 G6 回合时，G6 可花自己 T0 指
  定 1 名持盒玩家，从 4~6 号负面效果中**钦定 1 项**对其生效；
- **兜底**：礼盒在持有者怀里停留满 2 个全局轮次仍未拆 → 第 2 轮 R4 自动炸
  开，随机结算 4~6 号负面之一。

**六面礼盒池（3 正 3 负）**：

| 编号 | 性质 | 名称 | 结算 |
|---:|:---:|---|---|
| 1 | 正面 | 天降横财 | 立即 +4 信用点并恢复 2 HP |
| 2 | 正面 | 军火大放送 | 自选 1 件普通外甲或 1 把常规武器免费获得 |
| 3 | 正面 | 欢愉任意门 | 免费位移到自己指定的任意公共建筑（不触发借机攻击、不占 T1） |
| 4 | 负面 | 砰砰烟花 | 承受 4 点 `DIRECT_DAMAGE`，且钱包炸飞 2 信用点归 G6 |
| 5 | 负面 | 假冒伪劣 | 1 件外甲报废清零；无外甲则 1 把非初始武器报废（神器/融合武器改为禁用 2 轮） |
| 6 | 负面 | 走错片场 | 强制随机移动到另一公共建筑 + 震荡（破除架盾/防暴盾墙等驻地姿态） |

**G5「欢愉」诗**（已定稿）：① G6 笑点立即回满至 3；② 授「欢愉的延展」标记
（4 个未来 R4 tick）：当身升级【双面假面】（有人攻击 G6 反噬翻倍至 6 点烟花；
读空 → 玩偶在下个 G6 回合开始时自动飞向同地点或最近建筑的随机敌人炸开，
3 点烟花 + 震荡，永不落空）；G6 花 T0 代拆礼盒时可一次性引爆场上所有未拆礼
盒（每个由 G6 钦定 4~6 号负面）。

### 12.8 G7「大叔我啊，剪短发了」——小鸟游星野

全游戏机制最成熟、内部自洽度最高的角色。结构不动，本次只修两处：SP 接口
重做（SP 与 Cost 咬合）+ 新基线接口对齐。

**融合装备**：

- **铁之荷鲁斯（盾）**：第一次同时持有盾牌 + AT 力场时自动融合（一次性）；
  受损后 `special 修复`消耗 1 件组件修复；
- **荷鲁斯之眼（枪）**：第一次同时持有电磁步枪 + 高斯步枪时自动融合；弹
  匣上限 8 `[待风洞]`；3 弹丸射击与子弹属性（科技/魔法/普通）完全保留；
- 双融合完成 → 自动习得战术指令 + 2 次自由配发（每次可选 1 战术道具 /
  1 药物 / 2 发子弹）。

**光环**：3 层可再生护体值；三层首次全亮 → 一次性【战斗续行】免死（HP = 光
环复活值 `[待风洞]`）；Terror 形态下不生效；属三层漏斗 Death Gate 的
Morph 层。

**Cost 与战术宏**：每 R0 回满基础上限 `[待风洞]`；**失却汇流成泉**——上一全
局轮使用过战术宏 → 下个 R0 回满后 Cost −1（不叠加）；肾上腺素覆盖。

**战术宏**：T1 `special Hoshino` 进入，占一个标准根行动（复合根容器）；
只要 Cost ≥ 1 即可进入，**不耗 SP**；逐步执行并扣 Cost，某步不足即中断，
已执行步骤不回滚。宏动作表（Cost）：

| 动作 | Cost |
|---|---|
| 架盾 / 射击 | 2 |
| 重新装填 / 取消 / 转向 / 排弹 / 服药 | 0 |
| 持盾 / 投掷 / 冲刺 / find·lock | 1 |

**架盾**（三层漏斗 Barrier 层）：划分正面/背面；正面裸伤 ≤ 格挡阈值则完全
格挡，超阈值扣耐久并无效化剩余伤害；正面敌人正常离开需多花 1 回合；**架盾
期间 G7 无法 move**；每 R4 维持 cost（水着-Shielder 免费）。

**持盾**：减法防御 + 耐久吸收，击破吸收本次溢出；**被动保护**——未架盾/持
盾时仍提供减法防御 + 耐久吸收，溢出优先由光环吸收，再进护甲与 HP。

**战术道具与药物**：

- 道具（军基）：破片手雷 / 震撼弹 / 闪光弹 / 烟雾弹 / 燃烧瓶；
- 药物（医院）：EPO（Cost +1）/ 海豚巧克力（回 1 层光环）/**肾上腺素**
  （全局 1 次，宏外 `special` 注射，不占行动回合；下个 R0：Cost 回至临时高
  上限 + 光环全恢复 + 先攻 +3——覆盖失却汇流成泉）。

**SP 接口（本次修订核心：SP 与 Cost 咬合）**——

**1 SP 即演【大叔的午休】**（T0，不占 T1）：T0 宣言，耗 1 SP。眯一觉、换个
插板，T1 照常开宏。二选一：

1. **紧急包扎**：立即恢复 4 HP（半血以下额外 +2）`[待风洞]`；并清除下轮
   R0 的失却汇流成泉惩罚（睡饱了，不算疲劳）；
2. **更换防弹插板**：铁之荷鲁斯耐久 +6（或恢复 1 层光环）；并向荷鲁斯之眼
   免费压入 2 发普通子弹（为 2 SP 全弹倾泻备弹）。

**2 SP 公演【荷鲁斯之眼·全弹倾泻】**（三形态本命大招）：前置——持荷鲁斯
之眼且弹匣内 ≥ 1 发子弹；2 SP 公演（占 T1；支持崩铁式插队夺台）；消耗
2 SP + **倾泻弹匣内全部剩余 N 发子弹**——N 越多大招越强；自动取所倾泻子弹
中最优属性结算属性克制双倍碎甲。按当前形态释放本命大招：

| 形态 | 大招 | 效果 |
|---|---|---|
| 水着 / 常态-Shielder | EX【战术镇压】 | 强制将当地所有单位划入正面并直接进入架盾；对正面全体扇形轰击（随 N 增伤）并施加震荡；N ≥ 4 时可对 1 名主目标挂 `ACTION_SUPPRESSED` |
| 临战-Archer | NS+EX【扇形连喷·必穿高爆弹】 | 第一段：弹匣扇形四连喷，对当地全体挂脆弱（易伤 + 外甲磨损增加）；第二段：对主目标 1 发**无视 Barrier** 的穿甲点射，命中后范围爆炸波及当地全体（随 N 增伤碎甲） |
| 临战-Shielder | EX【前线突入·移动掩体】 | 可免费跨地冲刺至任意公共建筑（或原地）；落地重砸进入强化架盾（立即恢复铁之荷鲁斯耐久 + 按 N 获得防弹 Barrier）；落地冲击当地全体敌人并施加震荡 |

**色彩、自我怀疑与 Terror**：

- 色彩：每有 1 名玩家出局 +2；由 G7 击杀额外 +2；**G0 撤退按"玩家出局"计
  入 +2**；
- 色彩 6：自己 T0 可选进入自我怀疑；
- 色彩 10：本体受非致死 HP 伤害 → 恢复穿戴过且已破碎的护甲 → 强制自我怀
  疑 → 下一行动槽跳过 → 反转为 Terror。

**Terror**（全游戏最具破坏力的状态）：Cost 为 Null；失去战术指令/道具/药
物/铁之荷鲁斯/光环；只能 attack 或 move；进入时护甲/光环/铁之荷鲁斯折算
额外生命（保底 12 `[待风洞]`）；**攻击 = 荷鲁斯之眼对全图所有玩家单位分别
造成 `DIRECT_DAMAGE` + `absolute_death`**，结算后扣 6 额外生命（全歼他人则
免代价直接胜利）；移动后扣 2 额外生命；无法被举报，警察拒绝攻击/靠近/移动
指令；不参与即演/公演；战斗续行不生效。

**G5「守夜人」诗（手册救援版原文）**：需 G7 主动接受（拒绝则追忆照耗、
效果不发生）；接受后——色彩永久置 null；若在 Terror 则解除并把剩余额外
HP 转永久 HP；扣 min(2, 永久额外 HP) 恢复铁之荷鲁斯（曾融合则耐久 ≥2，
未融合不凭空创建）；恢复战术指令/药物/装备可用性；光环恢复初始层数。

与 G1 飞萤诗共同构成"绝境必死态（Terror / 繁育）的唯一救赎"轴。如果当局
没有 G5，Terror 的结局不可阻止——除非 G7 自己选择进入自我怀疑路径或被
全场合力击倒。

## 十三、G5 十四诗篇

十四诗篇是德谬歌（G5 阶段二）献予他人的能力。**小昔涟不能献诗**。共享入
口与全局规则：

- **消耗**：基础 2 SP，每差 1 SP 可用 2 层追忆代替（0 SP + 4 追忆可硬发；
  大即演，不占聚光灯）；追忆是德谬歌诞生后不再增长的有限总预算；
- **目标**：持有对应天赋的玩家（每首诗绑定一个天赋槽位；目标缺该天赋则
  不可用）；
- **爱愿**：目标获得爱愿——除非目标为 G5 自己或对局为双人局；持续 **4 个
  未来 R4 tick** `[待风洞]`；不是 buff/debuff，不可驱散；持有者不能伤害 G5
  或施加 debuff；G5 攻击爱愿持有者则爱愿立即破碎；
- **重复献诗**：只刷新，不叠加（显式例外：「爱与记忆」段数成长、「负世」
  永续加成）；
- **锚定互斥**（继承 M9）：激活中的锚定阻止献诗；G5 存在尚未失效的爱愿
  时不可锚定。

## 十四、新手指南

### 14.1 一局最短路线

1. **先起床，领初始包。** 私人房间出门就回不来，刀/盾二选一先决定。
2. **R1 必须出门**：进商店/魔法所/医院/军事基地/警察局之一。
3. **赚钱**：商店打工是唯一经济入口，没人在家里发工资。
4. **准备一套能打人的东西**：弓负责跨地点，近战同地显形直接打，护甲负责
   把对手的攻击变成你的维修账单。
5. **看 SP，不要只看血**：SP=1 可以即演，SP=2 可以选择立刻即演或参与夺台。
   等公演不是必然更强，而是在等全桌舞台——崩铁式插队让你能抢台。
6. **关注世界时钟**：白昼开始掉落，黄昏是神代终局集中期，终焉会把"我再
   发育一轮"变成遗言。
7. **死后继续玩**：普通死亡进入往世层；三个按钮零背诵——押注、微光、
   Encore。

### 14.2 常见误解

**Q：先攻最低是不是又要轮空？**
A：不是。所有正常玩家都有标准行动，先攻只决定顺序。

**Q：SP 是行动点吗？**
A：不是。SP 只管天赋演出，不增加或删除标准行动槽。

**Q：公演是不是天赋加强版？**
A：核心通常相同。公演多的是聚光灯、往世层 Encore、诗篇适配与夺台竞争；强
度看天赋。大即演（G2 全部演出、G5 讲故事/献诗）不占聚光灯但强度同样高。

**Q：`DIRECT_DAMAGE` 是不是必杀？**
A：不是。它跳过普通目标侧防御，但仍可被明文承接；是否跳过复活看
`absolute_death`。

**Q：普通死亡就没事做了吗？**
A：你只是从选手席去了证券交易所。三个按钮：押注、微光、Encore。`absolute_
dead` 才是真正没有往世层操作。

**Q：lock 还要花整轮吗？**
A：不用。V2.0-GA 里 lock 是 T0 小动作，T1 直接攻击。

**Q：公演还要排队吗？**
A：不用。V2.0-GA 废除 FIFO 报名队列，改为崩铁式插队夺台——多人 SP=2 按先
攻竞争，回合中被推到 SP=2 也能插队。

**Q：G7 Terror 没救了？**
A：G5 守夜人诗是唯一解除方式。当局没 G5，Terror 的结局不可阻止——除非 G7
自己选择进入自我怀疑或被全场合力击倒。

**Q：为什么神代天赋这么长？**
A：因为它们的目标不是成为一排容易平衡的按钮，而是让角色在规则里留下清
楚的轮廓。你可以嫌它们麻烦，这很合理；你也可以选 T1，然后把复杂问题处理
成一次近战攻击。

## 全局法则并存条款（跨天赋钉 12）

V2.0-GA 存在多个"全局法则"来源：世界时钟、G1 繁育（地点摧毁）、G2 双终局
（世末之雨 / 炉心融解）、G5 时间倒流。并存优先级：

1. **G5 时间倒流期间，世界时钟停走**（含 G2 的 2 倍速），终焉灼伤暂停；
2. 倒流被击败终止后，G2 的 2 倍速时钟恢复生效（若 G2 终局仍在）；
3. G2 世末之雨使非玩家单位永久沉沦——G5 倒流期间 NPC 本不行动，无冲突；
4. G1 摧毁地点按基线规则处理 G2 残影（G2 钉 3）；
5. 往世层押注在 G5 倒流期间照常每 R0 开市（死者不受动词约束）。
