## 一、游戏概述

### 1.1 目标

《起闯战争》是 2 至 6 人的回合制乱斗。玩家在五大公共建筑之间移动、发育、演出并争夺综合评分直到游戏结束，如只剩下最后一名存活的玩家等等（没错，不止这一种可能）。
最后产生两类胜者：

- **最后存活者**：活到最后的玩家；
- **综合评分第一**：谁把这一局打得最精彩。

两者可以是同一个人，也可以不是。
在大部分情况下，玩家HP归零而死亡时将进入往世层（AfterLife）以独特的方法继续参与游戏并积攒评分。
有两类不进入往世层的例外：绝对死亡 与 退场 

### 1.2 信息公开

本游戏有99%的信息公开，属于近完美信息博弈。一般情况下，玩家位置、HP、装备、护甲耐久、状态、先攻、SP、PP、案底与大多数专属资源均公开。需要特别强调的是，本游戏中隐身只通过提高闪避的方式影响侦测与命中，并不导致该玩家任一属性无法被观测到。
（才不是因为懒得给RL训练管线写信念呢！这个游戏在那个还是口口相传和想象力的年代就是这样设计的！）

### 1.3 玩家状态条

每名玩家至少显示：

| 项目 | 内容 |
|---|---|
| HP | 整数，一般上限为20；首轮完整数值见 §17 |
| 外层护甲 | 每件护甲的属性与耐久 |
| 信用点 | 唯一经济资源，一般仅在商店打工获得 |
| SP | 释放技能需要的资源，一般分为`0 / 1（可释放即演） / 2（可释放公演）`三个等级  |
| PP | 演出积分，最终得分的重要一项。不因为死亡而消失，不能消费，转移。 |
| 装备与弹药 | 武器、护甲、道具、模块等 |
| 状态 | 灼烧、震荡、石化、屏障、爱愿、天赋标记等 |
| 天赋资源 | 追忆、魔力、火种、失熵、Cost、孤独值、色彩等，仅持有者显示 |

## 二、游戏准备与地图

### 2.1 开局

1. 每名玩家选择一个天赋，或全桌约定无天赋局。
需要注意的是，一局中允许混用**原初天赋(T(x))** 和 **神代天赋(G(x))**。这一设计是为了降低全桌的认知负担，不过也会出现“别人的能力：进化，倒流时间，将世界推向终末”而你的能力是“被打死了复活一次”这种雷霆情况。再多吐槽一句：神代天赋现在快批发免死了。

2. 游戏开始的第一个全局轮次(R1)，每名玩家出生在自己的**私人房间**，HP 满值，处于"未起床"状态。
*（在游戏的早期版本是一个玩家一个home。这对RL不太友好，而且地名映射经常出bug。你也可以理解成比赛主办方没钱了只能租一栋公寓给你们住了hhh，这年头一人一个单间也不少了）*

3. R1 的 T0阶段：执行**起床** 之后领取**入坑福利**：
默认为 弓 + 初始箭矢（固定）+ 小刀盾牌二选一。有些天赋在这里进行了hook，比如G0拿到的弓会被AR取代，而G7的水着开局会额外拿到物资等等。

4. R1 的 T1阶段：**必须 `move` 进入五大公共建筑之一**——商店 / 魔法所 / 医院 /军事基地 / 警察局。
*有点像跳伞。这可能是你在整份文档里看到的最接近大逃杀的元素。*

5. **关门之前再怀念一下你温暖的床吧**：本局无法再返回这个房间。
*必要的眷恋之后就踏上舞台吧。我们急着在十二点之前退房，不然得多收一天钱。*

### 2.2 五大公共建筑

地图由五个可进入地点组成，任意地点之间移动消耗 T1 主行动槽。
*截止到目前*没有相邻或者远近的概念。

| 地点 | 主要功能 |
|---|---|
| 商店 | 唯一可以靠打工获得信用点的地区、小刀、盾牌、磨刀石、陶瓷护甲、隐身衣、热成像仪、力量模块、修甲、箭矢补给 |
| 魔法所 | 法术（1 回合学 1 个）、魔法护盾、魔法弹幕、火矢、魔导模块 |
| 医院 | 紧急治疗、便携急救针、无限模块、G7 专属药、终身一次三选一手术 |
| 军事基地 | AT 力场、电磁步枪、高斯步枪、雷达、隐形涂层、穿甲/冲击模块、钩索（直接购买，记案底） |
| 警察局 | 申请队长、举报、防暴编队驻地 |

### 2.3 地点摧毁

一般情况下地点是不会被常规效果破坏的。只有在叙事等级足够高，且明确表述相关效果时才能被摧毁。
例如G1.
地点的摧毁几乎是永久的，所有幸存单位被驱逐至其他公共建筑（按先攻降序 +
actor ID 分配）。最后一个仍可站立的公共建筑不能被摧毁。警察局被毁后防暴
编队立即停机，案件与通缉记录保留，暂停执法而不洗白。
G5的特定强化效果和时间倒流效果可能重建部分被摧毁的地点。

## 三、回合结构：全局轮次循环（R）和玩家单个回合的结构（T）

### 3.1 全局轮次 R0–R4

每个全局轮次按固定顺序进行：

```text
R0  世界时钟推进一次；天赋 on_round_start；往世层内玩家行动
R1  所有正常玩家判定先攻；愿意公演的合法 SP=2 玩家竞争 R3 首位
R2  队长就任、编队与案件状态推进（需要注意的是，齐射不在R2结算）
R3  轮初公演胜者先兑现（失效则递补）；其余标准槽按先攻依次执行
    T0：1 次免费小动作（整备）
    T1：1 次主行动
    T2：登记关注（→SP）；结算 StepFollowup，登记 ExtraTurn
    完整收尾后：合法公演插队 → 尚未开始的 ExtraTurn → 后续标准槽
R4  警务齐射 → 环境伤害 → 持续伤害与角色维护 → 回复 → 到期清理
```

需要注意的是，对于一个在本轮进入，有倒计时的状态（石化、无人机、繁育、救世主、固有结界等）
本轮 R4 结算倒计时；从之后第一个R4 开始计时。除非来源明确要求。

同一批范围伤害先处理所有目标与濒死，再检查终局，避免因遍历先后提前宣布胜利。
终局成立就停止后续 tick；G1“胜利优先于繁育倒计时”的明文例外保留。
此外，实际全局轮次数和世界时钟是分开计数的。例如G2的世界时钟二倍速加速，不会让一个全局轮次内完整遍历两遍R0-R4。

### 3.2 T0：免费小动作（整备）

特定动作可以在T0阶段发动，每回合限 **1 次**，节省出 T1：

- 起床（仅首轮）
- 吃药（便携急救针 / G7 专属药）
- 磨刀
- 装卸弓模块 / AR 遗物切换
- 换形态（G1 着装/卸甲 / G7 更衣 / G4 主动升格）
- `lock` 锁定目标：本回合 T1 攻击无视目标移动闪避，并获得命中/破甲加成
- 天赋明文归属 T0 的其他宣言
*在早期版本里，lock和find是占据单独行动的，现在lock变免费了，find直接删掉了——不然实在是太磨蹭了*
*免费说的不是不消耗资源啦！不消耗标准行动槽而已。*

G2 选择角色、G3 结界主目标选择属于必要回合设置，不占小动作；G7 宏内操作走宏的
费用和库存，宏外肾上腺素占 T0。例如 G7 本回合已经午休，就不能再在宏外扎针。

### 3.3 T1：主行动

每回合 1 次，四大类动词：

| 动词 | 说明 |
|---|---|
| `move <地点>` | 移动到任意其他公共建筑；主动离开交战可能触发借机攻击 |
| `attack <目标> <武器>` | 攻击同地点显形单位（近战）或跨地点（远程）；同地点显形无需先 find |
| `interact <项目>` | 购买、打工、手术、学法术、修甲、补给等地点功能 |
| `special <操作>` | 天赋专属、装备特殊操作、战术宏等明文操作 |

*早期版本里有个非常让人头疼的find，用于在两个处于统一地点的玩家之间建立允许近战的社交关系。
事实证明与其让大部分天赋提供绕过它的攻击方式，不如直接取消掉它算了*

`search`（原 find）只用于揪出同地点的**隐身**单位。
*AI coding的经典范例，我真不记得我设计过这个指令*

**先预检，后付费。** 没有合法目标、资源不足等在发动前拒绝，不收费，可重新选择。
合法发动后遭闪避或屏障拦截不退款；连发、战术宏逐段检查，已经生效的步骤不回滚。
免费装填/服药仍要有弹药/药物且未超容量；空操作不制造关注、资源或剧情事件。

### 3.4 T2：追击与额外行动

对一个玩家的行动回合，T2阶段可能获得以下两类行动，：

**StepFollowup（单步战技追击）**：只能来自天赋效果，只能执行天赋效果允许的动词，
没有独立 T0，不能即演或公演，不递归生成下一个追击。

**ExtraTurn（完整额外行动）**：重新执行完整 T0→T1→T2，允许 SP≥1 时即演，
但禁止公演。共同边界：

- 每名玩家每个全局轮次至多 1 个；
- 当前回合完整收尾后插入；若此时有合法公演插队，先执行公演回合，再开始额外回合；
  不能储存，不能转移；
- ExtraTurn的T2阶段不能再插入其他ExtraTurn；
- 被控制消费后直接损失。


### 3.5 被其他玩家感知的不同状态

感知状态分三类：**暴露  / 隐匿（隐身）/ 被锁定**。
感知状态是带方向的，例如A和B都有隐身效果，但只有A有探测，B没有，那么两个人集中在同一地点，不经其他操作时
A的视角下B是暴露，而B的视角下A是隐匿。

### 3.6 控制裁决
本游戏有若干个可以施加给玩家或者非玩家单位的控制类状态：

| 状态 | 效果 | 备注 |
|---|---|---|
| `SHOCKED` 震荡 | 下一槽只能有限移动、非敌对交互或放弃；槽收尾后移除 |---|
| `ACTION_SUPPRESSED` 压制 | 下一行动槽强制跳过 |---|
| `PETRIFIED` 石化 | 可放弃保持、花 1 SP 以 50% 概率挣脱（同槽至多 2 次），或挨两次有效伤害被动解除 | G3独特效果 |
| 睡眠 | 该槽只能唤醒 |这就是为什么这个游戏叫现在的名字| G7特有效果 |

| `SUBMERGED` 沉沦 | NPC 停机 | 多少个版本了都是G2的专属效果 | 

普通控制共用一个控制位，优先级：压制 > 石化 > 震荡。
睡眠与自我怀疑是结构状态，不占控制位。弱控制不覆盖强控制，一个控制效果持续期间添加新的同名控制效果，则计时器被后添加的效果刷新而非叠加持续时间。
石化挣脱是槽开始的特殊处理，不占正常 T0；同槽最多两次、每次付 1 SP，成功后
正常行动。轮制状态按未来 R4 计时，槽制状态按来源消费槽；灼烧等明文层数效果
按自己的层数上限处理，不能用“同名刷新”偷偷取消其叠层。

擦伤同时属于“闪避成功”和“实际受伤”，不属于附带状态所要求的命中。

## 四、装备、信用点与地点经济

### 4.1 信用点

- **商店打工**是唯一可重复主动赚取信用点的地点交互行动，每次 +2 信用点；
*早期版本允许在医院打工，在 V2.0-GA 中该交互被移除*
- 白昼后击杀使死者背包、装备与剩余弹药掉在死亡地点，拾取消耗一个 interact；
- 礼盒等明文奖励仍可给信用点，不据此增加第二个打工入口；
- 普通修甲占 T1 并支付费用，不能通过免费切姿态修复。

### 4.2 武器

**弓**是标准跨地点武器，开局人人携带（G0 以 AR 替换）。基础伤害 4，初始箭矢 5 支，
箭矢上限 10，商店花 1 信用点补给一次 5 支。武器、模块与价格全表见 §17.2。

弓有两个模块槽：

| 模块 | 来源 | 作用 |
|---|---|---|
| 力量 | 商店 | 增加弓伤害 |
| 火矢 | 魔法所 | 改为魔法属性 + 灼烧 |
| 魔导 | 魔法所 | 增加命中 |
| 穿甲 | 军事基地 | 改为科技属性 + 降防御系数 |
| 冲击 | 军事基地 | 命中后击退；双装追加先攻惩罚 |
| 无限 | 医院 | 独占双槽，不消耗箭矢，只发普通箭 |

G0专属 AR 不能装普通弓模块，有专属遗物改装槽，见 §12.1。

### 4.3 外层护甲
*早期版本中有内层护甲的概念，现在已经被移除。*

外层护甲是你可以获得的，用来提高你对应属性防御的道具。
它在你收到对应属性伤害时提供伤害减免，并根据吸收的伤害扣除自己的耐久。
它有两个属性：属性防御和耐久。属性防御决定这一击由外甲减免的伤害，耐久支付这次减免；
一般情况下为每减免 1 点伤害消耗 1 点耐久。

例如无其他修正、无额外碎甲、耐久足够且保底不改变结果时，攻击 6 对属性防御 3：
HP 扣 3，护甲耐久扣 3。耐久归零后破碎，后续攻击不再取得该件防御。

需要注意的是，无论叠加多少防御，每次攻击最终造成的伤害必然大于等于原始值的25%；
闪避成功只造成保底擦伤，不磨损普通外甲，见 §5.2。
有些天赋会提供攻击时对护甲耐久的磨损能力提高，例如翻倍，可以把每点减免的耐久单价由 1 改为 2。

## 五、伤害、防御结算顺序与死亡

### 5.1 防御结算顺序

V2.0-GA 统一了防御结算顺序：

```
攻击伤害 A
  → 第 1 层 Barrier（屏障）
      警察防暴盾墙 / G3 七重圆环·剑阵 / G7 架盾 / T4 元亨利贞
  → 第 2 层 Armor（属性减伤 + 耐久计费）
      盾牌 / 陶瓷护甲 / 魔法护盾 / AT 力场
  → 第 3 层 HP（生命与濒死）
```

普通攻击按上述防御层级处理；无视屏障、`DIRECT_DAMAGE` 等明文效果按各自规定跳过
对应层。Armor 层只做一次属性减伤，再对实际承担的减免计费，不再用同一外甲耐久
吸收剩余伤害。G7 未架盾的铁之荷鲁斯按普通外甲处理，持盾只提高属性防御，不另设
耐久吸收池，也没有“永远留一点耐久”的将破线。光环是有限护体池，在主动屏障之后、
普通外甲之前，按实际承担的伤害扣值；耗尽后的余量继续结算。

普通临时屏障也是挡多少扣多少，允许破碎余量继续；不是所有屏障都有下面的主动防护特权。

**主动防护特权（DEC-015–016，2026-10-26 已定）**：G7 主动架盾取消低伤免费格挡
阈值，每次在合法范围内成功格挡正伤害，都按来袭伤害扣盾耐久，最多扣尽。
G3 七重圆环与 G7 主动架盾的击破当次仍完整拦截该击，之后失效；本体与普通外甲
不承接该击余量。该特权不扩大拦截范围，也不阻止明文绕过屏障的攻击；不扩展到普通
外甲、G7 持盾/被动保护/光环或其他屏障。G7 正背面、不能移动与维持 Cost 规则保留。

例如 G7 架盾剩余耐久 3，成功格挡一记来袭伤害 6：扣尽 3 耐久、盾破，本击本体
扣血 0；后续攻击不能再靠这面已破的盾拦截。若来袭伤害只有 1，也必须扣 1 耐久。

### 5.2 两阶段伤害、保底与闪避

```text
A = max(0, ceil(base_damage × skill_core_multiplier
               + attacker_flat_bonus − weakness))

A_remaining = 屏障/护体承接后剩余的攻击伤害（无承接时等于 A）
F = min(A_remaining, ceil(A × 25%))
H_normal = max(A_remaining + vulnerability − flat_damage_reduction − E_effective, F)
```

**普通伤害保底（DEC-004，2026-10-26 已定）**：上式用于 `A>0`、进入本体普通防御
结算且未闪避的伤害，普攻与普通伤害技能同样适用。目标侧易伤与普通减伤均在取下限
之前计入，易伤不增加 `F` 的基数；之后不得再用普通减伤将结果压到 `F` 以下。
25% 为首轮数值基线，比例留待实现期风洞校准。

攻击方只在最终输出端向上取整一次；属性防御乘穿甲系数后向下取整一次，例如
防御 3×0.5→1。保底不补回屏障已承担的伤害：A=8、普通临时屏障=7，盾破后只剩
1 点进入本体，不能再补成 2；全部拦截时不进入本体流程。

`E_effective` 为本次实际生效的属性防御，名义值为「属性防御 × defense_coefficient」。
实际减免受剩余耐久与本次计费单价限制，不能直接代入完整名义防御，详见 §5.3。
无其他修正、普通计费且耐久足够，`A=4`、属性防御为 6 时，最终 `H=1`、耐久扣 3，
不能按名义防御收取 6 点磨损；同一护甲若仅剩 1 耐久，则 `H=3`、耐久扣 1 后破碎。

外甲耐久只为自身承担的减免计费。闪避、屏障或天赋减伤避免的伤害不能未经区分全部
归入外甲账目；目标侧不耗甲的普通减伤先结算，外甲只为剩余伤害中自身实际新增的
减免付费，并保留最终伤害下限，具体见 §5.3。附加固定磨甲单独记账。

**闪避擦伤（DEC-005，2026-10-26 已定）**：可闪避攻击的闪避判定成功，且仍需对
本体结算时，直接取 `H_graze=F`；不触发本次攻击附带的震荡、灼烧等状态，普通外甲
磨损为 0。不再运行普通外甲减伤，也不再套用第二次保底。比如 `A=4` 时擦伤为 1，
`A=10` 时擦伤为 3，均不磨普通外甲；移动闪避 +15 个百分点，完整命中表见 §17.1。

**例外与事件边界**：`A=0` 只来自明文攻击归零白名单，不消耗护甲或掩体。屏障/替身
等完整承接或绝对免疫时不强扣本体保底，保底不构成绕过拦截的直达伤害。
`DIRECT_DAMAGE` 按 §5.4 单独处理。擦伤若实际扣除 HP，仍满足 §5.7 的有效伤害定义；
这不等于触发攻击附带状态；G6 监听闪避成功，见 §3.6。部分屏障承接后的擦伤同样
不能超过剩余攻击伤害。

**普攻可用性约束**：T6 等角色不能被假定拥有独立伤害演出或直达伤害。后续平衡以
其普通武器攻击检查防御、回血、修甲循环，也检查警察支援不可用时的进攻能力；
有 1 点保底但始终被恢复抵消，不能视为已经解决普攻失效问题。

### 5.3 强化碎甲与当次溢出

**残甲限制当次减免（DEC-006，2026-10-26 已定）**：属性防御不是击破当次的免费
减伤额度。外甲只能按剩余耐久支持的减免参与这一击，普通计费每减免 1 点消耗 1
耐久；未挡住的部分直接进入 HP。这里的「溢出」就是未被减免的伤害，不再另加一次。

**双倍磨损改计费单价（DEC-007，2026-10-26 已定）**：通常每减免 1 点消耗 2 耐久，
因此同一击的可减免量也会减少。不采用先按普通单价完成减伤、再追加一次磨损的算法。
属性克制、T1 斩击、G0 神秘属性与 G7 最优弹药等明文双倍磨损来源统一引用本条；
固定数值的磨甲不自动转为倍率；攻击附加固定磨甲按 DEC-012 结算，独立纯磨甲按 DEC-014 处理。

**耐久尾数仍能保护（DEC-008，2026-10-26 已定）**：双倍单价下最后不足 2 点的
耐久仍能支付最后 1 点减免，仅实际用到尾数时才耗尽并碎甲。此例外不突破属性防御
或保底限制；没有实际减免就不计费。比如剩余耐久 3：减免 2 点时扣尽 3 耐久并破碎，
只需减免 1 点时扣 2、剩 1，不能提前清空。

**磨损倍率取最高（DEC-009，2026-10-26 已定）**：对每件外甲分别检查本击适用的
属性克制、天赋等倍率，只取最高；天赋双倍 + 属性双倍仍为单价 2，不相加、不连乘。
固定数值的独立磨甲不混入倍率比较。

**每击自动选一件主防甲（DEC-010，2026-10-26 已定）**：比较每件普通外甲在当前
属性、剩余耐久、计费单价与保底限制下的实际可减免量，自动选最多的一件，只有它
支付耐久。其余装备作备用或覆盖其他属性；同击不叠加防御、不分摊磨损，主防甲破碎
后也不调用另一件接力。后续攻击重新选择，不能只按最高名义防御固定选甲。

**同效择甲（DEC-017）**：实际减免相同，依次选本击普通耐久费用较少、击前剩余
耐久较多、固定装备 ID 较前的一件。例如两甲都减免 2，普通计费甲花 2、双倍计费甲
花 4，选前者；都花 2 时优先当前耐久更多的那件。

**不耗甲减伤优先（DEC-011，2026-10-26 已定）**：先计入目标侧易伤和天赋/状态等
不耗甲的普通减伤，再由主防甲承担剩余可减免部分，最后统一保底。外甲不能为其他
减伤已经挡住的部分再次付费；若其他减伤已将伤害压至保底，外甲不再承担普通减免。

下式用于 **A>0、未闪避且已进入本体普通防御结算**的伤害。`V` 为目标易伤，`R` 为
不耗甲的普通固定减伤。对每件候选普通外甲 `i`，`E_i` 为其本次名义属性防御，
`D_i>0` 为击前剩余耐久，`k_i` 为取最高后的单价（当前普通 1、双倍 2）。
`E_i` 先按属性防御乘穿甲系数向下取整；`D_i`、`V`、`R` 按各自整数数值表输入。
`A_remaining` 为屏障后的余量；全额拦截不执行本式：

```text
F = min(A_remaining, ceil(A × 25%))
B = A_remaining + V − R                # 先计入不耗甲的目标侧修正
L = max(0, B − F)                      # 外甲最多还能新增的减免
C_i = min(E_i, L, ceil(D_i / k_i))      # 每件候选本次可减免量
j ∈ argmax_i(C_i)                       # 同效按费用、剩余耐久、装备 ID 择一
H = max(B − C_j, F)                     # 最后统一保底
W_j = min(D_j, k_j × C_j)               # 尾数实际用到才耗尽
W_i = 0  （i ≠ j）                      # 其余普通外甲不计费
```

无候选外甲时按减免 0 处理；各候选减免均为 0 时普通减伤计费也为 0，附加固定磨甲
仍按同效次序选目标，不能伪装成普通减伤计费。
`D_j−W_j=0` 时主防甲破碎，其他甲不再对本击追加减免。`W_j` 不加到 `H` 上，
也不建立第二个吸收池。没有明文接入表的其他比例修正不能凭旧版本代码擅自加入。

单甲算例（以下六例均为 `V=R=0`）：

| 伤害 A | 属性防御 E | 剩余耐久 D | 单价 k | 实际减免 C | 扣血 H | 耐久消耗 W |
|---:|---:|---:|---:|---:|---:|---:|
| 4 | 3 | 1 | 1 | 1 | 3 | 1（甲碎） |
| 10 | 6 | 1 | 1 | 1 | 9 | 1（甲碎） |
| 4 | 3 | 4 | 2 | 2 | 2 | 4（甲碎） |
| 10 | 6 | 4 | 2 | 2 | 8 | 4（甲碎） |
| 4 | 3 | 3 | 2 | 2 | 2 | 3（甲碎） |
| 4 | 1 | 3 | 2 | 1 | 3 | 2（剩余 1） |

多甲算例（均不闪避、无其他增减伤、普通单价）：攻击 8，两件甲防御分别为 3、2，
耐久都足够，选择防御 3 的一件，扣血 5、该甲磨损 3，另一件磨损 0。若另有一件
名义防御 6 但仅剩耐久 1 的甲，它只能减免 1，不能挤掉实际可减免 3 的主防甲。
若攻击 8 面对防御 6 / 耐久 2 与防御 1 / 耐久 10 的两件甲，则前者减免 2 后破碎，
本体扣血 6；后者本击不接力，耐久仍为 10。

普通减伤算例：攻击 8、其他固定减伤 4、主防甲防御 4，普通单价且耐久足够。
`F=2、B=4、L=2`，外甲实际减免 2，最终扣血 2、磨甲 2；不能先让外甲付 4 耐久
再叠天赋减伤。若其他固定减伤已达 6，则扣血仍为 2、普通外甲磨损为 0。

**攻击附加固定磨甲（DEC-012，2026-10-26 已定）**：先确定本击 `H` 与 `W_j`，
再对本击主防甲扣除附加固定磨损 `M`，实际额外消耗为 `min(M, D_j−W_j)`。
`M` 不乘双倍磨损单价；普通减免计费与固定磨损分开记录。主防甲已碎则不再重复破甲，
余量不转另一件甲、不转 HP，也不反向重算本击减免。

例如攻击 6、甲防 3、耐久 4、普通单价、附加固定磨甲 2：先确定扣血 3、减免计费 3，
再扣掉该甲剩余 1 耐久并破碎；最终仍只扣血 3，另一件甲不承接多出的 1 点磨损。

本条只定义攻击附加的固定磨甲。闪避擦伤、明文 `A=0` 或完整拦截仍遵守各自的免磨甲
边界；不存在外甲时不改扣 HP。全部候选减免为 0 时，仍按费用/剩余耐久/装备 ID
选一件甲接受附加磨损，普通减伤费用保持 0；不能转而磨第二件甲。

**独立纯磨甲（DEC-014，2026-10-26 已定）**：T3 震波等属于装备损耗事件，只对
一件普通外甲扣固定耐久，最多扣尽该件，余量丢弃；不转移至另一件甲，不转 HP，
也不套 25% 保底。目标无甲时仅磨甲部分无效，其他技能效果正常生效；不是将一次
普通伤害攻击的 `A` 设为 0 后另行磨甲。有主动选择入口时由施术者指定一件外甲；
自动效果选当前耐久最高的一件，同耐久按装备 ID。适用屏障会先承接这笔固定磨损，
最多扣尽屏障值，本次不再磨外甲，余量丢弃；不因此自动穿屏障。
例：独立磨甲 2 对剩余耐久 1 的甲，只扣 1、甲碎、HP 不变；若先被适用屏障挡下，
只损耗屏障，不再给普通外甲计一次磨损，也不发普通破甲奖。

**通用破甲奖励（DEC-013，2026-10-26 已定）**：主动击碎他人的普通外甲才有资格；
自损、卸甲、形态转换不发此奖。只有耐久从正数变为 0 才登记一次破甲，已经碎裂的
外甲不因附加磨损重复登记。SP 走 §6.2 的关注额度，不另开破甲专属第二份 SP；通用
破甲 PP 奖励为 +1，每名发起者每全局轮最多领取一次。连发、范围攻击、
公演与额外回合在同一轮共用该额度。

此上限只约束通用破甲 PP 奖励，不把伤害/破甲战果分也限成每轮一次。T1「游侠」等
明文返 SP、G5 追忆/G6 笑点分别按 §6.6，押注按 §9.2。以上为规则算例，不是 T6
或其他角色的定值；通用 PP 奖励数量为 1。

旧「碎甲瞬间溢出伤害全额贯通」由上述当次减免规则取代，不再保留为另一套算法。

### 5.4 `DIRECT_DAMAGE`

令目标侧直接 H=A，跳过属性防御/护甲/普通固定减伤。仍可被明文替身、
重定向、绝对免疫或掩体承接。**不自动等于绝对死亡**。

### 5.5 Death Gate：濒死三顺序

致死结果按以下顺序处理：

1. **absolute_death**：直接绝对死亡，跳过后两层；
2. **形态转折**（Morph）：G1 繁育 / G4 救世主 / G0 调整呼吸 / G7 战斗续行 /
   G2 黄昏后首次融合；
3. **外部复活**（Resurrect）：T7 保险承接。

都未承接才正常死亡。一次致死只兑现一个有效替代：比如 G1 繁育成功，就不同时
消耗保险。替代成功后不将本击超额伤害追入新形态；连发的下一枪仍可正常攻击它。
G2 黄昏前不能融合，融合后的普通致死不再重复融合；致死融合的起始 HP 须为正数。

### 5.6 普通死亡与绝对死亡

**普通死亡**：SP 清零，进入往世层；战果分与剧情分**不打折**（铁律 1，
死后分数照常计入）；已达成第 3 章则当场锁分。

**绝对死亡（absolute_dead）**：跳过普通免死与复活；不进入往世层；
PP 冻结，不衰减也不能再花；装备照常掉落。

当前绝对死亡来源：G4 死星天裁、G7 Terror 攻击、G1 繁育倒计时归零。

### 5.7 有效伤害

以下任一成立才算一次有效伤害：H≥1 进入本体 HP；或一件护甲/掩体耐久归零。

## 六、SP、夺台与演出

### 6.1 SP：能力层级，不是货币

| SP | 权限 |
|---|---:|
| 0 | 正常行动，不能主动演出 |
| 1 | 可以即演（−1 SP） |
| 2 | 可以即演，或参与夺台竞争 |

开局 SP=1。SP 不交易、不计分、不兑换，也没有"这招打折便宜点"的临时议价。
死亡时 SP 清零，普通复活从 0 重新开始。

### 6.2 怎样得到 SP：关注

**关注**是公开事件把你登记为焦点或发起者，每次有效关注使 SP+1，上限 2；
每人每全局轮次通过关注至多实际 +1，下个 R0 重置。

| 事件 | 谁取得关注 |
|---|---|
| A 攻击 B | B 为焦点，A 为发起者；各自检查本轮额度 |
| A 对 B 执行高影响行动 | B 为焦点，A 为发起者 |
| A 犯罪 | A 为发起者；有受害者时受害者为焦点 |
| 承受环境/世界时钟伤害 | 受影响者为焦点，无发起者 |

主动击碎他人的普通外甲时，按同一关注机制登记，仍受每人每轮实际 +1 上限约束。
同一攻击的命中、破甲等事件不能另开一份 SP 额度；通用破甲 PP 奖励的独立限频见 §5.3。

已经 SP=2 时事件仍写日志，但不加到 3；若之后花掉 SP，本轮之后第一次关注
仍可使 SP+1。

### 6.3 夺台：崩铁式插队（废除 FIFO 报名队列）

每轮只有 **1 个全局公演位**，不保留 FIFO 或跨轮预约。以下时序为 2026-10-26 已决口径。

**窗口一：轮初夺台，R3 首位兑现。** R1 先攻排定后，愿意公演且满足条件的 SP=2
玩家按先攻竞争，可用 PP 重掷先攻。胜者把自己的标准回合移到 R3 最前并在该回合公演；
R2 照常先结算。轮中满 SP 的玩家不能抢走这个待兑现位置。

执行前重新检查资格。轮初胜者已不合法时，按先攻在其余愿意公演的合法轮初候选中
递补；未实际执行不扣公演 SP、不消费公演位，也不凭空消耗该候选的标准槽，其后仍按
原行动顺序与控制规则处理。轮初没有人能兑现，才继续开放轮中夺台。

**窗口二：轮中满 SP，当前回合收尾后兑现。** 回合中被推至 SP=2 可以提出申请，
但须公演位仍空、自己的本轮标准回合尚未开始，执行时也仍满足公演条件。同一边界的
多名合法申请者按本轮先攻竞争。

**插队不能切开一个玩家回合。** 当前回合的攻击、同一主行动内的连发/战术宏、濒死
处理及 T2 追击与收尾必须全部结算。然后才执行公演插队，且公演优先于尚未开始的
ExtraTurn；已经开始的 ExtraTurn 也须完整收尾，才能让夺台者行动。

例如 G3 宝具连发第一击把乙打到 2 SP，乙只能申请；连发、可能衔接的幻想崩坏及
G3 的 T2 全部结束后，乙仍存活、仍有 2 SP 且仍可公演，才可兑现。若赤原猎风已削掉
SP 或禁止本轮受击夺台，申请不能兑现。

夺台只**提前消费自己的标准回合**，原位置不再行动。自己的本轮标准回合已开始或已
结束者不能借此再行动；下一轮可重新竞争，不自动获得公演资格。

**自己的 T0 满 SP 不必插队。** 当前是自己的标准回合，T0 后满 2 SP、公演位仍空
且其他条件满足，就可用当前 T1 公演。例：G4 T0 主动升格把 SP 置 2，随后 T1
焚诏；本轮仍只有这个标准回合。若公演位已用，保留 SP 并选其他行动。ExtraTurn 禁公演。

### 6.4 演出类型

| 形态 | 时机 | SP 消耗 | 是否占聚光灯 |
|---|---|---|---|
| 准备型即演 | T0：G0 无人机、G1 着装、T3 玉璋、G7 午休 | −1 | 否 |
| 行动型即演 | T1：攻击演出、T6 整备、T7 保险/祝祷等 | −1 | 否 |
| 公演 | 标准回合 T1，SP=2 且取得公演位 | −2 | 是 |
| **大即演** | G5 讲故事/献诗占 T1；G2 按下文 | −2（或追忆代替） | **否** |

**大即演**是 V2.0-GA 新增区分：G2 全部演出与 G5 讲故事/献诗属于大即演，
不占聚光灯，不可崩铁式插队夺台，但强度不低于公演。区别在于入口，不在于强度。
G2 融合前 A 使用 T0，并强制本回合 T1 move；B 使用 T1。融合后演出均占 T1。
G2 主控声明本身不占小动作。大即演不会额外赠送 T1：G5 献诗后本回合不能再普通攻击。

### 6.5 落幕

落幕只关闭来源明文列出的能力，不一概关闭玩家的 SP 与全部演出。T7 保险兑现后
保险资格耗尽，但仍按关注取得 SP，仍可用 T1 祝祷。彼岸诗最多重启一次保险资格，
同一 T7 整局最多兑现两次；不能靠重复献诗无限续保。

### 6.6 专属资源：一次行动不要重复领奖

| 来源 | 已定额度 |
|---|---|
| 游侠返 SP | 一次诗篇标记只返 1 次，同一刀破甲兼击杀也只返 1 SP；不占关注额度 |
| G6 当身 SP | 并入关注每人每轮实际 +1 的额度，不另送第二份 |
| G5 高光追忆 | 每个根行动至多 +1，公演/破甲/阵亡、多段与多目标不重复叠领；执笔另算 |
| G6 被动笑点 | 每个根行动至多 +1；首版每全局轮最多获得 3 枚，存量上限 3；献诗置满另算 |

当身成立不返还架设花掉的笑点；无根行动的系统效果按同批事件合并登记。
这些资源闸门不替代实际伤害战果或不同玩家的独立记录。N0 中 G6 自己主动放弃
行动的笑点收益为 0；他人实际放弃仍可给笑点，见 §17.11。

## 七、计分：打出来的分

### 7.1 终分骨架

```text
终分 = 战果分 + 高光分 + 终幕王冠
```

**战果分**：玩家击杀数 × 6 + floor(实际造成的其他玩家 HP 损失总量 / 4) +
他人普通破甲次数 × 1。过量伤害不计；破甲不再折算为第二笔 HP 伤害。

通用破甲 PP 奖励按 §5.3 每名发起者每轮至多一次、每次 +1；它进入 PP 账目，
不将上式中的伤害/破甲战果统计也限为每轮一次。两部分权重须一起校准，避免重复奖励过重。

**高光分**：完成的剧情章数 × 4 + 剩余 PP。PP 生成与消费全表见 §17.4。

**终幕王冠（+6，最后存活者专属）**：必须 ≥1 击杀**或** ≥2 章剧情
才能戴上。0 击杀且 <2 章的庸碌幸存者得 0。

### 7.2 死后不打折

V2.0-GA **删除** `1.5 / 0.5` 生者/死者存活乘数与槽位天赋乘数。
生前取得的战果分与剧情分，死亡后照常计入，不缩水。

活着本身不再值钱，打出东西才值钱。

### 7.3 锁章，不锁钱包

战果与已解锁章节永久保留；第三章不冻结旧 PP 余额，也不停止后续得分。PP 按终局
实际剩余量计分。例如完成第三章时有 8 PP，后来花 3 PP，终局这一项计 5，不计 8。
最后存活者与综合评分第一分别公布；评分同分允许并列，不额外用生死身份破平。

### 7.4 十四人的剧情章（首版可达性合同）

每章只领一次；同一根行动满足不同章的独立条件，可以连续解锁。空操作、预检失败
不算生效。下表来自基线 RFC；章节难度是否相当仍须风洞验证。

| 天赋 | 第一章 | 第二章 | 第三章 |
|---|---|---|---|
| T1 | 斩击造成有效伤害 | 斩击破甲 | 公演穿屏障伤到本体，或斩击击杀 |
| T2 | 隐匿攻击造成有效伤害 | 成功暗影步 | 两个不同轮次完成演出有效攻击 |
| T3 | 玉璋实际承担攻击 | 天星成功石化 | 对自己石化的目标完成破甲或击杀 |
| T4 | 完成一次有效起卦 | 累计三种卦象 | 公演生效，且累计四种卦象 |
| T6 | 合法热线或个人有效攻击 | 整备编队或个人破甲 | 完成一次执法击杀或个人击杀 |
| T7 | 挂上保险 | 祝祷产生实际治疗或净化 | 保险兑现 |
| G0 | 实际挂载两种遗物 | 无人机协同有效射击 | 四遗物均有挂载/过载记录，且释放十字炮火 |
| G1 | 进入次级燃烧 | 完全燃烧中有效攻击 | 完成燃烧窗口并存活，或繁育中获救/胜出 |
| G2 | 首次演出生效 | 累计六枚键位 | 进入任一终局 |

| G5 | 讲故事生效 | 第二阶段献诗生效 | 升格，或三个不同轮次有效献诗 |

| G7 | 完成一次融合 | 双融合并执行战术宏 | 全弹倾泻有效命中，且曾主动架盾承伤 |

T6 没有警察时可以走个人攻击/破甲/击杀路径；G5 不升格也可通过三个不同轮次的

## 八、警察：防暴编队

### 8.1 从三个 NPC 到一支军队

V2.0-GA 删除 3 个独立警察 NPC 的寻路与逐个指挥，以及 4 类证据报案链。

**平时**：治安小队驻守警察局；目击/受害者/T6 热线可挂通缉；每轮 R4 对通缉
犯执行齐射。R2 只处理就任、编队和案件状态，不再重复攻击。

**队长就任**：合法玩家在警察局申请后，下一 R2 就任。特警编入随身
**【防暴编队】**，随队长同地点移动，不再逐个搬运。

### 8.2 两个姿态（T0 免费切换）

**防暴盾墙（防御）**：在队长正面建立 Barrier（每存活特警 4 点）
+ 全军蓄力齐刺（基础 2，伤害随特警数 +1/人）；**架盾期间本轮不可 `move`**
——死战不退，因为编队结构决定了退不了。

**火力压制（机动）**：正常移动；队长攻击时特警协同合击。

协同合击、即时齐射、R4 自动齐射共享编队每轮一次普通攻击额度。目标必须满足
通缉资格、射程、视野与隔离条件；队长未指定时按通缉登记顺序、actor ID 选择，
执行前公开。例如本轮已随队长合击，R4 就不会再凭同一普通额度打一轮。

### 8.3 破阵途径（反制设计）

这是刻意给出的，不是规则漏洞：

- 范围 AOE 同时刮特警与队长（盾墙不挡 AOE）；
- 震荡 / 钩索 / 闪光弹强制瓦解盾墙姿态；
- 命令特警攻击无辜者 → 威信反噬 → 特警哗变减编。

### 8.4 通缉与案底

案底来自合法犯罪事件，目击/受害者/T6 可据此挂通缉。军基未用黑市通行证获取装备
自动记案底（见 §4.5）；私宅、病毒和军基旧许可触发源全部退役。

警局被毁、队长解职或 NPC 停机不删除既成案底，只改变当前执法能力；律法重建也
不洗白记录。T6 在警务不可用时保留普通攻击与合法案件记录；整备必须指向真实
合法编队，不因一次演出凭空复制第二支。

## 九、往世层：三个按钮

### 9.1 从二十六张牌到三个按钮

V2.0-GA 删除 26 种独立攻防魂援表。往世层不需要背诵任何新内容，因为它的
三个权能都基于你已经知道的东西。

### 9.2 权能一【押注】

每个 R0 可选择或调整 1 名生者，只对之后的击杀/破甲/夺冠事件分红，不能看到
结果再改押。同一事件生成固定分红池，多名押中者均分：击杀 2、破甲 1、合格夺冠 2 PP，
完整频率与余数规则见 §17.4；不按死者人数
凭空复制奖励。例如某事件产生 2 PP 分红池，两人押中就分享这 2 PP，而不是各造 2 PP。

### 9.3 权能二【微光】

每轮花 2 PP，从三个按钮里选一个，零新增背诵：

- **赐福**：目标 +3 临时屏障（Barrier 层）或回 2 HP；
- **启示**：目标先攻 +2 且 +1 SP；
- **凝视**：目标破隐（自动看穿隐身）+ 下次受击 +2。

生者也可付 PP 向死者求援，方向是双向的。
每名死者每轮至多执行一次微光；同一生者每轮最多接受一次微光增益，多名死者不能
给同一人叠出多份屏障、先攻或 SP。付费与受益者公开，额度按实际执行消费。

### 9.4 权能三【Encore 英灵凭依】

每名死者整局 1 次，把生前 1 SP 即演的核心效果借给 1 名生者（神代借 7 枚简
化标记中选一枚，见 §13.3），不借整套角色状态。T7 只借祝祷；T4 不借或跃，抽到
额外回合结果重掷。其余原初借对应的 1 SP 简化效果，仍须满足合法目标与资源条件。

## 十、世界时钟：20 轮

### 10.1 四个阶段（已冻结）

平均对局目标从约 40 轮压缩到 15–20 轮。
下表使用**世界时钟刻度**，不是倒流期间仍不断增加的实际全局轮编号。

| 阶段 | 轮次 | 关键变化 |
|---|---|---|
| 黎明 | R1–4 | 开局发育期 |
| 白昼 | R5–10 | 地点供应竞争；击杀开始掉落 |
| 黄昏 | R11–15 | 神代终局集中期：G2 终局判决、G5 升格窗口锚在黄昏之后 |
| 终焉 | R16 起 | 每 R4 全员承受环境 `DIRECT_DAMAGE`，16–20 为 1/2/3/4/5，之后继续每刻度 +1 |

终焉是毒圈，只是它不画成圈，而是画成时钟。你若坚持在原地等下去，它会
亲自来拔。

首轮 R0 时钟为 1，此后只在 R0 推进：正常 +1，炉心后 +2。跨两个刻度产生两次
G2 节拍，不额外产生行动、警务、回血或状态 tick；R4 只结算当前刻度的环境伤害。
实际全局轮最多 40，届时按快照计分；多名幸存者不发王冠。此兜底触发即记录节奏异常。

### 10.2 G5 倒流期间时钟停走

G5 阶段三（德谬歌）激活时间倒流后，世界时钟停止向前（含 G2 炉心融解的
2 倍速）；终焉灼伤暂停；倒流终止后，已建立过的炉心双倍速恢复，即使 G2 已死亡
或获救。普通状态与角色自身倒计时继续，不把所有计时器一起冻结。详见 §12.6。

## 十一、原初天赋 T1–T4、T6–T7

V2.0-GA 没有 T5。原 T5 槽位已转为 G0（神代零号），T5 combo 的一切不迁入
本 profile。以下六人是本版基线对齐快审后的结果，骨架保留，接口更新。

### 11.1 T1「一刀缭断」

一句话概括：一次很不讲道理的近战攻击。对象是同地点、已显形的目标（无需
先 find），需持有合法近战武器。

核心：`skill_core_multiplier=2`，斩击对外甲施加强化碎甲：每减免 1 点伤害消耗
2 点耐久，尾数按 §5.3 的最后 1 点保护处理；不另设「碎甲直灌本体」算法。与属性
克制等双倍来源同时成立仍取单价 2，只对本击选中的一件普通外甲计费。掩体、命中与
死亡结算正常进行。

- **1 SP 即演**：消耗 1 SP，占 T1，结算完整核心；
- **2 SP 公演（可崩铁式插队）**：公演特权——本次斩击**无视目标第 1 层 Barrier**，
  一刀连盾带人劈开；开放往世层 Encore 与「游侠」诗追演。

「游侠」诗：下一次 T1 斩击可无视距离 chase-move 到任意已 lock 目标面前出刀；
若这一刀击碎外甲或完成击杀，返还 1 SP；兼有两种结果也只返一次，不占关注额度。

### 11.2 T2「剪刀手传奇一突牢玩家」

T2 的几条常驻身份：

- 伤害玩家但未杀死，不视为犯罪；
- 每第 2 次实际击中外层护甲时，修复自己同名且尚未破碎的外甲 1 耐久；
- 击杀数为 0 时，攻击不解除自身隐身；
- 1 SP 即演对同地显形目标直接攻击；2 SP 公演先 `move` 追到目标地点再攻击。

**暗影步（如影随形）**（V2.0-GA 更新，对齐基线铁律 4）：当与 T2 同地点的
目标主动 `move` 离开时，若 T2 持有 ≥1 SP，可选择消耗 1 SP——立即跟进移动
到同一目的地，并自动对目标挂 `lock`。**每局限 2 次**。
这是受限反应，不附赠 T0/T2；1 SP 原地攻击本身占 T1。

旧追猎反应（免费 find/lock）随基线铁律 4（同地显形免 find）贬值退役，以
暗影步替代。

「地火」诗：立即获得 1 个 ExtraTurn；立即进入隐匿；重置本局暗影步触发次数
至满额（2 次），且下一次暗影步无需消耗 1 SP。

### 11.3 T3「天星」

**1 SP 即演【玉璋护盾 / 地心岩脊】**（T0 宣言，不占 T1）：耗 1 SP，为自己
展开一层岩障（Barrier 层，耐久 3，持续 2 个未来 R4），并对同地点随机 1 名敌人造成
1 点震波外甲磨损。该震波按 §5.3 DEC-014 只损耗装备：无甲不改扣 HP、不产生
保底伤害；磨甲部分无效也不取消为自己展开的岩障。填补 SP=1 时的空白期。
自动选该敌人当前耐久最高的一件甲，同耐久按装备 ID；适用屏障可先承接震波。
玉璋本身为普通有限屏障，破碎余量继续结算，不享圆环的整击拦截特权。

**2 SP 公演【天星】**（可崩铁式插队）：在当前地点对除己外所有合法单位造成
无属性穿防 AOE（`defense_coefficient=0`，仍受普通减伤/掩体及明文承接约束，不另经
一次普通外甲耐久吸收，不是 `DIRECT_DAMAGE`）并施加**石化**。盟友也会吃，所以请在天星下落前确认队友不
在覆盖范围内。

石化者在槽开始特殊窗口可放弃保持，或每次花 1 SP 以 50% 概率挣脱（同槽至多两次）；
成功后可正常 T0/T1，不占小动作；也可等两次有效伤害或持续期到期解除。

「群星」诗：场上由该 T3 施加的石化升级为**尘世之锁**（不再因受击解除，只
能自行挣脱或到期）；立即为 T3 免费套满额玉璋护盾；下一次天星后额外弹射
2 颗无属性穿防流星。

### 11.4 T4「六爻」

选择另一名玩家猜拳，按组合结算六种结果。无使用次数限制，只检查 SP 与入口合法。

| 组合 | 卦象 | 效果 |
|---|---|---|
| 双剪刀 | 潜龙勿用 | 对目标造成穿甲伤害 |
| 双石头 | 飞龙在天 | 复制目标一件外层护甲（不破坏原件） |
| 双布 | 元亨利贞 | 免疫伤害与 debuff 至下一 R0（= 顶格 Barrier） |
| 剪刀/石头 | 亢龙有悔 | 禁用一件非拳击武器；无可禁则震荡 |
| 剪刀/布 | 或跃在渊 | 当轮获得 1 个 ExtraTurn（基线白名单来源） |
| 石头/布 | 群龙无首 | 清除被发现/锁定并隐身；对手传送到随机建筑 |

1 SP 正常猜拳占 T1。**2 SP 公演特权**：同时对至多两名合法目标分别起卦；双人局
可只选唯一对手，不要求补出第二个目标。无诗篇时不能自选结果；阴阳诗是明文例外。

「阴阳」诗：获得 2 层「阴阳的天机」，下两次发动六爻时无需猜拳，直接钦定
一种卦象（除或跃以外的五种）必定生效。

### 11.5 T6「朝阳好市民」

T6 的完整警察系统规则见第八章。演出快查：

**个人进攻基准**：T6 没有独立伤害演出，个人直接输出依赖普通武器攻击。编队齐射
受执法条件与编队状态限制，不能保证每个目标、每个局面都可调用；其防御对抗与成长
须按 §5.2 的普攻可用性约束验证，不预设另有高倍率或直达技能可以破局。

**被动【特别线索】**：合法伤人/杀戮犯罪、未用黑市通行证取得军基装备等写入公开案底；
私宅、病毒和军基旧许可触发源全部退役。T6 死亡后记录仍保留；警务停机不洗白。

**T0 小动作【市民热线】**：场上有犯罪写入案底后，T6 可在 T0 免费挂【全城
通缉】（不占 T1），无需到警察局，被通缉者成为防暴编队合法集火对象。

**演出【联防军需整备】**：
- 1 SP 即演占 T1：为真实合法编队整建制升级一项（高斯齐射阵列 / 盾墙耐久强化 / 补充 1 名阵亡特警编制）；
- 2 SP 公演（可插队）：整建制升级 + 若场上无队长，可直接呼叫防暴编队空降
  当前建筑，执行一次齐射执法或立起盾墙。

「律法」诗：若警察局曾被摧毁停机，直接重建并唤醒防暴编队；立即补满 3 名
特警满编并全员升级最高阶装备，空降至 T6 所在建筑，免费执行一次全军蓄力
齐刺或满额防暴盾墙。
以上不能复制第二支编队；攻击共享 §8.2 的每轮一次普通编队额度。警务不可用时
保留个人攻击与案件记录，剧情可走 §7.4 的个人战斗路径。律法重建不能解除仍在的
世末之雨、倒流停机或 Terror 拒绝执法。

### 11.6 T7「死者苏生」

即演或公演时，公开选择一名存活玩家（含自己），挂载全局唯一的**复活保险
伏笔**。无需去魔法所学习，无地点限制。T7 死亡后已挂好的保险仍存在。
1 SP 即演占 T1；普通濒死先处理自身形态转折，只有仍需外部承接才消耗保险。

目标普通致死时按顺序结算（Death Gate 第三层）：
1. `absolute_death` 来源：保险不赔付；
2. 目标自身明文免死效果优先；
3. 否则优先原地复活；地点无效则医院，再按固定建筑 ID 选未毁公共地点。恢复半最大
   HP（向上取整）、SP=0，保留背包，清普通控制和灼烧；不修满普通
   外甲，不刷新每局一次能力或本轮奖励额度。取消此次死亡/击杀，保留既成伤害与犯罪。

兑现后伏笔消耗、保险资格耗尽；关注 SP 和祝祷继续可用。

**补 1 SP 即演【生者的祝祷】**（填补挂保险后/落幕后的白板期）：当场上已有
保险伏笔或保险已兑现时，T7 可耗 1 SP、占 T1，为目标回 3 HP 并清普通
负面状态；不清案底、爱愿或不可逆形态。例如保险已救过人，T7 下轮仍能攒 SP 给自己祝祷。

「彼岸」诗：若保险未触发——目标因保险复活时 SP 置满为 2，并免费获得一件
护甲与近战武器；若保险已触发——整局至多重启一次保险资格、挂第二枚保险。同一
T7 整局最多兑现两次，重复献诗不能无限续保；Encore 只借祝祷。

## 十二、神代天赋 G0–G7

神代天赋是 V2.0-GA 的设计雄心所在。它们不是"比原初天赋更强的按钮"，而是
八种叙事前提不同的规则系统，共享同一个战场。每个角色使用完全不同的资源
语言（火种 / 魔力 / 追忆 / Cost / 孤独值 / 色彩 / 笑点 / 失熵），彼此不通用、
不可转换，但相互之间有预置的交叉影响点。

认知复杂度很高。开桌前请确认大家愿意看别人演出，而不是只愿意看自己赢。

### 12.1 G0「我还欠她们一个明天」——砂狼白子*Terror

来自另一条时间线的阿拜多斯。燃烧生命战斗的孤独枪手，背负逝去同伴的遗物。

**BLACK FANG 465（AR）**：开局以 AR 取代弓，箭矢按 1:3 转化为子弹（初始
15 / 上限 30）。两种射击模式：

- **点射（1 发）**：基础伤害 4；
- **全自动扫射（3 发）**：本次伤害 +2，且额外削减目标 2 点外甲耐久。

AR 不能装普通弓模块，有专属双**【遗物改装槽】**，T0 小动作切换挂载。

**阿拜多斯遗物（开局自带 4 件）**：

| 遗物 | 挂载效果 |
|---|---|
| 星野的破裂圆盾 | 每轮获得 2 点临时屏障；场上有 G7 时另有羁绊加成 |
| 野宫的机枪弹链 | 全自动扫射附带溅射，刮擦同地点另一随机敌人 |
| 芹香的瞄准挂件 | AR 攻击视为已 lock（无视移动闪避 + 破甲加成提升） |
| 绫音的破碎眼镜 | 当轮实际付过技能 HP 后，该轮 R4 回 1 HP；每轮一次 |

**1 SP 即演【深渊无人机·神秘协同】**：消耗 1 SP + 当前 HP 的 20%（向上取整，
最低 1，不致死）；T0 部署不占 T1。无人机持续 3 个未来 R4 tick，随 G0 移动，
可被攻击（不算犯罪）。无人机在场时 AR 射击转为**神秘属性**——对一切普通/
魔法/科技外甲均触发克制（双倍碎甲）；每次 AR 攻击协同追加 +1，无人机 HP4。

**2 SP 公演【黑洞·十字炮火】**（可崩铁式插队）：入口需无人机在场；消耗
2 SP + 当前 HP 的 30%（最低保留 1 HP）。对当前建筑内除 G0 外所有敌对单位
造成 `DIRECT_DAMAGE`（恢复真伤口径，撤销风洞"普通属性必中"修正，不再自伤）。
无人机释放后消失（超载自毁）。

**遗物绝唱（可选）**：释放时摧毁 1 件挂载遗物，附赠绝唱——
星野盾 → 震荡全场 + 自身屏障拉满；野宫弹链 → 炮火伤害翻倍；芹香挂件 →
炮火穿过有限数值屏障，仍受替身/绝对免疫承接，不另附普通磨甲；绫音眼镜 → 炮火结束后将自身 HP 抬回安全线。

**调整呼吸（Death Gate · 最后的 15 秒）**：每局 1 次；普通致死触发
（`absolute_death` 不触发）。锁 1 HP，清除普通控制；两轮窗口内阻止普通、直达、
DOT 与环境伤害造成的 HP 损失，绝对死亡致死来源仍可斩杀；自身技能代价照付。
期间装填免费但仍受库存/容量约束，仅实际造成的敌方 HP 损失可吸血，不从屏障损耗、
过量伤害或自损吸血（每根实际 HP 损失汇总的 50%，向下取整）。2 轮结束 HP ≥ 6
→ 逆转成功继续战斗；否则撤退。

**撤退（体面谢幕）**：不算被击杀（不产生凶手人头），不进往世层；PP 冻结；
战果分/剧情分 100% 全额保留；第三章不额外冻结一个旧 PP 快照；
计入"玩家出局"事件（G7 色彩 +2）。

**第 3 章弧光「我还欠她们一个明天」**：本局内挂载/过载过全部四件阿拜多斯
遗物，且轰出过十字炮火；全部三章见 §7.4。

**G5「明天」诗**：黑子打工信用点额外 +1，所有商店/医院/军基消耗 −1（最低
1）；下一次十字炮火不消耗自身 HP，且可同时过载触发 2 件遗物绝唱而不摧毁任
何遗物；若释放时正处于调整呼吸，立即恢复 6 HP 跨过止损线。

### 12.2 G1「火萤·燃烧循环」——流萤 / SAM

最后的格拉默铁骑，失熵症少女。**燃烧就是在死**——卸甲调息与着装参战的
风筝循环，以及必死的第三次死亡。

**三态阶梯（单向上行，可跌落）**：

| 形态 | 进入 | 失熵速率 | 行为约束 |
|---|---|---|---|
| 卸甲常态「流萤」 | 起始态 | 慢速 | 攻 −1 / 受击 +1 / 命中惩罚；可发育 |
| 次级燃烧「SAM·着装」 | T0 宣言，1 SP | 中速 | 禁 find/interact；解锁超新星 |
| 完全燃烧 | 2 SP 公演（须次级） | 最快 | 窗口 3 轮；T2 StepFollowup(allowed=[move,attack]) |

卸甲不是安全，只是更慢地死。每 R4 失熵缓慢累积，不暂停；本行动回合无攻击
类行动则 R4 失熵回落（唯一常规回落通道）。
卸甲发育补偿确定为有费用的 interact 减 1（最低 1），不再额外
叠卸甲移动闪避。主动卸甲不付 SP，但占唯一 T0；医院内循环炉按 §4.4 减少失熵累积。

**失熵量表**：0 起步、有上限的公开量表。达阈值 → 当轮 R4 触发结算，随后
回落（不清零——疾病不会痊愈，只是压回一段）。结算顺序（三层漏斗 Armor 层）：

1. 持有炽愿可消耗 1 层完全抵扣；
2. 否则摧毁 1 件自选外甲；
3. 无外甲时扣 HP——卸甲的她被失熵直接啃食血肉。

失熵结算不构成"受到攻击"，不触发反击/关注/犯罪。

**终焉环境抗性（V2.0-GA 分档）**：着甲态 100% 免疫终焉灼伤（含 G2 炉心融解
翻倍后的双倍终焉）；卸甲态实际承担 ceil(环境伤害×50%)。这对应星核猎手的使命——
应对虚无导向的终末结局。G2 炉心融解后的双倍终焉核冬天里，只有着甲的萨姆
毫发无伤。

**DHGDR-超新星过载**：形态门槛次级及以上。获取：进入次级 +1，完成击杀 +1，
上限 1。发动：`move` 根行动触发（落点可为当前地点），对落点内除己外玩家与
警察造成 AOE 伤害 + 穿甲 + 挂灼烧（普通属性 + `defense_coefficient` 折减）。

**超击破近似**：次级及以上形态，对受控（震荡/压制/石化）或灼烧/虚弱单位
攻击获得固定加值 +1。自洽循环：超新星挂灼烧 → 后续攻击吃增伤，
不依赖队友。

**第三次死亡（繁育）——3 轮必死倒计时**：

触发：每局 1 次。**本局曾开启过至少 1 次完全燃烧，且当前处于 ≥ 次级燃烧状态
时受到第一次普通致死伤害** → 必定触发（无概率骰）。`absolute_death` 来源
直接杀死，不入繁育。防开局碰瓷：没开过完全燃烧就没有第三次死亡；触发权
部分在对手（可以不打死她）。

内容：倒计时 3 轮（建立轮不 tick）；归零 = **绝对死亡**（进白名单，绕过一切
免死/复活/T7）。繁育期间再次普通致死 = 正常死亡（星核只有一枚）。

**繁育态效果**：
- 先攻 +3，繁育初始 HP 置 8（不超最大值）；
- 每轮首次合法 `move` 触发**结构超新星**（不读 SP、不占公演、不耗过载）→

### 12.4 G3「神话之外」——士郎

英灵卫宫的投影魔术与固有结界——「神话之外」= 无限剑制。母题：以魔力换
取时间；剑之丘陵的持续齐射，不是一发爆气。

**魔力与 SP（职责分离）**：魔力支付投影、维持与超限；SP 决定何时展开固有
结界——两者不互相替代。开局魔力 6，常规上限 8，结界外每 R0 恢复 1（唯一常规恢复入口）。

**结界外投影（T0 减负）**：非攻击型持续投影为 **T0 小动作**，支付对应魔力，
不占 T1：

- **七重圆环（Rho Aias）**：T0 展开，登记为三层漏斗第 1 层 Barrier——远程
  直接攻击先打圆环，击破当次不向本体溢出；
- **双刀·守势**：T0 建立防御标记，下一次以 G3 为目标的攻击取得固定减伤后
  消耗（`DIRECT_DAMAGE` 消耗标记但跳过该减伤）；
- **见证与复制**：见证过的普通武器家族可付魔力投影基础型（只复制基础伤
  害/属性/射程，不复制模块/弹药/蓄力/专属标签）；结界外只维持**一个持续
  投影通道**，新 T0 投影成功后旧持续投影在该回合收尾清理。

**攻击型投影仍为 T1 攻击根**：
- **螺旋剑（伪）**：远程攻击根，创建并立即发射；
- **双刀·攻势**：近战攻击根，以合法近战武器为基础 + 固定加值。

**1 SP 即演**（补 M9 空缺）：
- **鹤翼三连（近战双刀）**：1 SP，本次双刀获得固定加值；命中外甲时触发连携
  追击——额外磨损外甲耐久且必中；固定磨损部分按 §5.3 DEC-012，在本击扣血与普通
  外甲计费确定后结算，不反向增加本击扣血、不把余量转移到另一件甲；
- **伪·螺旋剑（远程狙击）**：1 SP + 魔力，跨地点轰出一发**无视掩体/屏障**
  的高爆穿甲螺旋剑。

**2 SP 公演【无限剑制】**（可崩铁式插队展开）：当前地点被替换为固有结界。

**展开即剑丘**：剑阵**自动常驻**（G3 攻击获命中加成 + 每轮第一次以 G3 为
目标的远程直接攻击被剑阵 Barrier 拦截）；已见证的复制武器自动进入**兵装池**，
随取随用、免创建行动与魔力。

**捕捉**：当前地点全部存活玩家 + 敌对/中立 NPC；警察不进入（案件挂起）；
外部世界继续推进；内外不能跨边界交互。

**主目标**：展开后公开指定 1 名存活被捕捉单位（幻想崩坏的唯一合法目标；
每个回合设置时可免费改选，不占小动作；死亡/离界即清空）。

**结界锚点与破界**：被困者可用普通武器攻击根打锚点（按 A 扣结构耐久），
或 `break_barrier` 稳定扣耐久（占整个标准行动）；锚点归零 → 强制解除，未
行动者回原地点后仍按原顺序行动。

**维持费简化**：每未来 R4 支付 1 魔力，最长 3 个未来 R4，建立轮不 tick。
各投影费用、锚点与伤害见 §17.9，不再使用 M9 五项加法公式。

**宝具连发与赤原猎风**：

- **`projection_chain` 宝具连发**：结界内螺旋剑根行动首发结算后，可支付递增

  复制武器不进入连发白名单；
- **累计耗魔计数器**：每根行动独立累计实际支付的投影魔力，达阈值后——
- **赤原猎风**：自该次起、本根行动内后续命中玩家单位的释放附加即时效果：

- **回路接通**：触发赤原猎风 → **理想燃烧自动点亮** → 可在同一根行动末尾
  无缝衔接终段幻想崩坏（不再需要打卡凑式样数）。

**幻想崩坏**：消耗全部剩余魔力 + 牺牲兵装/防壁/剑阵；对主目标结算一次统一
攻击：基础伤害 = `4 + min(本次结界累计式样数, 4)`
（式样自动累计）；普通属性、防御系数0.5 + **双倍耐久计费**（非 DIRECT_DAMAGE）；
结算完成后无条件解除结界。也可不终结保留结界（维持费照付），此后独立发动
幻想崩坏（需 `collapse_terminal_min_magic`）。

**G5「永恒」诗**：立即为 G3 恢复 4 点魔力（可突破上限转为临时魔力）；下一
次固有结界内，螺旋剑【宝具连发】首段免费（0 魔力）且连发上限 +1 段；展开

### 12.5 G4「愿负世，照拂黎明」——白厄

白厄 / 卡厄斯兰那——「以旧日余烬为来世破晓，烈阳撕裂长空」。母题：永劫轮
回里的英雄。与 G2（盗火×白厄双生）、G5（时间倒流 ∞）共同构成轮回叙事轴。

**资源：火种（上限 12）**——只在人形态积累。三条途径：

| 来源 | 条件 | 增量 |
|---|---|---|
| 受难之火（被动） | 人形态承受他人有效伤害（HP 损失或外甲破碎） | +1；每轮受击类至多 +2 |
| 逐火之剑（1 SP 即演「夺火」） | 人形态消耗 1 SP 发动斩击；命中或破甲 | +2 |
| 余烬共鸣（环境） | 场上其他玩家阵亡，或建筑被摧毁 | +2 |

不计入：DOT 后续 tick、环境/世界时钟伤害、自我消耗。撤销风洞修正
"敌对外来火种 1→0"——白厄的核心是用血肉扛下世界的恶意，受击攒火必须恢复。

**进入救世主形态（两条路径）**：

**主动升格（完整救世主）**：火种 = 12 且人形态；任意 T0 小动作主动燃尽全部
12 火种（不占 T1）；若公演位仍空，可直接用当前标准回合 T1 公演；否则保留 SP
选其他主行动。ExtraTurn 禁公演，不另外创建一个插队槽。
升格瞬间 SP 置满为 2；获得**余烬生命** 24；初始毁伤 3。

**濒死转折（残缺救世主）**：人形态遭普通致死且持有火种 ≥6；消耗当前全部火种 c
进入残缺形态；余烬生命为 2c，初始毁伤 max(1,floor(c/4))。火种 < 门槛 → 正常死亡（不拦截，杜绝 0 火种碰
瓷）；`absolute_death` 来源直接杀死。

M9 的"负世主动燃尽派发完整额外行动"**退役**——升格不创建额外行动槽。

**救世主形态（3 轮极境燃烧）**：持续 3 个未来 R4 tick（建立轮不 tick）；
形态内不再获得火种；毁伤为形态内局部预算，退出清空。

**强化普攻**：占标准根行动，不耗 SP；所选普通武器基础伤害 +2，命中毁伤 +2；T2 附带
【烈阳余波】对同地点其余敌人各纯磨甲 1。不做无条件扩散，不复制
十六次弹射拓扑；余波是附加效果，不再赠送一个行动槽。

**2 SP 公演【灾厄·弑魂焚诏】**（可崩铁式插队）：消耗当前全部毁伤 D，天裁段
数 = D。结构：

```text
全桌秘密承诺「迎战 / 拒战」
→ 迎战者按先攻降序逐个执行 challenge_response（受限反应，非完整行动）
→ 对迎战者的统一反击池
→ 对拒战者的死星天裁池
→ 公演收尾
```

- **迎战者**：临时解决距离/面对面，由玩家选择一项合法普通攻击，弹药照付，无可用
  武器可拳击；不强制最佳载荷，不借机公演或开宏。每次合法挑战天裁段数 −1；不产生
  犯罪/SP/关注/警务额度，也不附赠 T0/T2；
- **拒战者**：平摊剩余段数的死星天裁总池（`DIRECT_DAMAGE`；致死结果附
  `absolute_death`）；
- **固定总池**：反击与天裁都按总池均分，不按人头复制；分配顺序按先攻降序、
  actor ID；
- 秘密承诺前公开毁伤与两种池的分配规则，玩家知道迎战/拒战各意味着什么；
- **强制中断**：挑战攻击迫使 G4 退出形态 → 停止后续响应，取消反击与天裁，
  转入退场清理；
- **隔离边界**：不穿透结界类隔离（G3 重做后沿用"不穿透隔离层"原则）。

这是一个复合博弈：迎战有风险（你要攻击救世主），但可以降低其他人的天裁
压力；拒战更安全，但集体拒战会让天裁集中到所有人头上；合力抗争（全部迎
战）可通过强制中断退出形态彻底规避天裁。这不是简单的打 BOSS，而是全桌
的利益协商。

**退场**：天裁结算后 / 3 tick 到期 / 余烬血条被打空 → 退出形态，火种归零，
回人形态（可再次逐火）。章节按 §7.4，PP 按终局实际余额计分。

**G5「负世」诗**：人形态立即 +4 火种（无视每轮受击上限）；救世主形态立即
+4 毁伤；**【永劫的烈阳】**：白厄进入救世主形态后，3 轮倒计时**冻结**（只
要余烬生命未归零，形态永不因回合到期退出），且救世主攻击额外附带烈阳火伤；
**代价**：救世主形态存续期间，每个 T0 自动给自己挂 1 层【灼烧】（R4 真实
扣血，不可被常规净化免疫）。
必须在献诗时向 G4 展示永久改造和灼烧代价，由其主动接受；拒绝不退款，永久效果不叠加。

**宿命联动**：白厄常驻灼烧 → 恰好被 G1 流萤的超击破（对灼烧目标增伤）克
制——兑现"G1 与 G4 相互 counter"的原始设计。

### 12.6 G5「往世的涟漪」——昔涟 / 德谬歌

机制原型：ASBR 恩里克·普奇（最终）三阶演进——白蛇 → C-MOON → 天堂制造。
叙事轴：哀丽秘榭的小昔涟 → 黄金裔的同行者 → 记忆星神·德谬歌。

硬约束：昔涟不是死神，是执笔记录、陪伴、最后以自身走向过去换来明天的人。
压制开拓不是她做的事；手填 K 步脚本废除（RL 时间债不可接受）。

**资源：【追忆】**：场上高光事件（破甲/公演/阵亡）+1；T0 小动作「执笔」+1；
上限 12。追忆不是 SP，不交易、不计分，只驱动昔涟自己的三阶段。
每个根行动至多取得一次高光追忆，执笔另算；第一、第二阶段继续增长，第三阶段停止。

**阶段一「哀丽秘榭的讲述者」（开局态）**：正常 20 HP 入场，可正常移动/交互/
攻击。演出【讲故事】（2 SP 大即演，占 T1、不占聚光灯）：选择同地点一名其他玩家——
自己追忆 +2；目标 **SP 置 0**，同时 **HP +1**（温柔的抚慰：废掉其爆发，又
给一口防斩杀的奶）。

**进阶**：追忆 ≥ 6 且支付 1 SP（T0），升入阶段二。

**阶段二「黄金裔的同行者」（C-MOON 式纯数值）**：常驻被动【记忆的重量】——
按当前追忆加普通攻击与固定减伤，各为 floor(追忆/6)，最多各 2；代付后同步下降，不取历史峰值。
演出【此诗，献予一切生命】（基础 2 SP；**每少付 1 SP 可用 2 层追忆代替**：2 SP / 1 SP+2 追忆 /
0 SP+4 追忆；大即演，占 T1、不占聚光灯）：

- 对他人：展示效果和代价，支付成本并发出，目标主动接受后授诗篇强化 + 挂爱愿；
  拒绝不退资源或 T1（期间目标不能伤害昔涟；昔涟攻击
  则破碎）；
- 对自己：咏唱「爱与记忆」，对至多 n 目标射科技/普通/魔法/无视属性多段箭
  （初始段数 1+ceil(初始人数/2)，每次使用后下次 +1、最多 6；每目标最多 2 段，见 §17.11）。

**停在阶段二平推是完全成立的玩法**——对应"不上天堂制造也能赢"。
三个不同轮次有效献诗也能完成第三章，不必为剧情分强行升格。

**阶段三「我的明天叫做昨天」（记忆星神·德谬歌）**：

升格条件：第二阶段、世界时钟已到黄昏、当前追忆 ≥ 12 且支付 2 SP，使用公演入口。
完成后进入第三阶段，但**不删除本轮其他人的任何行动槽**；下一 R0 才启动倒流、
NPC 停机与动词约束。即使 G5 在 R3 首位公演，其余人本轮仍照常行动。

**时间倒流（历史动词倒放）**：下一 R0 起世界时钟停走，历史指针从升格实际轮 N 的
R_{N-1} 起递减。每轮 R0 公布所有存活玩家在对应历史标准回合执行过的**根行动
动词**（move / attack / interact / special 四大类）。除德谬歌外，每名玩家本
轮必须执行与历史相同的动词类型（具体对象/地点/武器自由重选）。
不读宏内步骤、追击或额外回合；历史无行动或当前确无该动词合法动作时免责自由选。
例如历史为 interact，但当前没有任何合法交互，则不因程序无选项惩罚玩家；仅嫌费用
高不算无法执行。普通状态与角色自身倒计时继续，倒流不冻结所有计时器。

**违逆命运惩罚（逐层叠加，满血满盾也扛不住连续忤逆）**：
1. 第 1 次：震碎 1 层屏障 / 扣 4 点外甲耐久（无甲则 −2 HP）；
2. 第 2 次：4 点 `DIRECT_DAMAGE` + 震荡；
3. 第 3 次起：`6 + 2×(次数−3)` 点 `DIRECT_DAMAGE` 且 **SP 清零**。

倒流期间（钉子 9）：世界时钟停走（终焉灼伤暂停；G2 双倍速暂停）；德谬歌
豁免动词约束、保留基础行动但不可再献诗；死者不行动、不受约束；德谬歌被
击杀 → 倒流立即终止，她按正常死亡进往世层。

**∞ 闭环（钉子 10）**：倒流指针抵达 R1 的瞬间（R1 的起床**不需要重演**）：
先保存战果、章节、PP 实际余额与存活者的计分快照，再把幸存面板展示为未起床并定格
结算。重置的是终幕表现，不清空已取得的成绩，也不真的重新开一局。

**第三阶段德谬歌不能献诗**；第二阶段可对他人献诗或对自己使用爱与记忆，见 §13。

### 12.7 G6「要有笑声！」——花火 / 阿哈

欢愉是活人之间的恶作剧、替身嫁祸、当身博弈与全员惊喜礼盒。与往世层
Encore（死者托付本命技能）和 G0（阿拜多斯遗物战术枪战）绝不撞车——G6 是
把别人的回合剪成喜剧的导演。

**常驻被动【看热闹不嫌事大】（笑点）**：闪避成功、普通外甲破碎、实际放弃行动槽、
有人拆盒等 → +1 笑点；每根行动至多一次，首版每轮最多获得 3 枚，献诗置满另算。
当身成立不返架设成本，非法指令/A=0/普通屏障拦截不算落空。笑点 = 假币：执行
`interact`（购物/治疗等）时每 1 枚笑点抵扣 1 信用点；上限 3。

**T0 小动作【替身玩偶·假面当身】**（当身技，高风险高回报）：T0 架设【当身
姿态】，支付 1 笑点、不耗 SP，持续至自己下个回合开始前。

- **成立**：第一段合法单体攻击被玩偶吞掉，该段伤害/破甲/附带效果无效；攻击者承受
  3 点烟花直达伤害 + 震荡。SP 走关注额度，不另送第二份，也不返笑点；
- 不拦范围攻击、DOT、环境伤害，不吞整条连段。例如三连射只挡第一枪，后两枪照常；
- **读空**：至下个回合开始没有符合条件的攻击，已付 T0 和 1 笑点不退款。

当身消耗真实资源；普攻能消耗它，不能每轮免费挡刀再把全部成本赚回来。

**1 SP 即演【插入式笑话·移花接木】**：耗 1 SP、占 T1，指定 1 名其他存活玩家 X 为
"冤大头"；**同一玩家不能连续两轮被指定**。二选一：

1. **刷他的卡**：以 X 所在建筑菜单隔空执行一次 `interact`（装备/物品归
   G6）；最多强划 X 实际持有的 2 信用点，不制造负债；不足部分 G6 自付或笑点抵扣，
   无法补齐则预检失败、不扣双方费用；
2. **借他的刀**：以 X 的位置与视野、用 G6 自己的武器（或 X 的基础武器面
   板）攻击与 X 同地的目标 Y——伤害/破甲/击杀归 G6；犯罪案底/通缉可以嫁祸 X，
   直接反击追向实际施术者 G6。不消耗 X 的弹药/专属次数，不复制技能、宏或连发；
   仍需满足视野、射程和隔离条件。

**2 SP 公演【全员派奖·超大惊喜礼盒】**（可崩铁式插队夺台）：向场上所有其
他存活玩家各塞一个【超大惊喜礼盒】。已有未拆盒时保留旧盒和进度，不立即引爆，
也不延后原期限；每人至多一个未拆盒。

**拆盒规则（额外的 T0 抉择）**：
- 持有者必须先得到一次可以自主选择的 T0；压制/失神剥夺了窗口不算拒拆。在此之前
  不能代拆或偷跑兜底。例如 G6 本轮抢先公演，尚未轮到自己的玩家不能马上被代拆。
- **路径 A（自己拆）**：持有者花自己 T0 拆开 → 从六面礼盒池等概率随机 1 项
  生效（拆盒笑点仍按 §6.6 的每根/每轮额度，不逐盒无限叠领）；
- **路径 B（花火代拆）**：持有者得到上述窗口后仍不拆 → G6 可花自己 T0 指
  定 1 名持盒玩家，从 4~6 号负面效果中**钦定 1 项**对其生效；
- **兜底**：首次可选窗口之后的两个未来 R4 仍未拆则自动炸开，随机负面 4~6；
  窗口当轮不 tick，重复塞盒不重置期限。

**六面礼盒池（3 正 3 负）**：

| 编号 | 性质 | 名称 | 结算 |
|---:|:---:|---|---|
| 1 | 正面 | 天降横财 | 立即 +4 信用点并恢复 2 HP |
| 2 | 正面 | 军火大放送 | 自选 1 件普通外甲或 1 把常规武器免费获得 |
| 3 | 正面 | 欢愉任意门 | 免费位移到自己指定的任意公共建筑（不触发借机攻击、不占 T1） |
| 4 | 负面 | 砰砰烟花 | 承受 4 点 `DIRECT_DAMAGE`，且钱包炸飞 2 信用点归 G6 |
| 5 | 负面 | 假冒伪劣 | 1 件外甲报废清零；无外甲则 1 把非初始武器报废（神器/融合武器改为禁用 2 轮） |
| 6 | 负面 | 走错片场 | 强制随机移动到另一公共建筑 + 震荡（破除架盾/防暴盾墙等驻地姿态） |

**G5「欢愉」诗**（已定稿）：① G6 笑点立即回满至 3；② 授「欢愉的延展」标记
（4 个未来 R4 tick）：当身升级【双面假面】（符合条件的单体攻击反噬翻倍至 6 点烟花；
读空 → 玩偶在下个 G6 回合开始时自动飞向同地随机敌人；同地无人按固定建筑 ID 选合法地点，
3 点烟花 + 震荡）；当身仍付 T0＋1 笑点。G6 可一次性代拆所有已获得响应窗口的
未拆盒，每盒钦定 4~6；未获窗口者不受这次群体代拆影响。

### 12.8 G7「大叔我啊，剪短发了」——小鸟游星野

战术宏、融合装备、SP/Cost 与 Terror 构成其战术循环；防御层级和首次攻击预警按本节执行。

**融合装备**：

- **铁之荷鲁斯（盾）**：第一次同时持有盾牌 + AT 力场时自动融合（一次性）；
  受损后 `special 修复`消耗 1 件组件修复；
- **荷鲁斯之眼（枪）**：第一次同时持有电磁步枪 + 高斯步枪时自动融合；弹
  匣上限 8；每次射击消耗 1 发，分成 3 弹丸，总基础伤害 4，分 2/1/1；属性可为科技/魔法/普通；
- 双融合完成 → 自动习得战术指令 + 2 次自由配发（每次可选 1 战术道具 /
  1 药物 / 2 发子弹）。

**光环**：3 层、每层 2，初始 1 层；未交战 R4 总池回 1，战斗内自动回 0。
三层首次全亮 → 一次性【战斗续行】免死（HP6，光环清空）；Terror 形态下不生效；属三层漏斗 Death Gate 的
Morph 层。
光环是有限护体池，在主动屏障之后、普通外甲之前；按实际承伤扣值，耗尽后余量继续，
不是一层吞任意整击。

**Cost 与战术宏**：每 R0 回满基础上限 6；**失却汇流成泉**——上一全
局轮使用过战术宏 → 下个 R0 回满后 Cost −1（不叠加）；肾上腺素覆盖。

**战术宏**：T1 `special Hoshino` 进入，占一个标准根行动（复合根容器）；
只要 Cost ≥ 1 即可进入，**不耗 SP**；逐步执行并扣 Cost，某步不足即中断，
已执行步骤不回滚。宏动作表（Cost）：

| 动作 | Cost |
|---|---|
| 架盾 / 射击 | 2 |
| 重新装填 / 取消 / 转向 / 排弹 / 服药 | 0 |
| 持盾 / 投掷 / 冲刺 / find·lock | 1 |

**架盾**（三层漏斗 Barrier 层，DEC-015–016）：划分正面/背面；取消低伤免费格挡
阈值，每次成功格挡正伤害都按来袭伤害扣盾耐久，最多扣尽。破盾这一击仍完整拦截，
之后失效；只在原本合法的拦截范围内生效。正面敌人正常离开需多花 1 回合；**架盾
期间 G7 无法 move**；每 R4 维持 Cost（水着-Shielder 免费，但受击仍扣耐久）。

**持盾 / 被动保护**：未架盾的铁之荷鲁斯按普通外甲择一减伤、耐久计费；持盾只提高
属性防御，没有额外耐久吸收池、不吞破碎余量、不保留永远剩一点的将破线。免费切姿态
不会修甲。例如主动架盾最后 1 耐久能完整挡一击，普通持盾最后 1 耐久只能支付相应减免。

**战术道具与药物**：

- 道具（军基）：破片手雷 / 震撼弹 / 闪光弹 / 烟雾弹 / 燃烧瓶；
- 药物（医院）：EPO（Cost +1）/ 海豚巧克力（回 1 层光环）/**肾上腺素**
  （全局 1 次，宏外注射占本回合 T0；下个 R0：Cost 回至临时高
  上限 + 光环全恢复 + 先攻 +3——覆盖失却汇流成泉）。

**SP 接口（本次修订核心：SP 与 Cost 咬合）**——

**1 SP 即演【大叔的午休】**（T0，不占 T1）：T0 宣言，耗 1 SP。眯一觉、换个
插板，T1 照常开宏。二选一：

1. **紧急包扎**：立即恢复 2 HP（使用前 HP≤半最大值时为 3）；并清除下轮
   R0 的失却汇流成泉惩罚（睡饱了，不算疲劳）；
2. **更换防弹插板**：尚未破碎的铁之荷鲁斯耐久 +2（或恢复 1 层光环）；并向荷鲁斯之眼
   免费压入 2 发普通子弹（为 2 SP 全弹倾泻备弹）。耐久0不能靠午休复原盾，须另花组件和T1修复。

**2 SP 公演【荷鲁斯之眼·全弹倾泻】**（三形态本命大招）：前置——持荷鲁斯
之眼且弹匣内 ≥ 1 发子弹；2 SP 公演（占 T1；支持崩铁式插队夺台）；消耗
2 SP + **倾泻弹匣内全部剩余 N 发子弹**——N 越多大招越强；自动取所倾泻子弹
中最优属性结算属性克制双倍碎甲。按当前形态释放本命大招：

| 形态 | 大招 | 效果 |
|---|---|---|
| 水着 / 常态-Shielder | EX【战术镇压】 | 强制将当地所有单位划入正面并直接进入架盾；对正面全体扇形轰击（随 N 增伤）并施加震荡；N ≥ 4 时可对 1 名主目标挂 `ACTION_SUPPRESSED` |
| 临战-Archer | NS+EX【扇形连喷·必穿高爆弹】 | 第一段：弹匣扇形四连喷，对当地全体挂脆弱（易伤 + 外甲磨损增加）；第二段：对主目标 1 发**无视 Barrier** 的穿甲点射，命中后范围爆炸波及当地全体（随 N 增伤碎甲） |
| 临战-Shielder | EX【前线突入·移动掩体】 | 可免费跨地冲刺至任意公共建筑（或原地）；落地重砸进入强化架盾（立即恢复铁之荷鲁斯耐久 + 按 N 获得防弹 Barrier）；落地冲击当地全体敌人并施加震荡 |

**色彩、自我怀疑与 Terror**：

- 色彩：每有 1 名玩家出局 +2；由 G7 击杀额外 +2；**G0 撤退按"玩家出局"计
  入 +2**；
- 色彩 6：自己 T0 可选进入自我怀疑；
- 色彩 10：本体受非致死 HP 伤害 → 恢复穿戴过且已破碎的护甲 → 强制自我怀
  疑 → 完整跳过下一标准槽 → 反转为 Terror；额外槽不能代缴，普通压制不能无限延期。

**Terror**（全游戏最具破坏力的状态）：Cost 为 Null；失去战术指令/道具/药
物/铁之荷鲁斯/光环；只能 attack 或 move；进入时护甲/光环/铁之荷鲁斯折算
额外生命（按 §17.12 折算，保底 12、上限 20）；**攻击 = 荷鲁斯之眼对全图所有其他玩家单位分别
造成 4 点 `DIRECT_DAMAGE`，仅真正致死的结果附 `absolute_death`**；不是命中即删人，

## 十四、新手指南

### 14.1 一局最短路线

1. **先起床，领初始包。** 私人房间出门就回不来，刀/盾二选一先决定。
2. **R1 必须出门**：进商店/魔法所/医院/军事基地/警察局之一。
3. **赚钱**：商店打工是唯一经济入口，没人在家里发工资。
4. **准备一套能打人的东西**：弓负责跨地点，近战同地显形直接打，护甲负责
   把对手的攻击变成你的维修账单。
5. **看 SP，不要只看血**：SP=1 可以即演，SP=2 可以选择立刻即演或参与夺台。
   等公演不是必然更强，而是在等全桌舞台——崩铁式插队让你能抢台。
6. **关注世界时钟**：白昼开始掉落，黄昏是神代终局集中期，终焉会把"我再
   发育一轮"变成遗言。
7. **死后继续玩**：普通死亡进入往世层；三个按钮零背诵——押注、微光、
   Encore。

### 14.2 常见误解

**Q：先攻最低是不是又要轮空？**
A：不是。所有正常玩家都有标准行动，先攻只决定顺序。

**Q：SP 是行动点吗？**
A：不是。SP 只管天赋演出，不增加或删除标准行动槽。

**Q：公演是不是天赋加强版？**
A：核心通常相同。公演多的是聚光灯、往世层 Encore、诗篇适配与夺台竞争；强
度看天赋。大即演（G2 全部演出、G5 讲故事/献诗）不占聚光灯但强度同样高。

**Q：`DIRECT_DAMAGE` 是不是必杀？**
A：不是。它跳过普通目标侧防御，但仍可被明文承接；是否跳过复活看
`absolute_death`。

**Q：普通死亡就没事做了吗？**
A：你只是从选手席去了证券交易所。三个按钮：押注、微光、Encore。`absolute_
dead` 才是真正没有往世层操作。

**Q：lock 还要花整轮吗？**
A：不用。V2.0-GA 里 lock 是 T0 小动作，T1 直接攻击。

**Q：公演还要排队吗？**
A：不用。轮初愿意公演的合法 SP=2 玩家按先攻竞争，胜者将标准回合提前到 R3
最前兑现。轮初无人兑现时，轮中满 SP 者可申请在当前玩家回合完整收尾后插队；
不能打断连招，也不能让已经行动的人多一次标准回合。详见 §6.3。

**Q：G7 Terror 没救了？**
A：守夜人诗是解除 Terror、恢复战术形态的救赎入口。没有 G5 时仍可利用预警合力
攻击、隔离与明文承接应对；Terror 是定值伤害真正致死时才绝对死亡，不是命中即死。

**Q：G5 第一个公演，我这轮就不能动了吗？**
A：仍能动。升格不删除本轮其他人的槽，下一 R0 才启动倒流规则。

**Q：T7 已经救过人，是不是以后只有普攻？**
A：仍可取得关注 SP，并用 T1 花 1 SP 祝祷；用尽的是保险资格。彼岸只能再开一次保险。

**Q：我被压制所以没法拆礼盒，算我拒绝吗？**
A：不算。必须先给你一次可以选择的 T0，之后 G6 才能代拆，自动爆炸计时也从该机会后开始。

**Q：昔涟能直接把繁育中的我变成普通人吗？**
A：不能替你决定。她发出诗后，你先看到强化、爱愿和失去机甲的代价，再接受或拒绝；
拒绝不发生改造，施法方已支付的资源与 T1 不退。

**Q：连发里的每次破甲、公演和击杀都给昔涟追忆吗？**
A：同一个根行动最多给一次高光追忆；不同目标的实际伤害仍分别记战果。资源限频与战果
记录是两件事。

**Q：为什么神代天赋这么长？**
A：因为它们的目标不是成为一排容易平衡的按钮，而是让角色在规则里留下清
楚的轮廓。你可以嫌它们麻烦，这很合理；你也可以选 T1，然后把复杂问题处理
成一次近战攻击。

## 全局法则并存条款（跨天赋钉 12）

V2.0-GA 存在多个"全局法则"来源：世界时钟、G1 繁育（地点摧毁）、G2 双终局
（世末之雨 / 炉心融解）、G5 时间倒流。并存优先级：

1. **G5 时间倒流期间，世界时钟停走**（含 G2 的 2 倍速），终焉灼伤暂停；
2. 倒流终止后，已经建立的 G2 双倍速恢复，即使 G2 已死亡或获救；
3. 世末之雨使 NPC 在法则期间沉沦，法则结束解除、不复活已死 NPC；倒流期间 NPC
   仍受停机约束，律法重建不豁免全局停机或 Terror 拒绝执法；
4. G1 摧毁地点按基线规则处理 G2 残影（G2 钉 3）；
5. 往世层押注在 G5 倒流期间照常每 R0 开市（死者不受动词约束）。

## 十七、首轮数值表 N0（2026-10-26）

这一节把“先填一版没有明显大问题的数值”落成可以直接取用的表。所有值都是设计初值，
尚未经过 GA 对局验证；调整时原位改表，不并存多个数值版本。机制继续服从前文与 RFC，
旧代码、M9 配置和历史风洞记录不自动补齐 GA。后续程序只从配置读数，本次不改配置或代码。

N0 的尺度是 **20 HP、常规攻击 4、一次普通治疗 4、普通外甲耐久 6～10**。
高投入爆发可以显著超过普攻；免费再生、每轮恢复、攻击段数和资源返还必须有边界。
本次数值调整包括：G7 午休由草案 4/6 HP 降为 2/3、补盾由 6 降为 2；G6 自己主动
放弃行动的笑点收益为 0；这些初值优先避免单普攻角色被永久防守循环锁死。

### 17.14 首轮检查与调整顺序

以下是数值表的静态推演口径，不是 GA 引擎跑分：

1. T6 用无模块弓A4打普通防御3/耐久10：前3击各掉HP1、磨甲3；第4击掉HP3、磨甲1。
   4击累计掉HP6且外甲耗尽；之后每击4。锁定后防御floor(3×0.75)=2，推进更快。
2. T3 每轮补玉璋3仍会被A4留下1点本体伤害；G7每轮补盾2小于一次A4架盾消耗4。
   破盾后午休不能从0补盾，须消耗组件和T1修复，避免“2耐久挡整击、再免费补2”的循环。
   G7战斗内光环不自动再生，普通弓不能被“1层挡整击”误实现成永远无伤。
3. 普通治疗付2回4，先打工再治疗需2个T1；在每轮吃一发A4的无甲例子里，两轮净损HP4。
   T7祝祷回3也低于无甲A4；临时针剂/手术/药物另有费用或次数边界。
4. G6初始1笑点若没有外部笑点事件，只能架一次当身；自己放弃不补回1笑点。
5. G3满资源三连发后仍能留3魔力用于终段；G5两人/六人局的基础箭数是2/4，单目标最多2段。
6. G7两件防具价5、两枪价7，开局4信用点再打工4次可支付全部12；跨地点和4次购买仍占行动，
   可以在中盘完成，不要求先攒几十轮。水着自带盾能省2；免费配发不反向刷新融合。

后续实测优先调：普攻对回血/修甲的净推进 → 开局到第一次演出的轮数 → 公演与章节可达性
→ G3/G7多段爆发 → G2/G5终局时长 → 得分分布。一次调整记录参数、原因和同场景前后结果，
不为一个天赋直接叠上新机制。40轮兜底、零永久进展循环或某角色始终无法完成章节都要单列。

**本轮已做的检查（2026-10-26）**：用独立算术脚本检查普通伤害/屏障/减伤/耐久组合
748,800例，确认扣血不超过屏障后余量、耐久不透支、整次承接为0；检查G3费用、G4总池
守恒、G5人数/段数、G7宏基础输出与初期采购账。另枚举G7无限SP、免费架盾、每轮吃A4的
纯防守简化模型：在没有外援、组件/药物与免死的条件下，午休/光环选择无法无限存活。
这只验证这些算术与循环边界，没有运行GA引擎，没有测胜率、控制连锁、走位或十四人平衡。
