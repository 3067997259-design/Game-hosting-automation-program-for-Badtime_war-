## 一、这是什么

V2.0-GA 是 M9-rfc 之后下一代规则的候选设计总集。与 M9 不同，它**先收口底层规则**（计分、
开局、回合、感知、演出、防御、警察、往世层、世界时钟），再让天赋挂载到这些干净的 hook 点上。

设计会话识别的七个病根：
1. 计分投降：`talent_score_multiplier`（槽位乘数）与 `1.5 / 0.5`（生死乘数）；
2. 苟活必胜：名次分 + 唯一生还分占比过高（RL v22 避战流实证，见 DOC-054）；
3. 私宅躲猫猫：6 个 `home_pX` 导致残局无碰撞、RL 动作空间动态膨胀；
4. 40 轮膀胱局：`find/lock/wake/打工/装模块` 全占整轮；
5. 公演官僚：R0 FIFO 排队、队首失效不递补；
6. 警察两极：没对策等死 / 有对策速溶；
7. 认知超载：往世层 26 种魂援表 + 医院永久内甲刮痧 + 全图防毒税。

## 五、全局法则并存条款（跨天赋钉 12）

V2.0-GA 存在多个"全局法则"来源：世界时钟、G1 繁育（地点摧毁）、G2 双终局（世末之雨 /
炉心融解）、G5 时间倒流。并存优先级：

1. **G5 时间倒流期间，世界时钟停走**（含 G2 的 2 倍速），终焉灼伤暂停；
2. 倒流终止后，已建立的 G2 双倍速恢复，即使 G2 已死亡或获救；
3. 世末之雨在法则期间使 NPC 沉沦，法则结束解除、不复活已死 NPC；倒流停机另行保持，
   律法重建不豁免仍生效的全局停机或 Terror 拒绝执法；
4. G1 摧毁地点按基线规则处理 G2 残影（G2 钉 3）；
5. 往世层押注在 G5 倒流期间照常每 R0 开市（死者不受动词约束）。
